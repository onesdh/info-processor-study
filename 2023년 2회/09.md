# 문제 09

## 문제

다음은 C언어 문제이다. 알맞은 출력값을 작성하시오.

```
#include <stdio.h>
#define MAX_SIZE 10

int isWhat[MAX_SIZE];
int point= -1;

int isEmpty() {
    if (point == -1) return 1;
    return 0;
}

int isFull() {
    if (point == 10) return 1;
    return 0;
}

void into(int num) {
    if (point >= 10) printf("Full");
    else isWhat[++point] = num;
}

int take() {
    if (isEmpty() == 1) printf("Empty");
    else return isWhat[point--];
    return 0;
}

int main(int argc, char const *argv[]){
    int e;
    into(5); into(2);

    while(!isEmpty()){
        printf("%d", take());
        into(4); into(1); printf("%d", take());
        into(3); printf("%d", take()); printf("%d", take());
        into(6); printf("%d", take()); printf("%d", take());
    }

    return 0;
}
```

## 1. 문제에서 묻는 것
**스택(Stack)** 의 `into(push)`와 `take(pop)`이 섞여 실행될 때 출력되는 수를 순서대로 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 스택(Stack)
**나중에 넣은 것이 먼저 나오는** LIFO(후입선출) 구조. 접시를 쌓는 것과 같다.
```text
 into(n) = push : 맨 위에 쌓기 (++point 후 저장)
 take()  = pop  : 맨 위에서 꺼내기 (현재 point 값을 꺼낸 뒤 point--)
 point = 맨 위 원소의 인덱스 (-1이면 빈 스택)
```
### (2) 코드의 의미
```c
void into(int num) { ... isWhat[++point] = num; }   // push
int  take()        { ... return isWhat[point--]; }  // pop
int isEmpty() { return point == -1; }
```
`printf("%d", take())` 는 **꺼낸 값을 즉시 출력**한다.

## 3. 실행 과정 (표기: 스택은 왼쪽이 바닥, 오른쪽이 맨 위)
**시작**: `into(5); into(2);` → 스택 `[5, 2]`

`while(!isEmpty())` 의 본문 한 번(스택이 비면 종료):
| 순서 | 실행 | 스택(실행 후) | 출력 |
|---:|---|---|:---:|
| 1 | `printf(take())` | [5] | **2** |
| 2 | `into(4)` | [5, 4] | |
| 3 | `into(1)` | [5, 4, 1] | |
| 4 | `printf(take())` | [5, 4] | **1** |
| 5 | `into(3)` | [5, 4, 3] | |
| 6 | `printf(take())` | [5, 4] | **3** |
| 7 | `printf(take())` | [5] | **4** |
| 8 | `into(6)` | [5, 6] | |
| 9 | `printf(take())` | [5] | **6** |
| 10 | `printf(take())` | [] | **5** |

스택이 비었으므로 while 종료.

출력을 이어 붙이면: `2 1 3 4 6 5` → **213465**

> **정답: `213465`**

## 4. 암기 포인트
- 스택은 **마지막에 넣은 것부터** 나온다. 매 `take`마다 스택을 갱신해 가며 추적한다.
- `isWhat[point--]` 는 **현재 값을 반환한 뒤** point를 줄인다.
