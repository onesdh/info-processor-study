# 문제 14 — Java 문자열 풀과 equals

## 문제

동일 문자열 리터럴과 new String 객체를 참조 비교·내용 비교한 네 결과를 쓰시오.

## 정답

true, false, true, true

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

문자열 리터럴은 풀에서 같은 객체를 공유할 수 있고, new String은 별도 객체를 만든다. equals는 내용을 비교한다.

## 풀이

str1과 str2는 같은 리터럴 객체를 참조해 ==가 true다. str3는 별도 객체라 str1==str3은 false다. 세 문자열의 내용은 같으므로 equals 두 번은 true다.

## 오답 분석

==와 equals를 혼동하지 않는다. 실제 Java에서는 문자열 리터럴에 큰따옴표를 써야 한다. 원문 예시의 작은따옴표는 표기 오류다.

## 암기 포인트

리터럴 == true, new 객체 == false, equals 내용 true.
