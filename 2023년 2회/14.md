## 1. 문제에서 묻는 것
Java의 **문자열 비교**: `==`(주소 비교)와 `equals()`(내용 비교)의 차이, 그리고 **문자열 리터럴 풀(String Pool)** 을 이해하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 문자열이 만들어지는 두 가지 방법
```java
String str1 = "Programming";            // 리터럴: String Pool에서 같은 내용이면 같은 객체를 재사용
String str2 = "Programming";            // str1과 같은 객체를 가리킴
String str3 = new String("Programming");// new: 힙에 항상 새로운 객체 생성
```
```text
 String Pool            Heap
 ┌─────────────┐        ┌─────────────┐
 │ "Programming"│◀─ str1 │"Programming"│◀─ str3 (new로 만든 별개 객체)
 └─────────────┘◀─ str2  └─────────────┘
```
### (2) `==` 와 `equals`
| 비교 | 의미 |
|---|---|
| `==` | **같은 객체(주소)** 인가 |
| `equals()` | **문자열 내용**이 같은가 |

## 3. 결과
| 식 | 판단 | 결과 |
|---|---|:---:|
| `str1 == str2` | 둘 다 **풀의 같은 객체** | **true** |
| `str1 == str3` | str3는 `new`로 만든 **다른 객체** | **false** |
| `str1.equals(str3)` | 내용 같음 | **true** |
| `str2.equals(str3)` | 내용 같음 | **true** |

> **정답**
> ```
> true
> false
> true
> true
> ```
> (원문 코드는 `'`로 작성된 오타 등이 있으나 `"Programming"` 문자열 기준)

## 4. 암기 포인트
- **리터럴끼리는 `==`가 true**, `new String`과는 false.
- 문자열 내용 비교는 항상 `equals()`.
