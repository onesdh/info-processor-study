# 문제 11

## 문제

단일 인스턴스를 공유하는 패턴과 자료구조를 순회하며 연산을 추가하는 패턴을 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

1. Singleton 2. Visitor

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

Singleton은 인스턴스 수를 하나로 제한하고, Visitor는 객체 구조와 연산을 분리한다.

## 풀이

DB 연결 풀처럼 공유 자원을 하나의 인스턴스로 관리하는 것은 Singleton이다. Visitor는 구성 객체를 순회하며 자료구조 클래스를 크게 변경하지 않고 새로운 연산을 추가한다.

## 오답 분석

Observer는 상태 변경 통지, Strategy는 알고리즘 교체다. 단일 인스턴스는 생성 패턴 Singleton이다.

## 암기 포인트

하나만 생성 Singleton, 구조에 연산 Visitor.
