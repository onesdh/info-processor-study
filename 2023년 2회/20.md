# 문제 20

## 문제

다음 설명에 대한 알맞는 답을 작성하시오.

1.

- 하향식 테스트 시 상위 모듈은 존재하나 하위 모듈이 없는 경우의 테스트를 위해 임시 제공되는 모듈이다.  
- 특별한 목적의 소프트웨어를 구현하는 것으로 컴포넌트를 개발하거나 테스트할 때 사용된다.  
- 서버-클라이언트 구조에서 서버만 구현된 상태로 테스트를 해보고 싶을때 단순히 값만 넘겨주는 가상의 클라이언트를 만들어서 테스트 할 수 있다.

2.

- 상향식 테스트 시 상위 모듈 없이 하위 모듈이 존재할 때 하위 모듈 구동 시 자료 입출력을 제어하기 위한 제어 모듈(소프트웨어)이다.  
- 서버-클라이언트 구조에서 클라이언트만 구현된 상태로 테스트를 해보고 싶을때 접속 인증 등의 간단한 기능만 하는 가상의 서버를 만들어서 테스트 할 수 있다.

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**통합 테스트에서 쓰는 가짜 모듈 2종류**(하향식용 / 상향식용)의 이름을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 통합 테스트와 더미 모듈
모듈을 합쳐 테스트할 때, **아직 개발되지 않은 모듈을 대신하는 임시 모듈**이 필요하다.
```text
          [ 상위 모듈 ]
           /         \
    [ 하위 모듈 B ] [ 하위 모듈 C ]
```
### (2) 스텁 vs 드라이버
| 구분 | **스텁(Stub)** | **드라이버(Driver)** |
|---|---|---|
| 테스트 방식 | **하향식** (상위부터) | **상향식** (하위부터) |
| 대체하는 모듈 | **하위 모듈** (아직 없음) | **상위 모듈** (아직 없음) |
| 역할 | **호출을 받아** 정해진 값만 반환 | 하위 모듈을 **호출**해 입력을 주고 결과 확인 |
| 비유 | 대본대로 대답하는 **가짜 하위 모듈** | 하위 모듈을 구동시키는 **테스트용 상위 모듈** |

```text
 하향식 : 실제 상위 ─▶ [스텁]           스텁이 "고정된 값"을 돌려줌
 상향식 : [드라이버] ─▶ 실제 하위         드라이버가 입력을 넣고 출력을 검사
```
### (3) 서버-클라이언트 예
- **스텁** = 서버만 구현된 상태에서 **값만 넘겨주는 가상의 클라이언트**를 만들어 서버를 시험
- **드라이버** = 클라이언트만 구현된 상태에서 **간단한 기능(인증 등)만 하는 가상의 서버**를 두고 시험

## 3. 문제 풀이
| 번호 | 단서 | 정답 |
|---|---|---|
| 1 | **하향식** 테스트, **상위는 있고 하위가 없을 때** 임시 모듈 | **스텁(Stub)** |
| 2 | **상향식** 테스트, **상위 없이 하위만** 있을 때 입출력 제어 모듈 | **드라이버(Driver)** |

> **정답: 1. 스텁 / 2. 드라이버**

## 4. 암기 포인트
- **하향식 = 스텁**, **상향식 = 드라이버**.
- 드라이버는 하위 모듈을 **운전(drive)해서** 구동한다.
