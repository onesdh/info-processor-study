# 문제 04

## 문제

다음은 테이블에 데이터를 삽입하기 위한 과정이다. 보기의 조건식에 맞게 데이터 삽입을 위한 SQL문을 작성하시오.

보기

CREATE TABLE 학생 (  
&nbsp;&nbsp;학번 int,  
&nbsp;&nbsp;이름 varchar(20),  
&nbsp;&nbsp;학년 int,  
&nbsp;&nbsp;전공 varchar(30),  
&nbsp;&nbsp;전화번호varchar(20)  
);

결과값

[학생]

| 학번 | 이름 | 학년 | 전공 | 전화번호 |
|---|---|---|---|---|
| 9830287 | 뉴진스 | 3 | 경영학개론 | 010-1234-1234 |

조건

문자열일 경우 작은따음표  
(작은따음표가 아니라 다른 단어로 명시되었습니다.)

<summary><strong>정답 보기</strong></summary>

INSTER INTO 학생(학번,이름,학년,전공,전화번호)  
VALUES(9830287,'뉴진스',3,'경영학개론','010-1234-1234');

## 1. 문제에서 묻는 것
표에 주어진 한 행의 데이터를 `학생` 테이블에 **삽입하는 INSERT문**을 작성하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) INSERT 문법
```sql
INSERT INTO 테이블명 (열1, 열2, ...)
VALUES (값1, 값2, ...);
```
| 부분 | 의미 |
|---|---|
| `INSERT INTO 테이블명` | 어느 테이블에 추가할지 |
| `(열1, 열2...)` | 값을 넣을 **열 목록**(생략 가능, 순서대로 전부 넣을 때) |
| `VALUES (...)` | 열 목록과 **같은 순서**의 값 |

### (2) 값 표기 규칙
| 자료형 | 표기 | 예 |
|---|---|---|
| 숫자(int) | 그대로 | 9830287, 3 |
| **문자열(varchar)** | **작은따옴표 `'...'`** | '뉴진스', '경영학개론', '010-1234-1234' |

## 3. 문제 풀이
테이블 정의: `학생(학번 int, 이름 varchar(20), 학년 int, 전공 varchar(30), 전화번호 varchar(20))`
넣을 값: 9830287 / 뉴진스 / 3 / 경영학개론 / 010-1234-1234

| 열 | 자료형 | 넣을 값 | 표기 |
|---|---|---|---|
| 학번 | int | 9830287 | `9830287` |
| 이름 | varchar | 뉴진스 | `'뉴진스'` |
| 학년 | int | 3 | `3` |
| 전공 | varchar | 경영학개론 | `'경영학개론'` |
| 전화번호 | varchar | 010-1234-1234 | `'010-1234-1234'` |

```sql
INSERT INTO 학생 (학번, 이름, 학년, 전공, 전화번호)
VALUES (9830287, '뉴진스', 3, '경영학개론', '010-1234-1234');
```
> **정답**: 위 SQL문 (원문 정답 표기의 `INSTER`는 **`INSERT`** 의 오타)

## 4. 암기 포인트
- **문자열은 작은따옴표**, 숫자는 따옴표 없이.
- 열 순서와 값 순서를 **반드시 일치**시킨다.
