# 문제 12

## 문제

다음 내용에서 설명하는 문제에 대해 보기에 알맞는 답을 골라 작성하시오.

( 1 ) Code는 데이터 전송시 1 비트의 에러를 정정할 수 있는, 오류정정부호의 일종으로 미국의 Bell 연구소의 Hamming에 의해 고안되었다. 선형블록부호 및 순회부호에 속에 속한다.

( 2 ) 은/는 송신측이 전송할 문자나 프레임에 부가적 정보(Redundancy)를 첨가하여 전송하고 수신측이 이 부가적 정보를 이용하여 에러검출 및 에러정정을 하는 방식이다.

( 3 ) 은/는 데이터 전송 과정에서 오류가 발생하면 송신 측에 재전송을 요구하는 방식이다. 오류를 검출하는 방법은 Parity검사와 CRC, 블록 합 검사 등이 있다.

( 4 ) 은/는 데이터가 저장장치 내의 한 장소에서 다른 장소로 이동되거나, 컴퓨터들간에 전송될 때, 데이터가 유실 또는 손상되었는지 여부를 점검하는 기술과 관련된 용어이다.

( 5 ) 은/는 네트워크 등을 통하여 데이터를 전송할 때 전송된 데이터에 오류가 있는지를 확인하기 위한 체크값을 결정하는 방식을 말한다.

## 1. 문제에서 묻는 것
**오류 검출·정정 용어**(Hamming, FEC, BEC, Parity, CRC)를 설명과 연결하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 오류 제어의 큰 그림
```text
                 오류 제어
        ┌───────────┴─────────────┐
   FEC (전진 오류 수정)        BEC (후진 오류 수정 = ARQ)
   수신측이 스스로 정정         오류 검출 → 재전송 요구
   대표: Hamming 코드          대표: Parity, CRC, 블록합
```
| 용어 | 설명 |
|---|---|
| **Hamming 코드** | 검사 비트를 여러 개 넣어 **1비트 오류를 정정**(Bell 연구소 Hamming 고안) |
| **FEC** (Forward Error Correction) | 부가 정보(Redundancy)를 이용해 **수신측이 직접** 검출·정정, **재전송 불필요** |
| **BEC** (Backward Error Correction) | **오류 발생 시 재전송 요구**. 검출 방법은 Parity, CRC, 블록 합 검사 |
| **Parity** | **1비트 검사 비트**를 붙여 오류를 **점검**(데이터 손상 여부 확인) |
| **CRC** | **다항식 나눗셈**으로 **체크값**을 만들어 오류 확인 |

## 3. 문제 풀이
| 번호 | 단서 | 정답 |
|---|---|---|
| (1) | **1비트 에러 정정**, Bell 연구소 Hamming 고안 | **Hamming** (Code) |
| (2) | **부가 정보(Redundancy)** 로 수신측이 **에러 검출 및 정정** | **FEC** |
| (3) | 오류 발생 시 **송신 측에 재전송 요구**, 검출은 Parity/CRC/블록합 | **BEC** |
| (4) | 데이터 이동·전송 중 **유실·손상 여부 점검** 기술 | **Parity** (원문 정답 기준) |
| (5) | 전송 데이터에 오류가 있는지 확인하기 위한 **체크값을 결정하는 방식** | **CRC** |

> **정답: 1. hamming 2. FEC 3. BEC 4. parity 5. CRC**

## 4. 암기 포인트
- **FEC = 해밍(정정)**, **BEC = 패리티·CRC(검출 후 재전송)**.
- 해밍 코드는 **1비트 오류 정정**, 패리티는 **1비트 오류 검출**만.
