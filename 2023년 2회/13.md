# 문제 13

## 문제

다음은 HDLC 프로토콜에 대한 설명이다. 보기 안에 알맞는 답을 골라 작성하시오.

( 1 ) 프레임은 Seq, Next, P/F의 필드를 가진다. 또한 맨 처음 비트를 0으로 가진다. Seq는 송신용 순서번호를 가지고 있다. Next는 응답용 순서번호를 가진다. P/F는 P가 1로 설정된 경우 주국에서 종국에 데이터 전송을 허용하는 것을 의미하고 F가 1로 설정된 경우 종국에서 주국으로 데이터 전송을 하는 것을 의미한다.

( 2 ) 프레임은 맨 앞의 필드가 1로 되어 있어 정보 프레임이 아니라는 것을 나타내고 다음 비트가 0이 나와있다. Type의 경우에는 2비트를 가지고 있어 4가지의 종류로 나누어진다.  데이터를 보내는 역할이 아니라 응답의 기능을 수행하므로 Seq에 대한 값은 필요가 없고 다음 프레임을 요구하는 Next만 존재한다.

( 3 ) 프레임은 순서 번호가 없는 프레임을 의미한다. 첫 번째 비트와 두 번째 비트가 모두 1로 설정되어 있다. 여러 종류를 가지고 있는데 Type의 2비트와 Modifier의 3비트를 합쳐 5비트를 통해 종류를 나눈다.

( 4 ) 은/는 두 호스트 모두 혼합국으로 동작한다. 양쪽에서 명령과 응답을 전송할 수 있다.

( 5 ) 은/는 불균형 모드로 주국의 허락 없이 종국에서 데이터를 전송할 수 있다.

## 1. 문제에서 묻는 것
**HDLC**의 프레임 종류(정보/감독/비번호)와 동작 모드(비동기 균형/비동기 응답)를 설명으로 구분하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) HDLC
OSI 2계층(데이터 링크)에서 쓰는 **비트 중심 프로토콜**. 데이터를 **프레임**으로 전송하며 **흐름·오류 제어**를 한다.

### (2) 프레임 구분은 제어부의 첫 비트로
```text
 제어부(Control) 8비트 앞부분:
   0 ........       → 정보(I) 프레임   : Seq(송신 순서번호) | P/F | Next(응답 순서번호)
   1 0 ......       → 감독(S) 프레임   : Type(2비트) | P/F | Next   (Seq 없음)
   1 1 ......       → 비번호(U) 프레임 : Type(2비트) | P/F | Modifier(3비트)
```
| 프레임 | 시작 비트 | 역할 |
|---|:---:|---|
| **정보(I)** | `0` | **사용자 데이터** 전송 (Seq, Next, P/F) |
| **감독(S)** | `10` | **흐름·오류 제어**, 응답 (Next만 존재, 데이터 없음) |
| **비번호(U)** | `11` | **순서 번호 없이** 링크 설정·해제, 모드 설정 (Type 2비트+Modifier 3비트 = 5비트 종류) |

### (3) 동작 모드
| 모드 | 설명 |
|---|---|
| 표준 응답(NRM) | 종국은 주국의 허락 받아 전송 |
| **비동기 응답 모드(ARM)** | **불균형** 모드, **주국 허락 없이** 종국이 전송 가능 |
| **비동기 균형 모드(ABM)** | **두 호스트 모두 혼합국**, 양쪽에서 명령·응답 전송 |

## 3. 문제 풀이
| 번호 | 단서 | 정답 |
|---|---|---|
| (1) | 첫 비트 **0**, **Seq/Next/P/F** | ㄷ. **정보** |
| (2) | 첫 비트 **1**, 다음 비트 **0**, 응답 기능, **Next만** 존재 | ㄴ. **감독** |
| (3) | 첫 두 비트가 **모두 1**, **순서 번호 없음**, Type+Modifier 5비트 | ㅂ. **비번호** |
| (4) | 두 호스트 모두 **혼합국**, 양쪽 명령·응답 | ㅊ. **비동기균형** |
| (5) | **불균형 모드**, 주국 허락 없이 종국이 전송 | ㅋ. **비동기응답** |

> **정답: 1. ㄷ 2. ㄴ 3. ㅂ 4. ㅊ 5. ㅋ**

## 4. 암기 포인트
- 프레임 첫 비트: **0=정보, 10=감독, 11=비번호**.
- 균형=동등, 불균형=주-종 구조.
