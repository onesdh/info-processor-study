<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
`DROP VIEW 학생 (   );` 의 괄호에 들어갈 키워드 — **"참조하는 다른 VIEW나 제약조건까지 모두 삭제"** 하는 옵션을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) VIEW(뷰)
**하나 이상의 테이블에서 만든 "가상 테이블"** 이다. 실제 데이터를 저장하지 않고 **저장된 SELECT 문**처럼 동작한다.

### (2) DROP의 옵션: CASCADE vs RESTRICT
```sql
DROP VIEW 뷰이름 [CASCADE | RESTRICT];
```
| 옵션 | 동작 |
|---|---|
| **CASCADE** | 삭제 대상을 **참조하는 다른 뷰·제약조건까지 연쇄적으로(폭포처럼) 함께 삭제** |
| **RESTRICT** | 다른 객체가 참조 중이면 **삭제하지 않고 거부**(오류) |

```text
 학생(뷰)를 참조 ─▶ 우수학생(뷰), 학생제약조건 …
 DROP VIEW 학생 CASCADE;   → 학생 + 학생을 참조하는 객체 모두 삭제
 DROP VIEW 학생 RESTRICT;  → 참조하는 객체가 있으면 삭제 거부
```
## 3. 문제 풀이
| 단서 | 해당 |
|---|---|
| 학생 테이블을 참조하는 **다른 VIEW나 제약조건까지 모두 삭제** | **CASCADE** |

> **정답: CASCADE** (대소문자 무관)

## 4. 암기 포인트
- **CASCADE = 연쇄 삭제**, **RESTRICT = 참조 중이면 거부**.
- 같은 옵션이 `DROP TABLE`, `DROP SCHEMA`, 참조 무결성(`ON DELETE CASCADE`)에도 쓰인다.
