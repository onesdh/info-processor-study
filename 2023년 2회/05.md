# 문제 05

## 문제

다음은 C언어의 문제이다. 알맞은 출력값을 작성하시오.

```
#include <stdio.h>

void main(){
    int n[3] = {73, 95, 82};
    int sum = 0;

    for(int i=0;i<3;i++){
        sum += n[i];
    }

    switch(sum/30){
        case 10:
        case 9: printf("A");
        case 8: printf("B");
        case 7:
        case 6: printf("C");
        default: printf("D");
    }
}
```

## 핵심 개념

switch는 일치 case 이후 break 전까지 아래 case 본문을 계속 실행한다.

## 풀이

합은 73+95+82=250이고 정수 나눗셈 250/30은 8이다. case 8에서 B를 출력하고 다음 case 7·6을 지나 case 6의 C, default의 D까지 출력한다.

## 오답 분석

case 8 뒤 break가 없으므로 B만 출력하지 않는다. 값은 실수 나눗셈이 아니라 정수 나눗셈이다.

## 암기 포인트

case 8 진입 후 break 전까지 BCD.
