# 문제 05

## 문제

다음은 C언어의 문제이다. 알맞은 출력값을 작성하시오.

```
#include <stdio.h>

void main(){
    int n[3] = {73, 95, 82};
    int sum = 0;

    for(int i=0;i<3;i++){
        sum += n[i];
    }

    switch(sum/30){
        case 10:
        case 9: printf("A");
        case 8: printf("B");
        case 7:
        case 6: printf("C");
        default: printf("D");
    }
}
```

## 1. 문제에서 묻는 것
**`switch` 문의 fall-through(break 없는 연속 실행)** 를 이해하고 출력 결과를 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) switch와 fall-through
- `switch(값)`은 **일치하는 `case`로 점프**한 뒤 아래로 실행한다.
- **`break`를 만나기 전까지는 다음 case 문도 계속 실행**한다(fall-through).
- 일치하는 case가 없으면 `default`.

```c
switch (8) {
    case 10:
    case 9: printf("A");     // 건너뜀
    case 8: printf("B");     // ← 여기서 시작
    case 7:
    case 6: printf("C");     // 이어서 실행
    default: printf("D");    // 이어서 실행
}
```
### (2) 정수 나눗셈
`sum / 30` 은 **몫만** (소수점 버림).

## 3. 실행 과정
| 단계 | 계산 | 값 |
|---|---|---:|
| ① 합계 | 73 + 95 + 82 | 250 |
| ② switch 값 | 250 / 30 = 8.33… → 정수 몫 | **8** |

**switch(8)** → `case 8`로 점프
| 실행 순서 | 문장 | 출력 |
|---:|---|:---:|
| 1 | `case 8:` `printf("B")` (break 없음) | **B** |
| 2 | `case 7:` (실행문 없음, 통과) | |
| 3 | `case 6:` `printf("C")` (break 없음) | **C** |
| 4 | `default:` `printf("D")` | **D** |

> **정답: `BCD`**

## 4. 암기 포인트
- `break`가 없으면 **아래 case를 계속 실행**한다. `case 9`의 A는 건너뛴다(점프 시작점이 8).
- `250/30`은 8.33이 아니라 **8**.
