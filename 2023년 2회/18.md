# 문제 18 — 선택 정렬 비교 연산자

## 문제

주어진 교환형 선택 정렬이 오름차순으로 정렬되도록 비교 연산자를 채우시오.

## 정답

>

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

현재 원소가 뒤 원소보다 클 때 교환하면 작은 값이 앞으로 온다.

## 풀이

E[i]>E[j]인 경우 두 값을 바꾸는 내부 반복을 수행한다. 이를 통해 각 i 위치에 더 작은 값이 놓이고 최종 배열은 오름차순이 된다.

## 오답 분석

<를 쓰면 더 큰 값을 앞으로 보내 내림차순 결과가 된다.

## 암기 포인트

오름차순에서 앞 값이 크면 교환.
