## 1. 문제에서 묻는 것
**선택 정렬**(오름차순)에서 두 원소를 교환하는 조건의 **비교 연산자**를 고르는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 선택 정렬(Selection Sort) 아이디어
기준 위치 `i`에 **알맞은 값(오름차순이면 가장 작은 값)** 이 오도록, `i` 뒤의 모든 `j`와 비교해 **더 작은 값이 있으면 교환**한다.
```text
 오름차순: i번째 값이 j번째 값보다 "크면" 교환 → 작은 값이 앞으로 이동
```
### (2) 코드 구조
```c
do { j = i + 1;
     do {
         if (E[i] ( ? ) E[j]) { swap(E[i], E[j]); }
         j++;
     } while (j < n);
     i++;
} while (i < n - 1);
```
## 3. 풀이
| 오름차순 조건 | 의미 |
|---|---|
| `E[i] > E[j]` | 앞 값이 뒤 값보다 크면 **교환** → 작은 값이 앞으로 → **오름차순** ✅ |
| `E[i] < E[j]` | 앞 값이 더 작으면 교환 → 큰 값이 앞으로 → 내림차순 ❌ |

**추적(일부)** `E = {64, 25, 12, 22, 11}`
| i | 비교·교환 결과 |
|---:|---|
| 0 | 64 > 25 교환 → {25,64,12,22,11}, 25 > 12 교환 → {12,64,25,22,11}, 12 > 22? 아니오, 12 > 11 교환 → **{11,64,25,22,12}** |
| 1 | 64 > 25 교환 → {11,25,64,22,12}, 25 > 22 → {11,22,64,25,12}, 22 > 12 → **{11,12,64,25,22}** |
| 2 | 64 > 25 → {11,12,25,64,22}, 25 > 22 → **{11,12,22,64,25}** |
| 3 | 64 > 25 → **{11,12,22,25,64}** |

최종 출력: `11 12 22 25 64` (오름차순)

> **정답: `>`**

## 4. 암기 포인트
- 오름차순 정렬의 교환 조건은 **앞 > 뒤**, 내림차순은 **앞 < 뒤**.
- 선택 정렬의 시간 복잡도: **O(n²)**.
