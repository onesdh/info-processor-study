# 문제 15

## 문제

다음 보기는 암호화 알고리즘에 대한 내용이다. 대칭키와 비대칭키에 해당하는 보기의 내용을 작성하시오

대칭키 : (              )

비대칭키 : (                    )

보기

DES, RSA, AES, ECC,  ARIA, SEED

## 1. 문제에서 묻는 것
암호화 알고리즘을 **대칭키 방식**과 **비대칭키 방식**으로 분류하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 대칭키 vs 비대칭키
| 구분 | **대칭키(비밀키)** | **비대칭키(공개키)** |
|---|---|---|
| 키 | 암호화·복호화에 **같은 키** | **공개키(암호화) / 개인키(복호화)** 쌍 |
| 속도 | **빠름** | 느림 |
| 키 관리 | 키를 안전하게 **공유**하기 어려움 | 공개키는 공개 가능, 키 관리 쉬움 |
| 용도 | 대용량 데이터 암호화 | 키 교환, 전자서명, 인증 |

```text
 대칭키 : [평문] ─(키 K)─▶ [암호문] ─(같은 키 K)─▶ [평문]
 비대칭 : [평문] ─(공개키)─▶ [암호문] ─(개인키)─▶ [평문]
```
### (2) 알고리즘 분류
| 방식 | 알고리즘 | 비고 |
|---|---|---|
| **대칭키** | **DES** | 56비트 키, 취약해 폐기 |
| | **AES** | DES 대체, 128/192/256비트 |
| | **SEED** | 한국(KISA) 개발, 128비트 블록 |
| | **ARIA** | 한국 국가보안기술연구소 개발 |
| **비대칭키** | **RSA** | **소인수분해**의 어려움 기반 |
| | **ECC** | **타원 곡선** 기반, 짧은 키로 높은 안전성 |

## 3. 문제 풀이
| 구분 | 보기에서 해당하는 것 |
|---|---|
| 대칭키 | **DES, AES, ARIA, SEED** |
| 비대칭키 | **RSA, ECC** |

> **정답: 대칭키 - DES, AES, ARIA, SEED / 비대칭키 - RSA, ECC**

## 4. 암기 포인트
- 비대칭키는 **RSA, ECC(+ ElGamal, DSA)** 로 외우고, 나머지는 대칭키.
- 한국 표준 대칭키: **SEED, ARIA**.
