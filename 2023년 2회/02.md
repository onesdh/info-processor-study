## 1. 문제에서 묻는 것
**4620원**을 1000원·500원·100원·10원으로 나눌 때 **각 단위의 개수**를 `/`(몫)와 `%`(나머지)만으로 구하는 문제다. (욕심쟁이 방식)

## 2. 먼저 알아야 할 개념
### (1) 정수 나눗셈 `/` 와 나머지 `%`
정수끼리 나누면 **몫**(소수점 버림), `%`는 **나머지**.
| 식 | 결과 |
|---|---:|
| 4620 / 1000 | 4 (몫) |
| 4620 % 1000 | 620 (나머지) |

### (2) 거스름돈 계산 원리
큰 단위부터 **몫으로 장수를 구하고**, **나머지로 다음 단위**를 계속 계산한다.
```text
 4620원 ─ 1000원 : 몫 4장,  나머지 620
          620원 ─ 500원 : 몫 1개, 나머지 120
                  120원 ─ 100원 : 몫 1개, 나머지 20
                           20원 ─ 10원 : 몫 2개, 나머지 0
```
## 3. 각 괄호 풀이
| 변수 | 의미 | 식 | 계산 | 값 |
|---|---|---|---|---:|
| a | 1000원 장수 | `m / 1000` | 4620 / 1000 | **4** |
| b | 500원 개수 | `(m % 1000) / 500` | 620 / 500 | **1** |
| c | 100원 개수 | `(m % 500) / 100` | 120 / 100 | **1** |
| d | 10원 개수 | `(m % 100) / 10` | 20 / 10 | **2** |

- 500원: `m % 1000` = 620 → `/ 500` = 1
- 100원: `m % 500` = 120 → `/ 100` = 1 (500원 단위를 쓰고 남은 값)
- 10원: `m % 100` = 20 → `/ 10` = 2

> **정답**
> a: `m / 1000`
> b: `(m % 1000) / 500`
> c: `(m % 500) / 100`
> d: `(m % 100) / 10`

## 4. 암기 포인트
- 단위가 큰 순서로 **나머지를 넘겨가며** 계산한다.
- 주어진 항목(`/`, `%`, 괄호, 숫자)만 사용해야 한다는 조건에 맞는 형태.
