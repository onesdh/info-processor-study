# 문제 16

## 문제

다음 괄호안에 알맞는 답을 작성하시오.

- ( ) 란 임의의 크기를 가진 데이터(Key)를 고정된 크기의 데이터(Value)로 변화시켜 저장하는 것이다.  
- 키에 대한 ( ) 값을 사용하여 값을 저장하고 키-값 쌍의 갯수에 따라 동적으로 크기가 증가한다.  
- ( ) 값 자체를 index로 사용하기 때문에 평군 시간복잡도가 O(1) 로 매우 빠르다  
- ( ) 함수는 임의의 길이의 데이터를 고정된 길이의 데이터로 매핑하는 함수이다.  
- ( ) 함수는 큰 파일에서 중복되는 레코드를 찾을 수 있기 때문에 데이터베이스 검색이나 테이블 검색의 속도를 가속할 수 있다.

해시 or 해싱 or hash

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
"임의 크기의 데이터를 **고정 크기 값**으로 변환해 저장", "값 자체를 **인덱스**로 사용, 평균 **O(1)**" → 어떤 자료구조/기법인지 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 해시(Hash)와 해시 함수
**해시 함수**는 키(길이가 제각각)를 **고정 길이의 숫자(해시값)** 로 바꿔 준다. 이 해시값을 **배열의 인덱스**로 삼아 데이터를 저장하는 것이 **해싱(Hashing)** 이고, 이 구조가 **해시 테이블**이다.

```text
 키 "apple" ─ 해시 함수 ─▶ 3  ──▶ [0][1][2][ apple 데이터 ][4]...   (인덱스 3에 저장)
 키 "banana" ─ 해시 함수 ─▶ 7  ──▶ [ ... ][7: banana 데이터 ]
 검색: 키 → 해시값 계산 → 해당 인덱스로 바로 접근  ⇒ 평균 O(1)
```
### (2) 특징
| 특징 | 내용 |
|---|---|
| 속도 | 검색·삽입·삭제 **평균 O(1)** (최악 O(n), 충돌 많을 때) |
| 충돌(Collision) | 서로 다른 키가 같은 해시값 → **체이닝, 개방 주소법**으로 해결 |
| 크기 | 키-값 쌍 개수에 따라 **동적으로 확장** |
| 활용 | 사전(dict), 캐시, DB 인덱스, 비밀번호 저장(암호용 해시), 중복 탐지 |

## 3. 문제 풀이
| 단서 | 해시 |
|---|---|
| 임의 크기 데이터(Key) → **고정 크기 데이터(Value)** 변환·저장 | ✅ |
| **해시값**을 index로 사용, 평균 **O(1)** | ✅ |
| 임의 길이 데이터를 고정 길이로 **매핑하는 함수** = 해시 함수 | ✅ |
| 큰 파일에서 **중복 레코드를 찾아** 검색 가속 | ✅ |

> **정답: 해시 (Hash, 해싱)**
