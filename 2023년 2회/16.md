# 문제 16 — 해시와 해싱

## 문제

임의 길이 키를 고정 길이 값으로 변환하고 평균 O(1) 검색을 지원하는 기법을 쓰시오.

해시 (Hashing)

## 핵심 개념

해시 함수는 다양한 길이 입력을 고정 크기 값으로 매핑하며 해시 테이블 인덱스 생성에 사용된다.

## 풀이

키를 해시 함수에 넣어 버킷 위치를 계산하면 평균적으로 빠른 조회가 가능하다. 서로 다른 키가 같은 값에 매핑되는 충돌은 별도 방식으로 처리해야 한다.

## 오답 분석

해시는 암호화처럼 역변환을 전제로 하지 않는다. 입력 길이와 출력 크기도 다르다.

## 암기 포인트

키를 고정 길이 해시값으로 매핑.
