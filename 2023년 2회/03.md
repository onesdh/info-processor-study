## 1. 문제에서 묻는 것
`gets`로 세 번 입력을 받아 세 개의 포인터에 저장했을 때, **세 포인터 모두 같은 배열을 가리킨다**는 것을 알아야 풀 수 있는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 전역 배열과 포인터 반환
```c
char n[30];            // 전역 배열: 프로그램 전체에서 단 하나만 존재
char *test() {
    gets(n);           // 입력을 n에 저장 (이전 내용을 덮어씀)
    return n;          // 배열 n의 주소를 반환
}
```
`test()`를 몇 번 호출해도 **같은 배열 `n`의 주소**가 반환된다.

### (2) 포인터는 주소만 저장한다
```text
 test1 ──┐
 test2 ──┼──▶ n[30]   (하나뿐인 배열)
 test3 ──┘
```
포인터 3개는 **서로 다른 문자열이 아니라 같은 곳을 가리킨다.** 그래서 마지막에 입력한 값이 모두에게 보인다.

## 3. 실행 과정 (입력: 홍길동 → 김철수 → 박영희)
| 단계 | 호출 | 배열 n의 내용 | 포인터 상태 |
|---|---|---|---|
| ① | `test1 = test()` (홍길동 입력) | "홍길동" | test1 → n |
| ② | `test2 = test()` (김철수 입력) | **"김철수"로 덮어씀** | test2 → n |
| ③ | `test3 = test()` (박영희 입력) | **"박영희"로 덮어씀** | test3 → n |

출력 시점에 n의 내용은 **"박영희"** → 세 줄 모두 같은 값

```text
 printf(test1) → 박영희
 printf(test2) → 박영희
 printf(test3) → 박영희
```
> **정답**
> ```

> 박영희
> 박영희
> ```

## 4. 암기 포인트
- 포인터는 문자열의 **복사본이 아니라 주소**를 가진다.
- 같은 버퍼를 재사용하면 **이전 입력은 사라진다** (각각 저장하려면 배열을 3개 쓰거나 `malloc`/`strcpy`).
- (참고) 원문 코드는 `stdio` 오타·따옴표 누락 등이 있으나 의도한 동작을 기준으로 한다.
