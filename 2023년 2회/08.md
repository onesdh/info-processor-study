# 문제 08

## 문제

다음 내용에 알맞는 답을 작성하시오.

- 소프트웨어에서 워터마크 삭제등과 같이 소프트웨어가 불법으로 변경(unauthorized modifications)되었을 경우, 그 소프트웨어가 정상 수행되지 않게 하는 기법이다.  
- 소프트웨어 변조 공격을 방어하기 위해 프로그램에 변조검증코드(tamper-proofing code)를 삽입하는 것도 한 방법으로  
- 변조검증코드의 용도는 첫째 프로그램이 변경되었는지를 탐지하는 것이고, 둘째는 변조가 탐지되었다면 프로그램이 실행되지 않게 한다.  
- 소프트웨어의 위변조 방지 역공학 기술의 일종으로 디지털 콘텐츠의 관련 산업이나 전자상거래 또는 보호해야 할 소프트웨어가 있는 다양한 산업 분야에 적용된다.

## 1. 문제에서 묻는 것
"소프트웨어가 **불법으로 변경**(워터마크 삭제 등)되면 **정상 수행되지 않게** 하는 기법, **변조검증코드** 삽입" → 어떤 기술인지 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 템퍼 프루핑(Tamper Proofing, 변조 방지)
**tamper = 함부로 변경하다**, **proofing = 방지**. 소프트웨어가 **무단으로 수정(크랙, 워터마크 제거, 패치)되었는지 스스로 탐지**하고, 변경이 확인되면 **실행을 중단**하게 만드는 보호 기법이다.

```text
 프로그램 실행 시작
   │
   ▼
 [ 변조검증코드 ]  ── 해시/체크섬으로 자신의 코드 무결성 확인
   ├─ 정상 ─▶ 계속 실행
   └─ 변조 감지 ─▶ 실행 중단(프로그램 종료/오동작)
```
### (2) 변조검증코드의 용도
| 용도 | 내용 |
|---|---|
| 1. **탐지** | 프로그램이 변경되었는지 **확인** |
| 2. **대응** | 변조가 탐지되면 프로그램이 **실행되지 않게** 함 |

### (3) 관련 SW 보호 기술
| 기술 | 목적 |
|---|---|
| **템퍼 프루핑** | **변조 방지** (변조 탐지 + 실행 차단) |
| 난독화(Obfuscation) | 코드를 **읽기 어렵게** 만듦(역공학 방지) |
| 워터마킹 | 소유권 표시를 **삽입** |
| DRM | 디지털 저작권 관리 |

## 3. 문제 풀이
| 단서 | 템퍼 프루핑 |
|---|---|
| **불법 변경** 시 정상 수행되지 않게 함 | ✅ |
| **변조검증코드(tamper-proofing code)** 삽입 | ✅ |
| 변경 탐지 → 실행 못 하게 함, **위변조 방지 역공학 방지** | ✅ |

> **정답: 템퍼 프루핑 (Tamper Proofing)**
