# 문제 15

## 문제

다음은 C코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
#include <stdio.h>
int main() {
    int x=7, y=4, z;
    z = y%3<3 ? 2 : 1;
    z = z & z >> 1;
    z = x>5 && z<=3 ? z*x : z/x;
    printf("%d", z);
    return 0;
}
```

## 1. 문제에서 묻는 것
**삼항 연산자, 비트 AND(`&`), 시프트(`>>`), 논리 AND(`&&`)** 와 **연산자 우선순위**가 섞인 문제다. 한 줄씩 정확히 계산해야 한다.

## 2. 먼저 알아야 할 개념
### (1) 삼항 연산자
`조건 ? 참일 때 값 : 거짓일 때 값`

### (2) 비트 연산
| 연산 | 의미 | 예 (2와 1) |
|---|---|---|
| `&` | **비트 AND** (둘 다 1이면 1) | `10 & 01 = 00` → 0 |
| `>>` | **오른쪽 시프트** (비트를 오른쪽으로 이동, 1칸 = ÷2) | `2 >> 1 = 1` |
| `&&` | **논리 AND** (참/거짓 판단) | |

### (3) 연산자 우선순위 (높음 → 낮음, 관련 부분만)
```text
 높음 ◀─────────────────────────────────────────────────────────────▶ 낮음
 * / %  >  + -  >  << >>  >  < <= > >=  >  == !=  >  &  >  ^  >  |  >  &&  >  ||  >  ?:  >  =
```
- `z & z >> 1` 에서 **`>>`가 `&`보다 먼저**.
- `x>5 && z<=3 ? ... : ...` 에서 **`?:`는 가장 나중**.

## 3. 실행 과정 (`x=7, y=4`)
**① `z = y%3<3 ? 2 : 1;`**
- `y % 3` = 4 % 3 = 1
- `1 < 3` → 참 → **z = 2**

**② `z = z & z >> 1;`** (`>>` 먼저)
- `z >> 1` = 2 >> 1 = 1 (`10₂` → `01₂`)
- `z & 1` = `10₂ & 01₂` = `00₂` → **z = 0**

```text
   z    = 10 (2)
 z >> 1 = 01 (1)
 AND    = 00 (0)
```
**③ `z = x>5 && z<=3 ? z*x : z/x;`**
- `x>5` → 7>5 참, `z<=3` → 0<=3 참 → `&&` 결과 **참**
- 참이므로 `z*x` = 0 × 7 = **0**

| 단계 | 식 | z |
|---|---|---:|
| ① | `4%3<3 ? 2 : 1` | 2 |
| ② | `2 & (2>>1)` | 0 |
| ③ | `참 ? 0*7 : ...` | **0** |

> **정답: `0`**

## 4. 암기 포인트
- `&`(비트 AND)는 `>>`보다 우선순위가 **낮다** → `z & (z>>1)`.
- 삼항 연산자는 거의 맨 마지막에 계산된다.
