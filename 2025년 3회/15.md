# 문제 15

## 문제

다음은 C코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
#include <stdio.h>
int main() {
    int x=7, y=4, z;
    z = y%3<3 ? 2 : 1;
    z = z & z >> 1;
    z = x>5 && z<=3 ? z*x : z/x;
    printf("%d", z);
    return 0;
}
```

<details>
<summary><strong>정답 보기</strong></summary>

0

</details>

<summary><strong>상세 해설</strong></summary>

## 핵심 개념

비트 AND(&)는 같은 자릿수 비트가 모두 1일 때만 1이다. 논리 AND(&&)와 용도가 다르다.

## 풀이

4%3은 1이고 1<3이 참이므로 z=2다. 오른쪽 시프트 2>>1은 1이므로 2&1=0이다. 마지막 조건 x>5 && z<=3은 참이어서 z*x, 즉 0×7=0을 택한다.

## 오답 분석

&와 &&를 혼동하지 않는다. 삼항식의 참/거짓 양쪽 계산은 조건 평가 후 한쪽만 선택한다.

## 암기 포인트

비트 AND(&)는 같은 자릿수 비트가 모두 1일 때만 1이다. 논리 AND(&&)와 용도가 다르다.
