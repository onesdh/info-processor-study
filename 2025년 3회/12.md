# 문제 12

## 문제

다음은 Java의 상속과 생성자 호출에 관한 코드이다. 밑줄에 알맞은 단어를 작성하시오.

```
class Rectangle {

    int width, height;

    Rectangle(int width, int height) {
        this.width = width;
        this.height = height;
    }
}

class Square extends Rectangle {

    Square(int a) {
        ____(a,a);
    }

    int getSquareArea() {
        return width * height;
    }
}

public class Main {
    public static void main(String[] args) {
        Square sq = new Square(10);
        System.out.println(sq.getSquareArea());
    }
}

```

## 1. 문제에서 묻는 것
자식 클래스 생성자에서 **부모 생성자를 호출하는 키워드**(`super`)를 채우는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 상속과 생성자
```java
class Square extends Rectangle { ... }   // Rectangle이 부모, Square가 자식
```
자식 객체를 만들면 **부모 부분도 먼저 만들어져야** 한다. 그래서 자식 생성자는 **반드시 부모 생성자를 먼저 호출**한다.

### (2) 부모 생성자 호출 규칙
| 상황 | 동작 |
|---|---|
| 부모에 **기본 생성자(매개변수 없음)** 가 있음 | 자식 생성자의 첫 줄에 `super();`가 **자동 삽입** |
| 부모에 **매개변수가 있는 생성자만** 있음 | 자식에서 **`super(값…)`을 직접** 써야 함(안 쓰면 컴파일 오류) |

### (3) super vs this
| 키워드 | 호출 대상 |
|---|---|
| **super(...)** | **부모** 클래스의 생성자 |
| this(...) | **같은 클래스**의 다른 생성자 |
- 둘 다 **생성자의 첫 줄**에만 쓸 수 있다.

## 3. 코드 분석
```java
class Rectangle {
    int width, height;
    Rectangle(int width, int height) { ... }   // ← 매개변수 있는 생성자만 존재
}
class Square extends Rectangle {
    Square(int a) {
        ____(a, a);      // 부모 Rectangle(int,int) 호출 → super(a, a)
    }
    int getSquareArea() { return width * height; }
}
```
- `Rectangle`에는 **매개변수 없는 생성자가 없으므로** `super(a, a)`로 직접 값을 넘겨야 한다.

## 4. 실행 과정
1. `new Square(10)` → `Square(10)` 진입
2. `super(10, 10)` → `Rectangle(10, 10)` 실행 → `width = 10`, `height = 10`
3. `getSquareArea()` = 10 × 10 = **100** 출력

> **정답: `super`** (출력 결과는 `100`)

## 5. 암기 포인트
- 부모 생성자 호출은 **`super(...)`, 반드시 첫 줄**.
- 부모에 기본 생성자가 없으면 자식이 `super(…)`로 인자를 넘겨야 한다.
