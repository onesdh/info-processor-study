# 문제 12

## 문제

다음은 Java의 상속과 생성자 호출에 관한 코드이다. 밑줄에 알맞은 단어를 작성하시오.

```
class Rectangle {

    int width, height;

    Rectangle(int width, int height) {
        this.width = width;
        this.height = height;
    }
}

class Square extends Rectangle {

    Square(int a) {
        ____(a,a);
    }

    int getSquareArea() {
        return width * height;
    }
}

public class Main {
    public static void main(String[] args) {
        Square sq = new Square(10);
        System.out.println(sq.getSquareArea());
    }
}

```

## 핵심 개념

this(...)는 같은 클래스의 다른 생성자, super(...)는 상위 클래스 생성자 호출이다.

## 풀이

자식 생성자에서 super(a,a)는 부모 클래스의 생성자를 호출한다. Java에서 부모 생성자 호출은 생성자 첫 문장에 와야 한다. 두 변에 같은 값을 전달하면 정사각형이 된다.

## 오답 분석

this(a,a)는 Square 내부의 다른 생성자를 찾으므로 부모 Rectangle의 초기화를 호출하지 않는다.

## 암기 포인트
