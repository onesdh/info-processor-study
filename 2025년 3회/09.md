# 문제 9

## 문제

다음은 파이썬에 대한 문제이다. 아래 코드를 확인하여 출력값에 알맞는 값을 작성하시오.

```
data = [
    [3, 5, 2, 4, 1],
    [4, 5, 1],
    [4, 4, 1, 5, 4],
    [4, 5]
]

result = {}

for index, lis in enumerate(data):
    list_sum = sum(lis)
    list_len = len(lis)

    result[index] = (list_sum, list_len)

print(result)

```

[ 출력값 ]

{0: (①, ②), 1: (③, ④), 2: (⑤, ⑥), 3: (⑦, ⑧)}

## 1. 문제에서 묻는 것
`enumerate`로 **인덱스와 리스트**를 함께 꺼내며 **합계와 길이**를 딕셔너리에 저장한 결과를 출력하는 문제다.

## 2. 먼저 알아야 할 개념
| 문법 | 의미 | 예 |
|---|---|---|
| `enumerate(리스트)` | `(인덱스, 항목)` 쌍을 **순서대로** 제공 | `(0, [..]), (1, [..])…` |
| `sum(lis)` | 리스트 원소의 **합** | `sum([1,2])` → 3 |
| `len(lis)` | 리스트의 **원소 개수** | |
| `result[index] = (a, b)` | 딕셔너리에 **키: 값(튜플)** 저장 | `{0: (15, 5)}` |
| 튜플 `(a, b)` | 값을 묶은 **변경 불가** 자료형 | |

## 3. 실행 과정
각 행(`lis`)마다 합과 길이를 구해 `result[index]`에 저장한다.

| index | lis | 합 `sum` | 길이 `len` | 저장 |
|---:|---|---:|---:|---|
| 0 | `[3, 5, 2, 4, 1]` | 3+5+2+4+1 = **15** | **5** | `0: (15, 5)` |
| 1 | `[4, 5, 1]` | 4+5+1 = **10** | **3** | `1: (10, 3)` |
| 2 | `[4, 4, 1, 5, 4]` | 4+4+1+5+4 = **18** | **5** | `2: (18, 5)` |
| 3 | `[4, 5]` | 4+5 = **9** | **2** | `3: (9, 2)` |

최종 출력: `{0: (15, 5), 1: (10, 3), 2: (18, 5), 3: (9, 2)}`

> **정답: ① 15, ② 5, ③ 10, ④ 3, ⑤ 18, ⑥ 5, ⑦ 9, ⑧ 2**

## 4. 암기 포인트
- 튜플은 **(합, 길이)** 순서이고, 딕셔너리 출력은 **입력한 순서 그대로**(Python 3.7+).
- 합을 구할 때 원소를 하나씩 빼먹지 않도록 표로 정리하자.
