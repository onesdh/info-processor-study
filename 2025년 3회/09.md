# 문제 9

## 문제

다음은 파이썬에 대한 문제이다. 아래 코드를 확인하여 출력값에 알맞는 값을 작성하시오.

```
data = [
    [3, 5, 2, 4, 1],
    [4, 5, 1],
    [4, 4, 1, 5, 4],
    [4, 5]
]

result = {}

for index, lis in enumerate(data):
    list_sum = sum(lis)
    list_len = len(lis)

    result[index] = (list_sum, list_len)

print(result)

```

[ 출력값 ]

{0: (①, ②), 1: (③, ④), 2: (⑤, ⑥), 3: (⑦, ⑧)}

<details>
<summary><strong>정답 보기</strong></summary>

①=15, ②=5, ③=10, ④=3, ⑤=18, ⑥=5, ⑦=9, ⑧=2

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

enumerate는 (인덱스, 항목)을 순서대로 제공하고, tuple은 괄호로 묶은 불변 순서 자료형이다.

## 풀이

각 리스트를 따로 합산한다. 첫 행은 3+5+2+4+1=15이며 길이는 5다. 다음 세 행은 합계/길이가 각각 10/3, 18/5, 9/2다. enumerate의 인덱스는 0부터 시작한다.

## 오답 분석

합계와 길이의 순서가 바뀌지 않도록 result[index]=(list_sum,list_len)를 그대로 읽는다.

## 암기 포인트
