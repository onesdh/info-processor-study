# 문제 20

## 문제

다음은 SQL에 관한 문제이다. 아래 A테이블을 참고하여 쿼리의 결과를 작성하시오.

![원문 문제 그림 1](source/정보처리기사_2025_3_Q20_01.png)

[ SQL ]

SELECT count(col2) FROM A WHERE col1 IN (2, 3) OR col2 IN (3, 5)

## 1. 문제에서 묻는 것
`WHERE col1 IN (2, 3) OR col2 IN (3, 5)` 조건을 만족하는 행에서 `COUNT(col2)`가 얼마인지 구하는 문제다. **NULL 처리**가 핵심이다.

## 2. 먼저 알아야 할 개념
### (1) NULL = "값이 없음/알 수 없음"
`NULL`은 0도 빈 문자열도 아니다. **어떤 비교(=, IN 등)를 해도 "참"이 되지 않는다**(결과는 UNKNOWN).

### (2) 3값 논리
| A | B | A OR B |
|---|---|---|
| TRUE | UNKNOWN | **TRUE** |
| FALSE | UNKNOWN | UNKNOWN |
| UNKNOWN | TRUE | **TRUE** |

→ `WHERE`는 결과가 **TRUE인 행만** 통과시킨다. (UNKNOWN은 탈락)

### (3) COUNT의 차이
| 표현 | 의미 |
|---|---|
| `COUNT(*)` | **모든 행**의 수 (NULL 포함) |
| `COUNT(col2)` | **col2가 NULL이 아닌** 행의 수 |

### (4) IN
`col1 IN (2, 3)` ⇔ `col1 = 2 OR col1 = 3`

## 3. 문제 데이터 (그림)
| 행 | col1 | col2 |
|---:|---|---|
| ① | 2 | null |
| ② | 3 | 6 |
| ③ | 2 | 3 |
| ④ | null | 3 |
| ⑤ | 4 | 5 |

## 4. 풀이: WHERE 조건 판정
| 행 | `col1 IN (2,3)` | `col2 IN (3,5)` | OR 결과 | 통과 |
|---:|:---:|:---:|:---:|:---:|
| ① (2, null) | ✅ TRUE | UNKNOWN | **TRUE** | ✅ |
| ② (3, 6) | ✅ TRUE | FALSE | **TRUE** | ✅ |
| ③ (2, 3) | ✅ TRUE | ✅ TRUE | **TRUE** | ✅ |
| ④ (null, 3) | UNKNOWN | ✅ TRUE | **TRUE** | ✅ |
| ⑤ (4, 5) | FALSE | ✅ TRUE | **TRUE** | ✅ |

→ **5행 모두 통과.**

## 5. COUNT(col2)
통과한 5행 중 `col2`가 NULL인 행은 ①뿐 → NULL 제외 → 5 − 1 = **4**

| 행 | col2 | 센다? |
|---:|---|:---:|
| ① | null | ❌ |
| ② | 6 | ✅ |
| ③ | 3 | ✅ |
| ④ | 3 | ✅ |
| ⑤ | 5 | ✅ |

> **정답: `4`**

## 6. 암기 포인트
- `COUNT(열)`은 **NULL을 세지 않는다.** `COUNT(*)`였다면 5.
- NULL이 있어도 OR의 한쪽이 TRUE이면 행은 통과한다.
