# 문제 8 — Java 인터페이스 구현

## 문제

WashingMachine 클래스가 Machine 인터페이스의 run()을 구현할 때 클래스 선언의 빈칸에 들어갈 Java 키워드를 쓰시오.

## 원문 이미지

원문 페이지에서 확인할 수 있습니다.

<details>
<summary><strong>정답 보기</strong></summary>

implements

</details>

<summary><strong>상세 해설</strong></summary>

## 핵심 개념

클래스 상속에는 extends, 인터페이스 구현에는 implements를 쓴다.

## 풀이

Java 클래스는 인터페이스를 implements로 구현한다. 인터페이스에 선언된 추상 메서드 run()을 클래스가 구현해야 한다.

## 오답 분석

extends는 클래스 상속에 쓰이며 인터페이스를 클래스가 구현하는 문법이 아니다.

## 암기 포인트

클래스 상속에는 extends, 인터페이스 구현에는 implements를 쓴다.
