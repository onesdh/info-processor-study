# 문제 8

## 문제

아래 코드는 Machine 이라는 인터페이스를 정의하고 WashingMachine 클래스에서 해당 인터페이스를 사용하고자 한다. 빈칸에 들어갈 올바른 키워드를 작성하시오.

```
interface Machine {
    void run();
}

class WashingMachine (____빈칸____) Machine {
    private String name;

    public WashingMachine() {
        this.name = "LG Washer";
    }

    public void run() {
        System.out.println("Washing machine running");
    }
}

public class Main {
    public static void main(String[] args) {
        WashingMachine wm = new WashingMachine();
        wm.run();
    }
}
```

## 1. 문제에서 묻는 것
Java에서 클래스가 **인터페이스를 구현**할 때 쓰는 키워드를 묻는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 인터페이스(interface)
"**무엇을 해야 하는지(메서드 이름)만 정해 놓은 설계도**"다. 구현은 없고 **약속**만 있다.
```java
interface Machine { void run(); }    // run()이라는 기능을 "반드시 가져야 한다"는 약속
```
### (2) 구현(implements)
클래스가 그 약속을 지키겠다고 선언하고 **메서드 몸체를 작성**한다.
```java
class WashingMachine implements Machine {
    public void run() { ... }         // 인터페이스 메서드를 반드시 구현
}
```
### (3) 상속(extends)과의 차이
| 키워드 | 대상 | 관계 | 개수 |
|---|---|---|---|
| **extends** | 클래스 → 클래스 | **상속** (is-a, 기능을 물려받음) | **1개만** |
| **implements** | 클래스 → 인터페이스 | **구현** (약속 이행) | **여러 개 가능** |
| extends | 인터페이스 → 인터페이스 | 인터페이스 확장 | 여러 개 |

```text
   «interface» Machine ┄┄┄ implements ┄┄▶ WashingMachine  (점선 + 속이 빈 화살표)
```
## 3. 문제 풀이
`class WashingMachine ( ? ) Machine` 에서 `Machine`은 **인터페이스**이므로 구현 관계 → **`implements`**.
인터페이스의 메서드 `run()`을 클래스에서 `public`으로 구현했는지도 확인된다(접근 범위를 줄일 수 없음).

> **정답: `implements`**

## 4. 암기 포인트
- 인터페이스를 쓰면 **implements**, 클래스를 물려받으면 **extends**.
- 인터페이스의 메서드는 기본 `public abstract`라, 구현 시 반드시 `public`.
