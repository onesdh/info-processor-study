# 문제 4 — 오류 제어와 검출 코드

## 문제

오류를 검출·수정하는 코드, 재전송 없이 수신 측에서 수정하는 방식, 재전송을 요청하는 방식, 1비트 패리티 검사, 다항식 기반 검사를 순서대로 채우시오.

## 핵심 개념

FEC는 전방 오류 정정, BEC는 역방향 오류 정정/재전송 기반 오류 제어다.

## 풀이

해밍 코드는 여분 비트를 여러 위치에 두어 오류 위치를 찾아 정정할 수 있다. 이런 방식은 수신 측에서 보정하는 FEC(Forward Error Correction)다. 오류 검출 뒤 송신 측에 재전송을 요청하는 것은 BEC(Backward Error Correction)이며, 패리티와 CRC가 대표적인 검출 기법이다. 패리티는 검사 비트로 1의 홀짝을 확인하고, CRC는 다항식 나눗셈의 나머지를 검사값으로 사용한다.

## 오답 분석

CRC는 여러 비트 오류 검출에 강하지만 일반적으로 자체 정정 방식이 아니다. Parity는 단순 오류 검출용이다.

## 암기 포인트

FEC는 전방 오류 정정, BEC는 역방향 오류 정정/재전송 기반 오류 제어다.
