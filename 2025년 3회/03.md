## 문제

다음은 유닉스(Unix) 또는 리눅스(Linux) 환경에서 자주 사용하는 기본 명령어에 대한 설명이다.

각 설명에 맞는 명령어를 보기에서 골라 연결하시오.

2. 디렉터리의 내용(파일 및 하위 디렉터리)을 목록으로 표시한다. (   )

3. 다른 디렉터리로 이동한다. (   )

4. 파일을 복사한다. (   )

## 1. 문제에서 묻는 것
리눅스/유닉스 기본 명령어 4개(`pwd`, `ls`, `cd`, `cp`)의 기능을 짝짓는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 터미널과 명령어
리눅스는 글자로 명령을 내려 컴퓨터를 조작한다(CLI). 파일이 **디렉터리(폴더)** 구조로 정리되어 있고, 지금 내가 서 있는 위치를 **현재 작업 디렉터리**라고 한다.
```text
 /
 ├─ home
 │   └─ user  ← 현재 위치(pwd로 확인)
 │       ├─ a.txt
 │       └─ docs
 └─ etc
```
### (2) 명령어 정리
| 명령 | 영문 | 기능 | 사용 예 |
|---|---|---|---|
| **pwd** | **p**rint **w**orking **d**irectory | **현재 디렉터리 경로 출력** | `pwd` → `/home/user` |
| **ls** | **l**i**s**t | 디렉터리 **내용 목록** | `ls`, `ls -l` |
| **cd** | **c**hange **d**irectory | **디렉터리 이동** | `cd docs`, `cd ..`(상위) |
| **cp** | **c**o**p**y | **파일 복사** | `cp a.txt b.txt` |
| mv | move | 이동/이름 변경 | `mv a.txt docs/` |
| rm | remove | 삭제 | `rm a.txt` |
| mkdir | make directory | 디렉터리 생성 | `mkdir work` |

## 3. 문제 풀이
| 번호 | 설명 | 정답 |
|---|---|---|
| 1 | 현재 작업 중인 디렉터리의 **경로 출력** | **pwd** |
| 2 | 디렉터리의 **내용을 목록으로 표시** | **ls** |
| 3 | 다른 디렉터리로 **이동** | **cd** |
| 4 | 파일을 **복사** | **cp** |

> **정답: 1. pwd / 2. ls / 3. cd / 4. cp**

## 4. 암기 포인트
- 이름의 첫 글자로 연상: **p**wd=print **w**orking, **l**s=**l**i**s**t, **c**d=**c**hange, **c**p=**c**opy.
- 자주 출제: `chmod`(권한 변경), `chown`(소유자 변경), `ps`(프로세스), `kill`(종료).
