# 문제 11

## 문제

다음 설명에 해당하는 인증 기술을 쓰시오.

한 번 사용하면 즉시 폐기되어 재사용이 불가능하다.

서버와 토큰(또는 앱)은 시간 동기화나 카운터 기반 방식으로 매번 새로운 값을 생성하고, 내부 검증은 해시 함수를 이용한 방식으로 서버에 평문을 저장하지 않고도 유효성을 확인할 수 있다.

이 특성 때문에 은행 인증 등 고보안 영역에서 널리 사용되며 재전송 공격 방지와 사용자 편의성을 동시에 만족한다.

## 1. 문제에서 묻는 것
"**한 번 사용하면 폐기**, **시간 동기화/카운터 기반**으로 매번 새 값을 생성" → 어떤 **인증 기술**인지 묻는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 인증(Authentication)
"당신이 정말 그 사람인가?"를 확인하는 절차. 방법은 크게 3가지다.

| 인증 요소 | 의미 | 예 |
|---|---|---|
| 지식 | **알고 있는 것** | 비밀번호, PIN |
| 소유 | **가지고 있는 것** | OTP 토큰, 스마트폰, 보안카드 |
| 존재(생체) | **나 자신** | 지문, 홍채, 얼굴 |

### (2) 고정 비밀번호의 한계
같은 비밀번호를 계속 쓰면 **한 번 유출·도청**될 때 계속 악용된다(재전송 공격).

### (3) OTP (One Time Password, 일회용 비밀번호)
**딱 한 번만 쓸 수 있는** 비밀번호. 쓰고 나면 즉시 무효가 된다.
```text
 [OTP 토큰/앱]                      [서버]
   같은 비밀키 + 현재 시각(또는 카운터)
        │  해시 함수로 계산                    │  같은 방식으로 계산
        ▼                                     ▼
     483 921  ──────── 입력 ──────────▶  값이 같은지 비교
   (30초마다 값 변경)                     (서버에 평문 비밀번호를 저장하지 않음)
```
| 방식 | 값 생성 기준 |
|---|---|
| **TOTP** (시간 동기화) | **현재 시간** |
| **HOTP** (카운터 기반) | 사용 횟수(**카운터**) |
| 비동기(챌린지-응답) | 서버가 낸 임의 값에 응답 |

## 3. 문제 풀이
| 문제 단서 | OTP의 특징 |
|---|---|
| 한 번 사용 후 폐기, **재사용 불가** | 일회용 |
| **시간 동기화·카운터** 기반 생성 | TOTP / HOTP |
| 해시 함수로 서버 평문 저장 없이 검증 | 해시 기반 |
| 은행 인증, **재전송 공격 방지** | 금융권 OTP |

> **정답: OTP (One Time Password)**

## 4. 암기 포인트
- **OTP = 소유 기반 인증**, 시간(TOTP)/카운터(HOTP) 기반 일회용.
- 방어하는 공격: **재전송(Replay) 공격**.
