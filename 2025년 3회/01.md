# 문제 1

## 문제

다음은 UML (    ) 다이어그램이다. 아래 내용을 보고 다이어그램의 관계를 확인하여 명칭을 작성하시오.

(   ) 다이어그램이란

시스템을 폴더 모양의 (   ) 단위로 구분하여 구성 요소 간의 관계를 표현하는 UML 구조 다이어그램이다.

하나의 (   ) 안에는 여러 클래스나 하위 (   ) 가 포함될 수 있으며,

(   ) 간에는 «import», «access», «merge» 등의 관계를 통해 의존성(Dependency) 을 표현한다.

이 다이어그램은 코드의 실제 구조(폴더 구조)와 비슷하게 표현되기 때문에

소프트웨어의 모듈화, 재사용성, 의존 관계를 시각적으로 설계할 때 자주 사용된다.

## 핵심 개념

패키지는 폴더처럼 관련 요소를 묶는다. «import», «access», «merge»는 패키지 사이 관계 표기다.

## 풀이

UML에서 패키지는 관련 모델 요소를 묶는 이름 공간이다. 패키지 다이어그램은 패키지 경계와 패키지 사이의 의존성을 그려 모듈 구성과 의존 방향을 보여준다. 클래스 다이어그램이 클래스의 속성·연산·관계를 자세히 보이는 데 비해, 패키지 다이어그램은 더 큰 단위의 구성과 정리에 초점을 둔다.

## 오답 분석

클래스 다이어그램은 클래스 자체의 구조를, 컴포넌트 다이어그램은 실행 가능한 구성 요소와 인터페이스를 표현한다.
