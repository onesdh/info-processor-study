# 문제 17

## 문제

다음은 Java에 대한 코드이다. 알맞는 출력값을 작성하시오.

```
enum Tri {
    A("A"), B("AB"), C("ABC");

    private String code;

    Tri(String code) {
        this.code = code;
    }

    public String code() {
        return code;
    }
}

public class Main {
    public static void main(String[] args) {
        Tri t = Tri.values()[Tri.A.name().length()];
        System.out.print(t.code());
    }
}

```

## 1. 문제에서 묻는 것
**열거형(enum)** 의 `values()`, `name()`, 생성자·필드가 섞인 코드의 출력값을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) enum(열거형)
**미리 정해진 상수들의 집합**. 요일, 등급, 상태처럼 값의 종류가 한정된 경우에 사용한다.
```java
enum Tri { A("A"), B("AB"), C("ABC"); ... }
```
- `A`, `B`, `C`는 각각 **Tri 타입의 객체(상수)** 이다.
- 괄호 안의 값(`"A"`, `"AB"`, `"ABC"`)은 **생성자**의 인자로 전달되어 필드 `code`에 저장된다.

### (2) 자주 쓰는 메서드
| 메서드 | 의미 | 예 |
|---|---|---|
| `values()` | **선언 순서대로** 모든 상수를 담은 **배열** | `[A, B, C]` |
| `name()` | 상수의 **이름 문자열** | `Tri.A.name()` → `"A"` |
| `ordinal()` | 선언 순서 번호(0부터) | A=0, B=1, C=2 |

### (3) 상수 객체의 구조
```text
 Tri.A → code = "A"
 Tri.B → code = "AB"
 Tri.C → code = "ABC"
 values() = [ A , B , C ]
 인덱스      0   1   2
```
## 3. 실행 과정
`Tri t = Tri.values()[Tri.A.name().length()];`

| 단계 | 식 | 값 |
|---|---|---|
| ① | `Tri.A.name()` | `"A"` |
| ② | `"A".length()` | **1** |
| ③ | `Tri.values()` | `[A, B, C]` |
| ④ | `Tri.values()[1]` | **B** |
| ⑤ | `t.code()` | `B`의 code = `"AB"` |

`System.out.print("AB")` → **AB**

> **정답: `AB`**

## 4. 암기 포인트
- `values()[인덱스]`는 **선언 순서**대로 0부터.
- `name()`은 **상수의 이름**(`"A"`)이고, `code()`는 **필드 값**(`"A"`, `"AB"`…)이다. 헷갈리지 말 것.
