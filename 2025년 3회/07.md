# 문제 7

## 문제

다음은 C코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
#include <stdio.h>

struct Node {
    struct Node* next;
    unsigned int x;
};

int main() {
    struct Node t1 = { 0, 5u };
    struct Node t2 = { 0, 7u };
    struct Node t3 = { 0, 11u };

    t3.next = &t2;
    t2.next = &t1;

    struct Node* curr = &t3;
    int sum = 0;

    while (curr) {
        sum = sum * 3 + curr->x;
        curr = curr->next;
    }

    sum = (sum ^ 42u) + 100u;

    printf("%u\n", sum);
}

```

<details>
<summary><strong>정답 보기</strong></summary>

187

</details>

<summary><strong>상세 해설</strong></summary>

## 핵심 개념

XOR은 비트가 다를 때 1이다. 각 자리의 2진 표현을 세로로 맞춰 연산하면 실수를 줄일 수 있다.

## 풀이

누적값은 0→11→11×3+7=40→40×3+5=125다. 125(0x7D) XOR 42(0x2A)는 87(0x57)이다. 여기에 100을 더하면 187이다.

## 오답 분석

노드 순서를 반대로 읽으면 누적식 결과가 달라진다. XOR은 덧셈이 아니다.

## 암기 포인트

XOR은 비트가 다를 때 1이다. 각 자리의 2진 표현을 세로로 맞춰 연산하면 실수를 줄일 수 있다.
