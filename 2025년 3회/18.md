# 문제 18

## 문제

다음은 정보보안에서 사용하는 접근통제(Access Control) 방식에 대한 설명이다.

설명에 해당하는 접근통제 모델을 &lt;보기&gt;에서 골라 빈칸에 작성하시오.

| ㄱ | 중앙에서 보안 정책을 일괄적으로 설정하며, 주체(사용자)가 임의로 수정하거나 변경할 수 없다. 주로 군사 기밀, 국가 보안과 같은 높은 보안 수준이 요구되는 환경에서 사용된다. 보안 등급(Top Secret / Secret / Confidential 등)에 따라 접근 여부가 결정된다. |
|---|---|
| ㄴ | 조직 내에서 부여된 직무나 역할(Role)에 따라 접근 권한을 부여하는 방식이다. 개별 사용자에게 직접 권한을 설정하지 않고, 역할에 권한을 묶어 부여하기 때문에 관리가 용이하며 직무 변경 시 역할만 변경하면 된다. |
| ㄷ | 자원의 소유자(Owner)가 해당 자원에 대한 접근 권한을 자유롭게 부여하거나 회수할 수 있는 방식이다. 파일이나 폴더의 소유자가 읽기/쓰기/실행 권한을 설정하는 것이 대표적인 예로 사용자의 임의 설정이 가능해 보안성이 상대적으로 낮다. |

## 1. 문제에서 묻는 것
세 가지 **접근통제 모델(DAC, MAC, RBAC)** 의 설명을 보고 이름을 연결하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 접근통제(Access Control)
**누가(주체) 무엇(객체/자원)에 어떤 권한(읽기·쓰기·실행)을 가질지 통제**하는 보안 기술이다.

### (2) 3가지 모델 비교
| 모델 | 권한을 정하는 주체 | 판단 기준 | 특징 | 사용처 |
|---|---|---|---|---|
| **DAC** (임의적 접근통제) | **자원의 소유자** | 사용자 **신원** | 소유자가 자유롭게 부여·회수, **유연**하지만 보안성 낮음 | 일반 OS 파일 권한(`chmod`) |
| **MAC** (강제적 접근통제) | **시스템·보안 관리자(중앙)** | **보안 등급(레이블)** | 사용자가 **임의로 변경 불가**, **가장 엄격** | 군사·국가기밀 |
| **RBAC** (역할 기반 접근통제) | 관리자가 **역할에 권한 부여** | **직무·역할** | 사용자에게 **역할(Role)** 을 할당, **관리 용이** | 기업·조직 시스템 |

```text
 MAC : 사용자(등급 Secret)  ──비교──▶  자원(등급 Top Secret)  → 등급 낮아 접근 불가
 RBAC: 사용자 ─▶ 역할(인사팀) ─▶ 권한(급여조회)               (직무 바뀌면 역할만 변경)
 DAC : 파일 소유자가 "철수에게 읽기 허용"                       (소유자 마음대로)
```
## 3. 문제 풀이
| 보기 | 핵심 단서 | 정답 |
|---|---|---|
| ㄱ | **중앙에서 일괄 설정**, 사용자가 **임의 변경 불가**, **군사·국가 보안**, **보안 등급** | **MAC** |
| ㄴ | **직무/역할(Role)** 에 따라 권한, 역할에 권한 묶음, **직무 변경 시 역할만 변경** | **RBAC** |
| ㄷ | **자원의 소유자**가 **자유롭게 부여·회수**, 보안성 상대적으로 낮음 | **DAC** |

> **정답: ㄱ. MAC / ㄴ. RBAC / ㄷ. DAC**

## 4. 암기 포인트
- **D**AC = **D**(소유자가 **마음대로**), **M**AC = **M**(**강제**, 등급), **R**BAC = **R**(**역할**).
- 보안 강도: **MAC > RBAC > DAC** (일반적 순서).
