## 1. 문제에서 묻는 것
`CROSS JOIN`으로 모든 조합을 만든 뒤 `LIKE`로 **패턴 매칭**한 행의 수(`COUNT(*)`)를 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) CROSS JOIN
두 테이블의 **모든 행을 서로 짝지은 조합(카티션 곱)** 을 만든다. T1이 3행, T2가 2행이면 결과는 3 × 2 = **6행**.

### (2) LIKE와 와일드카드
| 패턴 | 의미 |
|---|---|
| `%` | 0개 이상의 임의 문자열 |
| `_` | 정확히 1개의 문자 |

`A.NAME LIKE B.RULE` 처럼 **패턴이 열에 들어 있어도** 동작한다(행마다 `B.RULE` 값이 패턴이 됨).

| 패턴 | 뜻 |
|---|---|
| `s%` | **s로 시작** |
| `%t%` | **t를 포함** |

## 3. 문제 데이터 (그림)
**T1**

| CODE | NAME |
|---:|---|
| 3258 | smith |
| 4324 | allen |
| 5432 | scott |

**T2**

| NO | RULE |
|---:|---|
| 12 | s% |
| 32 | %t% |

```sql
SELECT COUNT(*) CNT FROM T1 A CROSS JOIN T2 B WHERE A.NAME LIKE B.RULE;
```

## 4. 풀이: 6개 조합을 모두 검사
| A.NAME | B.RULE | 매칭? | 이유 |
|---|---|:---:|---|
| smith | s% | ✅ | s로 시작 |
| smith | %t% | ✅ | sm**i**th → **t** 포함 |
| allen | s% | ❌ | a로 시작 |
| allen | %t% | ❌ | t 없음 |
| scott | s% | ✅ | s로 시작 |
| scott | %t% | ✅ | sco**tt** → t 포함 |

일치하는 행 = 4개 → `COUNT(*)` = **4**

> **정답: `4`**

## 5. 암기 포인트
- `CROSS JOIN` = 조건 없이 **모든 조합**(행 수 곱).
- LIKE는 대소문자 구분 여부가 DBMS마다 다르지만, 여기서는 모두 소문자라 문제없다.
