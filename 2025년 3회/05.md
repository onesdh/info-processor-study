# 문제 5

## 문제

다음은 C코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
#include <stdio.h>

struct Test {
    int i;
    const char *g;
};

int main() {
    struct Test test[] = {{1, "AB"}, {2, "DC"}, {3, "EB"}};
    struct Test *p = &test[1];
    printf("%s", p->g + (p->i - 1));
    return 0;
}
```

## 핵심 개념

문자열 포인터에 정수 n을 더하면 n번째 인덱스로 이동한다. C 문자열은 널 문자로 끝난다.

## 풀이

p는 test[1]을 가리키므로 i=2, g="DC"다. 포인터 오프셋은 2-1=1이다. 문자열 시작 주소에서 문자 한 칸 이동하면 "C"를 가리키며, 그 위치부터 널 문자까지 출력한다.

## 오답 분석

전체 문자열 "DC"가 아니라 포인터가 이동한 뒤의 접미 문자열만 출력된다.

## 암기 포인트
