# 문제 5

## 문제

두 번째 Test 원소의 i 값이 2이고 g가 "DC"일 때 p->g + (p->i - 1)을 %s로 출력한다. 결과를 쓰시오.

## 원문 이미지

원문 페이지에서 확인할 수 있습니다.

<details>
<summary><strong>정답 보기</strong></summary>

C

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

문자열 포인터에 정수 n을 더하면 n번째 인덱스로 이동한다. C 문자열은 널 문자로 끝난다.

## 풀이

p는 test[1]을 가리키므로 i=2, g="DC"다. 포인터 오프셋은 2-1=1이다. 문자열 시작 주소에서 문자 한 칸 이동하면 "C"를 가리키며, 그 위치부터 널 문자까지 출력한다.

## 오답 분석

전체 문자열 "DC"가 아니라 포인터가 이동한 뒤의 접미 문자열만 출력된다.

## 암기 포인트

문자열 포인터에 정수 n을 더하면 n번째 인덱스로 이동한다. C 문자열은 널 문자로 끝난다.
