# 문제 5

## 문제

다음은 C코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
#include <stdio.h>

struct Test {
    int i;
    const char *g;
};

int main() {
    struct Test test[] = {{1, "AB"}, {2, "DC"}, {3, "EB"}};
    struct Test *p = &test[1];
    printf("%s", p->g + (p->i - 1));
    return 0;
}
```

## 1. 문제에서 묻는 것
**구조체 배열**과 **구조체 포인터**, 그리고 `%s`로 **문자열 중간부터 출력**하는 방식이 섞인 문제다.

## 2. 먼저 알아야 할 개념
### (1) 구조체와 배열
```c
struct Test { int i; const char *g; };
struct Test test[] = {{1,"AB"}, {2,"DC"}, {3,"EB"}};
```
```text
 test[0] = { i:1, g:→"AB" }
 test[1] = { i:2, g:→"DC" }
 test[2] = { i:3, g:→"EB" }
```
### (2) 구조체 포인터와 `->`
`p->g` 는 `(*p).g`와 같다. 포인터로 멤버에 접근할 때 쓰는 화살표 연산자.

### (3) 문자열 포인터 + 정수
`const char *g`는 문자열 **첫 글자의 주소**를 가진다. `g + n`은 **n번째 글자의 주소**이고, `%s`는 그 주소부터 **널 문자('\0')까지** 출력한다.
```text
 g → [D][C][\0]
      0  1
 g + 0 → "DC"    g + 1 → "C"
```
## 3. 실행 과정
1. `struct Test *p = &test[1];` → p는 두 번째 요소(`{2, "DC"}`)를 가리킴
2. `p->i` = 2, `p->g` = `"DC"`
3. `p->g + (p->i - 1)` = `"DC"` 주소 + (2 − 1) = `"DC"` + 1 → **두 번째 글자 `C`의 주소**
4. `%s` → `C`부터 끝까지 → **`C`**

| 식 | 값 |
|---|---|
| `p->i - 1` | 1 |
| `p->g + 1` | `"C"` |
| 출력 | **C** |

> **정답: `C`**

## 4. 암기 포인트
- 문자 포인터 + n = **n글자 건너뛴 위치**부터의 문자열.
- 배열 인덱스는 0부터라 `test[1]`은 **두 번째** 원소다.
