# 문제 02 — OAuth 권한 위임

## 문제

사용자의 비밀번호를 공유하지 않고 토큰을 통해 제3자 앱에 제한된 리소스 접근을 허용하는 개방형 표준을 쓰시오.

## 정답

OAuth

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

OAuth는 사용자 인증 자격증명을 직접 전달하지 않고 토큰 기반으로 권한을 위임한다.

## 풀이

사용자가 권한을 승인하면 클라이언트는 액세스 토큰을 받아 허용된 범위의 리소스에 접근한다. 토큰은 비밀번호를 대체하는 제한된 권한 증표다.

## 오답 분석

OIDC는 OAuth 2.0 위에 사용자 인증 계층을 더한다. JWT는 토큰 형식, SSO는 로그인 경험이다.

## 암기 포인트

비밀번호 공유 없는 토큰 권한 위임은 OAuth.
