# 문제 10

## 문제

다음은 C언어의 포인터 문제이다. 알맞는 출력값을 작성하시오.

```
#include

int main() {
    char* p = "KOREA";
    printf("%s\n", p);
    printf("%s\n", p+1);
    printf("%c\n", *p);
    printf("%c\n", *(p+3));
    printf("%c\n", *p+4);
}

```

## 1. 문제에서 묻는 것
**문자 포인터와 문자열 출력**(`%s`, `%c`)에서 포인터 연산과 `*p + 4`의 의미를 구분하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 문자열 리터럴과 포인터
```c
char* p = "KOREA";
```
```text
 p ─▶ K  O  R  E  A  \0
      p  p+1 p+2 p+3 p+4
```
### (2) `%s` 와 `%c`
| 서식 | 인자 | 출력 |
|---|---|---|
| `%s` | **문자열의 주소**(`char*`) | 그 주소부터 `\0`까지 |
| `%c` | **문자 1개** | 그 문자 |

### (3) 연산자 우선순위 주의
`*p + 4` = `(*p) + 4` — **먼저 `*p`(문자 'K')** 를 구하고 거기에 4를 더한다. (`*(p+4)`와 다르다!)
- 문자 + 정수 = **ASCII 값 계산**: 'K'(75) + 4 = 79 = **'O'**

## 3. 출력 줄별 분석
| 줄 | 코드 | 해석 | 출력 |
|---:|---|---|:---:|
| 1 | `printf("%s\n", p)` | 처음부터 끝까지 | **KOREA** |
| 2 | `printf("%s\n", p+1)` | 한 글자 뒤(`O`)부터 | **OREA** |
| 3 | `printf("%c\n", *p)` | 첫 글자 | **K** |
| 4 | `printf("%c\n", *(p+3))` | 4번째 글자 | **E** |
| 5 | `printf("%c\n", *p+4)` | `'K' + 4` = 'O' (ASCII 75+4=79) | **O** |

> **정답**
> ```
> KOREA
> OREA
> K
> E
> O
> ```

## 4. 암기 포인트
- `*(p+4)`는 `A`, **`*p+4`는 `O`** — 괄호 위치로 결과가 달라진다.
- 문자에 정수를 더하면 알파벳이 앞으로 이동 (K→L→M→N→O).
