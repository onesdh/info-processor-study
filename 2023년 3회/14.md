## 문제

다음은 파이썬에 대한 문제이다. 밑줄친 부분에 알맞는 답을 작성하시오.

```
print("파이썬 입출력에 대한 문제입니다.")

num1, num2 = input()._____()
num1 = int(num1)
num2 = int(num2)
print(num1,num2)

num3 = num1 + num2
print(num1 + " + "  + num2 + " = " + num3)
```

특이사항

입력값은 2와 3이다.

출력화면

파이썬 입력출에 대한 문제입니다.  
2 3  
2 + 3 = 5

## 1. 문제에서 묻는 것
한 줄에 입력된 공백 구분 값(`2 3`)을 **두 변수로 나눠 받는** 메서드 이름을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) `input()`
키보드로 입력한 **한 줄 전체를 문자열**로 돌려준다. 입력이 `2 3`이면 `"2 3"` (공백 포함 문자열 하나).

### (2) `split()`
문자열을 **공백(기본 구분자)** 기준으로 **나눠 리스트**로 만든다.
```python
"2 3".split()   →   ['2', '3']
```
리스트의 원소 2개를 **언패킹**해 `num1, num2`에 각각 대입한다.
```python
num1, num2 = input().split()      # num1 = '2', num2 = '3'  (둘 다 문자열)
```
### (3) 형 변환
`int(num1)` : 문자열 `'2'` → 정수 `2`. 그래야 `num1 + num2`가 **덧셈(5)** 이 된다.

## 3. 실행 과정
| 단계 | 코드 | 값 |
|---|---|---|
| ① | `input()` (입력 `2 3`) | `"2 3"` |
| ② | `.split()` | `['2', '3']` |
| ③ | `num1, num2 = ...` | `'2'`, `'3'` |
| ④ | `int()` 변환 | `2`, `3` |
| ⑤ | `print(num1, num2)` | `2 3` |
| ⑥ | `num3 = num1 + num2` | `5` |

> **정답: `split`**

※ 문제의 마지막 `print(num1 + " + " + num2 + ...)`는 정수와 문자열을 `+`로 더하는 형태라 실제로는 오류가 나지만, 이 문제는 **빈칸에 들어갈 메서드**만 묻는다. (출력 화면 `2 + 3 = 5`는 `print(num1, "+", num2, "=", num3)` 같은 형태일 때 얻을 수 있다.)

## 4. 암기 포인트
- `input().split()` : 한 줄 입력을 **공백으로 나눠** 리스트화.
- `input()`의 결과는 **항상 문자열** → 계산하려면 `int()`로 변환.
