# 문제 14

## 문제

공백으로 입력된 두 문자열 값을 각각 변수에 나누어 받는 input 메서드를 채우시오.

<details>
<summary><strong>정답 보기</strong></summary>

split

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

split은 입력 문자열을 공백 기준 토큰으로 나눈다.

## 풀이

input()은 한 줄 문자열을 반환한다. `.split()`은 공백을 구분자로 분할하고 두 토큰을 num1과 num2에 각각 대입한다.

## 오답 분석

input 자체는 문자열 하나만 반환하므로 두 변수에 직접 넣으려면 분할이 필요하다. 이후 int로 변환한다.

## 암기 포인트

여러 공백 구분 입력은 input().split().
