# 문제 14

## 문제

다음은 파이썬에 대한 문제이다. 밑줄친 부분에 알맞는 답을 작성하시오.

```
print("파이썬 입출력에 대한 문제입니다.")

num1, num2 = input()._____()
num1 = int(num1)
num2 = int(num2)
print(num1,num2)

num3 = num1 + num2
print(num1 + " + "  + num2 + " = " + num3)
```

특이사항

입력값은 2와 3이다.

출력화면

파이썬 입력출에 대한 문제입니다.  
2 3  
2 + 3 = 5

## 핵심 개념

split은 입력 문자열을 공백 기준 토큰으로 나눈다.

## 풀이

input()은 한 줄 문자열을 반환한다. `.split()`은 공백을 구분자로 분할하고 두 토큰을 num1과 num2에 각각 대입한다.

## 오답 분석

input 자체는 문자열 하나만 반환하므로 두 변수에 직접 넣으려면 분할이 필요하다. 이후 int로 변환한다.

## 암기 포인트

여러 공백 구분 입력은 input().split().
