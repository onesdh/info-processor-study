# 문제 13

## 문제

다음 자바 코드를 실행할 경우 에러가 발생이 된다. 에러가 발생하는 라인명을 작성하시오.

```
class Person {
    private String name;
    public Person(String val) {
        name = val;
    }
    public static String get() {
    return name;
    }
    public void print() {
        System.out.println(name);
    }
}
public class main {
    public static void main(String[] args) {
        Person obj = new Person("Kim");
        obj.print();
    }
}
```

## 1. 문제에서 묻는 것
Java 코드에서 **컴파일 에러가 발생하는 줄 번호**를 찾는 문제다.

## 2. 먼저 알아야 할 개념
### (1) static 멤버와 인스턴스 멤버
| 구분 | static 메서드/변수 | 인스턴스 메서드/변수 |
|---|---|---|
| 소속 | **클래스**(객체 없이 사용) | **각 객체** |
| 생성 시점 | 클래스 로딩 시 | `new`로 객체 생성 시 |

### (2) 핵심 규칙
**static 메서드는 객체 없이 호출될 수 있으므로, 객체마다 있는 인스턴스 변수(`name`)를 직접 사용할 수 없다.**
```text
 static get() ──▶ name ?   "어느 객체의 name?" 객체가 없을 수 있음 → 컴파일 오류
```
인스턴스 변수에 접근하려면 객체가 필요하다(`obj.name`)거나, 메서드를 static이 아니게 만들어야 한다.

## 3. 코드 분석 (줄 번호)
```java
1  class Person {
2      private String name;                    // 인스턴스 변수
3      public Person(String val) {
4          name = val;
5      }
6      public static String get() {            // static 메서드
7          return name;                        // ❌ static 안에서 인스턴스 변수 접근 → 컴파일 에러
8      }
9      public void print() {
10         System.out.println(name);           // ✅ 인스턴스 메서드는 가능
11     }
12 }
```
오류 메시지: `non-static variable name cannot be referenced from a static context`

> **정답: 7 (번 줄)**

## 4. 암기 포인트
- **static → 인스턴스 멤버 직접 접근 불가**(역방향, 인스턴스 → static은 가능).
- 해결: `get()`에서 static을 제거하거나, `name`을 static으로 선언하거나, 매개변수로 객체를 받는다.
