# 문제 13

## 문제

다음 자바 코드를 실행할 경우 에러가 발생이 된다. 에러가 발생하는 라인명을 작성하시오.

```
class Person {
    private String name;
    public Person(String val) {
        name = val;
    }
    public static String get() {
    return name;
    }
    public void print() {
        System.out.println(name);
    }
}
public class main {
    public static void main(String[] args) {
        Person obj = new Person("Kim");
        obj.print();
    }
}
```

## 핵심 개념

static 메서드는 특정 객체 없이 호출되므로 인스턴스 필드를 직접 참조할 수 없다.

## 풀이

get() 선언과 return 문에서 클래스 변수처럼 인스턴스 필드 name을 접근한다. 문제가 지목하는 오류 행은 `return name;`이 있는 7행이다. 인스턴스 메서드로 바꾸거나 객체 참조를 받아야 한다.

## 오답 분석

new Person 객체의 이름을 인스턴스 print에서 출력하는 것은 유효하다. 오류는 static 메서드 내부의 직접 필드 접근이다.

## 암기 포인트

static에서 인스턴스 필드 직접 접근 불가.
