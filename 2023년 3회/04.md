# 문제 04

## 문제

다음은 C 언어 코드이다. 알맞는 출력 결과를 작성하시오.

```
#include <stdio.h>

int test(int n) {
    int i, sum = 0;

    for (i = 1; i <= n / 2; i++){
        if (n % i == 0)
        sum += i;
    }

    if (n == sum)
        return 1;
    ​
    return 0;
}


int main(){
    int i, sum=0;

    for (i = 2; i <= 100; i++){
        if (test(i))
        sum += i;
    }

    printf("%d ", sum);
    return 0;
}

```

## 1. 문제에서 묻는 것
2~100 사이의 수 중 **완전수(자기 자신을 제외한 약수의 합이 자기 자신과 같은 수)** 를 모두 더한 값을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 완전수
자기 자신을 제외한 **약수의 합 = 자기 자신**인 수.
| 수 | 약수(자기 자신 제외) | 합 |
|---:|---|---:|
| **6** | 1, 2, 3 | 6 ✅ |
| **28** | 1, 2, 4, 7, 14 | 28 ✅ |
| 12 | 1, 2, 3, 4, 6 | 16 ❌ |

### (2) 코드 읽기
```c
int test(int n) {
    int sum = 0;
    for (i = 1; i <= n / 2; i++)     // n의 약수는 n/2 이하이므로 n/2까지만 확인
        if (n % i == 0) sum += i;     // i가 n의 약수이면 더함
    if (n == sum) return 1;           // 약수의 합이 자기 자신 → 완전수
    return 0;
}
```
`main`: `i = 2 ~ 100`을 `test(i)`로 검사해 완전수(1 반환)이면 `sum`에 더한다.

## 3. 풀이
1~100 사이 완전수는 **6, 28** 두 개뿐이다(다음은 496).

| i | 약수 합 | 완전수? | sum |
|---:|---:|:---:|---:|
| 6 | 1+2+3 = 6 | ✅ | 6 |
| 28 | 1+2+4+7+14 = 28 | ✅ | 6 + 28 = **34** |

(나머지는 약수의 합이 다르다. 예: 8 → 1+2+4 = 7, 12 → 16, 20 → 22)

`printf("%d ", sum)` → **34**

> **정답: `34`**

## 4. 암기 포인트
- 완전수: **6, 28, 496, 8128 …** 100 이하는 6과 28.
- `i <= n/2`로 반복하면 약수를 모두 포함하면서도 효율적이다(n 자신 제외).
