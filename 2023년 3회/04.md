# 문제 04

## 문제

다음은 C 언어 코드이다. 알맞는 출력 결과를 작성하시오.

```
#include <stdio.h>

int test(int n) {
    int i, sum = 0;

    for (i = 1; i <= n / 2; i++){
        if (n % i == 0)
        sum += i;
    }

    if (n == sum)
        return 1;
    ​
    return 0;
}


int main(){
    int i, sum=0;

    for (i = 2; i <= 100; i++){
        if (test(i))
        sum += i;
    }

    printf("%d ", sum);
    return 0;
}

```

<details>
<summary><strong>정답 보기</strong></summary>

34

</details>

<summary><strong>상세 해설</strong></summary>

## 핵심 개념

완전수는 자기 자신을 제외한 양의 약수의 합이 자기 자신과 같은 수다.

## 풀이

100 이하 완전수는 6과 28이다. 6의 진약수 1+2+3=6이고 28은 1+2+4+7+14=28이다. 합은 34다.

## 오답 분석

약수 합에 자기 자신을 포함하지 않는다. 1은 완전수가 아니며 100까지의 다음 완전수는 없다.

## 암기 포인트

100 이하 완전수 6과 28.
