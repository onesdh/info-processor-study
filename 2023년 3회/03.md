# 문제 03 — Linux chmod 751

## 문제

소유자 rwx, 그룹 r-x, 기타 x 권한을 8진수로 지정하는 명령을 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

chmod 751 test.txt

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

8진수 권한 각 자리는 읽기 4, 쓰기 2, 실행 1의 합이다.

## 풀이

소유자 rwx는 4+2+1=7, 그룹 r-x는 4+1=5, 기타 x는 1이다. 파일 권한 변경 명령은 chmod이므로 `chmod 751 test.txt`다.

## 오답 분석

751에서 첫 자리는 소유자, 둘째는 그룹, 셋째는 기타 사용자다.

## 암기 포인트

rwx=7, r-x=5, --x=1.

</details>
