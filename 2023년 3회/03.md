# 문제 03

## 문제

리눅스(Linux)에서 사용자에게 읽기/쓰기/실행 권한을 부여하고, 그룹에게는 읽기/실행을 부여하고, 그 이외에는 실행 권한을 test.txt 파일에 부여하는 위한 명령어는 다음과 같다. 빈칸에 들어갈 답을 작성하시오. (8진법 사용)

(    (1)    ) (    (2)    ) test.txt

<details>
<summary><strong>정답 보기</strong></summary>

(1) chmod

(2) 751

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

8진수 권한 각 자리는 읽기 4, 쓰기 2, 실행 1의 합이다.

## 풀이

소유자 rwx는 4+2+1=7, 그룹 r-x는 4+1=5, 기타 x는 1이다. 파일 권한 변경 명령은 chmod이므로 `chmod 751 test.txt`다.

## 오답 분석

751에서 첫 자리는 소유자, 둘째는 그룹, 셋째는 기타 사용자다.

## 암기 포인트

rwx=7, r-x=5, --x=1.

</details>
