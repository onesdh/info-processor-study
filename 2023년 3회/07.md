# 문제 07

## 문제

규칙 기반·등급 기반, 역할 기반, 신분 기반 접근통제 모델을 약자로 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

MAC, RBAC, DAC

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

MAC은 중앙 정책과 보안등급, RBAC는 조직 역할, DAC는 소유자 재량에 근거한다.

## 풀이

주체의 보안등급과 객체 등급·허가를 규칙으로 적용하는 것은 MAC이다. 중앙 관리자가 역할에 권한을 매핑하는 것은 RBAC다. 객체 소유자나 사용자 신분에 따라 권한을 부여하는 것은 DAC다.

## 오답 분석

RBAC의 역할과 DAC의 사용자 신분을 혼동하지 않는다. MAC은 사용자가 임의로 정책을 바꾸기 어렵다.

## 암기 포인트

등급 MAC, 역할 RBAC, 재량 DAC.
