# 문제 07

## 문제

다음 설명은 서버 접근 통제의 유형이다. 괄호 안에 들어갈 용어를 작성하시오. (영어 약자로 작성하시오.)

- (   (1)   )은/는 규칙 기반(Rule-Based) 접근통제 정책으로, 객체에 포함된 정보의 허용 등급과 접근 정보에 대하여 주체가 갖는 접근 허가 권한에 근거하여 객체에 대한 접근을 제한하는 방법이다.

- (   (2)   )은/는 중앙 관리자가 사용자와 시스템의 상호관계를 통제하며 조직 내 맡은 역할(Role)에 기초하여 자원에 대한 접근을 제한하는 방법이다.

- (   (3)   )은/는 신분 기반(Identity-Based) 접근통제 정책으로, 주체나 그룹의 신분에 근거하여 객체에 대한 접근을 제한하는 방법이다.

## 1. 문제에서 묻는 것
접근통제 모델 3가지(MAC, RBAC, DAC)를 설명과 짝짓는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 접근통제
**누가(주체) 무엇(객체)에 어떤 권한**을 가질지 통제하는 보안 기술.

### (2) 3가지 모델 비교
| 모델 | 판단 기준 | 정책 결정자 | 특징 |
|---|---|---|---|
| **MAC** (강제적) | **보안 등급(레이블)** 비교 — 규칙 기반 | **중앙 관리자** | 사용자가 임의 변경 불가, 군사·기밀 |
| **RBAC** (역할 기반) | **조직 내 역할(직무)** | 중앙 관리자가 역할에 권한 부여 | 직무 변경 시 **역할만 변경** |
| **DAC** (임의적) | **주체·그룹의 신분(Identity)** | **자원 소유자** | 유연하지만 보안성 낮음 |

```text
 MAC : (객체 등급: 기밀) vs (주체 허가: 비밀) → 허가 등급 < 객체 등급 → 접근 거부
 RBAC: 사용자 ─▶ 역할 ─▶ 권한
 DAC : 소유자가 "철수에게 읽기 허용"
```
## 3. 문제 풀이
| 번호 | 단서 | 정답 |
|---|---|---|
| (1) | **규칙 기반**, 객체의 **허용 등급**과 주체의 **접근 허가 권한**에 근거 | **MAC** |
| (2) | **역할(Role)** 기반, 중앙 관리자가 통제 | **RBAC** |
| (3) | **신분(Identity) 기반**, 주체나 그룹의 신분에 근거 | **DAC** |

> **정답: (1) MAC (2) RBAC (3) DAC**

## 4. 암기 포인트
- MAC=**등급·규칙**, RBAC=**역할**, DAC=**신분·소유자 재량**.
