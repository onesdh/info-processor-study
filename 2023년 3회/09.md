# 문제 09

## 문제

다음 설명에 대해 괄호 안에 알맞는 용어를 작성하시오. (영어 약자로 작성하시오.)

- (     )은/는 자료를 일정한 크기로 정하여 순서대로 전송하는 자료의 전송 방식이다.

- 셀이라 부르는 고정 길이 패킷을 이용하여 처리가 단순하고 고속망에 적합하며, 연속적으로 셀을 보낼 때  
다중화를 하지 않고 셀단위로 동기가 이루어지지만 경우에 따라 동기식 시간 분할 다중화를 사용하기도 한다.

- 가상 채널 (Virtual Channel) 기반의 연결 지향 서비스로 셀이라 부르는 고정 길이(53바이트) 패킷을 사용하며 통계적 다중화 방식을 이용한다.

## 1. 문제에서 묻는 것
"**고정 길이 셀(53바이트)**, **가상 채널**, **통계적 다중화**, 고속망" → 어떤 전송 방식인지 영문 약자로 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) ATM (Asynchronous Transfer Mode, 비동기 전송 방식)
**고정 길이 패킷인 "셀(Cell)"** 로 데이터를 잘라 전송하는 **고속 통신망 기술**이다.

| 항목 | 내용 |
|---|---|
| 셀 크기 | **53바이트** = 헤더 5바이트 + 페이로드 48바이트 |
| 연결 방식 | **연결 지향** — 가상 채널(VC) / 가상 경로(VP)를 먼저 설정 |
| 다중화 | **비동기식(통계적) 시분할 다중화** — 데이터가 있는 채널에 슬롯을 할당 |
| 장점 | 고정 길이라 **처리가 단순하고 빠름**, 음성·영상·데이터 통합 |

```text
 [ 헤더 5B | 데이터 48B ] = 셀 53B (항상 같은 크기)  → 스위칭 하드웨어가 빠르게 처리
```
### (2) 다른 교환 방식과 비교
| 방식 | 특징 |
|---|---|
| 회선 교환 | 전용 회선 점유 (전화) |
| 패킷 교환 | **가변 길이** 패킷 (인터넷 IP) |
| **ATM(셀 교환)** | **고정 길이 셀**, 연결형 |

## 3. 문제 풀이
| 단서 | ATM |
|---|---|
| 자료를 **일정한 크기**로 순서대로 전송 | ✅ |
| **셀**이라 부르는 **고정 길이 패킷**, 고속망 적합 | ✅ |
| **가상 채널**, **53바이트**, **통계적 다중화** | ✅ |

> **정답: ATM (Asynchronous Transfer Mode)**
