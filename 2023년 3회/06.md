# 문제 06

## 문제

다음 빈칸에 들어갈 UNION 연산의 결과값을 작성하시오.

[테이블]

T1

| 3 |
|---|
| 1 |
| 4 |

T2

| 2 |
|---|
| 4 |
| 3 |

[쿼리]

SELECT A FROM  T1

UNION

SELECT A FROM  T2

ORDER BY A DESC;

결과 테이블

|  |
|---|
|  |
|  |
|  |

<details>
<summary><strong>정답 보기</strong></summary>

4

3

2

1

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
두 테이블에 `UNION`과 `ORDER BY ... DESC`를 적용한 결과를 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 집합 연산자
| 연산자 | 의미 | 중복 |
|---|---|---|
| **UNION** | **합집합** | **중복 제거** |
| UNION ALL | 합집합 | 중복 **포함** |
| INTERSECT | 교집합 | |
| MINUS(EXCEPT) | 차집합 | |

### (2) ORDER BY
`ORDER BY A DESC` : **내림차순**(큰 값 → 작은 값). UNION 전체 결과에 마지막에 적용된다.

## 3. 풀이
**T1.A** = {3, 1, 4}, **T2.A** = {2, 4, 3}

```text
 T1 : 3, 1, 4
 T2 : 2, 4, 3
 UNION (중복 제거) : 1, 2, 3, 4      ← 4와 3은 양쪽에 있어 한 번만
 ORDER BY A DESC   : 4, 3, 2, 1
```
| 결과 A |
|:---:|
| 4 |
| 3 |
| 2 |
| 1 |

> **정답: 4, 3, 2, 1 (위에서부터)**

## 4. 암기 포인트
- UNION은 **중복 제거**, UNION ALL이면 `4, 4, 3, 3, 2, 1`이 된다.
- DESC = 내림차순.
