# 문제 20

## 문제

다음은 데이터베이스에 관련된 문제이다. 괄호 안에 알맞는 답을 작성하시오.

- (            ) 무결성은 관계 데이터베이스 관계 모델에서 2개의 관련 있던 관계 변수(테이블) 간의 일관성(데이터 무결성)을 말한다.

- 종종 기본 키 또는 키가 아닌 후보 키와 외래 키의 조합으로 강제 적용된다.

- 외래 키가 선언된 관계 변수의 외래 키를 구성하는 속성(열)의 값은 그 관계 변수의 부모가 되는 관계 변수의 기본 키 값 또는 기본 키가 아닌 후보 키 값으로 존재해야 한다.

## 1. 문제에서 묻는 것
"**두 테이블 간의 일관성**, **외래키**가 부모 테이블의 **기본키(또는 후보키) 값으로 존재**해야 함" → 어떤 무결성인지 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 무결성 3가지
| 종류 | 규칙 |
|---|---|
| 개체 무결성 | **기본키**는 NULL·중복 불가 |
| **참조 무결성** | **외래키 값은 참조 대상 테이블의 키 값으로 존재**(또는 NULL) |
| 도메인 무결성 | 속성 값은 정의된 범위·형식 안 |

### (2) 참조 무결성
```text
 부모(고객)                     자식(주문)
 ┌──────────┬──────┐           ┌────────┬──────────┐
 │ 고객번호PK│ 이름 │ ◀── 참조 ─│ 주문번호│ 고객번호FK │
 ├──────────┼──────┤           ├────────┼──────────┤
 │ 1        │ 김   │           │ A1     │ 1  ✅    │
 │ 2        │ 이   │           │ A2     │ 9  ❌ 부모에 없는 값 → 위반
 └──────────┴──────┘           └────────┴──────────┘
```
### (3) 참조 무결성을 지키는 방법
부모 행 삭제/수정 시 자식이 있으면: **CASCADE**(함께 삭제/수정), **SET NULL**(외래키를 NULL로), **RESTRICT**(거부) 등.

## 3. 문제 풀이
| 단서 | 참조 무결성 |
|---|---|
| **2개의 관련된 테이블 간 일관성** | ✅ |
| **기본키 또는 후보키와 외래키**의 조합으로 강제 | ✅ |
| 외래키 값이 **부모 테이블의 기본키/후보키 값으로 존재**해야 함 | ✅ |
