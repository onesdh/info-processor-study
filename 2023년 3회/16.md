# 문제 16

## 문제

다음 설명에 알맞는 답을 보기에서 골라 작성하시오.

- 시스템이나 시스템 구성요소(component) 또는 소프트웨어 프로그램의 입력값과 출력값이 특정 그룹으로 분류되며, 분류된 그룹내의 값들이 시스템에 의해 동일하게 취급된다는 특성을 이용하여 시험하는 기법

- 유사한 입력값들이 시스템을 거치면서 유사한 답변이 나온다는 것을 가정하여 테스트

- 하나의 값은 그 분할 내 모든 값을 대표하는 것으로 간주하는 기법

- 모든 입력값을 시험할 필요가 없게 하여 시험을 효율적으로 수행하도록 지원

- 일반적으로 경계값 분석기법(boundary value analysis)과 함께 테스트 케이스 도출하는데 사용

## 1. 문제에서 묻는 것
"**입력값을 그룹으로 분류**, 같은 그룹의 값은 **동일하게 취급**, **대표값 하나로** 시험, **경계값 분석과 함께** 사용" → 어떤 테스트 기법인지 고르는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 동치 분할(Equivalence Partitioning)
입력 가능한 값을 **"시스템이 같게 처리하는 그룹(동치류)"** 으로 나누고, **그룹마다 대표값 1개**만 테스트한다. 모든 값을 시험하지 않아도 되어 **효율적**이다.

예) 점수 입력(0~100), 합격 기준 60점
```text
  무효(<0) | 불합격(0~59) | 합격(60~100) | 무효(>100)
   -1(대표)     30(대표)       80(대표)       101(대표)
```
### (2) 경계값 분석과의 관계
동치 분할로 나눈 **그룹의 경계(59, 60, 100, 101 등)** 에서 오류가 자주 발생하므로 **경계값 분석을 함께** 사용해 테스트 케이스를 도출한다.
