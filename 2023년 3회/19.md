# 문제 19

## 문제

다음은 관계 대수에 대한 내용이다. 보기에 알맞는 기호를 작성하시오.

1. join :   (   1   )

2. project :   (   2   )

3. select :   (   3   )

4. division :   (   4   )

보기

| ㄱ. σ              ㄴ.  π                   ㄷ.⋈                 ㄹ.÷ |
|---|

<details>
<summary><strong>정답 보기</strong></summary>

(1)  ㄷ

(2)  ㄴ

(3)  ㄱ

(4)  ㄹ

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

관계 대수는 연산 종류마다 표준 기호를 사용한다.

## 풀이

조인은 ⋈, 프로젝션은 π, 셀렉션은 σ, 디비전은 ÷로 표현한다.

## 오답 분석

π는 열 선택, σ는 행 선택이다. 기호만 외우기보다 의미를 같이 기억한다.

## 암기 포인트

join⋈, projectπ, selectσ, divide÷.

</details>
