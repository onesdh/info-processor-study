# 문제 19

## 문제

다음은 관계 대수에 대한 내용이다. 보기에 알맞는 기호를 작성하시오.

1. join :   (   1   )

2. project :   (   2   )

3. select :   (   3   )

4. division :   (   4   )

보기

| ㄱ. σ              ㄴ.  π                   ㄷ.⋈                 ㄹ.÷ |
|---|

<details>
<summary><strong>정답 보기</strong></summary>

(1)  ㄷ

(2)  ㄴ

(3)  ㄱ

(4)  ㄹ

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**관계대수 연산자와 기호**(조인, 프로젝트, 셀렉트, 디비전)를 연결하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 순수 관계 연산자
| 연산 | 기호 | 의미 | 쉬운 비유 |
|---|:---:|---|---|
| **Select** | **σ** (시그마) | 조건에 맞는 **행** 선택 | 필터 |
| **Project** | **π** (파이) | 원하는 **열**만 선택 (중복 제거) | 열 골라 복사 |
| **Join** | **⋈** (나비넥타이) | 공통 속성으로 두 릴레이션 **결합** | 표 합치기 |
| **Division** | **÷** | 나누는 릴레이션의 **모든 값과 연관된** 튜플 | "모두 수강한 학생" |

### (2) 예시
`σ_나이>20(학생)` : 나이가 20 초과인 **행**만 / `π_이름(학생)` : 이름 **열**만.

## 3. 문제 풀이
| 번호 | 연산 | 기호 | 보기 |
|---|---|:---:|:---:|
| 1 | join | ⋈ | **ㄷ** |
| 2 | project | π | **ㄴ** |
| 3 | select | σ | **ㄱ** |
| 4 | division | ÷ | **ㄹ** |

> **정답: (1) ㄷ (2) ㄴ (3) ㄱ (4) ㄹ**

## 4. 암기 포인트
- **S**elect = **σ**(Sigma, 행), **P**roject = **π**(Pi, 열): 이름의 첫 글자 S–σ, P–π로 기억.
- 이름과 달리 Select는 **행**, Project는 **열**.
