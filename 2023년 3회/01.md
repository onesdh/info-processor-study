# 문제 01

## 문제

다음은 Java 코드이다. 올바른 출력 결과를 작성하시오.

```
public class main{
    public static void main(String[] args) {
        A b = new B();
        b.paint();
        b.draw();
    }
}

class A {
    public void paint() {
        System.out.print("A");
        draw();
    }
    public void draw() {
        System.out.print("B");
        draw();
    }
}

class B extends A {
    public void paint() {
        super.draw();
        System.out.print("C");
        this.draw();
    }
    public void draw() {
        System.out.print("D");
    }
}

```

## 1. 문제에서 묻는 것
**오버라이딩 + `super` 호출 + `this` 호출**이 섞인 코드의 출력 순서를 따라가는 문제다. 부모 클래스 안에서 호출한 `draw()`도 **실제 객체(B)** 의 메서드가 실행된다는 점이 핵심이다.

## 2. 먼저 알아야 할 개념
### (1) 동적 바인딩
`A b = new B();` 처럼 변수 타입은 A여도 **실제 객체가 B**이면, 오버라이딩된 메서드는 **언제 어디서 호출하든 B의 것**이 실행된다. 부모 클래스 안(`A.paint`, `A.draw`)에서 `draw()`를 호출해도 마찬가지다.

### (2) super와 this
| 표기 | 의미 |
|---|---|
| `super.draw()` | **부모(A)의 `draw()`를 지정**해서 호출 (오버라이딩을 무시하고 A 것을 실행) |
| `this.draw()` | **현재 객체의 `draw()`** → 실제 객체 B의 `draw()` |
| `draw()` (이름만) | `this.draw()`와 같다 |

## 3. 클래스 구조
```text
 A : paint()  { print "A"; draw(); }       draw() { print "B"; draw(); }   ← 재귀처럼 보이나 아래 보면 해결
 B : paint()  { super.draw(); print "C"; this.draw(); }
     draw()   { print "D"; }               ← A.draw()를 오버라이딩
```
`A.draw()` 안의 `draw()`는 **B.draw()** 로 연결되므로 무한 재귀가 일어나지 않는다.

## 4. 실행 과정 (`b.paint(); b.draw();`)
**`b.paint()`** → 실제 객체 B → **B.paint()**
| 순서 | 실행 | 출력 | 누적 |
|---:|---|:---:|---|
| 1 | `super.draw()` → **A.draw()** 실행 시작: `print("B")` | B | B |
| 2 | A.draw() 안의 `draw()` → **B.draw()**: `print("D")` | D | BD |
| 3 | 돌아와서 `print("C")` | C | BDC |
| 4 | `this.draw()` → **B.draw()**: `print("D")` | D | BDCD |

**`b.draw()`** → **B.draw()**: `print("D")` → **D** → 누적 `BDCDD`

> **정답: `BDCDD`**

## 5. 암기 포인트
- `super.메서드()`는 **부모 것을 직접 지정**, 그 외 호출은 **실제 객체 기준**.
- 부모 안의 호출도 자식이 오버라이딩했다면 **자식 메서드**가 실행된다.
