# 문제 01

## 문제

다음은 Java 코드이다. 올바른 출력 결과를 작성하시오.

```
public class main{
    public static void main(String[] args) {
        A b = new B();
        b.paint();
        b.draw();
    }
}

class A {
    public void paint() {
        System.out.print("A");
        draw();
    }
    public void draw() {
        System.out.print("B");
        draw();
    }
}

class B extends A {
    public void paint() {
        super.draw();
        System.out.print("C");
        this.draw();
    }
    public void draw() {
        System.out.print("D");
    }
}

```

BDCDD

## 핵심 개념

super.draw는 부모 구현을 직접 호출하지만 paint 안의 this.draw는 실제 객체의 오버라이딩 메서드를 호출한다.

## 풀이

b.paint()는 B.paint를 실행한다. super.draw가 A.draw 본문에서 B를 출력하고, A.draw의 draw() 호출은 동적 디스패치로 B.draw가 실행되어 D를 출력한다. 이어 C, this.draw의 D를 출력한다. 다음 b.draw도 D이므로 전체 BDCDD다.

## 오답 분석

paint에서 A.paint가 실행된다고 보거나 재귀 호출이 계속된다고 보면 안 된다. B 객체의 B.draw는 종료한다.

## 암기 포인트

super는 부모 구현, this는 자식 객체의 오버라이딩.
