# 문제 01 — Java 오버라이딩과 super 호출

## 문제

A형 참조로 B 객체의 paint와 draw를 차례로 호출하는 출력 결과를 쓰시오.

## 정답

BDCDD

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

super.draw는 부모 구현을 직접 호출하지만 paint 안의 this.draw는 실제 객체의 오버라이딩 메서드를 호출한다.

## 풀이

b.paint()는 B.paint를 실행한다. super.draw가 A.draw 본문에서 B를 출력하고, A.draw의 draw() 호출은 동적 디스패치로 B.draw가 실행되어 D를 출력한다. 이어 C, this.draw의 D를 출력한다. 다음 b.draw도 D이므로 전체 BDCDD다.

## 오답 분석

paint에서 A.paint가 실행된다고 보거나 재귀 호출이 계속된다고 보면 안 된다. B 객체의 B.draw는 종료한다.

## 암기 포인트

super는 부모 구현, this는 자식 객체의 오버라이딩.
