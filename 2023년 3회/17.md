## 1. 문제에서 묻는 것
그림(전통적인 IT와 클라우드 서비스 모델별 관리 범위)의 (1), (2), (3)이 **IaaS / PaaS / SaaS** 중 무엇인지 고르는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 클라우드 서비스 모델
**클라우드 사업자가 어디까지 관리해 주는가**에 따라 3가지로 나뉜다. 레이어 구조(아래 → 위):
```text
 [네트워크] [스토리지] [서버] [가상화]        ← 하드웨어/인프라
 [운영체제] [미들웨어] [런타임]                 ← 플랫폼
 [데이터] [애플리케이션]                        ← 소프트웨어
```
### (2) 3가지 모델 비교
| 모델 | 사업자가 제공(파란색) | 사용자가 관리 | 예 |
|---|---|---|---|
| **IaaS** (Infrastructure) | **네트워크·스토리지·서버·가상화** | OS, 미들웨어, 런타임, 데이터, 앱 | AWS EC2, Azure VM |
| **PaaS** (Platform) | 위 + **OS·미들웨어·런타임** | **데이터, 애플리케이션** | Heroku, Google App Engine |
| **SaaS** (Software) | **전부**(앱까지) | 사용만 함 | Gmail, Office 365, Dropbox |

```text
 비유(피자): IaaS=재료만 받아 직접 요리 / PaaS=도우·소스 준비되어 토핑만 / SaaS=완성된 피자 배달
```
## 3. 그림 해석
| 그림 | 파란색(서비스로 제공) 범위 | 사용자 관리 영역 | 정답 |
|---|---|---|---|
| (1) | **가상화 ~ 네트워크** (아래 4칸) | 운영체제부터 애플리케이션까지 | **IaaS** |
| (2) | **런타임 ~ 네트워크** (아래 7칸) | 애플리케이션·데이터만 | **PaaS** |
| (3) | **전체(애플리케이션까지)** | 없음 | **SaaS** |

> **정답: (1) IaaS (2) PaaS (3) SaaS**

## 4. 암기 포인트
- 사업자가 관리하는 범위: **IaaS < PaaS < SaaS**.
- 개발자는 PaaS(플랫폼), 일반 사용자는 SaaS(서비스 완제품), 인프라 관리자는 IaaS.
