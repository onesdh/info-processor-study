# 문제 08

## 문제

다음 C언어 코드에 알맞는 출력값을 작성하시오.

```
#include

int f(int n) {
    if(n<=1) return 1;
    else return n*f(n-1);
}

int main() {
    printf("%d", f(7));
}
```

<details>
<summary><strong>정답 보기</strong></summary>

5040

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

팩토리얼은 n부터 1까지의 자연수를 곱한 값이다.

## 풀이

f(7)=7×6×5×4×3×2×1=5040이다. 재귀 호출은 1에서 종료한다.

## 오답 분석

반복 횟수나 종료 조건을 놓치지 않는다. 7!은 7×6!이다.

## 암기 포인트

7! = 5040.

</details>
