# 문제 08

## 문제

다음 C언어 코드에 알맞는 출력값을 작성하시오.

```
#include

int f(int n) {
    if(n<=1) return 1;
    else return n*f(n-1);
}

int main() {
    printf("%d", f(7));
}
```

<details>
<summary><strong>정답 보기</strong></summary>

5040

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**팩토리얼을 구하는 재귀 함수** `f(7)`의 결과를 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 팩토리얼 n!
1부터 n까지의 곱. `5! = 5×4×3×2×1 = 120`. 정의: `n! = n × (n-1)!`, `1! = 1`.

### (2) 재귀 구조
```c
int f(int n) {
    if (n <= 1) return 1;       // 종료 조건
    else return n * f(n - 1);   // n × (n-1)!
}
```
호출이 **끝까지 내려가고**, 값이 **위로 올라오며 곱해진다.**

## 3. 호출·반환 과정
```text
 f(7) = 7 × f(6)
            f(6) = 6 × f(5)
                       f(5) = 5 × f(4)
                                  f(4) = 4 × f(3)
                                             f(3) = 3 × f(2)
                                                        f(2) = 2 × f(1)
                                                                   f(1) = 1
```
| n | f(n) |
|---:|---:|
| 1 | 1 |
| 2 | 2 × 1 = 2 |
| 3 | 3 × 2 = 6 |
| 4 | 4 × 6 = 24 |
| 5 | 5 × 24 = 120 |
| 6 | 6 × 120 = 720 |
| 7 | 7 × 720 = **5040** |

> **정답: `5040`**

## 4. 암기 포인트
- 7! = 5040. 종료 조건 `n <= 1`에서 1을 반환.
- (원문에는 `#include <stdio.h>`가 줄여져 있지만 동작은 동일하다.)
