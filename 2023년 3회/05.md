# 문제 05

## 문제

C언어에서 구조체의 멤버에 접근하기 위해 괄호안의 기호를 작성하시오.

```
#include <stdio.h>
#include <stdlib.h>

typedef struct Data{
    char c;
    int *numPtr;
} Data;

int main(){
    int num = 10;
    Data d1;
    Data *d2 = malloc(sizeof(struct Data));

    d1.numPtr = &num;
   d2 ( ) numPtr = &num;

    printf("%d\n", *d1.numPtr);
    printf("%d\n", *d2 ( ) numPtr);

    free(d2);
    return 0;
}

```

출력결과

10

## 핵심 개념

일반 구조체 변수는 점 연산자, 구조체 포인터는 화살표 연산자로 멤버에 접근한다.

## 풀이

d1은 구조체 값이므로 `d1.numPtr`를 사용한다. d2는 구조체를 가리키는 포인터이므로 `d2->numPtr`를 사용한다. 두 포인터 멤버가 모두 num의 주소를 저장해 역참조하면 10이다.

## 오답 분석

포인터 멤버 접근에 점을 쓰려면 먼저 `(*d2).numPtr`처럼 포인터를 역참조해야 한다.

## 암기 포인트

값은 ., 포인터는 ->.
