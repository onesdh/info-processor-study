# 문제 05 — C 구조체 포인터 멤버 접근

## 문제

구조체 값 변수와 구조체 포인터에서 numPtr 멤버에 접근하는 기호를 쓰시오.

## 정답

d1.numPtr, d2->numPtr

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

일반 구조체 변수는 점 연산자, 구조체 포인터는 화살표 연산자로 멤버에 접근한다.

## 풀이

d1은 구조체 값이므로 `d1.numPtr`를 사용한다. d2는 구조체를 가리키는 포인터이므로 `d2->numPtr`를 사용한다. 두 포인터 멤버가 모두 num의 주소를 저장해 역참조하면 10이다.

## 오답 분석

포인터 멤버 접근에 점을 쓰려면 먼저 `(*d2).numPtr`처럼 포인터를 역참조해야 한다.

## 암기 포인트

값은 ., 포인터는 ->.
