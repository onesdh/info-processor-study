# 문제 05

## 문제

C언어에서 구조체의 멤버에 접근하기 위해 괄호안의 기호를 작성하시오.

```
#include <stdio.h>
#include <stdlib.h>

typedef struct Data{
    char c;
    int *numPtr;
} Data;

int main(){
    int num = 10;
    Data d1;
    Data *d2 = malloc(sizeof(struct Data));

    d1.numPtr = &num;
   d2 ( ) numPtr = &num;

    printf("%d\n", *d1.numPtr);
    printf("%d\n", *d2 ( ) numPtr);

    free(d2);
    return 0;
}

```

출력결과

10

## 1. 문제에서 묻는 것
**구조체 포인터로 멤버에 접근하는 연산자**(`->`)를 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 구조체 멤버 접근 연산자 2가지
| 상황 | 연산자 | 예 |
|---|---|---|
| **구조체 변수**로 접근 | **`.`** (점) | `d1.numPtr` |
| **구조체 포인터**로 접근 | **`->`** (화살표) | `d2->numPtr` |

`d2->numPtr` 는 `(*d2).numPtr`와 같다. (`*d2`로 구조체를 꺼낸 뒤 `.`로 접근)
```c
Data  d1;                              // 구조체 변수       → d1.numPtr
Data *d2 = malloc(sizeof(struct Data));  // 구조체 포인터(힙에 할당) → d2->numPtr
```
### (2) 포인터 멤버
`numPtr`은 `int*`이므로 `*d1.numPtr`처럼 `*`로 역참조해 가리키는 값을 읽는다.

## 3. 코드 분석
```c
d1.numPtr = &num;        // 변수이므로 '.'
d2 ( ) numPtr = &num;    // d2는 포인터이므로 '->'
printf("%d\n", *d1.numPtr);       // num의 값 10
printf("%d\n", *d2 ( ) numPtr);   // 마찬가지로 10
```
빈칸에는 `->` 가 들어가 두 줄 모두 `10`이 출력된다.

> **정답: `->` (화살표 연산자)**

## 4. 암기 포인트
- **변수 → 점(.)**, **포인터 → 화살표(->)**.
- `p->x` ≡ `(*p).x`.
