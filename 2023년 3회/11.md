# 문제 11

## 문제

다음은 Java 코드에 대한 알맞는 출력값을 작성하시오.

```
class Parent {
    int compute(int num) {
        if(num <= 1)
            return num;
        return compute(num-1) + compute(num-2);
    }
}

class Child extends Parent {
    int compute(int num) {
        if(num <= 1)
            return num;
        return compute(num-1) + compute(num-3);
    }
}

public class main {
    public static void main(String args[]) {
        Parent obj = new Child();
        System.out.print(obj.compute(7));
    }
}
```

## 1. 문제에서 묻는 것
**재귀 + 오버라이딩**이 합쳐진 문제다. 부모 변수 타입이지만 **실제 객체는 Child**이므로, 재귀 안의 `compute`도 모두 **Child의 compute**로 호출된다.

## 2. 먼저 알아야 할 개념
### (1) 동적 바인딩
`Parent obj = new Child();` 에서 `obj.compute(7)` → **Child.compute**. Child 메서드 **안에서 부르는 `compute(...)`도 `this.compute`** 이므로 **다시 Child.compute**가 호출된다.

### (2) Parent vs Child
| 클래스 | 점화식 |
|---|---|
| Parent | `c(n) = c(n-1) + c(n-2)` (피보나치) |
| **Child** (실제 사용) | **`c(n) = c(n-1) + c(n-3)`** (n ≤ 1이면 n 반환) |

## 3. Child.compute 값 구하기 (작은 값부터)
종료: `n <= 1` 이면 **n 그대로** (음수도 그대로).
| n | 계산 | 값 |
|---:|---|---:|
| -1 | n ≤ 1 | -1 |
| 0 | n ≤ 1 | 0 |
| 1 | n ≤ 1 | 1 |
| 2 | c(1) + c(-1) = 1 + (-1) | 0 |
| 3 | c(2) + c(0) = 0 + 0 | 0 |
| 4 | c(3) + c(1) = 0 + 1 | 1 |
| 5 | c(4) + c(2) = 1 + 0 | 1 |
| 6 | c(5) + c(3) = 1 + 0 | 1 |
| 7 | c(6) + c(4) = 1 + 1 | **2** |

> **정답: `2`**

## 4. 암기 포인트
- Parent의 피보나치(결과 13)로 계산하면 오답. **실제 객체 Child의 식**을 쓴다.
- `n <= 1`이면 음수도 그대로 반환되어 `c(-1) = -1`이 계산에 들어간다.
