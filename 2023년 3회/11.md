# 문제 11 — Java 재귀 메서드 오버라이딩

## 문제

부모형 참조가 Child 객체의 compute(7)을 호출할 때 결과를 구하시오.

<details>
<summary><strong>정답 보기</strong></summary>

2

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

오버라이딩된 재귀 메서드는 각 재귀 호출에서도 실제 클래스의 메서드를 사용한다.

## 풀이

obj.compute(7)은 Child.compute를 선택한다. 그 메서드가 compute(n-1)+compute(n-3)을 재귀 호출하며 각 하위 호출도 Child 규칙을 적용한다. 기저값 n<=1에서 종료하면 결과 2다.

## 오답 분석

부모의 피보나치식 n-1+n-2를 적용하면 안 된다. 객체의 실제 타입에 따른 오버라이딩을 전체 재귀 트리에 적용한다.

## 암기 포인트

재귀 호출마다 자식 규칙 n−1과 n−3.
