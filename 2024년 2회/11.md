# 문제 11

## 문제

아래 그림을 바탕으로 RIP을 구성하여 최단 경로 비용을 계산하여 흐름에 맞게 작성하시오.

예제

A  →

A → D  → C   → F

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
그림의 네트워크에서 **RIP**를 사용했을 때 A에서 F까지의 **최단 경로**를 구하는 문제다. **RIP는 비용이 아니라 "홉(Hop) 수"로 최단 경로를 판단**한다는 점이 핵심이다.

## 2. 먼저 알아야 할 개념
### (1) RIP (Routing Information Protocol)
| 항목 | 내용 |
|---|---|
| 종류 | **거리 벡터** 라우팅 프로토콜 (IGP) |
| **메트릭(경로 선택 기준)** | **홉 수(Hop Count)** — 거쳐 가는 **라우터(구간) 개수** |
| 최대 홉 | **15** (16은 도달 불가) |
| 특징 | 구현 간단, 소규모 망용, 링크의 **속도·비용은 무시** |

### (2) OSPF와의 차이
| 구분 | RIP | OSPF |
|---|---|---|
| 기준 | **홉 수** | **링크 비용(대역폭 기반)** |
| 알고리즘 | 거리 벡터 | 링크 상태(다익스트라) |

## 3. 그림 해석
```text
        B                 C ──1── E
      2╱ ╲2             2╱ ╲5     │2
      A ─1─ D ─────────┘   F ────┘
```
(A–B 2, A–D 1, B–D 2, D–C 2, C–E 1, C–F 5, E–F 2)
| 링크 | 비용(그림의 숫자) |
|---|---:|
| A–B | 2 |
| A–D | 1 |
| B–D | 2 |
| D–C | 2 |
| C–E | 1 |
| C–F | 5 |
| E–F | 2 |

## 4. A → F 경로 후보 비교
| 경로 | 홉 수 | 비용 합 |
|---|---:|---:|
| A → D → C → F | **3홉** | 1+2+5 = 8 |
| A → D → C → E → F | 4홉 | 1+2+1+2 = 6 |
| A → B → D → C → F | 4홉 | 2+2+2+5 = 11 |

- **OSPF라면** 비용이 최소인 `A→D→C→E→F`(6)를 선택.
- **RIP는 홉 수 최소**를 선택 → **`A → D → C → F`** (3홉).
 문제가 "RIP를 구성하여"라고 했으므로 홉 수 기준으로 답한다.

> **정답: `A → D → C → F`**

## 5. 암기 포인트
- **RIP = 홉 수(최대 15)**, **OSPF = 비용(Cost)**. 그림의 숫자(비용)에 속지 말 것!
