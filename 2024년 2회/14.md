# 문제 14

## 문제

다음은 Java 언어에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
class Main {
    public static void main(String[] args) {
        int a[] = {1, 2, 3, 4, 5, 6, 7, 8, 9};
        ODDNumber OE = new ODDNumber();
        System.out.print(OE.sum(a, true) + ", " + OE.sum(a, false));
    }
}

interface Number {
    int sum(int[] a, boolean odd);
}

class ODDNumber implements Number {
    public int sum(int[] a, boolean odd) {
        int result = 0;
        for(int i=0; i < a.length; i++){
            if((odd && a[i] % 2 != 0) || (!odd && a[i] % 2 == 0))
                result += a[i];
        }
        return result;
    }
}
```

## 1. 문제에서 묻는 것
배열에서 **홀수의 합**과 **짝수의 합**을 구해 `, `로 이어 출력하는 문제다. (인터페이스·구현 클래스 구조에 속지 말고 핵심 로직만 보면 된다.)

## 2. 먼저 알아야 할 개념
### (1) 인터페이스와 구현
```java
interface Number { int sum(int[] a, boolean odd); }          // 약속(메서드 선언)
class ODDNumber implements Number { public int sum(...) {...} }   // 약속을 구현
```
### (2) 조건식
```java
if ( (odd && a[i] % 2 != 0) || (!odd && a[i] % 2 == 0) ) result += a[i];
```
| `odd` 값 | 조건 의미 | 더하는 수 |
|:---:|---|---|
| `true` | `a[i] % 2 != 0` → **홀수** | 홀수만 |
| `false` | `a[i] % 2 == 0` → **짝수** | 짝수만 |

### (3) 논리 연산자
`&&` (AND), `||` (OR), `!` (NOT).

## 3. 실행 과정 (`a = {1,2,3,4,5,6,7,8,9}`)
| 호출 | 더하는 수 | 계산 | 결과 |
|---|---|---|---:|
| `sum(a, true)` | 1, 3, 5, 7, 9 | 1+3+5+7+9 | **25** |
| `sum(a, false)` | 2, 4, 6, 8 | 2+4+6+8 | **20** |

출력: `25` + `", "` + `20` → **`25, 20`**

> **정답: `25, 20`**

## 4. 암기 포인트
- `a % 2 != 0` = 홀수, `a % 2 == 0` = 짝수.
- `OE.sum(a,true) + ", " + OE.sum(a,false)` : 정수 + 문자열 → 문자열 연결.
