# 문제 14

## 문제

다음은 Java 언어에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
class Main {
    public static void main(String[] args) {
        int a[] = {1, 2, 3, 4, 5, 6, 7, 8, 9};
        ODDNumber OE = new ODDNumber();
        System.out.print(OE.sum(a, true) + ", " + OE.sum(a, false));
    }
}

interface Number {
    int sum(int[] a, boolean odd);
}

class ODDNumber implements Number {
    public int sum(int[] a, boolean odd) {
        int result = 0;
        for(int i=0; i < a.length; i++){
            if((odd && a[i] % 2 != 0) || (!odd && a[i] % 2 == 0))
                result += a[i];
        }
        return result;
    }
}
```

<details>
<summary><strong>정답 보기</strong></summary>

25, 20

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

boolean 인수에 따라 홀수 또는 짝수 조건을 선택해 합산한다.

## 풀이

odd=true이면 1,3,5,7,9를 더해 25다. odd=false이면 2,4,6,8을 더해 20이다.

## 오답 분석

배열 인덱스 홀짝이 아니라 원소 값의 나머지 연산을 검사한다.

## 암기 포인트

홀수 합 25, 짝수 합 20.
