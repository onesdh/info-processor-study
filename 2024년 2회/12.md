# 문제 12

## 문제

아래의 표를 확인하여 SRT 스케줄링의 평균 대기시간을 계산하여 작성하시오.

| 프로세스 | 도착 시간 | 서비스 시간 |
|---|---|---|
| A | 0 | 8 |
| B | 1 | 4 |
| C | 2 | 9 |
| D | 3 | 5 |

<details>
<summary><strong>정답 보기</strong></summary>

6.5

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**SRT(Shortest Remaining Time)** 스케줄링으로 4개 프로세스를 처리할 때 **평균 대기시간**을 구하는 문제다.

## 2. 먼저 알아야 할 개념
- **SRT**: **남은 실행 시간이 가장 짧은** 프로세스에게 CPU를 주는 **선점형** 스케줄링. (SJF의 선점형)
- 새 프로세스가 도착할 때마다 **남은 시간끼리 다시 비교**한다.
- **대기시간 = 종료시각 − 도착시각 − 서비스(실행)시간**

## 3. 문제 데이터
| 프로세스 | 도착 | 서비스 |
|---|---:|---:|
| A | 0 | 8 |
| B | 1 | 4 |
| C | 2 | 9 |
| D | 3 | 5 |

## 4. 간트 차트
| 시각 | 상황 | 선택 |
|---|---|---|
| 0 | A만 도착 | **A** 실행 |
| 1 | B 도착 (A 남은 7, B 4) | B가 더 짧음 → **B 선점** |
| 2 | C 도착 (B 남은 3, C 9) | B 계속 |
| 3 | D 도착 (B 남은 2, D 5) | B 계속 |
| 5 | B 종료 (A 7, C 9, D 5) | 가장 짧은 **D** |
| 10 | D 종료 (A 7, C 9) | **A** |
| 17 | A 종료 | **C** |
| 26 | C 종료 | |

```text
 0   1      5       10          17             26
 | A |  B   |   D   |     A     |       C      |
```
## 5. 대기시간
| 프로세스 | 종료 | 종료−도착−서비스 | 대기시간 |
|---|---:|---|---:|
| A | 17 | 17 − 0 − 8 | **9** |
| B | 5 | 5 − 1 − 4 | **0** |
| C | 26 | 26 − 2 − 9 | **15** |
| D | 10 | 10 − 3 − 5 | **2** |

평균 = (9 + 0 + 15 + 2) ÷ 4 = **6.5**

> **정답: `6.5`**

</details>
