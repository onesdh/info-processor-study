# 문제 18

## 문제

다음은 C언어에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력 값을 작성하시오.

```
#include <stdio.h>

void swap(int a, int b) {
    int t = a;
    a = b;
    b = t;
}

int main() {

    int a = 11;
    int b = 19;
    swap(a, b);

    switch(a) {
        case 1:
            b += 1;
        case 11:
            b += 2;
        default:
            b += 3;
        break;
    }

    printf("%d", a-b);
}
```

-13

## 1. 문제에서 묻는 것
**값 전달(swap 실패)** 과 **switch 문의 fall-through(break 없는 흐름)** 가 섞인 문제다.

## 2. 먼저 알아야 할 개념
### (1) 값 전달(Call by Value)
C는 함수에 인자의 **복사본**을 넘긴다. `swap(a, b)`에서 바꾼 것은 **복사본**이므로 `main`의 `a`, `b`는 **그대로**다.
```text
 main:  a=11, b=19
 swap(a,b) 안:  a'=19, b'=11  (복사본끼리 바뀜)  → main 영향 없음
```
### (2) switch 문과 fall-through
- `case` 에 해당하면 **그 위치부터 아래로 실행**한다.
- **`break`를 만날 때까지** 다음 case도 계속 실행된다(fall-through).
- `default`는 일치하는 case가 없을 때 실행되지만, **위에서 흘러 내려오면** 같이 실행된다.

## 3. 실행 과정
| 단계 | 내용 | a | b |
|---|---|---:|---:|
| 시작 | `a = 11, b = 19` | 11 | 19 |
| `swap(a, b)` | 복사본만 변경, **원본 불변** | 11 | 19 |
| `switch(a)` | a = 11 → **`case 11`** 에서 시작 | 11 | 19 |
| `case 11:` `b += 2` | break 없음 → 아래로 계속 | 11 | **21** |
| `default:` `b += 3` | | 11 | **24** |
| `break;` | switch 종료 | 11 | 24 |

(`case 1`은 건너뜀)

`printf("%d", a - b)` → 11 − 24 = **-13**

> **정답: `-13`**

## 4. 암기 포인트
- `swap(int a, int b)`는 값 전달이라 **교환되지 않는다**(포인터를 써야 함).
- **break 없는 case는 다음 case로 계속 실행**된다.
