# 문제 18

## 문제

다음은 C언어에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력 값을 작성하시오.

```
#include <stdio.h>

void swap(int a, int b) {
    int t = a;
    a = b;
    b = t;
}

int main() {

    int a = 11;
    int b = 19;
    swap(a, b);

    switch(a) {
        case 1:
            b += 1;
        case 11:
            b += 2;
        default:
            b += 3;
        break;
    }

    printf("%d", a-b);
}
```

<details>
<summary><strong>정답 보기</strong></summary>

-13

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

C의 일반 함수 인수는 값으로 전달되어 호출자 변수에 영향을 주지 않는다.

## 풀이

swap 내부에서 매개변수만 바뀌고 main의 a=11, b=19는 그대로다. case 11에서 b가 2 증가하고 break가 없어 default까지 내려가 3 더해 b=24다. a-b=11-24=-13이다.

## 오답 분석

case 1은 실행되지 않는다. switch가 case 11에서 시작한 뒤 default까지 fall-through한다.

## 암기 포인트

값 전달 swap은 원본 유지, case는 break 전까지 이어짐.
