# 문제 02

## 문제

다음 문제에서 설명하는 용어를 작성하시오.

데이터를 중복시켜 성능을 향상시키기 위한 기법으로 데이터를 중복 저장하거나

테이블을 합치는 등으로 성능을 향상시키지만 데이터 무결성이 저하될 수 있는 기법

## 1. 문제에서 묻는 것
"데이터를 **중복**시켜 **성능을 향상**, 테이블을 합침, **무결성이 저하**될 수 있음" → 어떤 DB 설계 기법인지 묻는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 정규화 vs 반정규화
| 구분 | 정규화 | **반정규화** |
|---|---|---|
| 목적 | **중복 제거**, 이상 현상 방지 | **조회 성능 향상** |
| 방법 | 테이블을 **분리** | 테이블을 **합치거나 중복 저장** |
| 장점 | 데이터 일관성·무결성 ↑ | **JOIN이 줄어 조회가 빠름** |
| 단점 | JOIN이 많아져 조회가 느려질 수 있음 | **무결성 저하**, 중복 관리 필요 |

### (2) 왜 반정규화를 하나?
정규화로 테이블이 잘게 나뉘면 데이터를 보려면 여러 테이블을 JOIN해야 해서 **느려질 수 있다.** 조회가 훨씬 많은 시스템에서는 **일부러 중복을 허용**한다.
```text
 정규화:  주문(주문번호, 고객번호)  +  고객(고객번호, 고객명)   → 조회 시 JOIN 필요
 반정규화: 주문(주문번호, 고객번호, 고객명)                    → JOIN 없이 빠르게 조회
                                      ↑ 고객명 중복 저장 (고객명 변경 시 모든 주문을 고쳐야 함)
```
### (3) 반정규화 기법
테이블 병합, 테이블 분할(수직/수평), **중복 칼럼 추가**, 파생(계산) 칼럼 추가, 요약 테이블 추가.

## 3. 문제 풀이
| 단서 | 반정규화 |
|---|---|
| 데이터를 중복 저장, 테이블을 합침 | ✅ |
| 성능 향상이 목적 | ✅ |
| 데이터 무결성 저하 가능 | ✅ |

> **정답: 반정규화 (Denormalization)**
