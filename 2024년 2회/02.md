# 문제 02

## 문제

다음 문제에서 설명하는 용어를 작성하시오.

데이터를 중복시켜 성능을 향상시키기 위한 기법으로 데이터를 중복 저장하거나

테이블을 합치는 등으로 성능을 향상시키지만 데이터 무결성이 저하될 수 있는 기법

<details>
<summary><strong>정답 보기</strong></summary>

반정규화

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

반정규화는 성능 요구에 따라 의도적으로 중복이나 통합 구조를 도입하는 데이터 모델링 기법이다.

## 풀이

정규화된 테이블은 중복을 줄이고 갱신 이상을 막는다. 조회가 느린 경우 조인 수를 줄이거나 값을 복제하는 반정규화를 적용할 수 있지만, 중복 데이터 갱신 불일치 위험을 관리해야 한다.

## 오답 분석

정규화는 중복을 줄여 무결성을 높이는 방향이고, 반정규화는 성능을 위해 이를 일부 완화한다.

## 암기 포인트

성능 향상을 위해 중복을 허용하면 반정규화.

</details>
