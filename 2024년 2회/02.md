# 문제 02 — 반정규화

## 문제

데이터 중복 저장이나 테이블 통합으로 조회 성능을 높이지만 무결성 저하 가능성이 있는 기법을 쓰시오.

## 정답

반정규화 (Denormalization)

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

반정규화는 성능 요구에 따라 의도적으로 중복이나 통합 구조를 도입하는 데이터 모델링 기법이다.

## 풀이

정규화된 테이블은 중복을 줄이고 갱신 이상을 막는다. 조회가 느린 경우 조인 수를 줄이거나 값을 복제하는 반정규화를 적용할 수 있지만, 중복 데이터 갱신 불일치 위험을 관리해야 한다.

## 오답 분석

정규화는 중복을 줄여 무결성을 높이는 방향이고, 반정규화는 성능을 위해 이를 일부 완화한다.

## 암기 포인트

성능 향상을 위해 중복을 허용하면 반정규화.
