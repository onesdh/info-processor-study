# 문제 13

## 문제

다음은 C언어에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
#include <stdio.h>

int main() {
    int arr[3][3] = {1, 2, 3, 4, 5, 6, 7, 8, 9};
    int* parr[2] = {arr[1], arr[2]};
    printf("%d", parr[1][1] + *(parr[1]+2) + **parr);

    return 0;
}
```

<details>
<summary><strong>정답 보기</strong></summary>

21

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**2차원 배열**과 **포인터 배열**을 이용한 여러 표현식의 합을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 2차원 배열은 "배열의 배열"
```c
int arr[3][3] = {1,2,3,4,5,6,7,8,9};   // 행 우선(row-major)으로 채워짐
```
```text
 arr[0] = {1, 2, 3}
 arr[1] = {4, 5, 6}
 arr[2] = {7, 8, 9}
```
`arr[1]`은 **두 번째 행의 첫 원소 주소**(= 4가 있는 곳)로 쓰인다.

### (2) 포인터 배열
```c
int* parr[2] = { arr[1], arr[2] };
```
```text
 parr[0] ──▶ {4, 5, 6}   (arr[1])
 parr[1] ──▶ {7, 8, 9}   (arr[2])
```
### (3) 표현식 해석
| 표현 | 의미 |
|---|---|
| `parr[1][1]` | parr[1]이 가리키는 배열의 **인덱스 1** = 8 |
| `*(parr[1] + 2)` | parr[1]에서 **2칸 뒤**의 값 = `parr[1][2]` = 9 |
| `**parr` | `*parr` = parr[0](=arr[1]), 한 번 더 `*` → 그 배열의 **첫 원소** = 4 |

## 3. 계산
| 항 | 값 |
|---|---:|
| `parr[1][1]` | 8 |
| `*(parr[1]+2)` | 9 |
| `**parr` | 4 |
| **합** | **21** |

> **정답: `21`**

## 4. 암기 포인트
- `**p` = `*(*p)` → `p[0][0]`.
- `*(p + n)` ≡ `p[n]`.
