# 문제 03 — SQL INSERT SELECT UPDATE

## 문제

값 직접 입력, 조회 결과 삽입, 전체 조회, 값 변경에 필요한 SQL 절을 채우시오.

## 정답

① VALUES ② SELECT ③ FROM ④ SET

<summary><strong>상세 해설</strong></summary>

## 핵심 개념

INSERT VALUES는 상수 행 입력, INSERT SELECT는 조회 결과 삽입, SELECT FROM은 테이블 조회, UPDATE SET은 값을 변경한다.

## 풀이

첫 문장은 VALUES 목록으로 새 행을 넣는다. 두 번째는 SELECT 결과를 INSERT 대상에 삽입한다. 조회 문장은 FROM 뒤에 대상 테이블을 적는다. UPDATE 문장은 SET 뒤에 변경할 열과 값을 지정한다.

## 오답 분석

INSERT INTO 다음에 VALUES 또는 SELECT가 올 수 있다. UPDATE의 변경 열은 WHERE가 아니라 SET에 둔다.

## 암기 포인트

입력 VALUES, 조회 SELECT/FROM, 변경 SET.
