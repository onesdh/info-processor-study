# 문제 03

## 문제

다음은 SQL에 관한 문제이다. 아래 SQL 구문의 빈칸을 작성하시오.

테이블

사원 [사원번호(PK), 이름, 나이, 부서]

부서 [사원번호(PK), 이름, 주소, 나이]

신입 사원이 들어와서 사원 테이블에 추가

INSERT INTO 사원 (사원번호, 이름, 주소, 부서)   [      ①     ] (32431, '정실기', '서울', '영업');

위에 신입사원을 검색하면서 부서 테이블에 추가

INSERT INTO 부서 (사원번호, 이름, 나이, 부서)

[    ②     ] 사원번호, 이름, 나이, 23 FROM 사원 WHERE 이름 = '정실기';

전체 사원 테이블 조회

SELECT  \*   [    ③   ]   사원;

퇴사로 인해 부서에 해당하는 값을 '퇴사'로 변경

UPDATE 사원   [      ④     ]   부서  =  '퇴사'  WHERE 사원번호  = 32431;

<details>
<summary><strong>정답 보기</strong></summary>

① : VALUES

② : SELECT

③ : FROM

④ : SET

</details>

## 1. 문제에서 묻는 것
**INSERT, UPDATE, SELECT**의 기본 문법에서 빠진 키워드 4개를 채우는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 데이터 조작어(DML) 기본 문법
| 명령 | 문법 | 의미 |
|---|---|---|
| **INSERT (값 직접)** | `INSERT INTO 테이블(열…) VALUES (값…);` | 새 행 추가 |
| **INSERT (조회 결과)** | `INSERT INTO 테이블(열…) SELECT …;` | 다른 조회 결과를 추가 |
| **SELECT** | `SELECT 열 FROM 테이블 [WHERE 조건];` | 조회 |
| **UPDATE** | `UPDATE 테이블 SET 열 = 값 [WHERE 조건];` | 값 변경 |
| DELETE | `DELETE FROM 테이블 [WHERE 조건];` | 행 삭제 |

### (2) 두 가지 INSERT 형태 비교
```sql
INSERT INTO 사원 (사원번호, 이름, 주소, 부서) VALUES (32431, '정실기', '서울', '영업');   -- 값을 직접 지정
INSERT INTO 부서 (사원번호, 이름, 나이, 부서)
SELECT 사원번호, 이름, 나이, 23 FROM 사원 WHERE 이름 = '정실기';                        -- 조회한 결과를 삽입
```
## 3. 문제 풀이
| 빈칸 | 위치 | 정답 | 이유 |
|:--:|---|---|---|
| ① | `INSERT INTO 사원(…) [ ① ] (32431, '정실기', '서울', '영업');` | **VALUES** | 괄호 안에 **값을 직접 나열**하는 형태 |
| ② | `INSERT INTO 부서(…) [ ② ] 사원번호, 이름, 나이, 23 FROM 사원 …` | **SELECT** | 값 대신 **다른 테이블의 조회 결과**를 삽입 |
| ③ | `SELECT * [ ③ ] 사원;` | **FROM** | 조회할 테이블 지정 |
| ④ | `UPDATE 사원 [ ④ ] 부서 = '퇴사' WHERE 사원번호 = 32431;` | **SET** | 바꿀 열과 값 지정 |

> **정답: ① VALUES ② SELECT ③ FROM ④ SET**

## 4. 암기 포인트
- `INSERT ... VALUES (…)` / `INSERT ... SELECT …` 두 형태.
- `UPDATE 테이블 SET 열=값 WHERE 조건` : **WHERE를 빼면 모든 행**이 바뀐다(주의).
