# 문제 09

## 문제

아래 내용을 확인하고 보기에서 알맞는 답을 고르시오.

실행 순서가 밀접한 관계를 갖는 기능을 모아 모듈로 구성한다.  
한 모듈 내부의 한 기능 요소에 의한 출력 자료가 다음 기능 원소의 입력 자료로서 제공되는 형태이다.

## 1. 문제에서 묻는 것
"기능 요소의 **출력**이 **다음 기능 요소의 입력**으로 제공되는" 모듈의 응집도 유형을 고르는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 응집도(Cohesion)
모듈 **내부 요소들이 얼마나 긴밀히 관련**되어 있는가. **높을수록 좋다.**

### (2) 응집도 7단계 (약 → 강)
```text
 우연적 < 논리적 < 시간적 < 절차적 < 통신적 < 순차적 < 기능적
```
| 유형 | 특징 |
|---|---|
| 우연적 | 관련 없는 기능이 묶임 |
| 논리적 | 유사한 기능을 묶고 **매개변수로 선택** |
| 시간적 | **같은 시간대**에 실행되는 기능 |
| **절차적** | **실행 순서가 밀접**한 기능(순서만 중요) |
| 통신적 | **같은 입력·출력 데이터**를 사용하는 기능 |
| **순차적** | **앞 기능의 출력이 뒤 기능의 입력**이 됨 |
| 기능적 | **단 하나의 기능**만 수행 |

### (3) 순차적 vs 절차적
```text
 절차적 : [기능A] → [기능B] → [기능C]      (순서만 정해짐, 데이터 전달은 필수 아님)
 순차적 : [기능A] ─출력▶ [기능B] ─출력▶ [기능C]   (앞의 출력이 뒤의 입력!)
```
## 3. 문제 풀이
| 문제 단서 | 해당 |
|---|---|
| 실행 순서가 밀접한 관계 | 절차적/순차적 후보 |
| **한 기능의 출력이 다음 기능의 입력** | **순차적(Sequential)** |

보기: ㄱ 기능적 ❌ / ㄴ 우연적 ❌ / ㄷ 통신적(같은 데이터 사용) ❌ / ㄹ 절차적(순서만) ❌ / ㅁ 시간적 ❌ / **ㅂ 순차적 ✅** / ㅅ 논리적 ❌

> **정답: ㅂ. 순차적(Sequential)**

## 4. 암기 포인트
- **출력 → 입력으로 이어짐 = 순차적**, **순서만 중요 = 절차적**.
