# 문제 19

## 문제

다음은 C언어의 구조체에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력 값을 작성하시오.

```
#include <stdio.h>

struct node {
    int n1;
    struct node *n2;
};

int main() {

    struct node a = {10, NULL};
    struct node b = {20, NULL};
    struct node c = {30, NULL};

    struct node *head = &a;
    a.n2 = &b;
    b.n2 = &c;

    printf("%d\n", head->n2->n1);

    return 0;
}
```

<details>
<summary><strong>정답 보기</strong></summary>

20

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

구조체 포인터의 n2를 따라 다음 노드로 이동해 해당 노드의 값을 읽는다.

## 풀이

head는 a, head->n2는 b, b의 n1은 20이다.

## 오답 분석

head->n1은 10이고 head->n2->n2->n1은 c의 30이다. 포인터 화살표를 한 단계씩 따라간다.

## 암기 포인트

head→a, n2→b, n1→20.

</details>
