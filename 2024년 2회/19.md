# 문제 19

## 문제

다음은 C언어의 구조체에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력 값을 작성하시오.

```
#include <stdio.h>

struct node {
    int n1;
    struct node *n2;
};

int main() {

    struct node a = {10, NULL};
    struct node b = {20, NULL};
    struct node c = {30, NULL};

    struct node *head = &a;
    a.n2 = &b;
    b.n2 = &c;

    printf("%d\n", head->n2->n1);

    return 0;
}
```

<summary><strong>정답 보기</strong></summary>

20

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**구조체 포인터로 연결 리스트**를 따라가 `head->n2->n1` 값을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 구조체와 포인터 멤버
```c
struct node { int n1; struct node *n2; };   // n1 = 값, n2 = 다음 노드 포인터
```
### (2) 연결 구성
```c
a = {10, NULL}, b = {20, NULL}, c = {30, NULL}
head = &a;  a.n2 = &b;  b.n2 = &c;
```
```text
 head ──▶ a(10) ──▶ b(20) ──▶ c(30) ──▶ NULL
```
### (3) `->` 연산자
`p->m` = `(*p).m` : 포인터가 가리키는 구조체의 멤버. 연속해서 쓰면 **한 칸씩 따라간다**.

## 3. 실행 과정
`head->n2->n1`
| 단계 | 의미 | 값 |
|---|---|---|
| `head` | `&a` (첫 노드) | a |
| `head->n2` | a의 다음 노드 | **b** |
| `head->n2->n1` | b의 값 | **20** |

> **정답: `20`**

## 4. 암기 포인트
- `head->n2->n1`: head에서 **한 번 이동**한 노드(b)의 값.
- 노드 이름이 아니라 **포인터 연결**을 따라간다.
