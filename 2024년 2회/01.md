# 문제 01 — Java 배열 참조 비교

## 문제

내용이 같은 별도 int 배열 세 쌍을 ==로 비교한 출력값을 구하시오.

<details>
<summary><strong>정답 보기</strong></summary>

NNN

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

배열의 == 연산은 원소가 아니라 배열 객체의 참조가 같은지 비교한다.

## 풀이

a, b, c는 각각 new로 생성된 서로 다른 배열 객체다. 원소와 길이가 같더라도 a==b, a==c, b==c는 모두 false여서 NNN이 출력된다.

## 오답 분석

배열 내용 비교는 Arrays.equals 같은 별도 기능을 써야 한다. 참조의 동일성과 내용의 동일성을 구분한다.

## 암기 포인트

배열 == 는 주소 비교.
