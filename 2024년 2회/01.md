# 문제 01

## 문제

다음은 Java 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
class Main {
    public static void main(String[] args) {
        int[] a = new int[]{1, 2, 3, 4};
        int[] b = new int[]{1, 2, 3, 4};
        int[] c = new int[]{1, 2, 3};

        check(a, b);
        check(a, c);
        check(b, c);
    }

    public static void check(int[] a, int[] b) {
        if (a==b) {
            System.out.print("O");
        }else{
            System.out.print("N");
        }

    }
}
```

## 1. 문제에서 묻는 것
Java 배열을 `==`로 비교했을 때의 결과를 묻는 문제다. **내용이 같아도 `==`는 같은 객체인지를 비교한다**는 점이 핵심이다.

## 2. 먼저 알아야 할 개념
### (1) 변수에는 "주소"가 들어 있다 (참조형)
배열·객체·문자열은 힙(heap) 메모리에 만들어지고, 변수에는 **그 위치(주소)** 가 저장된다.
```java
int[] a = new int[]{1, 2, 3, 4};   // 새 배열 객체 생성 → a는 그 주소를 가짐
int[] b = new int[]{1, 2, 3, 4};   // 또 다른 새 배열 객체 → b는 다른 주소
```
```text
 a ──▶ [1][2][3][4]   (주소 0x100)
 b ──▶ [1][2][3][4]   (주소 0x200)   ← 내용은 같아도 서로 다른 객체
 c ──▶ [1][2][3]      (주소 0x300)
```
### (2) `==` 와 `equals`
| 연산 | 비교 대상 |
|---|---|
| `a == b` (참조형) | **같은 객체(주소)** 인가 |
| `a.equals(b)` | **내용**이 같은가 (배열은 `Arrays.equals`로 내용 비교) |

## 3. 실행 과정
`new`를 쓸 때마다 **새 객체**가 만들어진다. 세 변수는 모두 서로 다른 주소를 가진다.

| 호출 | 비교 | 같은 객체? | 출력 |
|---|---|:---:|:---:|
| `check(a, b)` | a == b | 아니오 (내용은 같지만 별개 객체) | **N** |
| `check(a, c)` | a == c | 아니오 | **N** |
| `check(b, c)` | b == c | 아니오 | **N** |

> **정답: `NNN`**

## 4. 암기 포인트
- 참조형의 `==` = **같은 주소인가?** `a`와 `b`는 내용이 같아도 `N`.
- 만약 `int[] d = a;`라면 `a == d`는 같은 객체이므로 `O`.
