# 문제 20

## 문제

다음은 Java에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력 값을 작성하시오.

```
class Main {
    public static void main(String[] args) {
        String str = "ITISTESTSTRING";
        String[] result = str.split("T");
        System.out.print(result[3]);
    }
}
```

## 1. 문제에서 묻는 것
Java `String.split()`으로 문자열을 구분자로 나눈 뒤 **특정 인덱스의 조각**을 출력하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) `split(구분자)`
문자열을 **구분자를 기준으로 잘라** `String[]` 배열로 돌려준다. **구분자 자체는 결과에 포함되지 않는다.**
```java
"a,b,c".split(",")  →  ["a", "b", "c"]
```
### (2) 연속된 구분자
구분자가 연속되면 그 사이에 **빈 문자열("")** 이 생긴다. (맨 끝의 빈 문자열은 제거됨)

## 3. 실행 과정 (`"ITISTESTSTRING".split("T")`)
글자를 하나씩 보고 `T`가 나올 때마다 자른다.
```text
 I T I S T E S T S T R I N G
 └─┘ └──┘ └──┘ └┘ └────┘
  I    IS    ES   S   RING
  [0]  [1]   [2]  [3] [4]
```
| 인덱스 | 조각 |
|---:|---|
| 0 | `I` |
| 1 | `IS` |
| 2 | `ES` |
| 3 | `S` |
| 4 | `RING` |

`result[3]` = **`S`**

> **정답: `S`**

## 4. 암기 포인트
- 구분자 `T`는 결과에서 사라진다.
- 배열 인덱스는 **0부터** 센다 → `result[3]`은 **네 번째** 조각.
