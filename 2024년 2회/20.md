# 문제 20

## 문제

다음은 Java에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력 값을 작성하시오.

```
class Main {
    public static void main(String[] args) {
        String str = "ITISTESTSTRING";
        String[] result = str.split("T");
        System.out.print(result[3]);
    }
}
```

<details>
<summary><strong>정답 보기</strong></summary>

S

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

split은 구분 문자열을 기준으로 나눈 부분 문자열 배열을 만든다.

## 풀이

문자열은 T 위치에서 끊겨 [I, IS, ES, S, RING]이 된다. 인덱스는 0부터 시작하므로 result[3]은 S다.

## 오답 분석

구분 문자인 T 자체는 결과 조각에 포함되지 않는다. 4번째 항목을 인덱스 3으로 접근한다.

## 암기 포인트

split 결과 0부터 세기.
