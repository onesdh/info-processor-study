# 문제 08

## 문제

패킷 교환 방식 중에 연결형과 비연결형에 해당하는 방식을 작성하시오.

① 연결형 교환 방식

② 비연결형 교환 방식

① 가상회선

② 데이터그램

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**패킷 교환 방식**을 연결형과 비연결형으로 나눴을 때 각각의 이름을 묻는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 패킷 교환
데이터를 **작은 조각(패킷)** 으로 나눠 네트워크로 보내는 방식. 패킷을 어떻게 보내는지에 따라 두 가지가 있다.

### (2) 두 방식 비교
| 구분 | **가상회선(Virtual Circuit)** | **데이터그램(Datagram)** |
|---|---|---|
| 형태 | **연결형** | **비연결형** |
| 사전 설정 | 전송 전에 **논리적 경로를 먼저 설정** | 경로 설정 **없음** |
| 경로 | 모든 패킷이 **같은 경로** | 패킷마다 **각자 다른 경로** 가능 |
| 순서 | 도착 순서 **보장** | 도착 순서 **뒤바뀔 수 있음** (재조립 필요) |
| 비유 | **전화**(먼저 연결하고 대화) | **우편**(편지마다 따로 배달) |
| 예 | X.25, 프레임 릴레이, ATM | **IP(인터넷)**, UDP |

```text
 가상회선 :  송신 ─ 연결 설정 ─▶ ① → ② → ③ (같은 길) ─▶ 수신
 데이터그램:  송신 ─ ① ─▶ 경로A ─┐
                    ─ ② ─▶ 경로B ─┼─▶ 수신 (순서 섞여 도착 가능)
                    ─ ③ ─▶ 경로C ─┘
```
## 3. 문제 풀이
| 번호 | 방식 | 정답 |
|---|---|---|
| ① | 연결형 교환 방식 | **가상회선** |
| ② | 비연결형 교환 방식 | **데이터그램** |

> **정답: ① 가상회선 ② 데이터그램**
