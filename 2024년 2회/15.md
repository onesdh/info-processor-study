# 문제 15

## 문제

다음은 C언어에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
#include <stdio.h>
#include <string.h>

void sumFn(char* d, const char* s) {

    while (*s) {
        *d = *s;
        d++;
        s++;
    }
    *d = '\0';
}

int main() {
   const char* str1 = "first";
    char str2[50] = "teststring";
    int result=0;
    sumFn(str2, str1);

    for (int i = 0; str2[i] != '\0'; i++) {
        result += i;
    }
    printf("%d", result);

    return 0;
}
```

## 1. 문제에서 묻는 것
C 문자열 **복사 함수**를 실행한 뒤 문자열의 각 **인덱스 합**(`0+1+…`)을 구하는 문제다. 원래 문자열이 더 길었음에도 **널 문자로 끝나는 위치**가 핵심이다.

## 2. 먼저 알아야 할 개념
### (1) C 문자열과 널 문자
C 문자열은 **`'\0'`(널 문자)가 나오는 곳까지**가 문자열이다. 그 뒤에 다른 글자가 남아 있어도 **무시**된다.
```text
 str2 초기:  t e s t s t r i n g \0 ...
 복사 후  :  f i r s t \0 t r i n g ...       ← 5글자 복사 후 '\0'을 써 넣음
                      └ 이 뒤는 문자열로 취급 ❌ (널에서 끝)
```
### (2) sumFn 의 동작
```c
while (*s) { *d = *s; d++; s++; }   // s가 가리키는 글자가 널이 아닌 동안 한 글자씩 복사
*d = '\0';                           // 마지막에 널 문자 추가
```
복사 대상은 **"first"(5글자)** 이고, 그 뒤에 `'\0'`이 붙는다.

## 3. 실행 과정
| 단계 | 내용 |
|---|---|
| ① | `str2 = "teststring"` (10글자) |
| ② | `sumFn(str2, "first")` → `f,i,r,s,t` 5글자 복사 후 `str2[5] = '\0'` |
| ③ | `str2`는 이제 문자열 **"first"**, 길이 5 |

**루프** `for (i = 0; str2[i] != '\0'; i++) result += i;`
| i | str2[i] | result |
|---:|:---:|---:|
| 0 | f | 0 |
| 1 | i | 1 |
| 2 | r | 3 |
| 3 | s | 6 |
| 4 | t | 10 |
| 5 | `\0` | 종료 |

`result = 0+1+2+3+4` = **10**

> **정답: `10`**

## 4. 암기 포인트
- `'\0'` 뒤의 문자는 무시된다(`"first\0ring"`처럼 보이지만 문자열은 `first`).
- 길이 n인 문자열의 인덱스 합 = 0부터 n−1까지의 합.
