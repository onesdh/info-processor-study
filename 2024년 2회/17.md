# 문제 17

## 문제

다음은 Java에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력 값을 작성하시오.

```
class Main {
    public static void main(String[] args) {
        String str = "abacabcd";
        boolean[] seen = new boolean[256];
        System.out.print(calculFn(str, str.length()-1, seen));
    }

    public static String calculFn(String str, int index, boolean[] seen) {
        if(index < 0) return "";
        char c = str.charAt(index);
        String result = calculFn(str, index-1, seen);
        if(!seen[c]) {
            seen[c] = true;
            return c + result;
        }
        return result;
    }
}
```

## 1. 문제에서 묻는 것
**재귀 호출과 `seen` 배열**로 문자열의 **중복 문자를 제거**한 결과를 구하는 문제다. 재귀가 **끝까지 내려간 뒤 돌아오며** 실행되는 순서가 핵심이다.

## 2. 먼저 알아야 할 개념
### (1) 재귀의 실행 순서
```java
String result = calculFn(str, index-1, seen);   // ① 먼저 더 깊이 들어감 (앞쪽 글자부터 처리됨)
if (!seen[c]) { ... return c + result; }         // ② 돌아오면서 현재 글자 처리
```
`index`를 줄여 가며 호출하므로 **index 0(맨 앞 글자)이 가장 먼저** ②를 실행하고, 그 다음 index 1, 2 … 순서로 돌아온다.

### (2) `seen[c]`
`boolean[256]` 배열로 **문자 c가 이미 등장했는지** 기록한다. 문자 c는 아스키 코드값으로 인덱스가 된다.

### (3) `return c + result`
현재 글자를 **앞에** 붙이므로, 나중에 처리되는 글자가 **더 앞**에 온다.

## 3. 실행 과정 (`str = "abacabcd"`)
```text
 인덱스:  0  1  2  3  4  5  6  7
 문자  :  a  b  a  c  a  b  c  d
```
깊이 들어간 뒤 index 0부터 처리(돌아오는 순서):
| 처리 순서 | index | 글자 | seen 여부 | 동작 | 반환 문자열 |
|---:|---:|:---:|---|---|---|
| 1 | 0 | a | 처음 | seen[a]=true, `a + ""` | `a` |
| 2 | 1 | b | 처음 | `b + "a"` | `ba` |
| 3 | 2 | a | **이미 봄** | 건너뜀 | `ba` |
| 4 | 3 | c | 처음 | `c + "ba"` | `cba` |
| 5 | 4 | a | 이미 봄 | 건너뜀 | `cba` |
| 6 | 5 | b | 이미 봄 | 건너뜀 | `cba` |
| 7 | 6 | c | 이미 봄 | 건너뜀 | `cba` |
| 8 | 7 | d | 처음 | `d + "cba"` | **`dcba`** |

> **정답: `dcba`**

## 4. 암기 포인트
- 재귀 호출이 `result`를 **먼저** 만들면, 결과는 **앞 글자부터** 처리됨.
- `c + result` 로 앞에 붙이니 최종은 **뒤집힌 순서**(중복 제거된 문자: a,b,c,d → dcba).
