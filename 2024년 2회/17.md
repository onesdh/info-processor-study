# 문제 17

## 문제

다음은 Java에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력 값을 작성하시오.

```
class Main {
    public static void main(String[] args) {
        String str = "abacabcd";
        boolean[] seen = new boolean[256];
        System.out.print(calculFn(str, str.length()-1, seen));
    }

    public static String calculFn(String str, int index, boolean[] seen) {
        if(index < 0) return "";
        char c = str.charAt(index);
        String result = calculFn(str, index-1, seen);
        if(!seen[c]) {
            seen[c] = true;
            return c + result;
        }
        return result;
    }
}
```

## 핵심 개념

재귀는 인덱스를 감소시킨 뒤 되돌아오며 문자를 앞에 붙이고, seen이 처음 만난 출현만 허용한다.

## 풀이

호출이 되돌아오는 순서에서 앞 인덱스의 a,b,c,d가 처음으로 seen에 등록된다. 각 새 문자를 result 앞에 붙이므로 뒤쪽의 중복은 건너뛰고 최종 문자열은 dcba가 된다.

## 오답 분석

문자열을 앞에서부터 곧바로 누적한다고 착각하면 순서가 달라진다. result 문자열에 c + result로 앞에 붙인다.

## 암기 포인트

새 문자는 재귀 복귀 중 앞에 붙여 dcba.
