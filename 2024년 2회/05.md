# 문제 05

## 문제

다음은 프로토콜에 대한 내용이다. 아래 내용을 읽고 알맞는 답을 작성하시오.

- Network layer에서 IP패킷을 암호화하고 인증하는 등의 보안을 위한 표준이다.

- 기업에서 사설 인터넷망으로 사용할 수 있는 VPN을 구현하는데 사용되는 프로토콜이다.  
- AH(Authentication Header)와 ESP(Encapsulating Security Payload)라는 두 가지 보안 프로토콜을 사용한다.

## 1. 문제에서 묻는 것
"네트워크 계층(IP)에서 **패킷 암호화·인증**, **VPN 구현**, **AH와 ESP**" → 어떤 프로토콜인지 묻는 문제다.

## 2. 먼저 알아야 할 개념
### (1) IPsec (IP Security)
**IP 계층(3계층)** 에서 패킷을 **암호화·인증**하여 보호하는 **보안 프로토콜 모음**이다. 응용 프로그램을 수정하지 않아도 **모든 IP 통신이 보호**된다. VPN 구현에 널리 사용된다.

### (2) 두 가지 보안 프로토콜
| 프로토콜 | 이름 | 기능 |
|---|---|---|
| **AH** | Authentication Header | **인증 + 무결성** (암호화는 ✕) |
| **ESP** | Encapsulating Security Payload | **암호화 + 인증 + 무결성** |

### (3) 동작 모드
```text
 전송(Transport) 모드 : [IP 헤더][ ESP ][ 데이터 ]          ← 데이터 부분만 보호 (호스트↔호스트)
 터널(Tunnel)   모드 : [새 IP 헤더][ ESP ][ 원본 IP 패킷 전체 ]  ← 패킷 전체를 감싸 보호 (VPN 게이트웨이 간)
```
### (4) 계층별 보안 프로토콜 비교
| 계층 | 프로토콜 |
|---|---|
| 2계층 | L2TP, PPTP |
| **3계층** | **IPsec** |
| 4~7계층 | SSL/TLS, SSH |

## 3. 문제 풀이
| 단서 | IPsec |
|---|---|
| **Network layer**에서 IP 패킷 암호화·인증 | ✅ |
| 사설망(VPN) 구현에 사용 | ✅ |
| **AH**, **ESP** 두 가지 보안 프로토콜 | ✅ |

> **정답: IPSec (IP Security)**
