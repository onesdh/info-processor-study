# 문제 05

## 문제

다음은 프로토콜에 대한 내용이다. 아래 내용을 읽고 알맞는 답을 작성하시오.

- Network layer에서 IP패킷을 암호화하고 인증하는 등의 보안을 위한 표준이다.

- 기업에서 사설 인터넷망으로 사용할 수 있는 VPN을 구현하는데 사용되는 프로토콜이다.  
- AH(Authentication Header)와 ESP(Encapsulating Security Payload)라는 두 가지 보안 프로토콜을 사용한다.

## 핵심 개념

IPsec은 네트워크 계층에서 IP 통신의 기밀성, 무결성, 인증을 제공하는 프로토콜 모음이다.

## 풀이

AH는 인증과 무결성 확인을, ESP는 암호화와 선택적 인증을 제공한다. site-to-site 또는 원격접속 VPN 구현에 널리 쓰인다.

## 오답 분석

SSL/TLS는 전송 계층 위의 보안 프로토콜이다. AH·ESP 조합과 IP 계층 보호는 IPsec의 특징이다.

## 암기 포인트

IP 계층 + AH/ESP는 IPsec.
