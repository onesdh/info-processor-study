# 문제 06

## 문제

다음은 Python에 대한 문제이다. 아래 코드를 읽고 알맞는 출력 값을 작성하시오.

```
def fnCalculation(x,y):
    result = 0;
    for i in range(len(x)):
     temp = x[i:i+len(y)]
     if temp == y:
       result += 1;
    return result

a = "abdcabcabca"
p1 = "ab";
p2 = "ca";

out = f"ab{fnCalculation(a,p1)}ca{fnCalculation(a,p2)}"
print(out)
```

## 핵심 개념

각 인덱스에서 길이 2의 부분 문자열을 잘라 비교하므로 겹치는 출현도 셈한다.

## 풀이

문자열 abdcabcabca에서 길이 2로 훑으면 ab는 세 번, ca도 세 번 나타난다. f-string이 접두 문자열과 각 횟수를 이어 ab3ca3을 출력한다.

## 오답 분석

두 글자씩 건너뛰는 것이 아니라 매 인덱스마다 확인하므로 겹치는 부분 문자열이 가능하다.

## 암기 포인트

한 칸씩 이동하며 길이 2 부분 문자열 검사.
