# 문제 16

## 문제

아래는 소프트웨어 설계에 대한 내용이다. 내용을 읽고 괄호안에 알맞는 답을 작성하시오.

- 어떤 모듈이 다른 모듈 내부의 논리적인 흐름을 제어하기 위해, 제어를 통신하거나 제어 요소를 전달하는 결합도이다.  
- 한 모듈이 다른 모듈의 상세한 처리 절차를 알고 있어 이를 통제하는 경우나 처리 기능이 두 모듈에 분리되어 설계된 경우에 발생한다.

(              ) Coupling

제어  or  Control

<summary><strong>상세 해설</strong></summary>

## 핵심 개념

제어 결합도는 호출 모듈이 제어 플래그나 명령값을 전달해 피호출 모듈의 수행 경로를 선택하게 한다.

## 풀이

전달된 값이 단순 자료가 아니라 피호출 모듈이 어떤 동작을 할지 제어하는 데 쓰인다. 이 관계를 Control Coupling이라 한다.

## 오답 분석

자료 결합도는 필요한 데이터 전달, 공통 결합도는 전역 데이터 공유, 내용 결합도는 내부 구현에 직접 의존한다.

## 암기 포인트

제어용 플래그 전달은 Control Coupling.
