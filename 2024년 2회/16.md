# 문제 16

## 문제

아래는 소프트웨어 설계에 대한 내용이다. 내용을 읽고 괄호안에 알맞는 답을 작성하시오.

- 어떤 모듈이 다른 모듈 내부의 논리적인 흐름을 제어하기 위해, 제어를 통신하거나 제어 요소를 전달하는 결합도이다.  
- 한 모듈이 다른 모듈의 상세한 처리 절차를 알고 있어 이를 통제하는 경우나 처리 기능이 두 모듈에 분리되어 설계된 경우에 발생한다.

(              ) Coupling

제어  or  Control

## 1. 문제에서 묻는 것
"다른 모듈 **내부의 논리적 흐름을 제어**하기 위해 **제어 요소(플래그)** 를 전달" → 어떤 결합도인지 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 결합도 순서 (낮을수록 좋음)
```text
 자료 < 스탬프 < 제어 < 외부 < 공통 < 내용
```
### (2) 제어 결합도(Control Coupling)
한 모듈이 다른 모듈에 **"어떻게 동작하라"는 제어 정보(플래그, 모드 값)** 를 넘겨 **내부 흐름을 통제**하는 형태다.
```c
void process(int mode) {          // 호출자가 mode로 내부 분기를 결정
    if (mode == 1) { ... A ... }
    else           { ... B ... }
}
process(1);   // "A를 실행해라" 라고 제어를 전달
```
- 호출하는 쪽이 **상대 모듈의 처리 절차를 알고 있어야** 한다 → 의존이 높다.
- 한 기능이 **두 모듈에 나뉘어** 설계되었을 때 발생한다.

### (3) 가까운 유형과 구분
| 유형 | 전달하는 것 |
|---|---|
| 자료 | **필요한 값**만 |
| 스탬프 | **자료구조**(구조체·배열) 통째로 |
| **제어** | **흐름을 제어하는 값(플래그)** |

## 3. 문제 풀이
| 단서 | 제어 결합도 |
|---|---|
| 다른 모듈 내부의 **논리적 흐름을 제어** | ✅ |
| **제어 요소**를 전달 | ✅ |
| 한 모듈이 다른 모듈의 **상세한 처리 절차**를 알고 통제 | ✅ |

> **정답: 제어 (Control) 결합도**
