# 문제 16 — 제어 결합도

## 문제

한 모듈이 다른 모듈의 내부 처리 흐름을 제어하기 위해 제어 정보를 전달하는 결합도를 영문으로 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

제어 결합도 (Control Coupling)

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

제어 결합도는 호출 모듈이 제어 플래그나 명령값을 전달해 피호출 모듈의 수행 경로를 선택하게 한다.

## 풀이

전달된 값이 단순 자료가 아니라 피호출 모듈이 어떤 동작을 할지 제어하는 데 쓰인다. 이 관계를 Control Coupling이라 한다.

## 오답 분석

자료 결합도는 필요한 데이터 전달, 공통 결합도는 전역 데이터 공유, 내용 결합도는 내부 구현에 직접 의존한다.

## 암기 포인트

제어용 플래그 전달은 Control Coupling.
