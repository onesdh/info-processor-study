# 문제 05 — Java 상속 객체 생성

## 문제

Parent 참조 변수에 Child 객체를 생성해 대입하는 식 Parent pa = ___ Child(); 에 필요한 키워드를 쓰시오.

## 정답

new

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

new는 클래스의 새 객체를 생성한다.

## 풀이

Parent형 변수는 하위 타입 Child 객체를 참조할 수 있으므로 new Child()로 생성한다.

## 오답 분석

상속과 다형성은 참조형과 실제 객체형이 다를 수 있게 한다.

## 암기 포인트

객체 생성 키워드는 new.
