# 문제 05

## 문제

다음은 자바 코드이다. 다음 밑줄에 들어갈 키워드를 쓰시오.

```
class parent
	public void show(){
    	system.out.println("Parent");
    }
}

class Child extends Parent{
	public void show(){
    	system.out.println("Child");
    }
}

public class good{
	public static void main(String[] args){
    	Parent pa = ____  Child();
        pa.show();
    }
}
```

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**업캐스팅(부모 타입 변수에 자식 객체 대입)** 에서 객체를 생성하는 키워드(`new`)를 채우는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 객체 생성 `new`
```java
클래스이름 변수 = new 클래스이름(...);     // new로 힙에 객체를 만들고 그 주소를 변수에 저장
```
### (2) 다형성: 부모 타입 변수에 자식 객체
```java
Parent pa = new Child();     // 변수 타입은 Parent, 실제 객체는 Child (업캐스팅)
pa.show();                   // 오버라이딩된 Child.show() 실행 → "Child"
```
- 부모 타입으로 자식 객체를 가리킬 수 있다(자식은 부모의 일종).
- 메서드 호출은 **실제 객체(Child)** 의 오버라이딩된 것이 실행된다(동적 바인딩).

## 3. 풀이
`Parent pa = ____ Child();` → 객체를 생성하는 **`new`**

| 빈칸 | 정답 |
|---|---|
| `____ Child()` | **new** |

실행 결과: `pa.show()` → `Child.show()` → **Child** 출력

> **정답: `new`**

## 4. 암기 포인트
- `부모타입 변수 = new 자식타입();` = 다형성(업캐스팅).
- 호출되는 오버라이딩 메서드는 **실제 객체 기준**.
