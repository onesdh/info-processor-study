# 문제 13

## 문제

다음 설명 중 빈칸에 들어갈 알맞는 용어를 작성하시오.

HTTP, HTTPS SMTP를 통해서 XML 기반의 데이터를 주고받는 프로토콜로 웹 서비스 방식에 HTTP기반의  (    ) 을/를 사용하여 송수신한다. (    ) 대신 레스트풀(RESTful) 프로토콜로 대체할 수 있다.

SOAP (Simple Object Access Protocol)

## 1. 문제에서 묻는 것
"**HTTP, HTTPS, SMTP**를 통해 **XML 기반** 데이터를 주고받는 프로토콜, 웹 서비스에서 사용, **RESTful**로 대체 가능" → 프로토콜 이름을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) SOAP (Simple Object Access Protocol)
**XML 기반**의 메시지를 **HTTP, HTTPS, SMTP 등** 위에서 주고받는 **웹 서비스 통신 프로토콜**. 서로 다른 시스템이 **표준 형식**으로 기능을 호출한다.
```text
 클라이언트 ──[ SOAP 메시지(XML) ]──▶ 서버   (요청)
 클라이언트 ◀──[ SOAP 메시지(XML) ]── 서버   (응답)
```
### (2) 웹 서비스 3요소
| 표준 | 역할 |
|---|---|
| **SOAP** | 요청·응답 **메시지 포맷/전송** |
| WSDL | 서비스 **설명서**(위치·메시지 포맷) |
| UDDI | 서비스 **등록·검색** |

### (3) SOAP vs REST
| 구분 | **SOAP** | **REST(RESTful)** |
|---|---|---|
| 형식 | **XML** | JSON, XML 등 자유 |
| 방식 | 엄격한 규격, 무겁다 | **HTTP 메서드**(GET/POST/PUT/DELETE), 가볍다 |
| 용도 | 엔터프라이즈, 보안·트랜잭션 중요 | 웹/모바일 API 주류 |

## 3. 문제 풀이
| 단서 | SOAP |
|---|---|
| HTTP, HTTPS, SMTP를 통해 **XML 기반** 데이터 송수신 | ✅ |
| 웹 서비스에서 사용, **RESTful로 대체 가능** | ✅ |

> **정답: SOAP (Simple Object Access Protocol)**
