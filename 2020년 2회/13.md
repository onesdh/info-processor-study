# 문제 13 — SOAP

## 문제

HTTP나 HTTPS 등을 통해 XML 기반 메시지를 주고받는 웹 서비스 프로토콜로 REST 방식으로 대체되기도 하는 것을 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

SOAP (Simple Object Access Protocol)

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

SOAP는 XML을 사용해 서비스 요청과 응답 메시지를 교환하는 프로토콜이다.

## 풀이

웹 서비스의 메시지 인코딩과 처리 규약을 정의한다.

## 오답 분석

REST는 자원 중심 아키텍처 스타일이며 XML 메시지 프로토콜인 SOAP와 다르다.

## 암기 포인트

XML 메시지 교환 SOAP.

</details>
