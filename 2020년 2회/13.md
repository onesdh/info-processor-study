# 문제 13

## 문제

다음 설명 중 빈칸에 들어갈 알맞는 용어를 작성하시오.

HTTP, HTTPS SMTP를 통해서 XML 기반의 데이터를 주고받는 프로토콜로 웹 서비스 방식에 HTTP기반의  (    ) 을/를 사용하여 송수신한다. (    ) 대신 레스트풀(RESTful) 프로토콜로 대체할 수 있다.

<details>
<summary><strong>정답 보기</strong></summary>

SOAP (Simple Object Access Protocol)

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

SOAP는 XML을 사용해 서비스 요청과 응답 메시지를 교환하는 프로토콜이다.

## 풀이

웹 서비스의 메시지 인코딩과 처리 규약을 정의한다.

## 오답 분석

REST는 자원 중심 아키텍처 스타일이며 XML 메시지 프로토콜인 SOAP와 다르다.

## 암기 포인트

XML 메시지 교환 SOAP.

</details>
