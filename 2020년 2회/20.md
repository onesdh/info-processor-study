소프트웨어 개발 과정에서 변경 사항을 관리하는 기법은 (     ) 기법이라고 하며, (      ) 기법을 활용한 도구로는 CVS, SVN, Git 등이 있다. 빈칸에 알맞은 용어를 쓰시오.

## 1. 문제에서 묻는 것
"소프트웨어 개발 과정에서 **변경 사항을 관리**하는 기법, CVS·SVN·Git 같은 도구" → **형상 관리**를 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 형상 관리(SCM, Software Configuration Management)
소프트웨어의 **변경 사항(소스 코드·문서)을 체계적으로 추적·관리**하는 활동. **누가·언제·무엇을** 바꿨는지 기록하고, 필요하면 **이전 버전으로 복구**한다.

### (2) 형상 관리 도구
| 도구 | 방식 | 특징 |
|---|---|---|
| **CVS** | 중앙 집중식 | 초기 도구 |
| **SVN** | 중앙 집중식 | CVS 개선 |
| **Git** | **분산** | 각자 로컬에 전체 저장소, 현재 표준 |

### (3) 형상 관리 4가지 활동
**형상 식별 → 형상 통제(변경 관리) → 형상 감사 → 형상 기록(상태 보고)**.

## 3. 문제 풀이
| 단서 | 형상 관리 |
|---|---|
| 개발 과정에서 **변경 사항을 관리**하는 기법 | ✅ |
| **CVS, SVN, Git** 등의 도구 | ✅ |

> **정답: 형상 관리 (Software Configuration Management)**
