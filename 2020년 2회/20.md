# 문제 20 — 형상 관리

## 문제

소프트웨어 개발 중 변경 사항과 버전을 관리하며 CVS, SVN, Git 등이 활용되는 기법을 쓰시오.



## 정답

형상 관리 (Configuration Management)

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

형상 관리는 소프트웨어 구성 항목의 변경과 버전, 상태를 통제하는 활동이다.

## 풀이

버전 관리 도구는 변경 이력과 협업을 지원한다.

## 오답 분석

형상 통제는 형상 관리의 하위 절차 중 하나이고 전체 기법은 형상 관리다.

## 암기 포인트

버전과 변경 이력 관리는 형상 관리.
