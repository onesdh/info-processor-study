# 문제 20

## 문제

소프트웨어 개발 과정에서 변경 사항을 관리하는 기법은 (     ) 기법이라고 하며, (      ) 기법을 활용한 도구로는 CVS, SVN, Git 등이 있다. 빈칸에 알맞은 용어를 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

형상관리

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

형상 관리는 소프트웨어 구성 항목의 변경과 버전, 상태를 통제하는 활동이다.

## 풀이

버전 관리 도구는 변경 이력과 협업을 지원한다.

## 오답 분석

형상 통제는 형상 관리의 하위 절차 중 하나이고 전체 기법은 형상 관리다.

## 암기 포인트

버전과 변경 이력 관리는 형상 관리.
