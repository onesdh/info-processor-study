한 객체의 상태가 바뀌면 그 객체에 의존하는 다른 객체들이 연락이 가고 자동으로 내용이 갱신되는 방법으로 일대 다의 의존성을 가지며 상호작용하는 객체 사이에서는 가능하면 느슨하게 결합하는 디자인을 사용해야 한다.

## 1. 문제에서 묻는 것
"**한 객체의 상태가 바뀌면 의존하는 다른 객체들에 연락이 가고 자동 갱신**, **일대다** 의존" → 패턴 이름(영문 Full-Name)을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 옵저버(Observer) 패턴 — 행위 패턴
**Subject(주제)** 의 상태가 변하면, 등록된 **모든 Observer(관찰자)** 에게 **자동으로 알림**을 보내 갱신하게 한다.
```text
 Subject ─ 상태 변경 ─▶ notify() ─▶ Observer A (update)
                                 └▶ Observer B (update)
                                 └▶ Observer C (update)
   (1 : N 관계, Subject는 Observer의 구체 클래스를 몰라도 됨 → 느슨한 결합)
```
### (2) 특징
| 특징 | 설명 |
|---|---|
| **일대다(1:N)** 의존성 | 주제 1개 – 관찰자 여러 개 |
| **느슨한 결합** | 주제와 관찰자가 서로의 구체 내용을 몰라도 상호작용 |
| **발행-구독(Pub-Sub)** | 이벤트를 발행하고 구독자가 수신 |

예) 유튜브 구독 알림, 주가 변동 시 여러 화면 갱신, GUI 이벤트 리스너.

## 3. 문제 풀이
| 단서 | Observer |
|---|---|
| 한 객체의 **상태가 바뀌면** 의존 객체들에게 **자동 갱신** | ✅ |
| **일대다** 의존성 | ✅ |
| 상호작용 객체 사이를 **느슨하게 결합** | ✅ |

> **정답: Observer Pattern (옵저버 패턴)**
