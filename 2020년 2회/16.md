# 문제 16 — UI 유효성

## 문제

사용자가 정한 목표를 정확하고 완전하게 달성할 수 있도록 하는 UI 설계 원칙을 쓰시오.

## 정답

유효성

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

유효성은 시스템이 사용자의 목적을 정확하게 달성하도록 지원하는 정도다.

## 풀이

정확한 결과와 목표 달성 여부가 핵심이다.

## 오답 분석

직관성은 이해·사용의 쉬움, 학습성은 배우기 쉬움, 유연성은 요구와 상황에 대응하는 정도다.

## 암기 포인트

목표 달성의 정확성은 유효성.
