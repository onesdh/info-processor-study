# 문제 18 — 데이터 모델링 절차

## 문제

요구사항 분석 뒤 이어지는 개념적, 논리적, 물리적 데이터 모델링 단계를 순서대로 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

개념적 데이터 모델링; 논리적 데이터 모델링; 물리적 데이터 모델링

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

데이터 모델링은 현실 세계를 추상화한 뒤 논리 구조와 실제 저장 구조로 구체화한다.

## 풀이

요구 분석 후 개념, 논리, 물리 모델링 순으로 수행한다.

## 오답 분석

순서를 바꾸지 않는다. 물리 모델은 DBMS와 저장 특성을 고려한 마지막 단계다.

## 암기 포인트

개념→논리→물리.

</details>
