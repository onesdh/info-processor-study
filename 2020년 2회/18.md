## 1. 문제에서 묻는 것
**데이터 모델링 절차**(요구사항 분석 → ? → ? → ?)에 맞게 보기를 배치하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 데이터 모델링(DB 설계) 3단계
```text
 요구사항 분석 ─▶ 개념적 데이터 모델링 ─▶ 논리적 데이터 모델링 ─▶ 물리적 데이터 모델링
```
| 단계 | 하는 일 | 산출물 |
|---|---|---|
| 요구사항 분석 | 사용자 요구 수집·분석 | 요구사항 명세 |
| **개념적 모델링** | 현실 세계를 **개체와 관계**로 추상화 (DBMS 독립) | **E-R 다이어그램** |
| **논리적 모델링** | 개념 모델을 **테이블(스키마)** 로 변환, **정규화** | 논리 스키마 |
| **물리적 모델링** | **저장 구조·인덱스·성능** 고려, 특정 DBMS에 맞춤 | 물리 스키마(테이블 정의서) |

## 3. 문제 풀이
보기: 1. 물리적 / 2. 개념적 / 3. 논리적

|---|---|---|
| (1) | 요구사항 분석 다음 | **개념적 데이터 모델링** |
| (2) | 그다음 | **논리적 데이터 모델링** |
| (3) | 마지막 | **물리적 데이터 모델링** |

> **정답: 1. 개념적 데이터 모델링 2. 논리적 데이터 모델링 3. 물리적 데이터 모델링**
