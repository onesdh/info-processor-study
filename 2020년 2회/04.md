# 문제 04

## 문제

절차보다는 사람이 중심이 되어 변화에 유연하고 신속하게 적응하면서 효율적으로 시스템을 개발할 수 있는 신속 적응적 경량 개발방법론으로, 개발 기간이 짧고 신속하며, 워터폴에 대비되는 방법론으로 최근 회사에서 각광받는 방법론은 무엇인가?

## 1. 문제에서 묻는 것
"절차보다 **사람 중심**, 변화에 **유연하고 신속하게 적응**, **경량** 개발 방법론, 워터폴과 대비" → **애자일**을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 워터폴 vs 애자일
| 구분 | **워터폴(폭포수)** | **애자일(Agile)** |
|---|---|---|
| 진행 | **순차적**(요구 → 설계 → 구현 → 테스트 → 배포) | **짧은 반복(스프린트)** 으로 점진적 개발 |
| 변경 | 초기 요구 **고정**, 변경 어려움 | **변화 수용**, 계속 피드백 반영 |
| 문서/절차 | **절차·문서** 중심 | **사람·협업·동작하는 소프트웨어** 중심 |
| 고객 참여 | 인도 시점 | **개발 내내** 참여 |

```text
 워터폴:  요구 ─▶ 설계 ─▶ 구현 ─▶ 테스트 ─▶ 배포            (한 번에 쭉)
 애자일:  [계획─구현─테스트─피드백]×N 번 반복 (짧은 주기)    (조금씩 자주 배포)
```
### (2) 애자일 선언(핵심 가치)
- **프로세스·도구**보다 **개인과 상호작용**
- **포괄적 문서**보다 **동작하는 소프트웨어**
- **계약 협상**보다 **고객과의 협력**
- **계획을 따르기**보다 **변화에 대응**

### (3) 대표 방법론
**스크럼(Scrum)**, XP(eXtreme Programming), 칸반(Kanban).

## 3. 문제 풀이
| 단서 | 애자일 |
|---|---|
| **사람 중심**, 변화에 **유연·신속**하게 적응 | ✅ |
| **경량** 개발 방법론, 개발 기간이 짧음 | ✅ |
| **워터폴에 대비**되는 방법론 | ✅ |

> **정답: 애자일 방법론 (Agile)**
