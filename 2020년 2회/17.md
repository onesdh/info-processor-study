# 문제 17

## 문제

전 세계 오픈된 정보를 하나로 묶는 방식으로 link data와 open data의 합성어가 무엇인지 쓰시오.

<summary><strong>정답 보기</strong></summary>

LOD (Linked Open Data)

</details>

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
"전 세계에 **오픈된 정보를 하나로 묶는** 방식, **link data**와 **open data**의 합성어" → 용어를 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) LOD (Linked Open Data, 연결된 개방형 데이터)
| 요소 | 의미 |
|---|---|
| **Open Data** | 누구나 **자유롭게 이용**할 수 있도록 공개된 데이터 |
| **Linked Data** | 데이터를 **URI(주소)와 링크**로 서로 **연결**해 의미를 이해할 수 있게 한 데이터 |
| **LOD** | 위 둘을 합친 것: **개방된 데이터를 서로 연결**해 전 세계 데이터를 하나의 거대한 **데이터 웹**으로 만드는 방식 |

```text
 [서울시 데이터] ──링크── [국토부 데이터] ──링크── [위키데이터] ...   (서로 연결되어 활용·검색 가능)
```
- **시맨틱 웹**(의미를 이해하는 웹)의 실현 기술 중 하나. RDF, URI 등을 사용.

## 3. 문제 풀이
| 단서 | LOD |
|---|---|
| 전 세계 오픈된 정보를 하나로 묶는 방식 | ✅ |
| **link data + open data**의 합성어 | ✅ |

> **정답: LOD (Linked Open Data)**
