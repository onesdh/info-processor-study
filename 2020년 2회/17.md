# 문제 17

## 문제

전 세계 오픈된 정보를 하나로 묶는 방식으로 link data와 open data의 합성어가 무엇인지 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

LOD (Linked Open Data)

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

LOD는 웹 표준으로 데이터를 공개하고 다른 데이터와 연결해 재사용할 수 있게 하는 방식이다.

## 풀이

데이터 간 URI 링크와 공개 라이선스 등을 활용해 웹상의 데이터 집합을 연결한다.

## 오답 분석

일반 오픈 데이터는 공개만 의미할 수 있고 LOD는 데이터 연결을 강조한다.

## 암기 포인트

연결된 공개 데이터는 LOD.
