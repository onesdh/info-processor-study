# 문제 03

## 문제

브라우저가 가지고 있는 XMLHttpRequest 객체를 이용해서 전체 페이지를 새로 고치지 않고도 페이지의 일부분만을 위한 데이터를 로드하는 기법이며, 하이퍼텍스트 표기 언어(HTML)만으로 어려운 다양한 작업을 웹 페이지에서 구현해 이용자가 웹 페이지와 자유롭게 상호작용할 수 있도록 하는 기술명을 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

비동기 통신 기법 or AJAX(Asynchronous JavaScript and XML)

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

AJAX는 브라우저와 서버가 비동기 통신해 페이지 일부를 갱신하는 기술 방식이다.

## 풀이

전체 페이지를 새로 읽지 않고 필요한 데이터만 요청해 동적으로 화면을 바꾼다.

## 오답 분석

XML은 데이터 표현 형식이고 XMLHttpRequest는 브라우저 API다. 문항이 묻는 기법은 AJAX다.

## 암기 포인트

페이지 일부 비동기 갱신은 AJAX.

</details>
