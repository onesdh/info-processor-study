# 문제 03 — AJAX

## 문제

XMLHttpRequest로 전체 페이지를 새로고침하지 않고 일부 데이터를 비동기로 주고받는 웹 기술을 쓰시오.

## 정답

AJAX (Asynchronous JavaScript and XML)

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

AJAX는 브라우저와 서버가 비동기 통신해 페이지 일부를 갱신하는 기술 방식이다.

## 풀이

전체 페이지를 새로 읽지 않고 필요한 데이터만 요청해 동적으로 화면을 바꾼다.

## 오답 분석

XML은 데이터 표현 형식이고 XMLHttpRequest는 브라우저 API다. 문항이 묻는 기법은 AJAX다.

## 암기 포인트

페이지 일부 비동기 갱신은 AJAX.
