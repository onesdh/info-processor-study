# 문제 12 — SQL 인덱스 생성

## 문제

학생 테이블의 NAME 열에 IDX_NAME이라는 이름으로 인덱스를 생성하는 SQL을 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

CREATE INDEX IDX_NAME ON 학생(NAME);

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

인덱스는 검색 속도를 높이기 위해 열 값과 행 위치를 연결해 관리한다.

## 풀이

CREATE INDEX 인덱스명 ON 테이블명(컬럼명) 문법을 적용한다.

## 오답 분석

CREATE TABLE은 새 테이블 정의이며 인덱스 생성은 CREATE INDEX다.

## 암기 포인트

인덱스 생성은 CREATE INDEX.

</details>
