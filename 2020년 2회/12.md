# 문제 12

## 문제

학생 테이블의 name속성에 IDX\_NAME 이름으로 인덱스 생성하는 SQL문을 작성하시오.

| STID | NAME | SCORE | DEPTID |
|---|---|---|---|
| 1000 | 김이름 | 90 | 1 |
| 2000 | 허이름 | 95 | 2 |
| 3000 | 조이름 | 90 | 3 |
| 4000 | 장이름 | 95 | 4 |

<details>
<summary><strong>정답 보기</strong></summary>

CREATE INDEX IDX\_NAME ON 학생(NAME);

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
학생 테이블의 `NAME` 속성에 **`IDX_NAME`이라는 이름의 인덱스를 생성**하는 SQL을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 인덱스(Index)
책의 **색인(찾아보기)** 처럼, **특정 열의 값 → 행 위치**를 빠르게 찾게 해 주는 자료구조다. **검색 속도를 높이는** 대신 저장 공간과 쓰기(삽입·수정) 비용이 늘어난다.
```text
 인덱스(NAME → 위치)         테이블
 ┌─────────┬──────┐          ┌──────┬────────┐
 │ 김이름   │ ─────┼────────▶ │ 1000 │ 김이름  │
 │ 장이름   │ ─────┼────────▶ │ 4000 │ 장이름  │
 └─────────┴──────┘          └──────┴────────┘
```
### (2) 인덱스 생성/삭제 문법
```sql
CREATE [UNIQUE] INDEX 인덱스이름 ON 테이블명 (열이름 [, 열이름...]);
DROP INDEX 인덱스이름;
```
| 부분 | 의미 |
|---|---|
| `CREATE INDEX 이름` | 인덱스 생성 |
| `ON 테이블(열)` | **어느 테이블의 어느 열**에 만들지 |
| `UNIQUE` | 중복 값을 허용하지 않는 유일 인덱스(선택) |

## 3. 풀이
- 인덱스 이름: `IDX_NAME`
- 대상: `학생` 테이블의 `NAME` 속성

```sql
CREATE INDEX IDX_NAME ON 학생 (NAME);
```
> **정답: `CREATE INDEX IDX_NAME ON 학생(NAME);`**

## 4. 암기 포인트
- `CREATE INDEX 이름 ON 테이블(열)`.
- 인덱스는 **조회가 많고 값의 분포가 다양한 열**에 만드는 것이 효과적.
