# 문제 09

## 문제

애플리케이션을 실행하지 않고 소스 코드의 표준, 복잡도, 잠재 결함을 찾아내는 분석 도구를 쓰시오.

## 핵심 개념

정적 분석은 코드를 실행하지 않은 채 구조와 규칙을 분석한다.

## 풀이

코딩 규칙 위반과 복잡도, 일부 결함을 개발 중에 찾아낸다.

## 오답 분석

동적 분석은 프로그램을 실행해 메모리 누수나 실제 동작 문제를 확인한다.

## 암기 포인트

실행 없이 분석하면 정적 분석.
