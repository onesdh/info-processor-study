# 문제 08

## 문제

무결성과 인증을 보장하는 인증해더(AH)와 기밀성을 보장하는 암호화(ESP)를 이용한 프로토콜로 네트워크 계층(Network Layer)인 인터넷 프로토콜(IP)에 보안성을 제공해주는 표준화된 기술에 대해 쓰시오.

<summary><strong>정답 보기</strong></summary>

IPSec(Internet Protocol Security)

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
"**인증 헤더(AH)** 와 **암호화(ESP)** 를 이용해 **IP 계층(네트워크 계층)** 에 보안을 제공" → 프로토콜 이름을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) IPsec (Internet Protocol Security)
**IP 계층(3계층)에서 패킷을 암호화·인증**해 모든 IP 통신을 보호하는 **보안 프로토콜 표준**. VPN 구현에 많이 사용된다.

### (2) 두 가지 보안 프로토콜
| 프로토콜 | 이름 | 기능 |
|---|---|---|
| **AH** | Authentication Header | **무결성 + 인증** (암호화는 ✕) |
| **ESP** | Encapsulating Security Payload | **기밀성(암호화)** + 인증 + 무결성 |

### (3) 동작 모드
| 모드 | 보호 범위 |
|---|---|
| 전송(Transport) | **데이터 부분만** 보호 (호스트↔호스트) |
| 터널(Tunnel) | **패킷 전체**를 감싸 보호 (VPN 게이트웨이 간) |

### (4) 계층별 보안 프로토콜
| 계층 | 프로토콜 |
|---|---|
| 2 | L2TP, PPTP |
| **3** | **IPsec** |
| 4~7 | SSL/TLS, SSH |

## 3. 문제 풀이
| 단서 | IPsec |
|---|---|
| **무결성·인증(AH)** + **기밀성 암호화(ESP)** | ✅ |
| **네트워크 계층(IP)** 에 보안성 제공 | ✅ |

> **정답: IPSec (Internet Protocol Security)**
