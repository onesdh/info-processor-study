# 문제 08

## 문제

AH와 ESP를 이용해 IP 계층에서 인증·무결성 및 기밀성을 제공하는 표준 보안 기술을 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

IPSec (Internet Protocol Security)

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

IPSec은 IP 통신을 보호하기 위한 네트워크 계층 보안 프로토콜 집합이다.

## 풀이

AH는 데이터 출처 인증과 무결성, ESP는 기밀성과 선택적 인증을 제공한다.

## 오답 분석

TLS는 주로 전송 응용 사이에서 사용되며 IP 계층 보호는 IPSec이다.

## 암기 포인트

IP 계층 보안은 IPSec.

</details>
