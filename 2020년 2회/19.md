# 문제 19 — Java 상속 생성자

## 문제

B 객체를 만들며 B 생성자가 super(a)를 호출해 A의 display를 실행한다. B(10)의 출력값을 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

a = 10

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

하위 클래스 생성자는 super를 통해 상위 클래스 생성자를 호출하고, 상위 인스턴스 필드를 초기화할 수 있다.

## 풀이

A의 필드 a가 10으로 초기화된 뒤 display가 실행되어 해당 값이 출력된다.

## 오답 분석

오버라이딩된 메서드 호출이 아니라 생성자에서 상위 클래스 구현을 직접 호출한다.

## 암기 포인트

super(a)로 초기화한 a를 출력.
