# 문제 19

## 문제

다음은 자바 코드이다. 출력 결과를 쓰시오.

```
class A{
	private int a;
    public A(int a){
    	this.a = a;
    }
    public void display(){
    	system.out.println("a=" + a);
    }
}

class B extends A {
	public B(int a){
    	super(a);
        super.display();
    }
}


public class good {
	public static void main(String[] args){
    	B obj = new B(10);
    }
}

```

<details>
<summary><strong>정답 보기</strong></summary>

a = 10

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

하위 클래스 생성자는 super를 통해 상위 클래스 생성자를 호출하고, 상위 인스턴스 필드를 초기화할 수 있다.

## 풀이

A의 필드 a가 10으로 초기화된 뒤 display가 실행되어 해당 값이 출력된다.

## 오답 분석

오버라이딩된 메서드 호출이 아니라 생성자에서 상위 클래스 구현을 직접 호출한다.

## 암기 포인트

super(a)로 초기화한 a를 출력.
