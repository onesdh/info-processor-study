# 문제 19

## 문제

다음은 자바 코드이다. 출력 결과를 쓰시오.

```
class A{
	private int a;
    public A(int a){
    	this.a = a;
    }
    public void display(){
    	system.out.println("a=" + a);
    }
}

class B extends A {
	public B(int a){
    	super(a);
        super.display();
    }
}


public class good {
	public static void main(String[] args){
    	B obj = new B(10);
    }
}

```

<summary><strong>정답 보기</strong></summary>

a = 10

</details>

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**자식 생성자에서 `super(a)`로 부모 생성자를 호출하고 `super.display()`로 부모 메서드를 호출**하는 코드의 출력을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 객체 생성 시 생성자 호출 순서
`new B(10)` →
1. `B(int a)` 진입
2. 첫 줄 **`super(a)`** → **부모 생성자 `A(10)`** 실행 → `this.a = 10`
3. 이어서 `super.display()` → **부모 클래스 A의 `display()`** 호출 → `"a=" + a`

### (2) private 필드
`private int a`는 A 안에서만 접근 가능하다. 자식 B는 직접 못 쓰지만, **부모의 메서드(`display`)를 통해** 값을 볼 수 있다.

## 3. 실행 과정
| 단계 | 실행 | 결과 |
|---|---|---|
| ① | `new B(10)` → `B(10)` 시작 | |
| ② | `super(10)` → `A(10)`: `this.a = 10` | A의 a = 10 |
| ③ | `super.display()` | `"a=" + 10` 출력 |

출력: `a=10` (`println`이라 줄바꿈 포함)

> **정답: `a=10`**
> (원문 정답은 `a = 10`으로 공백이 있으나, 코드 `"a=" + a` 기준 출력은 `a=10`)

## 4. 암기 포인트
- 자식 생성자에서 `super(...)`는 **첫 줄**, 부모 생성자가 먼저 실행된다.
- `super.메서드()`는 **부모 클래스의 메서드**를 호출한다.
