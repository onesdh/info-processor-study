# 문제 11 — Android

## 문제

Linux 기반의 휴대용 장치용 운영체제 소프트웨어 스택으로 Java와 Kotlin 앱 실행 환경을 제공하는 운영체제를 쓰시오.

## 정답

Android

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

Android는 Linux 커널 기반의 모바일 플랫폼과 응용 실행 환경을 제공한다.

## 풀이

운영체제, 미들웨어, UI, 응용 프레임워크와 런타임을 포함한다.

## 오답 분석

Java나 Kotlin은 앱 작성 언어이지 운영체제 이름이 아니다.

## 암기 포인트

모바일 Linux 기반 운영체제는 Android.
