# 문제 11

## 문제

Linux 운영체제 위에서 구동하며 휴대폰 전화를 비롯한 휴대용 장치를 위한 운영체제와 미들웨어, 사용자 인터페이스 그리고 표준 응용프로그램(웹 브라우저 등) 등을 포함하고 있는 소프트웨어 스택이자 리눅스 모바일 운영체제로 개발자들이 자바와 코틀린 언어로 응용 프로그램을 작성할 수 있게 했고, 컴파일 된 바이트 코드를 구동할 수 있는 런타임 라이브러리를 제공하는 운영체제는 무언인지 쓰시오.

## 1. 문제에서 묻는 것
"**Linux 기반** 모바일 운영체제 + 미들웨어·UI·표준 응용 프로그램을 포함한 소프트웨어 스택, **자바·코틀린**으로 앱 작성, 바이트코드 구동" → 운영체제 이름을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 안드로이드(Android)
**Linux 커널 위에서 동작**하는 **오픈 소스 모바일 운영체제(소프트웨어 스택)** 이다. 구글이 주도해 개발했다.

### (2) 소프트웨어 스택 구조
```text
 ┌─────────────────────────────────┐
 │ 애플리케이션 (전화, 웹 브라우저 등)   │   ← 표준 응용 프로그램
 ├─────────────────────────────────┤
 │ 애플리케이션 프레임워크              │   ← 사용자 인터페이스 API
 ├─────────────────────────────────┤
 │ 라이브러리 + 안드로이드 런타임(ART/Dalvik) │ ← 컴파일된 바이트코드를 구동하는 가상 머신
 ├─────────────────────────────────┤
 │ 리눅스 커널                        │   ← 하드웨어 추상화·드라이버
 └─────────────────────────────────┘
```
| 특징 | 설명 |
|---|---|
| **리눅스 기반** | 커널이 Linux |
| **개발 언어** | **자바, 코틀린** (과거 Java 중심, 현재 Kotlin 권장) |
| **런타임** | 컴파일된 **바이트코드**를 구동하는 가상 머신(Dalvik → ART) |
| **오픈 소스** | AOSP |

### (3) 비교: iOS(애플), 안드로이드(구글).

## 3. 문제 풀이
| 단서 | 안드로이드 |
|---|---|
| **Linux 위**에서 구동하는 **모바일 운영체제**, 미들웨어·UI·표준 응용 프로그램 포함 | ✅ |
| **자바·코틀린**으로 앱 개발, 컴파일된 **바이트코드** 구동 | ✅ |

> **정답: 안드로이드 (Android)**
