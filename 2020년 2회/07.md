# 문제 07

## 문제

트랜잭션 Rollback에 대해 설명하시오.

<details>
<summary><strong>정답 보기</strong></summary>

트랜잭션 처리 중 오류가 발생했을 때, 오류 이전의 특징 시점(SAVEPOINT, CHECKPOINT) 상태로 되돌려주는 제어어(명령문)이다.

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**트랜잭션의 ROLLBACK**이 무엇인지 설명하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 트랜잭션과 TCL
**트랜잭션**은 "모두 성공하거나 모두 취소"되어야 하는 **작업 단위**. 이를 제어하는 명령을 **TCL(Transaction Control Language)** 이라 한다.
| 명령 | 기능 |
|---|---|
| **COMMIT** | 트랜잭션 변경 사항을 **영구 반영(확정)** |
| **ROLLBACK** | 트랜잭션 처리 중 **오류가 발생**했을 때 **이전 상태로 되돌림(취소)** |
| **SAVEPOINT** | 롤백할 **중간 지점**을 지정 |

### (2) 동작
```text
 [시작] ── UPDATE ─ UPDATE ─ [SAVEPOINT A] ─ UPDATE ─✖(오류)
                                      ROLLBACK TO A → SAVEPOINT A 시점 상태로 되돌림
                                      ROLLBACK     → 트랜잭션 시작 전 상태로 되돌림
```
### (3) 예: 계좌 이체
출금 성공 후 입금에서 오류 → **ROLLBACK**으로 출금까지 취소 → 돈이 사라지지 않음(**원자성** 보장).

## 3. 서술 답안
> **ROLLBACK: 트랜잭션 처리 중 오류가 발생했을 때, 오류 이전의 특정 시점(SAVEPOINT, 또는 트랜잭션 시작)의 상태로 되돌려 주는 제어어(명령문).**

## 4. 암기 포인트
- COMMIT = 확정, ROLLBACK = 취소(되돌림), SAVEPOINT = 중간 지점.

</details>
