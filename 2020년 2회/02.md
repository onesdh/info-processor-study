# 문제 02

## 문제

다음은 파이썬 코드이다. 출력 결과를 쓰시오.

```
a={'일본','중국','한국'}
a.add('베트남')
a.add('중국')
a.remove('일본')
a.update(['홍콩','한국','태국'])
print(a)
```

<details>
<summary><strong>정답 보기</strong></summary>

{'중국','한국','베트남','홍콩','태국'}

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

집합은 중복을 허용하지 않고 원소 순서를 보장하지 않는 자료형이다.

## 풀이

중복 추가한 중국과 한국은 한 번만 남고 일본은 삭제되며 새 원소들이 들어간다. 출력 순서는 실행 환경에 따라 달라질 수 있다.

## 오답 분석

집합의 출력 순서를 고정 순서로 예상하지 않는다. remove는 해당 원소를 제거한다.

## 암기 포인트

집합은 중복 없음, 순서 없음.
