# 문제 02

## 문제

다음은 파이썬 코드이다. 출력 결과를 쓰시오.

```
a={'일본','중국','한국'}
a.add('베트남')
a.add('중국')
a.remove('일본')
a.update(['홍콩','한국','태국'])
print(a)
```

<details>
<summary><strong>정답 보기</strong></summary>

{'중국','한국','베트남','홍콩','태국'}

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
파이썬 **집합(set)** 의 `add`, `remove`, `update` 동작과 **중복 제거**를 이해했는지 묻는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 집합(set)
| 특징 | 설명 |
|---|---|
| **중복 불가** | 같은 값은 **하나만** 유지 |
| **순서 없음** | 출력 순서가 일정하지 않을 수 있음 |

### (2) 메서드
| 메서드 | 동작 |
|---|---|
| `add(x)` | 원소 하나 추가 (이미 있으면 변화 없음) |
| `remove(x)` | 원소 삭제 |
| `update(iterable)` | 여러 원소를 **한꺼번에 추가** (합집합) |

## 3. 실행 과정
| 단계 | 코드 | 집합 |
|---|---|---|
| 시작 | `{'일본','중국','한국'}` | 일본, 중국, 한국 |
| ① | `add('베트남')` | 일본, 중국, 한국, **베트남** |
| ② | `add('중국')` | 이미 있음 → **변화 없음** |
| ③ | `remove('일본')` | 중국, 한국, 베트남 |
| ④ | `update(['홍콩','한국','태국'])` | 한국(이미 있음), **홍콩, 태국** 추가 |

최종: `{'중국', '한국', '베트남', '홍콩', '태국'}` (5개, **출력 순서는 달라질 수 있음**)

> **정답: `{'중국','한국','베트남','홍콩','태국'}`** (순서 무관)

## 4. 암기 포인트
- 집합은 **중복 제거 + 순서 없음**.
- 2023년 1회 15번과 같은 문제.
