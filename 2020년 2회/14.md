# 문제 14

## 문제

SQL Injection이 무엇인지 서술하시오.

<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**SQL Injection**이 무엇인지 서술하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) SQL Injection
웹 애플리케이션이 **사용자 입력값을 검증하지 않고** SQL 문에 그대로 넣을 때, 공격자가 **악의적인 SQL 구문을 끼워 넣어(Inject)** 실행시키는 공격이다. 인증 우회, **정보 탈취**, 데이터 **조작·삭제** 등이 가능하다.

### (2) 동작 예
```text
 로그인 SQL(취약):  SELECT * FROM users WHERE id = '[입력1]' AND pw = '[입력2]'

 공격자 입력1 = admin' --        (--는 이후를 주석 처리)
 실제 실행: SELECT * FROM users WHERE id = 'admin' --' AND pw = '...'
            → 비밀번호 검사가 주석 처리되어 admin으로 로그인 성공!
```
또 다른 예: `' OR '1'='1` 입력 → 조건이 항상 참이 되어 모든 행 조회.

### (3) 대응 방법
| 방법 | 설명 |
|---|---|
| **준비된 문장(Prepared Statement)** | 입력값을 **데이터로만** 바인딩(SQL로 해석 안 됨) |
| 입력값 검증·이스케이프 | 특수문자(`'`, `--`, `;`) 필터링 |
| **최소 권한** | DB 계정에 필요한 권한만 부여 |
| 에러 메시지 숨김 | 내부 정보 노출 방지 |
| WAF | 웹 방화벽 |

## 3. 서술 답안
> **SQL Injection: 응용 프로그램의 보안 취약점(입력값 검증 부재)을 이용해 악의적인 SQL 구문을 삽입·실행시켜, 데이터베이스에 접근하여 정보를 탈취하거나 조작하는 공격 기법.**
