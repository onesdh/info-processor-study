# 문제 14

## 문제

응용 프로그램 입력 취약점을 이용해 악의적인 SQL 구문을 삽입·실행하여 데이터베이스 정보를 탈취하거나 조작하는 공격을 설명하시오.

<details>
<summary><strong>정답 보기</strong></summary>

입력값에 악성 SQL을 삽입해 의도치 않은 데이터베이스 작업을 수행시키는 공격

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

입력 검증이나 매개변수화가 미흡할 때 공격자가 SQL 구문 일부를 실행시킬 수 있다.

## 풀이

사용자 입력을 SQL 문자열에 직접 연결하지 않고 바인드 변수를 사용해야 한다.

## 오답 분석

XSS는 브라우저에서 악성 스크립트를 실행시키는 공격이고, SQL Injection은 데이터베이스 쿼리를 겨냥한다.

## 암기 포인트

SQL 입력값을 쿼리에 주입하는 공격.

</details>
