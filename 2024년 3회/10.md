# 문제 10

## 문제

다음은 파이썬에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
def func(value):
    if type(value) == type(100):
        return 100
    elif type(value) == type(""):
        return len(value)
    else:
        return 20


a = '100.0'
b = 100.0
c = (100, 200)

print(func(a) + func(b) + func(c))

```

<details>
<summary><strong>정답 보기</strong></summary>

45

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

type(x)==type(100)은 정수형만 참이고, 문자열 분기는 문자열 길이를 반환한다.

## 풀이

'100.0'은 길이 5인 문자열이므로 5, 100.0은 float라 int 비교도 str 비교도 아니어서 20, (100,200)은 tuple이므로 20이다. 합계는 5+20+20=45다.

## 오답 분석

실수 100.0은 값이 100과 비슷해도 int가 아니다. 튜플도 세 번째 else 분기로 들어간다.

## 암기 포인트

자료형 검사는 값이 아니라 형을 비교.
