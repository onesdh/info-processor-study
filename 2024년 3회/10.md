# 문제 10

## 문제

다음은 파이썬에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
def func(value):
    if type(value) == type(100):
        return 100
    elif type(value) == type(""):
        return len(value)
    else:
        return 20


a = '100.0'
b = 100.0
c = (100, 200)

print(func(a) + func(b) + func(c))

```

<details>
<summary><strong>정답 보기</strong></summary>

45

</details>

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
파이썬의 **`type()` 비교**로 자료형을 구분하는 함수에 `str`, `float`, `tuple`을 넣었을 때의 반환값 합을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) type()
값의 **자료형**을 돌려준다.
| 값 | `type(...)` |
|---|---|
| `100` | `int` |
| `""` , `'100.0'` | `str` |
| `100.0` | **`float`** (소수점이 있으면 float) |
| `(100, 200)` | `tuple` |

### (2) 함수 분기
```python
def func(value):
    if type(value) == type(100):        # int 이면
        return 100
    elif type(value) == type(""):       # str 이면
        return len(value)               # 문자열 길이
    else:                               # 그 밖에는
        return 20
```
## 3. 실행 과정
| 호출 | 값 | 자료형 | 분기 | 반환 |
|---|---|---|---|---:|
| `func(a)` | `'100.0'` | **str** (따옴표 있음) | 문자열 → `len('100.0')` | **5** (`1,0,0,.,0`) |
| `func(b)` | `100.0` | **float** | int도 str도 아님 → else | **20** |
| `func(c)` | `(100, 200)` | **tuple** | else | **20** |

`5 + 20 + 20` = **45**

> **정답: `45`**

## 4. 암기 포인트
- `'100.0'`은 숫자처럼 보여도 **문자열**이다. 길이는 점(`.`)까지 5글자.
- `100.0`은 **float**이라 `type(100)`(int)와 다르다.
