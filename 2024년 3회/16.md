# 문제 16

## 문제

다음은 C언어에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
#include <stdio.h>

void func(int** arr, int size){
  for(int i=0; i<size; i++){
     *(*arr + i) = (*(*arr+i) + i) % size;
  }
}

int main(){
  int arr[] = {3,1, 4, 1, 5};
  int* p = arr;
  int** pp = &p;
  int num = 6;

  func(pp, 5);
  num = arr[2];
  printf("%d", num);

  return 0;
}
```

## 1. 문제에서 묻는 것
**이중 포인터**를 통해 배열 원소를 수정하는 함수 호출 후, `arr[2]`의 값을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 포인터와 이중 포인터
```text
 arr ─▶ [3][1][4][1][5]
         ▲
 p  ────┘          (p는 arr의 첫 원소를 가리킴)
 pp ───▶ p         (pp는 p의 주소를 가리킴: int** pp = &p)
```
| 표현 | 의미 |
|---|---|
| `*pp` | `p` (= `arr`의 시작 주소) |
| `*pp + i` | 시작 주소에서 **i칸 뒤** 주소 |
| `*(*pp + i)` | 그 칸의 **값** = `arr[i]` |

즉 `*(*arr + i)` ≡ `arr[i]` (함수 안에서 매개변수 이름은 `arr`이지만 `int**`).

### (2) 수식
`arr[i] = (arr[i] + i) % size;`  (size = 5)

## 3. 실행 과정 (`arr = {3, 1, 4, 1, 5}`)
| i | 계산 `(arr[i] + i) % 5` | 새 arr[i] | 배열 |
|---:|---|---:|---|
| 0 | (3 + 0) % 5 | 3 | 3, 1, 4, 1, 5 |
| 1 | (1 + 1) % 5 | 2 | 3, **2**, 4, 1, 5 |
| 2 | (4 + 2) % 5 = 6 % 5 | **1** | 3, 2, **1**, 1, 5 |
| 3 | (1 + 3) % 5 | 4 | 3, 2, 1, **4**, 5 |
| 4 | (5 + 4) % 5 = 9 % 5 | 4 | 3, 2, 1, 4, **4** |

`num = arr[2]` = **1**

> **정답: `1`**

## 4. 암기 포인트
- `*(*arr + i)` 는 `arr[i]`와 같다 → 이중 포인터를 풀어 읽는다.
- 함수에서 이중 포인터로 접근해도 **원본 배열이 수정**된다.
