# 문제 01

## 문제

다음은 Java 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
public class Main{
  static String[] s = new String[3];

  static void func(String[]s, int size){
    for(int i=1; i<size; i++){
      if(s[i-1].equals(s[i])){
        System.out.print("O");
      }else{
        System.out.print("N");
      }
    }
      for (String m : s){
        System.out.print(m);
      }
    }


  public static void main(String[] args){
    s[0] = "A";
    s[1] = "A";
    s[2] = new String("A");

    func(s, 3);
  }
}
```

## 1. 문제에서 묻는 것
Java 문자열 비교에서 `equals()`가 **내용 비교**임을 이해하고, 배열을 순회하며 출력되는 결과를 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) String 비교: `==` vs `equals()`
| 비교 | 의미 |
|---|---|
| `==` | **같은 객체(같은 주소)** 인가 |
| `equals()` | **문자열 내용**이 같은가 |

```java
s[1] = "A";              // 문자열 리터럴 풀의 "A"
s[2] = new String("A");  // 힙에 새로 만든 별개의 객체 (내용은 같음)
```
`s[1] == s[2]` → **false**(주소 다름), `s[1].equals(s[2])` → **true**(내용 같음).
이 문제는 `equals()`를 쓰므로 객체가 달라도 내용만 같으면 **참**이다.

### (2) 향상된 for문
`for (String m : s)` → 배열 s의 원소를 **처음부터 끝까지 하나씩** m에 꺼내어 반복.

## 3. 실행 과정
`func(s, 3)`, 배열 `s = ["A", "A", "A"]`

**① 첫 번째 for (i = 1, 2)**
| i | s[i-1] | s[i] | `equals` | 출력 |
|---:|---|---|:---:|---|
| 1 | "A" | "A" | true | `O` |
| 2 | "A" | "A"(new String) | true | `O` |

**② 두 번째 for-each**: `A`, `A`, `A` 차례로 출력 → `AAA`

> **정답: `OOAAA`**

## 4. 암기 포인트
- 내용 비교는 `equals()`. `new String("A") == "A"` 는 false이지만 `equals`는 true.
- `print`는 줄바꿈이 없어 모든 출력이 이어 붙는다.
