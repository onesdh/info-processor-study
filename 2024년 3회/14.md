## 1. 문제에서 묻는 것
UML **클래스 다이어그램**의 관계(연관 / 일반화 / 의존)를 **선의 모양**으로 구분하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 클래스 다이어그램의 관계 표기
| 관계 | 선 모양 | 의미 | 예 |
|---|---|---|---|
| **연관(Association)** | **실선** (화살표 없음 또는 열린 화살표) | 클래스 간 **지속적인 관계**(전체-부분, 소유 등) | 차 — 타이어/바퀴/엔진 |
| **일반화(Generalization)** | **실선 + 속이 빈 삼각형 화살표**, 자식 → 부모 | **상속**(is-a) | 버스·택시·승용차 → 차 |
| **의존(Dependency)** | **점선 + 열린 화살표** | **일시적 사용**(매개변수, 지역 변수) | 텔레비전 ┄▶ 리모컨 |
| 실체화(Realization) | 점선 + 속이 빈 삼각형 | 인터페이스 구현 | |
| 집약/합성 | 마름모 | 전체-부분(약/강) | |

### (2) 의존 vs 연관
- **연관**: 멤버 변수로 **계속 가지고 있는** 관계(오래 유지)
- **의존**: 메서드 안에서 **잠깐 사용하는** 관계(연관보다 약함)

## 3. 문제 풀이 (그림)
```text
 (1)       차                 실선으로 연결
        /  |  \               → 차는 타이어·바퀴·엔진을 "가진다"
    타이어 바퀴 엔진            ⇒ 연관(전체-부분)

 (2)       차 ◁──────────      속 빈 삼각형 화살표, 자식 → 부모
        ▲   ▲   ▲            → 버스·택시·승용차는 차의 일종 (상속)
      버스  택시 승용차          ⇒ 일반화

 (3) 텔레비전 ┄┄┄┄▶ 리모콘      점선 + 화살표
                              → 텔레비전이 리모콘을 사용(일시적)  ⇒ 의존
```
| 그림 | 선 모양 | 관계 |
|---|---|---|
| (1) 차-타이어/바퀴/엔진 | 실선 | **ㄴ. 연관** |
| (2) 버스/택시/승용차 → 차 | 속 빈 삼각형 화살표 | **ㄷ. 일반화** |
| (3) 텔레비전 ┄▶ 리모콘 | 점선 화살표 | **ㄱ. 의존** |

> **정답: (1) 연관 (2) 일반화 (3) 의존**

## 4. 암기 포인트
- **실선 = 연관, 속 빈 삼각형 = 일반화(상속), 점선 = 의존**.
- 상속 방향: 화살표는 **자식에서 부모**를 향한다.
