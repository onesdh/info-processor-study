# 문제 05

## 문제

다음은 네트워크 취약점에 대한 문제이다. 아래 내용을 보고 알맞는 용어를 작성하시오.

&nbsp;- IP나 ICMP의 특성을 악용하여 엄청난 양의 데이터를 한 사이트에 집중적으로 보냄으로써 네트워크의 일부를 불능 상태로 만드는 공격이다.  
&nbsp;- 여러 호스트가 특정 대상에게 다량의 ICMP Echo Reply 를 보내게 하여 서비스거부(DoS)를 유발시키는 보안공격이다.  
&nbsp;- 공격 대상 호스트는 다량으로 유입되는 패킷으로 인해 서비스 불능 상태에 빠진다.

## 1. 문제에서 묻는 것
"**여러 호스트가 ICMP Echo Reply를 대량으로 보내** 대상 호스트를 서비스 불능으로 만드는 공격" → 어떤 공격인지 묻는 문제다.

## 2. 먼저 알아야 할 개념
### (1) ICMP와 ping
**ICMP**(Internet Control Message Protocol)는 네트워크 상태/오류 알림용 프로토콜이다. `ping`은 **Echo Request**를 보내면 상대가 **Echo Reply**로 답하는 방식이다.

### (2) 스머프(Smurf) 공격 원리 (증폭 공격)
```text
 ① 공격자: 출발지 IP를 "피해자(V)"로 위조한 ICMP Echo Request를
           중간 네트워크의 **브로드캐스트 주소**로 전송
 ② 그 네트워크의 모든 호스트(수십~수백 대)가 응답(Echo Reply)을 **피해자 V에게** 전송
 ③ 피해자는 폭주하는 Reply로 네트워크·CPU가 마비 → 서비스 거부(DoS)

 공격자 ─(Src=V, Dst=브로드캐스트)─▶ [ 중간 네트워크 ]──▶ 호스트1,2,3…n
                                                │ (전부 Reply)
                                                ▼
                                           피해자 V (과부하)
```
작은 패킷 1개가 호스트 수만큼 **증폭**되는 것이 특징.

### (3) 대응
라우터에서 **브로드캐스트 지향 패킷 차단** (`no ip directed-broadcast`), 호스트가 브로드캐스트 ICMP에 응답하지 않도록 설정.

### (4) 다른 DoS 공격과 구분
| 공격 | 핵심 |
|---|---|
| **Smurf** | **ICMP + 브로드캐스트 + 출발지 위조**로 증폭 |
| SYN Flooding | SYN 대량 전송, 연결 큐 고갈 |
| Ping of Death | 비정상적으로 **큰** ICMP 패킷 |
| Land | 출발지=목적지 주소/포트로 위조 |

## 3. 문제 풀이
| 단서 | Smurf |
|---|---|
| IP·**ICMP의 특성**을 악용 | ✅ |
| 여러 호스트가 대상에게 다량의 **ICMP Echo Reply** | ✅ |
| 서비스 거부(DoS) 유발 | ✅ |

> **정답: 스머프(Smurf) 공격 (스머핑)**
