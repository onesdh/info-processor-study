# 문제 05

## 문제

다음은 네트워크 취약점에 대한 문제이다. 아래 내용을 보고 알맞는 용어를 작성하시오.

&nbsp;- IP나 ICMP의 특성을 악용하여 엄청난 양의 데이터를 한 사이트에 집중적으로 보냄으로써 네트워크의 일부를 불능 상태로 만드는 공격이다.  
&nbsp;- 여러 호스트가 특정 대상에게 다량의 ICMP Echo Reply 를 보내게 하여 서비스거부(DoS)를 유발시키는 보안공격이다.  
&nbsp;- 공격 대상 호스트는 다량으로 유입되는 패킷으로 인해 서비스 불능 상태에 빠진다.

스머프(Smurf) 또는 스머핑(Smurfing)

## 핵심 개념

IP의 브로드캐스트와 ICMP Echo 응답을 이용해 증폭 트래픽을 피해자에게 모은다.

## 풀이

공격자는 피해자 주소를 출발지로 위조한 ICMP Echo Request를 브로드캐스트 주소에 보낸다. 여러 호스트가 피해자에게 Echo Reply를 보내 대량 트래픽을 만든다.

## 오답 분석

SYN Flooding은 연결 대기 자원을 고갈시키는 공격이고 Ping of Death는 비정상적으로 큰 IP 패킷 계열이다. 다수의 ICMP 응답 증폭은 Smurf다.

## 암기 포인트

브로드캐스트 ICMP 증폭이면 Smurf.
