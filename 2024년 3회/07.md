# 문제 07

## 문제

다음은 C언어에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
#include <stdio.h>

int func(){
 static int x =0;
  x+=2;
  return x;
}

int main(){
  int x = 1;
  int sum=0;
  for(int i=0;i<4;i++) {
    x++;
    sum+=func();
  }
  printf("%d", sum);

  return 0;
}
```

<summary><strong>정답 보기</strong></summary>

20

</details>

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**지역 변수 `static`** 이 함수 호출 사이에 **값을 유지**하는 성질을 아는지 묻는 문제다. 서로 이름이 같은 `x`가 두 개 있는 점이 함정이다.

## 2. 먼저 알아야 할 개념
### (1) 지역 변수 vs static 지역 변수
| 구분 | 일반 지역 변수 | **static 지역 변수** |
|---|---|---|
| 생성 | 함수 호출 때마다 새로 생성 | **프로그램 시작 시 한 번만** 생성·초기화 |
| 값 유지 | 함수가 끝나면 사라짐 | **호출 사이에도 값이 유지됨** |
| 초기화 | 호출마다 실행 | **최초 1회만** |

```c
int func(){
  static int x = 0;   // 단 한 번만 0으로 초기화
  x += 2;
  return x;
}
```
### (2) 이름이 같은 변수 `x`
- `main`의 `int x = 1;` 과 `func`의 `static int x`는 **서로 다른 변수**다(범위가 다름).
- `main`에서 `x++`를 해도 `func`의 `x`에는 영향이 없다. (이 문제에서 main의 x는 결과에 쓰이지 않음)

## 3. 실행 과정 (`for` 4회)
| 반복 | main의 x | func 호출 전 static x | `x += 2` 후 (반환) | sum |
|---:|---:|---:|---:|---:|
| 1 | 2 | 0 | **2** | 2 |
| 2 | 3 | 2 | **4** | 6 |
| 3 | 4 | 4 | **6** | 12 |
| 4 | 5 | 6 | **8** | 20 |

`sum = 2 + 4 + 6 + 8` = **20**

> **정답: `20`**

## 4. 암기 포인트
- `static int x = 0;` 초기화는 **딱 한 번**. 그래서 매 호출마다 0으로 돌아가지 않는다.
- 같은 이름의 지역 변수는 **서로 무관**.
