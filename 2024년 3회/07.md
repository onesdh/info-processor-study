# 문제 07

## 문제

다음은 C언어에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
#include <stdio.h>

int func(){
 static int x =0;
  x+=2;
  return x;
}

int main(){
  int x = 1;
  int sum=0;
  for(int i=0;i<4;i++) {
    x++;
    sum+=func();
  }
  printf("%d", sum);

  return 0;
}
```

<details>
<summary><strong>정답 보기</strong></summary>

20

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

함수 안의 static 지역변수는 호출 사이에 값을 유지한다.

## 풀이

static x는 0으로 한 번 초기화된다. 호출마다 2씩 증가하여 반환값은 2,4,6,8이고 누적 합은 20이다. main의 지역 x는 함수 내부 x와 별개다.

## 오답 분석

일반 지역변수처럼 매 호출 때 0으로 초기화되지 않는다. 반환값만 더하므로 main의 x 증가는 무관하다.

## 암기 포인트

static 지역 변수는 호출 간 값 유지.
