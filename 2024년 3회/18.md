# 문제 18

## 문제

다음은 Java 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
public class ExceptionHandling {
  public static void main(String[] args) {
      int sum = 0;
      try {
          func();
      } catch (NullPointerException e) {
          sum = sum + 1;
      } catch (Exception e) {
          sum = sum + 10;
      } finally {
          sum = sum + 100;
      }
      System.out.print(sum);
  }

  static void func() throws Exception {
      throw new NullPointerException();
  }
}
```

## 1. 문제에서 묻는 것
예외가 발생했을 때 **어떤 `catch`가 선택되고, `finally`가 어떻게 실행되는지** 추적해 `sum`을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) catch 선택 규칙
예외가 발생하면 **위에서 아래로** catch를 검사해서 **타입이 맞는 첫 번째 하나만** 실행한다.
- `NullPointerException`은 `Exception`의 **자식 클래스**다. 자식 타입 catch가 위에 있으므로 먼저 매칭된다.
- 일반적으로 **구체적인(자식) 예외를 위에, 일반적인(부모) 예외를 아래에** 둔다.

```text
 Throwable
  └ Exception
      └ RuntimeException
          └ NullPointerException
```
### (2) finally
예외 **발생 여부와 상관없이 항상** 마지막에 실행.

### (3) throws
`func() throws Exception` : 이 메서드가 예외를 던질 수 있음을 선언. 실제로는 `NullPointerException`을 던진다.

## 3. 실행 과정 (`sum = 0`)
| 단계 | 실행 | sum |
|---|---|---:|
| ① | `func()` 호출 → `throw new NullPointerException()` | 0 |
| ② | catch 검사: `NullPointerException` ✅ 일치 → `sum = sum + 1` | **1** |
| ③ | (다음 catch `Exception`은 건너뜀) | 1 |
| ④ | `finally`: `sum = sum + 100` | **101** |

`System.out.print(sum)` → **101**

> **정답: `101`**

## 4. 암기 포인트
- catch는 **하나만** 실행, finally는 **항상** 실행.
- 첫 번째 catch(NPE)가 선택되므로 두 번째(+10)는 실행되지 않는다.
