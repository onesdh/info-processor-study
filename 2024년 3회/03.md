# 문제 03

## 문제

아래의 employee테이블과 project테이블을 참고하여 보기의 SQL명령어에 알맞는 출력 값을 작성하시오.

![원문 문제 그림 1](source/정보처리기사_2024_3_Q03_01.png)

보기

```
SELECT
    count(*)
FROM employee AS e JOIN project AS p ON e.project_id = p.project_id
WHERE p.name IN (
    SELECT name FROM project p WHERE p.project_id IN (
        SELECT project_id FROM employee GROUP BY project_id HAVING count(*) < 2
    )
);
```

## 1. 문제에서 묻는 것
**중첩 서브쿼리 + JOIN + GROUP BY/HAVING** 가 결합된 SQL의 `count(*)` 결과를 구하는 문제다. 가장 안쪽 쿼리부터 풀어야 한다.

## 2. 먼저 알아야 할 개념
| 문법 | 의미 |
|---|---|
| `GROUP BY 열` | 열 값이 같은 행끼리 **그룹**으로 묶음 |
| `HAVING 조건` | **그룹에 대한 조건** (WHERE는 행, HAVING은 그룹) |
| `IN (서브쿼리)` | 서브쿼리 결과 **목록 중 하나와 같으면** 참 |
| `JOIN ... ON` | 조건이 맞는 행끼리 연결 |

### 서브쿼리는 안쪽부터
```text
 ③ 가장 바깥  : employee JOIN project … WHERE p.name IN (②의 결과)
 ② 중간       : project 중 project_id IN (①의 결과) 의 name
 ① 가장 안쪽  : employee를 project_id로 그룹화해 인원이 2명 미만인 project_id
```
## 3. 문제 데이터 (그림)
**employee**

| no | first_name | last_name | project_id |
|---:|---|---|---:|
| 1 | John | Doe | 10 |
| 2 | Jim | Carry | 20 |
| 3 | Rachel | Redmond | 10 |

**project**

| project_id | name |
|---:|---|
| 10 | Alpha |
| 20 | Beta |
| 10 | Gamma |

## 4. 풀이
**① 가장 안쪽**: `SELECT project_id FROM employee GROUP BY project_id HAVING count(*) < 2`
| project_id | 인원 | `< 2`? |
|---:|---:|:---:|
| 10 | 2 (John, Rachel) | X |
| 20 | 1 (Jim) | ✅ |
→ 결과: **{20}**

**② 중간**: `SELECT name FROM project p WHERE p.project_id IN (20)`
→ project_id가 20인 행의 name = **{Beta}**

**③ 가장 바깥**: `employee e JOIN project p ON e.project_id = p.project_id WHERE p.name IN ('Beta')`
JOIN 결과 전체:
| e.no | e.project_id | p.name | `name IN ('Beta')` |
|---:|---:|---|:---:|
| 1 (John) | 10 | Alpha | X |
| 1 (John) | 10 | Gamma | X |
| 3 (Rachel) | 10 | Alpha | X |
| 3 (Rachel) | 10 | Gamma | X |
| 2 (Jim) | 20 | **Beta** | ✅ |

→ 조건에 맞는 행은 **1개** → `count(*)` = **1**

> **정답: `1`**

## 5. 암기 포인트
- project 테이블에 `project_id=10`이 **두 번** 나오므로 JOIN하면 행이 **늘어난다**(John, Rachel 각각 2행).
- 여기서는 Beta만 걸러 최종 1행.
