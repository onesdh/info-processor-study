# 문제 12

## 문제

다음은 C언어에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
#include <stdio.h>

struct Node {
 int value;
 struct Node* next;
};

void func(struct Node* node){
  while(node != NULL && node->next != NULL){
     int t = node->value;
     node->value = node->next->value;
     node->next->value = t;
     node = node->next->next;
  }
}

int main(){
  struct Node n1 = {1, NULL};
  struct Node n2 = {2, NULL};
  struct Node n3 = {3, NULL};

  n1.next = &n3;
  n3.next = &n2;

  func(&n1);

  struct Node* current = &n1;

  while(current != NULL){
    printf("%d", current->value);
    current = current->next;
 }

 return 0;

}
```

## 1. 문제에서 묻는 것
연결 리스트를 따라가며 **인접한 두 노드의 값을 교환**한 뒤 출력되는 순서를 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 연결 리스트 구성
```c
n1.next = &n3;   n3.next = &n2;   // n2.next 는 NULL
```
**연결 순서**는 변수 이름 순서가 아니라 `next` 포인터가 정한다.
```text
 n1(1) → n3(3) → n2(2) → NULL
```
### (2) `func`: 두 개씩 짝지어 값 교환
```c
while (node != NULL && node->next != NULL) {
   swap(node->value, node->next->value);   // 현재와 다음의 값을 교환
   node = node->next->next;                // 두 칸 점프
}
```
- 노드가 **노드 자체를 바꾸는 것이 아니라 값만** 맞바꾼다.

## 3. 실행 과정
| 단계 | node | node->next | 동작 | 리스트(값) |
|---|---|---|---|---|
| 초기 | n1 | n3 | | 1 → 3 → 2 |
| 1회 | n1(1) | n3(3) | 값 교환 | **3 → 1 → 2** |
| 이동 | `node = node->next->next` = n2 | | | |
| 종료 | n2 | NULL | `node->next != NULL` 거짓 → 종료 | 3 → 1 → 2 |

**출력**: 리스트 순서대로 `3`, `1`, `2` → **312**

> **정답: `312`**

## 4. 암기 포인트
- 먼저 **next 연결 순서(1→3→2)** 를 그린다.
- 홀수 개 리스트에서는 **마지막 노드(2)는 짝이 없어** 그대로 남는다.
