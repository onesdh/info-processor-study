# 문제 12

## 문제

다음은 C언어에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
#include <stdio.h>

struct Node {
 int value;
 struct Node* next;
};

void func(struct Node* node){
  while(node != NULL && node->next != NULL){
     int t = node->value;
     node->value = node->next->value;
     node->next->value = t;
     node = node->next->next;
  }
}

int main(){
  struct Node n1 = {1, NULL};
  struct Node n2 = {2, NULL};
  struct Node n3 = {3, NULL};

  n1.next = &n3;
  n3.next = &n2;

  func(&n1);

  struct Node* current = &n1;

  while(current != NULL){
    printf("%d", current->value);
    current = current->next;
 }

 return 0;

}
```

## 핵심 개념

포인터 연결은 그대로 두고 노드의 value 필드만 한 쌍씩 교환한다.

## 풀이

첫 반복은 n1과 n3의 값을 바꿔 리스트 값을 3→1→2로 만든다. 다음 node는 두 칸 이동해 n2를 가리키고, n2 뒤에는 노드가 없으므로 종료한다. 출력은 312다.

## 오답 분석

노드 위치를 재연결하는 코드가 아니라 임시 변수 t로 값만 바꾸는 코드다.

## 암기 포인트

next가 아니라 value를 교환.
