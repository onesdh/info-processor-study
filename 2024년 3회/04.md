# 문제 04

## 문제

다음은 운영체제 페이지 순서를 참고하여 할당된 프레임의 수가 3개일 때  LRU 알고리즘의 페이지 부재 횟수를 작성하시오.

페이지 참조 순서 : 7 0 1 2 0 3 0 4 2 3 0 3 2 1 2 0 1 7 0 1

<details>
<summary><strong>정답 보기</strong></summary>

12

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

LRU는 가장 오랫동안 참조되지 않은 페이지를 교체한다.

## 풀이

각 참조마다 적중이면 최근 사용 시점을 갱신하고, 부재인데 빈 프레임이 없으면 마지막 사용 시점이 가장 오래된 페이지를 내보낸다. 이 규칙으로 전체 열을 순서대로 추적하면 12회의 부재가 발생한다.

## 오답 분석

FIFO는 먼저 들어온 페이지를 내보내지만 LRU는 최근 사용 시점을 기준으로 선택한다. 두 알고리즘의 횟수를 혼동하지 않는다.

## 암기 포인트

LRU는 가장 오래 안 쓴 페이지를 교체.
