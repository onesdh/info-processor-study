# 문제 13

## 문제

다음은 테스트 커버리지에 대한 문제이다. 아래 내용에 알맞는 답을 보기에서 골라 작성하시오.

1. 테스트를 통해 프로그램의 모든 문장을 최소한 한 번씩 실행했는지를 측정  
2. 프로그램 내의 모든 분기(조건문)의 각 분기를 최소한 한 번씩 실행했는지를 측정  
3. 복합 조건 내의 각 개별 조건이 참과 거짓으로 평가되는 경우를 모두 테스트했는지를 측정

## 1. 문제에서 묻는 것
**화이트박스 테스트 커버리지** 3가지(문장, 분기, 조건)의 정의를 보기에서 고르는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 커버리지(Coverage)
테스트가 **코드를 얼마나 실행했는가**를 재는 척도. 코드 구조(화이트박스) 기반.

### (2) 커버리지 종류 (약 → 강)
| 커버리지 | 측정 대상 | 설명 |
|---|---|---|
| **문장(구문)** | **모든 문장** | 각 문장이 **최소 1번** 실행 |
| **분기 = 결정** | **분기의 결과** | 각 `if` 등의 **참/거짓 두 방향 모두** 1번 이상 |
| **조건** | **개별 조건식** | 복합 조건(`A && B`)에서 **A, B 각각이 참/거짓** 모두 |
| 조건/결정 | 위 둘 | 결정과 조건을 **동시에** 만족 |
| 다중 조건 | 조건의 모든 조합 | 조건들의 **모든 참/거짓 조합** |
| 경로 | 모든 경로 | 가능한 **모든 실행 경로** |

### (3) 예시
```c
if (A && B) { S1; } else { S2; }
```
| 커버리지 | 필요한 테스트 |
|---|---|
| 문장 | S1과 S2가 각각 실행되는 테스트 (A,B 둘 다 참 / 거짓 하나) |
| 분기 | `(A&&B)`가 **참인 경우**와 **거짓인 경우** |
| 조건 | A가 참·거짓, B가 참·거짓 각각 한 번씩 |

## 3. 문제 풀이
| 번호 | 설명 | 정답 |
|---|---|---|
| 1 | **모든 문장**을 최소 한 번씩 실행했는지 | ㅂ. **문장** |
| 2 | **모든 분기**의 각 분기를 최소 한 번씩 | ㄹ. **분기** |
| 3 | **복합 조건 내의 각 개별 조건**이 참/거짓으로 평가 | ㄱ. **조건** |

(ㄷ 결정은 분기와 같은 의미지만, 문제 문장이 "분기(조건문)의 각 분기"라서 보기의 **분기**가 정답.)

> **정답: 1. 문장 / 2. 분기 / 3. 조건**

## 4. 암기 포인트
- **문장 < 분기(결정) < 조건/결정 < 다중 조건** 순으로 엄격.
- 분기·결정 = **전체 식**의 T/F, 조건 = **개별 식**의 T/F.
