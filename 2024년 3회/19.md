# 문제 19

## 문제

다음은 Java 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
class Main {

  public static class Collection<T>{
    T value;

    public Collection(T t){
        value = t;
    }

    public void print(){
       new Printer().print(value);
    }

   class Printer{
      void print(Integer a){
        System.out.print("A" + a);
      }
      void print(Object a){
        System.out.print("B" + a);
      }
      void print(Number a){
        System.out.print("C" + a);
      }
   }
 }

  public static void main(String[] args) {
      new Collection<>(0).print();
  }

}

```

<details>
<summary><strong>정답 보기</strong></summary>

B0

</details>

<summary><strong>상세 해설</strong></summary>

## 핵심 개념

제네릭 타입 변수의 메서드 내부 정적 타입은 소거 후 Object로 취급되어 오버로드가 정적 타입 기준으로 선택된다.

## 풀이

Collection<T>.print 안에서 value의 타입은 T다. Java 제네릭은 타입 소거를 사용해 해당 위치의 오버로드 선택에서 Object가 선택된다. value의 문자열 표현은 0이므로 B0가 출력된다.

## 오답 분석

실제 객체가 Integer라고 해서 Integer 오버로드가 런타임에 자동 선택되지는 않는다. 오버로딩은 컴파일 시 선언 타입에 따라 결정된다.

## 암기 포인트

오버로딩은 컴파일 시 타입으로 결정.
