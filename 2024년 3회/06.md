# 문제 06

## 문제

다음은 GoF 디자인 패턴과 관련된 문제이다. 괄호안에 알맞는 용어를 작성하시오.

(        ) 패턴은 클래스나 객체들이 서로 상호작용하는 방법이나 책임 분배 방법을 정의하는 패턴이다.  
(        ) 패턴은 객체들 간의 통신 방법을 정의하고 알고리즘을 캡슐화하여 객체 간의 결합도를 낮춘다.  
(        ) 패턴은 Chain of Responsibility나 Command 또는 Observer 패턴이 있다.

## 핵심 개념

행위 패턴은 객체 간 협력, 책임 분배, 알고리즘 상호작용을 다룬다.

## 풀이

Observer는 상태 변화를 구독자에게 알리고, Command는 요청을 객체로 캡슐화하며, Chain of Responsibility는 요청을 처리자 사슬에 전달한다. 모두 객체 간 행동과 통신을 정의한다.

## 오답 분석

생성 패턴은 객체 생성, 구조 패턴은 클래스·객체 조합이 중심이다. 제시 예시는 행위 패턴이다.

## 암기 포인트

Observer·Command는 행위 패턴.
