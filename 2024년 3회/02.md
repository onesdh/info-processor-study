# 문제 02

## 문제

다음은 파이썬에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
def func(lst):
  for i in range(len(lst) //2):
    lst[i], lst[-i-1] = lst[-i-1], lst[i]

lst = [1,2,3,4,5,6]
func(lst)
print(sum(lst[::2]) - sum(lst[1::2]))
```

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
리스트를 **양 끝에서 안쪽으로 교환**(뒤집기)한 뒤, **짝수 인덱스 합 − 홀수 인덱스 합**을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 파이썬 다중 대입 (swap)
```python
lst[i], lst[-i-1] = lst[-i-1], lst[i]   # 두 값을 동시에 맞바꿈 (임시 변수 불필요)
```
- `lst[-1]`은 마지막 원소, `lst[-i-1]`은 **뒤에서 (i+1)번째**.

### (2) 슬라이싱 `lst[::2]`, `lst[1::2]`
| 표현 | 의미 |
|---|---|
| `lst[::2]` | 인덱스 **0, 2, 4…** (짝수 위치) |
| `lst[1::2]` | 인덱스 **1, 3, 5…** (홀수 위치) |

### (3) `len(lst) // 2`
`//`는 **몫(정수 나눗셈)** → 6 // 2 = 3 → 반복 횟수 3번 (i = 0, 1, 2).

## 3. 실행 과정 (`lst = [1,2,3,4,5,6]`)
| i | 교환 대상 | 교환 후 lst |
|---:|---|---|
| 0 | lst[0] ↔ lst[-1] (1 ↔ 6) | [**6**, 2, 3, 4, 5, **1**] |
| 1 | lst[1] ↔ lst[-2] (2 ↔ 5) | [6, **5**, 3, 4, **2**, 1] |
| 2 | lst[2] ↔ lst[-3] (3 ↔ 4) | [6, 5, **4**, **3**, 2, 1] |

결과: `[6, 5, 4, 3, 2, 1]` (역순)

| 슬라이스 | 값 | 합 |
|---|---|---:|
| `lst[::2]` (인덱스 0,2,4) | 6, 4, 2 | **12** |
| `lst[1::2]` (인덱스 1,3,5) | 5, 3, 1 | **9** |

`12 − 9` = **3**

> **정답: `3`**

## 4. 암기 포인트
- 절반(`len//2`)까지만 교환해야 다시 원상복구되지 않는다.
- `[::2]`는 짝수 **인덱스**(0부터 센다).
