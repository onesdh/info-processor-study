# 문제 02 — Python 리스트 역순과 슬라이싱

## 문제

리스트를 제자리에서 뒤집은 뒤 짝수 인덱스 합에서 홀수 인덱스 합을 뺀 결과를 구하시오.

<details>
<summary><strong>정답 보기</strong></summary>

3

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

양 끝 원소를 교환하면 리스트가 뒤집히고, 슬라이스 [::2]는 0,2,4번 인덱스를 선택한다.

## 풀이

[1,2,3,4,5,6]은 [6,5,4,3,2,1]이 된다. 짝수 인덱스 합은 6+4+2=12, 홀수 인덱스 합은 5+3+1=9라서 차는 3이다.

## 오답 분석

뒤집기 후 원래 리스트 인덱스 값을 사용하면 안 된다. 리스트는 func가 제자리 변경한다.

## 암기 포인트

역순 뒤 0·2·4와 1·3·5를 따로 더한다.
