# 문제 20

## 문제

다음은 네트워크에 대한 문제이다.  아래 내용을 보고 알맞는 용어를 작성하시오.

&nbsp;- 중앙 관리나 고정된 인프라 없이 임시로 구성되는 네트워크이다.  
&nbsp;- 일반적으로 무선 통신을 통해 노드들이 직접 연결되어 데이터를 주고받는다.  
&nbsp;- 긴급 구조, 긴급 회의, 군사적인 상황 등에서 유용하게 활용될 수 있다.

ㄱ.Infrastructure Network        ㄴ. Firmware Network        ㄷ. Peer-to-Peer Network        ㄹ. Ad-hoc Network         ㅁ. Mesh Network        ㅂ.Sensor Network        ㅅ.Virtual Private Network

ㄹ. (Ad-hoc Network)

## 1. 문제에서 묻는 것
"**중앙 관리·고정 인프라 없이 임시로** 구성되는 무선 네트워크" → 어떤 네트워크인지 보기에서 고르는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 인프라 기반 vs 애드혹
```text
 인프라 네트워크:   [단말] ─ [공유기/AP(중앙)] ─ [단말]     ← 중앙 장비 필요 (집 Wi-Fi)
 애드혹 네트워크:   [단말] ←→ [단말] ←→ [단말] ←→ [단말]   ← 장비 없이 단말끼리 직접 연결
```
### (2) 네트워크 종류 비교
| 보기 | 설명 |
|---|---|
| **ㄱ. Infrastructure Network** | AP(공유기) 같은 **고정 인프라**를 통해 연결 |
| ㄴ. Firmware Network | (일반 용어가 아님, 오답용) |
| ㄷ. Peer-to-Peer Network | **동등한 노드끼리** 직접 자원 공유(주로 파일 공유 방식) |
| **ㄹ. Ad-hoc Network** | **고정 인프라 없이 임시로** 단말이 직접 연결·중계 |
| ㅁ. Mesh Network | 노드들이 **그물망처럼 다중 경로**로 연결(인프라 일부 있을 수 있음) |
| ㅂ. Sensor Network | 센서 노드들이 환경 정보를 수집·전달 |
| ㅅ. VPN | 공용망 위의 암호화된 사설망 |

### (3) Ad-hoc의 특징과 활용
- **중앙 관리 없음**, 필요할 때 **임시 구성**, 노드가 **라우터 역할**도 수행
- 긴급 구조, 재난 현장, 군사 작전, 임시 회의, 센서/차량 통신(VANET)

## 3. 문제 풀이
| 단서 | Ad-hoc |
|---|---|
| **중앙 관리·고정 인프라 없이** 임시로 구성 | ✅ |
| **무선 통신**으로 노드들이 직접 연결 | ✅ |
| 긴급 구조·긴급 회의·군사 상황 | ✅ |

(P2P는 중앙 서버 없이 노드끼리 연결되지만 "임시 무선 네트워크"가 아닌 **파일 공유 구조**를, Mesh는 **다중 경로 그물망**을 가리킨다.)

> **정답: ㄹ. Ad-hoc Network**
