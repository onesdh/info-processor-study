# 문제 17

## 문제

다음 아래 내용을 보고 알맞는 용어를 작성하시오. (3글자로 작성)

&nbsp;- 공용 네트워크를 통해 사설 네트워크를 확장하는 기술이다.  
&nbsp;- 사용자의 IP 주소를 숨기고, 사용자가 어디에서 접속하는지를 추적하기 어렵게 만든다.  
&nbsp;- 종류로는 IPsec 또는 SSL, L2TP 등이 있다.

## 1. 문제에서 묻는 것
"**공용 네트워크로 사설 네트워크를 확장**, IP 숨김, IPsec/SSL/L2TP" → 3글자 용어(VPN)를 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) VPN (Virtual Private Network, 가상 사설망)
인터넷 같은 **공용망 위에 암호화된 "가상 터널"** 을 만들어, 마치 **전용선으로 연결된 사설망**처럼 안전하게 통신하게 해 주는 기술이다.
```text
 [ 집/출장지 PC ] ═══════ 암호화 터널 (인터넷 위) ═══════ [ 회사 내부망 ]
                  외부에서는 내용·사용자 IP를 알아보기 어려움
```
### (2) 특징
| 특징 | 설명 |
|---|---|
| **보안성** | 터널링 + **암호화**로 도청 방지 |
| **IP 은닉** | VPN 서버의 IP로 접속하므로 **원래 IP를 숨김**, 위치 추적 어려움 |
| **비용 절감** | 전용선 대신 인터넷 사용 |
| **원격 접속** | 재택근무·출장 시 회사 내부 자원 접근 |

### (3) 주요 프로토콜
| 프로토콜 | 계층 | 특징 |
|---|---|---|
| **IPsec** | 3계층 | IP 패킷 **암호화·인증**, 가장 널리 사용 |
| **SSL/TLS VPN** | 4~7계층 | 웹 브라우저 기반, 설치 간편 |
| **L2TP** | 2계층 | 터널링 담당, 보통 **IPsec와 함께**(L2TP/IPsec) |
| PPTP | 2계층 | 오래됨, 보안 취약 |

## 3. 문제 풀이
| 단서 | VPN |
|---|---|
| 공용 네트워크로 사설 네트워크를 **확장** | ✅ |
| IP 주소를 숨기고 접속 위치 추적을 어렵게 | ✅ |
| IPsec, SSL, L2TP 등 | ✅ |
| **3글자** | ✅ (V-P-N) |
