# 문제 11

## 문제

다음은 Java 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
public class Main{
  public static void main(String[] args){
    Base a =  new Derivate();
    Derivate b = new Derivate();

    System.out.print(a.getX() + a.x + b.getX() + b.x);
  }
}


class Base{
  int x = 3;

  int getX(){
     return x * 2;
  }
}

class Derivate extends Base{
  int x = 7;

  int getX(){
     return x * 3;
  }
}
```

## 1. 문제에서 묻는 것
**상속 + 필드 은닉 + 메서드 오버라이딩**이 섞인 문제다. 메서드와 필드가 **서로 다른 기준**으로 선택된다는 점이 핵심이다.

## 2. 먼저 알아야 할 개념
### (1) 필드 vs 메서드의 결정 방식
| 대상 | 무엇을 기준으로? |
|---|---|
| **메서드(오버라이딩)** | **실제 객체의 타입** (실행 시 결정, 동적 바인딩) |
| **필드(변수)** | **참조 변수의 선언 타입** (컴파일 시 결정) |

부모·자식이 같은 이름의 필드 `x`를 가져도 **별개의 변수**이며, 필드는 오버라이딩되지 않는다(은닉).

### (2) 객체 구조
```text
 Derivate 객체 하나 안에는 두 개의 x가 있다
   ├ Base.x = 3
   └ Derivate.x = 7
 getX(): Base → x*2 (Base.x),  Derivate → x*3 (Derivate.x)  ← 오버라이딩
```
## 3. 실행 과정
```java
Base a = new Derivate();   // 선언 타입 Base, 실제 객체 Derivate
Derivate b = new Derivate();
```
| 식 | 판단 | 값 |
|---|---|---:|
| `a.getX()` | 메서드 → **실제 객체(Derivate)** 의 `getX()` → `x*3` (Derivate의 x=7) | **21** |
| `a.x` | 필드 → **선언 타입(Base)** 의 `x` | **3** |
| `b.getX()` | Derivate의 `getX()` → 7×3 | **21** |
| `b.x` | 선언 타입 Derivate의 `x` | **7** |

`print(21 + 3 + 21 + 7)` → 정수 덧셈 **52**

> **정답: `52`**

## 4. 암기 포인트
- **메서드는 실제 객체, 필드는 변수 타입**.
- 전부 `int`라서 `+`는 덧셈이다 (문자열 연결 아님).
