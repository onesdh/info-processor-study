# 문제 11

## 문제

다음은 Java 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
public class Main{
  public static void main(String[] args){
    Base a =  new Derivate();
    Derivate b = new Derivate();

    System.out.print(a.getX() + a.x + b.getX() + b.x);
  }
}


class Base{
  int x = 3;

  int getX(){
     return x * 2;
  }
}

class Derivate extends Base{
  int x = 7;

  int getX(){
     return x * 3;
  }
}
```

<details>
<summary><strong>정답 보기</strong></summary>

52

</details>

## 핵심 개념

메서드는 런타임 객체 타입으로 동적 디스패치하지만 필드는 변수의 선언 타입으로 결정된다.

## 풀이

a는 Base 타입이지만 객체는 Derivate이므로 getX는 자식 메서드를 실행해 7×3=21이다. a.x는 Base 필드 3이다. b는 Derivate 타입이므로 b.getX=21, b.x=7이다. 합은 21+3+21+7=52다.

## 오답 분석

필드도 다형적으로 선택된다고 보면 안 된다. 동적 바인딩은 오버라이딩 메서드에 적용되고 필드 숨김은 참조 변수 선언 타입을 따른다.

## 암기 포인트

메서드는 실제 객체, 필드는 참조 타입.
