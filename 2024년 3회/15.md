# 문제 15

## 문제

다음은 데이터베이스에 관한 문제이다. 아래 내용을 읽고 알맞는 답을 보기에서 찾아 골라 작성하시오.

(1) 다른 테이블, 릴레이션의 기본 키를 참조하는 속성 또는 속성들의 집합  
(2) 테이블에서 각 행을 유일하게 식별할 수 있는 최소한의 속성들의 집합  
(3) 후보 키 중에서 선정된 기본 키를 제외한 나머지 후보 키  
(4) 테이블에서 각 행을 유일하게 식별할 수 있는 속성들의 집합

ㄱ. 슈퍼키         ㄴ. 외래키            ㄷ. 대체키             ㄹ. 후보키

## 1. 문제에서 묻는 것
**키(Key)의 종류**(외래키, 후보키, 대체키, 슈퍼키)를 설명과 연결하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 키란?
테이블에서 **행(튜플)을 구분**하거나 **테이블 간 관계를 맺는 데 쓰는 속성(들)** 이다.

### (2) 키의 포함 관계
```text
 ┌──────────────────────── 슈퍼키 (유일성 ○) ─────────────────────────┐
 │   ┌──────────────── 후보키 (유일성 ○ + 최소성 ○) ────────────────┐ │
 │   │    ┌──── 기본키 (후보키 중 선택) ────┐   ┌─ 대체키 (나머지) ─┐ │ │
 │   │    └─────────────────────────────────┘   └───────────────────┘ │ │
 │   └──────────────────────────────────────────────────────────────┘ │
 └──────────────────────────────────────────────────────────────────────┘
                          외래키: 다른 테이블의 기본키를 참조
```
| 키 | 정의 | 조건 |
|---|---|---|
| **슈퍼키** | 행을 **유일하게 식별**할 수 있는 속성의 집합 | 유일성 |
| **후보키** | 슈퍼키 중 **더 줄일 수 없는 최소한**의 집합 | 유일성 + **최소성** |
| **기본키** | 후보키 중 **대표로 선정**한 키 | NULL·중복 불가 |
| **대체키** | 후보키 중 **기본키가 아닌 나머지** | |
| **외래키** | **다른 테이블의 기본키를 참조**하는 속성 | 참조 무결성 |

### (3) 예: 학생(학번, 주민번호, 이름, 학과)
- 슈퍼키: {학번}, {주민번호}, {학번, 이름}, {학번, 주민번호, 이름} …
- 후보키: {학번}, {주민번호} (최소)
- 기본키: {학번} / 대체키: {주민번호}

## 3. 문제 풀이
| 번호 | 설명 | 정답 |
|---|---|---|
| (1) | 다른 릴레이션의 **기본키를 참조**하는 속성 | ㄴ. **외래키** |
| (2) | 각 행을 유일하게 식별하는 **최소한**의 속성 집합 | ㄹ. **후보키** |
| (3) | 후보키 중 **기본키를 제외한 나머지** | ㄷ. **대체키** |
| (4) | 각 행을 유일하게 식별할 수 있는 속성들의 집합(최소성 언급 없음) | ㄱ. **슈퍼키** |

> **정답: (1) 외래키 (2) 후보키 (3) 대체키 (4) 슈퍼키**

## 4. 암기 포인트
- **최소성이 있으면 후보키, 없으면 슈퍼키.**
- 대체키 = 후보키 − 기본키.
