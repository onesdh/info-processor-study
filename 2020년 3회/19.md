# 문제 19

## 문제

C++에서 생성자란 무엇인지 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

해당 클래스의 객체가 생성될 때 자동으로 호출되는 특수한 종류의 메서드

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

생성자는 클래스와 같은 이름을 가지며 객체 초기 상태를 설정한다.

## 풀이

일반 멤버 함수와 달리 반환형이 없고 객체 생성 과정에서 자동 호출된다.

## 오답 분석

소멸자는 객체가 제거될 때 호출된다.

## 암기 포인트

객체 생성 시 자동 실행되는 초기화 함수.

</details>
