# 문제 19

## 문제

C++에서 생성자란 무엇인지 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

해당 클래스의 객체가 생성될 때 자동으로 호출되는 특수한 종류의 메서드

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**생성자(Constructor)** 가 무엇인지 서술하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 생성자
**클래스의 객체(인스턴스)가 만들어질 때 자동으로 호출되는 특수한 메서드**다. 주로 객체의 **초기 상태(필드 값)를 설정**하는 데 쓴다.

### (2) 특징
| 특징 | 설명 |
|---|---|
| **이름** | **클래스 이름과 같음** |
| **반환형** | **없음**(`void`도 쓰지 않음) |
| **호출 시점** | `new`(또는 객체 선언)로 **객체가 생성될 때 자동** 호출 |
| **오버로딩** | 매개변수를 달리해 **여러 개** 정의 가능 |
| 기본 생성자 | 직접 안 만들면 컴파일러가 **매개변수 없는 기본 생성자**를 제공 |

### (3) C++ 예
```cpp
class Student {
    int age;
public:
    Student(int a) { age = a; }     // 생성자: 클래스 이름과 같고 반환형 없음
};
Student s(20);    // 객체 생성 시 Student(20)이 자동 호출 → age = 20
```
반대 개념: **소멸자(Destructor)** — 객체가 사라질 때 자동 호출(`~Student()`).

## 3. 서술 답안
> **생성자: 해당 클래스의 객체가 생성될 때 자동으로 호출되어 초기화를 수행하는 특수한 메서드 (클래스 이름과 동일, 반환형 없음).**
