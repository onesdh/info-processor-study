# 문제 17

## 문제

다음은 자바 코드이다. 출력 결과를 쓰시오.

```
public class good {
	public static void main(String[] args){
    int i=0;
    int sum=0;
    while (i<10){
    	i++;
        if(i%2 ==1)
        	continue;
        sum += i;
     }
     System.out.println(sum);
   }
}
```

<details>
<summary><strong>정답 보기</strong></summary>

30

2+4+6+8+10=30이 됩니다.

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

continue는 현재 반복의 나머지 문장을 건너뛰고 다음 반복으로 이동한다.

## 풀이

홀수를 제외하고 2+4+6+8+10=30이다.

## 오답 분석

1부터 10까지 전부 더하면 55이므로 홀수 건너뛰기를 적용해야 한다.

## 암기 포인트

짝수 합은 30.

</details>
