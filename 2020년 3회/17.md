# 문제 17

## 문제

다음은 자바 코드이다. 출력 결과를 쓰시오.

```
public class good {
	public static void main(String[] args){
    int i=0;
    int sum=0;
    while (i<10){
    	i++;
        if(i%2 ==1)
        	continue;
        sum += i;
     }
     System.out.println(sum);
   }
}
```

<details>
<summary><strong>정답 보기</strong></summary>

30

2+4+6+8+10=30이 됩니다.

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
`while`과 `continue`를 사용해 **짝수만 더하는** 코드의 합계를 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) continue
**반복문의 나머지 부분을 건너뛰고 다음 반복으로** 넘어간다.
```java
if (i % 2 == 1)    // i가 홀수이면
    continue;       // 아래 sum += i 를 건너뜀
sum += i;           // (짝수일 때만 실행)
```
### (2) 코드의 흐름
`i++`가 **먼저** 실행되어 i는 1부터 10까지 사용된다.

## 3. 실행 과정
| i (증가 후) | `i % 2 == 1`? | 동작 | sum |
|---:|:---:|---|---:|
| 1 | ✅ (홀수) | continue | 0 |
| 2 | ❌ | sum += 2 | 2 |
| 3 | ✅ | continue | 2 |
| 4 | ❌ | sum += 4 | 6 |
| 5 | ✅ | continue | 6 |
| 6 | ❌ | sum += 6 | 12 |
| 7 | ✅ | continue | 12 |
| 8 | ❌ | sum += 8 | 20 |
| 9 | ✅ | continue | 20 |
| 10 | ❌ | sum += 10 | **30** |

`i`가 10이 되면 `while (i < 10)`이 거짓이 되어 종료. **합 = 2 + 4 + 6 + 8 + 10 = 30**

> **정답: `30`**

## 4. 암기 포인트
- `continue` = 이번 반복의 나머지를 건너뜀(반복 자체는 계속).
- `break`는 반복문을 완전히 종료.
