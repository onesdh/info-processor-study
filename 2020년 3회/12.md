# 문제 12

## 문제

테스트의 종류 중, 둥치분할 테스트, 경계값 분석 테스트 등의 종류가 있는 테스트 기법을 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

블랙박스 테스트 (명세 기반 테스트)

블랙박스 테스트는 소프트웨어가 수행할 특정 기능을 알기 위해서 각 기능이 완전히 작동되는 것을 입증하는 테스트로 기능 테스트라고 불립니다.

동치 분할 검사 :

입력 자료에 초점을 맞춰 테스트 케이스를 만들고 검사하는 방법 (= 동등 분할 기법)

경계값 분석 :

입력 자료에만 치중한 동치 분할 기법을 보완한 기법으로, 입력 조건의 중간값보다 경계값에서 오류가 발생될 확률이 높다는 점을 이용하여 입력 조건의 경계값을 테스트 케이스로 선정하여 검사하는 기법

원인-효과 그래프 검사 :

입력 데이터 간의 관계와 출력에 영향을 미치는 상황을 체계적으로 분석한 다음 효용성이 높은 테스트 케이스를 선정하여 검사하는 기법

오류 예측 검사 :

과거의 경험이나 확인자의 감각으로 테스트하는 기법으로, 다른 블랙박스 테스트 기법으로는 찾아낼 수 없는 오류를 찾아내는 일력의 보충적 검사 기법 (= 데이터 확인 검사)

비교 검사 :

여러 버전의 프로그램에 동일한 테스트 자료를 제공하여 동일한 결과가 출력되는지 테스트하는 기법

## 1. 문제에서 묻는 것
"**동치 분할 테스트, 경계값 분석 테스트** 등이 포함되는 테스트 기법" → 상위 분류(**블랙박스 테스트**)를 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 블랙박스 vs 화이트박스
| 구분 | 블랙박스(명세 기반) | 화이트박스(구조 기반) |
|---|---|---|
| 관점 | **내부 구조를 모르고** 입력→출력 검증 | **소스 코드 내부 논리** 검증 |
| 별칭 | **기능 테스트** | 구조 테스트 |
| 기법 | 동치 분할, 경계값 분석, 원인-효과 그래프, 오류 예측, 비교 검사, 결정 테이블 | 문장·분기·조건 커버리지, 기본 경로 테스트 |

### (2) 블랙박스 기법
| 기법 | 설명 |
|---|---|
| **동치(동등) 분할** | 입력을 유효/무효 **영역**으로 나눠 대표값 검사 |
| **경계값 분석** | 영역 **경계**에서 오류가 많다는 점을 이용 |
| **원인-효과 그래프** | 입력 간 관계와 출력 영향을 분석 |
| **오류 예측** | 과거 경험·감각으로 테스트(보충적) |
| **비교 검사** | 여러 버전에 같은 입력을 주고 결과 비교 |

## 3. 문제 풀이
| 단서 | 블랙박스 |
|---|---|
| **동치 분할, 경계값 분석** 등이 속하는 테스트 | ✅ |

> **정답: 블랙박스 테스트 (명세 기반 테스트)**
