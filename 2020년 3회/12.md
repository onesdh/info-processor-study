# 문제 12 — 블랙박스 테스트

## 문제

동등분할과 경계값 분석이 포함되는 테스트 기법 유형을 쓰시오.

## 정답

블랙박스 테스트 (명세 기반 테스트)

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

블랙박스 테스트는 내부 구현을 보지 않고 요구사항과 입력·출력 명세를 기반으로 기능을 검증한다.

## 풀이

동등분할과 경계값 분석은 명세 기반의 대표적인 기법이다.

## 오답 분석

문장·분기·조건 커버리지는 소스 구조를 살피는 화이트박스 기법이다.

## 암기 포인트

동등분할·경계값은 블랙박스.
