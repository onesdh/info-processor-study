# 문제 02

## 문제

다음은 C언어 소스 코드이다. 출력 결과를 쓰시오.

```
#include <stdio.h>
	void main(){
    	int i=0, c=0;
        while (i<10){
        i++;
        c*=i;
        }
        printf("%d",c);
   }
```

<details>
<summary><strong>정답 보기</strong></summary>

0

c가 0이므로 어떤수를 곱해도 0이 됩니다.

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
`c *= i`처럼 **곱하기 누적**을 하는데 **초기값이 0**일 때의 결과를 구하는 문제다. 함정에 속지 말고 초기값부터 확인한다.

## 2. 먼저 알아야 할 개념
### (1) 복합 대입 연산자
`c *= i` 는 `c = c * i`.

### (2) 0과의 곱
**어떤 수에 0을 곱하면 항상 0**이다.

### (3) 코드 읽기
```c
int i = 0, c = 0;          // c의 초기값 = 0 !
while (i < 10) {
    i++;                   // i: 1, 2, ..., 10
    c *= i;                // c = c * i
}
```
## 3. 실행 과정
| 반복 | i | `c *= i` | c |
|---:|---:|---|---:|
| 1 | 1 | 0 × 1 | 0 |
| 2 | 2 | 0 × 2 | 0 |
| 3 | 3 | 0 × 3 | 0 |
| … | … | … | 0 |
| 10 | 10 | 0 × 10 | **0** |

`c`가 처음부터 0이므로 몇 번을 곱해도 **0**. (팩토리얼 10!을 구하려면 `c`를 1로 초기화해야 한다.)

> **정답: `0`**

## 4. 암기 포인트
- 누적 곱의 초기값은 **1**, 누적 합의 초기값은 **0**. 이 문제는 곱인데 초기값이 0이라 결과 0.

</details>
