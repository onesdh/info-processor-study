# 문제 02

## 문제

다음은 C언어 소스 코드이다. 출력 결과를 쓰시오.

```
#include <stdio.h>
	void main(){
    	int i=0, c=0;
        while (i<10){
        i++;
        c*=i;
        }
        printf("%d",c);
   }
```

<details>
<summary><strong>정답 보기</strong></summary>

0

c가 0이므로 어떤수를 곱해도 0이 됩니다.

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

c가 처음부터 0이며 이후에는 곱셈만 수행하므로 값은 계속 0이다.

## 풀이

어떤 값을 곱해도 0이므로 반복 종료 후 출력도 0이다.

## 오답 분석

반복 횟수를 곱해 10을 계산하지 않는다. c에 0 이외의 초기값을 대입한 적이 없다.

## 암기 포인트

0에 곱셈을 해도 계속 0.

</details>
