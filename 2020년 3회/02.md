# 문제 02 — C 반복문 초기값

## 문제

i=0,c=0에서 i가 10 미만인 동안 i를 증가시키고 c*=i를 수행한다. 출력값을 쓰시오.

## 정답

0

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

c가 처음부터 0이며 이후에는 곱셈만 수행하므로 값은 계속 0이다.

## 풀이

어떤 값을 곱해도 0이므로 반복 종료 후 출력도 0이다.

## 오답 분석

반복 횟수를 곱해 10을 계산하지 않는다. c에 0 이외의 초기값을 대입한 적이 없다.

## 암기 포인트

0에 곱셈을 해도 계속 0.
