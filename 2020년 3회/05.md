# 문제 05 — 프로토콜

## 문제

서로 다른 기기나 시스템 사이에서 메시지를 주고받고 도착 여부와 재전송 절차 등을 규정하는 통신 규약을 쓰시오.

## 정답

프로토콜

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

프로토콜은 통신 당사자가 따르는 데이터 형식, 의미, 순서와 제어 규칙의 집합이다.

## 풀이

구문은 형식, 의미는 제어 정보 해석, 순서는 전송 순서와 타이밍을 규정한다.

## 오답 분석

언어 문법과 달리 네트워크 통신 과정의 표준 규칙을 다룬다.

## 암기 포인트

시스템 간 통신 약속은 프로토콜.
