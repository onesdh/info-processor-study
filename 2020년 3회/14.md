# 문제 14

## 문제

DB스키마에 대해서 서술하시오.

<details>
<summary><strong>정답 보기</strong></summary>

데이터베이스의 구조, 제약조건 등의 정보를 담고 있는 기본적인 구조

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**데이터베이스 스키마**(DB Schema)가 무엇인지 서술하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 스키마(Schema)
데이터베이스의 **구조와 제약조건 등을 정의한 기본 설계도**다. **어떤 테이블이 있고, 각 테이블에 어떤 열(속성)·자료형이 있으며, 어떤 규칙(키·무결성)이 있는지**를 기술한다. 데이터 자체가 아니라 **"틀(구조)"** 이다.

```text
 스키마(구조·정의, 잘 안 변함)           인스턴스(데이터 내용, 자주 변함)
 학생(학번 INT PK, 이름 VARCHAR, 학과 …)  →  (101, 홍길동, 컴공), (102, 김철수, 전자) …
```
### (2) 3단계 스키마
| 스키마 | 관점 | 설명 |
|---|---|---|
| **외부 스키마** | 사용자 | 개인이 필요로 하는 논리적 구조(뷰, 서브 스키마), 여러 개 |
| **개념 스키마** | 조직 전체 | 전체 DB의 논리적 구조, 1개 |
| **내부 스키마** | 저장 장치 | 물리적 저장 구조, 인덱스 |

## 3. 서술 답안
> **DB 스키마: 데이터베이스의 구조(테이블·속성·자료형)와 제약조건 등의 정보를 담고 있는 기본적인 구조(설계도).**
