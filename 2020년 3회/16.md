# 문제 16

## 문제

UI 설계 원칙 중 직관성에 대해서 쓰시오.

<summary><strong>정답 보기</strong></summary>

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**UI 설계 원칙**의 하나인 **직관성**을 서술하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) UI 설계 기본 원칙 4가지
| 원칙 | 설명 |
|---|---|
| **직관성** | **누구나 쉽게 이해하고 쉽게 사용**할 수 있어야 함 |
| **유효성** | 사용자의 **목표를 정확하고 완벽하게** 달성할 수 있어야 함 |
| **학습성** | **쉽게 배우고** 익힐 수 있어야 함 |
| **유연성** | 사용자의 **다양한 요구**를 수용하고 오류를 최소화 |

### (2) 직관성의 부특성
| 부특성 | 의미 |
|---|---|
| **쉬운 검색** | 필요한 기능·정보를 **쉽게 찾음** |
| **쉬운 사용성** | 별도 설명 없이도 **쉽게 사용** |
| **일관성** | 화면·기능·용어가 **일관**되어 예측 가능 |

```text
 직관적인 UI 예: 쇼핑몰의 "장바구니" 아이콘 → 누구나 보고 바로 이해
```
## 3. 서술 답안
> **직관성: 누구나 쉽게 이해하고 사용할 수 있도록 설계하는 UI 설계 원칙으로, 쉬운 검색·쉬운 사용성·일관성 등을 부특성으로 가진다.**
