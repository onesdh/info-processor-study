# 문제 16

## 문제

UI 설계 원칙 중 누구나 쉽게 이해하고 사용할 수 있으며 검색과 사용성이 간단하도록 하는 특성을 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

직관성

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

직관성은 사용자가 별도 학습 없이도 인터페이스를 이해하고 쉽게 사용할 수 있는 정도다.

## 풀이

익숙한 표현과 일관된 배치로 사용자가 원하는 기능을 찾고 조작하기 쉽게 한다.

## 오답 분석

학습성은 배우기 쉬운 정도, 유연성은 사용자 요구와 다양한 상황에 대응하는 정도다.

## 암기 포인트

쉽게 이해하고 바로 사용하는 직관성.
