# 문제 15

## 문제

다음은 자바 코드이다. 출력 결과를 쓰시오.

```
abstract class vehicle{
	private String name;
    abstract public String getName(String val);
    public String getName(){
    	return "vehicle name:" + name;
    }
	public void setName(String val){
    	name = val;
    }
}

class Car extends Vehicle{
	public Car(String val){
    	setName(val);
   }
public String getName(String val){
	return "Car name : " + val;
   }
public String getName(byte val[]){
	return "Car name : " + val;
   }
}

public class good {
	public Static void main(String[] args){
    Vehicle obj = new Car("Spark");
    System.out.print(obj.getName());
    }
}

```

## 1. 문제에서 묻는 것
**추상 클래스와 상속**에서 `obj.getName()`이 어느 메서드를 호출하는지, 부모의 **private 필드**를 `setName`을 통해 설정하는 방법을 이해하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 추상 클래스
`abstract class`는 **추상 메서드(몸체 없음)** 를 가질 수 있고 **자식이 구현**해야 한다. 일반 메서드도 함께 가질 수 있다.

### (2) private 필드와 setter
`private String name;` 은 **같은 클래스 안에서만** 직접 접근 가능하다. 자식은 직접 못 쓰고 부모의 **`setName()`** 같은 공개 메서드를 통해 설정한다.
```java
public Car(String val) { setName(val); }    // 부모의 setName을 호출 → 부모의 name에 "Spark" 저장
```
### (3) 오버로딩된 getName 3개
| 클래스 | 메서드 | 매개변수 |
|---|---|---|
| Vehicle | `getName(String val)` (추상) | String 1개 |
| Vehicle | **`getName()`** | **없음** |
| Car | `getName(String val)` (구현) | String 1개 |
| Car | `getName(byte val[])` | byte 배열 |

`obj.getName()` → **매개변수가 없는 `getName()`** → **Vehicle의 getName()** (Car는 이를 오버라이딩하지 않음).

## 3. 실행 과정
1. `new Car("Spark")` → `setName("Spark")` → Vehicle의 `name = "Spark"`
2. `obj.getName()` → Vehicle.getName() → `"vehicle name:" + name`

> **정답: `vehicle name:Spark`**
> (원문 정답은 대소문자·공백이 다르게 표기되어 있으나, 코드 기준 출력은 `vehicle name:` 뒤에 `Spark`가 이어지는 형태. 핵심은 **Vehicle의 getName()** 이 호출되어 `Spark`가 포함된다는 것.)

## 4. 암기 포인트
- 매개변수가 다르면 **다른 메서드(오버로딩)** → 자식이 재정의하지 않은 부모 메서드가 호출된다.
- 2021년 3회 1번과 같은 계열(2023년 1회 17번 참고).
