# 문제 15

## 문제

다음은 자바 코드이다. 출력 결과를 쓰시오.

```
abstract class vehicle{
	private String name;
    abstract public String getName(String val);
    public String getName(){
    	return "vehicle name:" + name;
    }
	public void setName(String val){
    	name = val;
    }
}

class Car extends Vehicle{
	public Car(String val){
    	setName(val);
   }
public String getName(String val){
	return "Car name : " + val;
   }
public String getName(byte val[]){
	return "Car name : " + val;
   }
}

public class good {
	public Static void main(String[] args){
    Vehicle obj = new Car("Spark");
    System.out.print(obj.getName());
    }
}

```

## 핵심 개념

Vehicle형 참조로 호출한 무인자 getName은 Vehicle에 정의된 구현이며 private 필드 name의 현재값을 사용한다.

## 풀이

Car 생성자가 setName("Spark")를 호출하므로 필드는 Spark다. 오버로드된 getName(String)이나 getName(byte[])은 인자가 없어 선택되지 않는다.

## 오답 분석

인자 없는 메서드와 매개변수가 있는 오버로드를 구분한다. 객체의 필드 상태가 부모 메서드 출력에 반영된다.

## 암기 포인트

인자 없는 getName은 Vehicle의 필드명을 출력.
