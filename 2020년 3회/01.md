# 문제 01

## 문제

리팩토링의 목적을 설명하시오.

<details>
<summary><strong>정답 보기</strong></summary>

외부 동작은 유지하면서 코드 구조를 정리해 가독성, 유지보수성, 유연성, 품질을 높이는 것

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

리팩토링은 기능을 바꾸지 않고 내부 설계를 개선하는 작업이다.

## 풀이

복잡한 코드 단순화, 중복 제거, 명확한 구조를 통해 변경과 유지보수를 쉽게 한다.

## 오답 분석

새 기능을 추가하거나 버그 수정이 목적일 수 있지만 리팩토링 자체는 외부 동작을 보존한다.

## 암기 포인트

동작은 유지, 내부 구조를 개선.

</details>
