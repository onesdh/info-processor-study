# 문제 09

## 문제

학생 테이블에서 이름이 민수인 튜플을 삭제하는 SQL문을 작성하시오

[학생]

| 학번 | 이름 | 점수 | 과목이름 |
|---|---|---|---|
| 1000 | 김정미 | 90 | 알고리즘 |
| 2000 | 강은미 | 95 | 데이터베이스 |
| 3000 | 홍길동 | 90 | 전산수학 |
| 4000 | 민수 | 95 | 운영체제 |

<details>
<summary><strong>정답 보기</strong></summary>

DELETE FROM 학생 WHERE 이름 = '민수';

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
학생 테이블에서 **이름이 '민수'인 튜플(행)을 삭제**하는 SQL을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) DELETE
```sql
DELETE FROM 테이블명 WHERE 조건;
```
| 부분 | 의미 |
|---|---|
| `DELETE FROM 테이블` | 어느 테이블에서 행을 삭제할지 |
| `WHERE 조건` | **삭제할 행의 조건** — **생략하면 모든 행이 삭제**된다! |

### (2) 문자열 표기
문자열은 **작은따옴표**: `'민수'`.

## 3. 풀이
| 학번 | 이름 | 점수 | 과목이름 | 삭제? |
|---:|---|---:|---|:---:|
| 1000 | 김정미 | 90 | 알고리즘 | |
| 2000 | 강은미 | 95 | 데이터베이스 | |
| 3000 | 홍길동 | 90 | 전산수학 | |
| **4000** | **민수** | 95 | 운영체제 | ✅ |

```sql
DELETE FROM 학생 WHERE 이름 = '민수';
```
> **정답: `DELETE FROM 학생 WHERE 이름 = '민수';`**

## 4. 암기 포인트
- `WHERE`를 빼먹으면 **전체 삭제**.
- 2023년 1회 13번과 같은 문제.
