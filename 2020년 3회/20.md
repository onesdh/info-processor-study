# 문제 20

## 문제

학생 테이블에 주소 속성을 추가하는 SQL문을 작성하시오.

(    1.   ) TABLE 학생   (   2.  ) 주소 VARCHAR(20);

<details>
<summary><strong>정답 보기</strong></summary>

1.ALTER

2.ADD

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
학생 테이블에 **새 속성(열) `주소`를 추가**하는 SQL의 빈칸(`ALTER`, `ADD`)을 채우는 문제다.

## 2. 먼저 알아야 할 개념
### (1) ALTER TABLE (테이블 구조 변경)
**DDL(데이터 정의어)** 로 이미 만들어진 테이블의 **구조를 변경**한다.
| 작업 | 문법 |
|---|---|
| **열 추가** | `ALTER TABLE 테이블 ADD 열이름 자료형;` |
| 열 삭제 | `ALTER TABLE 테이블 DROP COLUMN 열이름;` |
| 열 수정 | `ALTER TABLE 테이블 MODIFY 열이름 자료형;` (DBMS마다 다름) |

### (2) DDL 명령
| 명령 | 기능 |
|---|---|
| CREATE | 테이블·뷰 등 **생성** |
| **ALTER** | **구조 변경** |
| DROP | **삭제**(구조까지) |
| TRUNCATE | 모든 행 삭제(구조 유지) |

## 3. 풀이
```sql
( 1 ) TABLE 학생 ( 2 ) 주소 VARCHAR(20);
```
| 빈칸 | 정답 | 이유 |
|---|---|---|
| (1) | **ALTER** | 테이블 구조를 변경하는 명령 |
| (2) | **ADD** | 새 열을 추가 |

```sql
ALTER TABLE 학생 ADD 주소 VARCHAR(20);
```
> **정답: 1. ALTER 2. ADD**

## 4. 암기 포인트
- `ALTER TABLE ... ADD / DROP COLUMN / MODIFY`.
- 구조 변경은 DDL, 데이터 변경은 DML(`UPDATE`).
