# 문제 20 — ALTER TABLE ADD

## 문제

학생 테이블에 주소 VARCHAR(20) 컬럼을 추가하는 SQL을 쓰시오.



## 정답

ALTER TABLE 학생 ADD 주소 VARCHAR(20);

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

ALTER TABLE은 기존 테이블 정의를 변경하며 ADD는 새 컬럼을 추가한다.

## 풀이

대상 테이블 학생에 주소 컬럼을 추가한다.

## 오답 분석

UPDATE는 행의 값을 수정하며 테이블 구조 변경 명령이 아니다.

## 암기 포인트

컬럼 추가는 ALTER TABLE ADD.
