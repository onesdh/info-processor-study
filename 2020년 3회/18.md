# 문제 18 — EAI 통합 유형

## 문제

Message Bus와 Hybrid 외에 EAI 데이터 전송 모델 두 가지를 쓰시오.

## 정답

Point-to-Point; Hub & Spoke

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

EAI는 기업 애플리케이션 사이의 데이터와 업무 흐름을 통합한다.

## 풀이

Point-to-Point는 1:1 직접 연결이고 Hub & Spoke는 중앙 허브를 통해 연결한다.

## 오답 분석

Message Bus는 미들웨어 기반 메시징, Hybrid는 여러 통합 방식을 조합한다.

## 암기 포인트

직접 연결과 중앙 허브를 추가.
