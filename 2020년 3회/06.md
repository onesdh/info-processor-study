# 문제 06

## 문제

TCP/IP에서 오류가 발생하면 (      ) 메세지를 보내서 오류가 발생했음을 알린다. 괄호 (     )안에 들어갈 용어를 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

ICMP(Internet Control Message Protocol)

ICMP : IP 패킷을 처리할 때 발생하는 문제를 알려주는 프로토콜로, 메세지 형식은 8바이트의 헤더와 가변 길이의 데이터 영역으로 분리되어 있다.

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
"TCP/IP에서 **오류가 발생하면** ( ) 메시지를 보내 **오류를 알림**" → 프로토콜 이름(ICMP)을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) IP의 한계와 ICMP
**IP**는 패킷을 "최선을 다해" 전달할 뿐 **오류를 보고하는 기능이 없다.** 그래서 이를 보완하는 **제어·오류 메시지 프로토콜**이 필요하다 — 이것이 **ICMP**.

### (2) ICMP (Internet Control Message Protocol)
| 항목 | 내용 |
|---|---|
| 역할 | **IP 패킷을 처리하다 발생한 문제**를 송신 측에 알림, 네트워크 상태 확인 |
| 계층 | **3계층(네트워크)** |
| 메시지 형식 | **8바이트 헤더 + 가변 길이 데이터** |

| 대표 활용 | 설명 |
|---|---|
| **ping** | **Echo Request/Reply**로 연결 상태 확인 |
| **traceroute** | TTL 초과(Time Exceeded) 메시지로 경로 추적 |
| 오류 보고 | **목적지 도달 불가**, **TTL 초과** 등 |

```text
 송신 PC ──패킷──▶ 라우터 ──✖(목적지 없음)
 송신 PC ◀── ICMP "Destination Unreachable" ── 라우터   (오류를 알려 줌)
```
## 3. 문제 풀이
| 단서 | ICMP |
|---|---|
| TCP/IP에서 **오류가 발생했음을 알리는** 메시지 | ✅ |
| IP 패킷 처리 중 발생하는 문제를 알려 주는 프로토콜 | ✅ |

> **정답: ICMP (Internet Control Message Protocol)**
