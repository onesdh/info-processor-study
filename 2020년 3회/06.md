# 문제 06 — ICMP

## 문제

TCP/IP에서 IP 패킷 처리 오류나 네트워크 상태를 알려주는 메시지 프로토콜을 쓰시오.

## 정답

ICMP (Internet Control Message Protocol)

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

ICMP는 IP 계층의 오류 보고와 진단 메시지를 전달하는 프로토콜이다.

## 풀이

도달 불가, 시간 초과 등 IP 전달 과정의 문제를 알린다.

## 오답 분석

TCP와 UDP는 전송 계층 프로토콜이며 ICMP는 응용 데이터 전송용 프로토콜이 아니다.

## 암기 포인트

IP 오류 보고는 ICMP.
