# 문제 06

## 문제

TCP/IP에서 오류가 발생하면 (      ) 메세지를 보내서 오류가 발생했음을 알린다. 괄호 (     )안에 들어갈 용어를 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

ICMP(Internet Control Message Protocol)

ICMP : IP 패킷을 처리할 때 발생하는 문제를 알려주는 프로토콜로, 메세지 형식은 8바이트의 헤더와 가변 길이의 데이터 영역으로 분리되어 있다.

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

ICMP는 IP 계층의 오류 보고와 진단 메시지를 전달하는 프로토콜이다.

## 풀이

도달 불가, 시간 초과 등 IP 전달 과정의 문제를 알린다.

## 오답 분석

TCP와 UDP는 전송 계층 프로토콜이며 ICMP는 응용 데이터 전송용 프로토콜이 아니다.

## 암기 포인트

IP 오류 보고는 ICMP.

</details>
