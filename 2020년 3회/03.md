# 문제 03

## 문제

대표적인 내부 라우팅 프로토콜로 다익스트라 알고리즘을 이용한 대규모 네트워크에 적합한 링크 상태 라우팅 프로토콜로 불리는 라우팅 프로토콜은 무엇인가?

<details>
<summary><strong>정답 보기</strong></summary>

OSPF(Open Shortest Path First)

OSPF(Open Shortest Path First)의 특징 :

다익스트라 알고리즘 사용 - 다익스트라 알고리즘 사용하는 내부 라우팅 프로토콜

라우팅 메트릭 지정 - 최소, 지연, 최대 처리량 등 관리자가 라우팅 메트릭 지정

AS분할 사용 - 자치 시스템을 지역으로 나누어 라우팅을 효과적으로 관리

홉 카운트 무제한 - 홉 카운트에 제한이 없다.

라우팅 : 어떤 네트워크 안에서 통신 데이터를 보낼 때 최적의 결로를 선택하는 과정입니다.

## 1. 문제에서 묻는 것
"대표적인 **내부 라우팅(IGP)** 프로토콜, **다익스트라 알고리즘**, **대규모** 네트워크, **링크 상태**" → 프로토콜 이름을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 라우팅과 라우팅 프로토콜
**라우팅**: 네트워크에서 데이터를 보낼 때 **최적의 경로를 선택**하는 과정. **라우터**들이 경로 정보를 서로 교환하는 규약이 **라우팅 프로토콜**.

### (2) IGP와 EGP
| 구분 | 범위 | 예 |
|---|---|---|
| **IGP** | **AS(자율 시스템) 내부** | RIP, **OSPF** |
| EGP | AS 간 | BGP |

### (3) OSPF (Open Shortest Path First)
| 특징 | 설명 |
|---|---|
| **링크 상태(Link State)** | 모든 라우터가 **전체 망의 지도(링크 상태)** 를 공유 |
| **다익스트라 알고리즘** | 지도를 바탕으로 **최단 경로** 계산 |
| **메트릭을 관리자가 지정** | 비용(최소 지연, 최대 처리량 등) 설정 가능 |
| **AS 분할(Area)** | 자치 시스템을 **지역(Area)** 으로 나눠 효율적 관리 → **대규모 망** 적합 |
| **홉 카운트 무제한** | RIP(최대 15홉)와 달리 제한 없음 |

## 3. 문제 풀이
| 단서 | OSPF |
|---|---|
| **내부 라우팅 프로토콜**(IGP) | ✅ |
| **다익스트라**, **링크 상태** | ✅ |
| **대규모 네트워크**에 적합 | ✅ |

> **정답: OSPF (Open Shortest Path First)**
