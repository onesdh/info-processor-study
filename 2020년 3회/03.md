# 문제 03

## 문제

대표적인 내부 라우팅 프로토콜로 다익스트라 알고리즘을 이용한 대규모 네트워크에 적합한 링크 상태 라우팅 프로토콜로 불리는 라우팅 프로토콜은 무엇인가?

<details>
<summary><strong>정답 보기</strong></summary>

OSPF(Open Shortest Path First)

OSPF(Open Shortest Path First)의 특징 :

다익스트라 알고리즘 사용 - 다익스트라 알고리즘 사용하는 내부 라우팅 프로토콜

라우팅 메트릭 지정 - 최소, 지연, 최대 처리량 등 관리자가 라우팅 메트릭 지정

AS분할 사용 - 자치 시스템을 지역으로 나누어 라우팅을 효과적으로 관리

홉 카운트 무제한 - 홉 카운트에 제한이 없다.

라우팅 : 어떤 네트워크 안에서 통신 데이터를 보낼 때 최적의 결로를 선택하는 과정입니다.

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

OSPF는 링크 상태 정보를 교환해 최단 경로를 계산하는 IGP다.

## 풀이

다익스트라 알고리즘과 계층적 영역 구조로 복잡하고 큰 네트워크에서 활용된다.

## 오답 분석

RIP은 홉 수 기반 거리 벡터 방식이며, BGP는 AS 사이의 외부 라우팅에 사용된다.

## 암기 포인트

링크 상태와 다익스트라는 OSPF.

</details>
