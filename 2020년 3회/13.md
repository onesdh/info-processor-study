# 문제 13 — C 함수 호출 반환값

## 문제

r1은 4를 반환하고 r10은 30+r1(), r100은 200+r10()을 반환한다. r100()의 출력값을 쓰시오.

## 정답

234

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

함수 호출을 안쪽부터 계산해 반환값을 합산한다.

## 풀이

r10=30+4=34이고 r100=200+34=234다.

## 오답 분석

함수 이름의 숫자 부분을 곱셈 인자로 보지 않는다.

## 암기 포인트

안쪽 34, 바깥 234.

</details>
