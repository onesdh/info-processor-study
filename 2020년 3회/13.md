# 문제 13

## 문제

다음은 C언어 소스 코드이다. 출력 결과를 쓰시오.

```
#include <studio.h>
int r1(){
	return 4;
}
int r10(){
	return (30+r1());
}
int r100(){
	return (200+r10());
}
int main(){
	printf("%d\n", r100());
    return 0;
}
```

<details>
<summary><strong>정답 보기</strong></summary>

234

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

함수 호출을 안쪽부터 계산해 반환값을 합산한다.

## 풀이

r10=30+4=34이고 r100=200+34=234다.

## 오답 분석

함수 이름의 숫자 부분을 곱셈 인자로 보지 않는다.

## 암기 포인트

안쪽 34, 바깥 234.

</details>
