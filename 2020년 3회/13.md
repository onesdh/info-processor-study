# 문제 13

## 문제

다음은 C언어 소스 코드이다. 출력 결과를 쓰시오.

```
#include <studio.h>
int r1(){
	return 4;
}
int r10(){
	return (30+r1());
}
int r100(){
	return (200+r10());
}
int main(){
	printf("%d\n", r100());
    return 0;
}
```

<details>
<summary><strong>정답 보기</strong></summary>

234

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**함수가 다른 함수를 호출하며 값을 더해 가는** 코드의 최종 출력을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 함수 호출과 반환
함수는 `return` 값을 호출한 곳에 돌려준다. 호출이 **끝까지 내려간 뒤 값이 위로 올라오며** 계산된다.

### (2) 구조
```c
int r1()   { return 4; }
int r10()  { return (30 + r1()); }
int r100() { return (200 + r10()); }
printf("%d\n", r100());
```
## 3. 실행 과정
```text
 r100() = 200 + r10()
                 r10() = 30 + r1()
                               r1() = 4
```
| 호출 | 계산 | 값 |
|---|---|---:|
| `r1()` | 4 | **4** |
| `r10()` | 30 + 4 | **34** |
| `r100()` | 200 + 34 | **234** |

> **정답: `234`**

## 4. 암기 포인트
- 안쪽 함수부터 값이 확정되어 바깥으로 올라온다.
- (원문의 `studio.h`는 `stdio.h`의 오타)
