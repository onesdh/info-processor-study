# 문제 16

## 문제

다음 중, 설명에 대한 괄호 ( ) 안에 들어갈 알맞는 보기를 고르시오.

(실제 기출문제에서는 답에 대한 보기 중, 영문 보기가 주어집니다.)

( ) 패턴은 객체지향 디자인 패턴이다.

( )는 부모(상위) 클래스에 알려지지 않은 구체 클래스를 생성하는 패턴이며,  
자식(하위) 클래스가 어떤 객체를 생성할지를 결정하도록 하는 패턴이기도 하다.

부모(상위) 클래스 코드에 구체 클래스 이름을 감추기 위한 방법으로도 사용한다.

<details>
<summary><strong>정답 보기</strong></summary>

Factory method

</details>

<summary><strong>상세 해설</strong></summary>

## 핵심 개념

팩토리 메서드는 객체 생성 책임을 하위 클래스에 위임해 생성 코드와 구체 제품을 분리한다.

## 풀이

상위 클래스는 생성 인터페이스를 정의하고 하위 클래스가 실제 제품 객체 생성을 선택한다.

## 오답 분석

Abstract Factory는 관련 객체군을 생성하는 인터페이스를 제공한다. 문제의 객체 생성 결정을 하위 클래스에 맡기는 것은 Factory Method다.

## 암기 포인트

객체 생성 결정을 하위 클래스에 위임.
