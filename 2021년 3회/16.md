# 문제 16

## 문제

다음 중, 설명에 대한 괄호 ( ) 안에 들어갈 알맞는 보기를 고르시오.

(실제 기출문제에서는 답에 대한 보기 중, 영문 보기가 주어집니다.)

( ) 패턴은 객체지향 디자인 패턴이다.

( )는 부모(상위) 클래스에 알려지지 않은 구체 클래스를 생성하는 패턴이며,  
자식(하위) 클래스가 어떤 객체를 생성할지를 결정하도록 하는 패턴이기도 하다.

부모(상위) 클래스 코드에 구체 클래스 이름을 감추기 위한 방법으로도 사용한다.

Factory method

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
"**부모 클래스에 알려지지 않은 구체 클래스를 생성**, **자식 클래스가 어떤 객체를 생성할지 결정**" → 어떤 디자인 패턴인지 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 팩토리 메소드(Factory Method) — 생성 패턴
**객체 생성을 위한 인터페이스(메서드)를 부모 클래스에 정의**하고, **어떤 구체 클래스의 객체를 만들지는 자식 클래스가 결정**하게 한다. 부모 코드에 **구체 클래스 이름이 드러나지 않는다.**
```text
          ┌──── Creator (부모) ────┐
          │ createProduct() : Product  ← 생성을 자식에 위임 (추상)
          └──────▲────────────▲────┘
                 │            │
        ConcreteCreatorA  ConcreteCreatorB
        createProduct() →  ProductA   createProduct() → ProductB
```
- 별칭: **Virtual Constructor**(가상 생성자)
- 효과: 부모는 `Product` 인터페이스만 알고 **구체 클래스에 의존하지 않는다.** 새 제품 추가 시 **새 Creator 서브클래스만 추가**.

### (2) 추상 팩토리와 구분
| 패턴 | 생성 대상 | 별칭 |
|---|---|---|
| **팩토리 메소드** | **한 종류**의 객체, **자식 클래스가 결정** | Virtual Constructor |
| 추상 팩토리 | **관련 객체의 제품군**(여러 종류) | **Kit** |

## 3. 문제 풀이
| 단서 | Factory Method |
|---|---|
| **부모 클래스에 알려지지 않은 구체 클래스**를 생성 | ✅ |
| **자식 클래스가 어떤 객체를 생성할지 결정** | ✅ |
| 부모 코드에서 **구체 클래스 이름을 감춤** | ✅ |

> **정답: Factory Method (팩토리 메소드)**
