# 문제 17

## 문제

다음 C언어에 대한 알맞는 출력값을 쓰시오.

```
#include <stdio.h>

struct jsu {
  char name[12];
  int os, db, hab, hhab;
};

int main(){
struct jsu st[3] = {{"데이터1", 95, 88},
                    {"데이터2", 84, 91},
                    {"데이터3", 86, 75}};
struct jsu* p;

p = &st[0];

(p + 1)->hab = (p + 1)->os + (p + 2)->db;
(p + 1)->hhab = (p+1)->hab + p->os + p->db;

printf("%d\n", (p+1)->hab + (p+1)->hhab);
}

```

<details>
<summary><strong>정답 보기</strong></summary>

501

jsu에는 {name, os, db, hab, hhab} 이런형태의 데이터가 들어가 있습니다.

p = &st[0]; :  
p = {"데이터1", 95, 88}

(p+1)→hab = (p+1)→os + (p+2)→db; :  
(p+1) = {"데이터2", 84, 91}, (p+2) = {"데이터3", 86, 75}  
(p+1)→os + (p+2)→db : 84 + 75 = 159

(p+1)→hhab = (p+1)→hab + p→os + p→db; :  
(p+1)→hab + p→os + p→db : 159 + 95 + 88 = 342

printf("%d", (p+1)→hab + (p+1)→hhab) :  
(p+1)→hab + (p+1)→hhab : 159 + 342 = 501

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

포인터 p가 st[0]을 가리키면 p+1은 st[1], p+2는 st[2]를 가리킨다.

## 풀이

hab=84+75=159다. hhab=159+95+88=342이고 최종합은 159+342=501이다.

## 오답 분석

각 포인터 이동이 구조체 배열의 다음 원소를 뜻한다. 초기 구조체 선언의 값과 새로 계산되는 필드를 구분한다.

## 암기 포인트

p+1은 둘째 구조체, p+2는 셋째 구조체.

</details>
