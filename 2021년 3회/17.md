# 문제 17

## 문제

다음 C언어에 대한 알맞는 출력값을 쓰시오.

```
#include <stdio.h>

struct jsu {
  char name[12];
  int os, db, hab, hhab;
};

int main(){
struct jsu st[3] = {{"데이터1", 95, 88},
                    {"데이터2", 84, 91},
                    {"데이터3", 86, 75}};
struct jsu* p;

p = &st[0];

(p + 1)->hab = (p + 1)->os + (p + 2)->db;
(p + 1)->hhab = (p+1)->hab + p->os + p->db;

printf("%d\n", (p+1)->hab + (p+1)->hhab);
}

```

<details>
<summary><strong>정답 보기</strong></summary>

501

jsu에는 {name, os, db, hab, hhab} 이런형태의 데이터가 들어가 있습니다.

p = &st[0]; :  
p = {"데이터1", 95, 88}

(p+1)→hab = (p+1)→os + (p+2)→db; :  
(p+1) = {"데이터2", 84, 91}, (p+2) = {"데이터3", 86, 75}  
(p+1)→os + (p+2)→db : 84 + 75 = 159

(p+1)→hhab = (p+1)→hab + p→os + p→db; :  
(p+1)→hab + p→os + p→db : 159 + 95 + 88 = 342

printf("%d", (p+1)→hab + (p+1)→hhab) :  
(p+1)→hab + (p+1)→hhab : 159 + 342 = 501

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**구조체 배열과 포인터 연산**(`p + 1`)으로 멤버를 읽고 쓰는 코드를 따라가는 문제다. 초기값을 일부만 준 구조체 멤버는 **0으로 초기화**된다는 점에 주의한다.

## 2. 먼저 알아야 할 개념
### (1) 구조체 배열과 초기화
```c
struct jsu { char name[12]; int os, db, hab, hhab; };
struct jsu st[3] = {{"데이터1", 95, 88}, {"데이터2", 84, 91}, {"데이터3", 86, 75}};
```
앞에서부터 `name, os, db`만 지정하면 **나머지(`hab`, `hhab`)는 자동으로 0**.
| 요소 | name | os | db | hab | hhab |
|---|---|---:|---:|---:|---:|
| st[0] | 데이터1 | 95 | 88 | 0 | 0 |
| st[1] | 데이터2 | 84 | 91 | 0 | 0 |
| st[2] | 데이터3 | 86 | 75 | 0 | 0 |

### (2) 구조체 포인터 연산
- `p = &st[0]` → p는 st[0]을 가리킴
- `p + 1` → **다음 구조체**(st[1]), `p + 2` → st[2]
- `(p + 1)->os` = `st[1].os`

## 3. 실행 과정
**① `(p + 1)->hab = (p + 1)->os + (p + 2)->db;`**
= `st[1].os + st[2].db` = 84 + 75 = **159** → `st[1].hab = 159`

**② `(p + 1)->hhab = (p + 1)->hab + p->os + p->db;`**
= `st[1].hab + st[0].os + st[0].db` = 159 + 95 + 88 = **342** → `st[1].hhab = 342`

**③ 출력** `(p + 1)->hab + (p + 1)->hhab` = 159 + 342 = **501**

| 단계 | 식 | 값 |
|---|---|---:|
| st[1].hab | 84 + 75 | 159 |
| st[1].hhab | 159 + 95 + 88 | 342 |
| 출력 | 159 + 342 | **501** |

> **정답: `501`**

## 4. 암기 포인트
- `p + n`은 **구조체 크기 단위**로 n칸 이동.
- 표를 먼저 만들고 어떤 요소를 가리키는지 확인한 뒤 계산한다.
