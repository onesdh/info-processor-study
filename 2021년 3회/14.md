# 문제 14

## 문제

다음 파이썬 코드이다. 알맞는 출력값을 쓰시오.

```
a,b = 100, 200
print(a==b)
```

<details>
<summary><strong>정답 보기</strong></summary>

False

여기서는 앞글자를 대문자로 표기하는 것이 포인트입니다.

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
파이썬의 **비교 연산** `a == b`의 결과(**불리언 값**)와 그 **출력 표기**를 묻는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 다중 대입
```python
a, b = 100, 200      # a = 100, b = 200 을 한 줄에 대입
```
### (2) 비교 연산자와 불리언
| 연산 | 의미 | 결과 |
|---|---|---|
| `a == b` | 같은가? | `100 == 200` → **False** |
| `a != b` | 다른가? | True |

### (3) 불리언의 표기
파이썬의 불리언 값은 **`True` / `False`** (**첫 글자가 대문자**)이다. `true`, `false`로 쓰면 오류(정의되지 않은 이름).

## 3. 실행
`print(a == b)` → `100 == 200` → 거짓 → **`False`** 출력

> **정답: `False`** (첫 글자 대문자!)

## 4. 암기 포인트
- 파이썬: **True / False / None** (대문자 시작). Java·C와 표기가 다르다.

</details>
