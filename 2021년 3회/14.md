# 문제 14 — Python 동등 비교

## 문제

a,b=100,200으로 대입한 뒤 print(a==b)를 실행한 결과를 쓰시오.

## 정답

False

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

==는 두 값이 같은지 비교하는 동등 연산자다.

## 풀이

100과 200은 같지 않으므로 False를 출력한다.

## 오답 분석

대입 연산자 = 와 비교 연산자 ==를 구분한다.

## 암기 포인트

같지 않으므로 False.
