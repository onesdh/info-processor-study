# 문제 02

## 문제

다음은 정보 보호 기술인 AAA에 대한 설명이다. 각 설명에 맞는 답을 고르시오

(실제 기출문제에서는 답의 보기 중, A에 대한 보기가 주어집니다.(오답 중, Application 등..))

1. 시스템을 접근하기 전에 접근 시도하는 사용자의 신원을 검증

2. 검증된 사용자에게 어떤 수준의 권한과 서비스를 허용

3. 사용자의 자원(시간,정보,위치 등)에 대한 사용 정보를 수집

<details>
<summary><strong>정답 보기</strong></summary>

1.Authentication

2.Authorization

3.Accounting

AAA는 유무선 이동 및 인터넷 환경에서 가입자에 대한 안전하고,  
신뢰성 있는 인증, 권한 검증 등의 기능을 체계적으로 제공하는 정보 보호 기술입니다.

신분을 확인하는 인증(authentication)  
접근·허가를 결정하는 인가(authorization)  
리소스 사용정보를 수집·관리하는 계정(accounting)

위의 3가지를 통합한 보안소프트웨어로 3A라고도 합니다.

## 1. 문제에서 묻는 것
정보 보호 기술 **AAA(3A)** 의 세 요소를 설명과 연결하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) AAA
사용자가 시스템에 접근해 사용하는 **전 과정을 보안 관점에서 관리**하는 세 단계.
```text
 [사용자] ─① 인증 ─▶ ─② 인가 ─▶ ─③ 과금/기록 ─▶ 사용
  "누구세요?"       "뭘 할 수 있어요?"   "무엇을 얼마나 썼는지 기록"
```
| 요소 | 영문 | 의미 | 질문 |
|---|---|---|---|
| **인증** | **Authentication** | 접근하려는 사용자의 **신원을 검증** (ID/PW, OTP, 생체) | **누구**인가? |
| **인가(권한 부여)** | **Authorization** | 검증된 사용자에게 **어떤 수준의 권한·서비스를 허용**할지 결정 | **무엇을 할 수 있나?** |
| **계정(과금)** | **Accounting** | 사용자의 **자원 사용 정보**(시간, 정보, 위치 등)를 **수집·기록** | **무엇을 얼마나 썼나?** |

### (2) 예시: 와이파이/사내망 접속
- 인증: 아이디·비밀번호로 로그인
- 인가: 게스트는 인터넷만, 직원은 사내 서버까지 허용
- 계정: 접속 시간·사용량 로그 기록(과금·감사)

### (3) 구현 프로토콜
**RADIUS**, **Diameter**, TACACS+ 가 AAA를 제공한다.

## 3. 문제 풀이
| 번호 | 단서 | 정답 |
|---|---|---|
| 1 | 접근 **전에** 사용자의 **신원을 검증** | **Authentication** |
| 2 | 검증된 사용자에게 **어떤 수준의 권한·서비스를 허용** | **Authorization** |
| 3 | 사용자의 **자원 사용 정보를 수집** | **Accounting** |

> **정답: 1. Authentication 2. Authorization 3. Accounting**

## 4. 암기 포인트
- **인증(누구) → 인가(무엇을 할 수 있나) → 계정(무엇을 했나)**.
- 인증과 인가를 혼동하지 말 것: 인증은 신원, 인가는 권한.
