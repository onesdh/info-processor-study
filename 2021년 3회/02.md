# 문제 02 — AAA 보안 기능

## 문제

사용자 신원 확인, 검증된 사용자에게 권한 부여, 자원 사용 내역 수집을 순서대로 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

Authentication; Authorization; Accounting

</details>

<details>
<summary><strong>해설</strong></summary>

## 핵심 개념

AAA는 인증, 인가, 계정관리 기능을 묶어 접근 통제와 사용 추적을 제공한다.

## 풀이

신원을 확인하는 것은 Authentication, 권한 허용은 Authorization, 사용 기록 수집은 Accounting이다.

## 오답 분석

Application은 AAA의 세 기능에 포함되지 않는다. 인증과 인가는 각각 신원과 허용 범위라는 다른 단계다.

## 암기 포인트

AAA는 인증·인가·계정.

</details>
