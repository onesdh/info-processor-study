# 문제 05

## 문제

한 모듈이 다른 모듈의 내부 논리 흐름을 제어하는 신호나 플래그를 전달하는 결합도를 영문으로 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

Control Coupling

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

제어 결합도는 한 모듈이 전달한 제어 정보에 따라 다른 모듈의 수행 경로가 달라지는 결합이다.

## 풀이

상위 모듈이 하위 모듈에 플래그를 전달해 특정 분기를 선택하게 하는 경우가 예다.

## 오답 분석

자료 결합도는 필요한 데이터 값만 전달해 비교적 약하다. 내부 구현을 제어하는 값이 전달되면 제어 결합도다.

## 암기 포인트

제어 신호로 동작을 지시하는 Control Coupling.
