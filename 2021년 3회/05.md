# 문제 05

## 문제

다음은 Coupling에 대한 설명이다. 설명에 대한 Coupling 종류를 영문으로 작성하시오.

어떤 모듈이 다른 모듈의 내부 논리 조직을 제어하기 위한 목적으로 제어 신호를 이용하여 통신하는 경우의 결합도

하위 모듈에서 상위 모듈로 제어 신호가 이동하여 상위 모듈에게 처리 명령을 부여하는 권리 전도 현상이 발생

## 1. 문제에서 묻는 것
"다른 모듈의 **내부 논리를 제어하기 위해 제어 신호**를 통신", "하위 모듈에서 상위 모듈로 제어 신호가 이동하여 **상위 모듈에게 처리 명령**을 부여하는 **권리 전도 현상**" → 결합도 종류를 영문으로 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 결합도(Coupling)
모듈 간 **의존 정도**. **낮을수록 좋다.**
```text
 자료(Data) < 스탬프(Stamp) < 제어(Control) < 외부(External) < 공통(Common) < 내용(Content)
 (약함, 좋음)                                                           (강함, 나쁨)
```
| 영문 | 한글 | 설명 |
|---|---|---|
| Data | 자료 | 필요한 **값만** 전달 |
| Stamp | 스탬프 | **구조체·배열** 등 자료구조 전달 |
| **Control** | **제어** | **제어 신호(플래그)** 로 상대 모듈의 내부 논리 흐름을 제어 |
| External | 외부 | 외부 형식·인터페이스 공유 |
| Common | 공통 | **전역 변수** 공유 |
| Content | 내용 | 다른 모듈 **내부 직접 참조/수정** |

### (2) 제어 결합도
```c
void process(int mode) { if (mode == 1) A(); else B(); }   // 호출자가 mode로 내부 분기를 지시
```
- 호출하는 모듈이 **상대 모듈의 내부 처리 절차를 알아야** 한다.
- **권리 전도(inversion of authority)**: 하위 모듈이 제어 신호를 올려 상위 모듈이 해야 할 **처리 명령을 하위가 결정**하게 되는 현상.

## 3. 문제 풀이
| 단서 | Control Coupling |
|---|---|
| 다른 모듈의 **내부 논리 조직을 제어**하려는 **제어 신호** 통신 | ✅ |
| 하위→상위로 **제어 신호**, **권리 전도** 현상 | ✅ |

> **정답: Control (Control Coupling, 제어 결합도)**

## 4. 암기 포인트
- 결합도 순서(약→강): **자료 → 스탬프 → 제어 → 외부 → 공통 → 내용**.
- 영어 용어도 같이: Data, Stamp, **Control**, External, Common, Content.
