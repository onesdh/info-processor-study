# 문제 20 — 상향식 통합 테스트

## 문제

하위 모듈부터 상위 모듈로 통합하는 테스트 방식과 아직 준비되지 않은 상위 모듈의 호출 역할을 하는 보조 도구를 쓰시오.



## 정답

상향식; 테스트 드라이버

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

상향식 통합은 하위 모듈부터 검증하며 상위 모듈이 완성되기 전에는 드라이버가 호출을 제공한다.

## 풀이

첫 빈칸은 상향식, 두 번째는 테스트 드라이버다.

## 오답 분석

하향식 통합에서는 미완성 하위 모듈을 대신하는 스텁을 사용한다.

## 암기 포인트

상향식은 드라이버, 하향식은 스텁.

</details>
