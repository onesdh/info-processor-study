# 문제 07

## 문제

다음 중, 설명에 대한 괄호 ( ) 안에 들어갈 알맞는 보기를 고르시오.

(실제 기출문제에서는 답에 대한 영어용어의 보기가 주어집니다.)

눈에 보이지 않는 것을 개념적으로 표현하는 것이 '추상화'라하며,  
이는 실세계의 복잡한 상황을 간결하고 명확하게 개념화(槪念化)하는 것이다.

(  1  )은 클래스들 사이의 전체 또는 부분 같은 관계를 나타내는 것이고,

(  2  )은 한 클래스가 다른 클래스를 포함하는 상위 개념일 때 IS-A관계라하며, 일반화 관계로 모델링한다.

UML :

UML(Unified Modeling Language)는 통합 모델링 언어라 불리며,

&nbsp;시스템을 모델로 표현해주는 대표적인 모델링 언어입니다.

UML 다이어그램 종류

1. 구조 다이어그램 (Structure Diagram)

(1) 클래스 다이어그램 (이곳에 해당됩니다.)

(2) 객체 다이어그램

(3) 복합체 구조 다이어그램

(4) 배치 다이어그램

(6) 패키지 다이어그램

2. 행위 다이어그램 (Behavior Diagram)

(1) 활동 다이어그램

(2) 상태 머신 다이어그램

(3) 유즈 케이스 다이어그램

(4) 상호작용 다이어그램

클래스 다이어그램 (Class Diagram) :

시간에 따라 변하지 않는 시스템의 정적인 면을 보여주는 대표적인 UML 구조 다이어그램이며,

시스템을 구성하는 클래스들 사이의 관계를 표현합니다.

UML에서 제공하는 클래스 사이의 관계 :

(1) 연관 관계 (association) : 클래스들이 개념상 서로 연결되어 있음을 나타냅니다.

(2) 일반화 관계 (generalization) : 상속 관계를 설명합니다. (위 문제 참조)

(3) 집합관계 :

1) 집약 관계(aggregation) : 클래스 사이의 전체 또는 부분 같은 관계를 나타냅니다. (객체 라이프 타임 : 독립적)

2) 합성 관계 (composition) : 클래스 사이의 전체 또는 부분 같은 관계를 나타냅니다. (객체 라이프 타임 : 의존적)

(4) 의존 관계 (dependency) : 연관 관계와 같이 한 클래스가 다른 클래스에서 제공하는 기능을 사용합니다.

(5) 실체화 관계 (realization) : 인터페이스와 구현 클래스 사이의 관계를 나타냅니다.

## 1. 문제에서 묻는 것
UML **클래스 다이어그램**의 관계 중 **집약(Aggregation)** 과 **일반화(Generalization)** 를 구분하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 클래스 사이의 관계
| 관계 | 표기 | 의미 |
|---|---|---|
| **연관(Association)** | 실선 | 클래스들이 개념상 연결됨 |
| **일반화(Generalization)** | 속 빈 삼각형 화살표(자식→부모) | **IS-A** (상속), 한 클래스가 다른 클래스를 **포함하는 상위 개념** |
| **집약(Aggregation)** | **속 빈 마름모** ◇ | **전체-부분** 관계, 부분이 **독립적**으로 존재 가능 |
| **합성(Composition)** | **속이 찬 마름모** ◆ | 전체-부분 관계, 부분이 전체에 **종속**(전체가 사라지면 같이 소멸) |
| **의존(Dependency)** | 점선 화살표 | 일시적 사용 |
| 실체화(Realization) | 점선+속 빈 삼각형 | 인터페이스 구현 |

### (2) 비교 그림
```text
 집약 (팀 ◇── 선수) : 팀이 해체되어도 선수는 존재한다 (라이프타임 독립)
 합성 (집 ◆── 방)   : 집이 사라지면 방도 사라진다   (라이프타임 종속)
 일반화 (동물 ◁── 개): 개 IS-A 동물                 (상속)
```
## 3. 문제 풀이
| 번호 | 설명 | 정답 |
|---|---|---|
| 1 | 클래스들 사이의 **전체 또는 부분** 같은 관계 | **Aggregation** (집약) |
| 2 | 한 클래스가 다른 클래스를 **포함하는 상위 개념**, **IS-A** 관계, **일반화** | **Generalization** |

> **정답: 1. Aggregation 2. Generalization**

## 4. 암기 포인트
- **IS-A = 일반화(상속)**, **HAS-A = 집약/합성(전체-부분)**.
- 집약(◇)은 독립, 합성(◆)은 종속.
