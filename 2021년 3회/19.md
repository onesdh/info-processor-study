# 문제 19

## 문제

사용자가 아이콘과 메뉴 같은 그래픽을 통해 컴퓨터와 정보를 교환하는 환경을 영문 약자로 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

GUI (Graphical User Interface)

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

GUI는 화면의 창, 메뉴, 아이콘, 포인터 등 그래픽 요소를 이용해 상호작용하는 사용자 인터페이스다.

## 풀이

Windows나 macOS 같은 데스크톱 환경이 대표적이다.

## 오답 분석

CLI는 명령어를 입력하는 방식이고 NUI는 말이나 동작 등 자연스러운 입력을 강조한다.

## 암기 포인트

그래픽 사용자 인터페이스는 GUI.
