# 문제 09

## 문제

다음 중, 설명에 대한 괄호 ( ) 안에 들어갈 알맞는 보기를 고르시오.

(실제 기출문제에서는 답에 대한 보기 중, 영문 보기가 주어집니다.)

(  ) 통해 요구사항 명세를 입력 조건과 출력 조건 간의 논리적 관계로 표현하고,

이를 기반으로 테스트케이스를 도출한다.

(  )의 ‘원인(causes)’은 입력 조건을 의미하고 ‘결과(effects)’는 입력 조건의 결과를 의미하며,  
원인과 결과 간의 논리적 관계를 AND, OR, NOT 같은 boolean 연산자를 사용하여 표현한다.

## 1. 문제에서 묻는 것
"**입력 조건과 출력 조건 간의 논리적 관계**로 요구사항 명세를 표현, **원인(causes)·결과(effects)**, AND/OR/NOT" → 어떤 블랙박스 테스트 기법인지 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 원인-결과 그래프(Cause-Effect Graph) 기법
입력 조건(**원인**)과 그에 따른 출력(**결과**) 사이의 **논리 관계**를 **그래프**로 그리고, 이를 **결정 테이블**로 바꿔 **테스트 케이스를 도출**하는 블랙박스 기법이다.
```text
 원인1(입력A) ──AND──┐
                      ├──▶ 결과1
 원인2(입력B) ──────┘
 원인3 ──NOT──▶ 결과2
```
- 원인 = **입력 조건**, 결과 = 입력 조건에 따른 **출력(결과)**
- 관계 표현: **AND, OR, NOT** 같은 **불리언 연산자**
- 여러 입력 조합이 복잡할 때 **빠짐없이 조합**을 검토하도록 돕는다.

### (2) 테스트 기법 분류
| 구분 | 기법 |
|---|---|
| **블랙박스(명세 기반)** | 동등(동치) 분할, **경계값 분석**, **원인-결과 그래프**, 의사결정(결정) 테이블, 상태 전이, 오류 예측 |
| **화이트박스(구현 기반)** | 문장·분기·조건·분기/조건·다중 조건 커버리지, 기본 경로 테스트 |

## 3. 문제 풀이
| 단서 | Cause-Effect Graph |
|---|---|
| 요구사항 명세를 **입력 조건과 출력 조건 간의 논리 관계**로 표현 | ✅ |
| **원인(입력 조건)·결과(출력 결과)** | ✅ |
| **AND, OR, NOT** 불리언 연산자로 관계 표현, 테스트 케이스 도출 | ✅ |

> **정답: cause effect graph (원인-결과 그래프)**
