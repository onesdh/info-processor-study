# 문제 09 — 원인-결과 그래프

## 문제

입력 조건과 출력 결과의 논리적 관계를 AND, OR, NOT으로 표현해 테스트 케이스를 도출하는 기법을 쓰시오.

원인-결과 그래프 (Cause-Effect Graph)

</details>

## 핵심 개념

원인-결과 그래프는 입력 조건을 원인, 출력 결과를 효과로 보고 논리 관계를 모델링하는 명세 기반 테스트 기법이다.

## 풀이

원인과 결과 사이의 조합 관계를 그래프로 정리한 뒤 테스트 케이스를 만든다.

## 오답 분석

분기 커버리지는 코드 실행 경로를 확인하는 화이트박스 기법이다. 원인-결과 그래프는 요구 명세를 바탕으로 한다.

## 암기 포인트

입력 원인과 출력 효과를 연결.
