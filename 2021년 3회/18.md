# 문제 18

## 문제

다음은, 파일 구조(File Structures)에 대한 설명이다. 괄호 ( ) 안에 들어갈 알맞는 답을 작성하시오.

파일구조는 파일을 구성하는 레코드들이 보조기억장치에 편성되는 방식으로 접근 방식에 따라 방식이 달라진다.

접근 방법중, 레코드들을 키-값 순으로 정렬하여 기록하고, 레코드의 키 항목만을 모은 (  )을 구성하여 편성하는 방식이 있으며, 레코드를 참조할 때는 (   ) 이 가르키는 주소를 사용하여 직접 참조할 수 있다. 파일 구조에는 순차 접근, (  ) 접근,  해싱 접근이 있다.

## 1. 문제에서 묻는 것
"키 항목만 모은 ( )을 구성", "( )이 가르키는 주소로 직접 참조", 접근 방식: 순차, ( ), 해싱 → **인덱스(색인)** 를 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 파일 구조(접근 방식)
보조기억장치(디스크)에 저장된 **레코드를 찾아가는 방법**이다.

| 방식 | 동작 | 책으로 비유 |
|---|---|---|
| **순차 접근** | **처음부터 차례로** 검사 | 첫 장부터 넘겨 보기 |
| **인덱스(색인) 접근** | 레코드의 **키 항목만 모은 색인**을 만들어 **키 → 주소(포인터)** 로 직접 접근 | **색인(찾아보기)** 에서 쪽 번호 확인 |
| **해싱 접근** | **해시 함수**로 키 → 주소를 계산 | 단어를 보고 계산해 바로 이동 |

### (2) 인덱스 파일
```text
 인덱스(키, 주소)                  데이터 파일(키 순 정렬)
 ┌────┬───────┐                   ┌─────────────┐
 │ 10 │ ─────┼─────────────────▶ │ 레코드(키10) │
 │ 20 │ ─────┼─────────────────▶ │ 레코드(키20) │
 └────┴───────┘                   └─────────────┘
```
레코드를 **키 값 순으로 정렬**해 기록하고, **키만 모은 인덱스**에서 **포인터가 가리키는 주소**로 바로 접근한다.

## 3. 문제 풀이
| 단서 | 인덱스 |
|---|---|
| **키 항목만을 모은** ( ) 구성, 키-값 순 정렬 | ✅ |
| ( )이 **가리키는 주소**로 레코드에 **직접 참조** | ✅ |
| 접근 방식: 순차 / **( )** / 해싱 | ✅ |

> **정답: 인덱스 (색인)**

## 4. 암기 포인트
- 접근 방식 3가지: **순차, 인덱스, 해싱**.
- 2025년 2회 1번과 같은 개념.
