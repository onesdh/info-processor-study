# 문제 18 — 인덱스 순차 접근 파일

## 문제

정렬된 키 레코드에서 키 항목을 모아 직접 참조용 주소를 제공하고, 순차·( )·해싱 접근 방식으로 나뉘는 파일 접근 방법을 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

인덱스 접근 (색인 접근)

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

인덱스 접근은 키와 레코드 주소를 연결한 색인을 이용해 원하는 레코드를 찾는다.

## 풀이

파일 구조에서 순차 접근, 인덱스 접근, 해싱 접근을 대표적인 접근 방식으로 분류한다.

## 오답 분석

해싱은 해시 함수로 주소를 계산하고, 순차는 저장 순서대로 읽는다.

## 암기 포인트

키 색인으로 바로 찾는 인덱스 접근.

</details>
