# 문제 01

## 문제

다음 Java 코드에 대한 알맞는 출력값을 쓰시오.

```
class Connection {
  private static Connection _inst = null;
  private int count = 0;
    static public Connection get() {
      if(_inst == null) {
      _inst = new Connection();
      return _inst;
      }
    return _inst;
    }
  public void count() { count ++; }
  public int getCount() { return count; }
}

public class testcon {
  public static void main(String[] args) {
    Connection conn1 = Connection.get();
    conn1.count();
    Connection conn2 = Connection.get();
    conn2.count();
    Connection conn3 = Connection.get();
    conn3.count();

    System.out.print(conn1.getCount());
  }
}

```

<details>
<summary><strong>정답 보기</strong></summary>

3

1.

conn1을 생성하여 Connection.get()을 호출할 때,

\_inst는 null이므로 Connection() 객체를 생성합니다.  
(객체를 생성하면 인스턴스를 생성하고 참조값을 return하기 때문에

여기서 부터는 \_inst가 null이 아니게 됩니다.)  
conn1.count() 는 0에서 count++ 하므로 1이 됩니다.

2.

conn2를 생성하고 다시 get()을 호출하면 \_inst는 null이 아니기 때문에

객체를 생성하지 않고 count 값을 그대로 가지고 갑니다.  
그래서 conn2.count() 는 1에서 count++ 하므로 2가 됩니다.

3. conn3.count()도 마찬가지로 위의 시스템처럼 진행되므로  2에서 count++로 3이 됩니다.

<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**싱글톤(Singleton)** 패턴에서 `get()`을 여러 번 호출해도 **같은 객체**가 반환되므로, `count()`를 세 번 호출한 결과가 누적되는지 묻는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 싱글톤 패턴 (생성 패턴)
클래스의 **인스턴스를 오직 1개만** 만들어 **어디서든 같은 객체**를 쓰게 한다.
```java
class Connection {
    private static Connection _inst = null;    // 유일한 객체를 저장할 static 변수
    static public Connection get() {
        if (_inst == null) {                    // 처음 한 번만 생성
            _inst = new Connection();
        }
        return _inst;                           // 이후엔 같은 객체를 반환
    }
}
```
```text
 conn1 ─┐
 conn2 ─┼──▶ [ Connection 객체 하나 ]  (count 를 공유)
 conn3 ─┘
```
## 3. 실행 과정
| 단계 | 코드 | 객체 | count |
|---|---|---|---:|
| ① | `conn1 = Connection.get()` | `_inst`가 null → **새 객체 생성** | 0 |
| ② | `conn1.count()` | | 1 |
| ③ | `conn2 = Connection.get()` | `_inst`가 이미 있음 → **같은 객체 반환** | 1 |
| ④ | `conn2.count()` | | 2 |
| ⑤ | `conn3 = Connection.get()`, `conn3.count()` | 같은 객체 | **3** |

`conn1.getCount()` → 같은 객체이므로 **3**

> **정답: `3`**

## 4. 암기 포인트
- 싱글톤은 객체가 하나라서 어느 변수로 호출해도 **하나의 count가 누적**된다.
- 2024년 1회 1번과 같은 구조(그쪽은 `count()`를 4번 호출 → 4).
