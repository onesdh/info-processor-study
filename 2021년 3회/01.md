# 문제 01

## 문제

Connection.get()이 단일 인스턴스를 반환하고 세 참조에서 count()를 한 번씩 호출한다. conn1.getCount()의 출력값을 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

3

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

싱글턴은 클래스의 인스턴스를 하나만 만들고 여러 호출자가 같은 인스턴스를 공유하도록 한다.

## 풀이

첫 호출이 인스턴스를 만들고 세 참조 모두 같은 객체를 가리킨다. count 필드는 공유되므로 0에서 세 번 증가해 3이다.

## 오답 분석

참조 변수가 셋이라고 객체가 세 개 생기는 것이 아니다. static 필드 _inst가 객체 하나를 보관한다.

## 암기 포인트

Singleton은 단일 객체를 공유.
