# 문제 03

## 문제

Grant의 기능에 대해 간략하게 약술하시오.

<details>
<summary><strong>정답 보기</strong></summary>

사용자(User)에게 접속권한, 오브젝트 생성권한, DBA 권한 등을 부여할 수 있는 명령어

Grant는 사용자에게 접속권한, 오브젝트 생성권한, DBA 권한 등을 부여할 수 있는 명령어이며,  
Revoke는 사용자에게 부여한 권한을 다시 회수하는 명령어입니다.

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
SQL의 **GRANT 명령어의 기능**을 간략히 서술하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) DCL (Data Control Language, 데이터 제어어)
데이터베이스 **접근 권한을 제어**하는 SQL 명령.
| 명령 | 기능 |
|---|---|
| **GRANT** | 사용자에게 **권한을 부여** |
| **REVOKE** | 사용자에게서 **권한을 회수** |

### (2) GRANT 문법
```sql
GRANT 권한 ON 객체 TO 사용자 [WITH GRANT OPTION];
-- 예) GRANT SELECT, INSERT ON 학생 TO user1;
```
- **권한 종류**: 접속 권한(CONNECT), 객체 생성 권한(CREATE TABLE 등), 조회·삽입·수정·삭제 권한(SELECT/INSERT/UPDATE/DELETE), **DBA 권한** 등.
- `WITH GRANT OPTION`: 받은 권한을 **다른 사용자에게 다시 부여**할 수 있게 함.

### (3) 함께 외우는 SQL 분류
| 분류 | 명령 |
|---|---|
| DDL | CREATE, ALTER, DROP |
| DML | SELECT, INSERT, UPDATE, DELETE |
| **DCL** | **GRANT, REVOKE** |
| TCL | COMMIT, ROLLBACK |

## 3. 서술 답안
> **GRANT는 데이터베이스 사용자(User)에게 접속 권한, 객체(테이블 등) 생성·조회·수정 권한, DBA 권한 등을 부여하는 DCL 명령어이다.** (회수는 REVOKE)

## 4. 암기 포인트
- **GRANT = 권한 부여, REVOKE = 권한 회수** (둘 다 DCL).
