# 문제 03 — GRANT

## 문제

데이터베이스 사용자에게 접속, 객체 생성, DBA 권한 등을 부여하는 SQL 명령어의 기능을 설명하시오.

## 정답

사용자에게 데이터베이스 권한을 부여하는 명령어

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

GRANT는 사용자나 역할에 객체 또는 시스템 권한을 부여한다.

## 풀이

예를 들어 특정 테이블에 대한 SELECT 권한이나 접속 권한을 부여한다.

## 오답 분석

REVOKE는 이미 부여한 권한을 회수한다.

## 암기 포인트

권한을 주는 GRANT, 회수하는 REVOKE.
