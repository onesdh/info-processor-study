# 문제 11

## 문제

다음 Java 코드에 대한 알맞는 출력값을 쓰시오.

```
public class testco {
 public static void main(String[] args) {
  int a = 3, b = 4, c = 3, d = 5;
  if((a == 2 | a == c) & !(c > d) & (1 == b ^ c != d)) {
   a = b + c;
    if(7 == b ^ c != a) {
     System.out.println(a);
    } else {
    System.out.println(b);
    }
  } else {
    a = c + d;
    if(7 == c ^ d != a) {
    System.out.println(a);
    } else {
    System.out.println(d);
    }
  }
 }
}

```

## 1. 문제에서 묻는 것
**논리 연산자와 비트 연산자(`&`, `|`, `^`)** 가 섞인 복잡한 조건식을 **정확히 평가**하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 연산자 의미 (참/거짓 값에 적용)
| 연산자 | 이름 | 결과 |
|---|---|---|
| `&` | AND | **둘 다 참**이면 참 |
| `\|` | OR | **하나라도 참**이면 참 |
| `^` | **XOR** | **두 값이 서로 다르면 참**, 같으면 거짓 |
| `!` | NOT | 반대 |

> 논리 연산자 `&&`, `||`는 앞 결과로 결정되면 **뒤를 평가하지 않지만(단락 평가)**, `&`, `|`는 **항상 양쪽을 모두 평가**한다.

### (2) 우선순위 (높음 → 낮음)
`!` > `> < >= <=` > `== !=` > **`&`** > **`^`** > **`|`**
→ 비교 연산(`==`, `!=`, `>`)이 먼저 계산된 뒤 `&`, `^`, `|`가 적용된다.

### (3) XOR 진리표
| A | B | A ^ B |
|:--:|:--:|:--:|
| T | T | F |
| T | F | T |
| F | T | T |
| F | F | F |

## 3. 변수와 조건 평가 (`a=3, b=4, c=3, d=5`)
**① 첫 if 조건**
```java
(a == 2 | a == c) & !(c > d) & (1 == b ^ c != d)
```
| 부분식 | 계산 | 값 |
|---|---|:---:|
| `a == 2` | 3 == 2 | F |
| `a == c` | 3 == 3 | T |
| `(a==2 \| a==c)` | F \| T | **T** |
| `c > d` | 3 > 5 | F |
| `!(c > d)` | | **T** |
| `1 == b` | 1 == 4 | F |
| `c != d` | 3 != 5 | T |
| `(1==b ^ c!=d)` | F ^ T | **T** |
| **전체** | T & T & T | **T** |

→ 조건 **참** → `a = b + c` = 4 + 3 = **7**

**② 안쪽 if 조건**: `7 == b ^ c != a` (a는 이제 7)
| 부분식 | 값 |
|---|:---:|
| `7 == b` | 7 == 4 → F |
| `c != a` | 3 != 7 → T |
| F ^ T | **T** |

→ 참 → `System.out.println(a)` → **7**

> **정답: `7`**

## 4. 암기 포인트
- **XOR은 "다르면 참"**.
- `==`, `!=`는 `&`, `^`, `|`보다 **먼저** 계산된다 → 부분식을 먼저 값으로 바꾼 뒤 연산.
