# 문제 08

## 문제

다음은 테스트케이스의 구성요소에 대한 설명이다. 괄호 ( ) 안에 들어갈 알맞는 보기를 고르시오.

(실제 기출문제에서는 답에 대한 보기가 주어집니다.)

![원문 문제 그림 1](source/정보처리기사_2021_3_Q08_01.png)

<details>
<summary><strong>정답 보기</strong></summary>

1. 테스트 조건

2. 테스트 데이터

3. 예상 결과

테스트 케이스란 특정 프로그램의 부분 및 경로를 실행해보거나,  
요구사항에 준수하는지 확인하기 위해 개발된 입력 값, 조건, 예상된 결과 세트입니다.

케스트 케이스를 함으로써 오류감소 / 비용감소 / 의사소통의 효과가 나타납니다.

테스트 케이스의 설계 기법 종류로는  
블랙박스 기법의 명세기반 / 경험기반 기법과  
화이트박스 기법의 구조기반 기법이 있습니다.

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**테스트 케이스** 표의 빈 열(조건 / 입력 / 결과)에 알맞은 구성요소 이름을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 테스트 케이스
"**어떤 조건에서, 어떤 값을 입력하면, 어떤 결과가 나와야 하는지**"를 문서로 정리한 것이다. 오류 감소·비용 감소·의사소통 효과가 있다.

### (2) 구성요소
| 구성요소 | 의미 | 예 |
|---|---|---|
| 식별자(ID) | 케이스 구분 번호 | DS-45S-21 |
| 테스트 항목 | 무엇을 테스트하나 | 로그인 기능 |
| **테스트 조건** | 테스트 **전제·상황** | 사용자 초기 화면 |
| **테스트 데이터** | **입력값** | 아이디 Test11, 비밀번호 … |
| **예상 결과** | 정상이라면 **나와야 하는 결과** | 로그인 성공 |

## 3. 그림 분석
| 식별자 ID | 테스트 항목 | **( ㉠ )** | **( ㉡ )** | **( ㉢ )** |
|---|---|---|---|---|
| DS-45S-21 | 로그인 기능 | 사용자 초기 화면 | 아이디(Test11) / 비밀번호(test@#@!#) | 로그인 성공 |
| DS-45S-25 | 로그인 기능 | 사용자 초기 화면 | 아이디(Test11) / 비밀번호("") | 로그인 실패 |

| 열 | 내용 | 정답 |
|---|---|---|
| ㉠ | 사용자 **초기 화면** (시작 상황) | **테스트 조건** |
| ㉡ | **아이디·비밀번호** (입력값) | **테스트 데이터** |
| ㉢ | **로그인 성공/실패** (기대 결과) | **예상 결과** |

> **정답: 1. 테스트 조건 2. 테스트 데이터 3. 예상 결과**

## 4. 암기 포인트
- 입력 = 테스트 **데이터**, 기대 출력 = **예상 결과**, 전제 = 테스트 **조건**.
- 25번 케이스는 **빈 비밀번호 → 실패**를 확인하는 **비정상 케이스**.
