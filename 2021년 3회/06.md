# 문제 06 — OSI 계층

## 문제

오류와 흐름 관리, 목적지 경로 결정, 데이터 표현 형식 변환을 수행하는 OSI 계층을 순서대로 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

데이터 링크 계층; 네트워크 계층; 표현 계층

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

데이터 링크는 인접 노드 사이의 프레임 전달과 오류·흐름 제어를 담당하고, 네트워크는 경로 선택, 표현은 형식 변환과 압축 등을 담당한다.

## 풀이

각 기능을 계층에 대응시키면 데이터 링크, 네트워크, 표현 순이다.

## 오답 분석

전송 계층은 종단 간 신뢰성 및 흐름 제어, 세션 계층은 세션 설정과 관리가 중심이다.

## 암기 포인트

링크는 인접 전달, 네트워크는 경로, 표현은 데이터 형식.

</details>
