# 문제 06

## 문제

OSI 7 Layer의 설명으로 해당되는 설명의 답을 작성하시오.

1. 물리계층을 통해 송수신되는 정보의 오류와 흐름을 관리하여 안전한 정보의 전달을 수행할 수 있도록 도와주는 역할

2. 데이터를 목적지까지 가장 안전하고 빠르게 전달하는 기능

3. 수신자에서 데이터의 압축을 풀수 있는 방식으로 된 데이터 압축

OSI 7 Layer :

OSI 7 Layer란 네트워크에서 통신이 일어나는 과정을 단계별로 파악하기 위해 7단계로 나눈 것을 말합니다.

1 Layer - 물리계층(Physical Layer)

단순 데이터를 전기적인 신호로 변환(on/off)해서 주고받는 기능만 하며,

케이블, 리피터, 허브를 통해 데이터를 전송합니다.

2 Layer - 데이터 링크계층(DataLink Layer)

물리계층을 통해 송수신되는 정보의 오류와 흐름을 관리하여 안전한 정보의 전달을 수행하도록 역할합니다.

MAC주소를 가지고 통신을 합니다.

3 Layer - 네트워크 계층(NetWork Layer)

&nbsp;전송 데이터를 목적지까지 경로를 찾아 전송하는 계층입니다.주소(IP)를 정하고, 경로(route)를 선택하여 패킷을 전달하는 것이 핵심입니다.

4 Layer - 전송 계층(Transport)

데이터를 전송하고 전송 속도를 조절하며 오류가 발생된 부분은 다시 맞춰주며,

주로 TCP프로토콜을 사용합니다.

5 Layer - 세션 계층(Session)

네트워크의 양쪽 연결을 관리하고 지속적으로 연결을 시켜줍니다.

&nbsp;TCP/IP의 세션을 만들고 없애는 것을 반복합니다.

6 Layer - 표현 계층(Presentation)

응용계층으로부터 전달받거나 전송하는 데이터의 인코딩(언어처리) 및 디코딩이 이루어 집니다.

JPEG,TIFF,GIF 등의 다양한 포멧을 지원합니다.

7 Layer - 응용계층(Application)

사용자가 네트워크에 접근할 수 있도록 도와줍니다.

사용자에게 보이는 유일한 계층으로 메일전송/인터넷접속 등의 작업을 수행합니다.

## 1. 문제에서 묻는 것
**OSI 7계층**의 각 계층 설명에 해당하는 계층 이름을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) OSI 7계층
네트워크 통신 과정을 **7단계로 나눠 표준화**한 모델이다. 아래(물리)에서 위(응용)로 갈수록 사용자에 가깝다.
| 계층 | 이름 | 역할 | 단위(PDU) | 대표 장비·프로토콜 |
|:---:|---|---|---|---|
| 7 | **응용** | 사용자가 네트워크에 접근하는 서비스(메일, 웹) | 데이터 | HTTP, FTP, SMTP |
| 6 | **표현** | 데이터 **형식 변환, 암호화, 압축/압축 해제** | 데이터 | JPEG, SSL |
| 5 | **세션** | 연결(세션) **설정·유지·종료**, 동기화 | 데이터 | |
| 4 | **전송** | **종단 간** 신뢰성 있는 전송, 흐름·오류 제어 | 세그먼트 | TCP, UDP |
| 3 | **네트워크** | **경로 설정(라우팅)**, **IP 주소** | 패킷 | IP, 라우터 |
| 2 | **데이터링크** | **물리 주소(MAC)**, 인접 노드 간 **오류·흐름 제어** | 프레임 | 이더넷, 스위치 |
| 1 | **물리** | **전기적 신호** 전송(비트) | 비트 | 케이블, 허브, 리피터 |

```text
 암기: 물-데-네-전-세-표-응 (1→7)   /  "응용(7) 표현(6) 세션(5) 전송(4) 네트워크(3) 데이터링크(2) 물리(1)"
```
## 3. 문제 풀이
| 번호 | 설명 | 정답 |
|---|---|---|
| 1 | **물리계층**을 통해 송수신되는 정보의 **오류와 흐름을 관리**하여 안전한 전달을 돕는 역할 | **데이터링크 계층** (2계층) |
| 2 | 데이터를 **목적지까지 가장 안전하고 빠르게 전달**(경로 선택) | **네트워크 계층** (3계층) |
| 3 | 수신자가 풀 수 있는 방식으로 **데이터 압축** (인코딩·압축·암호화) | **표현 계층** (6계층) |

> **정답: 1. 데이터링크 2. 네트워크 3. 표현**

## 4. 암기 포인트
- **데이터링크 = MAC·프레임·오류/흐름 제어**, **네트워크 = IP·라우팅**, **표현 = 변환·압축·암호화**.
