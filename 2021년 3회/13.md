## 1. 문제에서 묻는 것
`CROSS JOIN` 후 `LIKE`로 **패턴 매칭**한 행의 수를 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) CROSS JOIN
두 테이블 행의 **모든 조합**(카티션 곱). T1 3행 × T2 2행 = **6행**.

### (2) LIKE와 와일드카드
| 패턴 | 의미 |
|---|---|
| `%` | 0개 이상의 임의 문자열 |
| `_` | 정확히 1개의 문자 |
| `s%` | **s로 시작** |
| `%t%` | **t를 포함** |

`A.NAME LIKE B.RULE` : 행마다 `B.RULE` 값을 **패턴**으로 사용한다.

## 3. 문제 데이터 (그림)
**T1**

| CODE | NAME |
|---:|---|
| 3258 | smith |
| 4324 | allen |
| 5432 | scott |

**T2**

| NO | RULE |
|---:|---|
| 12 | s% |
| 32 | %t% |

## 4. 풀이: 6개 조합 검사
| A.NAME | B.RULE | 매칭 | 이유 |
|---|---|:---:|---|
| smith | `s%` | ✅ | s로 시작 |
| smith | `%t%` | ✅ | smi**t**h → t 포함 |
| allen | `s%` | ❌ | a로 시작 |
| allen | `%t%` | ❌ | t 없음 |
| scott | `s%` | ✅ | s로 시작 |
| scott | `%t%` | ✅ | sco**tt** → t 포함 |

일치 4개 → `COUNT(*)` = **4**
(규칙별로 보면 `s%`에 2행, `%t%`에 2행이 일치해 합이 4)

> **정답: `4`**

## 5. 암기 포인트
- CROSS JOIN은 **모든 조합**을 만든 뒤 WHERE로 거른다.
- 2025년 3회 10번과 동일한 문제.
