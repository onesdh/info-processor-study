# 문제 12

## 문제

다음 C언어에 대한 알맞는 출력값을 쓰시오.

```
#include <stdio.h>

int main(){
int *arr[3];
int a = 12, b = 24, c = 36;
arr[0] = &a;
arr[1] = &b;
arr[2] = &c;

printf("%d\n", *arr[1] + **arr + 1);

}

```

<details>
<summary><strong>정답 보기</strong></summary>

37

\*array[1] = 24  
\*\*array + 1 = 12 + 1 = 13  
24 + 13 = 37

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**포인터 배열**과 **이중 포인터(`**`)** 표현의 값을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 포인터 배열
```c
int *arr[3];            // 포인터 3개를 담는 배열
arr[0] = &a;  arr[1] = &b;  arr[2] = &c;
```
```text
 arr[0] ──▶ a(12)
 arr[1] ──▶ b(24)
 arr[2] ──▶ c(36)
```
### (2) 역참조(`*`)
| 표현 | 의미 | 값 |
|---|---|---:|
| `arr[1]` | b의 **주소** | |
| `*arr[1]` | arr[1]이 가리키는 **값** = b | **24** |
| `arr` | 배열 이름 = `&arr[0]` | |
| `*arr` | `arr[0]` = a의 주소 | |
| `**arr` | `*(*arr)` = `*(arr[0])` = a | **12** |

## 3. 계산
`*arr[1] + **arr + 1` = 24 + 12 + 1

| 항 | 값 |
|---|---:|
| `*arr[1]` | 24 |
| `**arr` | 12 |
| `+ 1` | 1 |
| **합** | **37** |

> **정답: `37`**

## 4. 암기 포인트
- `**arr` = `arr[0]`이 가리키는 값(첫 번째 변수).
- 연산자 우선순위: `*arr[1]`은 `*(arr[1])` (`[]`가 `*`보다 먼저).

</details>
