# 문제 12

## 문제

다음 C언어에 대한 알맞는 출력값을 쓰시오.

```
#include <stdio.h>

int main(){
int *arr[3];
int a = 12, b = 24, c = 36;
arr[0] = &a;
arr[1] = &b;
arr[2] = &c;

printf("%d\n", *arr[1] + **arr + 1);

}

```

<details>
<summary><strong>정답 보기</strong></summary>

37

\*array[1] = 24  
\*\*array + 1 = 12 + 1 = 13  
24 + 13 = 37

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

포인터 배열의 원소는 각각 int 변수의 주소를 저장하며, 역참조로 값을 얻는다.

## 풀이

*arr[1]=24, **arr은 arr[0]이 가리키는 값 12이므로 24+12+1=37이다.

## 오답 분석

arr[1] 자체는 주소이고 *를 한 번 적용해야 그 값 24를 얻는다. **arr은 첫 포인터가 가리키는 정수값이다.

## 암기 포인트

포인터 배열의 인덱스와 역참조 횟수를 나눠 계산.

</details>
