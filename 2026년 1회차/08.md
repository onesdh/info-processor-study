# 문제 8

## 문제

아래 파이썬 코드가 있다. 입력값으로 `HumanDev`를 주었을 때 출력되는 결과를 쓰시오.

```python
i = input()
x = []
for word in i.split():
    x.append(word)
y = ''.join(x)
z = ''.join(c for c in y[::-1] if c not in 'ong')
print(z)
```

<summary><strong>해설</strong></summary>

### 핵심 개념
이 문제는 문자열 분리, 문자열 결합, 슬라이싱을 이용한 역순 처리, 조건에 따른 문자 필터링을 묻는다.

### 문제 풀이
입력은 `HumanDev` 하나이므로 `i.split()` 결과는 사실상 `['HumanDev']`이다. 이를 `x`에 넣고 `''.join(x)`를 하면 `y`는 다시 `HumanDev`가 된다.

`y[::-1]`은 문자열을 뒤집는다.

`HumanDev` → `veDnamuH`

그다음 `if c not in 'ong'` 조건으로 `o`, `n`, `g` 문자를 제거한다. 뒤집힌 문자열 `veDnamuH`에서 `n`이 제거되므로 남는 문자는 `veDamuH`이다.

### 핵심 정리
- `split()` → 문자열을 분리
- `join()` → 문자열을 이어 붙임
- `[::-1]` → 역순
- `c not in 'ong'` → `o`, `n`, `g` 제외

따라서 출력은 **veDamuH**이다.
