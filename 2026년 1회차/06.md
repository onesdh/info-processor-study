# 문제 6

## 문제

HDLC는 비트 중심의 데이터 링크 제어 프로토콜로, 프레임 단위로 데이터를 전송하며 흐름 제어 및 오류 복구 기능을 제공한다. 다음 설명에 알맞은 용어를 쓰시오.

1. HDLC 프레임의 구성 단위로, 실제 사용자 데이터를 전송하는 프레임
2. 데이터 링크의 흐름을 관리하고 오류 제어 및 통신 상태를 감시하는 프레임
3. 순서 번호 없이 링크 설정, 해제, 모드 설정 등 제어 기능을 수행하는 프레임
4. 두 국(Station)이 동등한 위치에서 서로 명령과 응답을 주고받는 모드
5. 종국(Secondary)이 주국(Primary)의 허가 없이도 자발적으로 응답을 전송할 수 있는 모드

### 핵심 개념
HDLC의 프레임은 역할에 따라 **정보 프레임(I-frame)**, **감독 프레임(S-frame)**, **비번호 프레임(U-frame)**으로 나뉜다.

- **정보 프레임**: 사용자 데이터 전송
- **감독 프레임**: 흐름 제어와 오류 제어 등 링크 관리
- **비번호 프레임**: 순서 번호 없이 링크 설정·해제와 모드 설정 등 제어 기능

동작 모드에서는 주국과 종국의 관계가 중요하다.
- **비동기 균형 모드(ABM)**: 두 국이 동등한 위치에서 통신한다.
- **비동기 응답 모드(ARM)**: 종국이 주국의 허가 없이도 자발적으로 응답을 전송할 수 있다.

### 문제 풀이
각 설명의 핵심 단어를 대응시키면 1→정보, 2→감독, 3→비번호, 4→비동기 균형 모드, 5→비동기 응답 모드이다.

### 암기 포인트
**I = Information(정보), S = Supervisory(감독), U = Unnumbered(비번호)**로 기억하면 프레임 종류를 구분하기 쉽다.
