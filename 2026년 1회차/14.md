# 문제 14

## 문제

아래 파이썬 코드를 실행했을 때 출력되는 값을 쓰시오.

```python
def f(a):
    m = [[x] for x in a]
    b = m[:]
    for i in range(len(b) - 1):
        b[i+1] += b[i]
    return sum(len(x) for x in m)

print(f([1, 2, 3, 4]))
```

<summary><strong>정답</strong></summary>

10

<summary><strong>해설</strong></summary>

### 핵심 개념
이 문제의 핵심은 리스트의 **얕은 복사(shallow copy)**다. `b = m[:]`은 바깥 리스트만 새로 만들고 내부 리스트 객체는 같은 것을 참조한다.

처음 `m`은 다음과 같다.

```text
m = [[1], [2], [3], [4]]
```

`b = m[:]` 이후 `b`와 `m`은 내부 리스트를 공유한다.

### 실행 과정
첫 번째 반복에서 `b[1] += b[0]`이 실행되면 두 번째 내부 리스트가 `[2, 1]`이 된다.

두 번째 반복에서는 `b[2] += b[1]` → `[3, 2, 1]`이 된다.

세 번째 반복에서는 `b[3] += b[2]` → `[4, 3, 2, 1]`이 된다.

내부 리스트를 공유하고 있으므로 `m`도 결과적으로 다음처럼 변한다.

```text
[[1], [2,1], [3,2,1], [4,3,2,1]]
```

각 길이는 1, 2, 3, 4이고 합은 `1+2+3+4=10`이다.

### 암기 포인트
`m[:]`은 내부 객체까지 복제하는 깊은 복사가 아니다. **얕은 복사에서는 내부 리스트 변경이 원본에도 영향을 줄 수 있다.**
