# 문제 1

## 문제

다음은 C언어에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```c
#include <stdio.h>

double arr1(int p[], int len) {
    double av = 0;
    int i;
    for (i = 0; i < len; i++) av += (double)p[i];
    return av / len;
}

double arr2(int *p, int len) {
    double av = 0;
    int i;
    for (i = 0; i < len; i++) av += (double)(*(p + i));
    return av / len;
}

int main() {
    int arr[10] = {80,20,50,55,45,95,55,10,40,80};
    int len = 10;
    printf("%.2f", arr1(arr, len) + arr2(arr, len));
    return 0;
}
```

---

<details>
<summary><strong>정답</strong></summary>

106.00

</details>

<details>
<summary><strong>해설</strong></summary>

### 핵심 개념
배열을 함수에 전달할 때 `int p[]`와 `int *p`는 이 문제의 호출 상황에서는 같은 배열의 첫 원소를 가리키는 방식으로 동작한다. 따라서 두 함수 모두 동일한 10개 값을 이용해 평균을 계산한다.

### 풀이
배열의 합은 `80+20+50+55+45+95+55+10+40+80 = 530`이다. 원소가 10개이므로 평균은 `530 / 10 = 53.0`이다.

`arr1(arr, len)`은 53.0을 반환하고, `arr2(arr, len)`도 53.0을 반환한다. 따라서 두 값을 더하면 `106.0`이다.

`printf("%.2f", ...)`는 소수점 이하 두 자리까지 출력하므로 최종 출력은 **106.00**이다.

### 핵심 정리
- `p[i]`와 `*(p+i)`는 배열 원소 접근에서 같은 의미로 볼 수 있다.
- 평균 = 합계 / 원소 수
- `%.2f` → 소수점 이하 2자리 출력

### 암기 포인트
**같은 배열 → 같은 평균 → 두 함수의 평균을 더함 → 106.00**

</details>
