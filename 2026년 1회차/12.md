# 문제 12

## 문제

다음은 C언어에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```c
struct fns {
    int* (*fn)(int*);
} mine;

int* dummy(int *d) {
    return d + 1;
}

int main() {
    struct fns mine;
    int n[] = {16, 32};
    mine.fn = dummy;
    printf("%x", *mine.fn(n));
    return 0;
}
```

---

<details>
<summary><strong>정답</strong></summary>

20

</details>

<details>
<summary><strong>해설</strong></summary>

### 핵심 개념
이 문제는 함수 포인터와 포인터 연산을 묻는다.

`int* (*fn)(int*)`은 `int*`를 매개변수로 받고 `int*`를 반환하는 함수를 가리키는 함수 포인터다.

### 문제 풀이
`mine.fn = dummy;`이므로 `mine.fn(n)`은 `dummy(n)`과 같다.

`dummy()`는 `return d + 1;`을 수행한다. 배열에서 포인터에 1을 더하면 다음 원소를 가리킨다. 따라서 `n`의 첫 원소 16이 아니라 두 번째 원소 **32**를 가리키는 포인터가 반환된다.

`*mine.fn(n)`으로 역참조하면 32가 된다.

마지막으로 `%x`는 정수를 16진수로 출력한다. 십진수 32는 16진수로 `20`이므로 결과는 **20**이다.

### 암기 포인트
**`p+1` = 다음 원소 / `*p` = 그 원소의 값 / `%x` = 16진수**
