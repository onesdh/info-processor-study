# 문제 20

## 문제

다음은 응집도의 유형에 대한 설명이다. 괄호 안에 들어갈 알맞은 용어를 쓰시오.

(1)은/는 모듈이 다수의 관련 기능을 가질 때, 모듈 안의 구성요소들이 그 기능을 순차적으로 수행하는 경우의 응집도이다.

(2)은/는 동일한 입력과 출력을 사용하여 서로 다른 기능을 수행하는 활동들이 모여 있는 경우의 응집도이다.

(3)은/는 모듈 내부의 모든 기능이 단일한 목적을 위해 수행되는 경우의 응집도이다.

1. 절차

<details>
<summary><strong>해설</strong></summary>

### 핵심 개념
응집도(Cohesion)는 **하나의 모듈 내부 구성요소들이 서로 얼마나 밀접하게 관련되어 있는가**를 나타낸다. 정보처리기사에서는 여러 응집도 유형의 특징을 구분하는 것이 중요하다.

### 문제 풀이
**1번 절차적 응집도**는 모듈 안의 기능들이 일정한 순서에 따라 수행되는 경우다. 문제의 “순차적으로 수행”이 핵심 단서다.

**2번 교환적 응집도**는 동일한 입력과 출력을 사용하면서 서로 다른 기능을 수행하는 활동들이 하나의 모듈에 모인 경우다.

**3번 기능적 응집도**는 모듈의 모든 요소가 하나의 명확한 기능 또는 목적을 수행하기 위해 구성된 경우다.

### 비교
| 유형 | 핵심 단서 |
|---|---|
| 절차적 응집도 | 기능들이 특정 순서로 수행 |
| 교환적 응집도 | 동일한 입력/출력을 사용하며 서로 다른 기능 수행 |
| 기능적 응집도 | 하나의 명확한 기능·목적 수행 |

### 암기 포인트
**순차 수행 = 절차 / 같은 입력·출력 = 교환 / 하나의 목적 = 기능**
