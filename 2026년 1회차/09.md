# 문제 9

## 문제

아래 조건을 참고하여 각 SQL 구문을 실행했을 때 반환되는 행(Row)의 수를 쓰시오. (단, DEPT 칼럼은 학과명이다.)

STUDENT 테이블에는 다음 세 학과의 학생 정보가 저장되어 있다.
- 컴퓨터과 50명
- 인터넷과 100명
- 사무자동화과 50명

```sql
1. SELECT DEPT FROM STUDENT;
2. SELECT DISTINCT DEPT FROM STUDENT;
3. SELECT COUNT(DISTINCT DEPT) FROM STUDENT
   WHERE DEPT = '컴퓨터과';
```

---

<details>
<summary><strong>정답</strong></summary>

1. 200
2. 3
3. 1

</details>

<details>
<summary><strong>해설</strong></summary>

### 핵심 개념
`SELECT`는 조건에 맞는 행을 조회하고, `DISTINCT`는 중복된 값을 제거한다. `COUNT()`는 행 또는 값의 개수를 계산한다.

### 문제 풀이
**1번** `SELECT DEPT FROM STUDENT;`는 중복 제거가 없다. 학생이 총 `50+100+50=200명`이므로 DEPT 값도 200행 반환된다.

**2번** `DISTINCT DEPT`는 학과명을 중복 없이 반환한다. 학과는 컴퓨터과, 인터넷과, 사무자동화과의 3종류이므로 3행이다.

**3번** 먼저 `WHERE DEPT='컴퓨터과'`로 컴퓨터과만 남긴다. 그 뒤 `DISTINCT DEPT`를 적용하면 값은 '컴퓨터과' 하나뿐이다. `COUNT()` 결과는 1이다.

### 암기 포인트
**DISTINCT가 없으면 학생 수만큼 / DISTINCT가 있으면 서로 다른 값의 수**로 생각한다.

</details>
