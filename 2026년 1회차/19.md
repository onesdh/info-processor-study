# 문제 19

## 문제

다음은 통합 테스트에서 사용되는 더미 모듈에 대한 설명이다. 괄호 안에 들어갈 알맞은 용어를 쓰시오.

(1)은/는 하위 모듈을 대신하여 단순한 결과값만 반환하도록 임시로 작성된 더미 모듈로, 하향식 통합 테스트 수행 시 필요하다.

(2)은/는 상위 모듈을 대신하여 하위 모듈의 데이터 입력과 출력을 확인하기 위한 더미 모듈로, 상향식 통합 테스트 수행 시 필요하다.

---

<details>
<summary><strong>정답</strong></summary>

1. 스텁
2. 드라이버

</details>

<details>
<summary><strong>해설</strong></summary>

### 핵심 개념
통합 테스트에서는 아직 개발되지 않았거나 실제로 연결하기 어려운 모듈을 대신하는 **더미 모듈**을 사용할 수 있다.

- **스텁(Stub)**: 하위 모듈을 대신한다. 상위 모듈에서 하위 모듈을 호출하는 하향식 통합 테스트에서 사용한다.
- **드라이버(Driver)**: 상위 모듈을 대신하여 하위 모듈을 호출한다. 상향식 통합 테스트에서 사용한다.

### 문제 풀이
1번은 “하위 모듈을 대신”하고 “하향식 통합 테스트”에서 사용한다고 했으므로 **스텁**이다.

2번은 “상위 모듈을 대신”하고 “상향식 통합 테스트”에서 사용한다고 했으므로 **드라이버**이다.

### 암기 포인트
**하향식 → Stub / 상향식 → Driver**

스텁은 아래쪽을 대신하고, 드라이버는 위쪽을 대신한다고 기억하면 된다.

</details>
