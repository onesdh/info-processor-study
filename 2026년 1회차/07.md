# 문제 7

## 문제

다음은 Java 코드에 대한 문제이다. 아래 코드를 확인하여 알맞은 출력값을 작성하시오.

```java
class A {
    String f(Object x) { return "1"; }
    String g() { return f("a"); }
}

class B extends A {
    String f(Object x) { return "2"; }
    String f(String x) { return "3"; }
}

public class Main {
    public static void main(String[] args) {
        A a = new B();
        System.out.println(a.g());
    }
}
```

### 핵심 개념
이 문제는 Java의 **메서드 오버로딩**과 **메서드 오버라이딩**, 그리고 동적 바인딩을 함께 묻는다.

- **오버로딩**: 같은 이름의 메서드를 매개변수 타입 등을 다르게 정의한다.
- **오버라이딩**: 자식 클래스가 부모 클래스의 메서드를 같은 시그니처로 재정의한다.

### 문제 풀이
`A a = new B();`이므로 변수의 선언 타입은 `A`지만 실제 객체는 `B`이다.

`a.g()`를 호출하면 `g()`는 `A`에 정의되어 있으므로 실행된다. `g()` 내부에는 `f("a")`가 있다. 여기서 `g()`의 소스상 `f`를 결정할 때 사용할 수 있는 메서드 중 `A`가 알고 있는 시그니처는 `f(Object)`이다. 따라서 `f(String)`으로 선택되는 것이 아니라 `f(Object)` 호출이 결정된다.

그런데 실제 객체는 `B`이므로 오버라이딩된 `B.f(Object)`가 실행된다. 이 메서드는 문자열 **"2"**를 반환한다.

따라서 출력값은 **2**이다.

### 헷갈리기 쉬운 부분
`B`에 `f(String)`이 존재한다고 해서 항상 그것이 호출되는 것은 아니다. 오버로딩에 따른 메서드 선택과 오버라이딩에 따른 실제 실행 메서드 결정은 구분해야 한다.
