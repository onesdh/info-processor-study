# 문제 17

## 문제

다음은 Java 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```java
public class Main {
    public static void main(String[] args) {
        int x1 = 9;
        int x2 = 2;
        String x3 = "3";
        System.out.println(x1 + x2 + "2" + x3);
    }
}
```

---

<summary><strong>정답</strong></summary>

1123

</details>

<details>
<summary><strong>해설</strong></summary>

### 핵심 개념
Java에서 `+`는 숫자끼리 사용하면 덧셈이고, 문자열이 포함되면 문자열 연결 연산으로 동작한다. 연산은 왼쪽에서 오른쪽으로 진행한다.

### 문제 풀이
처음 두 값은 정수이므로:

`x1 + x2` → `9 + 2` → `11`

그다음 문자열 `"2"`가 등장한다.

`11 + "2"` → 문자열 **"112"**

마지막으로 `x3`도 문자열 `"3"`이므로:

`"112" + "3"` → **"1123"**

따라서 출력값은 **1123**이다.

### 암기 포인트
**문자열이 등장하기 전까지는 숫자 계산, 문자열이 등장한 이후에는 문자열 연결**이라고 생각하면 쉽다.
