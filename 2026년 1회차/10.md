# 문제 10

## 문제

아래는 선수(PLAYER) 정보를 관리하는 테이블을 정의하는 SQL 문이다. 팀(TEAM) 테이블의 특정 칼럼을 참조하는 외래키 제약 조건을 추가하려 할 때 괄호 ①~⑤에 들어갈 예약어 또는 칼럼명을 쓰시오.

조건
- 외래키 제약 조건의 이름은 TEAM_TF
- PLAYER 테이블의 TEAM_ID가 외래키
- TEAM 테이블의 TEAM_ID2를 참조

```sql
CREATE TABLE PLAYER (
  PLAYER_ID CHAR(7) NOT NULL,
  PLAYER_NAME VARCHAR2(20) NOT NULL,
  TEAM_ID CHAR(3) NOT NULL,
  PRIMARY KEY (PLAYER_ID),
  (1) TEAM_TF
  (2) KEY (3)
  (4) TEAM (5)
);
```

<details>
<summary><strong>해설</strong></summary>

### 핵심 개념
외래키 제약조건은 한 테이블의 컬럼이 다른 테이블의 키를 참조하도록 지정한다. 일반적인 Oracle SQL 문법에서는 다음과 같은 형태가 된다.

```sql
CONSTRAINT 제약조건명
FOREIGN KEY (외래키컬럼)
REFERENCES 참조테이블(참조컬럼)
```

### 문제 풀이
- 제약조건 이름을 지정하므로 ①은 `CONSTRAINT`
- 외래키를 선언하므로 ②는 `FOREIGN`
- PLAYER의 외래키 컬럼은 TEAM_ID이므로 ③은 `TEAM_ID`
- 참조 대상 테이블을 지정하므로 ④는 `REFERENCES`
- TEAM에서 참조하는 컬럼은 TEAM_ID2이므로 ⑤는 `TEAM_ID2`

완성하면 `CONSTRAINT TEAM_TF FOREIGN KEY (TEAM_ID) REFERENCES TEAM (TEAM_ID2)`가 된다.

### 암기 포인트
**CONSTRAINT → FOREIGN KEY → REFERENCES** 순서를 기억한다.

</details>
