# 문제 09

## 문제

IP 주소가 139.127.19.132이고 서브넷마스크 255.255.255.192일 때 아래의 답을 작성하시오.  
(10진수로 표기)

(1) 괄호안에 들어갈 네트워크 주소 : 139.127.19.( )

(2) 해당 네트워크 주소와 브로드캐스트 주소를 제외한 호스트 개수

## 1. 문제에서 묻는 것
IP `139.127.19.132`, 서브넷 마스크 `255.255.255.192`에서 **네트워크 주소**와 **사용 가능한 호스트 수**를 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 255.255.255.192
```text
 255.255.255.192 = 11111111.11111111.11111111.11 000000   → /26 (호스트 6비트)
```
### (2) 공식
| 구하는 것 | 공식 |
|---|---|
| **블록 크기** | 256 − 192 = **64** |
| **네트워크 주소** | IP AND 마스크 (블록 시작값) |
| **사용 가능 호스트 수** | **2^(호스트 비트) − 2** (네트워크·브로드캐스트 제외) |

## 3. 풀이
**(1) 네트워크 주소**
블록(64씩): 0~63 / 64~127 / **128~191** / 192~255
132는 **128~191** 블록 → 네트워크 주소 = 139.127.19.**128**
```text
 132 = 10000100
 192 = 11000000
 AND = 10000000 = 128
```
**(2) 호스트 개수**
호스트 비트 6개 → 2⁶ = 64 − 2 = **62**

| 항목 | 값 |
|---|---|
| 네트워크 주소 | 139.127.19.**128** |
| 사용 범위 | 139.127.19.129 ~ 139.127.19.190 |
| 브로드캐스트 | 139.127.19.191 |
| 호스트 수 | **62** |

> **정답: (1) 128 (2) 62**

## 4. 암기 포인트
- 마스크 192 → 블록 64, 호스트 62. (224 → 32/30, 240 → 16/14, 248 → 8/6)
