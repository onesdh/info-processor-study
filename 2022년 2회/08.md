struct A{

  int g
}

  A a = new A[2]
  for(i=0; i <2; i++) {
    a[i].n = i,

## 핵심 개념

배열 인덱스별 필드값을 대입한 뒤 지정한 두 필드를 더한다.

## 풀이

i=0일 때 a[0].n=0, i=1일 때 a[1].g=2이므로 0+2=2다.

## 오답 분석

a[0].g나 a[1].n을 더하는 것이 아니다. 식에서 지정한 인덱스와 필드 이름을 확인한다.

## 암기 포인트
