## 1. 문제에서 묻는 것
구조체 배열의 두 원소 `a[0].n`과 `a[1].g`를 더한 값을 출력하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 구조체(struct)
서로 다른 자료형의 데이터를 **하나로 묶은 자료형**이다.
```c
struct A { int n; int g; };      // n, g 두 멤버를 가진 구조체
```
### (2) 구조체 배열
`A a[2]` : A 구조체가 2개 들어 있는 배열.
```text
 a[0] = { n, g }     a[1] = { n, g }
```
멤버 접근: `a[i].n`, `a[i].g`.

## 3. 실행 과정
반복문 `for (i = 0; i < 2; i++)`: `a[i].n = i`, `a[i].g = i + 1`
| i | a[i].n = i | a[i].g = i+1 |
|---:|---:|---:|
| 0 | **0** | 1 |
| 1 | 1 | **2** |

`a[0].n + a[1].g` = 0 + 2 = **2**

> **정답: `2`**

(원문 코드는 문법상 오류가 있는 의사코드이며, 의도한 동작은 위와 같다.)

## 4. 암기 포인트
- 구조체 배열은 `배열[인덱스].멤버` 로 접근한다.
- 인덱스는 0부터.
