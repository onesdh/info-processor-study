# 문제 03

## 문제

H회사의 전체 제품 단가 보다 큰 제품 출력을 하고자 한다. 괄호안에 들어갈 알맞는 용어를 작성하시오.

[제품테이블]

![원문 문제 그림 1](source/정보처리기사_2022_2_Q03_01.png)

SELECT 제조사, 제품명, 단가  
FROM 제품  
WHERE 단가 &gt; ( ) (SELECT 단가 FROM 제품 WHERE 제조사='H')

<details>
<summary><strong>정답 보기</strong></summary>

ALL

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
H 회사 **전체 제품 단가보다 큰 제품**을 출력하는 SQL의 빈칸에 들어갈 **서브쿼리 비교 연산자**(ALL)를 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 서브쿼리 결과가 여러 개일 때의 비교
서브쿼리가 **여러 값**을 반환하면 단순 `>` 로는 비교할 수 없다. **ALL / ANY(SOME)** 를 붙인다.
| 연산자 | 의미 |
|---|---|
| `> ALL (집합)` | 집합의 **모든 값보다 큼** (= **최댓값보다 큼**) |
| `> ANY (집합)` | 집합의 **어느 하나보다라도 큼** (= **최솟값보다 큼**) |
| `= ANY` | `IN`과 같음 |

### (2) 예 (집합 {2000, 3000})
| 조건 | 조건을 만족하는 값 |
|---|---|
| `> ALL` | 3000 초과 (4000, 5000…) |
| `> ANY` | 2000 초과 (2500, 3000…) |

## 3. 문제 데이터 (그림)
| 제조사 | 제품명 | 단가 |
|---|---|---:|
| A | 과자 | 1,000 |
| B | 초콜릿 | 6,000 |
| H | 사탕 | 2,000 |
| C | 아이스크림 | 5,000 |
| H | 사탕 | 3,000 |

## 4. 풀이
**서브쿼리**: `SELECT 단가 FROM 제품 WHERE 제조사='H'` → **{2000, 3000}**

"전체 H 제품 단가보다 큰" = H의 **모든** 단가보다 큰 것 → `> ALL`

| 제품 | 단가 | 2000보다 큼 | 3000보다 큼 | `> ALL` |
|---|---:|:---:|:---:|:---:|
| 과자 | 1,000 | X | X | X |
| 초콜릿 | 6,000 | ✅ | ✅ | **✅** |
| 아이스크림 | 5,000 | ✅ | ✅ | **✅** |
| 사탕(H) | 2,000 | X | X | X |
| 사탕(H) | 3,000 | ✅ | X | X |

```sql
SELECT 제조사, 제품명, 단가
FROM 제품
WHERE 단가 > ALL (SELECT 단가 FROM 제품 WHERE 제조사 = 'H');
```
결과: B 초콜릿 6,000 / C 아이스크림 5,000

> **정답: ALL**

## 5. 암기 포인트
- `> ALL` = **최댓값보다 큼**, `> ANY` = **최솟값보다 큼**.
- 문제의 "**전체** ~보다 큰" → ALL.
