# 문제 05

## 문제

다음은 네트워크에 관련한 내용이다. 괄호안에 들어갈 알맞는 답을 작성하시오.

( )은/는 인터넷을 통해 디바이스 간에 사설 네트워크 연결을 생성하며, 퍼블릭 네트워크를 통해 데이터를 안전하게 익명으로 전송하는 데 사용된다.

또한 사용자 IP 주소를 마스킹하고 데이터를 암호화하여 수신 권한이 없는 사람이 읽을 수 없도록 한다.

## 1. 문제에서 묻는 것
"인터넷을 통해 **사설 네트워크 연결**을 생성, **IP 주소 마스킹**, **데이터 암호화**" → 용어를 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) VPN (Virtual Private Network, 가상 사설망)
**공용망(인터넷) 위에 암호화된 "가상 터널"** 을 만들어, 마치 **전용선으로 연결된 사설망**처럼 안전하게 통신하게 해 준다.
```text
 [ 내 PC ] ═══ 암호화 터널 (인터넷) ═══ [ VPN 서버 / 회사 내부망 ]
             외부에서는 내용도, 내 실제 IP도 알아보기 어려움
```
### (2) 핵심 기능
| 기능 | 설명 |
|---|---|
| **암호화** | 권한 없는 사람이 **읽을 수 없게** |
| **IP 마스킹** | VPN 서버 IP로 접속 → **실제 IP 은닉**, 위치 추적 어려움 |
| **사설망 확장** | 재택·출장 시 사내 자원 접근 |
| **터널링** | 패킷을 감싸 공용망 통과 |

### (3) 프로토콜
IPsec(3계층), SSL/TLS VPN, L2TP, PPTP 등.

## 3. 문제 풀이
| 단서 | VPN |
|---|---|
| 인터넷으로 **사설 네트워크 연결** 생성, 안전·익명 전송 | ✅ |
| **IP 주소 마스킹**, 데이터 **암호화** | ✅ |

> **정답: VPN (Virtual Private Network)**
