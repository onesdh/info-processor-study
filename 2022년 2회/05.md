# 문제 05

## 문제

다음은 네트워크에 관련한 내용이다. 괄호안에 들어갈 알맞는 답을 작성하시오.

( )은/는 인터넷을 통해 디바이스 간에 사설 네트워크 연결을 생성하며, 퍼블릭 네트워크를 통해 데이터를 안전하게 익명으로 전송하는 데 사용된다.

또한 사용자 IP 주소를 마스킹하고 데이터를 암호화하여 수신 권한이 없는 사람이 읽을 수 없도록 한다.

## 핵심 개념

VPN은 Virtual Private Network의 약자로 공용망 위에 논리적인 사설 통신 경로를 구성한다.

## 풀이

터널링과 암호화를 이용해 원격 사용자나 지점이 사설망처럼 안전하게 통신하게 한다.

## 오답 분석

방화벽은 접근 통제, 프록시는 중계, NAT는 주소 변환이 핵심이다. 사설 터널과 암호화는 VPN이다.

## 암기 포인트

공용망에 사설 통로를 만드는 VPN.
