# 문제 15

## 문제

다음 C언어에서 출력에 대한 알맞은 답을 작성하시오.

```
#include <stdio.h>

int len(char*p);

int main(){

  char* p1 = "2022";
  char* p2 = "202207";

  int a = len(p1);
  int b = len(p2);

  printf("%d", a + b);

}

int len(char* p){
  int r = 0;
  while(*p != '\0'){
    p++;
    r++;
 }
 return r;
}

```

<details>
<summary><strong>정답 보기</strong></summary>

10

</details>

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
C의 **문자열 길이를 구하는 함수**(`len`)를 두 문자열에 적용해 합을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 문자열과 널 문자
C 문자열은 끝에 **`'\0'`(널 문자)** 가 붙는다. 길이는 널 문자 **앞까지의 글자 수**.
```text
 "2022"   : 2 0 2 2 \0     → 길이 4
 "202207" : 2 0 2 2 0 7 \0 → 길이 6
```
### (2) 함수 `len` 읽기
```c
int len(char* p) {
    int r = 0;
    while (*p != '\0') { p++; r++; }   // 널 문자를 만날 때까지 포인터와 카운터를 증가
    return r;
}
```
`p++`는 **다음 글자로 이동**, `r++`는 **글자 수 세기**.

## 3. 실행 과정
| 호출 | 반복 횟수 | 반환 |
|---|---:|---:|
| `len("2022")` | 4번 (널 문자 만나면 종료) | **4** |
| `len("202207")` | 6번 | **6** |

`a + b` = 4 + 6 = **10**

> **정답: `10`**

## 4. 암기 포인트
- 이 함수는 표준 라이브러리 `strlen`과 같다(널 문자 제외).
- 포인터를 이동하며 `'\0'`까지 세는 패턴은 매우 자주 출제된다.
