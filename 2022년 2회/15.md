# 문제 15

## 문제

다음 C언어에서 출력에 대한 알맞은 답을 작성하시오.

```
#include <stdio.h>

int len(char*p);

int main(){

  char* p1 = "2022";
  char* p2 = "202207";

  int a = len(p1);
  int b = len(p2);

  printf("%d", a + b);

}

int len(char* p){
  int r = 0;
  while(*p != '\0'){
    p++;
    r++;
 }
 return r;
}

```

<details>
<summary><strong>정답 보기</strong></summary>

10

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

널 종료 문자를 만날 때까지 포인터를 한 칸씩 이동하고 센 횟수가 문자열 길이다.

## 풀이

"2022"는 4글자, "202207"은 6글자이므로 합은 10이다. 널 문자 \0은 길이에 포함하지 않는다.

## 오답 분석

문자열 리터럴을 저장할 때의 널 종료 문자는 출력 길이에 포함되지 않는다.

## 암기 포인트

널 문자는 종료 표시이며 길이에서 제외.
