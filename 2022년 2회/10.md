# 문제 10

## 문제

다음 설명에 대한 괄호안에 알맞는 단어를 작성하시오.

1. ( ) 테스트는 하드웨어나 소프트웨어의 개발 단계에서 상용화하기 전에 실시하는 제품 검사 작업. 제품의 결함 여부, 제품으로서의 가치 등을 평가하기 위해 실시한다. 선발된 잠재 고객으로 하여금 일정 기간 무료로 사용하게 한 후에 나타난 여러 가지 오류를 수정, 보완한다. 공식적인 제품으로 발매하기 이전에 최종적으로 실시하는 검사 작업이다.

2. ( ) 테스트는 새로운 제품 개발 과정에서 이루어지는 첫 번째 테스트. 즉, 시제품이 운영되는 동안의 신제품 연구와 개발 과정 단계에서 초기 작동의 결과를 평가하는 수단이며 개발 회사 내부에서 이루어지는 테스트로서 단위 테스트, 구성 테스트, 시스템 테스트 등을 포함한다.

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**알파 테스트**와 **베타 테스트**를 설명으로 구분하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 알파·베타 테스트 비교
| 구분 | **알파(Alpha) 테스트** | **베타(Beta) 테스트** |
|---|---|---|
| 수행 장소 | **개발 회사 내부** (개발자 환경) | **실제 사용자 환경** (고객 현장) |
| 수행자 | 개발자·**내부 직원**, 선발된 사용자 | **선발된 잠재 고객** |
| 시기 | 개발 후반, **먼저** 실시 | 알파 이후, **공식 출시 직전**에 최종 실시 |
| 목적 | 내부에서 **결함 조기 발견·수정** | 실사용 환경에서 **오류·가치 평가**, 마지막 보완 |
| 통제 | **통제된 환경** | **통제되지 않은 실제 환경** |

```text
 개발 ─▶ [알파 테스트: 사내] ─▶ [베타 테스트: 잠재 고객, 일정 기간 무료 사용] ─▶ 정식 출시
```
### (2) 소프트웨어 개발 단계의 테스트
단위 테스트 → 통합 테스트 → 시스템 테스트 → **인수 테스트(알파·베타)**.

## 3. 문제 풀이
| 번호 | 단서 | 정답 |
|---|---|---|
| 1 | 상용화 전 제품 검사, **선발된 잠재 고객**이 **일정 기간 무료 사용** 후 오류 수정, **공식 발매 전 최종** 검사 | **베타** |
| 2 | 신제품 개발 과정의 **첫 번째 테스트**, **개발 회사 내부**에서 수행(단위·구성·시스템 테스트 포함) | **알파** |

> **정답: 1. 베타 / 2. 알파**

## 4. 암기 포인트
- **알파 = 내부(개발사)**, **베타 = 외부(고객)**. 알파(α)가 먼저, 베타(β)가 나중(그리스 문자 순서).
