# 문제 20

## 문제

다음 모듈 F에 대한 Fan-in과 Fan-out을 작성하시오.

Fan-in : 3

Fan-out : 2

<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
그림에서 모듈 **F**의 **Fan-in**과 **Fan-out**을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) Fan-in / Fan-out (모듈의 호출 관계)
| 용어 | 의미 | 세는 방법 |
|---|---|---|
| **Fan-in** | 그 모듈을 **호출(사용)하는 상위 모듈의 수** | 그 모듈로 **들어오는 화살표** 수 |
| **Fan-out** | 그 모듈이 **호출(사용)하는 하위 모듈의 수** | 그 모듈에서 **나가는 화살표** 수 |

```text
   A    B    C        ← 상위 (F를 호출)
    ╲   │   ╱
      ▼ ▼ ▼
       [ F ]           Fan-in = 3 (A, B, C에서 들어옴)
      ╱     ╲
     ▼       ▼
    G         H        Fan-out = 2 (G, H로 나감)
```
### (2) 설계상 의미
| 지표 | 높으면 | 설계 권장 |
|---|---|---|
| **Fan-in** | **재사용성이 좋은** 공통 모듈 | 높을수록 좋음 |
| **Fan-out** | 모듈이 **많은 일을 직접 제어/의존**(복잡·결합도↑) | 낮을수록 좋음(일반적으로 7 이하) |

## 3. 그림 분석
| 화살표 | 방향 |
|---|---|
| A → F | F로 **들어옴** |
| B → F | F로 **들어옴** |
| C → F | F로 **들어옴** |
| F → G | F에서 **나감** |
| F → H | F에서 **나감** |

- **Fan-in** = A, B, C → **3**
- **Fan-out** = G, H → **2**

> **정답: Fan-in : 3, Fan-out : 2**

## 4. 암기 포인트
- **in = 나를 부르는 수(들어오는 화살표)**, **out = 내가 부르는 수(나가는 화살표)**.
- 좋은 설계: **Fan-in은 높게, Fan-out은 낮게**.
