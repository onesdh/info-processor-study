## 1. 문제에서 묻는 것
객체의 필드를 **중간에 바꾼 뒤** 메서드를 호출했을 때의 계산을 따라가는 문제다. 생성자에서 3으로 설정했지만 `obj.a = 5`로 **다시 바꾼다**는 점이 핵심이다.

## 2. 먼저 알아야 할 개념
### (1) 필드 변경
`obj.a = 5;` 는 객체 `obj`의 필드 `a`를 **5로 직접 변경**한다. 이후 메서드에서 쓰는 `a`는 5이다.

### (2) func() 읽기
```java
int func() {
    int b = 1;
    for (int i = 1; i < a; i++) {    // i = 1 ... a-1
        b = a * i + b;
    }
    return a + b;
}
```
## 3. 실행 과정
**① 객체 생성·변경**: `Conv obj = new Conv(3);` → a = 3, 이어서 `obj.a = 5;` → **a = 5**

**② `obj.func()`** (`a = 5`): `i`는 1~4
| i | 계산 `b = a*i + b` | b |
|---:|---|---:|
| 시작 | | 1 |
| 1 | 5×1 + 1 | 6 |
| 2 | 5×2 + 6 | 16 |
| 3 | 5×3 + 16 | 31 |
| 4 | 5×4 + 31 | **51** |

`return a + b` = 5 + 51 = **56** → `int b = 56`

**③ 출력**: `obj.a + b` = 5 + 56 = **61**

> **정답: `61`**

## 4. 암기 포인트
- 객체 생성 후 필드를 바꾸면 이후 메서드는 **바뀐 값**을 사용한다(3이 아닌 5).
- 여기서 `main`의 `b`(56)와 `func` 안의 `b`(51)는 서로 다른 변수.
