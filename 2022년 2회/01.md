# 문제 01

## 문제

다음은 관계 데이터 모델에 대한 설명이다. 괄호안에 들어가는 용어를 작성하시오.

( )은 /는 관계 데이터의 연산을 표현하는 방법으로, 원하는 정보를 정의할 때는 계산 수식을 사용한다.  
수학의 predicate calculus에 기반을 두고 있으며, 관계 데이터 모델의 제안자인 codd가 수학에 가까운 기반을 두고 특별히 관계 데이터베이스를 위해 제안하여 탄생하였다.

( ) /은/는 원하는 정보가 무엇이라는 것만 정의하는 비절차적 특성을 지니며, 튜블 ( )와/과 도메인 ( ) 이/가 있다.

## 1. 문제에서 묻는 것
"**계산 수식**으로 원하는 정보를 정의, **predicate calculus** 기반, **비절차적**, 튜플/도메인 ( )" → 어떤 관계 데이터 언어인지 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 관계 데이터 언어 2가지
릴레이션에서 원하는 데이터를 꺼내는 이론적 언어는 두 가지다.
| 구분 | **관계대수** | **관계해석** |
|---|---|---|
| 성격 | **절차적** — "어떻게" 얻을지 연산 순서를 기술 | **비절차적** — "무엇을" 원하는지만 기술 |
| 기반 | 집합 대수 | **술어 해석(Predicate Calculus)** |
| 표현 | σ, π, ⋈, ÷ 연산자 | **수식**(조건식) |
| 비유 | 요리 **레시피**(과정 설명) | **주문서**(결과만 설명) |

### (2) 관계해석(Relational Calculus)
- **E. F. Codd**가 관계 DB를 위해 제안
- 원하는 정보가 **무엇이라는 것만** 정의(어떻게 구하는지는 DBMS가 결정)
- **관계대수와 표현 능력이 동등**

### (3) 관계해석의 종류
| 종류 | 변수 | 의미 |
|---|---|---|
| **튜플 관계해석** | 튜플 변수 | 튜플 단위로 조건식 표현 (SQL의 기반) |
| **도메인 관계해석** | 도메인 변수 | 속성 값(도메인) 단위로 조건식 표현 (QBE의 기반) |

```text
 튜플 관계해석:  { t | t ∈ 학생 ∧ t.학과 = '컴공' }      ← "컴공 학생인 튜플 t의 집합"
```
## 3. 문제 풀이
| 단서 | 관계해석 |
|---|---|
| **계산 수식**을 사용해 정보를 정의, **predicate calculus** 기반 | ✅ |
| Codd가 관계 DB를 위해 제안 | ✅ |
| **비절차적** 특성, 튜플·도메인 관계해석이 있음 | ✅ |

> **정답: 관계해석 (Relational Calculus)**
