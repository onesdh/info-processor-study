# 문제 11

## 문제

다음 설명에 알맞는 테스트 용어를 보기에서 골라 작성하시오.  
(실제 기출문제에서는 답의 보기가 주어집니다.(오답 중, Iterating등..))

오류를 제거하거나 수정한 시스템이나 시스템 컴포넌트 또는 프로그램이 오류 제거와 수정에 의해 새로이 유입된 오류가 없는지를 확인하는 일종의 반복 시험이다.

반복적인 시험이 필요한 이유는 오류가 제거·수정되는 상당수의 시스템이 의도치 않았던 오동작이나 새로운 형태의 오류를 일으키기 때문이다.

결국, 수정·변경된 시스템이나 시스템 컴포넌트 또는 프로그램이 명세된 요구 사항을 충족시키는지를 확인하는 시험의 한 형태이다.

## 1. 문제에서 묻는 것
"오류를 **수정한 뒤** 새로 유입된 오류가 없는지 확인하는 **반복 시험**" → 어떤 테스트인지 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 회귀 테스트(Regression Test)
소프트웨어를 **수정(버그 수정·기능 추가)** 했을 때, 그 변경이 **기존에 잘 동작하던 기능을 망가뜨리지 않았는지** 다시 확인하는 테스트다. "regression"은 **퇴행·후퇴**라는 뜻 — 정상이던 기능이 **나빠지는 것**을 잡는다.

```text
 버전 1.0 : 기능 A ✅ 기능 B ✅ 기능 C ✅
   ▼ 기능 B 버그 수정
 버전 1.1 : 기능 A ? 기능 B ✅ 기능 C ?   ← 수정 때문에 A, C가 깨졌는지 전체를 다시 시험
```
### (2) 왜 필요한가?
오류를 고치면 **의도하지 않은 부작용**이 생겨 다른 부분이 오작동하는 일이 흔하다. 그래서 **같은 테스트를 반복**한다.

### (3) 특징
| 항목 | 내용 |
|---|---|
| 방법 | 기존 테스트 케이스를 **재실행** (**자동화**하면 효율적) |
| 시점 | 수정·변경·배포 **직후** |
| 관련 | 유지보수 단계에서 필수 |

### (4) 비슷한 용어
| 테스트 | 목적 |
|---|---|
| **회귀(Regression)** | 수정 후 **기존 기능이 안 깨졌는지** |
| 스모크 | 기본 기능이 **동작하는지 빠르게** 확인 |
| 확인(재테스트) | 고친 **그 결함이 해결됐는지** |

## 3. 문제 풀이
| 단서 | 회귀 테스트 |
|---|---|
| 오류 수정 후 **새로 유입된 오류가 없는지** 확인 | ✅ |
| **반복 시험**, 수정으로 인한 의도치 않은 오동작 | ✅ |
| 수정된 시스템이 **명세된 요구 사항을 충족**하는지 확인 | ✅ |

> **정답: Regression (회귀 테스트)**
