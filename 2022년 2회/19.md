# 문제 19 — HTTP, 하이퍼텍스트, HTML

## 문제

웹 문서 전송 통신 규약, 링크로 정보를 연결하는 방식, 웹 문서의 구조를 표시하는 마크업 언어를 순서대로 쓰시오.

## 정답

HTTP; Hypertext; HTML

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

HTTP는 웹 클라이언트와 서버 사이의 응용 계층 통신 규약이다. 하이퍼텍스트는 링크로 연결된 문서 구조 또는 정보 표현 방식이고, HTML은 웹 문서를 구조화하는 마크업 언어다.

## 풀이

전송 프로토콜은 HTTP, 링크 기반 정보 구조는 Hypertext, 웹 페이지 마크업은 HTML로 구분한다.

## 오답 분석

AJAX는 웹 비동기 통신 기술, ARP/RARP는 IP와 MAC 주소 변환과 관련된다.

## 암기 포인트

HTTP는 전송, Hypertext는 연결, HTML은 문서 구조.
