#include <stdio.h>

int main(int argc, char *argv[]) {
int a[4] = {0, 2, 4, 8};
int b[3] = {};
int i = 1;
int sum = 0;
int *p1;

for (i; i < 4; i++) {
p1 = a + i;
b[i-1] = *p1 - a[i-1];
sum = sum + b[i-1] + a[i];

## 핵심 개념

a+i는 배열의 i번째 원소 주소를 가리키므로 *(a+i)는 a[i]다.

## 풀이

i=1: b[0]=2-0=2, sum=2+2=4. i=2: b[1]=4-2=2, sum은 4+2+4=10. i=3: b[2]=8-4=4, sum은 10+4+8=22다.

## 오답 분석

포인터 연산 a+i는 i번째 원소를 가리키고, 누적 변수는 매 반복마다 이전 값에 더해진다.

## 암기 포인트

*(a+i)는 a[i]로 바꾸어 추적.
