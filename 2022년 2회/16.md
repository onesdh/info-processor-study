## 1. 문제에서 묻는 것
**배열과 포인터 연산**을 이용해 `b[i-1]`과 `sum`을 누적하는 코드의 결과를 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 배열과 포인터 덧셈
```c
int a[4] = {0, 2, 4, 8};
int *p1 = a + i;      // a의 i번째 원소의 주소
*p1                    // = a[i]
```
`a + i`는 **i칸 뒤 주소**, `*(a + i)` ≡ `a[i]`.

### (2) 코드의 규칙
```c
b[i-1] = *p1 - a[i-1];            // = a[i] - a[i-1]  (이웃한 두 원소의 차)
sum    = sum + b[i-1] + a[i];     // 차 + 현재 값 누적
```
## 3. 실행 과정 (`a = {0, 2, 4, 8}`, i = 1, 2, 3)
| i | `*p1` = a[i] | a[i-1] | `b[i-1]` = a[i] − a[i-1] | `b[i-1] + a[i]` | sum |
|---:|---:|---:|---:|---:|---:|
| 1 | 2 | 0 | 2 | 2 + 2 = 4 | **4** |
| 2 | 4 | 2 | 2 | 2 + 4 = 6 | **10** |
| 3 | 8 | 4 | 4 | 4 + 8 = 12 | **22** |

`printf("%d", sum)` → **22**

> **정답: `22`**

## 4. 암기 포인트
- `*(a + i)` = `a[i]`. 표로 정리하면 실수가 없다.
- `for (i; i < 4; i++)`에서 `i`는 이미 1로 초기화되어 있으므로 1부터 시작.
