# 문제 04

## 문제

다음 SQL 결과에 알맞는 답을 작성하시오.

[TABLE]

![원문 문제 그림 1](source/정보처리기사_2022_2_Q04_01.png)

SELECT count(col2)  
FROM TABLE  
WHERE col1 in(2,3) or col2 in(3,5);

## 1. 문제에서 묻는 것
`WHERE col1 IN (2,3) OR col2 IN (3,5)` 를 만족하는 행에서 `COUNT(col2)`를 구하는 문제다. **NULL 처리**가 핵심이다.

## 2. 먼저 알아야 할 개념
### (1) NULL = 값이 없음(알 수 없음)
`NULL`은 `=`, `IN` 등 어떤 비교에서도 **참이 되지 않는다**(UNKNOWN).

### (2) OR의 3값 논리
| A | B | A OR B |
|---|---|---|
| TRUE | UNKNOWN | **TRUE** |
| FALSE | UNKNOWN | UNKNOWN (탈락) |
| UNKNOWN | TRUE | **TRUE** |

`WHERE`는 결과가 **TRUE인 행만** 통과시킨다.

### (3) COUNT
- `COUNT(*)` : 모든 행
- `COUNT(col2)` : **col2가 NULL이 아닌** 행만

## 3. 문제 데이터 (그림)
| Index | col1 | col2 |
|---:|---|---|
| 1 | 2 | Null |
| 2 | 3 | 6 |
| 3 | 5 | 5 |
| 4 | 6 | 3 |
| 5 | Null | 3 |

## 4. 풀이: 행별 조건 판정
| 행 | `col1 IN (2,3)` | `col2 IN (3,5)` | OR 결과 | 통과 |
|---:|:---:|:---:|:---:|:---:|
| 1 (2, Null) | ✅ | UNKNOWN | TRUE | ✅ |
| 2 (3, 6) | ✅ | ❌ | TRUE | ✅ |
| 3 (5, 5) | ❌ | ✅ | TRUE | ✅ |
| 4 (6, 3) | ❌ | ✅ | TRUE | ✅ |
| 5 (Null, 3) | UNKNOWN | ✅ | TRUE | ✅ |

5행 모두 통과. 이 중 **col2가 NULL인 행은 1번뿐** → `COUNT(col2)` = 5 − 1 = **4**

| 행 | col2 | 센다? |
|---:|---|:---:|
| 1 | Null | ❌ |
| 2 | 6 | ✅ |
| 3 | 5 | ✅ |
| 4 | 3 | ✅ |
| 5 | 3 | ✅ |

> **정답: `4`**

## 5. 암기 포인트
- `COUNT(열)`은 **NULL 제외**, `COUNT(*)`는 NULL 포함.
- NULL이 있어도 OR의 다른 쪽이 TRUE이면 행은 통과한다.
