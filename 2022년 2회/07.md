public static void main(String args[]){

  int i = 3; int k = 1;
  switch(i) {
    case 1: k += 1;
    case 2: k++;
    case 3: k = 0;
    case 4: k += 3;
    case 5: k -= 10;
    default: k--;
  }
  System.out.print(k);

## 핵심 개념

case 3에 진입한 뒤 break가 없으므로 이후 case와 default 문장까지 연속 실행된다.

## 풀이

k=0에서 시작해 case 4에서 3, case 5에서 -7, default에서 -8이 된다.

## 오답 분석

case 3에서 멈춘다고 생각해 0을 쓰거나, default가 별도 실행된다고 해석하면 틀린다. break가 없으면 다음 라벨은 실행 흐름을 막지 않는다.
