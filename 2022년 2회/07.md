## 1. 문제에서 묻는 것
`switch` 문의 **fall-through**(break 없이 아래 case를 계속 실행)를 따라가며 `k`의 최종 값을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) switch와 fall-through
- `switch(i)`는 값이 **일치하는 case로 점프**한다.
- **`break`를 만나기 전까지 아래 case를 연속 실행**한다(fall-through).
- 이 코드에는 **`break`가 하나도 없다.**

```java
switch(3) {
    case 1: k += 1;      // 건너뜀
    case 2: k++;         // 건너뜀
    case 3: k = 0;       // ← 여기서 시작
    case 4: k += 3;      // 이어서 실행
    case 5: k -= 10;     // 이어서 실행
    default: k--;        // 이어서 실행
}
```
## 3. 실행 과정 (`i = 3`, 초기 `k = 1`)
| 실행 순서 | 문장 | k |
|---:|---|---:|
| (시작) | `k = 1` | 1 |
| 1 | `case 3: k = 0;` (case 3으로 점프) | **0** |
| 2 | `case 4: k += 3;` | 3 |
| 3 | `case 5: k -= 10;` | -7 |
| 4 | `default: k--;` | **-8** |

(`case 1`, `case 2`는 점프 시작점보다 위라서 실행되지 않는다. 초기값 1은 `k = 0`으로 덮어써짐)

`System.out.print(k)` → **-8**

> **정답: `-8`**

## 4. 암기 포인트
- 점프한 case부터 **끝까지** 모두 실행 (break가 없으면).
- `k = 0`(대입)은 이전 값을 지우고 0으로 시작한다.
