# 문제 03

## 문제

다음 C언어의 출력값을 작성하시오.

```
#include <stdio.h>

int main(){

    char* a = "qwer";
    char* b = "qwtety";

    for(int i = 0; a[i] != '\0' ; i++){
        for(int j = 0; b[j] != '\0'; j++){
            if(a[i] == b[j]) printf("%c", a[i]);
        }
    }

}
```

qwe

</details>

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
두 문자열 `a`, `b`를 **이중 반복문으로 비교**해 일치하는 문자를 출력하는 문제다. 출력 순서는 **a의 글자 순서**를 따른다.

## 2. 먼저 알아야 할 개념
### (1) 이중 반복문
바깥 반복(i)이 **한 번 돌 때마다** 안쪽 반복(j)이 **처음부터 끝까지** 돈다.
```text
 i=0 ─ j=0,1,2,3,4,5   (a[0]을 b의 모든 글자와 비교)
 i=1 ─ j=0,1,2,3,4,5   (a[1]을 b의 모든 글자와 비교)
 ...
```
### (2) 두 문자열
```text
 a : q w e r        (4글자)
 b : q w t e t y    (6글자)
```
`a[i] == b[j]` 이면 그 문자를 출력한다.

## 3. 실행 과정
| a[i] | b와 비교 (일치하는 j) | 출력 |
|:---:|---|:---:|
| `q` | b[0] = q ✅ (1번 일치) | **q** |
| `w` | b[1] = w ✅ | **w** |
| `e` | b[3] = e ✅ (b에 e는 한 번뿐) | **e** |
| `r` | b에 r 없음 | (없음) |

일치할 때마다 출력하며, 각 글자가 b에서 **몇 번 나오는지**만큼 출력된다. 여기서는 모두 1번씩이므로 `q`, `w`, `e` 한 번씩.

> **정답: `qwe`**

## 4. 암기 포인트
- 중복 개수만큼 출력된다(만약 b에 `q`가 2개였다면 `qq`).
- 출력 순서는 **바깥 반복(a)** 기준.
