# 문제 03

## 문제

다음 C언어의 출력값을 작성하시오.

```
#include <stdio.h>

int main(){

    char* a = "qwer";
    char* b = "qwtety";

    for(int i = 0; a[i] != '\0' ; i++){
        for(int j = 0; b[j] != '\0'; j++){
            if(a[i] == b[j]) printf("%c", a[i]);
        }
    }

}
```

<details>
<summary><strong>정답 보기</strong></summary>

qwe

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

바깥 반복은 a의 각 문자를 한 번씩 처리하고, 안쪽 반복은 일치가 발견될 때마다 출력한다.

## 풀이

a의 문자는 q,w,e,r이고 b에는 q,w,e가 각각 한 번씩 등장한다. 따라서 qwe가 출력되며 r은 일치가 없어 빠진다.

## 오답 분석

공통 부분 문자열을 찾는 것이 아니라 문자 단위로 두 문자열을 비교한다. b에 같은 문자가 반복되면 출력도 반복될 수 있다.

## 암기 포인트

바깥 문자열 순서대로 공통 문자를 출력.
