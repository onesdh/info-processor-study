# 문제 20

## 문제

다음 자바 코드에 대한 출력 값을 작성하시오.

```
class Parent {
    int x = 100;

    Parent() {
        this(500);
    }

    Parent(int x) {
        this.x = x;
    }

    int getX() {
        return x;
    }
}

class Child extends Parent {
    int x = 4000;

    Child() {
        this(5000);
    }

    Child(int x) {
        this.x = x;
    }
}

public class Main {
    public static void main(String[] args) {
        Child obj = new Child();
        System.out.println(obj.getX());
    }
}
```

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**생성자 체이닝(`this(...)`)** 과 **필드 은닉**이 섞인 문제다. `getX()`는 **Parent의 메서드**이므로 **Parent의 `x`** 를 반환한다는 점이 핵심이다.

## 2. 먼저 알아야 할 개념
### (1) 생성자 호출 순서
`new Child()` →
1. `Child()` → `this(5000)` 으로 **같은 클래스의 다른 생성자** 호출
2. `Child(int x)` 진입 → 첫 줄에 `super()`가 **암묵적으로** 삽입 → **부모 생성자 `Parent()`** 먼저 실행
3. `Parent()` → `this(500)` → `Parent(int x)` 실행 → **Parent.x = 500**
4. 부모 생성이 끝난 뒤 Child 필드 초기화(`int x = 4000`), 그 다음 `this.x = x`(Child.x = 5000)

### (2) 필드는 오버라이딩되지 않는다(은닉)
Parent와 Child에 **같은 이름의 `x`** 가 있어도 **별개의 변수**다.
```text
 Child 객체 안:   Parent.x = 500       Child.x = 5000
```
### (3) 메서드는 정의된 클래스의 필드를 쓴다
`getX()`는 **Parent에만 정의**되어 있고, 그 안의 `x`는 **Parent의 필드**다. Child가 `getX()`를 재정의하지 않았으므로 Parent의 `x`가 반환된다.

## 3. 실행 과정
| 순서 | 호출 | 변화 |
|---:|---|---|
| 1 | `new Child()` → `Child()` | |
| 2 | `this(5000)` → `Child(int x)` | |
| 3 | (암묵적) `super()` → `Parent()` | |
| 4 | `this(500)` → `Parent(int x)` : `this.x = x` | **Parent.x = 500** |
| 5 | 부모 생성 완료, Child 필드 초기화 | Child.x = 4000 |
| 6 | `this.x = x` (Child 생성자) | **Child.x = 5000** |
| 7 | `obj.getX()` → **Parent.getX()** → `return x` (Parent의 x) | **500** |

> **정답: `500`**

## 4. 암기 포인트
- 부모 클래스의 메서드가 접근하는 `x`는 **부모의 필드**다 (자식의 같은 이름 필드가 아님).
- 5000이나 4000이라고 답하기 쉽다 — 필드 은닉에 주의!
