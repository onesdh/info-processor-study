# 문제 20 — Java 생성자 체인과 필드 숨김

## 문제

Child 객체 생성 후 상속된 getX가 반환하는 부모 필드 값을 구하시오.



## 정답

500

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

생성자는 먼저 부모를 초기화하며, 자식의 x 필드와 부모의 x 필드는 서로 다른 필드다.

## 풀이

Child()는 Child(5000)을 호출한다. Child(int)는 명시적 super가 없어 Parent()를 호출하고, Parent()는 this(500)로 Parent.x를 500으로 설정한다. 이후 Child.x는 별도로 5000이 되지만 상속된 getX는 Parent.x를 읽어 500을 반환한다.

## 오답 분석

자식 필드 5000이 부모 메서드에 의해 자동으로 반환되지 않는다. 필드 숨김은 오버라이딩이 아니다.

## 암기 포인트

부모 생성자에서 Parent.x=500, 자식 x와 별개.
