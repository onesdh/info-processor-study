# 문제 20

## 문제

다음 자바 코드에 대한 출력 값을 작성하시오.

```
class Parent {
    int x = 100;

    Parent() {
        this(500);
    }

    Parent(int x) {
        this.x = x;
    }

    int getX() {
        return x;
    }
}

class Child extends Parent {
    int x = 4000;

    Child() {
        this(5000);
    }

    Child(int x) {
        this.x = x;
    }
}

public class Main {
    public static void main(String[] args) {
        Child obj = new Child();
        System.out.println(obj.getX());
    }
}
```

<details>
<summary><strong>정답 보기</strong></summary>

500

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

생성자는 먼저 부모를 초기화하며, 자식의 x 필드와 부모의 x 필드는 서로 다른 필드다.

## 풀이

Child()는 Child(5000)을 호출한다. Child(int)는 명시적 super가 없어 Parent()를 호출하고, Parent()는 this(500)로 Parent.x를 500으로 설정한다. 이후 Child.x는 별도로 5000이 되지만 상속된 getX는 Parent.x를 읽어 500을 반환한다.

## 오답 분석

자식 필드 5000이 부모 메서드에 의해 자동으로 반환되지 않는다. 필드 숨김은 오버라이딩이 아니다.

## 암기 포인트

부모 생성자에서 Parent.x=500, 자식 x와 별개.

</details>
