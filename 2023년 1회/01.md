# 문제 01 — Java static 필드와 후위 증가

## 문제

static 필드 설정 후 후위 증가, 인스턴스 필드 출력을 순서대로 구하시오.

## 정답

10, 11, 10, 20

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

static 변수는 클래스에 하나만 존재하고 후위 증가는 현재 값을 먼저 사용한 뒤 증가한다.

## 풀이

Static.b에 지역 a=10을 저장한다. 첫 출력은 b++의 현재값 10이며 이후 b는 11이 된다. st.b는 같은 static 필드라 11, 지역 a는 10, 인스턴스 필드 st.a는 20이다.

## 오답 분석

static 필드와 인스턴스 필드를 구분한다. 후위 증가 결과는 증가 전 값이다.

## 암기 포인트

static 공유, 후위 증가는 먼저 출력.
