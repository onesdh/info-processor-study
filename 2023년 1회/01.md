# 문제 01

## 문제

아래 자바 코드에서 출력되는 값을 작성하시오.

```
class Static{

    public int a = 20;
    static int b = 0;

}

public class Main{
    public static void main(String[] args) {

        int a;
        a = 10;
        Static.b = a;

        Static st = new Static();

        System.out.println(Static.b++);
        System.out.println(st.b);
        System.out.println(a);
        System.out.print(st.a);
    }
}

```

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**static 변수**(클래스 변수)와 **인스턴스 변수**, 그리고 **후위 증가(`b++`)** 가 섞인 출력을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) static 변수 vs 인스턴스 변수
| 구분 | `static int b` | `int a` |
|---|---|---|
| 소속 | **클래스** (모든 객체가 하나를 공유) | **각 객체**마다 따로 |
| 접근 | `Static.b` 또는 객체이름.b (같은 변수) | 객체이름.a |

```text
 클래스 Static ── static b  (하나만 존재, 공유) ◀── Static.b  /  st.b  (같은 변수)
 객체 st       ── a = 20    (객체 안에 존재)
```
### (2) 후위 증가 `b++`
`System.out.println(Static.b++);` → **현재 값을 먼저 출력**하고, 그 **다음에 1 증가**한다.

### (3) 변수 이름 `a` 가 두 개
`main`의 지역 변수 `a`(=10)와 객체 `st`의 멤버 `a`(=20)는 **서로 다른 변수**다.

## 3. 실행 과정
| 단계 | 코드 | 상태 | 출력 |
|---|---|---|:---:|
| ① | `a = 10; Static.b = a;` | static b = 10 | |
| ② | `Static st = new Static();` | st.a = 20 | |
| ③ | `println(Static.b++)` | **10 출력** 후 b = 11 | **10** |
| ④ | `println(st.b)` | st.b는 static b와 같은 변수 → 11 | **11** |
| ⑤ | `println(a)` | main의 지역 변수 a | **10** |
| ⑥ | `print(st.a)` | 객체의 멤버 a | **20** |

> **정답**
> ```
> 10
> 11
> 10
> 20
> ```

## 4. 암기 포인트
- static은 **공유되는 하나의 변수**: `Static.b`와 `st.b`는 같다.
- `x++`는 **쓰고 나서 증가**, `++x`는 **증가하고 나서 쓰기**.
