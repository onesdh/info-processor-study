# 문제 17

## 문제

다음 JAVA 코드에서 알맞는 출력 값을 작성하시오.

```
abstact class Vehicle {

    String name;
    abstract public String getName(String val);

    public String getName() {
            return "Vehicle name: " + name;
    }
}



class Car extends Vehicle {

    public Car(String val) {
            name=super.name=val;
    }

    public String getName(String val) {
            return "Car name:" + val;
    }

    public String getName(byte val[]) {
            return "Car name:" + val;
    }
}


public class Main {

    public static void main(String[] args) {

    Vehicle obj = new Car("Spark");
    System.out.println(obj.getName());

    }
}
```

## 1. 문제에서 묻는 것
**추상 클래스, 상속, 메서드 오버로딩**이 섞인 코드에서 `obj.getName()`이 어느 메서드를 호출하는지 묻는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 추상 클래스
`abstract class`는 **추상 메서드(몸체 없음)** 를 가질 수 있고, **자식이 반드시 구현**해야 한다. 일반 메서드(몸체 있음)도 함께 가질 수 있다.

### (2) 오버로딩(이름 같고 매개변수 다름)
같은 이름 `getName`이 **서로 다른 시그니처**로 3개 있다.
| 클래스 | 메서드 | 매개변수 |
|---|---|---|
| Vehicle | `getName(String val)` (추상) | String 1개 |
| Vehicle | **`getName()`** | **없음** |
| Car | `getName(String val)` (위 추상 구현) | String 1개 |
| Car | `getName(byte val[])` | byte 배열 |

### (3) 호출 결정
`obj.getName()` → **매개변수가 없는** `getName()`을 찾는다. 오직 **Vehicle의 `getName()`** 만 해당하고 Car는 이를 오버라이딩하지 않았다.

## 3. 실행 과정
```java
Vehicle obj = new Car("Spark");
```
- `Car("Spark")` 생성자: `name = super.name = val;` → 부모 필드 `name`에 `"Spark"` 저장 (Car에는 별도 name 필드 없음).
- `obj.getName()` → **Vehicle.getName()** 실행: `"Vehicle name: " + name` = **`Vehicle name: Spark`**

| 후보 | 호출됨? | 이유 |
|---|:---:|---|
| `Vehicle.getName()` | ✅ | 매개변수 없음 → 일치 |
| `getName(String)` / `getName(byte[])` | ❌ | 인자가 있어 시그니처 불일치 |

> **정답: `Vehicle name: Spark`**

## 4. 암기 포인트
- 매개변수의 **개수·타입**이 다르면 다른 메서드(오버로딩) → 자식이 재정의하지 않은 부모 메서드가 실행된다.
- (원문의 `abstact`는 `abstract`의 오타)
