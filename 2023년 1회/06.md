# 문제 06

## 문제

아래 내용을 확인하여 알맞는 답을 작성하시오.

- 2 계층(데이터링크 계층)에서 구현되는 터널링 기술 중 하나  
- L2F와 PPTP가 결합된 프로토콜로 VPN과 인터넷 서비스 제공자(ISP)가 이용  
- IPsec을 함께 사용하면 PPTP보다 훨씬 안전하지만 보안보다 익명화에 더 적합

## 1. 문제에서 묻는 것
"2계층 터널링, **L2F와 PPTP가 결합**, VPN·ISP가 이용, IPsec과 함께 사용" → 프로토콜 이름을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 터널링과 VPN
**터널링**: 패킷을 다른 패킷 안에 **캡슐화**해 공용망 위로 안전하게 보내는 기술. VPN의 핵심이다.

### (2) VPN 프로토콜
| 프로토콜 | 계층 | 특징 |
|---|:---:|---|
| **PPTP** | 2 | Microsoft 개발, 오래됨, 보안 취약 |
| **L2F** | 2 | Cisco 개발 |
| **L2TP** | 2 | **L2F + PPTP 결합**, 암호화는 자체 제공 안 함 → **보통 IPsec와 함께** (L2TP/IPsec) |
| **IPsec** | 3 | IP 패킷 암호화·인증 |
| SSL VPN | 4~7 | 웹 브라우저 기반 |

```text
 L2TP = Layer 2 Tunneling Protocol   (2계층 터널링 프로토콜)
        └ L2F(Cisco) + PPTP(Microsoft) 의 장점 통합
```
## 3. 문제 풀이
| 단서 | L2TP |
|---|---|
| **2계층(데이터링크)** 에서 구현되는 터널링 | ✅ |
| **L2F와 PPTP가 결합**, VPN·ISP가 이용 | ✅ |
| IPsec과 함께 쓰면 PPTP보다 안전 | ✅ (L2TP/IPsec) |

> **정답: L2TP (Layer 2 Tunneling Protocol)**
