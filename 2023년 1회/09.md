# 문제 09

## 문제

다음 아래 코드에서 이진수를 십진수로 변환하는 코드에 대해 괄호 (a) (b)의 적합한 답을 작성하시오.

```
#include <stdio.h>

int main() {

    int input = 101110;
    int di = 1;
    int sum = 0;

    while (1) {

        if (input == 0) break
        else {

          sum = sum + (input (a)(b)) * di;
             di = di * 2;
             input = input / 10;

        }
    }

    printf("%d", sum);

    return 0;
}
```

<details>
<summary><strong>정답 보기</strong></summary>

1. (a) %  ,(b) 10 or 5 or 2  
2. (a) &  ,(b) 1

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**이진수를 십진수로 변환**하는 코드에서 **마지막 자리 숫자를 추출하는 식**(괄호 (a), (b))을 채우는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 2진수 → 10진수 변환 원리
`101110₂` = 1×2⁵ + 0×2⁴ + 1×2³ + 1×2² + 1×2¹ + 0×2⁰ = 32+8+4+2 = **46**
**오른쪽 자리부터** 각 자리 값 × (1, 2, 4, 8, …)을 더한다.

### (2) 이 코드가 입력을 다루는 방식
`int input = 101110;` 는 **십진수 정수**이지만 모양이 이진수다. 각 **십진 자릿수**를 하나씩 뽑으면 이진수의 각 비트가 된다.
```text
 input % 10 → 마지막 십진 자릿수(= 마지막 비트)     input / 10 → 마지막 자리를 제거
```
### (3) 코드 읽기
```c
sum = sum + (input (a)(b)) * di;   // (마지막 비트) × (자리 가중치)
di  = di * 2;                      // 가중치: 1 → 2 → 4 → 8 …
input = input / 10;                // 마지막 자리를 버림
```
## 3. 괄호 채우기
- **`input % 10`**: 마지막 자릿수를 얻는다. (가장 자연스러운 답)
- 입력이 0과 1로만 이루어져 있으므로 `input % 2`, `input & 1`도 같은 결과(마지막 자리의 홀짝)를 준다.

| (a)(b) 후보 | 의미 | 정답 여부 |
|---|---|:---:|
| `% 10` | 마지막 십진 자릿수 | ✅ |
| `% 2` / `% 5` | 입력이 0/1뿐이라 동일 | ✅(허용) |
| `& 1` | 마지막 비트 | ✅(허용) |

## 4. 실행 과정 (`input = 101110`)
| 반복 | input | `input%10` | di | 더하는 값 | sum |
|---:|---:|---:|---:|---:|---:|
| 1 | 101110 | 0 | 1 | 0×1 = 0 | 0 |
| 2 | 10111 | 1 | 2 | 1×2 = 2 | 2 |
| 3 | 1011 | 1 | 4 | 1×4 = 4 | 6 |
| 4 | 101 | 1 | 8 | 1×8 = 8 | 14 |
| 5 | 10 | 0 | 16 | 0×16 = 0 | 14 |
| 6 | 1 | 1 | 32 | 1×32 = 32 | **46** |
| 7 | 0 | – | – | `input == 0` → break | 46 |

출력: **46**

> **정답: (a) `%`, (b) `10`** (또는 `%` `2`, `&` `1`)

## 5. 암기 포인트
- "마지막 자릿수 추출 = `% 10`", "자릿수 제거 = `/ 10`".
- 가중치 `di`는 2배씩 증가하므로 **이진수 → 십진수**.
