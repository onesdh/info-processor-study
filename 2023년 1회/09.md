# 문제 09

## 문제

다음 아래 코드에서 이진수를 십진수로 변환하는 코드에 대해 괄호 (a) (b)의 적합한 답을 작성하시오.

```
#include <stdio.h>

int main() {

    int input = 101110;
    int di = 1;
    int sum = 0;

    while (1) {

        if (input == 0) break
        else {

          sum = sum + (input (a)(b)) * di;
             di = di * 2;
             input = input / 10;

        }
    }

    printf("%d", sum);

    return 0;
}
```

<details>
<summary><strong>정답 보기</strong></summary>

1. (a) %  ,(b) 10 or 5 or 2  
2. (a) &  ,(b) 1

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

정수로 저장된 비트열에서 마지막 십진 자릿수를 꺼내고 다음 자릿수로 이동한다.

## 풀이

input % 10은 끝자리 0 또는 1을 얻는다. di는 1,2,4,8,…로 두 배씩 커져 각 비트의 가중치를 나타낸다. input/10으로 오른쪽 비트를 제거하고 누적하면 101110₂=46₁₀이다.

## 오답 분석

비트 값 계산을 위해 `& 1`을 쓰는 방식도 있지만, 코드가 input을 10으로 나누므로 해당 자릿수 추출은 `%10`이다.

## 암기 포인트

끝자리 `%10`, 자리 제거 `/10`, 가중치 ×2.

</details>
