# 문제 07 — SSH 원격 접속

## 문제

암호화된 원격 로그인·명령 실행·파일 복사를 제공하며 기본 포트 22를 쓰는 프로토콜을 쓰시오.

## 정답

SSH (Secure Shell)

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

SSH는 안전하지 않은 네트워크에서 암호화된 원격 관리 채널을 제공한다.

## 풀이

SSH는 rlogin·rsh·telnet 등 평문 원격 도구를 대체하며 인증과 암호화를 제공한다. 기본 TCP 포트는 22다.

## 오답 분석

FTP는 파일 전송, HTTPS는 웹 통신이다. 포트 22와 보안 원격 셸은 SSH다.

## 암기 포인트

원격 보안 접속 포트 22는 SSH.
