# 문제 18 — 외부·개념·내부 스키마

## 문제

사용자 관점, 조직 전체 논리 구조, 물리 저장 구조의 스키마 종류를 쓰시오.

## 정답

외부, 개념, 내부 스키마

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

3단계 스키마 구조는 사용자 뷰, 통합 논리 구조, 물리 저장 구조로 데이터 독립성을 지원한다.

## 풀이

외부 스키마는 사용자·응용마다 필요한 부분, 개념 스키마는 조직 전체의 논리 구조, 내부 스키마는 파일·레코드·인덱스 같은 물리 저장 방법을 정의한다.

## 오답 분석

외부 스키마는 여러 개, 개념 스키마는 하나, 내부 스키마는 저장장치 관점이다.

## 암기 포인트

외부 사용자, 개념 조직, 내부 물리.
