# 문제 15

## 문제

다음 파이썬 코드의 알맞는 출력값을 작성하시오.

```
a = {'한국', '중국', '일본'}
a.add('베트남')
a.add('중국')
a.remove('일본')
a.update({'홍콩', '한국', '태국'})
print(a)
```

<summary><strong>정답 보기</strong></summary>

{'한국', '중국', '베트남', '홍콩', '태국'}

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
파이썬 **집합(set)** 의 `add`, `remove`, `update` 동작과 **중복 제거** 특성을 이해했는지 묻는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 집합(set)
| 특징 | 설명 |
|---|---|
| **중복 불가** | 같은 값을 여러 번 넣어도 **하나만** 유지 |
| **순서 없음** | 인덱스 접근 불가, 출력 순서가 일정하지 않을 수 있음 |
| 표기 | `{'a', 'b'}` |

### (2) 주요 메서드
| 메서드 | 동작 |
|---|---|
| `add(x)` | 원소 **하나 추가** (이미 있으면 변화 없음) |
| `remove(x)` | 원소 **삭제** (없으면 오류) |
| `update(집합)` | 다른 집합의 원소를 **모두 추가**(합집합) |

## 3. 실행 과정
| 단계 | 코드 | 집합 상태 |
|---|---|---|
| 시작 | `a = {'한국', '중국', '일본'}` | 한국, 중국, 일본 |
| ① | `a.add('베트남')` | 한국, 중국, 일본, **베트남** |
| ② | `a.add('중국')` | 이미 있음 → **변화 없음** |
| ③ | `a.remove('일본')` | 한국, 중국, 베트남 |
| ④ | `a.update({'홍콩','한국','태국'})` | 한국(이미 있음), **홍콩, 태국** 추가 → 한국, 중국, 베트남, 홍콩, 태국 |

최종 집합: `{'한국', '중국', '베트남', '홍콩', '태국'}` (5개 원소, **출력 순서는 달라질 수 있음**)

> **정답: `{'한국', '중국', '베트남', '홍콩', '태국'}`** (순서 무관)

## 4. 암기 포인트
- 집합은 **중복 제거 + 순서 없음**: 출력 순서는 실행마다 다를 수 있으므로 원소가 맞으면 정답.
- 중복된 값 추가(`add('중국')`, `update`의 '한국')는 무시된다.
