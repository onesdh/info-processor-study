# 문제 08

## 문제

아래 설명에 대한 알맞는 답을 작성하시오.

(보기가 있습니다. ex: 랜섬웨어, 스파이웨어  등)

| 구분 | 내용 |
|---|---|
| (   1   ) | - 감염된 컴퓨터 시스템에서 스스로 복제해 다른 컴퓨터로 복사본을 확산시킬 수 있는 악성 프로그램이다. <br>- 독자적으로 실행되며 다른 실행 프로그램이 필요하지 않으며, 파일 전송 기능을 착취하도록 설계된다. <br>- 자가 복제 및 네트워크를 통한 전파도 가능하다. |
| (    2    ) | - 정상적인 프로그램으로 가장해 사용자가 직접 컴퓨터에 설치하도록 위장하며, 백도어를 만들어 공격자가 침입할 수 있도록 만들거나 시스템을 파괴한다. <br>- 정상적인 프로그램으로 위장하여 시작부터 끝까지 램에 상주하며, 시스템 내부 정보를 공격자의 컴퓨터로 빼돌리는 프로그램이다.  <br>- 좀비PC처럼 내부정보 유출뿐만 아니라 컨트롤까지 가능한 종류가 있고, 단순히 내부 데이터만 유출할 수 있는 타입의 트로이 목마가 있다. <br>- 감염된 후에 스스로를 복제하는 능력은 없다. |
| (    3    ) | - 대상(정상파일)을 감염시키는 형태로 실행되며, 감염시킬 대상이 존재하지 않을 때에는 실행되지 않으며 다른정상파일로의 자기 복제 기능이 있다. <br>- 컴퓨터 시스템에 침입해 프로그램에 기생하며 시스템을 변경하거나 사용할 수 없도록 만드는 악성코드이다. <br>- 네트워크를 통해 전파되지 않으며 방식 및 위치에 따라 여러형태로 나뉜다. |

## 1. 문제에서 묻는 것
세 가지 악성코드의 설명을 읽고 이름(웜 / 트로이 목마 / 바이러스)을 구분하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 악성코드 비교 (시험 단골)
| 구분 | **웜(Worm)** | **트로이 목마(Trojan)** | **바이러스(Virus)** |
|---|---|---|---|
| **복제** | **자기 복제 ○** (스스로) | **복제 ✕** | **자기 복제 ○** (숙주 필요) |
| **실행 방식** | **독립 실행** (숙주 불필요) | 정상 프로그램으로 **위장** | **정상 파일에 기생** (감염 대상 필요) |
| **전파** | **네트워크로 스스로 확산** | 사용자가 직접 설치 | 파일 공유·실행으로 전파(네트워크 자체 전파 ✕) |
| **목적** | 네트워크 마비 | **백도어**, 정보 유출, 원격 제어 | 파일·시스템 손상 |

```text
 웜     : [독립 프로그램] ─스스로 복제─▶ 네트워크 ─▶ 다른 PC (사람 개입 없이)
 트로이 : [정상 앱으로 위장] ─사용자가 설치─▶ 백도어 개방 ─▶ 공격자 침입 (복제 안 함)
 바이러스: [정상 파일] 속에 기생 ─그 파일 실행─▶ 감염 확산 (숙주 파일 없으면 실행 못 함)
```
## 3. 문제 풀이
| 번호 | 핵심 단서 | 정답 |
|---|---|---|
| (1) | **스스로 복제**, **독자적으로 실행(다른 프로그램 불필요)**, 네트워크를 통해 전파 | **웜** |
| (2) | **정상 프로그램으로 위장**, **백도어**, 내부 정보 유출, **스스로 복제 능력 없음** | **트로이 목마** |
| (3) | **감염 대상(정상 파일)이 있어야 실행**, 다른 파일로 자기 복제, **네트워크로 전파되지 않음** | **바이러스** |

> **정답: 1. 웜 / 2. 트로이 목마 / 3. 바이러스**

## 4. 암기 포인트
- **독립 실행·네트워크 전파 = 웜**, **위장 = 트로이(복제 ✕)**, **숙주 필요 = 바이러스**.
