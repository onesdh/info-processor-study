# 문제 04

## 문제

JavaScript와 XML을 이용해 페이지 전체를 새로고침하지 않고 비동기적으로 데이터를 주고받는 기법을 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

AJAX (Asynchronous JavaScript and XML)

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

AJAX는 브라우저와 서버가 비동기 통신해 필요한 데이터만 갱신하는 웹 개발 기법이다.

## 풀이

클라이언트 JavaScript가 요청을 보내고 서버 응답을 처리해 화면 일부를 갱신한다. XML 이름이 포함돼도 실제 데이터 형식은 JSON 등 다양할 수 있다.

## 오답 분석

페이지 전체를 매번 다시 받는 동기 방식과 다르다. XML만 사용할 수 있는 것은 아니다.

## 암기 포인트

비동기 부분 갱신은 AJAX.
