# 문제 04

## 문제

다음 괄호안에 들어가는 용어의 Full Name 또는 약자를 작성하시오.

(   )은/는 비동기적인 웹 애플리케이션의 제작을 위해 JavaScript와 XML을 이용한 비동기적 정보 교환 기법이다.

(   )은/는 필요한 데이터만을 웹서버에 요청해서 받은 후 클라이언트에서 데이터에 대한 처리를 할 수 있다.  
보통 SOAP이나 XML 기반의 웹 서비스 프로토콜이 사용되며, 웹 서버의 응답을 처리하기 위해 클라이언트 쪽에서는 자바스크립트를 쓴다.

(   )은/는 Google Map과 Google pages에서 사용한 기술에 기반하여 제작되었다.

AJAX (Asynchronous JavaScript and XML)

## 1. 문제에서 묻는 것
"JavaScript와 XML로 **비동기** 정보 교환, 필요한 데이터만 서버에 요청, **Google Map**에 사용된 기술" → 용어(Full name 또는 약자)를 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) Ajax = Asynchronous JavaScript And XML
| 구성 | 역할 |
|---|---|
| **Asynchronous(비동기)** | 서버 응답을 기다리는 동안 **페이지를 계속 사용** 가능 |
| **JavaScript** | 요청·화면 갱신 처리 |
| **XML**(요즘은 JSON도) | 주고받는 **데이터 형식** |

### (2) 전통 방식과의 차이
```text
 전통 웹 :  클릭 → 서버에 요청 → 페이지 "전체"를 다시 받아 새로 그림 (깜빡임)
 Ajax    :  클릭 → 서버에 "필요한 데이터만" 비동기 요청 → 화면의 "일부"만 갱신 (매끄러움)
```
- 데이터 처리는 **클라이언트(브라우저)** 에서 JavaScript로 수행한다.
- 대표 사례: **Google Maps**(지도를 드래그하면 필요한 타일만 로드), Google 검색 자동완성.

## 3. 문제 풀이
| 단서 | Ajax |
|---|---|
| 비동기적 웹 애플리케이션, **JavaScript와 XML** 비동기 정보 교환 | ✅ |
| 필요한 데이터만 웹서버에 요청, 클라이언트에서 JavaScript로 처리 | ✅ |
| **Google Map** 등에서 사용한 기술 | ✅ |

> **정답: AJAX (Asynchronous JavaScript and XML)**
