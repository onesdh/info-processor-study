# 문제 02

## 문제

다음 C언어의 출력값을 작성하시오.

```
#include <stdio.h>

int main(){
    char a[] = "Art";
    char* p = NULL;
    p = a;

    printf("%s\n", a);
    printf("%c\n", *p);
    printf("%c\n", *a);
    printf("%s\n", p);

    for(int i = 0; a[i] != '\0'; i++)
    printf("%c", a[i]);

}
```

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**문자 배열과 포인터**로 문자열을 출력하는 여러 방법(`%s`, `%c`, 반복문)을 구분하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 문자 배열과 문자열
```c
char a[] = "Art";        // {'A','r','t','\0'} 4칸 배열
```
```text
 a : A r t \0
 idx 0 1 2 3
```
`a`(배열 이름)는 **첫 원소의 주소**처럼 쓰인다.

### (2) 포인터
`char* p = a;` → p는 `a[0]`을 가리킨다. `*p`는 가리키는 **문자 하나**, `p`(주소) 자체는 문자열의 시작.

### (3) 서식 문자
| 서식 | 인자 | 출력 |
|---|---|---|
| `%s` | 문자열(주소) | `\0` 전까지 **전체** |
| `%c` | 문자 1개 | 그 문자 |

## 3. 줄별 분석
| 코드 | 의미 | 출력 |
|---|---|:---:|
| `printf("%s\n", a)` | 배열 전체를 문자열로 | **Art** |
| `printf("%c\n", *p)` | p가 가리키는 첫 문자 | **A** |
| `printf("%c\n", *a)` | 배열 이름의 첫 문자(`*a` = `a[0]`) | **A** |
| `printf("%s\n", p)` | p부터 문자열 전체 | **Art** |
| `for ... printf("%c", a[i])` | 한 글자씩 널 문자 전까지 | **Art** |

> **정답**
> ```
> Art
> A
> A
> Art
> Art
> ```

## 4. 암기 포인트
- `*a` = `a[0]` (배열 이름은 주소처럼 동작), `%s`에는 **주소**, `%c`에는 **문자**를 준다.
- 마지막 `for`의 출력에는 `\n`이 없어 줄바꿈 없이 끝난다.
