# 문제 02

## 문제

다음 C언어의 출력값을 작성하시오.

```
#include <stdio.h>

int main(){
    char a[] = "Art";
    char* p = NULL;
    p = a;

    printf("%s\n", a);
    printf("%c\n", *p);
    printf("%c\n", *a);
    printf("%s\n", p);

    for(int i = 0; a[i] != '\0'; i++)
    printf("%c", a[i]);

}
```

## 핵심 개념

배열 이름은 첫 원소 주소로 변환되고 %s는 널 문자까지, %c는 한 문자만 출력한다.

## 풀이

a와 p는 모두 문자열 A의 시작을 가리킨다. %s로 전체 문자열 Art, *p와 *a는 첫 문자 A, p의 %s는 다시 Art, 반복문은 각 문자를 차례로 찍어 Art다.

## 오답 분석

%s와 %c의 출력 범위를 혼동하지 않는다. p는 복사된 문자열이 아니라 배열의 첫 주소다.

## 암기 포인트

문자열은 %s, 첫 문자 역참조는 %c.
