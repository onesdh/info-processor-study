# 문제 14

## 문제

다음 코드에서 괄호안에 알맞는 값을 변수명으로 작성하시오.

(코드가 해깔려 시험문제와 동일하지 않지만 패턴이 비슷하다는 점만 참고해주세요.)

```
public class Sort {

    public static void swap(int[] arr, int idx1, int idx2){
        int temp = arr[idx1];
        arr[idx1] = arr[idx2];
        arr[( 1 )] = temp;
    }

    public static void Usort(int[] array, int length){
        for (int i = 0; i < length; i++) {
            for (int j = 0; j < length - i - 1; j++) {
                if (array[j] > array[j + 1]) {
                    swap(array, j, j + 1);
                }
            }
        }
    }

    public static void main(String[] args) {
        int[] item = new int[] { 5, 3, 8, 1, 2, 7 };
        int nx = 6;
        Usort(item, ( 2 ));

        for (int data : item) {
            System.out.print(data + " ");
        }
    }

}
```

출력 값 : 1 2 3 5 7 8

## 핵심 개념

교환 함수는 두 번째 인덱스 위치에 임시 저장 값을 놓고, 배열 길이만큼 정렬 루프를 돈다.

## 풀이

첫 값 arr[idx1]을 temp에 보관한 뒤 arr[idx1]=arr[idx2]로 덮는다. temp는 arr[idx2]에 복원한다. 정렬 호출은 배열 길이 변수 nx를 전달한다.

## 오답 분석

temp를 원래 첫 위치에 넣으면 동일 값을 덮어써 교환이 되지 않는다. 크기 상수 대신 nx를 인자로 넘긴다.

## 암기 포인트

swap의 끝 인덱스 idx2, 정렬 길이 nx.
