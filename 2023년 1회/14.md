# 문제 14

## 문제

다음 코드에서 괄호안에 알맞는 값을 변수명으로 작성하시오.

(코드가 해깔려 시험문제와 동일하지 않지만 패턴이 비슷하다는 점만 참고해주세요.)

```
public class Sort {

    public static void swap(int[] arr, int idx1, int idx2){
        int temp = arr[idx1];
        arr[idx1] = arr[idx2];
        arr[( 1 )] = temp;
    }

    public static void Usort(int[] array, int length){
        for (int i = 0; i < length; i++) {
            for (int j = 0; j < length - i - 1; j++) {
                if (array[j] > array[j + 1]) {
                    swap(array, j, j + 1);
                }
            }
        }
    }

    public static void main(String[] args) {
        int[] item = new int[] { 5, 3, 8, 1, 2, 7 };
        int nx = 6;
        Usort(item, ( 2 ));

        for (int data : item) {
            System.out.print(data + " ");
        }
    }

}
```

출력 값 : 1 2 3 5 7 8

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**버블 정렬** 코드에서 `swap` 함수의 빈칸(1)과 정렬 함수에 넘길 인자(2)를 채우는 문제다.

## 2. 먼저 알아야 할 개념
### (1) swap(두 값 교환)
```java
int temp = arr[idx1];     // ① 첫 값을 임시 변수에 보관
arr[idx1] = arr[idx2];    // ② 첫 칸에 둘째 값을 복사
arr[idx2] = temp;         // ③ 둘째 칸에 보관해 둔 첫 값을 넣음
```
교환은 항상 **세 단계(임시 변수 사용)** 이다.

### (2) 버블 정렬(Bubble Sort)
**이웃한 두 원소를 비교해 순서가 틀리면 교환**하는 과정을 반복한다. 한 번 훑을 때마다 **가장 큰 값이 맨 뒤로 "거품처럼" 이동**한다.
```text
 [5 3 8 1 2 7] → 한 바퀴 후 [3 5 1 2 7 8] → ... → [1 2 3 5 7 8]
```
```java
for (int i = 0; i < length; i++)
    for (int j = 0; j < length - i - 1; j++)     // 이미 뒤로 간 i개는 제외
        if (array[j] > array[j + 1]) swap(array, j, j + 1);
```
## 3. 빈칸 풀이
| 빈칸 | 위치 | 정답 | 이유 |
|---|---|---|---|
| (1) | `arr[( 1 )] = temp;` | **idx2** | 교환의 마지막 단계: 둘째 칸에 temp(원래 첫 값) 저장 |
| (2) | `Usort(item, ( 2 ));` | **nx** | 정렬할 배열의 **길이**(6) 전달 (`nx = 6`) |

`nx`는 `int nx = 6;`으로 선언된 배열 길이이다.

## 4. 정렬 결과 확인
`{5, 3, 8, 1, 2, 7}` → 오름차순 → **`1 2 3 5 7 8`** (문제의 출력값과 일치)

> **정답: (1) idx2 (2) nx**

## 5. 암기 포인트
- 교환의 마지막 줄은 `arr[idx2] = temp;`.
- 버블 정렬 시간 복잡도 **O(n²)**.
