# 문제 05

## 문제

아래 내용을 확인하여 괄호 안에 용어를 표안에 알맞는 값을 고르시오.

(보기가 있습니다. ex: 패킷  등)

| 구분 | 내용 |
|---|---|
| (   ) | - 회선교환 방식과 데이터그램 방식의 장점을 결합한 통신 기술이다.<br> - 처음 패킷으로 최적의 경로를 고정하고 경로가 고정되면 그 다음은 패킷으로 나누어 고속으로 전송할 수 있다.<br> - 통신기술에는 ATM이 있으며, 정해진 시간 안이나 다량의 데이터를 연속으로 보낼 때 적합하다. |
| (   ) | - 패킷교환 방식으로 동작하면서 IP 주소를 사용하는 인터넷을 의미한다. <br> - 각 전송패킷을 미리 정해진 경로 없이 독립적으로 처리하여 교환하는 방식이다 <br> - 특정 교환기의 고장 시 모든 패킷을 잃어버리는 가상회선과 달리, 그 경로를 피해서 전송할 수 있으므로 더욱 신뢰가 가능하다. <br> - 짧은 메시지의 패킷들을 전송할 때 효과적이고 재정렬 기능이 필요하다. |

## 1. 문제에서 묻는 것
두 가지 **패킷 교환 방식**의 특징을 읽고 이름(가상회선 / 데이터그램)을 맞히는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 패킷 교환 방식 2가지
| 구분 | **가상회선(Virtual Circuit)** | **데이터그램(Datagram)** |
|---|---|---|
| 연결 | **연결형** (경로를 먼저 설정) | **비연결형** |
| 경로 | 모든 패킷이 **같은 경로** | 패킷마다 **독립적 경로** |
| 순서 | **순서 보장** | **순서 뒤바뀜** → 재정렬 필요 |
| 장애 시 | 경로 장애 → 해당 경로 패킷 **모두 손실** | 장애 경로를 **피해서** 전송 가능(더 신뢰) |
| 효율 | **다량·연속** 데이터에 유리 | **짧은 메시지**에 유리 |
| 예 | **ATM**, X.25, 프레임 릴레이 | **IP(인터넷)** |

```text
 가상회선: [경로 설정] ─ ①→②→③ (같은 길)       (회선교환 + 패킷교환의 장점)
 데이터그램: ① ─ A경로 / ② ─ B경로 / ③ ─ C경로   (각자 따로)
```
## 3. 문제 풀이
| 단서 | 해당 |
|---|---|
| **회선교환과 데이터그램 장점 결합**, 처음 패킷으로 **경로 고정**, **ATM**, 다량의 데이터를 연속 전송에 적합 | **가상회선** |
| **IP 주소**를 사용하는 인터넷, **미리 정해진 경로 없이 독립적으로 처리**, 특정 교환기 고장 시 경로를 **피해서** 전송, 재정렬 필요 | **데이터그램** |

> **정답: ( ) = 가상회선, ( ) = 데이터그램**

## 4. 암기 포인트
- **가상회선 = 연결형·ATM·순서 보장**, **데이터그램 = 비연결형·IP·순서 재정렬**.
