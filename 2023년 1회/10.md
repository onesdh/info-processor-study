# 문제 10

## 문제

다음 보안 관련 설명으로 괄호안에 알맞는 용어를  작성하시오.

(    )은/는 TCP/IP에서 IP 패킷을 처리할 때 발생되는 문제를 알려주는 프로토콜이다.

(    ) 프로토콜은 보통 다른 호스트나 게이트웨이 와 연결된 네트웍에 문제가 있는지 확인하기 위한 목적으로 주로 사용된다.

(    ) 을/를 이용한 공격에는 (    ) Flooding가 있는데 ping 명령어를 통한 (     ) 패킷을 연속적으로 계속 보내어 서버의 요청에 응답으로 인한 다른작업을 하지 못하도록 하는 공격이다.

## 1. 문제에서 묻는 것
"IP 패킷 처리 중 발생하는 문제를 알리는 프로토콜, **ping** 명령, **Flooding** 공격" → 프로토콜(ICMP)을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) ICMP (Internet Control Message Protocol)
IP는 **오류를 알려 주는 기능이 없어서**, 이를 보완하는 **제어·오류 메시지 프로토콜**이 ICMP다.
| 용도 | 예 |
|---|---|
| **연결 상태 확인** | `ping` — **Echo Request**를 보내면 **Echo Reply**가 돌아옴 |
| **경로 추적** | `traceroute` — TTL 초과 메시지 활용 |
| **오류 보고** | 목적지 도달 불가, 시간 초과 등 |

### (2) ICMP를 이용한 공격
| 공격 | 방식 |
|---|---|
| **ICMP Flooding (Ping Flooding)** | `ping`으로 **ICMP Echo Request를 연속적으로 대량 전송** → 서버가 응답 처리에 자원을 소모해 **다른 작업 불가**(서비스 거부) |
| Smurf | 출발지 위조 + 브로드캐스트로 **증폭** |
| Ping of Death | 비정상적으로 **큰** ICMP 패킷 |

```text
 공격자 ──ICMP Echo Request × 수천~수만──▶ 서버 ──(전부 Reply 처리)──▶ CPU·대역폭 소진 → 정상 서비스 불가
```
## 3. 문제 풀이
| 단서 | ICMP |
|---|---|
| TCP/IP에서 **IP 패킷 처리 시 발생하는 문제를 알려 주는** 프로토콜 | ✅ |
| 연결된 네트워크에 문제가 있는지 **확인**(ping) | ✅ |
| ping으로 ICMP 패킷을 계속 보내 서버를 마비 → **ICMP Flooding** | ✅ |

> **정답: ICMP (Internet Control Message Protocol)**
