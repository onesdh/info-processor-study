# 문제 8

## 문제

다음은 웹 데이터 교환 방식에 관한 문제이다. 아래 설명을 읽고 괄호 안에 들어갈 알맞은 용어를 작성하시오.

(   )은/는 웹 페이지 전체를 다시 불러오지 않고 JavaScript와 XML(또는 JSON)을 이용하여 일부 콘텐츠만 비동기적으로 갱신할 수 있는 기술이다.

(   )은/는 HTML만으로는 구현하기 어려운 동적인 기능들을 가능하게 하여 사용자가 웹 페이지와 보다 자유롭게 상호작용할 수 있도록 해주는 웹 개발 기법이다.

## 1. 문제에서 묻는 것
"웹 페이지를 **새로고침하지 않고**, JavaScript와 XML/JSON으로 **일부만 비동기 갱신**" → 어떤 기술인지 묻는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 기존 웹 방식(동기) vs Ajax(비동기)
| 구분 | 전통 방식 | **Ajax** |
|---|---|---|
| 요청 시 | **페이지 전체**를 다시 불러옴 | **필요한 데이터만** 서버에서 받음 |
| 화면 | 깜빡임, 재로딩 | **부분 갱신**, 매끄러움 |
| 사용자 | 응답 올 때까지 대기 | **다른 작업을 계속** 가능 |

```text
 전통:  [브라우저] ──요청──▶ [서버]      → 전체 HTML 다시 수신 → 페이지 전체 새로 그림
 Ajax: [브라우저] ──(비동기 요청)──▶ [서버] → JSON/XML 데이터만 수신 → 화면의 일부만 갱신
```
### (2) Ajax = Asynchronous JavaScript And XML
| 구성 요소 | 역할 |
|---|---|
| **JavaScript** | 서버 요청·화면 갱신 로직 |
| **XMLHttpRequest / fetch** | 서버와 **비동기 통신** |
| **XML / JSON** | 주고받는 **데이터 형식** (요즘은 JSON이 주류) |
| DOM | 화면의 일부 요소를 수정 |

예) 검색창 자동완성, 좋아요 버튼, 무한 스크롤, 실시간 댓글.

## 3. 문제 풀이
| 단서 | Ajax |
|---|---|
| 페이지 **전체를 다시 불러오지 않고** 일부 콘텐츠만 갱신 | ✅ |
| JavaScript와 **XML(또는 JSON)** 사용 | ✅ |
| **비동기적** 갱신 | ✅ |
| HTML만으로 어려운 **동적 기능** 구현 | ✅ |

> **정답: AJAX (Asynchronous JavaScript and XML)**

## 4. 암기 포인트
- Ajax = **비동기 + 부분 갱신**. 주로 쓰는 데이터 형식: **JSON, XML**.
