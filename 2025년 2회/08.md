# 문제 8 — AJAX

## 문제

전체 페이지를 다시 로드하지 않고 JavaScript와 XML/JSON으로 일부 콘텐츠를 비동기 갱신하는 웹 기법은?

## 원문 이미지

원문 페이지의 해당 문제 영역을 참고하세요.

## 정답

AJAX (Asynchronous JavaScript and XML)

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

비동기 요청·응답을 이용해 부분 화면 갱신을 구현한다.

## 풀이

AJAX는 브라우저가 서버와 비동기 통신한 뒤 필요한 부분만 갱신하도록 하는 기법이다. 요즘은 XML보다 JSON을 흔히 사용하지만 이름은 AJAX로 유지된다.

## 오답 분석

HTML은 구조를 표현하고, AJAX는 브라우저-서버 간 비동기 데이터 교환과 화면 갱신 패턴이다.

## 암기 포인트

비동기 요청·응답을 이용해 부분 화면 갱신을 구현한다.
