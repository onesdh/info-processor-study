# 문제 13 — 라운드로빈 평균 대기 시간

## 문제

양자 4ms, 도착/실행 시간이 P1(0,8), P2(1,4), P3(2,9), P4(3,5)일 때 평균 대기 시간을 구하시오.

## 원문 이미지

원문 페이지의 해당 문제 영역을 참고하세요.

## 정답

11.75ms

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

대기시간 = 완료시간 - 도착시간 - CPU burst 시간

## 풀이

실행 순서는 P1 0–4, P2 4–8 완료, P3 8–12, P4 12–16, P1 16–20 완료, P3 20–24, P4 24–25 완료, P3 25–26 완료다. 대기시간은 완료-도착-실행시간이다. P1=12, P2=3, P3=15, P4=17ms라 평균은 47/4=11.75ms다.

## 오답 분석

도착 시각을 고려하지 않은 순환 순서는 틀린다. 문맥 교환은 무시하므로 추가 시간을 더하지 않는다.
