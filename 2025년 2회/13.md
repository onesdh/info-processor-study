# 문제 13

## 문제

라운드로빈(RR) 방식을 이용하고 아래 내용을 참고하여 평균대기시간을 구하시오.

운영체제에서 라운드로빈(Round Robin, RR) 스케줄링은 각 프로세스에 동일한 시간 할당량(타임 퀀텀)을 순차적으로 부여하며 CPU를 할당하는 방식이다.

다음은 4개의 프로세스가 서로 다른 시간에 도착하며 각기 다른 실행 시간을 가지는 상황이다. 이때 시간 할당량은 4ms이고 컨텍스트 스위칭 시간은 무시한다고 가정한다.

아래 정보를 바탕으로 라운드로빈(RR) 방식으로 CPU 스케줄링을 수행할 경우 모든 프로세스의 평균 대기시간(Average Waiting Time)은 얼마인가?

| 프로세스 | 도착 시간(ms) | 실행 시간(ms) |
|---|---|---|
| P1 | 0 | 8 |
| P2 | 1 | 4 |
| P3 | 2 | 9 |
| P4 | 3 | 5 |

<details>
<summary><strong>정답 보기</strong></summary>

11.75ms

</details>

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**라운드 로빈(RR)**, 타임 퀀텀 4ms로 4개 프로세스를 처리할 때의 **평균 대기시간**을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 라운드 로빈(RR)
모든 프로세스가 **같은 시간(타임 퀀텀)** 씩 번갈아 CPU를 사용한다. 퀀텀 안에 끝나지 못하면 **큐의 맨 뒤**로 돌아가 다시 차례를 기다린다. (선점형)
```text
 준비 큐:  [P1][P2][P3]  →  P1이 4ms 실행 → 안 끝나면 큐 맨 뒤로 [P2][P3][P1]
```
### (2) 큐에 넣는 순서의 규칙
퀀텀이 끝나는 순간 **새로 도착한 프로세스**와 **막 쫓겨나는 프로세스**가 겹치면, 일반적으로 **새로 도착한 프로세스를 먼저** 큐에 넣고 쫓겨난 프로세스를 그 뒤에 넣는다.

### (3) 대기시간
**대기시간 = 종료 시각 − 도착 시각 − 실행 시간**

## 3. 문제 데이터 (퀀텀 = 4ms)
| 프로세스 | 도착 | 실행 |
|---|---:|---:|
| P1 | 0 | 8 |
| P2 | 1 | 4 |
| P3 | 2 | 9 |
| P4 | 3 | 5 |

## 4. 간트 차트 만들기
| 구간 | 실행 | 사유 | 남은 시간 | 큐 상태(실행 후) |
|---|---|---|---|---|
| 0~4 | **P1** | 퀀텀 4 사용 | P1 4 | P2, P3, P4, P1 (그동안 도착한 P2~P4 먼저) |
| 4~8 | **P2** | 4로 종료 | P2 0 ✔ | P3, P4, P1 |
| 8~12 | **P3** | 퀀텀 4 사용 | P3 5 | P4, P1, P3 |
| 12~16 | **P4** | 퀀텀 4 사용 | P4 1 | P1, P3, P4 |
| 16~20 | **P1** | 4로 종료 | P1 0 ✔ | P3, P4 |
| 20~24 | **P3** | 퀀텀 4 사용 | P3 1 | P4, P3 |
| 24~25 | **P4** | 1로 종료 | P4 0 ✔ | P3 |
| 25~26 | **P3** | 1로 종료 | P3 0 ✔ | |

```text
 0    4    8    12   16   20   24 25 26
 | P1 | P2 | P3 | P4 | P1 | P3 |P4|P3|
```
## 5. 대기시간 계산
| 프로세스 | 종료 시각 | 종료 − 도착 − 실행 | 대기시간 |
|---|---:|---|---:|
| P1 | 20 | 20 − 0 − 8 | **12** |
| P2 | 8 | 8 − 1 − 4 | **3** |
| P3 | 26 | 26 − 2 − 9 | **15** |
| P4 | 25 | 25 − 3 − 5 | **17** |

평균 대기시간 = (12 + 3 + 15 + 17) ÷ 4 = 47 ÷ 4 = **11.75ms**

> **정답: 11.75ms**

## 6. 암기 포인트
- RR 풀이는 **큐 상태를 표로** 추적하면 실수가 줄어든다.
- 같은 데이터를 SRT로 풀면 6.5ms(2026년 2회 8번) — 알고리즘에 따라 결과가 크게 다르다.
