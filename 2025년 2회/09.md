# 문제 9

## 문제

다음은 Java언어의 문제이다. 아래 코드를 보고 알맞는 출력값을 작성하시오.

```
public class Main {

    static interface F {
        int apply(int x) throws Exception;
    }

    public static int run(F f) {
        try {
            return f.apply(3);
        } catch (Exception e) {
            return 7;
        }
    }

    public static void main(String[] args) {

        F f = (x) -> {
            if (x > 2) {
                throw new Exception();
            }
            return x * 2;
        };

        System.out.print(run(f) + run((int n) -> n + 9));
    }

}
```

<summary><strong>정답 보기</strong></summary>

19

</details>

## 핵심 개념

예외는 호출 스택을 따라 전달되며 catch가 잡으면 해당 catch의 반환값이 사용된다.

## 풀이

첫 번째 람드는 x=3에서 x>2가 참이므로 예외를 던진다. run의 catch가 7을 반환한다. 두 번째 run은 3+9=12를 반환한다. 출력은 7+12=19다.

## 오답 분석

첫 번째 호출은 x*2=6으로 끝나지 않고 예외 경로로 들어가므로 6+12가 아니다.

## 암기 포인트

예외는 호출 스택을 따라 전달되며 catch가 잡으면 해당 catch의 반환값이 사용된다.
