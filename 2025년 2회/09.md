# 문제 9

## 문제

다음은 Java언어의 문제이다. 아래 코드를 보고 알맞는 출력값을 작성하시오.

```
public class Main {

    static interface F {
        int apply(int x) throws Exception;
    }

    public static int run(F f) {
        try {
            return f.apply(3);
        } catch (Exception e) {
            return 7;
        }
    }

    public static void main(String[] args) {

        F f = (x) -> {
            if (x > 2) {
                throw new Exception();
            }
            return x * 2;
        };

        System.out.print(run(f) + run((int n) -> n + 9));
    }

}
```

## 1. 문제에서 묻는 것
Java의 **람다식과 예외 처리**가 결합된 코드에서 `run(f) + run(람다)`의 합을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 함수형 인터페이스와 람다식
**추상 메서드가 하나뿐인 인터페이스**는 **람다식 `(매개변수) -> 식`** 으로 구현을 간단히 쓸 수 있다.
```java
interface F { int apply(int x) throws Exception; }   // 추상 메서드 1개
F f = (x) -> { ... };                                  // 람다 = apply의 구현
```
### (2) throws와 try-catch
| 키워드 | 의미 |
|---|---|
| `throws Exception` | 이 메서드가 **예외를 던질 수 있음**을 선언 |
| `throw new Exception()` | 예외를 **발생**시킴 |
| `try { } catch (Exception e) { }` | 예외가 발생하면 **catch 블록으로 점프** |

### (3) 실행 흐름
`try` 안에서 **예외가 발생하면 그 줄 이후는 실행되지 않고** 곧바로 `catch`로 이동한다. `return`이 있어도 마찬가지다.

## 3. 코드 분석
```java
public static int run(F f) {
    try      { return f.apply(3); }     // 3을 넘겨 호출
    catch (Exception e) { return 7; }    // 예외 발생 시 7
}
F f = (x) -> { if (x > 2) throw new Exception(); return x * 2; };
```
- `f`: x > 2이면 **예외**, 아니면 `x * 2`.
- 두 번째 람다 `(int n) -> n + 9`: 단순히 `n + 9` 반환.

## 4. 실행 과정
| 호출 | apply(3) 결과 | 반환값 |
|---|---|---:|
| `run(f)` | x=3 > 2 → **예외 발생** → catch | **7** |
| `run((int n) -> n + 9)` | 3 + 9 = 12 (예외 없음) | **12** |

`System.out.print(run(f) + run(...))` → 7 + 12 = **19**
(두 값 모두 `int`이므로 **덧셈**이다.)

> **정답: `19`**

## 5. 암기 포인트
- 예외 발생 → **catch의 return 값**이 반환된다.
- `int + int`는 덧셈. 문자열 연결이 아니다.
