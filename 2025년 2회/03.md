# 문제 3

## 문제

공개키 기반 인증과 암호화 통신을 제공하고 기본 포트 22를 사용하는 Telnet의 보안 대안을 쓰시오.

## 원문 이미지

원문 페이지의 해당 문제 영역을 참고하세요.

<details>
<summary><strong>정답 보기</strong></summary>

SSH (Secure Shell)

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

SSH=22/TCP, Telnet=23/TCP

## 풀이

SSH는 원격 로그인과 명령 실행을 암호화한다. 기본 TCP 포트는 22다. Telnet은 일반적으로 내용을 암호화하지 않아 도청에 취약하다.

## 오답 분석

FTP는 파일 전송, HTTPS는 웹 통신 보호에 사용된다.

## 암기 포인트

SSH=22/TCP, Telnet=23/TCP

</details>
