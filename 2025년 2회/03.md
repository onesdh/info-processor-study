# 문제 3

## 문제

다음은 정보보안 관련 문제이다. 아래 내용을 보고 알맞는 단어를 작성하시오.

원격 접속과 관련된 보안 프로토콜이며 암호화된 통신을 제공하는 보안 접속용 프로토콜이다.

공개키 기반의 인증 방식을 사용하며 암호화된 데이터 전송을 지원한다.

주로 원격 서버에 안전하게 접속할 때 사용되며 기본 포트 번호는 22번이다.

Telnet의 보안 취약점을 보완한 대안으로 널리 사용된다.

## 1. 문제에서 묻는 것
"**암호화된 원격 접속**, **22번 포트**, **Telnet의 보안 취약점 보완**" → 어떤 프로토콜인지 묻는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 원격 접속
멀리 있는 서버에 **네트워크로 접속해서 명령을 입력**하는 것(서버 관리, 개발).

### (2) Telnet의 문제
Telnet(포트 23)은 아이디·비밀번호·명령을 **평문(암호화 없이)** 으로 전송한다. 중간에서 **도청(스니핑)** 하면 그대로 노출된다.
```text
 Telnet : 클라이언트 ─── "root / 1234" (평문) ───▶ 서버      (도청 가능 ⚠)
 SSH    : 클라이언트 ─── ▒▒▒▒▒ (암호화) ▒▒▒▒▒ ───▶ 서버      (도청해도 해독 불가)
```
### (3) SSH (Secure Shell)
| 항목 | 내용 |
|---|---|
| 목적 | **안전한 원격 접속** (명령 실행, 파일 전송 SFTP/SCP) |
| 기본 포트 | **TCP 22** |
| 인증 | **공개키 기반** 인증(또는 비밀번호) |
| 보안 | 통신 전체 **암호화**, 무결성 보장 |
| 관계 | **Telnet(23)의 보안 대안** |

### (4) 자주 나오는 포트 번호
| 프로토콜 | 포트 |
|---|---|
| FTP | 20, 21 |
| **SSH** | **22** |
| Telnet | 23 |
| SMTP | 25 |
| DNS | 53 |
| HTTP | 80 |
| HTTPS | 443 |

## 3. 문제 풀이
| 단서 | SSH |
|---|---|
| 암호화된 통신을 제공하는 원격 접속 프로토콜 | ✅ |
| 공개키 기반 인증 | ✅ |
| 기본 포트 22번 | ✅ |
| Telnet 취약점 보완 | ✅ |

> **정답: SSH (Secure Shell)**
