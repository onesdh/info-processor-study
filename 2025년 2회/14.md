# 문제 14

## 문제

다음은 C언어의 문제이다. 아래 코드를 보고 알맞는 출력값을 작성하시오.

```
#include <stdio.h>

struct dat {
    int x;
    int y;
};

int main() {
    struct dat a[] = {{1, 2}, {3, 4}, {5, 6}};
    struct dat* ptr = a;
    struct dat** pptr = &ptr;

    (*pptr)[1] = (*pptr)[2];
    printf("%d 그리고 %d", a[1].x, a[1].y);

    return 0;
}

```

<summary><strong>정답 보기</strong></summary>

5 그리고 6

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**구조체 배열 + 구조체 포인터 + 이중 포인터**를 통한 **구조체 대입**의 결과를 묻는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 구조체 배열과 포인터
```c
struct dat a[] = {{1,2}, {3,4}, {5,6}};
```
```text
 a[0] = {1, 2}    a[1] = {3, 4}    a[2] = {5, 6}
```
### (2) 포인터와 이중 포인터
| 변수 | 의미 | 값 |
|---|---|---|
| `ptr` | 배열 첫 원소 `a[0]`의 주소 | `&a[0]` |
| `pptr` | **`ptr`의 주소** (포인터를 가리키는 포인터) | `&ptr` |
| `*pptr` | pptr이 가리키는 곳의 값 = `ptr` | `&a[0]` |
| `(*pptr)[1]` | `ptr[1]` = `a[1]` | |

```text
 pptr ──▶ ptr ──▶ a[0] | a[1] | a[2]
        (*pptr)     [0]    [1]    [2]
```
### (3) 구조체 대입
`구조체A = 구조체B;` 는 **모든 멤버를 복사**한다. (`A.x = B.x; A.y = B.y;`)

## 3. 실행 과정
`(*pptr)[1] = (*pptr)[2];`
- `(*pptr)[1]` = `a[1]`  (왼쪽: 대입 대상)
- `(*pptr)[2]` = `a[2]` = `{5, 6}` (오른쪽: 복사할 값)
→ `a[1]`이 `{3, 4}`에서 **`{5, 6}`** 으로 바뀐다.

| | a[0] | a[1] | a[2] |
|---|---|---|---|
| 전 | {1, 2} | {3, 4} | {5, 6} |
| 후 | {1, 2} | **{5, 6}** | {5, 6} |

`printf("%d 그리고 %d", a[1].x, a[1].y)` → **5 그리고 6**

> **정답: `5 그리고 6`**

## 4. 암기 포인트
- `(*pptr)[i]` = `ptr[i]` = `a[i]`. 괄호를 먼저 풀자.
- 구조체 대입 = 멤버 **전체 값 복사**.
