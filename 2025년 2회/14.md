# 문제 14

## 문제

다음은 C언어의 문제이다. 아래 코드를 보고 알맞는 출력값을 작성하시오.

```
#include <stdio.h>

struct dat {
    int x;
    int y;
};

int main() {
    struct dat a[] = {{1, 2}, {3, 4}, {5, 6}};
    struct dat* ptr = a;
    struct dat** pptr = &ptr;

    (*pptr)[1] = (*pptr)[2];
    printf("%d 그리고 %d", a[1].x, a[1].y);

    return 0;
}

```

<details>
<summary><strong>정답 보기</strong></summary>

5 그리고 6

</details>

<summary><strong>상세 해설</strong></summary>

## 핵심 개념

구조체 대입은 모든 멤버 값을 복사한다. 포인터가 가리키는 배열 요소는 포인터 인덱싱으로 접근한다.

## 풀이

*pptr은 ptr이고 ptr은 배열 a의 첫 구조체 주소다. 배열 인덱스 2의 구조체 {5,6}를 인덱스 1에 구조체 대입하므로 a[1]도 {5,6}이 된다.

## 오답 분석

주소를 서로 바꾸는 코드가 아니라 구조체 값 전체를 대입한다.

## 암기 포인트

구조체 대입은 모든 멤버 값을 복사한다. 포인터가 가리키는 배열 요소는 포인터 인덱싱으로 접근한다.
