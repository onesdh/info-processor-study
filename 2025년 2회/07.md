# 문제 7

## 문제

다음은 디자인 패턴에 관한 문제이다. 아래 내용을 보고 알맞는 단어를 작성하시오.

어떤 객체에 대한 접근을 제어하거나 추가적인 기능을 부여하기 위해 해당 객체의 대리 객체를 사용하는 방식의 디자인 패턴이다.

실제 객체에 대한 접근 전에 필요한 작업을 수행할 수 있으며 실제 객체의 생성을 지연시켜 메모리와 자원을 절약할 수 있다.

또한, 실제 객체를 감추어 정보은닉을 강화할 수 있다는 장점이 있다.

## 핵심 개념

Proxy는 접근 제어/대리, Decorator는 같은 인터페이스로 책임을 덧붙이는 데 초점이 있다.

## 풀이

프록시는 실제 객체와 같은 인터페이스를 제공하는 대리 객체다. 실제 객체 호출 전에 접근 권한을 검사하거나, 필요할 때 실제 객체를 만드는 지연 초기화, 원격 호출 제어 등을 수행할 수 있다.

## 오답 분석

Adapter는 서로 다른 인터페이스를 호환시키고, Facade는 복잡한 하위 시스템에 단순한 창구를 제공한다.

## 암기 포인트
