# 문제 19 — SYN Flooding

## 문제

TCP 연결에서 다수의 SYN만 보내고 마지막 ACK를 보내지 않아 서버의 반개방 연결 큐를 소진시키는 공격은?

## 원문 이미지

원문 페이지의 해당 문제 영역을 참고하세요.

## 정답

SYN Flooding

<summary><strong>상세 해설</strong></summary>

## 핵심 개념

SYN Flooding은 TCP 연결 설정을 악용한 서비스 거부 공격이다.

## 풀이

TCP 3-way handshake에서 서버는 SYN을 받으면 SYN-ACK를 보내고 ACK를 기다린다. 공격자가 ACK를 완료하지 않은 요청을 대량 생성하면 서버 자원이 반개방 연결에 묶여 정상 연결이 어려워진다.

## 오답 분석

UDP Flooding은 UDP 트래픽을 대량 발생시키고, Smurf 공격은 ICMP 브로드캐스트를 악용한다.

## 암기 포인트

SYN Flooding은 TCP 연결 설정을 악용한 서비스 거부 공격이다.
