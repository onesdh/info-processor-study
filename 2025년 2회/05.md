# 문제 5

## 문제

다음은 Java의 문제이다. 아래 코드를 보고 알맞는 출력값을 작성하시오.

```
public class Main {
    public static void change(String[] data, String s){
        data[0] = s;
        s = "Z";
    }

    public static void main(String[] args) {
        String data[] = { "A" };
        String s = "B";

        change(data, s);
        System.out.print(data[0] + s);
    }
}
```

BB

## 핵심 개념

배열 객체의 내용 수정은 공유 객체에 반영되지만, 매개변수 변수 자체 재대입은 호출자의 변수를 바꾸지 않는다.

## 풀이

Java는 참조값도 값으로 전달한다. data 매개변수에는 배열 객체를 가리키는 참조의 복사본이 들어오므로 같은 배열의 원소를 바꾸면 호출자도 변화를 본다. 호출자는 data[0]이 B가 된다. 반면 매개변수 s에 Z를 다시 대입해도 호출자의 변수 s는 B 그대로다.

## 오답 분석

문자열이 불변인 것과 참조 전달을 혼동하지 않는다. 핵심은 배열 원소 수정과 지역 변수 재대입의 차이다.

## 암기 포인트

배열 객체의 내용 수정은 공유 객체에 반영되지만, 매개변수 변수 자체 재대입은 호출자의 변수를 바꾸지 않는다.
