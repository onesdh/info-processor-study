# 문제 5

## 문제

다음은 Java의 문제이다. 아래 코드를 보고 알맞는 출력값을 작성하시오.

```
public class Main {
    public static void change(String[] data, String s){
        data[0] = s;
        s = "Z";
    }

    public static void main(String[] args) {
        String data[] = { "A" };
        String s = "B";

        change(data, s);
        System.out.print(data[0] + s);
    }
}
```

## 1. 문제에서 묻는 것
Java의 **매개변수 전달 방식**(참조 전달의 정확한 의미)을 묻는 문제다. 배열 안의 값은 바뀌지만, 매개변수 `s` 자체의 재대입은 호출한 쪽에 영향을 주지 못한다.

## 2. 먼저 알아야 할 개념
### (1) Java는 항상 "값 전달(Pass by Value)"
메서드를 호출하면 **변수에 들어 있는 값을 복사**해서 넘긴다.
- 기본형(`int` 등): **실제 값**이 복사된다.
- 참조형(배열, String, 객체): **객체의 주소(참조값)가 복사**된다.

### (2) 참조값이 복사되면?
```text
 main                         change(data, s)
 data ──┐                     data ──┐   (같은 배열을 가리킴)
        ▼                            ▼
       [ "A" ]  ◀─────────────── 같은 배열 객체
 s ──▶ "B"                    s ──▶ "B"  (s는 복사본)
```
| 동작 | 결과 |
|---|---|
| `data[0] = s` | **같은 배열**을 수정 → main의 `data[0]`도 변함 ✅ |
| `s = "Z"` | **복사본 변수 s**가 다른 문자열을 가리킬 뿐 → main의 `s`는 그대로 ❌ |

### (3) String은 불변(immutable)
문자열 객체 자체는 바꿀 수 없다. `s = "Z"`는 **새 문자열을 가리키게** 할 뿐이다.

## 3. 실행 과정
| 단계 | 코드 | data[0] | main의 s | change 안의 s |
|---|---|---|---|---|
| 시작 | `data={"A"}, s="B"` | "A" | "B" | |
| 호출 | `change(data, s)` | "A" | "B" | "B"(복사) |
| ① | `data[0] = s` | **"B"** | "B" | "B" |
| ② | `s = "Z"` | "B" | **"B"(그대로)** | "Z" |
| 종료 | 메서드 반환 | "B" | "B" | (사라짐) |

`System.out.print(data[0] + s)` → `"B" + "B"` = **BB**

> **정답: `BB`**

## 4. 암기 포인트
- **객체 내용 수정은 반영**(같은 객체), **참조 변수 재대입은 반영 안 됨**(복사본).
- 흔한 함정: "배열이니까 바뀐다 → ZB?" 아님. `s`는 바뀌지 않는다.
