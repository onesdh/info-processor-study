# 문제 10

## 문제

다음은 Java언어의 문제이다. 아래 코드를 보고 알맞는 출력값을 작성하시오.

```
public class Main{

    public static class Parent {

        public int x(int i) { return i + 2; }
        public static String id() { return "P";}

    }

    public static class Child extends Parent {

        public int x(int i) { return i + 3; }
        public String x(String s) { return s + "R"; }
        public static String id() { return "C"; }

    }

    public static void main(String[] args) {

        Parent ref = new Child();
        System.out.println(ref.x(2) + ref.id());

    }

}
```

<details>
<summary><strong>정답 보기</strong></summary>

5P

</details>

<summary><strong>상세 해설</strong></summary>

## 핵심 개념

인스턴스 메서드 오버라이딩은 런타임 객체 타입, static 메서드는 참조/클래스 타입에 따라 결정된다.

## 풀이

인스턴스 메서드 x는 동적 디스패치되어 실제 객체 Child의 오버라이드가 호출되며 2+3=5다. static id는 오버라이딩이 아니라 숨김이므로 참조 변수의 선언 타입 Parent를 기준으로 Parent.id()가 호출되어 P가 붙는다.

## 오답 분석

Child 객체라는 이유만으로 static 메서드가 동적 바인딩된다고 보면 안 된다.

## 암기 포인트

인스턴스 메서드 오버라이딩은 런타임 객체 타입, static 메서드는 참조/클래스 타입에 따라 결정된다.
