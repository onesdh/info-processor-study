# 문제 10

## 문제

다음은 Java언어의 문제이다. 아래 코드를 보고 알맞는 출력값을 작성하시오.

```
public class Main{

    public static class Parent {

        public int x(int i) { return i + 2; }
        public static String id() { return "P";}

    }

    public static class Child extends Parent {

        public int x(int i) { return i + 3; }
        public String x(String s) { return s + "R"; }
        public static String id() { return "C"; }

    }

    public static void main(String[] args) {

        Parent ref = new Child();
        System.out.println(ref.x(2) + ref.id());

    }

}
```

<summary><strong>정답 보기</strong></summary>

5P

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**오버라이딩(재정의)** 과 **static 메서드(정적 바인딩)** 의 차이를 묻는 문제다. `ref`의 **변수 타입은 Parent**, **실제 객체는 Child**이다.

## 2. 먼저 알아야 할 개념
### (1) 인스턴스 메서드 → 동적 바인딩
상속 관계에서 자식이 부모 메서드를 **같은 시그니처로 재정의(오버라이딩)** 하면, 호출 시 **실제 객체의 타입**에 따라 자식 메서드가 실행된다.

### (2) static 메서드 → 정적 바인딩 (은닉)
static 메서드는 **객체가 아닌 클래스에 속한다.** 같은 이름으로 자식이 만들어도 **오버라이딩이 아니라 "은닉(hiding)"** 이고, **참조 변수의 선언 타입**을 기준으로 호출된다.

| 구분 | 인스턴스 메서드 | static 메서드 |
|---|---|---|
| 호출 기준 | **실제 객체 타입** | **변수의 선언 타입** |
| 결정 시점 | 실행 시 | 컴파일 시 |
| 이름 | 오버라이딩 | 은닉(Hiding) |

## 3. 코드 분석
```text
 Parent : int x(int i) = i + 2        static id() = "P"
 Child  : int x(int i) = i + 3        static id() = "C"
          String x(String s)          (오버로딩 - 이번 호출과 무관)

 Parent ref = new Child();   // 선언 타입 Parent, 실제 객체 Child
```
## 4. 실행 과정
| 호출 | 판단 | 결과 |
|---|---|---|
| `ref.x(2)` | 인스턴스 메서드 → **실제 객체(Child)** 의 `x(int)` → 2 + 3 | **5** |
| `ref.id()` | static → **선언 타입(Parent)** 의 `id()` | **"P"** |

`System.out.println(ref.x(2) + ref.id())` → `5 + "P"` → 정수 5와 문자열 연결 → **`5P`**

> **정답: `5P`**

## 5. 암기 포인트
- **일반 메서드 = 실제 객체 기준**(자식 것), **static = 변수 타입 기준**(부모 것).
- `int + String`이면 문자열 연결이다.
