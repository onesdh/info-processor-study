# 문제 15

## 문제

다음은 Java언어의 문제이다. 아래 코드를 보고 알맞는 출력값을 작성하시오.

```
public class Main{
    public static class BO {
        public int v;
        public BO(int v) {
            this.v = v;
        }
    }
    public static void main(String[] args) {
        BO a = new BO(1);
        BO b = new BO(2);
        BO c = new BO(3);
        BO[] arr = {a, b, c};
        BO t = arr[0];
        arr[0] = arr[2];
        arr[2] = t;
        arr[1].v = arr[0].v;
        System.out.println(a.v + "a" + b.v + "b" + c.v);
    }
}

```

<details>
<summary><strong>정답 보기</strong></summary>

1a3b3

</details>

<summary><strong>상세 해설</strong></summary>

## 핵심 개념

배열 원소에는 객체 자체가 아니라 객체 참조가 저장된다. 참조 교환과 객체 필드 수정은 다르다.

## 풀이

처음 배열은 [a,b,c]다. 첫째와 셋째 참조를 교환해 [c,b,a]가 된다. arr[1]은 b, arr[0]은 c이므로 b.v가 3으로 바뀐다. 객체 a와 c는 1, 3을 유지해 연결 결과는 1a3b3이다.

## 오답 분석

참조 배열의 위치를 바꾸었다고 객체 a와 c 자체가 교환되는 것은 아니다.

## 암기 포인트

배열 원소에는 객체 자체가 아니라 객체 참조가 저장된다. 참조 교환과 객체 필드 수정은 다르다.
