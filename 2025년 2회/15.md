# 문제 15

## 문제

다음은 Java언어의 문제이다. 아래 코드를 보고 알맞는 출력값을 작성하시오.

```
public class Main{
    public static class BO {
        public int v;
        public BO(int v) {
            this.v = v;
        }
    }
    public static void main(String[] args) {
        BO a = new BO(1);
        BO b = new BO(2);
        BO c = new BO(3);
        BO[] arr = {a, b, c};
        BO t = arr[0];
        arr[0] = arr[2];
        arr[2] = t;
        arr[1].v = arr[0].v;
        System.out.println(a.v + "a" + b.v + "b" + c.v);
    }
}

```

## 1. 문제에서 묻는 것
**객체 참조를 담은 배열의 순서를 바꿨을 때**, 원래 변수 `a`, `b`, `c`의 값이 어떻게 변하는지 묻는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 객체 배열 = 객체의 "주소 목록"
`BO[] arr = {a, b, c};` 에서 배열 칸에는 **객체 자체가 아니라 객체를 가리키는 참조(주소)** 가 들어간다.
```text
 a ──▶ [BO v=1]      arr[0] ──┐
 b ──▶ [BO v=2]      arr[1] ──┼─ 같은 객체를 가리킴
 c ──▶ [BO v=3]      arr[2] ──┘
```
### (2) 참조 교환은 객체를 바꾸지 않는다
`arr[0]`과 `arr[2]`의 참조를 맞바꾸는 것은 **배열 칸이 가리키는 대상을 바꿀 뿐**, 객체 `a`, `c`의 값(v)은 변하지 않는다.

### (3) 같은 객체를 가리키면 한쪽 수정이 다른 쪽에 보인다
`arr[1].v = ...` 는 `arr[1]`이 가리키는 **객체의 v**를 직접 바꾼다.

## 3. 실행 과정
| 단계 | 코드 | arr[0] | arr[1] | arr[2] |
|---|---|---|---|---|
| 초기 | `arr = {a,b,c}` | a(1) | b(2) | c(3) |
| ① | `BO t = arr[0]` | | | t → a |
| ② | `arr[0] = arr[2]` | **c** | b | c |
| ③ | `arr[2] = t` | c | b | **a** |
| ④ | `arr[1].v = arr[0].v` | c | **b.v = c.v = 3** | a |

최종 결과: 배열 = `[c, b, a]`

| 변수 | v |
|---|---:|
| a | 1 (변화 없음) |
| b | **3** (④에서 변경) |
| c | 3 |

`a.v + "a" + b.v + "b" + c.v` → `1` + `"a"` + `3` + `"b"` + `3` = **`1a3b3`**

> **정답: `1a3b3`**

## 4. 암기 포인트
- 참조 배열의 **순서를 바꿔도 객체 값은 그대로**.
- `arr[i].v = …`는 배열 칸이 가리키는 **실제 객체의 값**을 바꾼다 → 원래 변수(`b`)에도 반영.
