# 문제 15 — Java 객체 배열 참조 교환

## 문제

BO 객체 참조 배열의 첫째와 셋째를 바꾼 뒤 arr[1].v에 arr[0].v를 대입한다. 객체 a,b,c의 v를 문자열로 출력한 결과는?

## 원문 이미지

원문 페이지의 해당 문제 영역을 참고하세요.

<details>
<summary><strong>정답 보기</strong></summary>

1a3b3

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

배열 원소에는 객체 자체가 아니라 객체 참조가 저장된다. 참조 교환과 객체 필드 수정은 다르다.

## 풀이

처음 배열은 [a,b,c]다. 첫째와 셋째 참조를 교환해 [c,b,a]가 된다. arr[1]은 b, arr[0]은 c이므로 b.v가 3으로 바뀐다. 객체 a와 c는 1, 3을 유지해 연결 결과는 1a3b3이다.

## 오답 분석

참조 배열의 위치를 바꾸었다고 객체 a와 c 자체가 교환되는 것은 아니다.

## 암기 포인트

배열 원소에는 객체 자체가 아니라 객체 참조가 저장된다. 참조 교환과 객체 필드 수정은 다르다.
