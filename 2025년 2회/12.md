# 문제 12

## 문제

다음은 C언어의 문제이다. 아래 코드를 보고 알맞는 출력값을 작성하시오.

```
#include <stdio.h>
#define SIZE 3

typedef struct {
    int a[SIZE];
    int front;
    int rear;
} Queue;

void enq(Queue* q, int val){
    q->a[q->rear] = val;
    q->rear = (q->rear + 1) % SIZE;
}

int deq(Queue* q) {
    int val = q->a[q->front];
    q->front = (q->front + 1) % SIZE;
    return val;
}

int main() {
    Queue q = {{0}, 0, 0};

    enq(&q,1); enq(&q,2); deq(&q); enq(&q, 3);

    int first = deq(&q);
    int second = deq(&q);
    printf("%d 그리고 %d", first, second);

    return 0;
}

```

## 1. 문제에서 묻는 것
**원형 큐(Circular Queue)** 의 `enq`(삽입)와 `deq`(삭제) 동작을 따라가 두 번의 `deq` 결과를 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 큐(Queue)
먼저 들어간 것이 먼저 나오는 **FIFO(선입선출)** 구조. 줄서기와 같다.
- `rear`: 다음에 **넣을 위치**, `front`: 다음에 **꺼낼 위치**.

### (2) 원형 큐
배열 끝에 닿으면 **처음(0)으로 되돌아가** 빈 칸을 재사용한다.
```c
q->rear = (q->rear + 1) % SIZE;   // SIZE=3 → 0,1,2,0,1,2,... 로 순환
```
```text
 인덱스:  0   1   2
        ┌───┬───┬───┐
        │   │   │   │   front=0, rear=0
        └───┴───┴───┘
```
### (3) `q->a`는 구조체 포인터로 멤버 접근
`q->rear`는 `(*q).rear`와 같다.

## 3. 실행 과정 (SIZE=3, 초기 front=0, rear=0)
| 순서 | 호출 | 동작 | a[0] a[1] a[2] | front | rear |
|---:|---|---|---|---:|---:|
| 시작 | | | 0 0 0 | 0 | 0 |
| 1 | `enq(1)` | a[0]=1, rear=1 | 1 0 0 | 0 | 1 |
| 2 | `enq(2)` | a[1]=2, rear=2 | 1 2 0 | 0 | 2 |
| 3 | `deq()` | a[0]=**1** 반환(버림), front=1 | 1 2 0 | 1 | 2 |
| 4 | `enq(3)` | a[2]=3, rear=(2+1)%3=**0** | 1 2 3 | 1 | 0 |
| 5 | `first=deq()` | a[1]=**2**, front=2 | 1 2 3 | 2 | 0 |
| 6 | `second=deq()` | a[2]=**3**, front=(2+1)%3=0 | 1 2 3 | 0 | 0 |

(3번의 `deq()` 반환값은 변수에 저장하지 않아 버려진다.)

`printf("%d 그리고 %d", first, second)` → **2 그리고 3**

> **정답: `2 그리고 3`**

## 4. 암기 포인트
- `(index + 1) % SIZE` = 원형 큐의 핵심 식.
- 큐는 **먼저 넣은 것부터** 꺼낸다: 1 → 2 → 3 순서, 첫 번째 꺼낸 1은 버려지고 2, 3이 출력.
