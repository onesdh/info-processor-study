# 문제 12

## 문제

다음은 C언어의 문제이다. 아래 코드를 보고 알맞는 출력값을 작성하시오.

```
#include <stdio.h>
#define SIZE 3

typedef struct {
    int a[SIZE];
    int front;
    int rear;
} Queue;

void enq(Queue* q, int val){
    q->a[q->rear] = val;
    q->rear = (q->rear + 1) % SIZE;
}

int deq(Queue* q) {
    int val = q->a[q->front];
    q->front = (q->front + 1) % SIZE;
    return val;
}

int main() {
    Queue q = {{0}, 0, 0};

    enq(&q,1); enq(&q,2); deq(&q); enq(&q, 3);

    int first = deq(&q);
    int second = deq(&q);
    printf("%d 그리고 %d", first, second);

    return 0;
}

```

2 그리고 3

</details>

<summary><strong>상세 해설</strong></summary>

## 핵심 개념

원형 큐는 front/rear를 배열 끝에서 0으로 되돌리기 위해 (index+1)%SIZE를 사용한다.

## 풀이

첫 삽입으로 1, 다음으로 2가 들어간다. 첫 deq는 1을 꺼내 front를 한 칸 이동한다. 그 다음 enq(3)은 배열의 다음 위치에 3을 넣는다. 남은 큐의 순서는 2, 3이므로 두 번의 deq 결과는 2와 3이다.

## 오답 분석

이미 꺼낸 1을 다시 출력하지 않는다. enq는 rear, deq는 front를 갱신한다.

## 암기 포인트

원형 큐는 front/rear를 배열 끝에서 0으로 되돌리기 위해 (index+1)%SIZE를 사용한다.
