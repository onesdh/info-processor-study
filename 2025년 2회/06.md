# 문제 6

## 문제

다음은 IP 주소와 서브넷 마스크에 관한 문제이다. 주어진 정보를 참고하여 괄호 안에 들어갈 알맞은 값을 쓰시오.

호스트의 IP 주소가 223.13.234.132이고 서브넷 마스크가 255.255.255.192일 때 다음 물음에 답하시오.

이 호스트가 속한 네트워크 주소는 223.13.234.( ① )이다.

이 네트워크에서 사용 가능한 호스트 수는 ( ② )개이다.

(단, 네트워크 주소와 브로드캐스트 주소는 제외한다.)

## 1. 문제에서 묻는 것
IP `223.13.234.132`, 서브넷 마스크 `255.255.255.192`일 때 **네트워크 주소**와 **사용 가능한 호스트 수**를 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) IP 주소와 서브넷 마스크
IP 주소는 **네트워크 부분 + 호스트 부분**으로 나뉘고, 서브넷 마스크의 **1인 비트가 네트워크 부분**이다.

### (2) 255.255.255.192를 2진수로
```text
 255.255.255.192 = 11111111.11111111.11111111.11 000000
                                              └ 네트워크 2비트 + 호스트 6비트
 프리픽스 = 8+8+8+2 = /26
```
### (3) 계산 공식
| 구하는 것 | 공식 |
|---|---|
| **블록 크기** | 256 − 마지막 옥텟 마스크값 = 256 − 192 = **64** |
| **네트워크 주소** | IP **AND** 마스크 (= 블록 시작값) |
| **브로드캐스트 주소** | 블록의 **마지막 값** |
| **사용 가능 호스트 수** | **2^(호스트 비트) − 2** = 2⁶ − 2 = **62** |
- `−2`는 **네트워크 주소(맨 앞)** 와 **브로드캐스트 주소(맨 뒤)** 는 호스트에 쓸 수 없기 때문.

## 3. 풀이
**① 네트워크 주소**: 블록이 64씩 → 0~63 / 64~127 / **128~191** / 192~255
마지막 옥텟 132는 **128~191** 블록 → 네트워크 주소 = 223.13.234.**128**

```text
 132 = 10000100
 192 = 11000000
 AND = 10000000 = 128
```
**② 호스트 수**: 호스트 비트 6개 → 2⁶ = 64개 − 2 = **62개**

| 항목 | 값 |
|---|---|
| 네트워크 주소 | 223.13.234.**128** |
| 사용 가능 범위 | 223.13.234.129 ~ 223.13.234.190 |
| 브로드캐스트 | 223.13.234.191 |
| 호스트 수 | **62** |

> **정답: ① 128 ② 62**

## 4. 암기 포인트
- 마스크 192 → 블록 64, 호스트 62개 / 224 → 32, 30개 / 240 → 16, 14개 / 248 → 8, 6개 / 252 → 4, 2개.
