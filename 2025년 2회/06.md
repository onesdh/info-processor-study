# 문제 6 — IPv4 네트워크 주소와 호스트 수

## 문제

IP 223.13.234.132, 마스크 255.255.255.192에서 네트워크 마지막 옥텟과 사용 가능한 호스트 수를 구하시오.

## 원문 이미지

원문 페이지의 해당 문제 영역을 참고하세요.

<details>
<summary><strong>정답 보기</strong></summary>

① 128 ② 62

</details>

## 핵심 개념

블록 크기로 네트워크 경계를 찾고, 사용 호스트 수는 2^(호스트 비트 수)-2다.

## 풀이

마스크의 마지막 옥텟 192는 2진수 11000000으로 /26을 뜻한다. 블록 크기는 256-192=64다. 132가 속한 구간은 128~191이므로 네트워크 주소는 .128이다. 호스트 비트는 6개라 총 2^6=64개 주소 중 네트워크와 브로드캐스트를 빼면 62개다.

## 오답 분석

마지막 옥텟 .132를 그대로 네트워크 주소로 쓰지 않는다. 네트워크 주소와 브로드캐스트 주소는 호스트에 할당하지 않는다.

## 암기 포인트

블록 크기로 네트워크 경계를 찾고, 사용 호스트 수는 2^(호스트 비트 수)-2다.
