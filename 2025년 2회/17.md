# 문제 17

## 문제

다음은 Pyhon언어의 문제이다. 아래 코드를 보고 알맞는 출력값을 작성하시오.

```
lst = [1,2,3]
dst = {i : i* 2 for i in lst}
s = set(dst.values())
lst[0] = 99
dst[2]=7
s.add(99)
print(len(s & set(dst.values())))
```

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**딕셔너리 컴프리헨션, set, 집합 연산(&)** 이 섞인 문제다. 어느 시점의 값이 복사됐고 어느 것이 바뀌었는지가 핵심이다.

## 2. 먼저 알아야 할 개념
| 문법 | 의미 |
|---|---|
| `{i: i*2 for i in lst}` | 딕셔너리 컴프리헨션: 리스트의 각 값 i에 대해 `i → i*2` |
| `dst.values()` | 딕셔너리의 **값들** |
| `set(...)` | **중복 제거**, 순서 없는 집합. **새 객체로 값을 복사** |
| `s.add(x)` | 집합에 원소 추가 |
| `A & B` | **교집합** (둘 다에 있는 원소) |
| `len(...)` | 원소 개수 |

**중요**: `dst`는 **만들어지는 순간의 `lst` 값**으로 계산된다. 이후 `lst`를 바꿔도 `dst`는 변하지 않는다. `set(dst.values())`도 그 순간의 값을 **복사한 새 집합**이다.

## 3. 실행 과정
| 단계 | 코드 | 상태 |
|---|---|---|
| ① | `lst = [1,2,3]` | lst = [1,2,3] |
| ② | `dst = {i: i*2 ...}` | dst = {1:2, 2:4, 3:6} |
| ③ | `s = set(dst.values())` | s = {2, 4, 6} |
| ④ | `lst[0] = 99` | lst = [99,2,3] (dst, s에는 **영향 없음**) |
| ⑤ | `dst[2] = 7` | dst = {1:2, **2:7**, 3:6} → values = {2, 7, 6} |
| ⑥ | `s.add(99)` | s = {2, 4, 6, 99} |

## 4. 교집합
```text
 s                 = {2, 4, 6, 99}
 set(dst.values()) = {2, 7, 6}
 ───────────────────────────────
 s & ...           = {2, 6}       ← 공통 원소
```
`len({2, 6})` = **2**

> **정답: `2`**

## 5. 암기 포인트
- `lst[0] = 99`는 `dst`/`s`와 무관 (이미 값을 만들어 둠).
- `dst`를 수정(⑤)하면 `dst.values()`는 바뀌지만, 먼저 만든 `s`는 바뀌지 않는다 → 교집합에서 4는 빠지고 7은 빠진다.
