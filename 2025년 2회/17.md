# 문제 17

## 문제

딕셔너리 값 집합과 기존 집합의 교집합 크기를 출력한다. 중간에 원본 리스트를 바꾸고 dst[2]=7, s.add(99)를 실행하면 결과는?

## 원문 이미지

원문 페이지의 해당 문제 영역을 참고하세요.

<summary><strong>정답 보기</strong></summary>

2

</details>

## 핵심 개념

딕셔너리와 집합은 생성 시 값의 스냅샷을 가지며 원본 리스트와 자동 동기화되지 않는다.

## 풀이

초기에 dst는 {1:2,2:4,3:6}, s는 {2,4,6}이다. lst[0]=99는 이미 만든 딕셔너리와 집합에 영향을 주지 않는다. dst[2]=7이므로 dst 값은 {2,7,6}; s.add(99)는 {2,4,6,99}다. 교집합은 {2,6}이고 크기는 2다.

## 오답 분석

dst[2] 대입 후 s가 자동 변경된다고 착각하지 않는다. 두 컨테이너는 별개의 객체다.

## 암기 포인트

딕셔너리와 집합은 생성 시 값의 스냅샷을 가지며 원본 리스트와 자동 동기화되지 않는다.
