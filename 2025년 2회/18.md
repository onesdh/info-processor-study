# 문제 18

## 문제

다음은 C언어의 문제이다. 아래 코드를 보고 알맞는 출력값을 작성하시오.

```
#include <stdio.h>
#include <stdlib.h>

struct node {
    char c;
    struct node* p;
};

struct node* func(char* s) {
    struct node* h = NULL, *n;

    while(*s) {
        n = malloc(sizeof(struct node));
        n->c = *s++;
        n->p = h;
        h = n;
    }

    return h;
}

int main() {
    struct node* n = func("BEST");

    while(n) {
        putchar(n->c);
        struct node* t = n;
        n = n->p;
        free(t);
    }

    return 0;
}
```

## 1. 문제에서 묻는 것
문자열을 읽으며 **연결 리스트의 맨 앞에 노드를 추가**했을 때, 출력 순서가 어떻게 되는지 묻는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 연결 리스트의 head 삽입
새 노드를 **맨 앞(head)** 에 붙이면 나중에 넣은 것이 앞으로 온다. → **입력 순서와 반대로** 저장된다. (스택과 같은 LIFO)
```text
 새 노드 n 의 다음 = 기존 head;   head = n;
```
### (2) malloc / free
- `malloc(크기)`: **힙 메모리**에 노드 공간을 새로 확보
- `free(포인터)`: 사용한 공간 반납 (출력 결과에는 영향 없음)

### (3) 포인터 연산 `*s++`
`n->c = *s++;` = **현재 글자를 저장한 뒤** `s`가 다음 글자로 이동. `while(*s)`는 널 문자(`'\0'`) 전까지 반복.

## 3. 리스트 만들기 (`func("BEST")`)
| 반복 | 읽은 글자 | 새 노드 n | n->p (다음) | head(h) |
|---:|---|---|---|---|
| 1 | B | [B] | NULL | [B] |
| 2 | E | [E] | [B] | [E]→[B] |
| 3 | S | [S] | [E] | [S]→[E]→[B] |
| 4 | T | [T] | [S] | **[T]→[S]→[E]→[B]** |

```text
 h → [T] → [S] → [E] → [B] → NULL
```
## 4. 출력
`main`에서 `n`이 head부터 순서대로 따라가며 `putchar(n->c)`:

| 순서 | n | 출력 |
|---:|---|---|
| 1 | T | `T` |
| 2 | S | `S` |
| 3 | E | `E` |
| 4 | B | `B` |

(각 노드는 출력 후 `free`로 해제)

> **정답: `TSEB`**

## 5. 암기 포인트
- head 삽입 → **역순 저장**. 문자열 "BEST"가 "TSEB"로 뒤집혀 나온다.
- 꼬리(tail)에 삽입하면 원래 순서가 유지된다.
