# 문제 18

## 문제

다음은 C언어의 문제이다. 아래 코드를 보고 알맞는 출력값을 작성하시오.

```
#include <stdio.h>
#include <stdlib.h>

struct node {
    char c;
    struct node* p;
};

struct node* func(char* s) {
    struct node* h = NULL, *n;

    while(*s) {
        n = malloc(sizeof(struct node));
        n->c = *s++;
        n->p = h;
        h = n;
    }

    return h;
}

int main() {
    struct node* n = func("BEST");

    while(n) {
        putchar(n->c);
        struct node* t = n;
        n = n->p;
        free(t);
    }

    return 0;
}
```

<details>
<summary><strong>정답 보기</strong></summary>

TSEB

</details>

<summary><strong>상세 해설</strong></summary>

## 핵심 개념

새 노드를 항상 head 앞에 연결하면 입력 순서가 뒤집힌다.

## 풀이

입력 순서대로 B, E, S, T를 머리에 붙인다. 따라서 리스트는 B, E, S, T가 들어온 뒤 T→S→E→B가 된다. head부터 출력하면 TSEB다.

## 오답 분석

입력 문자열을 그대로 출력하는 것이 아니라 삽입 정책 때문에 역순이 된다.

## 암기 포인트

새 노드를 항상 head 앞에 연결하면 입력 순서가 뒤집힌다.
