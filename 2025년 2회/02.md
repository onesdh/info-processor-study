# 문제 2

## 문제

다음은 데이터베이스 릴레이션의 구성 요소 중 하나에 대한 설명이다. 설명을 읽고 보기에서 알맞은 기호를 골라 작성하시오.

릴레이션(Relation)에서 열(Column)을 의미하며 데이터 항목의 속성(Attribute) 또는 특성을 나타낸다.

각 열은 고유한 이름을 가지며 특정 도메인(Domain)에서 정의된 값을 갖는다.

예를 들어 "학생" 릴레이션에서 학번, 이름, 전공 등은 각각 하나의 열이며 이 열들은 학생의 고유한 속성을 나타낸다.

이 개념은 파일 구조에서의 필드(Field)에 해당하며 릴레이션에서 행(Row, Tuple)의 구성 요소가 된다.

## 1. 문제에서 묻는 것
"릴레이션의 **열(Column)**, 데이터 항목의 **특성**, 파일 구조의 **필드**에 해당" → 용어 이름을 보기에서 고르는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 릴레이션(테이블)의 구조
```text
              속성(Attribute) = 열(Column) = (파일 구조의) 필드
              ┌────────┬────────┬────────┐
              │  학번  │  이름  │  전공  │   ← 스키마(Schema, 구조)
              ├────────┼────────┼────────┤
 튜플(Tuple) ▶│ 20201  │ 홍길동 │ 컴공   │
 = 행 = 레코드 │ 20202  │ 김철수 │ 전자   │
              └────────┴────────┴────────┘
              차수(Degree) = 열 수(3)     카디널리티(Cardinality) = 행 수(2)
```
### (2) 용어 정리 (파일 구조와 대응)
| DB 용어 | 파일 시스템 용어 | 의미 |
|---|---|---|
| **릴레이션** | 파일 | 테이블 |
| **튜플(Tuple)** | **레코드** | **행(Row)** |
| **속성(Attribute)** | **필드** | **열(Column)**, 특성 |
| 도메인(Domain) | – | 속성이 가질 수 있는 **값의 범위** |
| 차수(Degree) | – | **속성(열)의 개수** |
| 카디널리티(Cardinality) | – | **튜플(행)의 개수** |
| 스키마(Schema) | – | **구조(정의)** |

## 3. 문제 풀이
| 문제의 단서 | 해당 용어 |
|---|---|
| **열(Column)** 을 의미 | 속성 |
| 데이터 항목의 **특성** | 속성 |
| 파일 구조의 **필드(Field)** 에 해당 | 속성 |
| 학번, 이름, 전공은 각각 하나의 열 | 속성 |

보기별: ㄱ Cardinality(행 수) ❌ / ㄴ Domain(값 범위) ❌ / **ㄷ Attribute ✅** / ㅁ Degree(열 수) ❌ / ㅂ Schema(구조) ❌ / ㅅ Tuple(행) ❌

> **정답: ㄷ. Attribute (속성)**

## 4. 암기 포인트
- **속성 = 열 = 필드**, **튜플 = 행 = 레코드**.
- **차수 = 열 수**, **카디널리티 = 행 수**.
