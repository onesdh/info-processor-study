# 문제 2

## 문제

릴레이션에서 고유 이름을 가지는 열로, 파일 구조의 필드에 대응하는 구성 요소를 보기에서 고르시오.

## 원문 이미지

원문 페이지의 해당 문제 영역을 참고하세요.

<details>
<summary><strong>정답 보기</strong></summary>

ㄷ. Attribute (속성)

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

속성은 열, 튜플은 행, 도메인은 속성에 허용되는 값의 집합이다.

## 풀이

릴레이션의 열은 속성이다. 한 속성은 이름과 도메인을 가지며 레코드의 항목을 구성한다. 학생 릴레이션의 학번, 이름, 전공이 각각 속성이다.

## 오답 분석

차수는 열 개수이고 카디널리티는 행 개수다. 속성 하나 자체를 뜻하지 않는다.

## 암기 포인트

속성은 열, 튜플은 행, 도메인은 속성에 허용되는 값의 집합이다.
