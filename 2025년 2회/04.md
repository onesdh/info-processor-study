# 문제 4

## 문제

스케줄링 알고리즘에 관한 다음 설명을 읽고 (1)과 (2)에 알맞은 스케줄링 알고리즘의 명칭을 각각 쓰시오.

(1) CPU burst 시간이 짧은 프로세스를 우선적으로 처리하는 스케줄링 방식이다. "Shortest Next CPU Burst"라고도 불리며 선점형 또는 비선점형으로 구현될 수 있다.

(2) 위의 스케줄링 방식을 선점형으로 구현한 형태로 실행 중인 프로세스보다 더 짧은 burst 시간을 가진 프로세스가 도착하면 현재 CPU를 선점한다.

<details>
<summary><strong>정답 보기</strong></summary>

(1) SJF (Shortest Job First)

(2) SRT (Shortest Remaining Time)

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
CPU 스케줄링 알고리즘 두 가지를 설명으로 구분하는 문제다. (1) **짧은 작업 우선, 선점/비선점 모두 가능**, (2) 그것을 **선점형으로 구현**.

## 2. 먼저 알아야 할 개념
### (1) 스케줄링
CPU는 한 번에 한 프로세스만 실행하므로 **대기 중인 프로세스 중 누구에게 CPU를 줄지** 정하는 규칙이 필요하다.

### (2) 선점 vs 비선점
| 구분 | 의미 |
|---|---|
| **비선점** | 한 번 CPU를 받으면 **끝날 때까지** 빼앗기지 않음 |
| **선점** | 실행 중이라도 **더 우선인 프로세스가 오면 CPU를 빼앗김** |

### (3) 스케줄링 알고리즘 한눈에
| 알고리즘 | 기준 | 선점 |
|---|---|---|
| FCFS | **도착 순서** | 비선점 |
| **SJF** | **버스트(실행) 시간이 가장 짧은** 작업 | 비선점 (선점형이 SRT) |
| **SRT** | **남은 실행 시간이 가장 짧은** 작업 | **선점** |
| HRN | (대기+실행)/실행 이 큰 작업 | 비선점 |
| RR | 타임 퀀텀씩 번갈아 | 선점 |

```text
 SJF : P1(8) 실행 중, P2(4) 도착 → P1이 끝날 때까지 기다림 (비선점)
 SRT : P1(8) 실행 중, P2(4) 도착 → P1 남은 7 > P2 4 → P1을 밀어내고 P2 실행 (선점)
```
## 3. 문제 풀이
| 설명 | 알고리즘 |
|---|---|
| (1) **CPU burst가 짧은** 프로세스 우선, "**Shortest Next CPU Burst**", 선점/비선점 모두 구현 가능 | **SJF (Shortest Job First)** |
| (2) 위 방식의 **선점형**, **더 짧은 burst**가 도착하면 CPU **선점** | **SRT (Shortest Remaining Time)** |

> **정답: (1) SJF (2) SRT**

## 4. 암기 포인트
- **SRT = SJF의 선점형**.
- 단점(기아 현상): 긴 작업이 계속 밀릴 수 있다 → 해결책 **에이징** 또는 **HRN**.

</details>
