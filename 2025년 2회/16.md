# 문제 16

## 문제

다음은 C언어의 문제이다. 아래 코드를 보고 알맞는 출력값을 작성하시오.

```
#include <stdio.h>
#include <stdlib.h>

struct node {
    int p;
    struct node* n;
};

int main() {
    struct node a = {1, NULL};
    struct node b = {2, NULL};
    struct node c = {3, NULL};

    a.n = &b; b.n = &c; c.n = NULL;
    c.n = &a; a.n = &b; b.n = NULL;
    struct node* head = &c;
    printf("%d %d %d", head->p, head->n->p, head->n->n->p);
    return 0;
}

```

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**연결 리스트의 포인터를 여러 번 바꾼 뒤**, 최종 연결 순서(head부터)를 구하는 문제다. **마지막에 수행한 대입이 결과를 결정**한다.

## 2. 먼저 알아야 할 개념
### (1) 노드와 연결
```c
struct node { int p; struct node* n; };   // n = 다음 노드 포인터
```
`a.n = &b;` 는 "a의 다음은 b"라는 뜻이다. **같은 포인터에 다시 대입하면 이전 연결은 사라진다.**

### (2) 최종 연결 상태만 중요
중간 과정은 **마지막 대입**으로 덮어써진다. 각 노드의 `n`이 **마지막으로 무엇으로 설정됐는지**만 추적한다.

## 3. 실행 과정
**초기** `a={1,NULL}, b={2,NULL}, c={3,NULL}`

**1번째 줄** `a.n=&b; b.n=&c; c.n=NULL;`
```text
 a(1) → b(2) → c(3) → NULL
```
**2번째 줄** `c.n=&a; a.n=&b; b.n=NULL;`
| 대입 | 결과 |
|---|---|
| `c.n = &a` | c의 다음 = a |
| `a.n = &b` | a의 다음 = b (그대로) |
| `b.n = NULL` | b의 다음 = **NULL** (끊김) |

```text
 c(3) → a(1) → b(2) → NULL
```
`head = &c` → 연결 순서: **c → a → b**

| 접근 | 노드 | p |
|---|---|---:|
| `head->p` | c | **3** |
| `head->n->p` | a | **1** |
| `head->n->n->p` | b | **2** |

`printf("%d %d %d", ...)` → **3 1 2**

> **정답: `3 1 2`**

## 4. 암기 포인트
- 포인터 대입은 **덮어쓰기** — 마지막 값만 유효.
- 연결을 그림(화살표)으로 그리면 실수가 없다.
