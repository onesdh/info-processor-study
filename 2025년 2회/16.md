# 문제 16 — 연결 리스트 포인터 변경

## 문제

a, b, c 노드를 만든 뒤 c→a→b로 연결하고 head를 c로 둔다. 세 노드의 p값을 출력하시오.

## 원문 이미지

원문 페이지의 해당 문제 영역을 참고하세요.

## 정답

3 1 2

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

포인터 대입은 해당 연결만 바꾸므로 가장 마지막에 수행한 링크 설정을 기준으로 최종 구조를 그린다.

## 풀이

두 번째 연결 대입이 앞의 연결을 다시 설정한다. 최종적으로 c.n=&a, a.n=&b, b.n=NULL이다. head는 c이므로 차례로 3, 1, 2가 출력된다.

## 오답 분석

초기 연결 a→b→c는 뒤의 대입으로 일부 덮어써졌으므로 사용하지 않는다.

## 암기 포인트

포인터 대입은 해당 연결만 바꾸므로 가장 마지막에 수행한 링크 설정을 기준으로 최종 구조를 그린다.
