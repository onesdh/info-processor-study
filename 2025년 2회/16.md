# 문제 16

## 문제

다음은 C언어의 문제이다. 아래 코드를 보고 알맞는 출력값을 작성하시오.

```
#include <stdio.h>
#include <stdlib.h>

struct node {
    int p;
    struct node* n;
};

int main() {
    struct node a = {1, NULL};
    struct node b = {2, NULL};
    struct node c = {3, NULL};

    a.n = &b; b.n = &c; c.n = NULL;
    c.n = &a; a.n = &b; b.n = NULL;
    struct node* head = &c;
    printf("%d %d %d", head->p, head->n->p, head->n->n->p);
    return 0;
}

```

<summary><strong>정답 보기</strong></summary>

3 1 2

</details>

<summary><strong>상세 해설</strong></summary>

## 핵심 개념

포인터 대입은 해당 연결만 바꾸므로 가장 마지막에 수행한 링크 설정을 기준으로 최종 구조를 그린다.

## 풀이

두 번째 연결 대입이 앞의 연결을 다시 설정한다. 최종적으로 c.n=&a, a.n=&b, b.n=NULL이다. head는 c이므로 차례로 3, 1, 2가 출력된다.

## 오답 분석

초기 연결 a→b→c는 뒤의 대입으로 일부 덮어써졌으므로 사용하지 않는다.

## 암기 포인트

포인터 대입은 해당 연결만 바꾸므로 가장 마지막에 수행한 링크 설정을 기준으로 최종 구조를 그린다.
