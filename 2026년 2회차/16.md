# 문제 16

## 문제

다음은 IP 주소 서브네팅(Subnetting)에 대한 설명이다. 물음에 답하시오.

10.0.0.0/27 네트워크를 동일한 크기의 2개 서브넷으로 분할하였다.

- 첫 번째 서브넷: 10.0.0.0 ~ 10.0.0.15
- 두 번째 서브넷: 10.0.0.16 ~ 10.0.0.31

이때 10.0.0.1이 속한 서브넷의 프리픽스 길이(비트 수)를 구하시오.

---
<details>
<summary><strong>정답</strong></summary>

`28`

</details>

<details>
<summary><strong>해설</strong></summary>

## 1. 문제에서 묻는 핵심

하나의 네트워크를 동일한 크기의 두 서브넷으로 나눌 때 프리픽스 길이가 어떻게 변하는지 묻는다.

## 2. 개념 이해

`/27`은 네트워크 비트가 27개라는 뜻이다. 하나의 네트워크를 같은 크기의 **2개**로 나누려면 기존 호스트 영역에서 1비트를 빌려 서브넷 비트로 사용한다.

따라서 프리픽스 길이는 `27 + 1 = 28`이 된다.

## 3. 문제 풀이

`10.0.0.0/27`의 전체 주소 수는 2^(32-27)=32개이다.

이를 2개로 나누면 각 서브넷은 16개 주소를 갖는다.

16개 주소를 표현하려면 호스트 비트는 4개가 필요하다.

따라서 네트워크 비트는 `32 - 4 = 28`개이다.

첫 번째 서브넷이 `10.0.0.0 ~ 10.0.0.15`이고 `10.0.0.1`이 여기에 속하므로 답은 `/28`이다.

## 4. 핵심 정리

서브넷을 2배로 나누면 **프리픽스 길이가 1 증가**한다.

## 5. 암기 포인트

`/27 → 2개로 분할 → /28`.
