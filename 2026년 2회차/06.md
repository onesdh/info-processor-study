# 문제 6

## 문제

다음은 파이썬 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

### 코드

```python
a = "_THIS_IS_KIM_SPEAKING"
b = a[:4]
c = a[6:8]
d = a[18:]
e = b + c + d
print(e)
```

`_THIISING`

<summary><strong>해설</strong></summary>

## 1. 문제에서 묻는 핵심

파이썬 문자열 슬라이싱의 시작 인덱스와 끝 인덱스 규칙을 묻는다.

## 2. 개념 이해

파이썬의 `s[a:b]`는 **a 이상 b 미만**의 인덱스를 가져온다. 시작 인덱스는 포함되고 끝 인덱스는 포함되지 않는다.

문자열은 다음과 같이 인덱스가 부여된다.

```text
_THIS_IS_KIM_SPEAKING
0123456789...
```

## 3. 문제 풀이

- `b = a[:4]` → 인덱스 0~3 → `_THI`
- `c = a[6:8]` → 인덱스 6~7 → `IS`
- `d = a[18:]` → 인덱스 18부터 끝까지 → `ING`

따라서 `b + c + d`는 **`_THI` + `IS` + `ING` = `_THIISING`**이다.

## 4. 암기 포인트

`[시작:끝]`에서 **끝 인덱스는 포함되지 않는다**.
