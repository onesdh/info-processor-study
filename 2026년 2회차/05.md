# 문제 5

## 문제

다음은 파이썬 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

### 코드

```python
class LocationDict:
    locations = {
        "NYC": "New York",
        "LON": "London",
        "PAR": "Paris",
        "TKY": "Tokyo"
    }

tmpdict = LocationDict()
str01 = ""

for key, location in tmpdict.locations.items():
    keyk = key[-1]
    locationk = location[0]
    str01 += keyk + locationk

print(str01, end="")
```

## 1. 문제에서 묻는 핵심

딕셔너리의 각 항목을 순회하면서 문자열의 마지막 문자와 첫 문자를 추출하는 방법을 묻는다.

## 2. 개념 이해

`key[-1]`은 문자열의 마지막 문자이고, `location[0]`은 첫 번째 문자이다. `items()`는 딕셔너리에서 키와 값을 함께 순회할 수 있게 한다.

## 3. 문제 풀이

각 항목을 순서대로 계산한다.

| key | location | `key[-1]` | `location[0]` | 추가되는 문자열 |
|---|---|---|---|---|
| NYC | New York | C | N | CN |
| LON | London | N | L | NL |
| PAR | Paris | R | P | RP |
| TKY | Tokyo | Y | T | YT |

따라서 `CN + NL + RP + YT` = **CNNLRPYT**이다.

## 4. 암기 포인트

- `s[0]` → 첫 문자
- `s[-1]` → 마지막 문자
- `dict.items()` → 키와 값을 함께 순회
