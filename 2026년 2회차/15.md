# 문제 15

## 문제

다음은 Java 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.


### 코드

```java
class A {
    int a;
    private int b;
    protected int c;

    void set(int aa, int bb, int cc) {
        a = aa;
        b = bb;
        c = cc;
    }

    int hap() {
        return a + b + c;
    }
}

class B extends A {
    public int hap() {
        return a * c;
    }
}

public class Main {
    public static void main(String[] args) {
        A aaa = new A();
        B bbb = new B();

        aaa.set(1, 5, 3);
        bbb.set(10, 30, 50);

        System.out.print(aaa.hap() + bbb.hap());
    }
}
```

<summary><strong>해설</strong></summary>

## 1. 문제에서 묻는 핵심

부모 클래스와 자식 클래스에서 같은 이름의 메서드를 재정의(Overriding)하고, 각각의 객체가 어떤 메서드를 호출하는지 묻는다.

## 2. 개념 이해

A의 `hap()`은 `a+b+c`를 반환한다.

B는 A를 상속하면서 `hap()`을 재정의하여 `a*c`를 반환한다.

따라서 A 객체에서는 A의 `hap()`, B 객체에서는 B의 `hap()`이 호출된다.

## 3. 문제 풀이

`aaa.set(1,5,3)`이므로 A 객체의 값은 `a=1, b=5, c=3`이다.

A의 `hap()`:

`1 + 5 + 3 = 9`

`bbb.set(10,30,50)`이므로 B 객체의 `a=10, b=30, c=50`이다.

B의 `hap()`:

`10 × 50 = 500`

마지막으로 `9 + 500 = 509`이다.

## 4. 핵심 정리

메서드 오버라이딩은 자식 클래스가 부모 클래스의 메서드를 같은 이름으로 다시 정의하는 것이다.

## 5. 암기 포인트

문제에서 객체의 실제 타입을 먼저 확인하고, 해당 객체에서 어떤 `hap()`이 실행되는지 판단한다.
