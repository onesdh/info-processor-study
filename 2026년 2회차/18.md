# 문제 18

## 문제

다음은 C언어 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.


### 코드

```c
#include <stdio.h>

int c(int n) {
    if (n <= 1) return n;
    return c(n - 1) + c(n - 3);
}

int main() {
    printf("%d", c(5));
    return 0;
}
```

## 1. 문제에서 묻는 핵심

재귀 함수가 호출될 때 어떤 값이 반환되는지 계산하는 문제이다.

## 2. 개념 이해

함수는 다음과 같다.

`c(n) = c(n-1) + c(n-3)` 단, `n <= 1`이면 `c(n)=n`이다.

재귀 함수에서는 가장 먼저 **기저 조건(base case)**을 확인하고, 그 조건에 도달할 때까지 식을 계속 전개한다.

## 3. 문제 풀이

먼저 작은 값부터 계산한다.

- `c(0) = 0`
- `c(1) = 1`
- `c(2) = c(1) + c(-1) = 1 + (-1) = 0`
- `c(3) = c(2) + c(0) = 0 + 0 = 0`
- `c(4) = c(3) + c(1) = 0 + 1 = 1`
- `c(5) = c(4) + c(2) = 1 + 0 = 1`

따라서 출력값은 **1**이다.

## 4. 핵심 정리

`n <= 1`이라는 조건 때문에 음수 인자인 `c(-1)`도 기저 조건에서 바로 `-1`을 반환한다.

## 5. 암기 포인트

재귀 문제는 무작정 전체 호출 트리를 그리기보다 **기저 조건부터 작은 값들을 표로 계산**하면 실수를 줄일 수 있다.
