# 문제 4

## 문제

다음은 라우팅 프로토콜에 대한 설명이다. 괄호 안에 들어갈 알맞은 용어를 쓰시오.

( )는 링크 상태(Link State) 알고리즘을 사용하는 대표적인 내부 라우팅 프로토콜(IGP)이다. 다익스트라(Dijkstra) 알고리즘을 이용하여 최단 경로를 탐색하며, 대규모 네트워크에 적합하고 멀티캐스트를 지원한다.

OSPF (Open Shortest Path First)

<summary><strong>해설</strong></summary>

## 1. 문제에서 묻는 핵심

링크 상태 방식과 다익스트라 알고리즘을 사용하는 대표적인 IGP를 묻는다.

## 2. 개념 이해

**OSPF(Open Shortest Path First)**는 내부 게이트웨이 프로토콜(IGP)이다. 네트워크의 링크 상태 정보를 이용하여 경로를 계산하며, 최단 경로 계산에 Dijkstra 알고리즘을 사용한다.

## 3. 문제 풀이

문제의 단서는 `Link State`, `IGP`, `Dijkstra`, `Shortest Path`이다. 이 특징들이 모두 OSPF와 일치한다.

## 4. 핵심 정리

**OSPF = Link State + Dijkstra + IGP**

## 5. 암기 포인트

OSPF의 이름에 **Shortest Path**가 들어 있다는 점과 Dijkstra를 함께 연결해서 기억한다.
