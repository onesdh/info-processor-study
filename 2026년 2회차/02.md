# 문제 2

## 문제

다음은 Java 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

### 코드

```java
class A {
    private int a;

    public A(int a) {
        this.a = a;
    }

    void print() {
        System.out.print(a + "a");
    }
}

class B extends A {
    private int b;

    B(int a, int b) {
        super(a);
        this.b = b;
    }

    void print() {
        super.print();
        System.out.print(b + "b");
    }
}

public class Main {
    public static void main(String[] args) {
        B obj = new B(10, 20);
        obj.print();
    }
}
```

<summary><strong>해설</strong></summary>

## 1. 문제에서 묻는 핵심

상속받은 클래스에서 부모 생성자와 `super.print()`가 어떻게 동작하는지를 묻는 문제이다.

## 2. 개념 이해

`B extends A`는 B가 A를 상속한다는 뜻이다. B의 생성자에서 `super(a)`를 호출하면 부모 클래스 A의 생성자가 실행된다.

따라서 `new B(10, 20)`을 만들면 부모 A의 `a`에는 10, 자식 B의 `b`에는 20이 저장된다.

`super.print()`는 현재 객체의 부모 클래스인 A의 `print()` 메서드를 호출한다.

## 3. 문제 풀이

`obj.print()`는 B의 `print()`를 실행한다.

1. `super.print()` 실행 → A의 `print()`가 `10a` 출력
2. 다음 줄에서 `b + "b"`를 출력 → `20b`

두 출력에는 줄바꿈이 없으므로 최종 결과는 `10a20b`가 된다.

## 4. 핵심 정리

- `extends` → 상속
- `super(...)` → 부모 생성자 호출
- `super.메서드()` → 부모 클래스의 메서드 호출
- `System.out.print()` → 줄바꿈 없이 출력

## 5. 암기 포인트

`super.print()`는 **부모 버전의 print()를 호출한다**고 기억하면 된다.
