# 문제 7

## 문제

다음은 C언어 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.


### 코드

```c
#include <stdio.h>

typedef struct N {
    int v;
    struct N* a;
    struct N* b;
} N;

int c = 0;
int ans = 0;

void pst(N *n) {
    if (!n) return;
    pst(n->a);
    pst(n->b);
    if (++c == 3) ans = n->v;
}

int main() {
    N ne = {35, 0, 0};
    N nd = {64, 0, 0};
    N nc = {53, 0, 0};
    N nb = {12, &ne, &nc};
    N na = {21, &nb, &nd};

    pst(&na);
    printf("%d\n", ans);
    return 0;
}
```

<summary><strong>해설</strong></summary>

## 1. 문제에서 묻는 핵심

트리 구조를 재귀적으로 순회하는 코드에서 방문 순서를 파악하는 문제이다.

## 2. 개념 이해

함수 `pst()`는 먼저 `n->a`, 다음으로 `n->b`를 재귀 호출한 뒤 현재 노드의 값을 처리한다. 즉 **후위 순회(Postorder Traversal)** 방식이다.

후위 순회 순서는 `왼쪽 자식 → 오른쪽 자식 → 현재 노드`이다.

## 3. 문제 풀이

트리 구조는 다음과 같다.

```text
        21
       /  \
     12    64
    /  \
  35    53
```

후위 순회하면 `35 → 53 → 12 → 64 → 21` 순서로 방문한다.

전역 변수 `c`는 방문할 때마다 1 증가한다.

1. 35 → c=1
2. 53 → c=2
3. 12 → c=3 → `ans=12`

따라서 출력값은 **12**이다.

## 4. 핵심 정리

후위 순회는 **왼쪽 → 오른쪽 → 루트** 순서이다.

## 5. 암기 포인트

`pst`라는 이름과 관계없이 코드 자체에서 **자식 재귀 호출 후 현재 노드 처리**라는 순서를 확인해야 한다.
