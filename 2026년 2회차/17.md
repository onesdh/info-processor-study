# 문제 17

## 문제

다음 설명에 해당하는 보안 기술 용어를 쓰시오.

입력값의 길이와 상관없이 항상 정해진 길이의 결과값을 만들어내는 암호 기술이 있다.

이 기술은 단방향성을 가지고 있어 결과값만으로는 원래의 입력값을 알아낼 수 없으며, 서로 다른 두 입력값이 같은 결과값을 만들어내는 경우가 최대한 발생하지 않도록 설계되어야 한다.

이러한 성질을 가진 암호 기술을 무엇이라 하는가?

<summary><strong>해설</strong></summary>

## 1. 문제에서 묻는 핵심

입력 데이터의 길이와 관계없이 고정 길이의 결과를 만들고, 원래 입력을 결과만으로 되돌리기 어려운 기술을 묻는다.

## 2. 개념 이해

**해시(Hash)**는 임의 길이의 입력 데이터를 해시 함수에 넣어 일정한 길이의 해시값을 생성하는 방식이다.

일반적인 암호화와 달리 해시는 원래 데이터를 복호화하기 위한 목적의 기술이 아니다. 또한 서로 다른 입력이 같은 해시값을 만드는 **충돌(Collision)**이 가능하면 보안상 문제가 되므로 충돌 가능성을 낮추도록 설계한다.

## 3. 문제 풀이

문제의 단서는 다음과 같다.

- 입력 길이와 관계없이 고정 길이 결과
- 단방향성
- 서로 다른 입력의 동일 결과인 충돌을 최대한 방지

이 특징들이 해시의 설명과 일치한다.

## 4. 핵심 정리

**Hash = 임의 길이 입력 → 고정 길이 해시값**

## 5. 암기 포인트

해시는 **복호화해서 원문을 얻는 암호화 방식이 아니라, 입력을 고정 길이 값으로 변환하는 함수**라고 이해하면 된다.
