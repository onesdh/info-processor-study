# 문제 3

## 문제

다음은 소프트웨어 모듈 간의 결합도(Coupling)에 대한 설명이다. 괄호 안에 들어갈 말을 보기에서 골라 기호로 쓰시오.

( )는 한 모듈이 다른 모듈 내부에 있는 변수나 기능을 직접 참조하거나 사용하는 경우에 발생하는 결합도로, 결합도 종류 중 결합 강도가 가장 높은 형태이다.

### 보기

1. 자료결합도 (Data Coupling)
2. 스탬프결합도 (Stamp Coupling)
3. 제어결합도 (Control Coupling)
4. 외부결합도 (External Coupling)
5. 내용결합도 (Content Coupling)
6. 공통결합도 (Common Coupling)

## 1. 문제에서 묻는 핵심

한 모듈이 다른 모듈의 **내부 구현에 직접 접근하는 가장 강한 결합도**를 묻는다.

## 2. 개념 이해

결합도(Coupling)는 모듈과 모듈 사이의 의존 정도이다. 일반적으로 모듈 간 결합도가 낮을수록 한 모듈의 변경이 다른 모듈에 미치는 영향이 작아진다.

**내용 결합도(Content Coupling)**는 한 모듈이 다른 모듈의 내부 자료나 내부 기능을 직접 참조하거나 변경하는 경우이다.

## 3. 문제 풀이

문제의 핵심 표현은 **'다른 모듈 내부에 있는 변수나 기능을 직접 참조하거나 사용'**이다. 이는 내용 결합도의 정의와 일치한다.

## 4. 보기별 분석

- 자료 결합도: 데이터를 전달하여 결합한다.
- 스탬프 결합도: 자료구조나 레코드 등 묶음 자료를 전달한다.
- 제어 결합도: 다른 모듈의 실행 흐름을 제어할 정보를 전달한다.
- 외부 결합도: 외부 환경이나 장치, 프로토콜 등과 관련된다.
- **내용 결합도: 다른 모듈의 내부에 직접 접근한다. → 정답**
- 공통 결합도: 여러 모듈이 공통 데이터를 공유한다.

## 5. 핵심 정리

**내용 결합도 = 다른 모듈의 내부까지 직접 접근**.

## 6. 암기 포인트

'내부를 직접 참조'라는 표현이 나오면 내용 결합도를 떠올린다.
