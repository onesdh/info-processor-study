# 문제 9

## 문제

다음은 C언어 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.


### 코드

```c
#include <stdio.h>

void fn1(int* i) { *i = 50; }
void fn2(int i) { i = 60; }

void fn34(int* p) {
    printf("3. %d\n", *p);
    printf("4. %d\n", *(p + 3));
}

int main() {
    int i = 30;
    int list[] = {2, 4, 6, 8, 10};

    fn1(&i);
    printf("1. %d\n", i);

    fn2(i);
    printf("2. %d\n", i);

    fn34(list);

    return 0;
}
```

<summary><strong>해설</strong></summary>

## 1. 문제에서 묻는 핵심

포인터를 이용한 함수 호출과 값에 의한 전달, 배열 포인터 연산을 묻는다.

## 2. 개념 이해

`fn1(int* i)`는 정수의 주소를 받기 때문에 `*i = 50`을 수행하면 호출한 쪽 변수의 값이 실제로 바뀐다.

반면 `fn2(int i)`는 값을 복사해서 받는다. 함수 안에서 `i=60`으로 바꿔도 호출한 쪽 변수에는 영향을 주지 않는다.

배열에서 `p`는 첫 번째 원소의 주소를 가리키므로 `*(p+3)`은 네 번째 원소를 의미한다.

## 3. 문제 풀이

1. `i=30`에서 `fn1(&i)` 호출 → `*i=50` → 실제 `i`가 50
2. `fn2(i)`에는 50이 복사되어 전달된다. 함수 안에서 60으로 바뀌지만 원래 `i`는 50
3. `list[0]`은 2이므로 `*p`는 2
4. `p+3`은 네 번째 원소 `list[3]`을 가리키므로 8

따라서 출력은 다음과 같다.

```text
1. 50
2. 50
3. 2
4. 8
```

## 4. 핵심 정리

- 포인터 매개변수 → 원본 변수에 접근 가능
- 일반 값 매개변수 → 값이 복사됨
- `p+3` → 배열에서 4번째 원소의 주소
- `*(p+3)` → 4번째 원소의 값
