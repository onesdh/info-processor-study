## 1. 문제에서 묻는 것
응집도 유형 4개(기능, 교환, 우연, 시간)를 **응집도가 높은 순서**로 나열하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 응집도(Cohesion)
한 모듈 안의 **구성 요소들이 얼마나 하나의 목적으로 긴밀하게 모여 있는가**. **높을수록 좋은 설계**다.

### (2) 응집도 7단계 (약 → 강)
```text
 우연적 < 논리적 < 시간적 < 절차적 < 교환(통신)적 < 순차적 < 기능적
 (낮음, 나쁨)                                          (높음, 좋음)
```
| 유형 | 설명 |
|---|---|
| **우연적(Coincidental)** | 서로 관계없는 기능이 우연히 같은 모듈에 |
| 논리적 | 논리적으로 유사한 기능을 한 모듈에 |
| **시간적(Temporal)** | **같은 시간**에 실행되어야 하는 기능 (초기화 등) |
| 절차적 | 정해진 **순서**대로 실행 |
| **교환(통신)적** | **같은 입력/출력 데이터**를 사용 |
| 순차적 | 앞의 출력이 뒤의 입력 |
| **기능적(Functional)** | **하나의 기능**만 수행 |

## 3. 문제 풀이
보기: ㄱ 기능 / ㄴ 교환 / ㄷ 우연 / ㄹ 시간

7단계 순서에서 위치를 찾으면:
| 유형 | 순위(높은 순) |
|---|:---:|
| ㄱ **기능적** | 1 (가장 높음) |
| ㄴ **교환적** | 2 |
| ㄹ **시간적** | 3 |
| ㄷ **우연적** | 4 (가장 낮음) |

> **정답: ㄱ → ㄴ → ㄹ → ㄷ**

## 4. 암기 포인트
- **우연 < 논리 < 시간 < 절차 < 교환(통신) < 순차 < 기능**.
- 가장 좋은 것은 **기능적**, 가장 나쁜 것은 **우연적**.
