# 문제 06

## 문제

아래 표에서 나타나고 있는 정규형을 작성하시오.

| 고객아이디 | 강좌명 | 강사번호 |
|---|---|---|
| apple | 영어회화 | P001 |
| banana | 기초토익 | P002 |
| carrot | 영어회화 | P001 |
| carrot | 기초토익 | P004 |
| orange | 영어회화 | P003 |
| orange | 기초토익 | P004 |

<details>
<summary><strong>정답 보기</strong></summary>

제 3정규형

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
표(수강 정보)가 **어떤 정규형까지 만족하는지** 판단하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 함수적 종속 `X → Y`
**X 값이 정해지면 Y 값이 하나로 정해진다.** X를 결정자, Y를 종속자라 한다.

### (2) 정규형 단계
| 정규형 | 조건 |
|---|---|
| **1NF** | 모든 속성이 **원자값** |
| **2NF** | 1NF + **부분 함수 종속 제거**(기본키 일부에만 종속하는 속성 없음) |
| **3NF** | 2NF + **이행 함수 종속 제거**(비주요 속성끼리 종속 없음) |
| **BCNF** | 3NF + **모든 결정자가 후보키** |

## 3. 문제 데이터
| 고객아이디 | 강좌명 | 강사번호 |
|---|---|---|
| apple | 영어회화 | P001 |
| banana | 기초토익 | P002 |
| carrot | 영어회화 | P001 |
| carrot | 기초토익 | P004 |
| orange | 영어회화 | P003 |
| orange | 기초토익 | P004 |

## 4. 분석
**① 기본키**: 한 고객이 여러 강좌를 수강(carrot, orange) → **(고객아이디, 강좌명)** 이 키.

**② 함수적 종속**
| 종속 | 성립? | 근거 |
|---|:---:|---|
| (고객아이디, 강좌명) → 강사번호 | ✅ | 기본키 |
| 고객아이디 → 강사번호 | ❌ | carrot: P001, P004 |
| 강좌명 → 강사번호 | ❌ | 영어회화: P001, P003 |
| **강사번호 → 강좌명** | ✅ | P001=영어회화, P004=기초토익 … |

**③ 단계별 판정**
| 정규형 | 만족? | 이유 |
|---|:---:|---|
| 1NF | ✅ | 원자값 |
| 2NF | ✅ | 강사번호가 키의 **일부**에만 종속되는 경우 없음 |
| **3NF** | ✅ | 종속되는 `강좌명`이 **키의 구성 속성(주요 속성)** 이라 이행 종속이 아님 |
| BCNF | ❌ | 결정자 `강사번호`가 **후보키가 아님** |

→ 현재 상태 = **제3정규형** (BCNF는 아님)

> **정답: 제3정규형**

## 5. 암기 포인트
- 단계: 1NF(원자값) → 2NF(부분종속 제거) → 3NF(이행종속 제거) → BCNF(결정자=후보키).
- BCNF로 만들려면 `강사번호 → 강좌명` 테이블을 분리한다.
