# 문제 18

## 문제

아래의 SQL 코드와 테이블을 참고하여 결과 값을 작성하시오.

![원문 문제 그림 1](source/정보처리기사_2024_1_Q18_01.png)

```
SELECT
    COUNT(*)
FROM
    TABLE
WHERE
    EMPNO > 100
AND
    SAL >= 3000 OR EMPNO = 200
```

## 1. 문제에서 묻는 것
`AND`와 `OR`가 섞인 `WHERE` 조건에서 **연산자 우선순위**를 적용해 `COUNT(*)`를 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 논리 연산자 우선순위
**`AND`가 `OR`보다 먼저** 계산된다(곱셈이 덧셈보다 먼저인 것과 같다).
```sql
WHERE  EMPNO > 100  AND  SAL >= 3000   OR   EMPNO = 200
```
은 다음과 같이 해석된다.
```sql
WHERE ( EMPNO > 100 AND SAL >= 3000 )  OR  ( EMPNO = 200 )
```
### (2) 조건 평가
`( A AND B ) OR C` → **(A와 B 모두 참)** 이거나 **C가 참**이면 선택.

## 3. 문제 데이터 (그림)
| EMPNO | SAL |
|---:|---:|
| 100 | 1000 |
| 200 | 3000 |
| 300 | 1500 |

## 4. 풀이: 행별 판정
| EMPNO | SAL | `EMPNO>100` | `SAL>=3000` | **(A AND B)** | `EMPNO=200` (C) | **A AND B OR C** |
|---:|---:|:---:|:---:|:---:|:---:|:---:|
| 100 | 1000 | X | X | X | X | **X** |
| 200 | 3000 | ✅ | ✅ | ✅ | ✅ | **✅** |
| 300 | 1500 | ✅ | X | X | X | **X** |

조건을 만족하는 행: EMPNO = 200 한 행 → `COUNT(*)` = **1**

> **정답: `1`**

## 5. 암기 포인트
- 괄호가 없으면 **AND 먼저, OR 나중**.
- 300번은 `EMPNO > 100`은 참이지만 `SAL >= 3000`이 거짓이라 탈락한다.
