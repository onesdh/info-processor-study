# 문제 11

## 문제

다음 C언어의 알맞는 출력값을 작성하시오.

```
#include <stdio.h>


typedef struct{
    int accNum;
    double bal;
}BankAcc;



double sim_pow(double base, int year){
    int i;
    double r = 1.0;

    for(i=0; i<year; i++){
        r = r*base;
    }
    return r;
}



void initAcc(BankAcc *acc, int x, double y){
    acc -> accNum = x;
    acc -> bal = y;
}



void xxx(BankAcc *acc, double *en){
    if (*en > 0 && *en < acc -> bal) {
        acc -> bal = acc -> bal-*en;
    }else{
        acc -> bal = acc -> bal+*en;
    }
}



void yyy(BankAcc *acc){
    acc -> bal = acc -> bal * sim_pow((1+0.1),3);
}


int main(){

    BankAcc myAcc;
    initAcc(&myAcc, 9981, 2200.0);
    double amount = 100.0;
    xxx(&myAcc, &amount);
    yyy(&myAcc);
    printf("%d and %.2f", myAcc.accNum, myAcc.bal);
    return 0;

}

```

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**구조체 포인터, 출금/입금 로직, 복리 계산**을 순서대로 추적해 최종 잔액을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 구조체와 `->`
```c
typedef struct { int accNum; double bal; } BankAcc;
acc->bal  =  (*acc).bal      // 포인터로 멤버 접근
```
### (2) 포인터 매개변수
함수에 **주소**(`&myAcc`, `&amount`)를 넘기면 함수 안에서 **원본을 변경**할 수 있다.

### (3) 거듭제곱 함수
`sim_pow(base, year)` = `base`를 `year`번 곱한 값. `sim_pow(1.1, 3)` = 1.1³ = **1.331**.

## 3. 실행 과정
| 단계 | 호출 | 동작 | accNum | bal |
|---|---|---|---:|---:|
| ① | `initAcc(&myAcc, 9981, 2200.0)` | 초기화 | 9981 | 2200.0 |
| ② | `xxx(&myAcc, &amount)` (`amount = 100.0`) | 조건: `100 > 0 && 100 < 2200` **참** → `bal = 2200 − 100` | 9981 | **2100.0** |
| ③ | `yyy(&myAcc)` | `bal = 2100 × sim_pow(1.1, 3)` = 2100 × 1.331 | 9981 | **2795.1** |

`printf("%d and %.2f", 9981, 2795.1)` → `%.2f`는 소수 둘째 자리까지 → **2795.10**

> **정답: `9981 and 2795.10`**

## 4. 암기 포인트
- `xxx` 함수는 "0 < 값 < 잔액"이면 **출금**, 아니면 **입금**.
- `%.2f` → `2795.1`이 아니라 **`2795.10`** 으로 출력.
