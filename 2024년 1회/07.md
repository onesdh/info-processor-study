# 문제 07

## 문제

아래의 내용에서 설명하는 네트워크 용어를 영문 약자로 작성하시오.

1. 대표적인 링크 상태 라우팅 프로토콜이다. 이것은 인터넷에서 연결된 링크의 상태를 감시하여 최적의 경로를 선택한다는것이다.

2. 단일 자율 시스템 내에서 라우팅 정보를 배포하는 데 사용되는 내부 게이트웨이 프로토콜이다.

3. 모든 대상에 도달하기 위한 최단 경로를 구축하고 계산하며 최단 경로는 Dijkstra 알고리즘을 사용하여 계산된다.

OSPF (Open Shortest Path First)

## 1. 문제에서 묻는 것
"**링크 상태** 라우팅, **내부 게이트웨이**, **다익스트라** 알고리즘" → 영문 약자를 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) AS와 IGP
- **AS(자율 시스템)**: 하나의 기관이 관리하는 네트워크 묶음.
- **IGP**: **AS 내부**에서 쓰는 라우팅 프로토콜 (RIP, **OSPF**, IGRP)
- **EGP**: **AS 사이**에서 쓰는 프로토콜 (BGP)

### (2) OSPF (Open Shortest Path First)
| 항목 | 내용 |
|---|---|
| 방식 | **링크 상태(Link State)** — 모든 라우터가 **전체 망 지도**를 공유 |
| 알고리즘 | **다익스트라(Dijkstra)** 로 최단 경로 계산 |
| 메트릭 | **비용(Cost)**, 대역폭 기반 |
| 장점 | 대규모 망, 빠른 수렴, 멀티캐스트 지원 |
| 분류 | **IGP** |

### (3) RIP와 비교
| 구분 | RIP | OSPF |
|---|---|---|
| 알고리즘 | 거리 벡터 | **링크 상태(다익스트라)** |
| 기준 | 홉 수(최대 15) | **비용** |
| 규모 | 소규모 | **대규모** |

## 3. 문제 풀이
| 단서 | OSPF |
|---|---|
| **링크 상태** 라우팅 프로토콜, 링크 상태 감시 후 최적 경로 | ✅ |
| 단일 **자율 시스템 내**, 내부 게이트웨이 프로토콜 | ✅ |
| **Dijkstra**로 최단 경로 계산 | ✅ |

> **정답: OSPF (Open Shortest Path First)**
