# 문제 07 — OSPF 라우팅

## 문제

링크 상태 정보를 바탕으로 다익스트라 최단 경로를 계산하는 내부 게이트웨이 프로토콜 약자를 쓰시오.

## 정답

OSPF

<summary><strong>상세 해설</strong></summary>

## 핵심 개념

OSPF는 링크 상태 라우팅 프로토콜이며 같은 자율 시스템 내부에서 경로를 계산한다.

## 풀이

라우터는 링크 상태 광고로 네트워크 토폴로지 정보를 공유하고 최단 경로 우선 알고리즘으로 경로를 선택한다.

## 오답 분석

RIP은 거리 벡터이며 기본 메트릭으로 홉 수를 사용한다. 다익스트라와 링크 상태는 OSPF다.

## 암기 포인트

링크 상태 + Dijkstra는 OSPF.
