# 문제 07

## 문제

아래의 내용에서 설명하는 네트워크 용어를 영문 약자로 작성하시오.

1. 대표적인 링크 상태 라우팅 프로토콜이다. 이것은 인터넷에서 연결된 링크의 상태를 감시하여 최적의 경로를 선택한다는것이다.

2. 단일 자율 시스템 내에서 라우팅 정보를 배포하는 데 사용되는 내부 게이트웨이 프로토콜이다.

3. 모든 대상에 도달하기 위한 최단 경로를 구축하고 계산하며 최단 경로는 Dijkstra 알고리즘을 사용하여 계산된다.

<details>
<summary><strong>정답 보기</strong></summary>

OSPF (Open Shortest Path First)

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

OSPF는 링크 상태 라우팅 프로토콜이며 같은 자율 시스템 내부에서 경로를 계산한다.

## 풀이

라우터는 링크 상태 광고로 네트워크 토폴로지 정보를 공유하고 최단 경로 우선 알고리즘으로 경로를 선택한다.

## 오답 분석

RIP은 거리 벡터이며 기본 메트릭으로 홉 수를 사용한다. 다익스트라와 링크 상태는 OSPF다.

## 암기 포인트

링크 상태 + Dijkstra는 OSPF.
