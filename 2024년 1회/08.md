# 문제 08

## 문제

아래 내용의 각각의 설명에 대한 답을 작성하시오.

(1) 조인에 참여하는 두 릴레이션의 속성 값을 비교하여 조건을 만족하는 튜플만 반환한다.

(2) 조건이 정확하게 '=' 등호로 일치하는 결과를 반환한다.

(3) ( (2) ) 조인에서 조인에 참여한 속성이 두 번 나오지 않도록 중복된 속성을 제거한 결과를 반환한다.

## 1. 문제에서 묻는 것
**관계대수의 JOIN 종류**(세타 조인, 동등 조인, 자연 조인)를 설명에 맞게 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 조인(Join)
두 릴레이션의 **속성 값을 비교**해 조건을 만족하는 튜플을 **하나로 합치는** 연산이다.

### (2) 조인의 종류 (포함 관계)
```text
 세타 조인(θ) ⊃ 동등 조인(Equi) ⊃ 자연 조인(Natural)
 (모든 비교연산)   (= 비교만)        (= 비교 + 중복 속성 제거)
```
| 종류 | 조건 | 결과 |
|---|---|---|
| **세타 조인(θ-join)** | **`=, <, >, ≤, ≥, ≠`** 등 **임의의 비교 연산** | 조건을 만족하는 튜플 |
| **동등 조인(Equi-join)** | **`=`(등호)** 만 사용하는 세타 조인 | 조인 속성이 **두 번** 나옴 |
| **자연 조인(Natural join)** | 동등 조인 + **중복된 속성을 한 번만** 남김 | 조인 속성이 **한 번만** 나옴 |

### (3) 예
R(학번, 이름) ⋈ S(학번, 점수) 를 `R.학번 = S.학번`으로 조인
| 방식 | 결과 열 |
|---|---|
| 동등 조인 | R.학번, 이름, **S.학번**, 점수 (학번이 2번) |
| **자연 조인** | 학번, 이름, 점수 (학번이 **1번**) |

## 3. 문제 풀이
| 번호 | 설명 | 정답 |
|---|---|---|
| (1) | 두 릴레이션의 속성 값을 **비교**해 조건을 만족하는 튜플만 반환 | **세타 조인** |
| (2) | 조건이 정확히 **'=' 등호**로 일치 | **동등 조인** |
| (3) | (2) 조인에서 **중복 속성을 제거** | **자연 조인** |

> **정답: (1) 세타 조인 (2) 동등 조인 (3) 자연 조인**
