# 문제 08

## 문제

아래 내용의 각각의 설명에 대한 답을 작성하시오.

(1) 조인에 참여하는 두 릴레이션의 속성 값을 비교하여 조건을 만족하는 튜플만 반환한다.

(2) 조건이 정확하게 '=' 등호로 일치하는 결과를 반환한다.

(3) ( (2) ) 조인에서 조인에 참여한 속성이 두 번 나오지 않도록 중복된 속성을 제거한 결과를 반환한다.

<details>
<summary><strong>정답 보기</strong></summary>

(1) 세타 조인

(2) 동등 조인

(3) 자연 조인

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

세타 조인은 임의 비교 조건, 동등 조인은 등호, 자연 조인은 같은 이름의 공통 속성을 중복 없이 반환한다.

## 풀이

임의 비교 연산자를 쓰는 조인이 세타 조인이다. 그중 =만 사용하는 경우 동등 조인이다. 자연 조인은 공통 속성 값이 같은 행을 결합하면서 조인 속성을 한 번만 결과에 둔다.

## 오답 분석

자연 조인은 동등 조인의 한 형태이며, 결과에서 공통 속성이 두 번 나오지 않는 점이 특징이다.

## 암기 포인트

세타 포함, 등호는 동등, 중복열 제거는 자연.

</details>
