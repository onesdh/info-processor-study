## 1. 문제에서 묻는 것
라우터로 구분된 세 개의 네트워크 그림에서, 같은 네트워크에 속하는 **빈칸 2·4·5번의 IP 주소**를 보기에서 고르는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 네트워크와 라우터
**라우터**는 서로 다른 네트워크를 연결한다. 한 구역(점선 박스)에 있는 호스트들은 **같은 네트워크**여야 하고, 구역이 다르면 **네트워크 주소가 달라야** 한다.

### (2) 같은 네트워크 판별: IP AND 서브넷마스크 = 네트워크 주소
| 표기 | 마스크 |
|---|---|
| /24 | 255.255.255.0 |
| /22 | 255.255.252.0 (3번째 옥텟을 **4씩 묶음**) |

### (3) 사용 불가능한 주소
호스트 주소로 쓸 수 없는 두 값: **네트워크 주소(호스트 비트 모두 0)**, **브로드캐스트 주소(모두 1)**.

## 3. 그림 구조
```text
 [ 네트워크 A ]──라우터──[ 네트워크 B ]──라우터──[ 네트워크 C ]
   ① ②                    ③ ④                    ⑤ ⑥
 192.168.35.3/24          129.200.10.16/22        192.168.36.24/24
```
| 구역 | 알려진 주소 | 네트워크 주소 | 범위 |
|---|---|---|---|
| A (①②) | 192.168.35.3/24 | 192.168.35.0/24 | 192.168.35.1 ~ .254 |
| B (③④) | 129.200.10.16/22 | 10 → 블록 8~11 → **129.200.8.0/22** | 129.200.8.1 ~ 129.200.11.254 |
| C (⑤⑥) | 192.168.36.24/24 | 192.168.36.0/24 | 192.168.36.1 ~ .254 |

## 4. 보기 판별
보기: `192.168.35.0` / `192.168.35.72` / `192.168.36.0` / `192.168.36.249` / `129.200.8.0` / `129.200.8.249`

| 빈칸 | 구역 | 후보 | 판단 |
|---|---|---|---|
| ② | A (192.168.35.x) | 192.168.35.0 | **네트워크 주소** → 호스트 사용 불가 ❌ |
| ② | A | **192.168.35.72** | 사용 가능 ✅ |
| ④ | B (129.200.8~11.x) | 129.200.8.0 | **네트워크 주소** ❌ |
| ④ | B | **129.200.8.249** | 사용 가능 ✅ |
| ⑤ | C (192.168.36.x) | 192.168.36.0 | **네트워크 주소** ❌ |
| ⑤ | C | **192.168.36.249** | 사용 가능 ✅ |

> **정답: 2) 192.168.35.72 / 4) 129.200.8.249 / 5) 192.168.36.249**

## 5. 암기 포인트
- 보기의 `.0`으로 끝나는 주소는 **네트워크 주소**라서 호스트 IP로 못 쓴다.
- /22는 3번째 옥텟이 8~11인 주소까지 같은 네트워크이다 (129.200.10.16도 포함).
