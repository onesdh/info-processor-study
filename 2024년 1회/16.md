# 문제 16 — Java 오버라이딩과 다형성

## 문제

부모형 참조가 자식 객체의 print를 호출할 때 출력값을 구하시오.

## 정답

9

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

오버라이딩된 인스턴스 메서드는 런타임 객체의 실제 타입을 기준으로 호출된다.

## 풀이

one의 선언 타입은 classOne이지만 실제 객체는 classTwo다. 실행 시 classTwo.print가 선택되어 po=3의 제곱인 9를 출력한다.

## 오답 분석

부모 메서드의 a+b=21은 오버라이드되어 실행되지 않는다. 필드와 달리 인스턴스 메서드는 동적 바인딩된다.

## 암기 포인트

부모 참조여도 자식 메서드 실행.
