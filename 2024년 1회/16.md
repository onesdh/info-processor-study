# 문제 16

## 문제

다음 Java 코드를 보고 알맞는 출력 값을 작성하시오.

```
class classOne {
    int a, b;

    public classOne(int a, int b) {
        this.a = a;
        this.b = b;
    }

    public void print() {
        System.out.println(a + b);
    }

}
class classTwo extends classOne {
    int po = 3;

    public classTwo(int i) {
        super(i, i+1);
    }

    public void print() {
        System.out.println(po*po);
    }
}

public class main {
    public static void main(String[] args) {
        classOne one = new classTwo(10);
        one.print();
    }
}
```

## 1. 문제에서 묻는 것
**상속과 메서드 오버라이딩**에서 변수 타입이 부모(`classOne`)여도 **실제 객체가 자식(`classTwo`)** 일 때 어떤 메서드가 실행되는지 묻는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 오버라이딩과 동적 바인딩
자식 클래스가 **같은 시그니처의 메서드를 재정의**하면, 변수의 선언 타입이 부모라도 **실제 객체(자식)의 메서드**가 실행된다.
```java
classOne one = new classTwo(10);   // 선언 타입 classOne, 실제 객체 classTwo
one.print();                        // → classTwo.print() 실행!
```
### (2) 생성자 `super(i, i+1)`
자식 생성자는 부모 생성자를 `super(...)`로 호출해 부모의 필드(`a`, `b`)를 초기화한다.

## 3. 클래스 구조
```text
 classOne : int a, b;    print() → a + b 출력
     ▲
 classTwo : int po = 3;  print() → po * po 출력   ← classOne.print() 오버라이딩
            classTwo(int i) { super(i, i+1); }     → a=10, b=11
```
## 4. 실행 과정
| 단계 | 내용 |
|---|---|
| ① | `new classTwo(10)` → `super(10, 11)` → `a = 10`, `b = 11` |
| ② | `one.print()` → **실제 객체가 classTwo** → `classTwo.print()` |
| ③ | `po * po` = 3 × 3 = **9** (부모의 `a + b = 21`은 실행되지 않음) |

> **정답: `9`**

## 5. 암기 포인트
- **오버라이딩된 메서드는 실제 객체의 것이 실행**된다(변수 타입이 부모여도).
- 21(`a+b`)이라고 답하면 오답 — 자식이 재정의했기 때문.
