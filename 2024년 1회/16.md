# 문제 16

## 문제

다음 Java 코드를 보고 알맞는 출력 값을 작성하시오.

```
class classOne {
    int a, b;

    public classOne(int a, int b) {
        this.a = a;
        this.b = b;
    }

    public void print() {
        System.out.println(a + b);
    }

}
class classTwo extends classOne {
    int po = 3;

    public classTwo(int i) {
        super(i, i+1);
    }

    public void print() {
        System.out.println(po*po);
    }
}

public class main {
    public static void main(String[] args) {
        classOne one = new classTwo(10);
        one.print();
    }
}
```

<details>
<summary><strong>정답 보기</strong></summary>

9

</details>

<summary><strong>상세 해설</strong></summary>

## 핵심 개념

오버라이딩된 인스턴스 메서드는 런타임 객체의 실제 타입을 기준으로 호출된다.

## 풀이

one의 선언 타입은 classOne이지만 실제 객체는 classTwo다. 실행 시 classTwo.print가 선택되어 po=3의 제곱인 9를 출력한다.

## 오답 분석

부모 메서드의 a+b=21은 오버라이드되어 실행되지 않는다. 필드와 달리 인스턴스 메서드는 동적 바인딩된다.

## 암기 포인트

부모 참조여도 자식 메서드 실행.
