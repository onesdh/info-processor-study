# 문제 10

## 문제

아래 JAVA언어 코드의 실행 순서를 중복 번호없이 작성하시오.

```
class Parent {
    int x, y;

    Parent(int x, int y) { ①
        this.x=x;
        this y=y;
    }

    int getT() { ②
        return x*y;
    }
}



​class Child extend Parent {
    int x;

    Child (int x) { ③
        super(x+1, x);
        this.x=x;
    }

    int getT(int n){ ④
        return super.getT()+n;
    }
}



class Main {
    public static void main(String[] args) { ⑤
        Parent parent = new Child(3); ⑥
        System.out.println(parent.getT()); ⑦
    }
}

```

## 핵심 개념

객체 생성 시 부모 생성자가 먼저 실행되고, 오버로딩된 부모 메서드는 선언된 시그니처로 호출된다.

## 풀이

main 진입 ⑤, Child 생성 ⑥, Child 생성자의 super 호출 ③, Parent 생성자 본문 ①, 부모 메서드 반환·출력문 ⑦, 마지막으로 getT 본문 ② 순으로 실행된다.

## 오답 분석

getT(int n)은 호출되지 않고, 부모 생성자가 자식 생성자보다 먼저 완료돼야 한다.

## 암기 포인트

main→객체 생성→super→부모 생성→호출 메서드.
