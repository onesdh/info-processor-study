# 문제 10 — Java 상속 생성 실행 순서

## 문제

Child 객체를 부모 참조에 넣은 뒤 getT를 호출할 때 코드 실행 번호 순서를 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

5 → 6 → 3 → 1 → 7 → 2

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

객체 생성 시 부모 생성자가 먼저 실행되고, 오버로딩된 부모 메서드는 선언된 시그니처로 호출된다.

## 풀이

main 진입 ⑤, Child 생성 ⑥, Child 생성자의 super 호출 ③, Parent 생성자 본문 ①, 부모 메서드 반환·출력문 ⑦, 마지막으로 getT 본문 ② 순으로 실행된다.

## 오답 분석

getT(int n)은 호출되지 않고, 부모 생성자가 자식 생성자보다 먼저 완료돼야 한다.

## 암기 포인트

main→객체 생성→super→부모 생성→호출 메서드.

</details>
