```
class Parent {
    int x, y;

    Parent(int x, int y) { ①
        this.x=x;
        this y=y;
    }

    int getT() { ②
        return x*y;
    }
}

class Main {

        Parent parent = new Child(3); ⑥
        System.out.println(parent.getT()); ⑦
    }
}

```

## 1. 문제에서 묻는 것
Java 코드가 실행되는 **순서(번호)** 를 쓰는 문제다. **생성자 호출 순서**와 **오버로딩 vs 오버라이딩**을 이해해야 한다.

## 2. 먼저 알아야 할 개념
### (1) 객체 생성 시 호출 순서
`new Child(3)` →
1. `Child` 생성자 진입
2. **`super(...)` 로 부모 `Parent` 생성자**가 먼저 실행
3. 부모 생성자가 끝나면 돌아와 **자식 생성자의 나머지** 실행

### (2) 오버라이딩 vs 오버로딩
```java
class Parent { int getT() {...} }          // ② 매개변수 없음
class Child  { int getT(int n) {...} }     // ④ 매개변수 int → 이름만 같고 시그니처가 다름
```
- `getT()` 와 `getT(int n)` 은 **시그니처가 다르므로 오버라이딩이 아니라 오버로딩**이다.
- `parent.getT()` 는 **변수 타입 `Parent`** 에 `getT()`(인자 없음)만 있으므로 **Parent의 `getT()`(②)** 가 호출된다. `Child.getT(int)`(④)는 호출되지 않는다.

## 3. 실행 순서 추적
| 순서 | 번호 | 코드 | 설명 |
|---:|:---:|---|---|
| 1 | ⑤ | `main` 시작 | |
| 2 | ⑥ | `new Child(3)` | 객체 생성 시작 |
| 3 | ③ | `Child(int x)` 생성자 진입 | |
| 4 | ① | `super(x+1, x)` → `Parent(int x, int y)` | 부모 생성자 실행 (x=4, y=3) |
| 5 | ⑦ | `println(parent.getT())` | 출력문 실행 시작 |
| 6 | ② | `Parent.getT()` | 4 × 3 = **12** 반환 (④ 실행 안 됨) |

**실행 순서: ⑤ → ⑥ → ③ → ① → ⑦ → ②**

> **정답: 6 → 3 → 1 → 7 → 2** (괄호 순서대로)

(출력되는 값은 12 이다. Parent의 x=4, y=3 이며 Child의 `int x`는 별개 필드.)

## 4. 암기 포인트
- **자식 생성자 진입 → `super()`로 부모 생성자 → 자식 나머지** 순서.
- 매개변수가 다른 같은 이름의 메서드는 오버라이딩이 아니다 → ④는 실행되지 않는다.
