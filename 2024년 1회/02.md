# 문제 02

## 문제

다음 C언어 코드에서 알맞는 출력 값을 작성하시오.

```
#include <stdio.h>

int main() {

    int v1 = 0, v2 = 35, v3 = 29;

    if(v1 > v2 ? v2 : v1) {
        v2 = v2 << 2;
    }else{
        v3 = v3 << 2;
    }

    printf("%d", v2+v3);

}
```

<details>
<summary><strong>정답 보기</strong></summary>

151

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**삼항 연산자가 `if` 조건 안에 들어간 문장**과 **비트 시프트(`<<`)** 를 해석해 `v2 + v3`을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 삼항 연산자 `조건 ? 값1 : 값2`
조건이 **참이면 값1**, **거짓이면 값2**를 결과로 한다. 결과 **자체가 하나의 값**이다.

### (2) C의 참/거짓
`if (값)` 에서 **0이면 거짓, 0이 아니면 참**이다.

### (3) 비트 시프트
`x << n` : 2진수를 **왼쪽으로 n칸** 이동 = **x × 2ⁿ**. 따라서 `x << 2` = `x × 4`.

## 3. 실행 과정 (`v1 = 0, v2 = 35, v3 = 29`)
**① if의 조건 해석**
```c
if ( v1 > v2 ? v2 : v1 )
```
- 먼저 삼항식: `v1 > v2` → `0 > 35` → **거짓** → 결과는 **`v1`** = **0**
- `if (0)` → **거짓** → **else 블록** 실행

**② else: `v3 = v3 << 2`**
- 29 × 4 = **116**

| 변수 | 값 |
|---|---:|
| v2 | 35 (변화 없음) |
| v3 | 116 |

`printf("%d", v2 + v3)` → 35 + 116 = **151**

> **정답: `151`**

## 4. 암기 포인트
- 삼항 연산의 **결과(0)** 가 if의 조건이 된다 (비교식 자체가 if의 조건이 아님).
- `<< 2` = ×4.
