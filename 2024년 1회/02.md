# 문제 02 — C 삼항 연산자와 시프트

## 문제

삼항 연산 결과를 if 조건에 사용하고 값에 왼쪽 시프트를 적용한 합을 구하시오.

## 정답

151

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

삼항 연산자는 선택한 피연산자의 값을 반환하고, 왼쪽 시프트는 2의 거듭제곱 배수 효과를 낸다.

## 풀이

v1>v2는 거짓이므로 삼항식의 결과 v1=0이 if 조건으로 평가된다. 거짓이라 v3=29<<2=116이 된다. v2는 35 그대로여서 합은 151이다.

## 오답 분석

조건식 자체가 비교 결과를 내는 게 아니라 삼항식의 선택값이 조건이 된다. 0은 거짓이다.

## 암기 포인트

삼항식 결과 0이면 else.
