# 문제 13

## 문제

아래 보기의 SQL 문장과 테이블을 참고하여 출력 값을 표로 작성하시오.

```
SELECT
    B
FROM
    R1
WHERE
    C IN (SELECT C FROM R2 WHERE D="k");
```

## 1. 문제에서 묻는 것
**서브쿼리(IN)** 로 R2의 조건에 맞는 `C` 값을 구하고, 그 값을 가진 R1의 `B`를 출력하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 서브쿼리와 IN
```sql
SELECT B FROM R1 WHERE C IN ( SELECT C FROM R2 WHERE D = "k" );
```
- **안쪽 쿼리를 먼저** 실행해 값의 목록을 만든다.
- 바깥 쿼리는 `C`가 **그 목록에 포함된** 행만 선택한다.

## 3. 문제 데이터 (그림)
**R1**

| A | B | C |
|---:|---|---|
| 1 | a | x |
| 2 | b | x |
| 1 | c | w |
| 3 | d | w |

**R2**

| C | D | E |
|---|---|---:|
| x | k | 3 |
| y | k | 3 |
| z | s | 2 |

## 4. 풀이
**① 서브쿼리**: `SELECT C FROM R2 WHERE D = "k"`
| R2의 행 | D = "k"? |
|---|:---:|
| x, k, 3 | ✅ |
| y, k, 3 | ✅ |
| z, s, 2 | ❌ |

→ 결과 목록: **{x, y}**

**② 바깥 쿼리**: R1에서 `C IN (x, y)`
| A | B | C | 포함? |
|---:|---|---|:---:|
| 1 | a | x | ✅ |
| 2 | b | x | ✅ |
| 1 | c | w | ❌ |
| 3 | d | w | ❌ |

→ 선택된 행의 `B` 열 출력

| B |
|---|
| a |
| b |

> **정답: 위 표 (B = a, b)**

## 5. 암기 포인트
- 서브쿼리는 **안쪽부터**. R2에 `y`가 있어도 R1에 `C=y`가 없으므로 결과에 영향 없음.
