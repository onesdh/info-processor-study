# 문제 20

## 문제

다음 아래의 내용을 보고 알맞는 용어를 작성하시오.

구체적인 클래스에 의존하지 않고 서로 연관되거나 의존적인 객체들의 조합을 만드는 인터페이스를 제공하는 패턴이다.

연관성이 있는 객체 군이 여러개 있을 경우 이들을 묶어 추상화하고, 어떤 구체적인 상황이 주어지면 팩토리 객체에서 집합으로 묶은 객체 군을 구현화 하는 생성 패턴이다

관련성 있는 여러 종류의 객체를 일관된 방식으로 생성하는 경우에 유용하다.

## 핵심 개념

추상 팩토리는 서로 연관된 객체들의 제품군을 구체 클래스 노출 없이 생성한다.

## 풀이

클라이언트가 추상 팩토리에 생성을 요청하면 특정 제품군에 맞는 객체 조합을 돌려받는다. 팩토리를 바꾸면 관련 객체군을 함께 바꿀 수 있다.

## 오답 분석

팩토리 메서드는 단일 제품 생성을 하위 클래스에 맡기는 패턴이다. 관련 객체군 전체 생성은 추상 팩토리다.

## 암기 포인트

관련된 객체군 생성은 Abstract Factory.
