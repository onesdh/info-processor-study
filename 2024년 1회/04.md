# 문제 04

## 문제

다음은 C언어에 대한 문제이다. 알맞는 출력 값을 작성하시오.

```
#include <stdio.h>
#include <string.h>

void reverse(char* str){
    int len = strlen(str);
    char temp;
    char*p1 = str;
    char*p2 = str + len - 1;
    while(p1<p2){
        temp = *p1;
        *p1 = *p2;
        *p2 = temp;
        p1++;
        p2--;
    }
}

int main(int argc, char* argv[]){
    char str[100] = "ABCDEFGH";

    reverse(str);

    int len = strlen(str);

    for(int i=1; i<len; i+=2){
        printf("%c",str[i]);
    }

    printf("\n");

    return 0;

}
```

## 핵심 개념

양 끝 포인터가 교환을 반복해 문자열을 역순으로 만든 뒤 인덱스 1,3,5,7을 읽는다.

## 풀이

역순 문자열은 HGFEDCBA다. 인덱스 1,3,5,7의 문자는 G,E,C,A이므로 GECA가 출력된다.

## 오답 분석

원본 문자열에서 홀수 위치를 뽑는 것이 아니다. 먼저 문자열 전체를 뒤집는다.

## 암기 포인트

뒤집은 HGFEDCBA에서 1·3·5·7.
