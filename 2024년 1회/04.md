# 문제 04

## 문제

다음은 C언어에 대한 문제이다. 알맞는 출력 값을 작성하시오.

```
#include <stdio.h>
#include <string.h>

void reverse(char* str){
    int len = strlen(str);
    char temp;
    char*p1 = str;
    char*p2 = str + len - 1;
    while(p1<p2){
        temp = *p1;
        *p1 = *p2;
        *p2 = temp;
        p1++;
        p2--;
    }
}

int main(int argc, char* argv[]){
    char str[100] = "ABCDEFGH";

    reverse(str);

    int len = strlen(str);

    for(int i=1; i<len; i+=2){
        printf("%c",str[i]);
    }

    printf("\n");

    return 0;

}
```

## 1. 문제에서 묻는 것
**포인터 두 개로 문자열을 뒤집는** 함수를 실행한 뒤, **홀수 인덱스의 문자**만 출력하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 문자열과 포인터
```text
 str : A B C D E F G H \0
 idx : 0 1 2 3 4 5 6 7  8
```
`char* p1 = str;` 는 첫 글자, `char* p2 = str + len - 1;` 는 마지막 글자(널 문자 바로 앞)를 가리킨다.

### (2) 양 끝에서 좁혀 오며 교환
```c
while (p1 < p2) { swap(*p1, *p2); p1++; p2--; }   // 두 포인터가 만날 때까지
```
## 3. 실행 과정
`len = 8`
| 반복 | p1 가리킴 | p2 가리킴 | 교환 후 문자열 |
|---:|---|---|---|
| 시작 | A | H | ABCDEFGH |
| 1 | A ↔ H | | **H**BCDEFG**A** |
| 2 | B ↔ G | | H**G**CDEF**B**A |
| 3 | C ↔ F | | HG**F**DE**C**BA |
| 4 | D ↔ E | | HGF**ED**CBA |
| 종료 | p1 ≥ p2 | | **HGFEDCBA** |

**출력**: `i = 1, 3, 5, 7` (홀수 인덱스)
```text
 idx: 0 1 2 3 4 5 6 7
 문자: H G F E D C B A
        ▲   ▲   ▲   ▲
        G   E   C   A
```
`G`, `E`, `C`, `A` → **GECA**

> **정답: `GECA`**

## 4. 암기 포인트
- 뒤집은 문자열은 `HGFEDCBA`. 인덱스 0은 `H`, **1은 `G`**.
- `for (i=1; i<len; i+=2)`는 **1, 3, 5, 7번째 인덱스**만 순회.
