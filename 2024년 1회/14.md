# 문제 14

## 문제

아래는 애플리케이션 테스트 관리에 대한 내용이다. 설명하는 답을 보기에서 골라 작성하시오.

1. 모든 분기와 조건의 조합을 고려하나 모든 조합을 테스트하는 대신에 테스트가 필요한 중요한 조합을 찾아내는데에 중점을 둔다.

2. 특정 조건을 수행할 때 다른 조건과는 상관없이 전체 결과에 영향을 미치는 조건만을 테스트한다.

3. 각각의 파라미터는 적어도 한 번은 최종 결과에 영향을 주어야 한다.

## 1. 문제에서 묻는 것
**화이트박스 테스트 커버리지** 중 설명(변경 조건/결정)에 해당하는 것을 보기에서 고르는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 용어
- **결정(Decision)**: `if (A && B)` 전체 조건식
- **조건(Condition)**: `A`, `B` 같은 개별 조건식

### (2) 커버리지 종류 (약 → 강)
| 커버리지 | 기준 |
|---|---|
| 구문 | 모든 문장 실행 |
| 결정(분기) | 결정의 T/F 모두 |
| 조건 | 각 조건의 T/F 모두 |
| 조건/결정 | 결정 + 조건 모두 만족 |
| **변경 조건/결정 (MC/DC)** | **각 조건이 다른 조건과 무관하게 단독으로 결과에 영향**을 주도록 |
| 다중 조건 | 조건의 **모든 조합** (2ⁿ 가지) |

### (3) MC/DC 의 아이디어
`if (A && B)`에서 모든 조합(4가지)을 다 하는 대신, **"A만 바꿨더니 결과가 바뀌는 쌍"**, **"B만 바꿨더니 결과가 바뀌는 쌍"** 을 확보한다.
| 테스트 | A | B | A&&B |
|---|:---:|:---:|:---:|
| t1 | T | T | T |
| t2 | F | T | **F** ← A만 바꿈 (t1↔t2 결과 바뀜) |
| t3 | T | F | **F** ← B만 바꿈 (t1↔t3 결과 바뀜) |

→ 3개 테스트로 **각 조건이 결과에 독립적으로 영향**을 줌을 보인다. 다중 조건 커버리지(4개)보다 **적게** 테스트하면서 **중요한 조합**만 확인한다.

## 3. 문제 풀이
| 설명 | 해당 |
|---|---|
| 1. 모든 조합을 고려하되 **중요한 조합**만 찾아 테스트 | MC/DC |
| 2. 특정 조건이 **다른 조건과 상관없이 전체 결과에 영향**을 미치는 조건만 테스트 | MC/DC |
| 3. 각 파라미터가 **최소 한 번은 최종 결과에 영향** | MC/DC |

> **정답: ㄹ. 변경 조건/결정 커버리지 (MC/DC)**

## 4. 암기 포인트
- **다중 조건 = 모든 조합**, **MC/DC = 각 조건의 독립적 영향만 확인**(조합 수 감소).
