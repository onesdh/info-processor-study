# 문제 01

## 문제

다음 Java 코드에서 알맞는 출력 값을 작성하시오.

```
class Connection {

    private static Connection _inst = null;
    private int count = 0;

    static public Connection get() {
        if(_inst == null) {
            _inst = new Connection();
            return _inst;
        }
        return _inst;
    }

    public void count() {
         count++;
    }

    public int getCount() {
         return count;
    }
}


public class main {

    public static void main(String[] args) {

        Connection conn1 = Connection.get();
        conn1.count();

        Connection conn2 = Connection.get();
        conn2.count();

        Connection conn3 = Connection.get();
        conn3.count();

        conn1.count();
        System.out.print(conn1.getCount());
    }

}
```

## 1. 문제에서 묻는 것
**싱글톤(Singleton) 패턴**으로 구현된 클래스에서, 여러 변수가 **같은 객체**를 가리킨다는 것을 이해하고 `count` 값을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 싱글톤(Singleton) 패턴 (생성 패턴)
어떤 클래스의 **인스턴스(객체)를 오직 1개만** 만들도록 보장하고, 어디서든 **그 하나에 접근**하게 하는 패턴이다. (설정 정보, DB 연결, 로그 관리자 등)

### (2) 구현 방식
```java
class Connection {
    private static Connection _inst = null;     // ① 유일한 객체를 저장할 static 변수
    private Connection() {...}                   // ② (보통) 생성자를 private으로 막음
    static public Connection get() {             // ③ 접근 통로
        if (_inst == null) { _inst = new Connection(); }   // 처음 한 번만 생성
        return _inst;                                       // 이후엔 기존 객체 반환
    }
}
```
```text
 get() 1회차: _inst == null → new Connection() 생성 → _inst에 저장 → 반환
 get() 2회차 이후: _inst가 이미 있음 → 같은 객체 반환
```
### (3) 핵심
`new`를 매번 하는 것이 아니라 **`get()`이 항상 같은 객체를 돌려준다.** 따라서 `conn1`, `conn2`, `conn3`는 **모두 같은 하나의 객체**를 가리킨다.
```text
 conn1 ─┐
 conn2 ─┼──▶ [ Connection 객체  count = ? ]   (하나뿐)
 conn3 ─┘
```
## 3. 실행 과정
| 단계 | 코드 | 객체 | count |
|---|---|---|---:|
| ① | `conn1 = Connection.get()` | **새로 생성**(count=0) | 0 |
| ② | `conn1.count()` | 같은 객체 | 1 |
| ③ | `conn2 = Connection.get()` | **기존 객체 반환**(=conn1과 동일) | 1 |
| ④ | `conn2.count()` | | 2 |
| ⑤ | `conn3 = Connection.get()`, `conn3.count()` | 기존 객체 | 3 |
| ⑥ | `conn1.count()` | | **4** |

`conn1.getCount()` → **4**

> **정답: `4`**

## 4. 암기 포인트
- 싱글톤은 객체가 1개 → 어느 변수로 증가시켜도 **하나의 `count`가 누적**된다.
- (변수가 3개라고 해서 객체도 3개가 아니다.)
