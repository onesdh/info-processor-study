# 문제 19

## 문제

다음 C언어 코드의 알맞는 출력 값을 작성하시오.

```
#include<stdio.h>
#include<ctype.h>

int main(){
    char*p = "It is 8";
    char result[100];
    int i;

    for(i=0; p[i]!='\0'; i++){
        if(isupper(p[i]))
            result[i] = (p[i]-'A'+5)% 25 + 'A';
        else if(islower(p[i]))
            result[i] = (p[i]-'a'+10)% 26 + 'a';
        else if(isdigit(p[i]))
            result[i] = (p[i]-'0'+3)% 10 + '0';
        else if(!(isupper(p[i]) || islower(p[i]) || isdigit(p[i])))
            result[i] = p[i];
    }

    result[i] = '\0';
    printf("%s\n",result);

    return 0;
}
```

## 핵심 개념

각 문자 범위에서 기준 문자로부터의 오프셋을 계산하고 모듈로 연산으로 순환시킨다.

## 풀이

대문자 I는 5칸 이동하여 N, 소문자 t는 10칸 이동해 d, 공백은 그대로, i는 s, s는 c, 두 번째 공백도 그대로, 숫자 8은 3칸 이동해 1이 된다.

## 오답 분석

대문자 공식은 문제에서 %25로 주어져 일반적인 26자 회전과 다르게 보일 수 있다. 주어진 식을 그대로 적용한다.

## 암기 포인트

대문자 +5, 소문자 +10, 숫자 +3.
