# 문제 19

## 문제

다음 C언어 코드의 알맞는 출력 값을 작성하시오.

```
#include<stdio.h>
#include<ctype.h>

int main(){
    char*p = "It is 8";
    char result[100];
    int i;

    for(i=0; p[i]!='\0'; i++){
        if(isupper(p[i]))
            result[i] = (p[i]-'A'+5)% 25 + 'A';
        else if(islower(p[i]))
            result[i] = (p[i]-'a'+10)% 26 + 'a';
        else if(isdigit(p[i]))
            result[i] = (p[i]-'0'+3)% 10 + '0';
        else if(!(isupper(p[i]) || islower(p[i]) || isdigit(p[i])))
            result[i] = p[i];
    }

    result[i] = '\0';
    printf("%s\n",result);

    return 0;
}
```

## 1. 문제에서 묻는 것
문자 종류(대문자·소문자·숫자·기타)별로 **ASCII 값을 이용해 문자를 이동(암호화)** 하는 코드의 출력을 구하는 문제다. (시저 암호와 비슷)

## 2. 먼저 알아야 할 개념
### (1) 문자는 숫자(ASCII)다
| 범위 | 문자 | ASCII |
|---|---|---|
| 대문자 | A ~ Z | 65 ~ 90 |
| 소문자 | a ~ z | 97 ~ 122 |
| 숫자 | 0 ~ 9 | 48 ~ 57 |

`p[i] - 'A'` = 대문자의 **알파벳 순번(A=0)**, 여기에 이동량을 더한 뒤 `% 개수`로 순환시키고 다시 `+ 'A'`로 문자 복원.

### (2) 분류 함수 (`<ctype.h>`)
`isupper`(대문자), `islower`(소문자), `isdigit`(숫자) — 참/거짓 판별.

## 3. 변환 규칙
| 종류 | 식 | 의미 |
|---|---|---|
| 대문자 | `(c - 'A' + 5) % 25 + 'A'` | 5칸 이동, **25로 나눔**(26이 아님!) |
| 소문자 | `(c - 'a' + 10) % 26 + 'a'` | 10칸 이동 |
| 숫자 | `(c - '0' + 3) % 10 + '0'` | 3 증가 |
| 기타(공백 등) | 그대로 | |

## 4. 실행 과정 (`"It is 8"`)
| 글자 | 종류 | 계산 | 결과 |
|:---:|---|---|:---:|
| `I` | 대문자 | I는 순번 8 → (8+5)%25 = 13 → 13번째 | **N** |
| `t` | 소문자 | t는 순번 19 → (19+10)%26 = 3 → 3번째 | **d** |
| ` ` | 기타 | 그대로 | ` ` |
| `i` | 소문자 | i는 순번 8 → (8+10)%26 = 18 | **s** |
| `s` | 소문자 | s는 순번 18 → (18+10)%26 = 2 | **c** |
| ` ` | 기타 | 그대로 | ` ` |
| `8` | 숫자 | (8+3)%10 = 1 | **1** |

※ 알파벳 순번: A0 B1 C2 D3 E4 F5 G6 H7 I8 J9 K10 L11 M12 **N13** … , a0 b1 c2 **d3** … i8 … **s18**… (s=18, 28 % 26 = 2 → c)

결과 문자열: `N d ␣ s c ␣ 1` → **`Nd sc 1`**

> **정답: `Nd sc 1`**

## 5. 암기 포인트
- 대문자는 **`% 25`** 라는 함정(소문자는 `% 26`).
- 공백은 마지막 `else if(!(…))`에서 **원래 문자 그대로** 저장.
