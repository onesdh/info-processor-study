# 문제 14

## 문제

테스트 오라클 중 특정한 몇 개의 입력값에 대해서만 기대하는 결과를 제공해주는 오라클은 무엇인가?

<details>
<summary><strong>정답 보기</strong></summary>

샘플링 오라클

테스트 오라클은 테스트의 결과가 참인지 거짓인지를 판단하기 위해서 사전에 정의된 참값을 입력하여 비교하는 기법

테스트 오라클 유형 :

참 오라클 - 모든 입력값에 대하여 기대하는 결과를 생성하여 오류 검출

샘플링 오라클 - 특정한 몇 개의 입력값에 대해서만 기대하는 결과를 제공

휴리스틱 오라클 - 샘플링 오라클을 개선 / 특정 입력값에 올바른 결과를 제공하고 나머지 값은 휴리스틱(추정)으로 처리

일관성 검사 오라클 - 애플리케이션 변경이 있을 때, 수행 전과 후의 결괏값이 동일한지 확인

## 1. 문제에서 묻는 것
"**특정한 몇 개의 입력값에 대해서만** 기대하는 결과를 제공해 주는 **테스트 오라클**" → 어떤 오라클인지 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 테스트 오라클(Test Oracle)
테스트 결과가 **참인지 거짓인지 판단**하기 위해 **사전에 정의된 "정답(기대 결과)"** 과 실제 결과를 비교하는 기법·도구. ("oracle = 신탁, 정답을 알려주는 존재")

### (2) 오라클 유형
| 유형 | 설명 |
|---|---|
| **참(True) 오라클** | **모든 입력값**에 대해 기대 결과를 생성해 오류 검출 (가장 완벽) |
| **샘플링(Sampling) 오라클** | **특정한 몇 개의 입력값**에 대해서만 기대 결과를 제공 |
| **휴리스틱(Heuristic) 오라클** | 샘플링 오라클을 개선 — **특정 입력값**에는 올바른 결과, **나머지는 추정(휴리스틱)** |
| **일관성 검사(Consistent) 오라클** | **변경 전후**의 결과가 **동일한지** 확인 |

```text
 참        : 입력 1…N 모두 정답 보유  (100% 정답표)
 샘플링    : 입력 중 일부(몇 개)만 정답 보유
 휴리스틱  : 일부는 정답 + 나머지는 추정
 일관성    : 수정 전 결과 == 수정 후 결과?
```
## 3. 문제 풀이
| 단서 | 샘플링 오라클 |
|---|---|
| **특정한 몇 개의 입력값**에 대해서만 기대 결과 제공 | ✅ |

> **정답: 샘플링 오라클 (Sampling Oracle)**
