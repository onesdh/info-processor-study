# 문제 14

## 문제

테스트 입력 중 일부에 대해서만 기대 결과를 제공하는 테스트 오라클 유형을 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

샘플링 오라클

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

샘플링 오라클은 일부 대표 입력의 예상 결과만 제공해 실제 결과와 비교한다.

## 풀이

모든 입력을 계산하지 않고 특정 표본값의 기대 결과만 갖고 검증한다.

## 오답 분석

참 오라클은 모든 입력의 결과를 제공하고, 휴리스틱은 일부 정확값과 나머지 추정값을 사용한다.

## 암기 포인트

일부 표본의 정답만 있으면 샘플링.

</details>
