# 문제 07

## 문제

스니핑(Sniffing)에 대하여 서술하시오.

<details>
<summary><strong>정답 보기</strong></summary>

암호화되지 않은 패킷들을 수집하여 순서대로 재조합 후 ID, PW와 같은 중요한 정보를 유출하기 위한 수동적인 형태의 공격

네트워크 공격 기법

스니핑 / 네트워크 스캐너, 스니퍼 / 패스워드 크래킹 / IP 스푸핑 / ARP 스푸핑 / ICMP Redirect 공격 / 트로이 목마

IP스푸핑 : 발신지 IP나 목적지 IP를 위조하여 공격하는 기법

ARP스푸핑 : MAC 주소를 위조하여 랜상에서의 통신 흐름을 왜곡시키는 공격 기법

트로이 목마 : 사용자가 원하는 무언가로 변장해 시스템 방어망을 뚫고 들어가는 공격 기법

## 1. 문제에서 묻는 것
**스니핑(Sniffing)** 이 무엇인지 서술하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 스니핑(Sniffing)
**sniff = 킁킁 냄새 맡다.** 네트워크를 지나가는 **패킷을 몰래 엿보는(도청) 공격**이다. 상대에게 직접 패킷을 보내지 않고 **조용히 훔쳐보기만 하므로 "수동적(passive) 공격"** 이다.
```text
 [ 사용자 ] ─── ID/PW(평문) ───▶ [ 서버 ]
                 ▲
                 │ 공격자가 같은 네트워크에서 패킷을 수집(스니핑)
              [ 공격자 ]  →  ID, 비밀번호 획득
```
### (2) 특징
| 항목 | 내용 |
|---|---|
| 대상 | **암호화되지 않은** 평문 패킷 (Telnet, FTP, HTTP 등) |
| 방식 | 패킷 수집 → **순서대로 재조합** → ID·PW 같은 중요 정보 유출 |
| 성격 | **수동적 공격**(통신 내용을 바꾸지 않고 엿보기만) |
| 도구 | 와이어샤크(Wireshark), tcpdump |
| 대응 | **암호화**(HTTPS, SSH, VPN), 스위치 환경 보호 |

### (3) 다른 네트워크 공격과 비교
| 공격 | 설명 |
|---|---|
| **스니핑** | 패킷 **도청**(수동) |
| IP 스푸핑 | **출발지/목적지 IP를 위조** |
| ARP 스푸핑 | **MAC 주소 위조**로 LAN 통신 흐름 왜곡 |
| 트로이 목마 | 정상 프로그램으로 위장해 침투 |

## 3. 서술 답안
> **스니핑: 네트워크를 지나는 암호화되지 않은 패킷을 수집·재조합하여 ID, PW 같은 중요한 정보를 유출하는 수동적(도청) 공격.**
