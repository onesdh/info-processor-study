# 문제 19

## 문제

다음은 자바 소스 코드이다. 출력 결과를 쓰시오.

```
class parent{
	public int compute(int num){
    	if(num <=1) return num;
        return compute(num-1) + compute(num-2);
    }
 }

 class Child extends parent {
 	public int compute(int num){
    	if(num<=1) return num;
        	return compute(num-1) + compute(num-3);
        }
   }

  class good{
  	public static void main (String[] args){
    parent obj = new Child();
    System.out.print(obj.compute(4));
   }
 }


```

## 핵심 개념

오버라이딩 메서드는 실제 객체의 타입을 기준으로 실행된다. 재귀 호출도 Child.compute 구현으로 동적 바인딩된다.

## 풀이

C(0)=0, C(1)=1이다. C(2)=C(1)+C(-1)=0, C(3)=C(2)+C(0)=0, C(4)=C(3)+C(1)=1이다.

## 오답 분석

부모 변수형이라는 이유로 부모의 피보나치식이 호출되는 것이 아니다. 코드의 종료 조건은 0 이하가 아닌 1 이하이므로 음수 입력은 그 값 그대로 반환한다.

## 암기 포인트

실행 객체가 Child면 재귀도 Child 메서드.
