# 문제 19

## 문제

다음은 자바 소스 코드이다. 출력 결과를 쓰시오.

```
class parent{
	public int compute(int num){
    	if(num <=1) return num;
        return compute(num-1) + compute(num-2);
    }
 }

 class Child extends parent {
 	public int compute(int num){
    	if(num<=1) return num;
        	return compute(num-1) + compute(num-3);
        }
   }

  class good{
  	public static void main (String[] args){
    parent obj = new Child();
    System.out.print(obj.compute(4));
   }
 }


```

## 1. 문제에서 묻는 것
**재귀 + 오버라이딩**: 변수 타입은 `parent`지만 **실제 객체가 `Child`** 이므로, 재귀 안의 `compute`도 모두 **Child의 compute**로 호출된다.

## 2. 먼저 알아야 할 개념
### (1) 동적 바인딩
`parent obj = new Child();` 에서 `obj.compute(4)` → **Child.compute**. Child 메서드 안에서 부르는 `compute(...)`도 `this.compute`라 **다시 Child.compute**가 실행된다.

### (2) 두 클래스의 점화식
| 클래스 | 식 |
|---|---|
| parent | `c(n) = c(n-1) + c(n-2)` (피보나치) |
| **Child** (실제 사용) | **`c(n) = c(n-1) + c(n-3)`**, `n ≤ 1`이면 n 반환 |

## 3. Child.compute 값 계산
| n | 계산 | 값 |
|---:|---|---:|
| -1 | n ≤ 1 | -1 |
| 0 | n ≤ 1 | 0 |
| 1 | n ≤ 1 | 1 |
| 2 | c(1) + c(-1) = 1 + (-1) | 0 |
| 3 | c(2) + c(0) = 0 + 0 | 0 |
| 4 | c(3) + c(1) = 0 + 1 | **1** |

> **정답: `1`**

## 4. 암기 포인트
- 부모의 피보나치 식(결과 3)으로 계산하면 오답. **실제 객체 Child의 식**을 쓴다.
- `n <= 1`이면 **음수도 그대로 반환**된다.
