# 문제 08

## 문제

IP 패킷에서 외부의 공인 IP주소와 포트 주소에 해당하는 내부 IP주소를 재기록하여 라우터를 통해 네트워크 트래픽을 주고받는 기술은 무엇인가?

<details>
<summary><strong>정답 보기</strong></summary>

NAT(Network Address Transformation)

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

NAT는 네트워크 주소 변환으로 주소와 필요시 포트 정보를 변경해 내부와 외부 통신을 연결한다.

## 풀이

주소 변환 테이블에 공인·사설 주소 대응을 기록해 여러 내부 장치가 외부망과 통신하도록 한다.

## 오답 분석

DHCP는 IP 주소를 동적으로 할당하고, VPN은 암호화된 가상 사설망을 구성한다.

## 암기 포인트

사설·공인 주소 변환은 NAT.

</details>
