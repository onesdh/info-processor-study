# 문제 08

## 문제

IP 패킷에서 외부의 공인 IP주소와 포트 주소에 해당하는 내부 IP주소를 재기록하여 라우터를 통해 네트워크 트래픽을 주고받는 기술은 무엇인가?

<details>
<summary><strong>정답 보기</strong></summary>

NAT(Network Address Transformation)

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
"**공인 IP와 포트**에 해당하는 **내부 IP를 재기록**하여 라우터를 통해 통신" → 약자를 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 사설 IP와 공인 IP
| 구분 | 설명 | 예 |
|---|---|---|
| **사설 IP** | 내부망에서만 쓰는 주소(인터넷에서 직접 사용 불가) | 192.168.x.x, 10.x.x.x |
| **공인 IP** | 인터넷에서 **유일**한 주소 | 211.x.x.x |

### (2) NAT (Network Address Translation, 네트워크 주소 변환)
라우터(공유기)가 **내부 사설 IP ↔ 외부 공인 IP(와 포트)** 를 **변환(재기록)** 해 준다.
```text
 내부 PC(192.168.0.10:5000) ──▶ [ 라우터 NAT ] ──▶ 인터넷 (공인 IP 211.1.1.1:6001로 변환)
 인터넷 응답(211.1.1.1:6001) ──▶ [ 라우터 NAT ] ──▶ 내부 PC(192.168.0.10:5000)  (변환표를 보고 되돌림)
```
- **포트까지 변환**하면 여러 내부 PC가 **공인 IP 하나**를 공유(**PAT/NAPT**).
- 장점: **공인 IP 절약**, 내부 주소 **은닉**.

## 3. 문제 풀이
| 단서 | NAT |
|---|---|
| **공인 IP·포트**에 해당하는 **내부 IP를 재기록** | ✅ |
| 라우터를 통한 트래픽 송수신 | ✅ |

> **정답: NAT (Network Address Translation)**
> (원문 정답에는 "Transformation"으로 표기되어 있으나 표준 용어는 **Translation**.)

</details>
