# 문제 09

## 문제

다음은 파이썬 소스 코드이다. 출력 결과를 쓰시오.

```
lol = [[1,2,3],[4,5],[6,7,8,9]]
print(lol[0])
print(lol[2][1])
	for sub in lol:
   	for item in sub:
        	print(item, end = '')
      	print()
```

## 1. 문제에서 묻는 것
**2차원 리스트(리스트 안의 리스트)** 의 인덱싱과 **중첩 반복문의 출력**을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 리스트 안의 리스트
```python
lol = [[1,2,3],[4,5],[6,7,8,9]]
```
```text
 lol[0] = [1, 2, 3]
 lol[1] = [4, 5]
 lol[2] = [6, 7, 8, 9]
```
### (2) 인덱싱
| 표현 | 의미 | 값 |
|---|---|---|
| `lol[0]` | 첫 번째 안쪽 리스트 | `[1, 2, 3]` |
| `lol[2][1]` | 세 번째 리스트의 **두 번째** 값 | `7` |

### (3) `print(item, end='')`
`end=''` → **줄바꿈 없이** 이어서 출력. 안쪽 반복이 끝나면 `print()`로 **줄바꿈**.

## 3. 실행 과정
**① `print(lol[0])`** → `[1, 2, 3]` (리스트 모양 그대로 출력; 원문 정답은 공백 없이 `[1,2,3]`로 표기)

**② `print(lol[2][1])`** → `7`

**③ 중첩 반복**
| 바깥 sub | 안쪽 item 출력 | 줄바꿈 후 결과 |
|---|---|---|
| [1,2,3] | `1` `2` `3` | **123** |
| [4,5] | `4` `5` | **45** |
| [6,7,8,9] | `6` `7` `8` `9` | **6789** |

> **정답**
> ```
> [1, 2, 3]
> 7
> 123
> 45
> 6789
> ```

## 4. 암기 포인트
- `lst[a][b]` : a번째 안쪽 리스트의 b번째 값(0부터).
- 안쪽 반복이 끝난 뒤의 `print()`가 줄바꿈을 만든다.
