# 문제 09 — Python 중첩 리스트 출력

## 문제

lol=[[1,2,3],[4,5],[6,7,8,9]]에서 lol[0], lol[2][1]을 출력하고 각 하위 리스트를 한 줄씩 이어 출력한다. 결과를 쓰시오.

## 정답

[1, 2, 3]; 7; 123; 45; 6789

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

중첩 리스트에서 두 인덱스는 바깥 리스트와 안쪽 원소를 차례로 가리킨다.

## 풀이

lol[0]은 첫 하위 리스트, lol[2][1]은 세 번째 리스트의 두 번째 원소 7이다. 중첩 반복은 각 리스트의 수를 end=''로 이어 출력한다.

## 오답 분석

기본 print는 줄을 바꾸지만 end=''는 같은 줄에 이어 쓰게 한다. 각 하위 리스트마다 별도 print가 있어 행이 나뉜다.

## 암기 포인트

바깥 인덱스와 안쪽 인덱스를 구분.
