# 문제 20

## 문제

정보보안에서 가용성(Availablility) 에 대하여 서술하시오.

<details>
<summary><strong>정답 보기</strong></summary>

권한을 가진 사용자가 애플리케이션이 원하는 서비스를 지속 사용할 수 있도록 보장하는 특성

SW개발 보안의 3개 요소 : 기밀성 / 무결성 / 가용성

기밀성 : 인가되지 않은 개인 혹은 시스템 접근에 따라 정보 공개 및 노출을 차단하는 특성

무결성 : 정당한 방법을 따르지 않고선 데이터가 변경될 수 없으며, 데이터의 정확성 및 완정성과 고의/악의로 변경되거나 훼손 또는 파괴되지 않음을 보장하는 특성

</details>

## 1. 문제에서 묻는 것
정보보안의 3요소 중 **가용성(Availability)** 을 서술하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 정보보안의 3요소 (CIA Triad)
| 요소 | 영문 | 의미 |
|---|---|---|
| **기밀성** | **C**onfidentiality | **인가되지 않은** 개인·시스템의 접근을 막아 정보 **노출을 차단** |
| **무결성** | **I**ntegrity | **정당한 방법 없이는** 데이터가 **변경될 수 없고**, 정확성·완전성 유지 (고의/악의적 훼손 방지) |
| **가용성** | **A**vailability | **권한을 가진 사용자**가 **필요할 때 서비스를 지속적으로 사용**할 수 있도록 보장 |

```text
        기밀성 (남이 못 보게)
          ▲
          │
  무결성 ──┼── 가용성 (필요할 때 쓸 수 있게)
 (남이 못 바꾸게)
```
### (2) 가용성을 위협하는 것과 대책
| 위협 | 대책 |
|---|---|
| **DoS/DDoS** 공격, 장애, 재난 | 이중화(Redundancy), **백업**, 부하 분산, DDoS 방어 장비, 장애 복구 계획 |

## 3. 서술 답안
> **가용성: 권한을 가진 사용자가 원하는 서비스(시스템·정보)를 필요할 때 지속적으로 사용할 수 있도록 보장하는 보안 특성.**

## 4. 암기 포인트
- **기밀성 = 노출 방지, 무결성 = 변조 방지, 가용성 = 계속 사용 가능**.
