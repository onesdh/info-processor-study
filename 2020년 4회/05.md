# 문제 05

## 문제

다음은 n이 10일 때, 10을 2진수로 변환하는 자바 소스 코드이다. 1,2에 알맞는 값을 적으시오.

[출력결과] : 00001010

```
class good {
	public static void main (String[] args) {
    	int[]a = new int[8];
        int i=0; int n=10;
        while (  1.  ) {
        	a[i++] = (  2.  );
            n /= 2;
        }
        for(i=7; i>=0; i--){
         System.out.print(a[i]);
        }
     }
  }
```

<details>
<summary><strong>정답 보기</strong></summary>

1. n &gt; 0 or n &gt;=1 or i &lt; 8 or i &lt;= 7

2. n%2 or n&1

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**10진수 → 2진수 변환** 코드에서 `while` 조건(1)과 **나머지 저장 식**(2)을 채우는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 10진수를 2진수로 바꾸는 방법 (2로 나눈 나머지)
**몫이 0이 될 때까지 2로 나누며 나머지를 구하고**, 나머지를 **아래에서 위로** 읽는다.
```text
 10 ÷ 2 = 5 … 0
  5 ÷ 2 = 2 … 1
  2 ÷ 2 = 1 … 0
  1 ÷ 2 = 0 … 1
 → 아래에서 위로: 1 0 1 0  = 1010₂
```
### (2) 코드의 동작
```java
while ( 조건 ) {
    a[i++] = ( 나머지 );     // 나머지를 배열에 차례로 저장 (낮은 자리 비트부터)
    n /= 2;                  // 몫으로 갱신
}
for (i = 7; i >= 0; i--) print(a[i]);   // 배열을 거꾸로(높은 자리부터) 출력 → 8자리 2진수
```
## 3. 풀이
| 빈칸 | 정답 | 이유 |
|---|---|---|
| (1) | **`n > 0`** (또는 `n >= 1`, `i < 8`) | 몫 n이 0이 될 때까지 반복 |
| (2) | **`n % 2`** (또는 `n & 1`) | 현재 n을 2로 나눈 **나머지** = 현재 가장 낮은 비트 |

**실행 과정 (n = 10, `a`는 8칸, 초기 0)**
| 반복 | n | `a[i++] = n % 2` | n /= 2 |
|---:|---:|---|---:|
| 1 | 10 | a[0] = 0 | 5 |
| 2 | 5 | a[1] = 1 | 2 |
| 3 | 2 | a[2] = 0 | 1 |
| 4 | 1 | a[3] = 1 | 0 |
| 종료 | 0 | `n > 0` 거짓 | |

`a = [0, 1, 0, 1, 0, 0, 0, 0]` → 거꾸로 출력(i=7→0): **00001010** ✓

> **정답: (1) `n > 0` (2) `n % 2`**

## 4. 암기 포인트
- 2진 변환 = **2로 나눈 나머지를 거꾸로**.
- 배열을 8칸으로 만들어 두고 거꾸로 출력하면 **앞에 0이 채워진 8자리**가 나온다.
