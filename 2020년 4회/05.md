# 문제 05 — Java 10진수의 2진수 변환

## 문제

n=10을 8비트 이진 문자열 00001010으로 출력한다. 반복 조건과 한 비트를 구하는 식을 각각 쓰시오.

## 정답

n>0; n%2 (또는 n&1)

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

2진수 변환은 정수를 2로 나눈 나머지를 순서대로 기록한 뒤 역순으로 읽는다.

## 풀이

10을 2로 나누면 나머지 0,1,0,1이 차례로 생긴다. 배열에 넣고 뒤에서부터 출력하면 00001010이 된다.

## 오답 분석

n/2는 나머지가 아니라 다음 반복용 몫이다. 비트를 낮은 자리부터 얻으므로 출력 순서를 뒤집는다.

## 암기 포인트

2로 나눈 나머지를 거꾸로 출력.
