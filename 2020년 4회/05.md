# 문제 05

## 문제

다음은 n이 10일 때, 10을 2진수로 변환하는 자바 소스 코드이다. 1,2에 알맞는 값을 적으시오.

[출력결과] : 00001010

```
class good {
	public static void main (String[] args) {
    	int[]a = new int[8];
        int i=0; int n=10;
        while (  1.  ) {
        	a[i++] = (  2.  );
            n /= 2;
        }
        for(i=7; i>=0; i--){
         System.out.print(a[i]);
        }
     }
  }
```

<details>
<summary><strong>정답 보기</strong></summary>

1. n &gt; 0 or n &gt;=1 or i &lt; 8 or i &lt;= 7

2. n%2 or n&1

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

2진수 변환은 정수를 2로 나눈 나머지를 순서대로 기록한 뒤 역순으로 읽는다.

## 풀이

10을 2로 나누면 나머지 0,1,0,1이 차례로 생긴다. 배열에 넣고 뒤에서부터 출력하면 00001010이 된다.

## 오답 분석

n/2는 나머지가 아니라 다음 반복용 몫이다. 비트를 낮은 자리부터 얻으므로 출력 순서를 뒤집는다.

## 암기 포인트

2로 나눈 나머지를 거꾸로 출력.
