# 문제 11

## 문제

일반 컴퓨터들로 분산 저장소를 만들고 대규모 데이터를 병렬 처리하는 오픈소스 Java 기반 프레임워크를 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

Hadoop

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

Hadoop은 대규모 데이터를 분산 저장하고 병렬 처리하는 오픈소스 프레임워크다.

## 풀이

분산 파일 시스템과 MapReduce 계열 처리 모델이 대표 구성이다.

## 오답 분석

일반 데이터베이스 서버 한 대가 처리하는 구조와 다르며, Apache Spark와는 별도 기술이다.

## 암기 포인트

분산 저장·병렬 분석은 Hadoop.
