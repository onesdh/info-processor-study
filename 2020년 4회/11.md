# 문제 11

## 문제

오픈 소스 기반으로 한 분산 컴퓨팅 플랫폼으로, 일반 PC급 컴퓨터들로 가상화된 대형 스토리지를 형성하고 그 안에 보관된 거대한 데이터 세트를 병렬로 처리할 수 있도록 개발된 자바 소프트웨어 프레임워크로 구글, 야후 등에 적용한 기술은 무엇인가?

## 1. 문제에서 묻는 것
"**오픈 소스** 분산 컴퓨팅 플랫폼, 일반 PC로 **가상화된 대형 스토리지**, 거대한 데이터 세트를 **병렬 처리**, **자바** 프레임워크, 구글·야후 적용" → 기술 이름을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 하둡(Hadoop)
**빅데이터**(너무 커서 한 컴퓨터로는 처리할 수 없는 데이터)를 **여러 대의 저렴한 컴퓨터에 나눠 저장하고 병렬로 처리**하는 **오픈 소스 자바 프레임워크**다 (Apache).
```text
 거대한 데이터 ─▶ [ 노드1 ] [ 노드2 ] [ 노드3 ] … (저렴한 PC 수십~수천 대)
                   각자 일부 데이터를 저장하고 동시에 계산 → 결과 취합
```
### (2) 구성 요소
| 구성 | 역할 |
|---|---|
| **HDFS** (Hadoop Distributed File System) | 데이터를 **여러 노드에 분산 저장** (가상화된 대형 스토리지) |
| **MapReduce** | 데이터를 **병렬로 처리**하는 프로그래밍 모델 (Map: 분할·가공 → Reduce: 취합) |
| YARN | 자원 관리 |

### (3) 특징
- **오픈 소스**, **확장성**(노드 추가로 용량·성능 증가), **장애 허용**(노드가 죽어도 복제본으로 복구), 저렴한 하드웨어 사용.

## 3. 문제 풀이
| 단서 | 하둡 |
|---|---|
| **오픈 소스** 분산 컴퓨팅 플랫폼 | ✅ |
| 일반 PC로 **가상화된 대형 스토리지**(HDFS) | ✅ |
| 거대한 데이터를 **병렬 처리**(MapReduce), **자바 프레임워크** | ✅ |

> **정답: 하둡 (Hadoop)**
