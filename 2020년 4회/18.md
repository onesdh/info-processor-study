# 문제 18

## 문제

다음은 C언어 소스 코드이다. 출력값을 쓰시오.

```
#include <stdio.h>

void main(){
	char *p = "KOREA"
    printf("%s\n" , p);
    printf("%s\n" , p+3);
    printf("%c\n" , *p);
    printf("%c\n" , *(p+3));
    printf("%c\n" , *p+2);
```

## 1. 문제에서 묻는 것
**문자 포인터와 문자열 출력**(`%s`, `%c`)에서 **포인터 연산**과 **`*p + 2`(문자 + 정수)** 를 구분하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 문자열 리터럴과 포인터
```c
char *p = "KOREA";
```
```text
 p ─▶ K  O  R  E  A  \0
      p  p+1 p+2 p+3 p+4
```
### (2) 서식 문자
| 서식 | 인자 | 출력 |
|---|---|---|
| `%s` | 문자열의 **주소**(`char*`) | 그 주소부터 `\0`까지 |
| `%c` | **문자 1개** | 그 문자 |

### (3) `*p + 2` vs `*(p + 2)`
- `*p + 2` = `(*p) + 2` = 'K'(ASCII 75) + 2 = 77 = **'M'** ← 문자 값에 2를 **더함**
- `*(p + 2)` = `p[2]` = 'R' ← 2칸 뒤의 **문자**

## 3. 줄별 출력
| 줄 | 코드 | 해석 | 출력 |
|---:|---|---|:---:|
| 1 | `printf("%s\n", p)` | 처음부터 끝까지 | **KOREA** |
| 2 | `printf("%s\n", p+3)` | 4번째 글자부터 | **EA** |
| 3 | `printf("%c\n", *p)` | 첫 글자 | **K** |
| 4 | `printf("%c\n", *(p+3))` | 4번째 글자 | **E** |
| 5 | `printf("%c\n", *p+2)` | `'K' + 2` → ASCII 77 | **M** |

> **정답**
> ```
> KOREA
> EA
> K
> E
> M
> ```

## 4. 암기 포인트
- `*p + 2`는 알파벳을 **뒤로 2칸 밀기**(K → L → M), `*(p+2)`는 **2번째 인덱스 글자**.
- 2023년 3회 10번과 같은 유형.
