# 문제 06 — Java 2차원 배열 크기

## 문제

3행 5열 배열을 만들고 a[i][j]=j*3+(i+1)로 채워 출력한다. 두 배열 크기를 순서대로 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

3; 5

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

2차원 배열 선언의 첫 길이는 행 수, 둘째 길이는 열 수다.

## 풀이

i는 0..2를 순회하고 j는 0..4를 순회하므로 크기는 3×5다. 각 행은 1,4,7,10,13부터 시작해 열마다 3씩 증가한다.

## 오답 분석

코드의 반복 횟수와 출력 모양을 함께 확인한다. 첫 번째 차원은 행, 두 번째 차원은 열이다.

## 암기 포인트

행 3, 열 5.

</details>
