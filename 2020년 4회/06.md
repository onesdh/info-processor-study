# 문제 06

## 문제

다음은 자바 소스 코드이다. 출력 결과를 보고 , 1,2에 알맞는 값을 적으시오.

[출력 결과]

1 4 7 10 13

2 5 8 11 14

3 6 9 12 15

```
public class good {
	public static void main(String[] args) {
    	int[][]a = new int[(1.)][(2.)];
        for(int i = 0; i <3; i++){
        for(int j=0; j < 5; j++){
        a[i][j] = j*3+(i+1);
        	System.out.print(a[i][j]+"");
         }
         System.out.println();
       }
     }
   }
```

## 1. 문제에서 묻는 것
출력 결과(3행 × 5열의 숫자표)를 보고 **2차원 배열의 크기**(행, 열)를 정하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 2차원 배열 선언
```java
int[][] a = new int[행][열];
```
### (2) 코드의 반복 범위
```java
for (i = 0; i < 3; i++)          // i: 행 인덱스 0~2 → 행 3개
    for (j = 0; j < 5; j++)      // j: 열 인덱스 0~4 → 열 5개
        a[i][j] = j*3 + (i+1);
```
반복문이 **i는 0~2**, **j는 0~4**를 사용하므로 배열은 최소 **3행 5열**이 필요하다.

## 3. 값 확인 (`a[i][j] = j*3 + (i+1)`)
| i \ j | 0 | 1 | 2 | 3 | 4 |
|---:|---:|---:|---:|---:|---:|
| 0 | 1 | 4 | 7 | 10 | 13 |
| 1 | 2 | 5 | 8 | 11 | 14 |
| 2 | 3 | 6 | 9 | 12 | 15 |

출력 결과와 일치:
```text
 1 4 7 10 13
 2 5 8 11 14
 3 6 9 12 15
```
## 4. 풀이
| 빈칸 | 정답 | 이유 |
|---|:---:|---|
| (1) 행 수 | **3** | 바깥 반복 `i < 3` |
| (2) 열 수 | **5** | 안쪽 반복 `j < 5` |

> **정답: (1) 3 (2) 5** → `new int[3][5]`

## 5. 암기 포인트
- 반복문의 **종료 조건 값**이 배열의 크기가 된다.
- `a[행][열]` 순서.
