# 문제 06

## 문제

다음은 자바 소스 코드이다. 출력 결과를 보고 , 1,2에 알맞는 값을 적으시오.

[출력 결과]

1 4 7 10 13

2 5 8 11 14

3 6 9 12 15

```
public class good {
	public static void main(String[] args) {
    	int[][]a = new int[(1.)][(2.)];
        for(int i = 0; i <3; i++){
        for(int j=0; j < 5; j++){
        a[i][j] = j*3+(i+1);
        	System.out.print(a[i][j]+"");
         }
         System.out.println();
       }
     }
   }
```

1. 3

2. 5

<summary><strong>상세 해설</strong></summary>

## 핵심 개념

2차원 배열 선언의 첫 길이는 행 수, 둘째 길이는 열 수다.

## 풀이

i는 0..2를 순회하고 j는 0..4를 순회하므로 크기는 3×5다. 각 행은 1,4,7,10,13부터 시작해 열마다 3씩 증가한다.

## 오답 분석

코드의 반복 횟수와 출력 모양을 함께 확인한다. 첫 번째 차원은 행, 두 번째 차원은 열이다.

## 암기 포인트

행 3, 열 5.
