# 문제 10

## 문제

분산 컴퓨팅 기술 기반의 데이터 위변조 방지 기술로 P2P방식을 기반으로 하여 소규모 데이터들이 연결되어 형성된 '블록'이라는 분산 데이터 저장 환경에 관리 대상 데이터를 저장함으로써 누구도 임의로 수정할 수 없고 누구나 변경의 결과를 열람할 수 있게끔 만드는 기술은 무엇인가?

## 1. 문제에서 묻는 것
"**P2P** 기반, **블록** 단위 분산 저장, **누구도 임의로 수정할 수 없고** 누구나 열람" → 기술 이름을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 블록체인(Blockchain)
**거래 데이터를 묶은 "블록"을 시간 순서로 사슬(Chain)처럼 연결**해, **여러 참여자가 똑같은 장부를 나눠 가지는 분산 데이터 저장 기술**이다.
```text
 [블록1: 거래 ... 해시] ◀─ [블록2: 거래 ... 이전해시] ◀─ [블록3: 거래 ... 이전해시] ◀─ ...
      각 블록은 "이전 블록의 해시값"을 포함 → 한 블록만 고쳐도 뒤의 모든 해시가 어긋나 즉시 들통
```
### (2) 핵심 특징
| 특징 | 설명 |
|---|---|
| **분산(P2P)** | 중앙 서버 없이 **참여자(노드) 모두가 동일한 장부 보유** |
| **위변조 방지** | 블록이 **해시로 연결**되어 있어 **임의 수정 불가**, 다수가 합의(**합의 알고리즘**)해야 추가 |
| **투명성** | **누구나** 거래 내역을 열람 가능 |
| **추적성** | 모든 거래가 시간순으로 기록 |

### (3) 활용
암호화폐(비트코인), 스마트 계약, 공급망 추적, 전자 투표.

## 3. 문제 풀이
| 단서 | 블록체인 |
|---|---|
| **분산 컴퓨팅**, 데이터 **위변조 방지**, **P2P** | ✅ |
| 소규모 데이터가 연결된 **'블록'** 에 저장 | ✅ |
| 누구도 **임의로 수정할 수 없고** 누구나 **열람** | ✅ |

> **정답: 블록체인 (Blockchain)**
