# 문제 17

## 문제

데니스 리치와 켄톰슨 등이 함께 벨 연구소를 통해 만든 운영체제이며, 90% 이상 C언어로 구현되어 있고, 시스템 프로그램이 모듈화되어 있어서 다른 하드웨어 기종으로 쉽게 이식 가능하며 계층적 트리 구조를 가짐으로써 통합적인 파일 관리가 용이한 운영체제는 무엇인가?

## 1. 문제에서 묻는 것
"**데니스 리치와 켄 톰슨**, 벨 연구소, **C언어로 90% 이상** 구현, **이식성**, **계층적 트리 구조** 파일" → 운영체제 이름을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 유닉스(UNIX)
**1969년 벨 연구소의 켄 톰슨과 데니스 리치**가 개발한 운영체제. 이후 **C언어로 다시 작성**되어(데니스 리치가 C를 개발) 다른 하드웨어에 **쉽게 옮길 수 있게(이식성)** 되었다.

### (2) 유닉스의 특징
| 특징 | 설명 |
|---|---|
| **C언어로 구현** | 90% 이상 C로 작성 → **이식성 우수** |
| **대화식** | 사용자와 쉘을 통해 명령을 주고받음 |
| **다중 작업(멀티태스킹)** | 여러 프로그램 동시 실행 |
| **다중 사용자(멀티유저)** | 여러 사용자가 동시에 사용 |
| **계층적 트리 구조 파일 시스템** | 루트(`/`)부터 디렉터리가 나뭇가지처럼 분기 → 통합적 파일 관리 |
| **모듈화된 시스템 프로그램** | 커널 + 유틸리티 구조 |

```text
 /
 ├─ bin  ├─ etc  ├─ home ─ user ─ a.txt  └─ usr
```
### (3) 계보
유닉스 → BSD, System V, **리눅스**(유닉스 계열, 오픈 소스), macOS 등.

## 3. 문제 풀이
| 단서 | 유닉스 |
|---|---|

| **C언어로 90% 이상** 구현, 다른 하드웨어로 **이식** 용이 | ✅ |
| **계층적 트리 구조**의 통합 파일 관리 | ✅ |
