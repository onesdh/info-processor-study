# 문제 03 — UML 패키지 다이어그램

## 문제

판매 관련 폴더 모양 요소와 의존 관계를 묶어 보여주는 UML 다이어그램의 이름을 쓰시오.

## 핵심 개념

패키지 다이어그램은 모델 요소를 패키지 단위로 그룹화하고 패키지 간 의존을 표시한다.

## 풀이

폴더 모양의 패키지 기호와 점선 의존 관계, import 표기가 단서다.

## 오답 분석

클래스 다이어그램은 클래스 속성과 관계, 컴포넌트 다이어그램은 구현 단위를 나타낸다.

## 암기 포인트

폴더형 모델 묶음은 패키지 다이어그램.
