# 문제 02

## 문제

목적에 따른 디자인 패턴의 유형에는 생성, 구조, (  ) 이/가 있다. 괄호 (   ) 안에 알맞는 유형을 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

행위

디자인 패턴

목적 : 생성 / 구조 / 행위

범위 : 클래스 / 객체

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
디자인 패턴의 **목적에 따른 3가지 유형**(생성, 구조, ?) 중 빈칸을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) GoF 디자인 패턴 분류 — 두 가지 축
| 축 | 구분 |
|---|---|
| **목적(Purpose)** | **생성**, **구조**, **행위** |
| 범위(Scope) | **클래스** (상속으로 해결), **객체** (객체 합성으로 해결) |

### (2) 목적별 분류와 패턴
| 목적 | 관심사 | 대표 패턴 |
|---|---|---|
| **생성(Creational)** | 객체를 **어떻게 만들까** | Singleton, Factory Method, Abstract Factory, Builder, Prototype |
| **구조(Structural)** | 클래스·객체를 **어떻게 조합할까** | Adapter, Bridge, Composite, Decorator, Facade, Flyweight, Proxy |
| **행위(Behavioral)** | 객체·클래스 간 **상호작용·책임 분배** | Observer, Strategy, Command, Iterator, Template Method, State, Visitor, Mediator, Memento, Chain of Responsibility, Interpreter |

## 3. 문제 풀이
| 단서 | 정답 |
|---|---|
| 생성, 구조, ( ) | **행위** |

> **정답: 행위 (Behavioral)**
