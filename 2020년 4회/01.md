# 문제 01

## 문제

현재 IPv4의 확장형으로 IPv4가 가지고 있는 주소 고갈, 보안성, 이동성 지원 등의 문제점을 해결하기 위해서 개발된 128비트 주소체계를 갖는 차세대 인터넷 프로토콜은 무엇인가?

<summary><strong>정답 보기</strong></summary>

IPv6

</details>

## 1. 문제에서 묻는 것
"IPv4의 **주소 고갈·보안성·이동성** 문제를 해결, **128비트** 주소체계의 **차세대 인터넷 프로토콜**" → 이름을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) IPv4의 한계
| 문제 | 설명 |
|---|---|
| **주소 고갈** | 32비트 → 약 43억 개뿐, 인터넷 기기 폭증으로 **부족** |
| 보안성 | 암호화·인증 기능이 기본이 아님(IPsec는 선택 사항) |
| 이동성 | 이동 단말 지원이 불편 |

### (2) IPv6
| 항목 | IPv4 | **IPv6** |
|---|---|---|
| 주소 길이 | 32비트 | **128비트** |
| 표기 | 10진수 4덩어리 `192.168.0.1` | **16진수 8덩어리** `2001:0db8:85a3::8a2e:0370:7334` |
| 주소 수 | 약 43억 | **약 3.4×10³⁸** (사실상 무한) |
| 보안 | 선택(IPsec) | **IPsec 기본 포함** |
| 헤더 | 가변·복잡 | **단순화**(고정 40바이트) |
| 자동 설정 | DHCP 필요 | **자동 주소 설정** 지원 |
| 전송 방식 | 유니캐스트/멀티캐스트/**브로드캐스트** | 유니캐스트/멀티캐스트/**애니캐스트**(브로드캐스트 없음) |

```text
 IPv4: 32비트  → 약 4.3 × 10⁹ 개
 IPv6: 128비트 → 약 3.4 × 10³⁸ 개
```
## 3. 문제 풀이
| 단서 | IPv6 |
|---|---|
| IPv4의 **주소 고갈·보안성·이동성** 문제 해결 | ✅ |
| **128비트** 주소체계 | ✅ |
| **차세대** 인터넷 프로토콜 | ✅ |

> **정답: IPv6**
