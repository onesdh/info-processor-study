# 문제 15

## 문제

점수에 따른 성적 부여가 잘 되었는지 테스트하고자 한다. 아래에 알맞는 테스트 기법은 무엇인가?

| 점수 | 성적 |
|---|---|
| 0 ~ 59 | 가 |
| 60 ~ 69 | 양 |
| 70 ~ 79 | 미 |
| 80 ~ 89 | 우 |
| 90 ~ 100 | 수 |

[테스트 값] : -10점 / 30점 / 65점 / 75점 / 85점 / 95점 / 110점

<details>
<summary><strong>정답 보기</strong></summary>

동등분할 테스트

동등분할 테스트는 입력 데이터의 영역을 유사한 도메인별로 유효 값 / 무효 값을 그룹핑하여 대푯값 테스트 케이스를 도출하여 테스트하는 기법 (블랙박스 테스트)

데이터 영역에 가까운 값이 아닌 영역 내에 있는 일반 값들로 테스트한다.

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

동등분할은 같은 처리 결과를 낼 입력값들을 유효 또는 무효 동등 클래스로 나누고 대표값을 시험한다.

## 풀이

점수와 등급 구간에 따라 대표 점수를 뽑아 각 영역의 처리 결과를 확인한다.

## 오답 분석

경계값 분석은 구간의 경계와 바로 앞뒤 값을 중심으로 시험한다. 제시된 값은 각 영역 대표값을 구성한다.

## 암기 포인트

동등한 입력 구간별 대표값 시험.

</details>
