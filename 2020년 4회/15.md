# 문제 15

## 문제

점수에 따른 성적 부여가 잘 되었는지 테스트하고자 한다. 아래에 알맞는 테스트 기법은 무엇인가?

| 점수 | 성적 |
|---|---|
| 0 ~ 59 | 가 |
| 60 ~ 69 | 양 |
| 70 ~ 79 | 미 |
| 80 ~ 89 | 우 |
| 90 ~ 100 | 수 |

[테스트 값] : -10점 / 30점 / 65점 / 75점 / 85점 / 95점 / 110점

<details>
<summary><strong>정답 보기</strong></summary>

동등분할 테스트

동등분할 테스트는 입력 데이터의 영역을 유사한 도메인별로 유효 값 / 무효 값을 그룹핑하여 대푯값 테스트 케이스를 도출하여 테스트하는 기법 (블랙박스 테스트)

데이터 영역에 가까운 값이 아닌 영역 내에 있는 일반 값들로 테스트한다.

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
점수 구간별 성적 부여를 테스트하는데, 테스트 값이 **각 구간의 중간값(대표값)** 이다 → 어떤 **블랙박스 테스트 기법**인지 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 동치(동등) 분할 vs 경계값 분석
| 기법 | 선택하는 테스트 값 |
|---|---|
| **동등(동치) 분할** | 각 **영역(구간) 안의 일반적인 대표값** |
| 경계값 분석 | 구간의 **경계 및 그 양옆**(59, 60, 61 등) |

### (2) 구간 정리
| 점수 | 성적 | 선택된 테스트 값 |
|---|---|---|
| 0 ~ 59 | 가 | **30** |
| 60 ~ 69 | 양 | **65** |
| 70 ~ 79 | 미 | **75** |
| 80 ~ 89 | 우 | **85** |
| 90 ~ 100 | 수 | **95** |
| (무효) 0 미만 | – | **-10** |
| (무효) 100 초과 | – | **110** |

```text
 -10 | 0 ─ 30 ─ 59 | 60 ─ 65 ─ 69 | 70 ─ 75 ─ 79 | 80 ─ 85 ─ 89 | 90 ─ 95 ─ 100 | 110
무효영역  가(대표30)     양(대표65)      미(대표75)      우(대표85)       수(대표95)    무효영역
```
- 각 **유효 구간의 한가운데 값**과 **무효 구간의 대표값**(-10, 110)을 선택했다.
- **경계값(59, 60, 69, 70…)** 은 사용하지 않았다.

## 3. 문제 풀이
| 단서 | 동등 분할 |
|---|---|
| 입력 영역을 **유효값/무효값 그룹**으로 나눔 | ✅ |
| 각 구간의 **대표값**(영역 내 일반 값)으로 테스트 | ✅ |
| 영역의 경계 근처가 아닌 **중간 값**을 선택 | ✅ |

> **정답: 동등(동치) 분할 테스트 (Equivalence Partitioning)**

</details>
