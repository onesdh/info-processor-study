# 문제 16

## 문제

다음 조건을 만족하면서 학과별로 튜플 수가 얼마인지 구하는 SQL문을 작성하시오.

- 대소문자를 구분하지 않는다.

- WHERE 구문을 사용하지 않는다.

- GROUP BY 를 사용한다.

- 세미콜론(;)은 생략 가능하다.

- 별칭(AS)을 사용해야 한다. (별칭 사용 시 별칭은 작은 따옴표를 써야 함)

- 집계 함수를 사용해야 한다.

[학생]

| 학과 | 학생 |
|---|---|
| 전기 | 이순신 |
| 컴퓨터 | 안중근 |
| 컴퓨터 | 윤봉길 |
| 전자 | 이봉창 |
| 전자 | 강우규 |

[결과]

| 학과 | 학과별튜플수 |
|---|---|
| 전기 | 1 |
| 컴퓨터 | 2 |
| 전자 | 2 |

<details>
<summary><strong>정답 보기</strong></summary>

SELECT 학과, COUNT(학과) AS 학과별튜플수 FROM 학생 GROUP BY 학과;

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**GROUP BY + 집계 함수 + 별칭**으로 "학과별 튜플 수"를 구하는 SQL을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) GROUP BY
같은 값을 가진 행끼리 **그룹**으로 묶어 **그룹별로 집계**한다.
```text
 전기   : 이순신                   → 1행
 컴퓨터 : 안중근, 윤봉길            → 2행
 전자   : 이봉창, 강우규            → 2행
```
### (2) 집계 함수
`COUNT(열)` : 그룹별 **개수**를 센다.

### (3) 별칭(AS)
결과 열의 **이름을 지정**한다. 문제 조건대로 **작은따옴표**를 사용한다.
```sql
COUNT(학과) AS '학과별튜플수'
```
### (4) 조건 점검
| 조건 | 충족 |
|---|---|
| WHERE 미사용 | ✅ |
| **GROUP BY** 사용 | ✅ |
| **집계 함수**(COUNT) 사용 | ✅ |
| **별칭(AS)** 사용, 작은따옴표 | ✅ |

## 3. 풀이
```sql
SELECT 학과, COUNT(학과) AS '학과별튜플수'
FROM 학생
GROUP BY 학과;
```
**결과**
| 학과 | 학과별튜플수 |
|---|---:|
| 전기 | 1 |
| 컴퓨터 | 2 |
| 전자 | 2 |

> **정답: `SELECT 학과, COUNT(학과) AS '학과별튜플수' FROM 학생 GROUP BY 학과;`**

## 4. 암기 포인트
- SELECT에 쓰는 일반 열은 **GROUP BY에 있는 열**이어야 한다.
- `COUNT(*)`을 써도 결과는 같다.

</details>
