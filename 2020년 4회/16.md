# 문제 16

## 문제

다음 조건을 만족하면서 학과별로 튜플 수가 얼마인지 구하는 SQL문을 작성하시오.

- 대소문자를 구분하지 않는다.

- WHERE 구문을 사용하지 않는다.

- GROUP BY 를 사용한다.

- 세미콜론(;)은 생략 가능하다.

- 별칭(AS)을 사용해야 한다. (별칭 사용 시 별칭은 작은 따옴표를 써야 함)

- 집계 함수를 사용해야 한다.

[학생]

| 학과 | 학생 |
|---|---|
| 전기 | 이순신 |
| 컴퓨터 | 안중근 |
| 컴퓨터 | 윤봉길 |
| 전자 | 이봉창 |
| 전자 | 강우규 |

[결과]

| 학과 | 학과별튜플수 |
|---|---|
| 전기 | 1 |
| 컴퓨터 | 2 |
| 전자 | 2 |

<details>
<summary><strong>정답 보기</strong></summary>

SELECT 학과, COUNT(학과) AS 학과별튜플수 FROM 학생 GROUP BY 학과;

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

GROUP BY는 같은 학과 값을 가진 행을 그룹화하고 COUNT는 각 그룹의 행 수를 계산한다.

## 풀이

전기 1명, 컴퓨터 2명, 전자 2명이므로 학과별 COUNT 결과를 반환한다.

## 오답 분석

WHERE는 그룹화 전 행을 필터링한다. 그룹 집계 조건은 HAVING을 사용하지만 이번 문항에는 필요 없다.

## 암기 포인트

그룹별 행 수는 GROUP BY와 COUNT.

</details>
