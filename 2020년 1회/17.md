# 문제 17

## 문제

비정규화(De-Normalization)의 개념을 쓰시오

<details>
<summary><strong>정답 보기</strong></summary>

정규화된 엔티티, 속성, 관계에 대해 성능 향상과 개발 운영의 단순화를 위해 중복, 통합, 분리 등을 수행하는 데이터모델링 기법

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**비정규화(De-Normalization)** 의 개념을 서술하는 문제다. (2021년 1회 8번, 2024년 2회 2번과 같은 개념)

## 2. 먼저 알아야 할 개념
### (1) 정규화 vs 비정규화
| 구분 | 정규화 | **비정규화(반정규화)** |
|---|---|---|
| 목적 | **중복 제거**, 이상 현상 방지 | **조회 성능 향상**, 개발·운영 단순화 |
| 방법 | 테이블을 **분리** | 테이블 **통합·분할**, **중복 추가** |
| 장점 | 데이터 무결성↑ | **JOIN 감소로 조회가 빠름** |
| 단점 | JOIN 증가로 조회가 느릴 수 있음 | **무결성 저하**, 중복 관리 부담 |

```text
 정규화:    주문 + 고객(분리)           → 조회 시 JOIN 필요
 비정규화:  주문(고객명 중복 저장)       → JOIN 없이 빠른 조회, 대신 고객명 변경 시 여러 곳 수정
```
### (2) 비정규화 기법
테이블 통합, 테이블 분할(수직/수평), 중복 테이블 추가, 중복 속성 추가.

## 3. 서술 답안
> **비정규화: 정규화된 엔티티·속성·관계에 대해 성능 향상과 개발·운영의 단순화를 위해 중복, 통합, 분리 등을 수행하는 데이터 모델링 기법.**
