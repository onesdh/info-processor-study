# 문제 16

## 문제

LoC(Line of Code)가 30,000라인이고, 개발자가 5명이며, 개발자가 월평균 300라인을 개발한다. 이때 프로젝트 개발 기간과 계산식을 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

프로젝트 개발 기간 : 20개월

계산식 : (30,000라인 / 300라인) / 5명 = 20개월

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
LoC(코드 라인 수), 개발자 수, 1인당 월 생산량이 주어졌을 때 **프로젝트 개발 기간**과 **계산식**을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) LoC 기반 개발 기간 산정
| 용어 | 의미 |
|---|---|
| **LoC (Lines of Code)** | 전체 코드 **라인 수**(규모) |
| 생산성 | 개발자 **1인당 월평균 개발 라인 수** |
| 인월(M/M) | 1명이 1개월 일하는 노력 단위 |

```text
 노력(인월 M/M) = LoC ÷ (1인당 월 생산 라인 수)
 개발 기간(개월) = 노력(M/M) ÷ 투입 인원
```
## 3. 계산
| 단계 | 식 | 값 |
|---|---|---:|
| 총 노력 (M/M) | 30,000 ÷ 300 | **100 인월** |
| 개발 기간 | 100 ÷ 5명 | **20 개월** |

**한 줄로**: `(30,000 / 300) / 5 = 20`

> **정답: 프로젝트 개발 기간 = 20개월 / 계산식 = (30,000라인 ÷ 300라인) ÷ 5명**

## 4. 암기 포인트
- 개발 기간 = (LoC / 생산성) / 인원. (인원이 늘면 기간이 줄어든다는 단순 모델)
