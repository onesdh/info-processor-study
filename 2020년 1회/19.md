# 문제 19

## 문제

단위 시간당 트랜잭션 수, 입력 후 첫 응답이 시작될 때까지의 시간, 요청 입력부터 결과 출력 완료까지의 시간을 순서대로 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

처리량; 응답 시간; 경과 시간

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

처리량은 단위 시간당 처리 건수다. 응답 시간은 요청 후 응답이 시작될 때까지, 경과 시간은 요청부터 완료까지 걸리는 전체 시간이다.

## 풀이

웹 처리량은 시간당 페이지 수로 표현할 수 있다.

## 오답 분석

응답 개시 시간과 전체 처리 완료 시간을 구분한다.

## 암기 포인트

처리량·응답 시간·경과 시간.

</details>
