# 문제 02

## 문제

데이터 마이닝의 개념에 관해서 서술하시오.

<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**데이터 마이닝(Data Mining)** 의 개념을 서술하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 데이터 마이닝
**대규모로 저장된 데이터 속에서 숨어 있는 유용한 패턴·규칙·관계를 체계적·자동적으로 찾아내는 기술**이다. 광산(mine)에서 **금을 캐듯 데이터에서 지식을 캐낸다**고 해서 붙은 이름이다.

```text
 방대한 데이터(구매 기록) ─ 통계·머신러닝 ─▶ "기저귀를 사는 고객은 맥주도 함께 산다" (연관 규칙)
```
### (2) 주요 기법
| 기법 | 설명 | 예 |
|---|---|---|
| **연관 규칙** | 항목 간 **함께 발생하는 패턴** | 장바구니 분석 |
| **분류(Classification)** | 데이터를 **미리 정한 범주**로 나눔 | 스팸/정상 메일 |
| **군집(Clustering)** | **비슷한 것끼리 묶음**(범주 미정) | 고객 세분화 |
| **예측(회귀)** | 값을 예측 | 매출 예측 |
| 이상 탐지 | 평소와 **다른 데이터** 탐지 | 카드 부정 사용 |

### (3) 관련 개념
**빅데이터**, **데이터 웨어하우스**(분석용 통합 저장소), **OLAP**.

## 3. 서술 답안
> **데이터 마이닝: 대규모로 저장된 데이터 안에서 체계적이고 자동적으로 통계적 규칙이나 패턴을 찾아내는 기술.**
