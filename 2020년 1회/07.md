# 문제 07

## 문제

스케줄링 방식에서 HRN(Highest Response ratio Next) 우선순위 계산식을 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

(대기 시간 + 서비스 시간) / 서비스 시간

HRN 스케줄링 기법은 SJF 스케줄링 기법의 약점인 긴 작업과 짧은 작업 사이의 불평등을 보완하기 위한 방법으로, 위에 우선순위 계산식은 시스템 응답시간이 커질수록 우선순위가 높아진다는 의미 입니다.

위의 HRN를 비롯하여, SJF와 FIFO, 우선순위, 기반부는 비선점형 프로세스 스케줄링에 속합니다.

SJF(Shortest Job First) : 프로세스의 실행시간이 가장 적은 프로세스를 먼저 실행시키는 기법입니다.

FIFO(First In First Out)는 각 페이지가 주기억장치에 적재될 때마다 가장 먼저 들어왔던 페이지가 가장 오래 있었기 때문에 해당 페이지를 교체하는 기법입니다.

&nbsp;우선순위 : 미리 정의한 알고리즘대로 프로세스의 우선순위를 결정하는 방식기한부 : 프로세스마다 정해진 시간할당량만큼만 실행되도록 지정하는 방식

## 1. 문제에서 묻는 것
**HRN 스케줄링의 우선순위 계산식**을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) SJF의 약점과 HRN
- **SJF(Shortest Job First)** 는 **짧은 작업을 우선** 처리해 평균 대기시간이 짧지만, **긴 작업은 계속 뒤로 밀려** 오래 기다리는 **기아(Starvation) 현상**이 생긴다.
- **HRN(Highest Response ratio Next)** 은 이를 보완해 **대기 시간이 길수록 우선순위가 높아지게** 한다.

### (2) 우선순위 계산식
```text
 우선순위 = ( 대기 시간 + 서비스 시간 ) / 서비스 시간
```
| 요소 | 의미 |
|---|---|
| 대기 시간 | 준비 큐에서 기다린 시간 |
| 서비스 시간 | 프로세스의 실행 시간(CPU 사용 시간) |

- **값이 클수록 먼저 실행**
- 대기 시간이 길어질수록 분자가 커져 **우선순위가 올라감** → 긴 작업도 결국 실행(기아 방지)
- 서비스 시간이 **짧을수록** 값이 커져 짧은 작업에 유리(SJF의 장점 유지)

### (3) 계산 예
| 프로세스 | 대기 | 서비스 | 우선순위 |
|---|---:|---:|---:|
| P1 | 10 | 5 | (10+5)/5 = **3.0** |
| P2 | 2 | 1 | (2+1)/1 = **3.0** |
| P3 | 20 | 10 | (20+10)/10 = **3.0** |

### (4) 스케줄링 분류
| 선점 | 비선점 |
|---|---|
| RR, SRT, 다단계 큐 등 | FCFS, SJF, **HRN**, 우선순위 |

## 3. 정답
> **HRN 우선순위 = (대기 시간 + 서비스 시간) / 서비스 시간**
