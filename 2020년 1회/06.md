# 문제 06

## 문제

STUDENT 테이블에서 컴퓨터과 학생 50명, 인터넷과 학생 100명, 사무자동화과 학생 50명의 정보가 저장되어 있을 때, 다음 SQL문의 실행 결과에 따른 튜플의 수는? (단, DEPT 칼럼은 학과명이다.)

1) SELECT DERP FROM STUDENT;

2) SELECT DISTINCT DEPT FROM STUDENT;

3) SELECT COUNT(DISTINCT DEPT) FROM STUDENT WHERE DEPT = '컴퓨터과';

<details>
<summary><strong>정답 보기</strong></summary>

1. 200

2. 3

3. 1

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
세 SQL의 **결과 튜플(행) 수**를 구하는 문제다. `SELECT`, `DISTINCT`, `COUNT(DISTINCT ...)`의 차이를 묻는다. (2022년 3회 12번과 같은 문제)

## 2. 먼저 알아야 할 개념
### (1) 데이터 상황
| DEPT | 학생 수 |
|---|---:|
| 컴퓨터과 | 50 |
| 인터넷과 | 100 |
| 사무자동화과 | 50 |
| **합계** | **200행** |

### (2) 핵심 문법
| 문법 | 의미 |
|---|---|
| `SELECT 열` | 모든 행의 해당 열 출력 (**중복 허용**) |
| `SELECT DISTINCT 열` | **중복 제거** |
| `COUNT(DISTINCT 열)` | 서로 다른 값의 **개수**를 구해 **1행**으로 반환 |
| `WHERE` | 먼저 **행을 걸러냄** |

## 3. 풀이
**1)** `SELECT DEPT FROM STUDENT;` (문제의 `DERP`는 `DEPT`의 오타)
→ 조건·중복 제거 없음 → **200행**

**2)** `SELECT DISTINCT DEPT FROM STUDENT;`
→ 서로 다른 학과 3개(컴퓨터과, 인터넷과, 사무자동화과) → **3행**

**3)** `SELECT COUNT(DISTINCT DEPT) FROM STUDENT WHERE DEPT = '컴퓨터과';`
1. `WHERE`로 컴퓨터과 50행만 남김
2. 그 50행의 DEPT는 모두 `'컴퓨터과'` → 서로 다른 값 **1개**
3. COUNT는 집계 함수라 **결과 1행**(값 1)
→ **1행**

> **정답: 1) 200 2) 3 3) 1**

## 4. 암기 포인트
- 집계 함수만 쓴 SELECT는 **1행만 반환**.

</details>
