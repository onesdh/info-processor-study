# 문제 06 — SQL 튜플 수와 DISTINCT

## 문제

컴퓨터과 50명, 인터넷과 100명, 사무자동화과 50명이 있을 때 DEPT 조회, DISTINCT DEPT 조회, 컴퓨터과 조건의 COUNT(DISTINCT DEPT) 결과를 각각 구하시오.

<details>
<summary><strong>정답 보기</strong></summary>

200; 3; 1

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

SELECT 열은 각 행의 값을 반환하고 DISTINCT는 중복 값을 제거한다. COUNT(DISTINCT 열)은 조건을 만족하는 서로 다른 값의 수를 센다.

## 풀이

전체 행은 50+100+50=200개, 서로 다른 학과는 3개, 컴퓨터과 조건에서 서로 다른 학과 값은 1개다.

## 오답 분석

전체 행 수와 고유값 수를 구분한다. WHERE가 컴퓨터과로 제한한 뒤 DISTINCT를 적용한다.

## 암기 포인트

전체 200행, 고유 학과 3개, 조건 고유 학과 1개.
