# 문제 06

## 문제

STUDENT 테이블에서 컴퓨터과 학생 50명, 인터넷과 학생 100명, 사무자동화과 학생 50명의 정보가 저장되어 있을 때, 다음 SQL문의 실행 결과에 따른 튜플의 수는? (단, DEPT 칼럼은 학과명이다.)

1) SELECT DERP FROM STUDENT;

2) SELECT DISTINCT DEPT FROM STUDENT;

3) SELECT COUNT(DISTINCT DEPT) FROM STUDENT WHERE DEPT = '컴퓨터과';

<details>
<summary><strong>정답 보기</strong></summary>

1. 200

2. 3

3. 1

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

SELECT 열은 각 행의 값을 반환하고 DISTINCT는 중복 값을 제거한다. COUNT(DISTINCT 열)은 조건을 만족하는 서로 다른 값의 수를 센다.

## 풀이

전체 행은 50+100+50=200개, 서로 다른 학과는 3개, 컴퓨터과 조건에서 서로 다른 학과 값은 1개다.

## 오답 분석

전체 행 수와 고유값 수를 구분한다. WHERE가 컴퓨터과로 제한한 뒤 DISTINCT를 적용한다.

## 암기 포인트

전체 200행, 고유 학과 3개, 조건 고유 학과 1개.

</details>
