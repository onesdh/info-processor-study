# 문제 12

## 문제

다음은 C언어 소스 코드이다. 출력 결과를 쓰시오.

```
 #include <stdio.h>
 void main(){
 	int i,j;
    int temp;
    int a[5] = {75,95,85,100,50};

    for(i=0; i<4; i++){
    	for(j=0; j<4-i; j++){
        	if(a[j] > a[j+1]){
            	temp=a[j];
                a[j] = a[j+1];
                a[j+1] = temp;
             }
           }
        }

       	for(i=0; i<5; i++){
        	printf("%d", a[i]);
        }
  }
```

<details>
<summary><strong>정답 보기</strong></summary>

50758595100

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

인접한 두 원소를 비교하고 앞 값이 크면 교환해 배열을 오름차순 정렬한다.

## 풀이

정렬 결과는 50,75,85,95,100이며 공백 없이 출력하면 50758595100이다.

## 오답 분석

원소 수가 다섯 개이고 각 값을 구분자 없이 붙여 출력하므로 100이 마지막 세 자리로 이어진다.

## 암기 포인트

정렬 후 50·75·85·95·100.
