# 문제 12

## 문제

다음은 C언어 소스 코드이다. 출력 결과를 쓰시오.

```
 #include <stdio.h>
 void main(){
 	int i,j;
    int temp;
    int a[5] = {75,95,85,100,50};

    for(i=0; i<4; i++){
    	for(j=0; j<4-i; j++){
        	if(a[j] > a[j+1]){
            	temp=a[j];
                a[j] = a[j+1];
                a[j+1] = temp;
             }
           }
        }

       	for(i=0; i<5; i++){
        	printf("%d", a[i]);
        }
  }
```

## 1. 문제에서 묻는 것
**버블 정렬(Bubble Sort)** 후 배열을 출력한 결과를 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 버블 정렬
**이웃한 두 원소를 비교해 순서가 틀리면 교환**하는 것을 반복한다. 한 바퀴 돌 때마다 **가장 큰 값이 맨 뒤로** 이동한다(거품처럼).
```c
for (i = 0; i < 4; i++)
    for (j = 0; j < 4 - i; j++)           // 이미 뒤로 간 i개는 비교 제외
        if (a[j] > a[j+1]) swap(a[j], a[j+1]);   // 앞이 크면 교환 → 오름차순
```
### (2) 출력
`printf("%d", a[i])`는 **공백이 없어** 숫자가 붙어서 출력된다.

## 3. 실행 과정 (`a = {75, 95, 85, 100, 50}`)
**1회전 (i=0, j=0~3)**
| j | 비교 | 교환 후 배열 |
|---:|---|---|
| 0 | 75 > 95? 아니오 | 75 95 85 100 50 |
| 1 | 95 > 85? 예 | 75 **85 95** 100 50 |
| 2 | 95 > 100? 아니오 | 75 85 95 100 50 |
| 3 | 100 > 50? 예 | 75 85 95 **50 100** |

**2회전 (i=1, j=0~2)**
| j | 비교 | 배열 |
|---:|---|---|
| 0 | 75 > 85? 아니오 | 75 85 95 50 100 |
| 1 | 85 > 95? 아니오 | 75 85 95 50 100 |
| 2 | 95 > 50? 예 | 75 85 **50 95** 100 |

**3회전 (i=2, j=0~1)**
| j | 비교 | 배열 |
|---:|---|---|
| 0 | 75 > 85? 아니오 | 75 85 50 95 100 |
| 1 | 85 > 50? 예 | 75 **50 85** 95 100 |

**4회전 (i=3, j=0)**: 75 > 50? 예 → **50 75** 85 95 100

최종 배열: `50 75 85 95 100` → 공백 없이 출력 → **50758595100**

> **정답: `50758595100`**

## 4. 암기 포인트
- 버블 정렬 후 **오름차순**. 출력에 공백이 없어 `50`+`75`+`85`+`95`+`100`이 이어진다.
