# 문제 13 — Java 배열 출력

## 문제

배열 {0,1,2,3}의 원소를 공백과 함께 순서대로 출력하는 프로그램의 결과를 쓰시오.

## 정답

0 1 2 3

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

for문은 인덱스 0부터 3까지 각 원소를 출력한다.

## 풀이

배열의 저장 순서대로 0,1,2,3이 표시된다.

## 오답 분석

마지막에도 코드에서 공백을 붙이지만 화면상 후행 공백은 답 표기에서 생략할 수 있다.

## 암기 포인트

배열 순서 그대로 0부터 3.
