# 문제 13

## 문제

다음은 자바 소스코드이다. 출력 결과를 쓰시오.

```
public class good {
	public static void main(String[] args){
    	int i;
        int[] a = {0,1,2,3};
        for(i=0; i<4; i++){
        	System.out.print(a[i] + " ");
        }
     }
 }
```

</details>

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**배열의 모든 원소를 `for`로 출력**하는 간단한 Java 코드의 출력 형식을 묻는 문제다. (공백 포함 출력에 주의)

## 2. 먼저 알아야 할 개념
### (1) 배열 순회
```java
int[] a = {0, 1, 2, 3};
for (i = 0; i < 4; i++) System.out.print(a[i] + " ");   // 값 + 공백 출력
```
### (2) `print` vs `println`
`print`는 **줄바꿈 없이** 이어서 출력한다. `a[i] + " "`는 정수와 문자열이 만나 **문자열 연결**이 되어 `"0 "`, `"1 "` …

## 3. 실행 과정
| i | a[i] | 출력(누적) |
|---:|---:|---|
| 0 | 0 | `0 ` |
| 1 | 1 | `0 1 ` |
| 2 | 2 | `0 1 2 ` |
| 3 | 3 | `0 1 2 3 ` |

> **정답: `0 1 2 3`** (마지막에 공백 하나가 더 붙는다)

## 4. 암기 포인트
- `print(숫자 + " ")`는 숫자 뒤에 **공백**이 붙는다.
