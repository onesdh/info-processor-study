# 문제 14

## 문제

다음은 자바 소스코드이다. 출력 결과를 쓰시오.

```
public class good {
	public static void main(String[] args){
    	int i = 3;
        int k = 1;
        swich (i) {
        case 0;
        case 1;
        case 2;
        case 3 k = 0;
        case 4 k += 3;
        case 5 k -= 10;
        default: k--;
        }
        system.out.print(k);
     }
}

```

<details>
<summary><strong>정답 보기</strong></summary>

-8

switch case문에 break가 없는 점을 주의하셔야 합니다.

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

switch에서 break가 없으면 처음 일치한 라벨부터 이후 문장들이 순서대로 실행된다.

## 풀이

k=0에서 시작해 3, -7, -8 순으로 변한다.

## 오답 분석

case 3만 실행된다고 생각하면 틀린다. default는 앞 case에서 빠져나오지 않았을 때 실행 흐름 끝에서 수행된다.

## 암기 포인트

break가 없으면 아래 case로 계속 진행.

</details>
