# 문제 14

## 문제

다음은 자바 소스코드이다. 출력 결과를 쓰시오.

```
public class good {
	public static void main(String[] args){
    	int i = 3;
        int k = 1;
        swich (i) {
        case 0;
        case 1;
        case 2;
        case 3 k = 0;
        case 4 k += 3;
        case 5 k -= 10;
        default: k--;
        }
        system.out.print(k);
     }
}

```

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
`switch` 문의 **fall-through(break 없는 연속 실행)** 를 따라가며 `k`의 최종 값을 구하는 문제다. (2022년 2회 7번과 같은 문제)

## 2. 먼저 알아야 할 개념
### (1) switch와 fall-through
- `switch(i)`는 **일치하는 case로 점프**한다.
- **`break`를 만나기 전까지 아래 case를 연속 실행**한다.
- 이 코드는 **break가 하나도 없다.**

```java
switch (3) {
    case 0: case 1: case 2:     // 건너뜀
    case 3: k = 0;               // ← 여기서 시작
    case 4: k += 3;
    case 5: k -= 10;
    default: k--;
}
```
## 3. 실행 과정 (`i = 3`, 초기 `k = 1`)
| 실행 순서 | 문장 | k |
|---:|---|---:|
| (시작) | `k = 1` | 1 |
| 1 | `case 3: k = 0;` | **0** |
| 2 | `case 4: k += 3;` | 3 |
| 3 | `case 5: k -= 10;` | -7 |
| 4 | `default: k--;` | **-8** |

`system.out.print(k)` → **-8**

> **정답: `-8`**

## 4. 암기 포인트
- 점프한 case부터 끝까지 **모두 실행**(break 없음). `k = 0`은 이전 값을 덮어쓴다.
