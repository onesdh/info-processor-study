# 문제 10

## 문제

RFC 1321로 지정되어 있으며, 주로 프로그램이나 파일이 원본 그대로 인지를 확인하는 무결성 검사 등에 사용된다. 1991년 로널드 라이베스트가 예전에 쓰이던 MD4를 대체하기 위해 고안된 128비트 암호화 해시 함수는 무엇인가?

## 1. 문제에서 묻는 것
"**RFC 1321**, 파일 **무결성 검사**, **1991년 로널드 라이베스트**가 **MD4 대체**, **128비트** 암호화 해시 함수" → 이름을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 해시 함수
임의 길이의 데이터를 **고정 길이 값(해시값)** 으로 바꾸는 **단방향 함수**.

### (2) MD5 (Message-Digest algorithm 5)
| 항목 | 내용 |
|---|---|
| 출력 | **128비트** 해시값 |
| 개발 | **로널드 라이베스트**(RSA의 'R'), 1991년, **MD4를 대체** |
| 표준 | **RFC 1321** |
| 용도 | 파일이 **원본 그대로인지(무결성)** 확인 |
| 현황 | **충돌 취약점**이 발견되어 보안 용도로는 **권장하지 않음** (→ SHA-256 사용) |

### (3) 해시 알고리즘 비교
| 알고리즘 | 출력 길이 | 상태 |
|---|---|---|
| **MD5** | 128비트 | 취약 |
| SHA-1 | 160비트 | 취약 |
| **SHA-256** | 256비트 | 현재 널리 사용 |

## 3. 문제 풀이
| 단서 | MD5 |
|---|---|
| **RFC 1321**, **로널드 라이베스트**, **MD4 대체** | ✅ |
| **128비트** 해시 함수, 무결성 검사 | ✅ |

> **정답: MD5**
