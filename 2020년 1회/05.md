# 문제 05 — JSON

## 문제

속성-값 쌍으로 구성된 가벼운 데이터 교환 형식으로 AJAX에서 널리 쓰이며 언어 독립적인 형식을 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

JSON (JavaScript Object Notation)

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

JSON은 객체와 배열을 사용해 데이터를 표현하는 텍스트 기반 교환 형식이다.

## 풀이

다양한 프로그래밍 언어에서 파싱·생성이 가능하다.

## 오답 분석

JavaScript 문법에서 유래했지만 JavaScript 전용 데이터 형식은 아니다.

## 암기 포인트

속성-값 데이터 형식 JSON.

</details>
