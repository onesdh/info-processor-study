# 문제 05

## 문제

속성-값(Attribute-value Pair)으로 이루어진 데이터 오프젝트를 전달하기 위해 사용하는 개방형 표준 포멧이다. Ajax(Asynchronous JavaScript and XML)에서 많이 사용되고 XML(eXtensible Markup Language)을 대체하는 주요 데이터 포맷이다. 언어 독립형 데이터 포맷으로 다양한 데이터 프로그래밍 언어에서 사용하고 있는 기술은 무엇인가?

## 1. 문제에서 묻는 것
"**속성-값 쌍**으로 이루어진 데이터 오브젝트를 전달하는 개방형 표준 포맷, **Ajax**에서 많이 사용, **XML을 대체**, **언어 독립형**" → 이름을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) JSON (JavaScript Object Notation)
**`{ "속성": 값 }` 형태(key-value)** 로 데이터를 표현하는 **가벼운 텍스트 데이터 교환 형식**. 원래 JavaScript 객체 표기에서 출발했지만 **특정 언어에 종속되지 않아** 거의 모든 언어에서 사용한다.
```json
{
  "name": "홍길동",
  "age": 25,
  "skills": ["Java", "Python"]
}
```
### (2) XML과 비교
| 구분 | **JSON** | **XML** |
|---|---|---|
| 형식 | `{ key: value }` | `<태그>값</태그>` |
| 크기 | **가볍다** | 태그가 많아 **무겁다** |
| 가독성 | **읽고 쓰기 쉬움** | 장황 |
| 파싱 | 빠름 | 상대적으로 느림 |
| 용도 | **웹/모바일 API**, **Ajax**의 주류 | 문서·설정·SOAP |

## 3. 문제 풀이
| 단서 | JSON |
|---|---|
| **속성-값(Attribute-value Pair)** 데이터 오브젝트 전달 | ✅ |
| **Ajax**에서 많이 사용, **XML 대체** 주요 포맷 | ✅ |
| **언어 독립형** 데이터 포맷 | ✅ |

> **정답: JSON (JavaScript Object Notation)**
