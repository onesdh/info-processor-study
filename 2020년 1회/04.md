# 문제 04

## 문제

다음이 설명하는 용어는 무엇인지 쓰시오.

W3C(World wide Web Consortium)에서 개발되었고, 웹 브라우저 간 호환이 되지 않는 문제와 SGML(Standard Generalized Markup Language)의 복잡함을 해결하기 위해 개발된 다목적 마크업 언어이다.

<details>
<summary><strong>정답 보기</strong></summary>

XML (eXtensible Markup Language)

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

XML은 사용자가 태그를 정의할 수 있는 구조화 문서 및 데이터 표현 언어다.

## 풀이

확장 가능한 태그와 계층 구조로 데이터를 표현한다.

## 오답 분석

HTML은 미리 정의된 웹 문서 태그 중심이고 XML은 데이터 구조 표현을 강조한다.

## 암기 포인트

확장 가능한 마크업은 XML.
