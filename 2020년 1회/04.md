# 문제 04

## 문제

다음이 설명하는 용어는 무엇인지 쓰시오.

W3C(World wide Web Consortium)에서 개발되었고, 웹 브라우저 간 호환이 되지 않는 문제와 SGML(Standard Generalized Markup Language)의 복잡함을 해결하기 위해 개발된 다목적 마크업 언어이다.

XML (eXtensible Markup Language)

## 1. 문제에서 묻는 것
"**W3C**에서 개발, 웹 브라우저 간 **호환 문제**와 **SGML의 복잡함**을 해결한 **다목적 마크업 언어**" → 이름을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 마크업 언어의 계보
```text
 SGML (복잡·무겁다) ─▶ HTML (웹 표시용, 태그 고정) ─▶ XML (태그를 사용자가 정의, 단순화한 SGML)
```
| 언어 | 특징 |
|---|---|
| **SGML** | 문서 구조를 정의하는 **표준 메타 언어**, **너무 복잡** |
| **HTML** | 웹 페이지 표시용, **정해진 태그**만 사용 |
| **XML** | **eXtensible(확장 가능한)** Markup Language — 사용자가 **태그를 직접 정의**, SGML을 단순화, 데이터 교환용 |

### (2) XML 예
```xml
<학생>
   <이름>홍길동</이름>
   <학년>3</학년>
</학생>
```
- **데이터의 구조와 의미**를 태그로 표현 → 시스템 간 **데이터 교환**에 널리 사용(웹 서비스 SOAP 등)

## 3. 문제 풀이
| 단서 | XML |
|---|---|
| **W3C**가 개발한 **다목적 마크업 언어** | ✅ |
| **SGML의 복잡함** 해결, 브라우저 간 호환 문제 해결 | ✅ |

> **정답: XML (eXtensible Markup Language)**
