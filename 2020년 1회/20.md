# 문제 20

## 문제

다음은 모듈의 관계를 나타낸 다이어그램이다. fan-in  개수가 2 이상인 모듈 명칭을 쓰시오.

![원문 문제 그림 1](source/정보처리기사_2020_1_Q20_01.png)

<details>
<summary><strong>정답 보기</strong></summary>

F,H

모듈에서 화살표가 나가는 경우 팬아웃이고 모듈에서 화살표가 들어오는 경우 팬인이라고 합니다.

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

Fan-in은 해당 모듈을 직접 호출하거나 의존하는 상위 모듈 수다.

## 풀이

그림에서 입력 방향 화살표가 두 개 이상 들어오는 모듈은 F와 H다.

## 오답 분석

Fan-out은 반대로 해당 모듈이 직접 호출하는 하위 모듈 수다.

## 암기 포인트

들어오는 선을 세어 F와 H.

</details>
