# 문제 11

## 문제

다음은 공통 모듈 구현의 개념에 대한 설명이다. 괄호 (    ) 안에 알맞은 용어를 쓰시오.

- 소프트웨어 개발에 있어 기능을 분할하고 추상화하여 성능을 향상시키고 유지보수를 효과적으로 하기 위한 공통 컴포넌트 구현 기법이다.

- 인터페이스 모듈, 데이터베이스 접근 모듈 등 필요한 공통 모듈을 구현한다.

- 모듈 간의 (   1.   ) 은/는 줄이고, (   2 .  ) 은/는 높은 공통 모듈 구현을 권한하고 있다.

## 1. 문제에서 묻는 것
**공통 모듈 구현**에서 "모듈 간의 ( )은 줄이고 ( )은 높이는" 것을 권장 → 결합도와 응집도를 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 공통 모듈
**여러 곳에서 공통으로 쓰는 기능**(인터페이스 모듈, DB 접근 모듈 등)을 **하나의 모듈로 분리·구현**한 것이다. 기능을 **분할·추상화**해 성능을 높이고 유지보수를 쉽게 한다.

### (2) 좋은 모듈 설계의 원칙
| 지표 | 목표 | 이유 |
|---|---|---|
| **결합도(Coupling)** | **낮게** (줄임) | 모듈 간 **의존이 적어야** 한 곳을 고쳐도 다른 곳에 영향이 적음 |
| **응집도(Cohesion)** | **높게** | 한 모듈이 **하나의 목적에 집중**해야 이해·재사용이 쉬움 |

```text
 좋은 설계 = 낮은 결합도 + 높은 응집도    ("모듈은 독립적으로, 내부는 알차게")
```
### (3) 순서
| 결합도(낮을수록 좋음) | 자료 < 스탬프 < 제어 < 외부 < 공통 < 내용 |
|---|---|
| 응집도(높을수록 좋음) | 우연 < 논리 < 시간 < 절차 < 통신 < 순차 < 기능 |

## 3. 문제 풀이
| 칸 | 정답 |
|---|---|
| (1) 줄이는 것 | **결합도** |
| (2) 높이는 것 | **응집도** |

> **정답: 1. 결합도 2. 응집도**
