## 문제

다음은 결합도와 관련된 내용이다. 보기에 알맞는 답을 골라 작성하시오.

(1) 다른 모듈 내부에 있는 변수나 기능을 다른 모듈에서 사용하는 경우의 결합도

(2) 모듈 간의 인터페이스로 배열이나 오브젝트, 자료구조 등이 전달되는 경우의 결합도

(3) 파라미터가 아닌 모듈 밖에 선언되어 있는 전역 변수를 참조하고 전역 변수를 갱신하는 식으로 상호작용하는 경우의 결합도

## 1. 문제에서 묻는 것
설명 3개가 각각 **어떤 결합도**인지 보기에서 고르는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 결합도 = 모듈 사이의 의존 정도 (낮을수록 좋음)
```text
 자료 < 스탬프 < 제어 < 외부 < 공통 < 내용
 (좋음)                          (나쁨)
```
| 유형 | 설명 | 예 |
|---|---|---|
| **자료** | **필요한 값만** 매개변수로 전달 | `sum(a, b)` |
| **스탬프** | **배열·구조체·객체** 같은 자료구조를 통째로 전달 | `print(student)` |
| **제어** | 상대의 **흐름을 제어하는 값(플래그)** 전달 | `run(mode)` |
| 외부 | **외부 형식/프로토콜/장치**를 공유 | 같은 파일 포맷 |
| **공통** | **전역 변수**를 여러 모듈이 읽고 갱신 | `g_count` 공유 |
| **내용** | **다른 모듈 내부 변수·기능을 직접 사용/수정** | 다른 모듈 속으로 점프 |

## 3. 문제 풀이
| 번호 | 설명의 핵심 | 정답 |
|---|---|---|
| (1) | 다른 모듈 **내부**의 변수·기능을 **직접 사용** | ㅁ. **내용 결합도** |
| (2) | 인터페이스로 **배열·오브젝트·자료구조 전달** | ㄴ. **스탬프 결합도** |
| (3) | 파라미터가 아닌 **전역 변수**를 참조·갱신 | ㄹ. **공통 결합도** |

헷갈리기 쉬운 쌍
| 비교 | 구분 |
|---|---|
| 자료 vs 스탬프 | 값 **하나씩**(자료) / **묶음 구조 통째로**(스탬프) |
| 공통 vs 외부 | **전역 변수** 공유(공통) / 외부 **형식·장치** 공유(외부) |

> **정답: (1) ㅁ (2) ㄴ (3) ㄹ**

## 4. 암기 포인트
- 순서 암기: **자 · 스 · 제 · 외 · 공 · 내**.
- "전역 변수" → **공통**, "내부 직접 참조" → **내용**, "자료구조 전달" → **스탬프**.
