# 문제 15

## 문제

문장(Statement) 커버리지 테스트를 수행하려고 한다. 코드를 아래의 제어 흐름도 빈칸에 연결되도록 작성하고 문장 커버리지 순서대로 작성하시오.

```
int Main(int b[], int m, int x) {
    int a = 0;
    while (a < m || b[a] < x) {
        if (b[a] < 0)
            b[a] = -b[a];
        a++;
    }
    return 1;
}
```

## 1. 문제에서 묻는 것
코드를 **제어 흐름도(그림)** 의 각 칸에 연결하고, **문장(구문) 커버리지**를 만족하는 실행 순서를 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 제어 흐름도(Control Flow Graph)
코드를 **노드(실행 단위)와 화살표(흐름)** 로 그린 그림. 사각형은 **일반 문장**, 마름모는 **조건(분기)** 이다.

### (2) 문장(구문, Statement) 커버리지
**모든 문장(노드)이 최소 한 번은 실행**되도록 테스트하는 기준. (분기 커버리지는 모든 **화살표**를 지나야 하므로 더 강한 기준)

### (3) 코드 읽기
```c
int Main(int b[], int m, int x) {
    int a = 0;                              // ① 초기화
    while (a < m || b[a] < x) {             // ② 반복 조건 (마름모)
        if (b[a] < 0)                       // ③ 조건 (마름모)
            b[a] = -b[a];                   // ④ 음수면 양수로
        a++;                                // ⑤ 증가
    }
    return 1;                               // ⑥ 종료
}
```
## 3. 흐름도 해석 (그림)
```text
          ① int a = 0
              │
        ┌──▶ ② while 조건 ──(거짓)──▶ ⑥ return 1
        │      │ (참)
        │   ③ if (b[a] < 0) ──(거짓)──┐
        │      │ (참)                  │
        │   ④ b[a] = -b[a]             │
        │      │                       │
        │   ⑤ a++ ◀────────────────────┘
        └──────┘
```
- 그림에서 노드 2·3은 마름모(조건), 노드 3의 왼쪽 선은 **거짓일 때 ⑤로 건너뛰는 경로**, 노드 5에서 **②로 되돌아가는 반복 경로**가 있다.

| 번호 | 연결할 코드 |
|---|---|
| ① | `int a = 0` |
| ② | `a < m \|\| b[a] < x` |
| ③ | `b[a] < 0` |
| ④ | `b[a] = -b[a];` |
| ⑤ | `a++;` |
| ⑥ | `return 1;` |

## 4. 문장 커버리지 순서
**모든 노드(①~⑥)를 한 번씩 이상 실행**하는 경로 하나를 만든다.

1. `① → ②` : 시작, 조건 확인 (참이라고 가정)
2. `③` : if 조건 참 (b[a] < 0) → **④ 실행** 해야 ④를 커버
3. `④ → ⑤` : 음수를 양수로 바꾸고 a 증가
4. `⑤ → ②` : 반복해서 조건 확인
5. 이번엔 조건 **거짓** → `⑥` 실행

**경로: ① → ② → ③ → ④ → ⑤ → ② → ⑥**

| 순서 | 실행 노드 | 커버한 새 문장 |
|---:|---|---|
| 1 | ① | `int a = 0` |
| 2 | ② | while 조건 |
| 3 | ③ | if 조건 |
| 4 | ④ | `b[a] = -b[a]` |
| 5 | ⑤ | `a++` |
| 6 | ② | (반복 확인) |
| 7 | ⑥ | `return 1` |

문제에서 `1 → 2 →` 까지 주어졌으므로 이어서 **⑦ = ③ → ④ → ⑤ → ② → ⑥**.

> **정답**
> (1) int a = 0 (2) a < m || b[a] < x (3) b[a] < 0 (4) b[a] = -b[a]; (5) a++; (6) return 1;
> **(7) ③ → ④ → ⑤ → ② → ⑥**

## 5. 암기 포인트
- 문장 커버리지는 **모든 문장을 한 번씩** 실행하는 경로면 충분하다. 그래서 `b[a] < 0`이 **참인 경로**가 필요하다(④를 실행하려면).
- 같은 테스트로 분기(결정) 커버리지를 만족하려면 ③이 거짓인 경로도 추가로 필요하다.
