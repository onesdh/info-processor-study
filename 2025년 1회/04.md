# 문제 04

## 문제

다음은 악성코드 관련된 문제이다. 아래 내용을 확인하여 보기에 골라 작성하시오.

사용자가 원치 않는 소프트웨어를 구매하도록 조작하기 위해 사회 공학을 사용하여 충격, 불안 또는 위협에 대한 인식을 유발하는 악성 소프트웨어의 한 형태이다.

‘겁을 주다’라는 영어 단어에서 유래한 것으로 공포를 이용하여 피해자를 속여 대가를 지불 하거나 특정 행동을 유도하는 랜섬웨어이다.

가짜 바이러스 경고나 시스템 문제를 표시하여 사용자가 돈을 지불하거나 특정 소프트웨어를 설치하도록 속이는 방식으로 작동한다.

## 1. 문제에서 묻는 것
"가짜 바이러스 경고로 **공포를 주어** 돈을 내거나 소프트웨어를 설치하게 만드는 악성 소프트웨어" → 어떤 악성코드인지 보기에서 고르는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 악성코드(Malware)
**악의적인 목적**으로 만든 소프트웨어. 종류별로 동작 방식이 다르다.

### (2) 대표 악성코드 비교
| 종류 | 핵심 특징 |
|---|---|
| 바이러스 | 다른 파일에 **기생**해 복제·전파 |
| 웜 | **독립 실행**, 네트워크로 스스로 확산 |
| 트로이 목마 | **정상 프로그램으로 위장**, 백도어 설치 |
| **랜섬웨어** | 파일을 **암호화**하고 **금전 요구** |
| **스케어웨어(Scareware)** | **공포(Scare)를 이용**, 가짜 경고로 결제·설치 유도 |
| 스파이웨어 | 사용자 정보를 **몰래 수집** |
| 애드웨어 | **광고를 강제로 노출** |
| 키로거 | 키 입력을 **기록** |

### (3) 스케어웨어 동작
```text
 [⚠ 경고! 당신의 PC가 바이러스 37개에 감염되었습니다!]
 [지금 즉시 "PC 클리너"를 설치/결제하세요!] ← 가짜 경고, 사회공학으로 공포 유발
```
- 사회공학(Social Engineering): 기술이 아닌 **사람의 심리**를 속이는 방식.
- 설치되는 "치료 프로그램"이 사실은 악성코드이거나 결제를 유도하는 사기.

## 3. 문제 풀이
| 단서 | 스케어웨어 |
|---|---|
| **충격·불안·위협**에 대한 인식을 유발 | ✅ |
| '**겁을 주다**(scare)'에서 유래 | ✅ |
| **가짜 바이러스 경고**로 결제/설치 유도 | ✅ |
