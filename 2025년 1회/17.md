# 문제 17

## 문제

다음은 파이썬에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
class Node:
    def __init__(self, value):
        self.value = value
        self.children = []

def tree(li):
    nodes = [Node(i) for i in li]
    for i in range(1, len(li)):
        nodes[(i - 1) // 2].children.append(nodes[i])
    return nodes[0]

def calc(node, level=0):
    if node is None:
        return 0
    return (node.value if level % 2 == 1 else 0) + sum(calc(n, level + 1) for n in node.children)

li = [3, 5, 8, 12, 15, 18, 21]

root = tree(li)

print(calc(root))
```

## 핵심 개념

루트의 레벨을 0으로 놓고 홀수 레벨인 깊이 1,3,…만 합산한다.

## 풀이

배열 인덱스 연결은 부모 (i-1)//2다. 루트 3은 레벨 0이라 제외되고, 자식 5와 8은 레벨 1이라 합에 들어가 13이 된다. 레벨 2의 12,15,18,21은 제외된다.

## 오답 분석

트리 높이나 배열의 홀짝 인덱스가 아니라 재귀 인자 level의 홀짝을 검사한다.

## 암기 포인트

레벨 0 루트 제외, 레벨 1의 5+8.
