## 문제

다음은 파이썬에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
class Node:
    def __init__(self, value):
        self.value = value
        self.children = []

def tree(li):
    nodes = [Node(i) for i in li]
    for i in range(1, len(li)):
        nodes[(i - 1) // 2].children.append(nodes[i])
    return nodes[0]

def calc(node, level=0):
    if node is None:
        return 0
    return (node.value if level % 2 == 1 else 0) + sum(calc(n, level + 1) for n in node.children)

li = [3, 5, 8, 12, 15, 18, 21]

root = tree(li)

print(calc(root))
```

## 1. 문제에서 묻는 것
리스트로 **이진 트리(힙 모양)** 를 만든 뒤, **홀수 레벨(깊이 1, 3, …)** 에 있는 노드 값의 합을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 리스트로 만드는 트리 (완전 이진 트리)
인덱스 `i`의 **부모는 `(i-1)//2`**, 자식은 `2i+1`, `2i+2`이다.
```python
for i in range(1, len(li)):
    nodes[(i - 1) // 2].children.append(nodes[i])   # i번 노드를 부모의 자식으로 추가
```
### (2) 레벨(깊이)
루트의 레벨은 **0**, 그 자식은 1, 손자는 2 …

### (3) `calc` 함수
```python
def calc(node, level=0):
    return (node.value if level % 2 == 1 else 0) + sum(calc(n, level+1) for n in node.children)
```
- **level이 홀수일 때만** 자기 값을 더하고, 아니면 0
- 자식들의 결과(레벨+1)를 모두 더함

## 3. 트리 만들기 (`li = [3, 5, 8, 12, 15, 18, 21]`)
| i | 값 | 부모 인덱스 (i−1)//2 | 부모 값 |
|---:|---:|---:|---:|
| 1 | 5 | 0 | 3 |
| 2 | 8 | 0 | 3 |
| 3 | 12 | 1 | 5 |
| 4 | 15 | 1 | 5 |
| 5 | 18 | 2 | 8 |
| 6 | 21 | 2 | 8 |

```text
                3            ← 레벨 0
             /     \
            5       8        ← 레벨 1 (홀수)
          /  \     /  \
        12   15  18    21    ← 레벨 2 (짝수)
```
## 4. 계산
| 레벨 | 노드 | 홀수 레벨? | 더하는 값 |
|---:|---|:---:|---:|
| 0 | 3 | X | 0 |
| 1 | 5, 8 | ✅ | 5 + 8 = **13** |
| 2 | 12, 15, 18, 21 | X | 0 |

(자식이 없는 레벨 2 노드에서 `children`이 비어 있어 더 내려가지 않는다.)

> **정답: `13`**

## 5. 암기 포인트
- 리스트 → 트리: 부모 인덱스 = `(i-1)//2`.
- **레벨 번호는 0부터** 시작한다. (그래서 홀수 레벨 = 두 번째 줄)
