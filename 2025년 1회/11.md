# 문제 11

## 문제

다음은 C언어에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
#include <stdio.h>
#include <stdlib.h>

void set(int** arr, int* data, int rows, int cols) {
    for (int i = 0; i < rows * cols; ++i) {
        arr[((i + 1) / rows) % rows][(i + 1) % cols] = data[i];
    }
}

int main() {
    int rows = 3, cols = 3, sum = 0;
    int data[] = {5, 2, 7, 4, 1, 8, 3, 6, 9};
    int** arr;
    arr = (int**) malloc(sizeof(int*) * rows);
    for (int i = 0; i < cols; i++) {
        arr[i] = (int*) malloc(sizeof(int) * cols);
    }

    set(arr, data, rows, cols);

    for (int i = 0; i < rows * cols; i++) {
        sum += arr[i / rows][i % cols] * (i % 2 == 0 ? 1 : -1);
    }

    for(int i=0; i<rows; i++) {
        free(arr[i]);
    }
    free(arr);

    printf("%d", sum);
}
```

13

<summary><strong>상세 해설</strong></summary>

## 핵심 개념

원소 저장 위치와 합산 순서를 분리해 표로 추적한다.

## 풀이

입력 데이터가 배치되는 행·열은 i별로 각각 ((i+1)/3)%3, (i+1)%3이다. 결과 행렬은 [9,5,2], [7,4,1], [8,3,6]이다. 합산 루프는 행 우선으로 +,-,+ 부호를 번갈아 적용하여 9-5+2-7+4-1+8-3+6=13을 만든다.

## 오답 분석

입력 배열 순서 그대로 더하거나 열·행 계산을 바꾸면 다른 값이 나온다. i/rows가 행, i%cols가 열이다.

## 암기 포인트

먼저 3×3 표를 채운 뒤 부호를 교대로 적용.
