# 문제 11

## 문제

다음은 C언어에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
#include <stdio.h>
#include <stdlib.h>

void set(int** arr, int* data, int rows, int cols) {
    for (int i = 0; i < rows * cols; ++i) {
        arr[((i + 1) / rows) % rows][(i + 1) % cols] = data[i];
    }
}

int main() {
    int rows = 3, cols = 3, sum = 0;
    int data[] = {5, 2, 7, 4, 1, 8, 3, 6, 9};
    int** arr;
    arr = (int**) malloc(sizeof(int*) * rows);
    for (int i = 0; i < cols; i++) {
        arr[i] = (int*) malloc(sizeof(int) * cols);
    }

    set(arr, data, rows, cols);

    for (int i = 0; i < rows * cols; i++) {
        sum += arr[i / rows][i % cols] * (i % 2 == 0 ? 1 : -1);
    }

    for(int i=0; i<rows; i++) {
        free(arr[i]);
    }
    free(arr);

    printf("%d", sum);
}
```

## 1. 문제에서 묻는 것
**2차원 동적 배열(이중 포인터)** 에 값이 어떤 위치에 저장되는지 추적한 뒤, 홀짝 인덱스에 따라 더하고 빼서 합을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 이중 포인터와 동적 2차원 배열
```c
int** arr = malloc(sizeof(int*) * rows);          // 행 3개짜리 "포인터 배열"
for (...) arr[i] = malloc(sizeof(int) * cols);    // 각 행마다 정수 3칸
```
```text
 arr ─▶ [●]─▶ [ ][ ][ ]   arr[0]
        [●]─▶ [ ][ ][ ]   arr[1]
        [●]─▶ [ ][ ][ ]   arr[2]
 arr[r][c] : r행 c열
```
### (2) 정수 나눗셈과 나머지
`(i+1)/rows` 는 **몫(소수점 버림)**, `(i+1)%cols` 는 **나머지**.

## 3. `set()` 에서 저장 위치 추적 (rows=cols=3)
저장 위치: `arr[ ((i+1)/3) % 3 ][ (i+1) % 3 ] = data[i]`

| i | data[i] | i+1 | 행 `((i+1)/3)%3` | 열 `(i+1)%3` | 저장 위치 |
|---:|---:|---:|---:|---:|---|
| 0 | 5 | 1 | 0 | 1 | arr[0][1] |
| 1 | 2 | 2 | 0 | 2 | arr[0][2] |
| 2 | 7 | 3 | 1 | 0 | arr[1][0] |
| 3 | 4 | 4 | 1 | 1 | arr[1][1] |
| 4 | 1 | 5 | 1 | 2 | arr[1][2] |
| 5 | 8 | 6 | 2 | 0 | arr[2][0] |
| 6 | 3 | 7 | 2 | 1 | arr[2][1] |
| 7 | 6 | 8 | 2 | 2 | arr[2][2] |
| 8 | 9 | 9 | `(3)%3=0` | `0` | arr[0][0] |

**완성된 배열**
```text
          열0  열1  열2
 arr[0] :  9    5    2
 arr[1] :  7    4    1
 arr[2] :  8    3    6
```
(마지막 `i=8`에서 행이 `3 % 3 = 0`으로 순환해 `arr[0][0]`에 저장된다.)

## 4. 합계 계산
`sum += arr[i/3][i%3] * (i % 2 == 0 ? 1 : -1)` → **짝수 i는 더하고, 홀수 i는 뺀다**

| i | arr[i/3][i%3] | 부호 | 누적 sum |
|---:|---:|:---:|---:|
| 0 | 9 | + | 9 |
| 1 | 5 | − | 4 |
| 2 | 2 | + | 6 |
| 3 | 7 | − | -1 |
| 4 | 4 | + | 3 |
| 5 | 1 | − | 2 |
| 6 | 8 | + | 10 |
| 7 | 3 | − | 7 |
| 8 | 6 | + | **13** |

> **정답: `13`**

## 5. 암기 포인트
- `% rows`로 인해 마지막 원소가 **맨 앞 칸으로 순환**되어 들어간다.
- 값이 어디에 저장됐는지 **표를 먼저 완성**한 뒤 계산하자.
