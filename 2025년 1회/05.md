# 문제 05

## 문제

다음은 Java 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
public class Main {

  public static void main(String[] args) {

    int a=5,b=0;

    try{
      System.out.print(a/b);
    }catch(ArithmeticException e){
      System.out.print("출력1");
    }catch(ArrayIndexOutOfBoundsException e) {
      System.out.print("출력2");
    }catch(NumberFormatException e) {
      System.out.print("출력3");
    }catch(Exception e){
      System.out.print("출력4");
    }finally{
      System.out.print("출력5");
    }
  }
}
```

## 1. 문제에서 묻는 것
**예외(Exception) 처리 구조**(`try-catch-finally`)에서 **어떤 catch가 실행되고 finally는 언제 실행되는지** 묻는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 예외란?
프로그램 실행 중 발생하는 **오류 상황**(0으로 나누기, 배열 범위 초과 등). 처리하지 않으면 프로그램이 **강제 종료**된다.

### (2) try - catch - finally
```java
try {        // 예외가 발생할 수 있는 코드
} catch (예외타입 e) {   // 그 타입의 예외가 발생하면 실행 (위에서부터 첫 번째로 맞는 것 하나만)
} finally {  // 예외 발생 여부와 상관없이 "항상" 마지막에 실행
}
```
| 블록 | 실행 시점 |
|---|---|
| `try` | 항상 먼저 실행. **예외가 발생한 줄에서 중단**하고 catch로 이동 |
| `catch` | 발생한 예외 타입과 **일치하는 첫 번째** catch 하나만 실행 |
| `finally` | **예외가 있든 없든 항상 실행** |

### (3) 주요 예외 타입
| 예외 | 발생 원인 |
|---|---|
| `ArithmeticException` | **정수를 0으로 나눔** |
| `ArrayIndexOutOfBoundsException` | 배열 범위를 벗어난 인덱스 |
| `NumberFormatException` | 숫자가 아닌 문자열을 숫자로 변환 |
| `Exception` | 모든 예외의 **부모** (가장 마지막에 둠) |

## 3. 실행 과정
`int a=5, b=0;`
1. `try`: `a / b` = `5 / 0` → **ArithmeticException 발생** (`print`는 실행되지 않음)
2. catch를 위에서부터 검사
   - `ArithmeticException` ✅ **일치** → `"출력1"` 출력 (나머지 catch는 건너뜀)
3. `finally` → `"출력5"` 출력

| 단계 | 출력 |
|---|---|
| try에서 예외 발생 | (출력 없음) |
| catch(ArithmeticException) | `출력1` |
| finally | `출력5` |

> **정답: `출력1출력5`**

## 4. 암기 포인트
- **정수 ÷ 0 → ArithmeticException** (실수 ÷ 0은 예외 없이 Infinity).
- finally는 **항상 실행**. catch는 **하나만** 실행.
