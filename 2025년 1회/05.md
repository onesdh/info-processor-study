# 문제 05 — 예외 처리와 finally

## 문제

0으로 나누는 Java 코드의 catch와 finally 출력 순서를 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

출력1출력5

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

정수 0 나눗셈은 ArithmeticException을 발생시키고, finally 블록은 예외 발생 여부와 관계없이 실행된다.

## 풀이

5/0 계산에서 ArithmeticException이 발생한다. 첫 번째 catch가 이를 받아 출력1을 출력한다. 그 다음 finally가 실행되어 출력5를 출력한다. 다른 catch는 실행되지 않는다.

## 오답 분석

예외가 발생했다고 finally가 생략되지 않는다. 아래쪽의 일반 Exception catch도 이미 처리된 예외에 대해 추가 실행되지 않는다.

## 암기 포인트

catch 처리 후 finally는 항상.
