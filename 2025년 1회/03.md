# 문제 03

## 문제

아래의 내용에서 설명 글의 괄호안의 용어를 영문 약자로 작성하시오.

(        ) 은/는 3글자의 영어 약자로 이루어진 오류 기법으로 데이터를 전송하거나 저장할 때 데이터의 오류를 감지하는 데 사용되는 오류 검출 코드이다.

(        ) 은/는 데이터에 체크섬을 추가하여 데이터를 전송하거나 저장한 후, 수신 또는 읽을 때 이 체크섬을 다시 계산하여 데이터가 변경되었는지 확인하는 기법이다.

(        ) 은/는 데이터 전송의 안정성을 높이는 데 중요한 역할을 한다.

데이터는 이진수(0과 1)로 표현되며 정해진 다항식(x³ + x + 1)을 기반으로 데이터를 2진수 나눗셈하고나머지를 (       ) 값으로 삼는다.

## 1. 문제에서 묻는 것
"3글자 영어 약자의 **오류 검출 코드**", "**다항식으로 2진수 나눗셈**하고 **나머지**를 검사값으로" → 어떤 방식인지 묻는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 오류 검출이 필요한 이유
통신·저장 중 잡음 때문에 비트가 **0→1, 1→0**으로 바뀔 수 있다. 데이터에 **검사용 값**을 덧붙여 수신 측이 오류 여부를 확인한다.

### (2) CRC (Cyclic Redundancy Check, 순환 중복 검사)
| 항목 | 내용 |
|---|---|
| 아이디어 | **송·수신자가 약속한 다항식(생성 다항식)** 으로 데이터를 **나눈 나머지**를 데이터 뒤에 붙여 전송 |
| 수신 확인 | 수신 측도 같은 다항식으로 나눠 **나머지가 0이면 정상**, 아니면 오류 |
| 강점 | **연속된 여러 비트 오류(버스트 오류)** 검출에 강함, 구현이 쉬움 |
| 한계 | 오류를 **검출**만 하고 **정정은 못 함** (재전송 필요) |

### (3) 계산 흐름 (개념)
```text
 송신: 데이터 1101 ─ (생성 다항식 x³+x+1 = 1011 으로 2진 나눗셈, XOR) ─▶ 나머지 R
       전송 데이터 = 1101 | R
 수신: (1101 | R) ÷ 1011 → 나머지가 0 이면 OK
```
2진 나눗셈은 **뺄셈 대신 XOR**을 쓴다.

### (4) 다른 검출 방식과 비교
| 방식 | 특징 |
|---|---|
| 패리티 | 1비트 추가, 1비트 오류만 검출 |
| 체크섬 | 데이터 합을 이용 |
| **CRC** | **다항식 나눗셈**, 버스트 오류에 강함 |
| 해밍 코드 | **오류 정정**까지 가능 |

## 3. 문제 풀이
| 문제의 단서 | CRC |
|---|---|
| **3글자 영어 약자**의 오류 검출 코드 | ✅ (C-R-C) |
| 체크섬을 더해 전송, 수신 후 다시 계산해 비교 | 검사값 방식 |
| 데이터 전송의 **안정성**에 중요 | ✅ |
| **정해진 다항식(x³+x+1)** 으로 2진 나눗셈, **나머지**를 검사값 | CRC의 핵심 |

> **정답: CRC (Cyclic Redundancy Check)**
