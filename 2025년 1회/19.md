# 문제 19

## 문제

다음은 C언어에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
#include <stdio.h>

typedef struct student {
    char* name;
    int score[3];
} Student;

int dec(int enc) {
    return enc & 0xA5;
}

int sum(Student* p) {
    return dec(p->score[0]) + dec(p->score[1]) + dec(p->score[2]);
}

int main() {
    Student s[2] = { "Kim", {0xA0, 0xA5, 0xDB}, "Lee", {0xA0, 0xED, 0x81} };
    Student* p = s;
    int result = 0;

    for (int i = 0; i < 2; i++) {
        result += sum(&s[i]);
    }
    printf("%d", result);
    return 0;
}
```

<details>
<summary><strong>정답 보기</strong></summary>

908

</details>

<summary><strong>상세 해설</strong></summary>

## 핵심 개념

비트 AND는 마스크에서 1인 비트 위치만 보존한다.

## 풀이

0xA0&0xA5=0xA0=160, 0xA5&0xA5=165, 0xDB&0xA5=0x81=129이므로 첫 학생 합은 454다. 둘째도 0xED&0xA5=0xA5, 0x81&0xA5=0x81이어서 합 454다. 두 합을 더하면 908이다.

## 오답 분석

16진수를 십진수처럼 더하는 문제가 아니다. 먼저 각 비트 위치에 AND를 적용한 뒤 십진수 값으로 합산한다.

## 암기 포인트

A5 마스크를 비트별 AND, 학생별 454.
