# 문제 19

## 문제

다음은 C언어에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
#include <stdio.h>

typedef struct student {
    char* name;
    int score[3];
} Student;

int dec(int enc) {
    return enc & 0xA5;
}

int sum(Student* p) {
    return dec(p->score[0]) + dec(p->score[1]) + dec(p->score[2]);
}

int main() {
    Student s[2] = { "Kim", {0xA0, 0xA5, 0xDB}, "Lee", {0xA0, 0xED, 0x81} };
    Student* p = s;
    int result = 0;

    for (int i = 0; i < 2; i++) {
        result += sum(&s[i]);
    }
    printf("%d", result);
    return 0;
}
```

<summary><strong>정답 보기</strong></summary>

908

## 1. 문제에서 묻는 것
**구조체 배열과 포인터**, 그리고 **비트 AND 마스킹(`& 0xA5`)** 으로 값을 해독해서 합산한 결과를 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 16진수와 2진수
16진수 한 자리 = 2진수 4자리.
| 16진수 | 2진수 | 10진수 |
|---|---|---:|
| A | 1010 | 10 |
| 5 | 0101 | 5 |
| D | 1101 | 13 |
| B | 1011 | 11 |
| E | 1110 | 14 |
| 8 | 1000 | 8 |
| 0 | 0000 | 0 |
| 1 | 0001 | 1 |

### (2) 비트 AND (`&`)
**둘 다 1일 때만 1.** 마스크(0xA5 = `1010 0101`)로 **마스크에서 1인 자리의 비트만 남기는** 연산이다.
```text
 0xA5 = 1010 0101   (남기고 싶은 자리 = 1)
```
### (3) 구조체와 포인터
`Student s[2]` : 이름(name)과 점수 3개(score[3])를 가진 구조체 2개. `p->score[0]`은 포인터로 멤버에 접근.

## 3. 실행 과정 (`dec(x) = x & 0xA5`)
**Kim**: `{0xA0, 0xA5, 0xDB}`
| 점수 | 2진수 | & 1010 0101 | 결과 | 10진수 |
|---|---|---|---|---:|
| 0xA0 | 1010 0000 | 1010 0000 | 0xA0 | **160** |
| 0xA5 | 1010 0101 | 1010 0101 | 0xA5 | **165** |
| 0xDB | 1101 1011 | 1000 0001 | 0x81 | **129** |
→ 160 + 165 + 129 = **454**

**Lee**: `{0xA0, 0xED, 0x81}`
| 점수 | 2진수 | & 1010 0101 | 결과 | 10진수 |
|---|---|---|---|---:|
| 0xA0 | 1010 0000 | 1010 0000 | 0xA0 | **160** |
| 0xED | 1110 1101 | 1010 0101 | 0xA5 | **165** |
| 0x81 | 1000 0001 | 1000 0001 | 0x81 | **129** |
→ 160 + 165 + 129 = **454**

`result = 454 + 454 = 908`

> **정답: `908`**

## 4. 암기 포인트
- 0xDB & 0xA5 = 0x81 (1101 1011 → 1000 0001).
- 16진수는 **2진수로 풀어서** 세로로 맞추면 실수가 없다. A5(165), 81(129), A0(160) 기억해 두면 빠르다.
