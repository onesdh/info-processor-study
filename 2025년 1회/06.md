# 문제 06

## 문제

아래 내용은 ARP/RARP에 대한 설명이다. 각 설명에 해당하는 것을 작성하시오.

( 1 ) 은/는 네트워크상에서 IP 주소를 MAC 주소로 변환하는 프로토콜이고,

( 2 ) 은/는 MAC 주소를 IP 주소로 변환하는 프로토콜이다.

<details>
<summary><strong>정답 보기</strong></summary>

(1) ARP

(2) RARP

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
IP 주소 → MAC 주소 변환 프로토콜과 MAC 주소 → IP 주소 변환 프로토콜의 이름을 묻는 문제다.

## 2. 먼저 알아야 할 개념
### (1) IP 주소와 MAC 주소
| 구분 | IP 주소 | MAC 주소 |
|---|---|---|
| 역할 | **논리적 주소** (네트워크 위치) | **물리적 주소** (랜카드 고유 번호) |
| 예 | 192.168.0.10 | 00:1A:2B:3C:4D:5E |
| 계층 | 3계층(네트워크) | 2계층(데이터링크) |
| 바뀜 | 네트워크 옮기면 변경 | 고정(하드웨어) |

같은 네트워크 안에서 실제로 프레임을 전달하려면 **MAC 주소**가 필요하다. 그런데 사용자는 IP 주소만 알고 있다 → **변환 프로토콜**이 필요하다.

### (2) ARP / RARP
| 프로토콜 | 변환 방향 | 동작 |
|---|---|---|
| **ARP** (Address Resolution Protocol) | **IP → MAC** | "이 IP 가진 사람 MAC 주소 알려줘" 를 **브로드캐스트**로 묻고 응답 받음 |
| **RARP** (Reverse ARP) | **MAC → IP** | 자기 MAC은 아는데 IP를 모를 때(디스크 없는 장비) 서버에 IP를 물어봄 |

```text
 ARP :  PC A ──[ 192.168.0.5 누구? MAC 알려줘 (브로드캐스트) ]──▶ 모든 호스트
        PC A ◀──[ 내 MAC은 AA:BB:CC… (유니캐스트 응답) ]── 192.168.0.5
```
(Reverse = "역방향"이라서 RARP.)

## 3. 문제 풀이
| 문장 | 정답 |
|---|---|
| (1) **IP → MAC** 변환 | **ARP** |
| (2) **MAC → IP** 변환 | **RARP** |

> **정답: (1) ARP (2) RARP**

## 4. 암기 포인트
- **ARP = IP를 MAC으로**, **RARP = MAC을 IP로**(Reverse).
- 관련: ICMP(오류 보고, ping), DHCP(IP 자동 할당).
