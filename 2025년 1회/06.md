# 문제 06

## 문제

IP 주소에서 MAC 주소를 찾는 프로토콜과 MAC 주소에서 IP 주소를 찾는 프로토콜을 각각 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

(1) ARP (2) RARP

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

ARP는 IPv4 주소를 로컬 네트워크의 MAC 주소로 해석하고, RARP는 반대 방향으로 MAC에서 IP 정보를 얻는다.

## 풀이

LAN에서 목적지 IP로 프레임을 보내려면 링크 계층 목적지 MAC이 필요하다. ARP 요청·응답으로 이를 찾는다. RARP는 과거 디스크 없는 단말이 MAC 주소를 제시해 IP를 얻는 용도로 사용됐다.

## 오답 분석

두 프로토콜의 방향을 뒤집기 쉽다. 주소 해석의 일상적 사용은 IP→MAC인 ARP다.

## 암기 포인트

ARP는 IP에서 MAC으로.
