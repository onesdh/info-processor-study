# 문제 20

## 문제

다음은 Java 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
public class Main {
  public static void main(String[] args) {
    System.out.println(calc("5"));
  }

  static int calc(int value) {
    if (value <= 1) return value;
    return calc(value - 1) + calc(value - 2);
  }

  static int calc(String str) {
    int value = Integer.valueOf(str);
    if (value <= 1) return value;
    return calc(value - 1) + calc(value - 3);
  }
}
```

## 1. 문제에서 묻는 것
**메서드 오버로딩**(같은 이름, 다른 매개변수 타입)과 **재귀**가 합쳐진 문제다. `calc("5")`가 어느 `calc`를 부르고, 그 안의 호출이 또 어느 `calc`를 부르는지가 핵심이다.

## 2. 먼저 알아야 할 개념
### (1) 오버로딩
같은 이름의 메서드를 **매개변수 타입/개수만 다르게** 여러 개 정의한 것. 호출할 때 **인자의 타입**으로 어느 것을 부를지 결정한다.

| 메서드 | 인자 타입 | 동작 |
|---|---|---|
| `calc(String str)` | **문자열** | 숫자로 바꾼 뒤 `calc(value-1) + calc(value-3)` |
| `calc(int value)` | **정수** | `calc(value-1) + calc(value-2)` (피보나치) |

### (2) 중요한 함정
`calc(String)` **안에서** 호출하는 `calc(value - 1)`, `calc(value - 3)`의 인자는 `int`(숫자)이므로 **`calc(int)` 버전**이 호출된다! (String 버전이 재귀하는 것이 아니다.)

### (3) `calc(int)`는 피보나치 수열
`f(n) = f(n-1) + f(n-2)`, `f(n) = n (n ≤ 1)`
| n | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---:|---:|---:|---:|---:|---:|
| calc(n) | 0 | 1 | 1 | 2 | 3 | 5 |

## 3. 실행 과정
`calc("5")` → **String 버전** 실행
- `value = Integer.valueOf("5")` = 5
- `5 <= 1`? 아니오 → `return calc(4) + calc(2);`
  - 인자가 `int`(4, 2) → **int 버전** 사용

| 호출 | 버전 | 계산 | 값 |
|---|---|---|---:|
| `calc("5")` | String | `calc(4) + calc(2)` | |
| ↳ `calc(4)` | **int** | calc(3)+calc(2) = 2+1 | **3** |
| ↳ `calc(2)` | **int** | calc(1)+calc(0) = 1+0 | **1** |

`calc("5")` = 3 + 1 = **4**

> **정답: `4`**

## 4. 암기 포인트
- 오버로딩은 **인자의 타입**으로 결정된다 — `"5"`는 String, `value - 1`은 int.
- String 버전의 `value - 3`을 따라가며 재귀한다고 착각하면 오답(실제로는 int 버전 피보나치).
