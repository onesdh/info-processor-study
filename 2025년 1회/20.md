# 문제 20

## 문제

다음은 Java 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
public class Main {
  public static void main(String[] args) {
    System.out.println(calc("5"));
  }

  static int calc(int value) {
    if (value <= 1) return value;
    return calc(value - 1) + calc(value - 2);
  }

  static int calc(String str) {
    int value = Integer.valueOf(str);
    if (value <= 1) return value;
    return calc(value - 1) + calc(value - 3);
  }
}
```

4

## 핵심 개념

첫 호출은 문자열 매개변수 메서드, 그 안의 정수 인수 호출은 정수 메서드를 선택한다.

## 풀이

calc("5")는 calc(String)을 선택한다. 내부 값 5에서 calc(4)+calc(2)를 호출하며 둘 다 int 오버로드다. 정수 버전은 피보나치형으로 calc(4)=3, calc(2)=1이므로 합은 4다.

## 오답 분석

모든 재귀 호출이 문자열 버전을 계속 호출한다고 생각하면 안 된다. 인수의 정적 타입에 따라 오버로드가 결정된다.

## 암기 포인트

처음만 String, 내부는 int 재귀.
