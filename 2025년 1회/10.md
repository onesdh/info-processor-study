# 문제 10

## 문제

다음은 C언어에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
#include <stdio.h>
char Data[5] = {'B', 'A', 'D', 'E'};
char c;

int main(){
    int i, temp, temp2;

    c = 'C';
    printf("%d\n", Data[3]-Data[1]);

    for(i=0;i<5;++i){
        if(Data[i]>c)
            break;
    }

    temp = Data[i];
    Data[i] = c;
    i++;

    for(;i<5;++i){
        temp2 = Data[i];
        Data[i] = temp;
        temp = temp2;
    }

    for(i=0;i<5;i++){
        printf("%c", Data[i]);
    }
}
```

## 1. 문제에서 묻는 것
문자 배열에서 **문자의 ASCII 값 비교**, **삽입 위치 찾기**, **뒤 요소 한 칸씩 밀기**가 섞인 코드의 출력값을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 문자는 숫자(ASCII)로 저장된다
| 문자 | A | B | C | D | E |
|---|---:|---:|---:|---:|---:|
| ASCII | 65 | 66 | 67 | 68 | 69 |

그래서 `'E' - 'A'` = 69 − 65 = **4**, `Data[i] > c` 는 문자 크기 비교(알파벳 순서)다.

### (2) 배열 초기화의 함정
```c
char Data[5] = {'B','A','D','E'};   // 4개만 초기화 → Data[4]는 자동으로 0('\0')
```
```text
 인덱스:  0    1    2    3    4
 값  :   'B'  'A'  'D'  'E'  '\0'(0)
```
### (3) 전역 변수 `c`
`c = 'C'` (67).

## 3. 실행 과정
**① 첫 `printf("%d\n", Data[3]-Data[1])`**
`'E' - 'A'` = 69 − 65 = **4** → 첫 줄 출력 `4`

**② 삽입 위치 찾기** (`Data[i] > c`인 첫 위치)
| i | Data[i] | > 'C'(67)? |
|---:|---|:---:|
| 0 | B(66) | X |
| 1 | A(65) | X |
| 2 | D(68) | ✅ → break, **i=2** |

**③ 삽입하고 뒤로 한 칸씩 밀기**
```text
 temp = Data[2] = 'D';  Data[2] = 'C';  i = 3
```
| i | temp2 = Data[i] | Data[i] = temp | temp = temp2 | 배열 |
|---:|---|---|---|---|
| 시작 | | | 'D' | B A **C** E 0 |
| 3 | 'E' | 'D' | 'E' | B A C **D** 0 |
| 4 | 0 | 'E' | 0 | B A C D **E** |

**④ 출력** (`%c`로 5개)
`B A C D E` → **BACDE**

> **정답**
> ```
> 4
> BACDE
> ```

## 4. 암기 포인트
- 배열 크기보다 적게 초기화하면 **나머지는 0**.
- `'C'`가 들어갈 자리를 찾아 **삽입 정렬**처럼 뒤를 밀어냈다 → 정렬된 순서 `A B C D E`가 아닌 `B A C D E`(앞부분은 원래 순서 그대로).
