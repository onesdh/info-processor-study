# 문제 16

## 문제

다음은 Java 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
public class Main {

    public static void main(String[] args) {
        int[] data = {3, 5, 8, 12, 17};
        System.out.println(func(data, 0, data.length - 1));
    }

    static int func(int[] a, int st, int end) {
        if (st >= end) return 0;
        int mid = (st + end) / 2;
        return a[mid] + Math.max(func(a, st, mid), func(a, mid + 1, end));
    }

}
```

<summary><strong>정답 보기</strong></summary>

20

</details>

<summary><strong>상세 해설</strong></summary>

## 핵심 개념

각 호출은 중간 원소에 하위 구간 결과 중 큰 값을 더한다.

## 풀이

func(0,4)는 중간 인덱스 2의 8에 max(func(0,2),func(3,4))를 더한다. 왼쪽 구간 결과는 5+max(3,0)=8이고, 오른쪽은 12+max(0,0)=12다. 최종은 8+max(8,12)=20이다.

## 오답 분석

종료 조건 st>=end인 단일 원소 구간은 0을 반환한다. 배열 원소 전체의 합을 구하는 재귀가 아니다.

## 암기 포인트

중간값에 두 하위 결과 중 큰 값 하나만 더한다.
