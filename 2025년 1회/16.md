# 문제 16

## 문제

다음은 Java 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
public class Main {

    public static void main(String[] args) {
        int[] data = {3, 5, 8, 12, 17};
        System.out.println(func(data, 0, data.length - 1));
    }

    static int func(int[] a, int st, int end) {
        if (st >= end) return 0;
        int mid = (st + end) / 2;
        return a[mid] + Math.max(func(a, st, mid), func(a, mid + 1, end));
    }

}
```

## 1. 문제에서 묻는 것
**이진 탐색처럼 구간을 반으로 나누는 재귀 함수**를 따라가며, 중간값을 누적하는 합을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 재귀 호출
함수가 **자기 자신을 다시 호출**한다. 종료 조건(`st >= end`)에 닿으면 값을 돌려주고, 호출한 곳으로 올라오며 계산을 이어 간다.

### (2) 이 함수가 하는 일
```java
static int func(int[] a, int st, int end) {
    if (st >= end) return 0;                        // 구간에 원소가 0~1개면 0
    int mid = (st + end) / 2;                       // 중간 인덱스
    return a[mid] + Math.max(func(a, st, mid), func(a, mid + 1, end));
    //      중간값 + (왼쪽 구간 결과 vs 오른쪽 구간 결과 중 큰 값)
}
```
`mid`는 정수 나눗셈이라 **소수점이 버려진다.**

## 3. 호출 트리 (`data = {3, 5, 8, 12, 17}`, 인덱스 0~4)
```text
 func(0,4): mid=2 → a[2]=8 + max( func(0,2), func(3,4) )
 ├─ func(0,2): mid=1 → a[1]=5 + max( func(0,1), func(2,2) )
 │   ├─ func(0,1): mid=0 → a[0]=3 + max( func(0,0), func(1,1) ) = 3 + max(0,0) = 3
 │   └─ func(2,2): st>=end → 0
 │   → func(0,2) = 5 + max(3, 0) = 8
 └─ func(3,4): mid=3 → a[3]=12 + max( func(3,3), func(4,4) ) = 12 + max(0,0) = 12
 → func(0,4) = 8 + max(8, 12) = 8 + 12 = 20
```
## 4. 계산 표
| 호출 | mid | a[mid] | 왼쪽 결과 | 오른쪽 결과 | 반환 |
|---|---:|---:|---:|---:|---:|
| func(0,1) | 0 | 3 | func(0,0)=0 | func(1,1)=0 | **3** |
| func(0,2) | 1 | 5 | func(0,1)=3 | func(2,2)=0 | 5+3 = **8** |
| func(3,4) | 3 | 12 | func(3,3)=0 | func(4,4)=0 | **12** |
| func(0,4) | 2 | 8 | func(0,2)=8 | func(3,4)=12 | 8+12 = **20** |

> **정답: `20`**

## 5. 암기 포인트
- 재귀는 **가장 작은 구간(종료 조건)부터 거꾸로 채우면** 쉽다.
- `Math.max`로 **두 하위 결과 중 큰 쪽만** 더한다.
