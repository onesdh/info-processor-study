# 문제 09

## 문제

IP 주소가 192.168.35.10, 서브넷 255.255.252.0인 PC에서 브로드캐스팅으로 다른 IP로 정보를 전달한다고 할 때 수신할 수 있는 알맞는 IP를 보기에서 골라 모두 작성하시오.

[보기]

ㄱ. 192.168.34.1  
ㄴ. 192.168.32.19  
ㄷ. 192.168.35.200  
ㄹ. 192.168.33.138  
ㅁ. 192.168.35.50

ㄱ,ㄴ,ㄷ,ㄹ,ㅁ

## 1. 문제에서 묻는 것
IP `192.168.35.10`, 서브넷 마스크 `255.255.252.0`인 PC가 **브로드캐스트**로 보낼 때, **수신할 수 있는 IP**를 보기에서 모두 고르는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 브로드캐스트
**같은 네트워크(서브넷)에 속한 모든 호스트에게 한꺼번에** 보내는 통신. 라우터를 넘어가지 못하므로 **같은 네트워크의 호스트만** 받는다.

### (2) 같은 네트워크 판별
서브넷 마스크로 **네트워크 주소 범위**를 구해 그 안에 있는 IP인지 본다.

### (3) 255.255.252.0 의 의미
```text
 255.255.252.0 = 11111111.11111111.111111 00.00000000 → /22 (호스트 10비트)
```
3번째 옥텟 마스크 252 → **블록 크기 = 256 − 252 = 4** (3번째 옥텟을 4씩 묶음)

## 3. 풀이
**① 네트워크 범위 구하기**
- 3번째 옥텟 블록: 0~3 / 4~7 / … / **32~35** / 36~39 …
- 35는 **32~35** 블록에 속함

| 항목 | 값 |
|---|---|
| 네트워크 주소 | 192.168.**32**.0 |
| 사용 범위 | 192.168.32.1 ~ 192.168.**35**.254 |
| 브로드캐스트 주소 | 192.168.**35**.255 |

```text
 3번째 옥텟:   32     33     34     35
              └──────┴──────┴──────┘
              192.168.32.0 ~ 192.168.35.255  (같은 네트워크, 1024개)
```
**② 보기 판별**
| 보기 | 3번째 옥텟 | 32~35 안? | 수신 |
|---|---:|:---:|:---:|
| ㄱ. 192.168.34.1 | 34 | ✅ | ✅ |
| ㄴ. 192.168.32.19 | 32 | ✅ | ✅ |
| ㄷ. 192.168.35.200 | 35 | ✅ | ✅ |
| ㄹ. 192.168.33.138 | 33 | ✅ | ✅ |
| ㅁ. 192.168.35.50 | 35 | ✅ | ✅ |

보기 5개 모두 같은 네트워크(192.168.32.0/22) 안에 있다.

> **정답: ㄱ, ㄴ, ㄷ, ㄹ, ㅁ (전부)**

## 4. 암기 포인트
- /22 → 3번째 옥텟을 **4씩** 묶는다 (…, 28~31, 32~35, 36~39 …).
- "전부 정답"처럼 보여도 의심하지 말고 **범위를 직접 계산**해 확인한다.
