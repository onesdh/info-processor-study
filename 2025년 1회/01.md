# 문제 01

## 문제

세션 상태를 훔치거나 시퀀스 번호를 조작해 정상 TCP 통신을 탈취하는 공격의 이름을 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

세션 하이재킹 (Session Hijacking)

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

인증을 마친 세션의 식별 정보나 통신 흐름을 가로채는 공격이다.

## 풀이

공격자는 사용자의 세션 쿠키 또는 TCP 시퀀스 정보를 알아내 정상 연결에 끼어든다. TCP 연결이 형성된 뒤 시퀀스 번호를 맞춰 통신을 이어받는 경우도 TCP 세션 하이재킹이라 한다.

## 오답 분석

IP 스푸핑은 출발지 IP 위조, 스니핑은 패킷 도청, 피싱은 사용자를 속여 정보를 입력시키는 방식이다. 세션을 이어받아 권한을 사용하는 상황은 하이재킹이다.

## 암기 포인트

로그인 뒤 세션을 탈취하면 하이재킹.

</details>
