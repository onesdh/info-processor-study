# 문제 01

## 문제

다음은 네트워크 보완에 관련된 문제이다. 괄호안에 알맞는 용어를 작성하시오.

(   )은/는 '세션을 가로채다.' 라는 의미로 다른 사람의 세션 상태를 훔치거나 도용하여 액세스하는 해킹 기법이다.

TCP (   )은/는 TCP의 3-way 핸드셰이크가 완료된 후에 공격자가 시퀀스 번호 등을 조작하여 정상적인 세션을 가로채고 인증 없이 통신을 탈취하는 공격 공격이다.

## 1. 문제에서 묻는 것
"다른 사람의 **세션을 가로채는** 해킹 기법", 그중 TCP 연결 후 **시퀀스 번호를 조작**해 통신을 탈취하는 공격의 이름을 묻는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 세션(Session)이란?
로그인에 성공한 뒤 서버와 사용자 사이에 유지되는 **"인증된 상태의 연결"** 이다. 서버는 매번 비밀번호를 묻지 않고 **세션 ID(쿠키 등)** 로 사용자를 알아본다.
```text
 사용자 ──로그인(아이디/비번)──▶ 서버
 사용자 ◀──세션 ID 발급──────── 서버
 사용자 ──세션 ID 제시──▶ 서버 : "아, 로그인한 그 사용자구나" (비번 재확인 없음)
```
### (2) 세션 하이재킹(Session Hijacking)
**하이재킹(Hijacking) = 납치.** 공격자가 정상 사용자의 **세션 ID나 TCP 연결 상태를 훔쳐서** 그 사용자인 것처럼 접속한다. **이미 인증이 끝난 뒤**를 노리므로 비밀번호를 몰라도 된다.
```text
 정상 사용자 ═══ (연결) ═══ 서버
                 ↑ 공격자가 끼어들어 연결/세션을 가로챔
 공격자 ──(탈취한 세션)──▶ 서버  → 인증 없이 사용자 권한으로 접근
```
### (3) TCP 세션 하이재킹
- **3-way handshake로 연결이 완료된 후**, 공격자가 패킷을 스니핑해 **시퀀스 번호(SEQ)와 ACK 번호**를 알아낸다.
- 공격자가 그 번호를 맞춰 위조 패킷을 보내면 서버는 **정상 클라이언트로 오인**하고 받아들인다.
- 이때 진짜 클라이언트와의 연결은 번호가 어긋나 끊어진다(ACK Storm 등).

### (4) 비슷한 공격과 구분
| 공격 | 핵심 |
|---|---|
| **세션 하이재킹** | 이미 **성립된 세션을 가로챔** |
| IP 스푸핑 | **출발지 IP를 위조** |
| 스니핑 | 패킷을 **도청** |
| 피싱 | 가짜 사이트로 **정보 입력을 유도** |

### (5) 대응
HTTPS(암호화) 사용, 세션 ID 주기적 재발급·만료, 쿠키에 `Secure`/`HttpOnly` 설정.

## 3. 문제 풀이
| 단서 | 해당 |
|---|---|
| "세션을 가로채다" | 하이재킹 |
| 3-way 핸드셰이크 **완료 후**, **시퀀스 번호** 조작 | TCP 세션 하이재킹 |
| 인증 없이 통신 탈취 | 인증된 세션을 가로챔 |

> **정답: 세션 하이재킹 (Session Hijacking)**
