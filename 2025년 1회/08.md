# 문제 08

## 문제

아래는 데이터베이스에 관련된 설명이다. 알맞는 용어를 보기에서 골라 괄호를 작성하시오.

1. 릴레이션에서 속성의 개수를 의미 : ( 1 )

2. 릴레이션에서 튜플의 개수를 의미 : ( 2 )

3. 한 릴레이션의 속상이 다른 릴레이션의 기본 키를 참조할 때, 참조하는 속성을 의미 : ( 3 )

4. 특정 속성에 대해 입력될 수 있는 값의 유형이나 범위를 의미하고 무결성을 보장하는 기준 : ( 4 )

## 1. 문제에서 묻는 것
릴레이션 관련 용어 4개(차수, 카디널리티, 외래키, 도메인)를 설명과 연결하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 릴레이션 구조
```text
        속성(Attribute) = 열
        ┌─────┬──────┬──────┐
        │ 학번 │ 이름 │ 학과 │   ← 속성 3개 → 차수(Degree) = 3
        ├─────┼──────┼──────┤
 튜플 ▶ │ 101 │ 홍   │ 컴공 │
        │ 102 │ 김   │ 전자 │   ← 튜플 2개 → 카디널리티(Cardinality) = 2
        └─────┴──────┴──────┘
```
### (2) 용어 정리
| 용어 | 의미 |
|---|---|
| **차수(Degree)** | **속성(열)의 개수** |
| **카디널리티(Cardinality)** | **튜플(행)의 개수** |
| **도메인(Domain)** | 속성이 가질 수 있는 **값의 유형·범위**, 무결성 보장의 기준 |
| 속성(Attribute) | 열 |
| **기본키(Primary Key)** | 튜플을 **유일하게 식별**하는 키 |
| 후보키(Candidate Key) | 기본키가 될 수 있는 **유일성·최소성** 만족 키 |
| **외래키(Foreign Key)** | **다른 릴레이션의 기본키를 참조**하는 속성 |

## 3. 문제 풀이
| 번호 | 설명 | 정답 |
|---|---|---|
| 1 | 릴레이션에서 **속성의 개수** | ㄷ. **degree** |
| 2 | 릴레이션에서 **튜플의 개수** | ㅁ. **cardinality** |
| 3 | 다른 릴레이션의 **기본키를 참조**하는 속성 | ㅅ. **foreign** |
| 4 | 입력될 수 있는 **값의 유형이나 범위**, 무결성 보장 기준 | ㄱ. **domain** |

> **정답: (1) ㄷ (2) ㅁ (3) ㅅ (4) ㄱ**

## 4. 암기 포인트
- **차수 = 열 수, 카디널리티 = 행 수** ("차(열)·카(행)").
- 외래키 = 다른 테이블의 기본키를 **참조(Reference)**.
