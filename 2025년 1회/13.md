# 문제 13 — Java 생성자와 동적 디스패치

## 문제

Parent 생성자와 Child 생성자에서 오버라이딩된 show가 실행될 때 static total 값을 구하시오.

## 정답

54

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

상위 생성자에서도 실제 객체 타입의 오버라이딩 메서드가 호출될 수 있다.

## 풀이

Parent 생성자에서 v는 1에서 2가 되어 total=2다. 이때 호출한 show는 Child 버전이 실행되어 total=2+2×2=6이다. 이어 Child 필드 v가 10으로 초기화되고 생성자에서 12가 된다. total에 후위 증가 전 값 12를 더해 18, 다시 Child.show가 18+36=54를 만든다.

## 오답 분석

Parent.show가 호출된다고 잘못 생각하면 중간 결과가 달라진다. 자식 필드는 상위 생성자가 실행될 때 아직 기본값 0이며, 명시적 초기화는 이후 이뤄진다.

## 암기 포인트

상위 생성자 호출 중 오버라이드 메서드도 자식 구현으로 디스패치.
