# 문제 13

## 문제

다음은 Java 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
public class Main {
    public static void main(String[] args) {
        new Child();
        System.out.println(Parent.total);
    }
}


class Parent {
    static int total = 0;
    int v = 1;

    public Parent() {
        total += (++v);
        show();
    }

    public void show() {
        total += total;
    }
}


class Child extends Parent {
    int v = 10;

    public Child() {
        v += 2;
        total += v++;
        show();
    }

    @Override
    public void show() {
        total += total * 2;
    }
}


```

54

<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**상속, 정적 변수, 필드 은닉, 오버라이딩, 생성자 호출 순서**가 모두 섞인 고난도 문제다. 실행 순서를 정확히 추적해야 한다.

## 2. 먼저 알아야 할 개념
### (1) 자식 객체 생성 순서
`new Child()` →
1. **부모 생성자 `Parent()`** 가 먼저 실행 (자식 생성자 첫 줄에 `super()`가 자동 삽입)
2. 부모 생성자 실행이 끝난 뒤 **자식 필드 초기화**(`int v = 10;`)
3. **자식 생성자 본문** 실행

### (2) static 변수
`static int total`은 **클래스에 하나만** 존재하며 모든 객체가 공유한다. (`Parent.total`)

### (3) 필드는 오버라이딩되지 않는다 (은닉)
부모와 자식이 같은 이름의 필드 `v`를 가져도 **서로 별개의 변수**다. (Parent의 `v` ≠ Child의 `v`)

### (4) 메서드는 오버라이딩된다
부모 생성자 안에서 `show()`를 호출해도 **실제 객체가 Child이므로 `Child.show()`가 실행**된다.

### (5) 전위/후위 증가
`++v`: 먼저 증가한 값을 사용 / `v++`: **현재 값을 사용한 뒤** 증가.

## 3. 클래스 요약
```text
 Parent : static total = 0;   int v = 1;
          Parent() { total += (++v);  show(); }        show() { total += total; }  (사용 안 됨)
 Child  : int v = 10;  (Parent.v와 별개)
          Child()  { v += 2;  total += v++;  show(); }
          show()   { total += total * 2; }              ← Parent.show()를 오버라이딩
```
## 4. 실행 과정 (`new Child()`)
| 단계 | 코드 | 변수 변화 | total |
|---:|---|---|---:|
| 시작 | | `total = 0` | 0 |
| ① | `Parent()` : `++v` | **Parent.v: 1 → 2** | |
| ② | `total += 2` | | 0 + 2 = **2** |
| ③ | `show()` → **Child.show()** : `total += total*2` | | 2 + 4 = **6** |
| ④ | (부모 생성자 종료) Child 필드 초기화 | **Child.v = 10** | 6 |
| ⑤ | `Child()` : `v += 2` | Child.v = 12 | 6 |
| ⑥ | `total += v++` | 12를 더하고 Child.v = 13 | 6 + 12 = **18** |
| ⑦ | `show()` → Child.show() : `total += total*2` | | 18 + 36 = **54** |

`System.out.println(Parent.total)` → **54**

> **정답: `54`**

## 5. 암기 포인트
- 생성 순서: **부모 생성자 → 자식 필드 초기화 → 자식 생성자**.
- 부모 생성자 안의 메서드 호출은 **자식 오버라이딩 메서드**가 실행된다(자식 필드는 아직 초기화 전).
- 같은 이름 필드는 **각자 따로**.
