## 1. 문제에서 묻는 것
표의 설명을 읽고 **CPU 스케줄링 알고리즘**(SJF, RR, SRT)을 맞히는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 스케줄링 알고리즘 비교
| 알고리즘 | 선택 기준 | 선점 여부 |
|---|---|---|
| FCFS | 도착 순서 | 비선점 |
| **SJF** (Shortest Job First) | **CPU 처리(실행) 시간이 가장 짧은** 작업 | **비선점** |
| **RR** (Round Robin) | **시간 할당량(타임 퀀텀)** 씩 번갈아 | 선점 |
| **SRT** (Shortest Remaining Time) | **남은 CPU 시간이 가장 짧은** 작업 | **선점** (SJF의 선점형) |

## 3. 문제 풀이
| 스케줄링 | 설명의 핵심 | 정답 |
|---|---|---|
| ( ) | Ready Queue의 프로세스 중 **CPU 처리 시간이 짧은 순서**, **비선점형**, 늦게 도착해도 처리 시간이 더 짧으면 먼저 CPU를 받을 수 있음 | **SJF** |
| ( ) | **도착한 순서대로** 디스패치하되 **정해진 시간 할당량**으로 실행 제한, 시간 안에 못 끝나면 **큐 맨 뒤**로 → CPU를 독점하지 않고 **공평하게** | **RR (라운드 로빈)** |
| ( ) | **선점** 방식으로 변경한 기법, CPU 점유 프로세스보다 **남은 시간이 짧은** 프로세스가 도착하면 CPU 선점, 평균 대기 시간이 가장 짧지만 **Context Switching 오버헤드** 큼 | **SRT** |

> **정답: SJF, RR, SRT**

## 4. 암기 포인트
- **SRT = SJF의 선점형**, **RR = 시간 할당량 + 공평성**.
- SRT는 평균 대기 시간이 짧지만 **문맥 교환(오버헤드)** 이 많다.
