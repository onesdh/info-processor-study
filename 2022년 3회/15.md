# 문제 15

## 문제

아래 설명에 대하여 알맞는 용어를 작성하시오.

(       )은/는 여러 개의 사이트에서 한번의 로그인으로 여러가지 다른 사이트들을 자동적으로 접속하여 이용하는 방법을 말한다. 일반적으로 서로 다른 시스템 및 사이트에서 각각의 사용자 정보를 관리하게 되는데 이때 하나의 사용자 정보를 기반으로 여러 시스템을 하나의 통합 인증을 사용하게 하는 것을 말한다.

즉 하나의 시스템에서 인증을 할 경우 타 시스템에서는 인증 정보가 있는지 확인하고 있으면 로그인 처리를 하도록 하고, 없는 경우 다시 통합 인증을 할 수 있도록 만드는 것을 의미한다.

## 1. 문제에서 묻는 것
"**한 번의 로그인**으로 **여러 사이트**를 이용", **통합 인증**" → 용어를 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) SSO (Single Sign-On)
**한 번 인증**하면 **서로 다른 여러 시스템·사이트**에 **다시 로그인하지 않고** 접근할 수 있게 하는 **통합 인증** 방식이다.
```text
 [사용자] ──① 로그인──▶ [ 통합 인증 서버(SSO) ]
     │                         │ ② 인증 토큰/티켓 발급
     ├──③ 토큰 제시──▶ 사이트 A (인증 정보 확인 → 로그인 처리)
     ├──③ 토큰 제시──▶ 사이트 B
     └──③ 토큰 제시──▶ 사이트 C
 (한 번 로그인으로 A, B, C 모두 이용)
```
### (2) 동작 방식
- 하나의 시스템에서 인증 → 다른 시스템은 **인증 정보가 있는지 확인**해서 있으면 **자동 로그인**
- 없으면 **통합 인증 서버로 보내 다시 인증**

### (3) 장단점
| 장점 | 단점 |
|---|---|
| 사용자 **편의성** ↑ (비밀번호 하나) | 인증 서버·계정이 **침해되면 전체 시스템이 위험** (단일 장애점) |
| 계정 **관리 효율** ↑ | 구축 복잡 |

### (4) 비슷한 용어
| 용어 | 차이 |
|---|---|
| **SSO** | 한 번 로그인으로 **여러 시스템** 인증 |
| OAuth | **권한 위임(인가)** |
| Kerberos | 티켓 기반 인증 프로토콜(SSO 구현에 사용) |

## 3. 문제 풀이
| 단서 | SSO |
|---|---|
| **한 번의 로그인**으로 여러 사이트 자동 접속 | ✅ |
| 하나의 사용자 정보로 **통합 인증** | ✅ |
| 인증 정보가 있으면 로그인 처리, 없으면 통합 인증 | ✅ |

> **정답: SSO (Single Sign-On)**
