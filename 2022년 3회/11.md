## 1. 문제에서 묻는 것
보기 중 **형상 관리 도구** 3가지를 고르는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 형상 관리(SCM, Software Configuration Management)
소프트웨어의 **변경 사항(소스 코드, 문서, 설정 등)을 체계적으로 관리**하는 활동이다. **누가, 언제, 무엇을 바꿨는지** 기록하고, 필요하면 **이전 버전으로 되돌리기** 쉽게 해 준다.

### (2) 형상 관리 도구
| 도구 | 방식 | 특징 |
|---|---|---|
| **CVS** | 중앙 집중식 | 초기 도구, 오래됨 |
| **SVN (Subversion)** | 중앙 집중식 | CVS 개선, 커밋 단위 버전 관리 |
| **Git** | **분산** | 각자 로컬에 전체 저장소 복사, 빠름·브랜치 강력 (현재 표준) |
| 그 외 | | Mercurial, Perforce, Bitbucket 등 |

```text
 중앙 집중식(CVS, SVN): 모든 개발자 ─▶ [ 하나의 중앙 서버 ]
 분산(Git)            : 개발자 A [로컬 저장소] ⇄ 원격 저장소 ⇄ [로컬 저장소] 개발자 B
```
