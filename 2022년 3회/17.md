# 문제 17

## 문제

다음은 UML에 관한 설명이다. 괄호안에 알맞는 답을 작성하시오.

UML은 통합 모델링 언어로써, 시스템을 모델로 표현해주는 대표적인 모델링 언어이다.

구성 요소로는 사물, (    1    ), 다이어그램으로 이루어져 있으며, 구조 다이어그램 중, (     2    ) 다이어그램은 시스템에서 사용되는 객체 타입을 정의하고, 그들 간의 존재하는 정적인 관계를 다양한 방식으로 표현한 다이어그램이다.

또한 UML 모델링에서 (     3    )은/는 클래스와 같은 기타 모델 요소 또는 컴포넌트가 구현해야 하는 오퍼레이션 세트를 정의하는 모델 요소이다.

## 1. 문제에서 묻는 것
UML의 **구성 요소**, **클래스 다이어그램**, **인터페이스**를 설명으로 구분하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) UML (Unified Modeling Language)
소프트웨어 구조·동작을 **그림으로 표현하는 표준 모델링 언어**.

### (2) UML의 구성 요소 3가지
| 구성 요소 | 설명 | 예 |
|---|---|---|
| **사물(Things)** | 모델의 기본 요소 | 클래스, 인터페이스, 유스케이스, 컴포넌트, 노드 등 |
| **관계(Relationships)** | 사물 사이의 연결 | 연관, 집합, 포함, 일반화(상속), 의존, 실체화 |
| **다이어그램(Diagrams)** | 사물과 관계를 그림으로 표현 | 클래스, 시퀀스, 유스케이스 다이어그램 등 |

### (3) 클래스 다이어그램
시스템에서 사용되는 **객체 타입(클래스)** 을 정의하고, 그들 간의 **정적인 관계**를 보여주는 **구조 다이어그램**.
```text
 ┌──────────┐        ┌──────────┐
 │  학생    │◇───────│  수강신청 │   (클래스 박스: 이름 / 속성 / 오퍼레이션)
 │ - 이름   │        └──────────┘
 │ + 신청() │
 └──────────┘
```
### (4) 인터페이스(Interface)
클래스나 컴포넌트가 **구현해야 하는 오퍼레이션(메서드) 집합**을 정의하는 모델 요소. **구현 없이 "무엇을 해야 하는지"만** 정의한다.
```text
   «interface»                 클래스가 인터페이스를
   Payable          ◁┄┄┄┄┄┄┄  구현(실체화, 점선+속 빈 삼각형)
   + pay()
```
## 3. 문제 풀이
| 번호 | 단서 | 정답 |
|---|---|---|
| (1) | 구성 요소 = 사물, ( ), 다이어그램 | **관계** |
| (2) | 구조 다이어그램, 객체 **타입을 정의**, **정적인 관계** 표현 | **클래스** (다이어그램) |
| (3) | 클래스나 컴포넌트가 **구현해야 하는 오퍼레이션 세트**를 정의 | **인터페이스** |

> **정답: 1. 관계 / 2. 클래스 / 3. 인터페이스**
