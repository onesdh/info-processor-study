# 문제 03 — Bridge와 Observer 패턴

## 문제

추상화와 구현을 분리하는 패턴, 상태 변경을 구독자에게 알리는 패턴을 쓰시오.

## 정답

1. Bridge 2. Observer

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

Bridge는 추상화와 구현 계층을 분리해 독립 확장하고, Observer는 일대다 상태 변경 통지를 지원한다.

## 풀이

기능 클래스와 구현 추상 클래스를 분리해 서로 독립적으로 바꾸는 것은 Bridge다. 객체 상태가 바뀌면 구독자에게 알리는 것은 Observer다.

## 오답 분석

Adapter는 기존 인터페이스를 변환한다. Observer의 핵심은 상태 변화 구독·통보다.

## 암기 포인트

추상화/구현 분리 Bridge, 상태 통지 Observer.
