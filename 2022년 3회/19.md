## 1. 문제에서 묻는 것
**배열을 만들어 반환하는 메서드**를 호출한 뒤 배열의 모든 원소를 출력한 결과를 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 배열 생성과 반환
```java
int[] tempArr = new int[4];     // 정수 4칸 배열 (초기값 0,0,0,0)
return tempArr;                  // 배열의 "참조(주소)"를 돌려줌
```
배열은 힙에 만들어지고 **참조**가 반환되므로 메서드가 끝나도 배열은 살아 있다.

### (2) 반복문
`for (int i = 0; i < 길이; i++)`
- `i`가 0부터 **길이−1**까지 반복. (이 문제의 `.Length`는 자바에서는 `.length`가 맞는 표기)

## 3. 실행 과정
**① `MakeArray()`** : `tempArr[i] = i;`
| i | tempArr[i] |
|---:|---:|
| 0 | 0 |
| 1 | 1 |
| 2 | 2 |
| 3 | 3 |

→ `[0, 1, 2, 3]` 반환 → `intArr`가 이 배열을 가리킴.

**② 출력**: `print(intArr[i])` (줄바꿈 없음)
`0` `1` `2` `3` → **0123**

> **정답: `0123`**

## 4. 암기 포인트
- 배열 인덱스는 0부터, 길이 4 → 인덱스 0~3.
- `print`는 줄바꿈이 없어 숫자가 붙어서 출력된다.
- (원문 코드의 `.Length`는 C# 표기이며 자바에서는 `.length`)
