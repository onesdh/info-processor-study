## 1. 문제에서 묻는 것
파이썬 `map()`과 `lambda`로 리스트의 모든 값에 100을 더한 결과를 출력하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) lambda (익명 함수)
**이름 없는 한 줄 함수**.
```python
lambda num : num + 100     # num을 받아서 num + 100 을 돌려주는 함수
(lambda num: num + 100)(5) # → 105
```
### (2) map(함수, 반복가능객체)
반복 가능한 객체(리스트 등)의 **모든 원소에 함수를 적용**한 결과를 순서대로 돌려준다. 결과는 **map 객체**라서 `list(...)`로 감싸 리스트로 변환한다.
```python
list(map(lambda x: x*2, [1, 2, 3]))   # [2, 4, 6]
```
## 3. 실행 과정
`TestList = [1, 2, 3, 4, 5]`
| 원소 | `num + 100` |
|---:|---:|
| 1 | 101 |
| 2 | 102 |
| 3 | 103 |
| 4 | 104 |
| 5 | 105 |

`TestList = list(map(...))` → `[101, 102, 103, 104, 105]`

> **정답: `[101, 102, 103, 104, 105]`**

(참고: 원문 코드는 괄호가 하나 더 있는 오타이지만 의도한 동작은 위와 같다.)

## 4. 암기 포인트
- `map`은 각 원소에 함수를 적용, 결과는 `list()`로 변환해야 출력 가능.
- 파이썬 리스트 출력 형태는 `[a, b, c]` 형식(쉼표 뒤 공백).
