# 문제 09 — Python map과 lambda

## 문제

각 리스트 원소에 100을 더한 새 리스트를 출력하시오.

<details>
<summary><strong>정답 보기</strong></summary>

[101, 102, 103, 104, 105]

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

map은 반복 가능한 자료의 각 항목에 함수를 적용한다.

## 풀이

lambda num:num+100을 [1,2,3,4,5]의 각 원소에 적용해 101부터 105까지 만든 뒤 list로 감싼다.

## 오답 분석

map 객체 자체를 출력하는 것이 아니라 list로 변환해 원소를 표시한다. 원본을 더한 값은 100씩 증가한다.

## 암기 포인트

map 적용 후 list로 변환.

</details>
