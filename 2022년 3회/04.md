## 1. 문제에서 묻는 것
이중 반복문으로 각 원소의 **순위(큰 값이 몇 개인가 + 1)** 를 구해 출력하는 코드의 결과를 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 순위 계산 알고리즘
```c
result[i] = 1;                        // 기본 순위 1등
for (j = 0; j < 5; j++)
    if (arr[i] < arr[j]) result[i]++; // 나보다 "큰" 값을 만날 때마다 순위가 한 칸 밀림
```
**순위 = (나보다 큰 값의 개수) + 1.** (같은 점수가 있다면 같은 순위)

### (2) 이중 반복의 동작
바깥 `i`가 하나 정해질 때마다 안쪽 `j`가 0~4 전체를 돌며 `arr[i]`를 모든 원소와 비교한다.

## 3. 실행 과정 (`arr = [77, 32, 10, 99, 50]`)
| i | arr[i] | 나보다 큰 값 | 개수 | result[i] = 1 + 개수 |
|---:|---:|---|---:|---:|
| 0 | 77 | 99 | 1 | **2** |
| 1 | 32 | 77, 99, 50 | 3 | **4** |
| 2 | 10 | 77, 32, 99, 50 | 4 | **5** |
| 3 | 99 | (없음) | 0 | **1** |
| 4 | 50 | 77, 99 | 2 | **3** |

`result` = `[2, 4, 5, 1, 3]` → 공백 없이 출력 → **24513**

> **정답: `24513`**

## 4. 암기 포인트
- `arr[i] < arr[j]` 이면 **j가 i보다 크다** → 내 순위가 낮아짐(숫자 증가).
- 점수가 큰 99가 **1등**.
