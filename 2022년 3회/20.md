## 1. 문제에서 묻는 것
1부터 998까지의 수 중 **3의 배수이면서 홀수인 가장 큰 수**를 구하는 문제다. (마지막으로 조건을 만족한 값이 `a`에 남는다.)

## 2. 먼저 알아야 할 개념
### (1) 조건식
```java
if (i % 3 == 0 && i % 2 != 0)  a = i;
```
| 조건 | 의미 |
|---|---|
| `i % 3 == 0` | i는 **3의 배수** |
| `i % 2 != 0` | i는 **홀수** |
| `&&` | **둘 다** 만족 |

### (2) 반복의 특징
`i`가 증가하며 조건을 만족할 때마다 `a`를 **덮어쓴다.** → 반복이 끝났을 때 `a`는 **마지막(가장 큰)으로 조건을 만족한 값**.

## 3. 풀이
반복 범위: `i = 1 ~ 998` (`i < 999`, **999는 포함되지 않음**)

조건: **3의 배수이면서 홀수 = 6으로 나눈 나머지가 3인 수** (3, 9, 15, 21 …, 6k+3)
```text
 6k + 3 ≤ 998  →  k ≤ 165.8  →  k = 165
 마지막 값 = 6 × 165 + 3 = 993
```
검산: 995(3의 배수 아님), 996(짝수), 997·998(3의 배수 아님) → **993**
(참고: 999는 3의 배수이면서 홀수지만 `i < 999`라서 제외된다.)

| 후보 | 3의 배수? | 홀수? | 만족 |
|---:|:---:|:---:|:---:|
| 998 | X | | X |
| 997 | X | | X |
| 996 | ✅ | X | X |
| 995 | X | | X |
| 994 | X | | X |
| **993** | ✅ | ✅ | **✅ (마지막)** |

`System.out.print(a)` → **993**

> **정답: `993`**

## 4. 암기 포인트
- 반복문 범위 **`i < 999`** → 999 제외.
- 3의 배수이면서 홀수 = **3, 9, 15, … (6씩 증가)**.
