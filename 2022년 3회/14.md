# 문제 14

## 문제

아래 설명에 대하여 알맞는 답을 보기에서 고르시오.

(기호식 보기가 있습니다. ex: CSRF 등)

(   1   )은/는 프로세서(processor) 안에 독립적인 보안 구역을 따로 두어 중요한 정보를 보호하는 ARM사에서 개발한 하드웨어 기반의 보안 기술로 프로세서(processor) 안에 독립적인 보안 구역을 별도로 하여, 중요한 정보를 보호하는 하드웨어 기반의 보안 기술이다.

(   2   )은/는 사용자들이 사이트에 접속할 때 주소를 잘못 입력하거나 철자를 빠뜨리는 실수를 이용하기 위해 유사한 유명 도메인을 미리 등록하는 일로 URL 하이재킹(hijacking)이라고도 한다.

## 1. 문제에서 묻는 것
(1) **ARM사**의 **하드웨어 기반 보안 기술**, (2) **철자를 잘못 입력**하는 실수를 노려 **유사 도메인을 선점**하는 공격 → 용어를 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) TrustZone (ARM)
프로세서 안에 **일반 영역(Normal World)** 과 **보안 영역(Secure World)** 을 **하드웨어 수준에서 분리**해, 중요한 정보(지문 데이터, 암호키, 결제 정보)를 안전하게 처리하는 기술이다.
```text
 ┌──────────── 프로세서 (ARM) ────────────┐
 │  일반 영역(Normal World)  │ 보안 영역(Secure World, TrustZone) │
 │  일반 OS, 앱              │ 암호키·지문 등 중요 정보 처리       │
 └────────────────────────────────────────┘
        하드웨어로 격리되어 일반 영역의 악성코드가 보안 영역에 접근 불가
```
스마트폰의 지문 인증·모바일 결제 등에 활용된다.

### (2) 타이포스쿼팅(Typosquatting)
**Typo(오타) + Squatting(무단 점거)**. 사용자가 주소를 입력할 때 **오타(철자 빠뜨림, 비슷한 글자)** 를 내는 것을 노려 **유명 사이트와 비슷한 도메인을 미리 등록**해 두는 공격. **URL 하이재킹**이라고도 한다.
| 원래 도메인 | 오타 도메인 예 |
|---|---|
| google.com | goggle.com, gooogle.com |
| naver.com | navver.com |

피싱 사이트로 유도하거나 광고 수익을 노린다.

## 3. 문제 풀이
| 번호 | 단서 | 정답 |
|---|---|---|
| (1) | **ARM사** 개발, 프로세서 안에 **독립적인 보안 구역**, **하드웨어 기반** 보안 | **TrustZone** |
| (2) | **주소를 잘못 입력하는 실수**를 이용, **유사 도메인 미리 등록**, **URL 하이재킹** | **typosquatting** |

> **정답: 1. TrustZone / 2. typosquatting**
