## 1. 문제에서 묻는 것
6부터 30까지의 수 중 **완전수(자기 자신 제외 약수의 합이 자기 자신인 수)** 의 개수를 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 완전수
자기 자신을 제외한 **약수의 합이 자기 자신과 같은 수**.
| 수 | 약수(자기 제외) | 합 |
|---:|---|---:|
| **6** | 1, 2, 3 | 6 ✅ |
| **28** | 1, 2, 4, 7, 14 | 28 ✅ |
| 12 | 1, 2, 3, 4, 6 | 16 ❌ |
| 20 | 1, 2, 4, 5, 10 | 22 ❌ |

### (2) 코드 읽기
```c
for (n = 6; n <= 30; n++) {
    s = 0;
    k = n / 2;                      // 약수는 n/2 이하이므로 거기까지만 검사
    for (j = 1; j <= k; j++)
        if (n % j == 0) s += j;     // 약수이면 합산
    if (s == n) el++;               // 약수의 합 = 자기 자신 → 완전수
}
```
## 3. 풀이
6~30 범위의 완전수는 **6, 28** 두 개뿐이다.

| n | 약수 합 s | 완전수? | el |
|---:|---:|:---:|---:|
| 6 | 1+2+3 = 6 | ✅ | 1 |
| 28 | 1+2+4+7+14 = 28 | ✅ | **2** |

`printf("%d", el)` → **2**

> **정답: `2`**

## 4. 암기 포인트
- 완전수: **6, 28, 496, 8128…**
- 이 범위(6~30)에서는 2개.
