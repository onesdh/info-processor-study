# 문제 08

## 문제

아래 설명에 대한 알맞는 답을 작성하시오.

(     1     ) 은/는 보안학적 측면에서 기술적인 방법이 아닌 사람들간의 기본적인 신뢰를 기반으로 사람을 속여 비밀 정보를 획득하는 기법이다.

(     2     ) 은/는  빅데이터(Big Data)와 비슷하면서도 구조화돼 있지 않고, 더는 사용하지 않는 ‘죽은’ 데이터를 의미한다. 일반적으로 정보를 수집해 저장한 이후 분석이나 특별한 목적을 위해 활용하는 데이터가 아니며,  저장공간만 차지하고 이러한 이유로 심각한 보안 위험을 초래할 수 있다.

## 1. 문제에서 묻는 것
(1) 사람의 신뢰·심리를 이용해 비밀 정보를 얻는 기법, (2) 사용되지 않고 저장만 되어 있는 "죽은 데이터" → 용어를 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 사회공학(Social Engineering)
**기술(해킹 도구)이 아니라 "사람"을 속여** 정보를 얻는 공격. 사람들 사이의 **신뢰, 호기심, 두려움, 친절**을 악용한다.
| 기법 | 예 |
|---|---|
| 전화·사칭 | IT 담당자를 사칭해 비밀번호를 물어봄 |
| 피싱 | 가짜 이메일/사이트로 계정 정보 입력 유도 |
| 어깨너머 훔쳐보기(Shoulder surfing) | 입력하는 비밀번호를 곁눈질 |
| 쓰레기통 뒤지기(Dumpster diving) | 버려진 서류에서 정보 수집 |
| 스캐어웨어 | 가짜 경고로 공포 유발 |

### (2) 다크 데이터(Dark Data)
기업이 **수집·저장했지만 분석이나 활용 없이 방치된 데이터**(오래된 로그, 사용하지 않는 고객 DB, 비정형 문서 등). 빅데이터와 비슷하지만 **구조화되어 있지 않고 쓰이지 않는다.**
| 문제점 | 설명 |
|---|---|
| 저장 비용 | **저장공간만 차지** |
| **보안 위험** | 관리되지 않아 **유출 시 인지하기 어렵고** 개인정보가 포함될 수 있음 |
| 규정 위반 | 개인정보 보관 기간 초과 가능 |

## 3. 문제 풀이
| 번호 | 단서 | 정답 |
|---|---|---|
| (1) | **기술적 방법이 아닌**, 사람 간의 **신뢰**를 기반으로 **속여** 비밀 정보를 획득 | **사회공학** |
| (2) | 빅데이터와 비슷하나 **구조화되지 않고 사용하지 않는 '죽은' 데이터**, 저장공간만 차지, 보안 위험 | **다크 데이터** |

> **정답: 1. 사회공학 / 2. 다크 데이터**
