# 문제 05

## 문제

아래 코드에 대한 출력 값을 작성하시오.

첫번째 네트워크 주소가 192.168.1.0/24일때 FLSM 3개로 분할했을때  
두번째 네트워크 브로드캐스드 IP를 10진수로 변환한 값을 작성하시오.

<details>
<summary><strong>정답 보기</strong></summary>

192.168.1.127

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
`192.168.1.0/24` 네트워크를 **FLSM**으로 **3개 이상으로 분할**했을 때, **두 번째 서브넷의 브로드캐스트 주소**를 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 서브넷팅과 FLSM
- **서브넷팅**: 하나의 큰 네트워크를 **여러 작은 네트워크**로 나누는 것.
- **FLSM (Fixed Length Subnet Mask)**: 서브넷을 **모두 같은 크기**로 나누는 방식. (VLSM은 크기가 서로 다름)

### (2) 서브넷 개수와 필요한 비트
서브넷 개수 N을 만들려면 호스트 비트 중 **n비트를 네트워크로 빌려** 2ⁿ ≥ N 이어야 한다.
| 필요 서브넷 수 | 빌리는 비트 | 만들어지는 서브넷 수 | 프리픽스 |
|---:|---:|---:|---|
| 2 | 1 | 2 | /25 |
| **3~4** | **2** | **4** | **/26** |
| 5~8 | 3 | 8 | /27 |

3개가 필요 → 2비트(2² = 4 ≥ 3) → **/26**, 서브넷 크기 = 2⁶ = **64**개 주소.

## 3. 풀이
`192.168.1.0/24`를 /26으로 4등분:
| 서브넷 | 네트워크 주소 | 사용 범위 | 브로드캐스트 |
|---:|---|---|---|
| 1번째 | 192.168.1.0/26 | .1 ~ .62 | 192.168.1.63 |
| **2번째** | **192.168.1.64/26** | .65 ~ .126 | **192.168.1.127** |
| 3번째 | 192.168.1.128/26 | .129 ~ .190 | 192.168.1.191 |
| 4번째 | 192.168.1.192/26 | .193 ~ .254 | 192.168.1.255 |

두 번째 서브넷의 **브로드캐스트 = 서브넷의 마지막 주소 = 192.168.1.127**

```text
 64 ~ 127 :  네트워크 주소 .64 ... 브로드캐스트 .127
```
> **정답: `192.168.1.127`**

## 4. 암기 포인트
- 서브넷이 3개 필요하면 **2비트(4개)** 를 빌린다 → /26, 블록 크기 64.
- 브로드캐스트 = **다음 서브넷 시작 − 1**.
