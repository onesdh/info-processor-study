# 문제 19

## 문제

다음은 JAVA 관한 문제이다. 알맞는 출력값을 작성하시오.

```
public class ovr1 {
	public static void main(String[] args){
    	ovr1 a1 = new ovr1();
        ovr2 a2 = new ovr2();
        System.out.println(a1.sun(3,2) + a2.sun(3,2));
    }

    int sun(int x, int y){
    	return x + y;
    }
}

class ovr2 extends ovr1 {

	int sun(int x, int y){
    	return x - y + super.sun(x,y);
    }

}
```

<details>
<summary><strong>정답 보기</strong></summary>

11

</details>

<summary><strong>상세 해설</strong></summary>

## 핵심 개념

하위 클래스는 상위 메서드를 재정의할 수 있으며 super는 상위 구현을 호출한다.

## 풀이

부모 호출은 3+2=5다. 자식은 3-2+super.sun(3,2)=1+5=6이므로 합은 11이다.

## 오답 분석

오버로딩이 아니라 동일 서명의 메서드를 재정의한 상황이다. 자식 호출에도 부모 결과가 포함된다.

## 암기 포인트

부모 5, 자식 6, 합 11.
