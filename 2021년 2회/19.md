# 문제 19

## 문제

다음은 JAVA 관한 문제이다. 알맞는 출력값을 작성하시오.

```
public class ovr1 {
	public static void main(String[] args){
    	ovr1 a1 = new ovr1();
        ovr2 a2 = new ovr2();
        System.out.println(a1.sun(3,2) + a2.sun(3,2));
    }

    int sun(int x, int y){
    	return x + y;
    }
}

class ovr2 extends ovr1 {

	int sun(int x, int y){
    	return x - y + super.sun(x,y);
    }

}
```

## 1. 문제에서 묻는 것
**상속, 오버라이딩, `super` 호출**이 섞인 코드에서 두 객체의 `sun(3,2)` 결과를 더하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 오버라이딩과 super
- 자식 클래스가 부모의 메서드를 **같은 시그니처로 재정의**하면, 객체 타입에 맞는 메서드가 실행된다.
- `super.sun(x, y)` : **부모 클래스의 `sun`** 을 호출.

### (2) 클래스 구조
```text
 ovr1 : int sun(x, y) = x + y
   ▲
 ovr2 : int sun(x, y) = x - y + super.sun(x, y)     ← 부모 것을 오버라이딩, 안에서 부모 것도 호출
```
## 3. 실행 과정
| 호출 | 실행되는 메서드 | 계산 | 값 |
|---|---|---|---:|
| `a1.sun(3, 2)` | ovr1.sun | 3 + 2 | **5** |
| `a2.sun(3, 2)` | **ovr2.sun** | 3 − 2 + `super.sun(3,2)`(= 5) = 1 + 5 | **6** |

`println(a1.sun(3,2) + a2.sun(3,2))` → 5 + 6 = **11** (`int + int`이므로 덧셈)

> **정답: `11`**

## 4. 암기 포인트
- 자식 `sun`은 부모 `sun`을 `super`로 불러 **그 결과를 포함**한다.
- `5 + 6`은 정수 덧셈(`56`이 아님).
