## 1. 문제에서 묻는 것
테스트 하네스의 구성 요소 중, **하향식 테스트에서 하위 모듈을 대신하는 것**을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 테스트 하네스(Test Harness)
시스템이나 컴포넌트를 시험하는 **환경 전체**. 시험을 지원하기 위해 만든 **코드와 데이터**를 말한다.

### (2) 구성 요소
| 구성 요소 | 역할 |
|---|---|
| **테스트 드라이버** | **상향식** 테스트에서 **상위 모듈 대신** 하위 모듈을 호출·구동 |
| **테스트 스텁(Stub)** | **하향식** 테스트에서 **하위 모듈 대신** 정해진 값만 반환 |
| 테스트 슈트 | 테스트 케이스 묶음 |
| 테스트 케이스 | 입력·예상 결과 등 |
| 테스트 스크립트 | 자동 실행 절차 |
| 목 오브젝트 | 가짜 객체(의존 객체 대체) |

```text
 상향식: [드라이버] ─호출▶ 실제 하위 모듈           (상위 모듈 대역)
 하향식: 실제 상위 모듈 ─호출▶ [스텁]               (하위 모듈 대역)
```
## 3. 문제 풀이
| 단서 | 스텁 |
|---|---|
| **하향식 테스트** 시 **하위 모듈 역할을 대신** | ✅ |
| (상향식에서 상위 모듈 역할을 대신하는 것은 **드라이버**) | |

> **정답: 스텁 (Stub)**

## 4. 암기 포인트
- **하향식 = 스텁**, **상향식 = 드라이버**.
