# 문제 08

## 문제

미국 국립 표준 기술연구소 (NIST), DES를 대체하며, 128 비트 블록 크기와 128,192,256비트 키 크기의 대칭 키 암호화 방식은?

<details>
<summary><strong>정답 보기</strong></summary>

AES (Advanced Encryption Standard)

대칭키 알고리즘 :

동일한 키를 사용하여 암호화와 복호화를 하는 것을 의미하며 가장많이 사용하는 알고리즘이 AES 입니다.

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
"**NIST**, **DES를 대체**, **128비트 블록**, **128/192/256비트 키**의 대칭키" → 알고리즘 이름을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 대칭키 암호
암호화와 복호화에 **같은 키**를 사용. **빠르다**. 그중 가장 널리 쓰이는 것이 **AES**.

### (2) AES (Advanced Encryption Standard)
| 항목 | 내용 |
|---|---|
| 종류 | 대칭키 **블록 암호** |
| 블록 크기 | **128비트** 고정 |
| 키 길이 | **128 / 192 / 256비트** (AES-128, AES-192, AES-256) |
| 라운드 수 | **10 / 12 / 14** |
| 배경 | **DES**(키 56비트)의 취약점을 보완하려고 **NIST가 공모**해 선정(Rijndael 알고리즘) |
| 현황 | 현재 **세계 표준**, 안전성·효율·속도 우수 |

### (3) DES와 비교
| 구분 | DES | AES |
|---|---|---|
| 블록 | 64비트 | **128비트** |
| 키 | 56비트 | **128/192/256비트** |
| 안전성 | 취약(폐기) | **안전(표준)** |

## 3. 문제 풀이
| 단서 | AES |
|---|---|
| **NIST**, **DES를 대체** | ✅ |
| **128비트 블록**, **128/192/256비트 키** | ✅ |
| 대칭키 암호화 방식 | ✅ |

> **정답: AES (Advanced Encryption Standard)**

</details>
