# 문제 05

## 문제

다음은 테이블을 수정할때의 상황입니다. SQL 보기에서 괄호안에 알맞는 문장을 작성하시오.

(    1   ) 테이블명  (     2    )  컬럼 = 값 WHERE 점수 &gt;= 90;

<details>
<summary><strong>정답 보기</strong></summary>

1. UPDATE

2. SET

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
테이블 값을 **수정**하는 SQL의 빈칸(`UPDATE`, `SET`)을 채우는 문제다.

## 2. 먼저 알아야 할 개념
### (1) UPDATE 문법
```sql
UPDATE 테이블명
SET    컬럼 = 값 [, 컬럼2 = 값2 ...]
WHERE  조건;
```
| 부분 | 의미 |
|---|---|
| `UPDATE 테이블명` | 어느 테이블을 수정할지 |
| `SET 컬럼 = 값` | **바꿀 열과 새 값** |
| `WHERE 조건` | **수정할 행의 조건** (**생략하면 모든 행이 수정됨!**) |

### (2) 예
```sql
UPDATE 학생 SET 등급 = 'A' WHERE 점수 >= 90;   -- 점수가 90 이상인 학생만 등급을 A로
```
## 3. 문제 풀이
`( 1 ) 테이블명 ( 2 ) 컬럼 = 값 WHERE 점수 >= 90;`
| 빈칸 | 정답 | 이유 |
|---|---|---|
| (1) | **UPDATE** | 테이블 앞에 오는 수정 명령 |
| (2) | **SET** | `컬럼 = 값` 앞에 오는 키워드 |

> **정답: 1. UPDATE 2. SET**

## 4. 암기 포인트
- `UPDATE 테이블 SET 열=값 WHERE 조건;` — WHERE 없으면 **전체 수정**.
- DML: `INSERT`(추가) / `UPDATE`(수정) / `DELETE`(삭제) / `SELECT`(조회).
