# 문제 05

## 문제

다음은 테이블을 수정할때의 상황입니다. SQL 보기에서 괄호안에 알맞는 문장을 작성하시오.

(    1   ) 테이블명  (     2    )  컬럼 = 값 WHERE 점수 &gt;= 90;

<details>
<summary><strong>정답 보기</strong></summary>

1. UPDATE

2. SET

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

UPDATE는 테이블 행을 수정하고 SET은 변경할 컬럼과 새 값을 지정한다.

## 풀이

형식은 UPDATE 테이블명 SET 컬럼=값 WHERE 점수>=90; 이다.

## 오답 분석

INSERT는 행 추가, DELETE는 행 삭제에 사용한다.

## 암기 포인트

행 수정은 UPDATE, 변경값은 SET.

</details>
