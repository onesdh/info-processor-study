# 문제 05 — UPDATE와 SET

## 문제

점수 90 이상인 행의 특정 컬럼 값을 수정하는 SQL에서 테이블 수정 명령과 대입 절을 쓰시오.

## 정답

UPDATE; SET

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

UPDATE는 테이블 행을 수정하고 SET은 변경할 컬럼과 새 값을 지정한다.

## 풀이

형식은 UPDATE 테이블명 SET 컬럼=값 WHERE 점수>=90; 이다.

## 오답 분석

INSERT는 행 추가, DELETE는 행 삭제에 사용한다.

## 암기 포인트

행 수정은 UPDATE, 변경값은 SET.
