# 문제 01

## 문제

네트워크 장치를 필요로하지 않고 네트워크 토폴로지가 동적으로 변화되는 특징이 있으며 응용 분야로는 긴급 구조, 긴급 회의, 전쟁터에서의 군사 네트워크에 활용되는 네트워크는?

<details>
<summary><strong>정답 보기</strong></summary>

애드혹 네트워크(Ad-hoc Network)

무선 네트워크 구성 방식 :

애드혹 네트워크 - 센서망, 재난망에 사용되며 구성이 빠르고 모든 단말이 동등한 자격으로 망을 구성

Infrastructure 네트워크 - 이동통신망,Wi-Fi에 사용되며 중앙집중형 방식

메쉬 네트워크 - 무선백본망에 사용되며 신뢰성이 우수하고, 계층적인 구조를 가지고 있음

</details>

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
"네트워크 **장치(공유기 등)가 필요 없음**, **토폴로지가 동적으로 변화**, 긴급 구조·군사 네트워크" → 어떤 네트워크인지 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 무선 네트워크 구성 방식 3가지
```text
 인프라 네트워크:   [단말] ─ [AP/기지국(중앙)] ─ [단말]          중앙 장비 필요
 애드혹 네트워크:   [단말] ⇄ [단말] ⇄ [단말] ⇄ [단말]           중앙 장비 없이 단말끼리 직접
 메시 네트워크  :   노드들이 그물망으로 다중 경로 연결            (백본망)
```
| 방식 | 중앙 장비 | 특징 | 용도 |
|---|:---:|---|---|
| **Infrastructure** | **필요**(AP, 기지국) | **중앙 집중형**, 안정적 | 이동통신망, Wi-Fi |
| **Ad-hoc (애드혹)** | **불필요** | **임시로 구성**, 구성 빠름, 모든 단말이 **동등**, 토폴로지가 **동적으로 변화** | **긴급 구조, 재난망, 군사, 센서망** |
| **Mesh (메시)** | 일부 필요 | **다중 경로**로 신뢰성 우수, 계층적 구조 | 무선 백본망 |

### (2) 애드혹 네트워크의 핵심
- 노드(단말)가 **스스로 라우터 역할**까지 수행해 데이터를 중계
- 단말이 **이동**하면 **연결 구조(토폴로지)가 계속 변화**
- 인프라 구축이 어려운 **재난·전장** 환경에 적합

## 3. 문제 풀이
| 단서 | Ad-hoc |
|---|---|
| **네트워크 장치 없이** 구성 | ✅ |
| **토폴로지가 동적으로 변화** | ✅ |
| **긴급 구조, 긴급 회의, 전쟁터 군사 네트워크** | ✅ |

> **정답: 애드혹 네트워크 (Ad-hoc Network)**
