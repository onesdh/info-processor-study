# 문제 02

## 문제

사람의 감정과 경험을 나타내는 개념, 사용자와 시스템이 상호작용하는 인터페이스를 순서대로 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

UX (User Experience); UI (User Interface)

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

UX는 사용자가 제품이나 서비스를 이용하며 느끼는 전체 경험이고 UI는 상호작용 수단과 화면을 뜻한다.

## 풀이

첫 설명은 경험, 두 번째는 인터페이스이므로 각각 UX와 UI다.

## 오답 분석

CLI는 UI의 한 종류다. GUI 역시 UI이며 UX와 동일한 개념이 아니다.

## 암기 포인트

경험은 UX, 접점은 UI.

</details>
