# 문제 02

## 문제

다음 (1), (2)에 알맞는 답안을 쓰시오.

(1) 사람의 감정이나 경험을 나타내는 개념

(2) 사용자 인터페이스. 예로는 CLI이 있다.

<details>
<summary><strong>정답 보기</strong></summary>

(1) UX(User Experience)  /  (2) UI(User Interface)

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
(1) 사람의 **감정이나 경험**을 나타내는 개념, (2) **사용자 인터페이스**(예: CLI) → **UX**와 **UI**를 구분하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) UI와 UX
| 구분 | **UI (User Interface)** | **UX (User Experience)** |
|---|---|---|
| 뜻 | 사용자와 시스템이 **만나는 접점**(화면·조작 방식) | 사용자가 **서비스를 이용하며 느끼는 총체적 경험·감정** |
| 범위 | 버튼, 메뉴, 색상, 레이아웃, 명령어 | 편리함, 만족감, 신뢰, 재방문 의사 |
| 예 | **CLI**, GUI, NUI | "이 앱은 쓰기 편하고 기분이 좋다" |
| 비유 | 자동차의 **핸들·계기판** | 그 차를 **운전하는 느낌** |

### (2) UI의 종류
| 종류 | 설명 |
|---|---|
| **CLI** | 명령어(텍스트)로 조작 |
| GUI | 그래픽(아이콘·마우스)으로 조작 |
| NUI | 음성·제스처 등 자연스러운 조작 |

```text
 UI(화면·조작 방법)  ──사용──▶  사용자가 느끼는 감정·경험 = UX   (UI는 UX를 만드는 수단 중 하나)
```
## 3. 문제 풀이
| 번호 | 단서 | 정답 |
|---|---|---|
| (1) | 사람의 **감정이나 경험**을 나타내는 개념 | **UX (User Experience)** |
| (2) | **사용자 인터페이스**, 예로 **CLI** | **UI (User Interface)** |

> **정답: (1) UX (2) UI**

</details>
