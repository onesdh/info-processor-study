# 문제 11

## 문제

응집도 문제로써, 각 번호에 해당하는 응집도를 쓰시오. (실제 시험문제에서는 보기가 주어집니다.)

1. 입출력 간 연관성은 없으나, 순서에 따라 수행되는 것

2. 동일한 입력과 출력 사용

3. 하나의 기능에 모두 기어하고 밀접하게 연관되어 있는 것 (그룹화)

<details>
<summary><strong>정답 보기</strong></summary>

1. 절차적 응집도

2. 교환적 응집도

3. 기능적 응집도

응집도 순서 (낮은것부터 높은 순서)

우연적 &gt; 논리적 &gt; 시간적 &gt; 절차적 &gt; 교환적 &gt; 순차적 &gt; 기능적

우연적 응집도 : 모듈 내부의 각 구성요소들이 연관이 없을 경우

논리적 응집도 : 유사한 성격을 갖거나 특정 형태로 분류되는 처리 요소들이 한 모듈에서 처리되는 경우

시간적 응집도 : 연관된 기능이라기보단 특정 시간에 처리되어야 하는 활동들을 한 모듈에서 처리할 경우

순차적 응집도 : 모듈 내에서 한 활동으로부터 나온 출력값을 다른 활동이 사용할 경우

## 1. 문제에서 묻는 것
응집도 유형 3가지(절차적, 교환적, 기능적)를 설명으로 구분하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 응집도
**한 모듈 안의 요소들이 얼마나 밀접하게 관련되어 있는가**. **높을수록 좋다.**
```text
 우연적 < 논리적 < 시간적 < 절차적 < 교환(통신)적 < 순차적 < 기능적
 (낮음, 나쁨)                                          (높음, 좋음)
```
| 유형 | 설명 |
|---|---|
| 우연적 | 요소들이 **연관이 없음** |
| 논리적 | **유사한 성격**의 처리를 한 모듈에서 처리 |
| 시간적 | 특정 **시간**에 처리되어야 하는 활동들을 한 모듈에 |
| **절차적** | **입출력 간 연관성은 없으나, 순서**에 따라 수행 |
| **교환(통신)적** | **동일한 입력과 출력**을 사용하는 활동들 |
| 순차적 | 한 활동의 **출력값을 다른 활동이 사용**(데이터 흐름) |
| **기능적** | **하나의 기능**에 모두 기여, 밀접하게 연관 |

### (2) 절차적 vs 순차적
```text
 절차적: [A] → [B] → [C]               (순서만 정해짐, 데이터 전달은 없어도 됨)
 순차적: [A] ─출력▶ [B] ─출력▶ [C]       (앞의 출력이 뒤의 입력)
```
## 3. 문제 풀이
| 번호 | 단서 | 정답 |
|---|---|---|
| 1 | **입출력 간 연관성은 없으나, 순서에 따라** 수행 | **절차적 응집도** |
| 2 | **동일한 입력과 출력** 사용 | **교환(통신)적 응집도** |
| 3 | **하나의 기능**에 모두 기여, 밀접하게 연관 | **기능적 응집도** |

> **정답: 1. 절차적 2. 교환적 3. 기능적**

## 4. 암기 포인트
- 순서: **우-논-시-절-교-순-기**. 가장 좋은 것 = **기능적**.
