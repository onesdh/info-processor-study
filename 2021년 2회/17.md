# 문제 17

## 문제

클래스 내에서 객체 생성 없이 사용할 수 있는 메소드로써 출력 결과를 작성하시오.

```
public class Test {
   public static void main(String[] args){
      system.out.print(Test.check(1));
   }

   (    )  String check (int num) {
      return (num >= 0) ? "positive" : "negative";
   }
}

[출력결과]
positive
```

## 1. 문제에서 묻는 것
"클래스 내에서 **객체 생성 없이** 사용할 수 있는 메서드" → 수식어(`static`)를 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) static 메서드
| 구분 | static 메서드 | 인스턴스 메서드 |
|---|---|---|
| 소속 | **클래스** | **객체** |
| 호출 | **`클래스명.메서드()`** — 객체 생성 불필요 | 객체를 만든 뒤 `객체.메서드()` |
| 용도 | 유틸리티 함수(`Math.max`, `main`) | 객체의 상태를 사용하는 기능 |

### (2) main에서의 호출
```java
public static void main(String[] args) {
    System.out.print(Test.check(1));    // 객체 없이 클래스 이름으로 직접 호출
}
static String check(int num) { ... }     // 그래서 check도 static이어야 함
```
`main`은 **static**이라 객체 없이 실행되므로, 객체 없이 `Test.check(1)`로 부르는 메서드는 반드시 **static**이어야 한다.

### (3) 삼항 연산자
`(num >= 0) ? "positive" : "negative"` → 조건이 참이면 `"positive"`.

## 3. 풀이
| 빈칸 | 정답 | 이유 |
|---|---|---|
| `( ) String check(int num)` | **static** | 객체 생성 없이 `Test.check(1)`로 호출 |

실행: `check(1)` → `1 >= 0` 참 → `"positive"` 출력

> **정답: `static`**

## 4. 암기 포인트
- 객체 없이 호출 = **static**. `main`도 static 메서드.
- static 메서드는 인스턴스 변수를 직접 쓸 수 없다.
