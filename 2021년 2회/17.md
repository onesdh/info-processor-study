# 문제 17

## 문제

클래스 내에서 객체 생성 없이 사용할 수 있는 메소드로써 출력 결과를 작성하시오.

```
public class Test {
   public static void main(String[] args){
      system.out.print(Test.check(1));
   }

   (    )  String check (int num) {
      return (num >= 0) ? "positive" : "negative";
   }
}

[출력결과]
positive
```

<details>
<summary><strong>정답 보기</strong></summary>

static

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

static 메서드는 클래스에 속하므로 인스턴스 없이 클래스명으로 호출할 수 있다.

## 풀이

Test.check(1)처럼 클래스 이름으로 부르므로 check 선언에 static이 필요하다.

## 오답 분석

인스턴스 메서드는 객체 참조를 통해 호출해야 한다. static 문맥에서는 인스턴스 필드를 바로 사용할 수 없다.

## 암기 포인트

클래스명으로 호출하려면 static.
