# 문제 12

## 문제

패킷교환방식 중에서, 번호에 해당하는 방식을 적으시오.

1. 목적지 호스트와 미리 연결한 후, 통신하는 연결형 교환 방식

2. 헤더에 붙어서 개별적으로 전달하는 비연결형 교환 방식

## 1. 문제에서 묻는 것
**패킷 교환 방식**의 두 종류(연결형 / 비연결형)를 구분하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 교환 방식
| 방식 | 설명 |
|---|---|
| **회선 교환** | 통신 동안 **물리적 전용 회선**을 점유 (전화망) |
| **패킷 교환** | 데이터를 **패킷(조각)** 으로 나눠 전송 (인터넷) — 아래 2가지 |

### (2) 패킷 교환의 2가지
| 구분 | **가상회선** | **데이터그램** |
|---|---|---|
| 연결 | **연결형** (사전에 논리적 경로 설정) | **비연결형** |
| 경로 | 모든 패킷이 **같은 경로** | 패킷마다 **개별 경로** |
| 헤더 | 연결 후에는 짧은 식별자 | 각 패킷에 **목적지 주소 등 전체 정보** |
| 순서 | 도착 순서 **보장** | 순서 **뒤바뀔 수** 있음(재조립) |
| 예 | ATM, X.25 | **IP(인터넷)** |

```text
 가상회선:  [연결 설정] ① → ② → ③ (같은 길) → 수신
 데이터그램: ① 경로A / ② 경로B / ③ 경로C (각자) → 수신 측에서 재조립
```
## 3. 문제 풀이
| 번호 | 단서 | 정답 |
|---|---|---|
| 1 | 목적지와 **미리 연결**한 후 통신하는 **연결형** | **가상 회선** 방식 |
| 2 | 각 패킷 **헤더에 붙어서 개별적으로 전달**, **비연결형** | **데이터그램** 방식 |

> **정답: 1. 가상 회선 방식 2. 데이터그램 방식**
