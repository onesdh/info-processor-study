# 문제 18

## 문제

다음은 C언어 문제이다. 출력값을 작성하시오.

```
int main(){

int ary[3];
int s = 0;
*(ary+0)=1;
ary[1] = *(ary+0)+2;
ary[2] = *ary+3;
for(int i=0; i<3; i++){
  s=s+ary[i]
}

print("%d",s);

}
```

<details>
<summary><strong>정답 보기</strong></summary>

8

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

배열 이름은 첫 원소를 가리키므로 *ary는 ary[0]이다.

## 풀이

배열은 {1,3,4}가 되고 합은 8이다.

## 오답 분석

*(ary+0)는 ary[0]과 같고, 세 번째 값도 첫 원소 1에 3을 더한 4다.

## 암기 포인트

배열값 1+3+4.

</details>
