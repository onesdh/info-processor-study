# 문제 18

## 문제

다음은 C언어 문제이다. 출력값을 작성하시오.

```
int main(){

int ary[3];
int s = 0;
*(ary+0)=1;
ary[1] = *(ary+0)+2;
ary[2] = *ary+3;
for(int i=0; i<3; i++){
  s=s+ary[i]
}

print("%d",s);

}
```

<details>
<summary><strong>정답 보기</strong></summary>

8

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**배열과 포인터 표현**(`*(ary+0)`, `*ary`)이 같다는 것을 이용해 배열의 합을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 배열과 포인터
배열 이름 `ary`는 **첫 원소의 주소**처럼 동작한다.
| 표현 | 의미 |
|---|---|
| `ary[i]` | i번째 원소 |
| `*(ary + i)` | i번째 원소 (**`ary[i]`와 완전히 동일**) |
| `*ary` | `*(ary+0)` = `ary[0]` |

## 3. 실행 과정
| 단계 | 코드 | 의미 | 값 |
|---|---|---|---:|
| ① | `*(ary+0) = 1;` | `ary[0] = 1` | ary[0] = **1** |
| ② | `ary[1] = *(ary+0) + 2;` | `ary[0] + 2` = 1 + 2 | ary[1] = **3** |
| ③ | `ary[2] = *ary + 3;` | `ary[0] + 3` = 1 + 3 | ary[2] = **4** |

```text
 ary : [1] [3] [4]
```
합 `s = 1 + 3 + 4` = **8**

> **정답: `8`**

## 4. 암기 포인트
- `*ary + 3`은 `*(ary + 3)`이 **아니라** `(*ary) + 3` (역참조가 덧셈보다 먼저).
- `*(ary + i)` ≡ `ary[i]`.
