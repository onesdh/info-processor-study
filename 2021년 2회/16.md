# 문제 16

## 문제

다음은 C언어에 관한 소스코드이다. 실행 결과값을 작성하시오.

```
int main(){
   int res;
   res = mp(2,10);
   printf("%d",res);
   return 0;
}

int mp(int base, int exp) {
   int res = 1;
   for(int i=0; i < exp; i++){
      res = res * base;
   }

   return res;
}
```

<details>
<summary><strong>정답 보기</strong></summary>

1024

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

반복 곱셈으로 거듭제곱을 계산한다.

## 풀이

2^10=1024다.

## 오답 분석

반복 횟수는 10회이며 초기 결과 1에서 두 배씩 증가한다.

## 암기 포인트

2를 열 번 곱하면 1024.

</details>
