# 문제 16

## 문제

다음은 C언어에 관한 소스코드이다. 실행 결과값을 작성하시오.

```
int main(){
   int res;
   res = mp(2,10);
   printf("%d",res);
   return 0;
}

int mp(int base, int exp) {
   int res = 1;
   for(int i=0; i < exp; i++){
      res = res * base;
   }

   return res;
}
```

<details>
<summary><strong>정답 보기</strong></summary>

1024

</details>

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**거듭제곱 함수** `mp(2, 10)`의 반환값을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 함수 정의와 호출
```c
int mp(int base, int exp) {      // base의 exp제곱을 구하는 함수
    int res = 1;
    for (int i = 0; i < exp; i++)    // exp번 반복
        res = res * base;            // 매번 base를 곱함
    return res;
}
```
`mp(2, 10)` = 2를 10번 곱함 = 2¹⁰.

### (2) 지역 변수
`main`의 `res`와 `mp`의 `res`는 **서로 다른 변수**다(각 함수 안에서만 유효).

## 3. 실행 과정 (`base = 2`, `exp = 10`)
| i | res = res × 2 |
|---:|---:|
| 시작 | 1 |
| 0 | 2 |
| 1 | 4 |
| 2 | 8 |
| 3 | 16 |
| 4 | 32 |
| 5 | 64 |
| 6 | 128 |
| 7 | 256 |
| 8 | 512 |
| 9 | **1024** |

`res = mp(2, 10)` = **1024** → `printf("%d", res)`

> **정답: `1024`**

## 4. 암기 포인트
- 2¹⁰ = **1024**. 2의 거듭제곱: 2,4,8,16,32,64,128,256,512,1024.
- 곱하기 전에 `res`를 **1**로 초기화해야 한다.
