# 문제 06

## 문제

다음 SQL 보기에서 JOIN할 경우 괄호안에 알맞는 문장을 작성하시오.

SELECT .... FROM 학생정보 a JOIN 학과정보 b (   1   ) a.학과 = b.(   2   )

<details>
<summary><strong>정답 보기</strong></summary>

1. ON

2. 학과

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

ON은 조인할 두 행을 대응시키는 조건을 지정한다.

## 풀이

조건은 ON a.학과=b.학과다.

## 오답 분석

WHERE는 조인 결과를 추가로 필터링한다. USING은 양쪽에 같은 이름의 컬럼을 공통 열로 쓰는 다른 표기다.

## 암기 포인트

조인 연결 조건은 ON.

</details>
