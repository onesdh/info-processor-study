# 문제 06

## 문제

다음 SQL 보기에서 JOIN할 경우 괄호안에 알맞는 문장을 작성하시오.

SELECT .... FROM 학생정보 a JOIN 학과정보 b (   1   ) a.학과 = b.(   2   )

<details>
<summary><strong>정답 보기</strong></summary>

1. ON

2. 학과

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**JOIN 문법**의 연결 조건을 쓰는 `ON` 절과, 비교할 열 이름을 채우는 문제다.

## 2. 먼저 알아야 할 개념
### (1) JOIN
두 테이블을 **공통 열의 값이 같은 행끼리 연결**한다.
```sql
SELECT 열 FROM 테이블1 별칭 JOIN 테이블2 별칭 ON 조인조건;
```
| 키워드 | 의미 |
|---|---|
| `JOIN` | 두 테이블 결합 (기본 = INNER JOIN) |
| **`ON`** | **조인 조건** 지정 (어느 열이 같을 때 연결할지) |
| `a`, `b` | 테이블 **별칭(alias)** — 긴 테이블 이름을 줄여 쓰고 열 앞에 `a.열`처럼 소속 표시 |

### (2) 예
```text
 학생정보 a                    학과정보 b
 ┌────┬──────┐                ┌──────┬────────┐
 │ 이름│ 학과  │                │ 학과  │ 학과장  │
 │ 김  │ 컴공  │──── a.학과 = b.학과 ───▶│ 컴공  │ 박교수  │
 └────┴──────┘                └──────┴────────┘
```
## 3. 문제 풀이
`SELECT .... FROM 학생정보 a JOIN 학과정보 b ( 1 ) a.학과 = b.( 2 )`
| 빈칸 | 정답 | 이유 |
|---|---|---|
| (1) | **ON** | 조인 조건을 쓰는 키워드 |
| (2) | **학과** | 학생정보의 `학과`와 **같은 의미의 열**(학과정보의 `학과`) |

```sql
SELECT ... FROM 학생정보 a JOIN 학과정보 b ON a.학과 = b.학과;
```
> **정답: 1. ON 2. 학과**

## 4. 암기 포인트
- `JOIN ... ON 조건` (또는 `USING(열)`, `NATURAL JOIN`).
- `a.학과 = b.학과` : 양쪽 테이블의 **같은 의미의 열**을 `=`로 연결.
