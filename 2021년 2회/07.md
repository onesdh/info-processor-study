# 문제 07

## 문제

파이썬 비트 연산자 코드 결과

```
a = 100
result = 0
for i in range(1,3);
   result = a >> i
   result = result + 1
pirnt(result)
```

<details>
<summary><strong>정답 보기</strong></summary>

26

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

비트 오른쪽 시프트는 양의 정수에서 2의 거듭제곱으로 나눈 몫과 같다.

## 풀이

i=1일 때 100>>1은 50, 여기에 1을 더해 51이다. i=2에서 새로 계산된 100>>2는 25, 여기에 1을 더해 최종 26이다.

## 오답 분석

result가 누적되지 않고 매 반복에서 덮어써진다는 점에 주의한다. 마지막 반복의 값만 남는다.

## 암기 포인트

루프 마지막 i=2에서 25+1=26.

</details>
