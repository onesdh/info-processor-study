# 문제 07

## 문제

파이썬 비트 연산자 코드 결과

```
a = 100
result = 0
for i in range(1,3);
   result = a >> i
   result = result + 1
pirnt(result)
```

<details>
<summary><strong>정답 보기</strong></summary>

26

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**비트 시프트 연산(`>>`)** 을 반복문에서 사용하되, **`result`가 매번 `a`로부터 새로 계산**된다는 점을 파악하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 오른쪽 시프트 `>>`
`a >> n` : a를 2진수로 보고 **오른쪽으로 n칸 이동** = **a ÷ 2ⁿ (몫)**.
```text
 100 = 1100100 (2진수)
 100 >> 1 = 0110010 = 50     (÷2)
 100 >> 2 = 0011001 = 25     (÷4)
```
### (2) range(1, 3)
`i = 1, 2` (끝값 3은 제외).

### (3) 주의
`result = a >> i` 는 **이전 result를 쓰지 않고** 항상 **a(=100)** 를 시프트한다. 그 다음 `result = result + 1`로 1을 더한다. 다음 반복에서 `result`는 다시 덮어써진다.

## 3. 실행 과정 (`a = 100`)
| i | `result = a >> i` | `result = result + 1` |
|---:|---:|---:|
| 1 | 100 >> 1 = 50 | 51 |
| 2 | 100 >> 2 = 25 | **26** |

반복 종료 후 `print(result)` → **26**

> **정답: `26`**

(원문 코드는 문법 오타(`for ...;`, `pirnt`)가 있으나 의도한 동작은 위와 같다.)

## 4. 암기 포인트
- `a >> n` = `a // 2**n`, `a << n` = `a * 2**n`.
- 마지막 반복의 결과만 남는다 (덮어쓰기).
