# 문제 10

## 문제

SQL문에서 괄호안에 알맞은 답안을 작성하시오. (실제 시험에는 결과 이미지가 있습니다.)

('이름'이란 컬럼에 '이'로 시작하는 문자열을 '내림차순'하는 쿼리 결과 내용입니다.)

SELECT .... FROM ... WHERE '이름' LIKE (   1   )  ORDER BY  '컬럼명'  (    2    )

<details>
<summary><strong>정답 보기</strong></summary>

1. 이%

2. DESC

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

LIKE의 %는 0개 이상의 임의 문자를 나타내므로 이%는 ‘이’로 시작하는 문자열을 찾는다. DESC는 내림차순이다.

## 풀이

WHERE 이름 LIKE '이%' ORDER BY 컬럼명 DESC 형태로 작성한다.

## 오답 분석

%이%는 중간에 ‘이’가 포함된 값을, _이%는 특정 한 글자 다음에 ‘이’가 오는 값을 찾는다.

## 암기 포인트

앞글자 검색은 이%, 내림차순은 DESC.

</details>
