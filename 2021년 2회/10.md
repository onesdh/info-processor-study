# 문제 10

## 문제

SQL문에서 괄호안에 알맞은 답안을 작성하시오. (실제 시험에는 결과 이미지가 있습니다.)

('이름'이란 컬럼에 '이'로 시작하는 문자열을 '내림차순'하는 쿼리 결과 내용입니다.)

SELECT .... FROM ... WHERE '이름' LIKE (   1   )  ORDER BY  '컬럼명'  (    2    )

1. 이%

2. DESC

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
"이름이 '이'로 **시작**하는 값을 **내림차순** 정렬"하는 SQL의 빈칸(`LIKE` 패턴, 정렬 방향)을 채우는 문제다.

## 2. 먼저 알아야 할 개념
### (1) LIKE와 와일드카드
| 패턴 | 의미 | 예 |
|---|---|---|
| `%` | **0개 이상**의 임의 문자열 | `'이%'` = "이"로 **시작**하는 모든 값 |
| `_` | **정확히 1개**의 문자 | `'이_'` = "이" + 한 글자 |
| `'%이'` | "이"로 **끝나는** 값 | |
| `'%이%'` | "이"를 **포함**하는 값 | |

### (2) ORDER BY
| 키워드 | 의미 |
|---|---|
| `ASC` | **오름차순** (기본값) |
| `DESC` | **내림차순** (큰 값 → 작은 값) |

## 3. 풀이
```sql
SELECT ... FROM ... WHERE 이름 LIKE ( 1 ) ORDER BY 컬럼명 ( 2 );
```
| 빈칸 | 정답 | 이유 |
|---|---|---|
| (1) | **'이%'** | "이"로 시작하는 문자열 |
| (2) | **DESC** | 내림차순 |

> **정답: 1. `이%` 2. `DESC`**
> (패턴은 문자열이므로 SQL에서는 작은따옴표로 감싼 `'이%'`로 쓴다.)

## 4. 암기 포인트
- `%` = 여러 글자, `_` = 한 글자. "~로 시작" = `'값%'`.
- `DESC`는 내림차순, 생략 시 `ASC`.
