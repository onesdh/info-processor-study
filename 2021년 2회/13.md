# 문제 13

## 문제

괄호 (   ) 안에 알맞는 단어를 쓰시오.

디자인 패턴 중에서 (   )패턴은 반복적으로 사용되는 객체들의 상호작용을 패턴화 한 것으로,

클래스나 객체들이 상호작용하는 방법이다. 알고리즘의 패턴에는 Interpreter, Observer, Command 가 있다.

행위(behavioral)

## 핵심 개념

행위 패턴은 객체 사이의 책임 분배와 상호작용을 다룬다.

## 풀이

Interpreter, Observer, Command는 행위 패턴의 예다.

## 오답 분석

생성 패턴은 객체 생성, 구조 패턴은 클래스와 객체의 조합 구조를 다룬다.

## 암기 포인트

상호작용은 행위 패턴.
