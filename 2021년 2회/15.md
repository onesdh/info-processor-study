# 문제 15

## 문제

럼바우 데이터 모델링에 관한 설명으로써, 보기에 해당하는 답안을 작성하시오.

(실제 시험문제에서는 보기가 주어집니다.)

1. 입력값이 출력값일 때 ex) 자료 흐름도(DFD)

2. 시간에 따라 변하는 것 ex) 상태 다이어그램(상태도)

3. 객체들 간의 관계를 정의 ex) ER다이어그램(ERD)

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**럼바우(Rumbaugh) 객체지향 분석**의 3가지 모델링(기능/동적/객체)을 설명과 연결하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 럼바우 분석 기법
소프트웨어를 **그래픽 표기법으로 3가지 관점에서 모델링**하는 객체지향 분석 방법이다. 절차는 **객체 → 동적 → 기능 모델링** 순서.

| 모델링 | 관점 | 대표 다이어그램 | 설명 |
|---|---|---|---|
| **객체 모델링 (Object)** | **정적 구조** | **ER 다이어그램, 클래스 다이어그램** | **객체들 간의 관계**를 정의 |
| **동적 모델링 (Dynamic)** | **시간에 따른 변화** | **상태 다이어그램(상태도), 시나리오** | 시간에 따라 변하는 **객체의 상태·행위** |
| **기능 모델링 (Function)** | **데이터 흐름** | **자료 흐름도(DFD)** | **입력값이 어떻게 출력값이 되는가**(처리 과정) |

```text
 객체(무엇이 있나) ─▶ 동적(언제 어떻게 변하나) ─▶ 기능(어떻게 처리하나)
```
## 3. 문제 풀이
| 번호 | 단서 | 정답 |
|---|---|---|
| 1 | **입력값이 출력값**이 되는 처리 / 예: **DFD** | **Function Modeling** |
| 2 | **시간에 따라 변하는 것** / 예: **상태 다이어그램** | **Dynamic Modeling** |
| 3 | **객체들 간의 관계** 정의 / 예: **ER 다이어그램** | **Object Modeling** |

> **정답: 1. Function Modeling 2. Dynamic Modeling 3. Object Modeling**

## 4. 암기 포인트
- **객체=ER·클래스, 동적=상태도, 기능=DFD**. 분석 순서는 **객체→동적→기능**.
