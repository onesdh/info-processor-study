# 문제 15 — 럼바우 모델링

## 문제

입력과 출력 변환을 표현하는 모델, 시간에 따른 상태 변화를 표현하는 모델, 객체와 관계를 표현하는 모델을 순서대로 쓰시오.

## 정답

기능 모델링; 동적 모델링; 객체 모델링

## 핵심 개념

럼바우 객체지향 분석은 기능, 동적, 객체 관점으로 시스템을 분석한다.

## 풀이

DFD는 기능 모델링, 상태 다이어그램은 동적 모델링, ERD는 객체 모델링에 대응한다.

## 오답 분석

절차는 보통 객체 모델링, 동적 모델링, 기능 모델링 순으로 진행한다고 기억하되 문항의 정의와는 별개로 각 유형을 구분한다.

## 암기 포인트

기능=입출력, 동적=시간, 객체=구조.
