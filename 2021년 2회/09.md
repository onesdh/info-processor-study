# 문제 09 — 화이트박스 커버리지

## 문제

모든 문장을 적어도 한 번 수행하는 기준, 각 결정의 참·거짓 결과를 수행하는 기준, 개별 조건식을 각각 참·거짓으로 평가하는 기준을 순서대로 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

문장 커버리지; 결정 커버리지; 조건 커버리지

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

화이트박스 테스트는 프로그램 내부 구조와 제어 흐름을 기준으로 테스트한다.

## 풀이

각 설명은 statement, decision/branch, condition coverage에 해당한다.

## 오답 분석

블랙박스 테스트는 코드 구조를 보지 않고 입력과 출력 명세를 중심으로 한다.

## 암기 포인트

문장, 분기, 개별 조건의 실행 여부.

</details>
