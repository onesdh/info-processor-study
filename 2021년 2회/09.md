# 문제 09

## 문제

화이트박스 테스트 검중 중에, 각 번호에 해당하는 단어 선택해주시오. (실제 시험문제에서는 보기가 주어집니다.)

1. 최소 한번은 모든 문장 수행

2. 결정(Decision) 검증기준이라고도 하며, 조건별 참 / 거짓

3. 2번과 달리 전체 조건식을 무시하며, 조건 상관없이 개별 조건 참 / 거짓

## 1. 문제에서 묻는 것
**화이트박스 테스트 커버리지** 3가지(문장, 결정, 조건)를 설명과 연결하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 화이트박스 커버리지
소스 코드 **내부 구조**를 보고 **어디까지 테스트했는지** 재는 기준.

| 커버리지 | 기준 |
|---|---|
| **문장(구문)** | 모든 **문장을 최소 한 번** 실행 |
| **결정(분기)** | 각 **결정(조건식 전체)** 이 **참/거짓 두 결과를 모두** |
| **조건** | 결정 안의 **개별 조건식** 각각이 참/거짓 모두 |

### (2) 결정 vs 조건
```c
if (A && B) { ... }       // 결정 = (A && B) 전체,  조건 = A, B 각각
```
| 커버리지 | 확인하는 것 |
|---|---|
| 결정(분기) | **A&&B 전체**가 T인 경우, F인 경우 |
| 조건 | **A**가 T/F, **B**가 T/F (전체 결과는 신경 안 씀) |

## 3. 문제 풀이
| 번호 | 단서 | 정답 |
|---|---|---|
| 1 | **최소 한 번은 모든 문장** 수행 | **문장** 커버리지 |
| 2 | **결정(Decision) 검증 기준**, 조건식 **전체**의 참/거짓 | **결정** 커버리지 |
| 3 | 2번과 달리 **전체 조건식을 무시**, **개별 조건**의 참/거짓 | **조건** 커버리지 |

> **정답: 1. 문장 2. 결정 3. 조건**

## 4. 암기 포인트
- 결정(분기) = **전체 식**의 T/F, 조건 = **개별 식**의 T/F.
- 강도: 문장 < 결정(분기) ≈ 조건 < 조건/결정 < 다중 조건.
