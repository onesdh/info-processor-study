# 문제 09 — C 포인터 매개변수와 배열 접근

## 문제

다음 C언어 코드가 출력하는 네 줄의 값을 순서대로 쓰시오.

```c
#include <stdio.h>
void fn1(int *i) { *i = 50; }
void fn2(int i) { i = 60; }
void fn34(int *p) {
    printf("3. %d\n", *p);
    printf("4. %d\n", *(p + 3));
}
int main() {
    int i = 30;
    int list[] = {2, 4, 6, 8, 10};
    fn1(&i);
    printf("1. %d\n", i);
    fn2(i);
    printf("2. %d\n", i);
    fn34(list);
    return 0;
}
```

<details>
<summary><strong>정답 보기</strong></summary>

1. 50
2. 50
3. 2
4. 8

</details>



<details>
<summary><strong>상세 해설</strong></summary>
이 문제는 **포인터로 전달하는 경우와 일반 변수로 전달하는 경우의 차이**, 그리고 **배열과 포인터의 관계**를 이해하면 쉽게 풀 수 있습니다.

### 1. `fn1(&i)` → `i`의 실제 값 변경

```c
int i = 30;
fn1(&i);
```

`fn1()`은 `int *`를 매개변수로 받습니다.

```c
void fn1(int *i) {
    *i = 50;
}
```

`&i`는 변수 `i`의 **주소**이고, `*i`는 그 주소에 저장된 **실제 값**입니다.

따라서

```text
i = 30
↓
fn1(&i)
↓
*i = 50
↓
i = 50
```

이후:

```c
printf("1. %d\n", i);
```

출력은

```text
1. 50
```

입니다.

---

### 2. `fn2(i)` → 원래 `i`는 변경되지 않음

현재 `i`는 50입니다.

```c
fn2(i);
```

`fn2()`의 매개변수는 포인터가 아니라 일반 `int`입니다.

```c
void fn2(int i) {
    i = 60;
}
```

여기서는 `i`의 **값을 복사해서 전달**합니다.

```text
main의 i = 50
       ↓
    fn2(i)
       ↓
fn2 내부의 i = 50
       ↓
fn2 내부의 i = 60
```

`fn2()` 내부의 `i`만 60으로 바뀌고, `main()`의 `i`는 그대로 50입니다.

따라서:

```c
printf("2. %d\n", i);
```

출력은

```text
2. 50
```

입니다.

---

### 3. `fn34(list)` → 배열의 첫 번째 원소 주소 전달

배열은 다음과 같습니다.

```c
int list[] = {2, 4, 6, 8, 10};
```

메모리를 순서대로 표현하면:

```text
list
 ↓
┌────┬────┬────┬────┬─────┐
│  2 │  4 │  6 │  8 │  10 │
└────┴────┴────┴────┴─────┘
  ↑              ↑
 p            p + 3
```

`fn34(list)`에서 배열 이름 `list`는 첫 번째 원소의 주소인 `&list[0]`처럼 전달됩니다.

즉:

```c
p = &list[0]
```

와 같은 의미입니다.

---

### 4. `*p`의 값

```c
printf("3. %d\n", *p);
```

`p`는 `list[0]`의 주소이므로:

```text
*p = list[0] = 2
```

따라서:

```text
3. 2
```

---

### 5. `*(p + 3)`의 값

여기가 핵심입니다.

```c
*(p + 3)
```

포인터에서 `+3`은 **3바이트 이동**이 아니라 **int형 변수 3개만큼 이동**한다는 의미입니다.

따라서:

```text
p       → list[0] → 2
p + 1   → list[1] → 4
p + 2   → list[2] → 6
p + 3   → list[3] → 8
```

즉,

```c
*(p + 3) == list[3] == 8
```

따라서:

```text
4. 8
```

---

## 최종 출력

네 줄은 순서대로:

```text
1. 50
2. 50
3. 2
4. 8
```

### 핵심 암기

| 코드                    | 의미                |
| --------------------- | ----------------- |
| `fn1(&i)` + `*i = 50` | 원본 변수 `i` 변경      |
| `fn2(i)` + `i = 60`   | 복사된 값만 변경 → 원본 유지 |
| `list`                | `&list[0]`처럼 전달   |
| `*p`                  | `list[0]`         |
| `*(p + 3)`            | `list[3]`         |

따라서 **정답은 `50, 50, 2, 8`**입니다.
