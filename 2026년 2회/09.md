# 문제 09

## 문제

다음은 C언어 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
#include <stdio.h>

void fn1(int* i) { *i = 50; }
void fn2(int i) { i = 60; }

void fn34(int* p) {
    printf("3. %d\n", *p);
    printf("4. %d\n", *(p + 3));
}

int main() {
    int i = 30;
    int list[] = {2, 4, 6, 8, 10};

    fn1(&i);
    printf("1. %d\n", i);

    fn2(i);
    printf("2. %d\n", i);

    fn34(list);

    return 0;
}
```

<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**값 전달(call by value)** 과 **주소 전달(call by address)** 의 차이, 그리고 **배열 이름이 포인터처럼 쓰이는 것**을 이해했는지 묻는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 변수 = 이름 붙은 메모리 칸
```text
  변수 i  [ 30 ]   주소 예) 0x100
```
### (2) 포인터
`int* p` 는 "**정수가 들어 있는 칸의 주소**"를 저장하는 변수다. `&i`는 i의 주소, `*p`는 p가 가리키는 칸의 **값**.

### (3) 함수 호출 방식
| 방식 | 코드 | 동작 |
|---|---|---|
| **값 전달** | `fn2(i)` | i의 **복사본**을 넘김 → 함수 안에서 바꿔도 **원본은 그대로** |
| **주소 전달** | `fn1(&i)` | i의 **주소**를 넘김 → `*i = 50` 이 **원본을 바꿈** |

### (4) 배열과 포인터
배열 이름 `list`는 **첫 원소의 주소**다. `p + 3`은 3칸(`int` 3개) 뒤의 주소, `*(p+3)` 은 `p[3]`과 같다.

## 3. 실행 과정
```text
list: [ 2 ][ 4 ][ 6 ][ 8 ][10]
 인덱스  0    1    2    3    4
```
| 순서 | 코드 | 변화 | 출력 |
|---|---|---|---|
| 1 | `fn1(&i)` | 원본 i가 30 → **50** | `1. 50` |
| 2 | `fn2(i)` | 복사본만 60, **원본은 50 유지** | `2. 50` |
| 3 | `fn34(list)` → `*p` | `p[0]` = 2 | `3. 2` |
| 4 | `*(p + 3)` | `p[3]` = 8 | `4. 8` |

> **정답**
> ```
> 1. 50
> 2. 50
> 3. 2
> 4. 8
> ```

## 4. 암기 포인트
- 함수에서 **원본 값을 바꾸려면 포인터(주소)** 를 넘겨야 한다.
- `*(p + n)` ≡ `p[n]`, 포인터 연산은 **자료형 크기 단위**로 이동.
