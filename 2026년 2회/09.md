# 문제 09 — C 포인터 매개변수와 배열 접근

## 문제

다음 C언어 코드가 출력하는 네 줄의 값을 순서대로 쓰시오.

```c
#include <stdio.h>
void fn1(int *i) { *i = 50; }
void fn2(int i) { i = 60; }
void fn34(int *p) {
    printf("3. %d\n", *p);
    printf("4. %d\n", *(p + 3));
}
int main() {
    int i = 30;
    int list[] = {2, 4, 6, 8, 10};
    fn1(&i);
    printf("1. %d\n", i);
    fn2(i);
    printf("2. %d\n", i);
    fn34(list);
    return 0;
}
```

<details>
<summary><strong>정답 보기</strong></summary>

1. 50
2. 50
3. 2
4. 8

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

포인터 매개변수는 호출한 쪽의 값을 간접 변경할 수 있다. 일반 정수 매개변수는 값 복사이므로 함수 안의 대입이 호출자 변수에 반영되지 않는다.

## 문제 풀이

`fn1(&i)`를 통해 원래 변수 i가 50으로 바뀐다. `fn2(i)`는 50의 복사본만 60으로 바꾸므로 호출자 i는 계속 50이다. `list`의 첫 원소는 2이고 `p+3`은 네 번째 원소를 가리켜 8을 읽는다.

## 오답 및 혼동 포인트

`fn2`의 매개변수는 포인터가 아니라 `int`이므로 원본과 연결되지 않는다. 포인터 덧셈의 3은 3바이트가 아니라 int 원소 세 칸 이동한다.

## 암기 포인트

주소를 넘긴 함수는 원본을 바꿀 수 있고, 값을 넘긴 함수는 복사본만 바꾼다.
