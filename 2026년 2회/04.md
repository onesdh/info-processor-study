# 문제 04

## 문제

다음은 라우팅 프로토콜에 대한 설명이다. 괄호 안에 들어갈 알맞은 용어를 쓰시오.

( )는 링크 상태(Link State) 알고리즘을 사용하는 대표적인 내부 라우팅 프로토콜(IGP)이다. 다익스트라(Dijkstra) 알고리즘을 이용하여 최단 경로를 탐색하며, 대규모 네트워크에 적합하고 멀티캐스트를 지원한다.

OSPF (Open Shortest Path First)

## 1. 문제에서 묻는 것
**링크 상태 알고리즘 + 다익스트라 + 대규모 네트워크 + 멀티캐스트 지원 + 내부(IGP) 프로토콜** → 어떤 라우팅 프로토콜인지 묻는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 라우팅과 라우터
인터넷은 수많은 네트워크가 연결된 구조다. **라우터**가 패킷의 목적지를 보고 **어느 길로 보낼지(경로)** 결정하는 일이 라우팅이고, 라우터들이 서로 경로 정보를 주고받는 규약이 **라우팅 프로토콜**이다.

### (2) AS와 IGP / EGP
- **AS(Autonomous System)**: 하나의 기관이 관리하는 네트워크 덩어리 (예: 한 통신사).
```text
 [ AS 1 ]  ◀── EGP(BGP) ──▶  [ AS 2 ]
  ┌────────────┐              ┌────────────┐
  │ RIP / OSPF │  ← IGP       │ RIP / OSPF │
  └────────────┘              └────────────┘
```
- **IGP**: **AS 내부**에서 쓰는 프로토콜 (RIP, OSPF, IGRP/EIGRP)
- **EGP**: **AS 사이**에서 쓰는 프로토콜 (BGP)

### (3) 경로를 계산하는 방식
| 방식 | 대표 | 아이디어 |
|---|---|---|
| **거리 벡터** | RIP | 이웃에게 "나는 목적지까지 N홉"만 전달. 홉 수(최대 15) 기준, 소규모용 |
| **링크 상태** | **OSPF** | 모든 라우터가 **전체 망의 지도(링크 상태)** 를 공유 → 각자 **다익스트라**로 최단 경로 계산 |

## 3. 문제 풀이
| 문제의 단서 | OSPF의 특징 |
|---|---|
| 링크 상태 알고리즘 | OSPF는 링크 상태(LSA)를 flooding |
| 다익스트라 | SPF(Shortest Path First) 트리 계산 |
| 대규모 네트워크 | 영역(Area) 개념으로 계층화 |
| 멀티캐스트 지원 | 224.0.0.5 등 멀티캐스트로 갱신 전달 |
| 내부 라우팅(IGP) | AS 내부용 |

## 4. RIP과 비교
| 구분 | RIP | OSPF |
|---|---|---|
| 알고리즘 | 거리 벡터 (벨만-포드) | **링크 상태 (다익스트라)** |
| 기준 | 홉 수 (최대 15) | 대역폭 기반 **비용(cost)** |
| 규모 | 소규모 | **대규모** |
| 수렴 속도 | 느림 | **빠름** |

> **정답: OSPF (Open Shortest Path First)**

## 5. 암기 포인트
- "**링크 상태 + 다익스트라**" → OSPF / "**거리 벡터 + 홉 수 15**" → RIP / "**AS 간**" → BGP
