# 문제 04

## 문제

( )는 한 모듈이 다른 모듈 내부에 있는 변수나 기능을 직접 참조하거나 사용하는 경우에 발생하는 결합도로, 결합도 종류 중 결합 강도가 가장 높은 형태이다.

<details>
<summary><strong>정답 보기</strong></summary>

OSPF (Open Shortest Path First)

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

OSPF는 링크 상태 정보를 공유해 각 라우터가 네트워크 토폴로지를 만들고 최단 경로를 계산하는 내부 게이트웨이 프로토콜이다.

## 문제 풀이

링크 상태, 다익스트라 최단 경로, IGP라는 단서가 OSPF를 가리킨다.

## 오답 및 혼동 포인트

RIP는 거리 벡터 방식이며 홉 수를 기준으로 경로를 선택한다. BGP는 서로 다른 자율 시스템 사이의 경로 정보를 교환하는 외부 게이트웨이 프로토콜이다.

## 암기 포인트

OSPF는 링크 상태와 다익스트라, RIP는 거리 벡터와 홉 수로 구분한다.

</details>
