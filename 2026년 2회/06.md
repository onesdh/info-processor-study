# 문제 06 — Python 문자열 슬라이싱

## 문제

다음 Python 코드의 출력값을 쓰시오.

```python
a = "_THIS_IS_KIM_SPEAKING"
b = a[:4]
c = a[6:8]
d = a[18:]
e = b + c + d
print(e)
```

<details>
<summary><strong>정답 보기</strong></summary>

_THIISING

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

문자열 슬라이스 `s[i:j]`는 인덱스 i부터 j 직전까지를 가져온다. 생략된 시작·끝 인덱스는 문자열의 처음·끝으로 처리된다.

## 문제 풀이

`a[:4]`는 `_THI`, `a[6:8]`은 `IS`, `a[18:]`은 `ING`이다. 세 조각을 이어 붙이면 `_THIISING`이다.

## 오답 및 혼동 포인트

슬라이스의 끝 인덱스는 포함되지 않는다. 따라서 `a[6:8]`에는 인덱스 6과 7의 두 문자만 들어간다.

## 암기 포인트

슬라이스는 시작 인덱스 포함, 끝 인덱스 제외다.
