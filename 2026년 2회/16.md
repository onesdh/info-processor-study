# 문제 16

## 문제

다음은 IP 주소 서브네팅(Subnetting)에 대한 설명이다. 물음에 답하시오.

10.0.0.0/27 네트워크를 동일한 크기의 2개 서브넷으로 분할하였다.

- 첫 번째 서브넷: 10.0.0.0 ~ 10.0.0.15

- 두 번째 서브넷: 10.0.0.16 ~ 10.0.0.31

이때 10.0.0.1이 속한 서브넷의 프리픽스 길이(비트 수)를 구하시오.

<details>
<summary><strong>정답 보기</strong></summary>

28

</details>



<details>
<summary><strong>상세 해설</strong></summary>
이 문제는 **CIDR 프리픽스 길이와 서브넷 분할**을 이해하면 쉽게 풀 수 있습니다.

## 해설

### 1. 기존 네트워크 확인

주어진 네트워크는:

```text
10.0.0.0/27
```

`/27`은 IPv4 주소 32비트 중 **27비트를 네트워크 비트**로 사용한다는 의미입니다.

따라서 호스트 비트는:

```text
32 - 27 = 5비트
```

이고, 전체 주소 개수는:

```text
2⁵ = 32개
```

즉,

```text
10.0.0.0 ~ 10.0.0.31
```

범위를 가집니다.

---

### 2. 2개의 동일한 크기로 분할

32개의 주소를 같은 크기의 2개 서브넷으로 나누면:

```text
32 ÷ 2 = 16개
```

각 서브넷이 16개의 주소를 갖습니다.

문제에서 실제 범위도:

```text
첫 번째: 10.0.0.0  ~ 10.0.0.15
두 번째: 10.0.0.16 ~ 10.0.0.31
```

으로 주어졌습니다.

---

### 3. 프리픽스 길이 계산

기존 `/27`에서 서브넷을 **2개로 분할**하려면 호스트 비트 중 1비트를 네트워크 비트로 가져와야 합니다.

```text
2¹ = 2개 서브넷
```

따라서:

```text
27 + 1 = 28
```

즉, 각 서브넷의 프리픽스 길이는:

```text
/28
```

입니다.

---

### 4. 10.0.0.1이 속한 서브넷

`10.0.0.1`은:

```text
10.0.0.0 ~ 10.0.0.15
```

범위에 속하므로 첫 번째 서브넷입니다.

첫 번째 서브넷 역시 `/28`입니다.

## 정답

```text
/28
```

### 시험에서 빠르게 푸는 방법

```text
/27 → 전체 32개
32개 ÷ 2 = 16개
16 = 2⁴
→ 호스트 비트 4개
→ 32 - 4 = 28
→ /28
```

따라서 **정답은 `28` 또는 `/28`**입니다.
