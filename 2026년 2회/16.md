# 문제 16

## 문제

다음은 IP 주소 서브네팅(Subnetting)에 대한 설명이다. 물음에 답하시오.

10.0.0.0/27 네트워크를 동일한 크기의 2개 서브넷으로 분할하였다.

- 첫 번째 서브넷: 10.0.0.0 ~ 10.0.0.15

- 두 번째 서브넷: 10.0.0.16 ~ 10.0.0.31

이때 10.0.0.1이 속한 서브넷의 프리픽스 길이(비트 수)를 구하시오.

28

## 1. 문제에서 묻는 것
`10.0.0.0/27` 네트워크를 같은 크기로 2등분했을 때, **10.0.0.1 주소가 속한 서브넷의 프리픽스 길이**를 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 프리픽스(/n)
IP 주소는 32비트. `/27`은 **앞 27비트가 네트워크 부분**, 나머지 5비트가 호스트 부분이라는 뜻이다.
```text
/27 : 11111111.11111111.11111111.111 00000  (호스트 5비트 → 주소 2^5 = 32개)
```
### (2) 서브넷팅(분할)
네트워크 부분 비트를 **1비트 늘리면** 주소 범위가 **절반**으로 쪼개져 **서브넷 2개**가 생긴다.

| 프리픽스 | 주소 수 |
|---:|---:|
| /27 | 32 |
| **/28** | **16** |
| /29 | 8 |

## 3. 풀이
| 단계 | 내용 |
|---|---|
| 원래 | 10.0.0.0/27 → 10.0.0.0 ~ 10.0.0.31 (32개) |
| 2등분 | 서브넷 1개당 32 ÷ 2 = **16개** |
| 호스트 비트 | 16 = 2⁴ → 호스트 **4비트** |
| 프리픽스 | 32 − 4 = **/28** |

```text
10.0.0.0/27
 ├─ 10.0.0.0/28   (0 ~ 15)   ← 10.0.0.1 이 여기
 └─ 10.0.0.16/28  (16 ~ 31)
```
10.0.0.1은 첫 번째 서브넷(0~15)에 속하며, 프리픽스는 **28**이다. (서브넷 마스크 255.255.255.240)

> **정답: 28**

## 4. 암기 포인트
- **서브넷 N개로 나누기** : 필요한 비트 수 = log₂N, 프리픽스에 **더한다**. (2개 → +1, 4개 → +2)
- 마스크 마지막 옥텟: /25=128, /26=192, /27=224, **/28=240**, /29=248, /30=252.
