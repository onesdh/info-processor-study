# 문제 05

## 문제

다음은 파이썬 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
class LocationDict:
    locations = {
        "NYC": "New York",
        "LON": "London",
        "PAR": "Paris",
        "TKY": "Tokyo"
    }

tmpdict = LocationDict()
str01 = ""
for key, location in tmpdict.locations.items():
    keyk = key[-1]
    locationk = location[0]
    str01 += keyk + locationk

print(str01, end="")
```

## 1. 문제에서 묻는 것
클래스 변수인 **딕셔너리를 순회**하며 각 키의 마지막 글자와 값의 첫 글자를 이어 붙인 문자열을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 딕셔너리(dict)
`{키: 값}` 쌍의 모음. `items()`는 `(키, 값)` 쌍을 하나씩 꺼내 준다. (Python 3.7+ 에서는 **입력한 순서대로** 나온다.)

### (2) 문자열 인덱스
| 표현 | 의미 | 예 (`"NYC"`) |
|---|---|---|
| `s[0]` | 첫 글자 | `N` |
| `s[-1]` | **마지막 글자** | `C` |

### (3) 클래스 변수
`locations`는 `__init__` 안이 아니라 **클래스 본문**에 선언되어 모든 객체가 공유한다. `tmpdict.locations`로 접근 가능하다.

### (4) `end=""`
`print` 끝에 줄바꿈을 붙이지 않는다는 뜻이다.

## 3. 실행 과정
`str01 = ""` 에서 시작해 4번 반복한다. `str01 += keyk + locationk`

| 반복 | key | location | `key[-1]` | `location[0]` | str01 |
|---|---|---|---|---|---|
| 1 | NYC | New York | **C** | **N** | `CN` |
| 2 | LON | London | **N** | **L** | `CNNL` |
| 3 | PAR | Paris | **R** | **P** | `CNNLRP` |
| 4 | TKY | Tokyo | **Y** | **T** | `CNNLRPYT` |

> **정답: `CNNLRPYT`**

## 4. 실수 포인트
- 키의 **마지막 글자 → 값의 첫 글자** 순서임을 놓치지 말 것 (`keyk + locationk`).
- `location[0]`이 아니라 `key[-1]`이 먼저 붙는다.
