# 문제 05 — Python 딕셔너리 순회와 문자열 인덱스

## 문제

다음 Python 코드의 출력값을 쓰시오.

```python
class LocationDict:
    locations = {
        "NYC": "New York",
        "LON": "London",
        "PAR": "Paris",
        "TKY": "Tokyo"
    }

tmpdict = LocationDict()
str01 = ""
for key, location in tmpdict.locations.items():
    keyk = key[-1]
    locationk = location[0]
    str01 += keyk + locationk
print(str01, end="")
```

## 핵심 개념

딕셔너리의 `items()`는 키와 값을 순서대로 제공한다. 문자열의 `[-1]`은 마지막 문자, `[0]`은 첫 문자를 가리킨다.

## 문제 풀이

삽입 순서대로 각 키의 마지막 글자와 도시 이름의 첫 글자를 붙인다. NYC/New York은 CN, LON/London은 NL, PAR/Paris는 RP, TKY/Tokyo는 YT가 되어 `CNNLRPYT`가 출력된다.

## 오답 및 혼동 포인트

키의 첫 글자나 도시 이름의 마지막 글자를 고르는 문제가 아니다. 인덱스가 각각 `-1`과 `0`이므로 키 끝 문자와 값의 첫 문자를 취한다.

## 암기 포인트

문자열 `s[-1]`은 끝 글자, `s[0]`은 첫 글자다.
