# 문제 02

## 문제

다음 Java 코드의 출력값을 쓰시오.

```java
class A {
    private int a;

    public A(int a) { this.a = a; }

    void print() { System.out.print(a + "a"); }
}

class B extends A {
    private int b;

    B(int a, int b) {
        super(a);
        this.b = b;
    }

    void print() {
        super.print();
        System.out.print(b + "b");
    }
}

public class Main {
    public static void main(String[] args) {
        B obj = new B(10, 20);
        obj.print();
    }
}
```

## 핵심 개념

하위 클래스 생성자는 `super(a)`로 상위 클래스의 생성자를 호출할 수 있다. 오버라이딩한 메서드에서 `super.print()`를 호출하면 상위 클래스 버전이 실행된다.

## 문제 풀이

`new B(10, 20)`은 상위 객체 부분의 `a`를 10으로, B의 `b`를 20으로 초기화한다. `obj.print()`는 B의 메서드를 실행하고, 먼저 `super.print()`가 `10a`를 출력한 뒤 `20b`를 이어서 출력한다.

## 오답 및 혼동 포인트

두 `print` 호출 사이에 줄바꿈이나 공백이 없으므로 결과를 따로 출력하지 않는다. `super.print()`는 B의 메서드를 다시 호출하는 것이 아니라 A의 구현을 직접 호출한다.

## 암기 포인트

하위 메서드 안의 `super.메서드()`는 상위 클래스 구현을 실행한다.
