# 문제 02

## 문제

다음은 Java 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
class A {
    private int a;

    public A(int a) {
        this.a = a;
    }

    void print() {
        System.out.print(a + "a");
    }
}

class B extends A {
    private int b;

    B(int a, int b) {
        super(a);
        this.b = b;
    }

    void print() {
        super.print();
        System.out.print(b + "b");
    }
}

public class Main {
    public static void main(String[] args) {
        B obj = new B(10, 20);
        obj.print();
    }
}
```

## 1. 문제에서 묻는 것
**상속**과 `super`가 붙은 생성자·메서드 호출이 어떤 순서로 실행되어 문자열이 출력되는지 추적하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 상속(extends)
`class B extends A`는 "B는 A의 모든 기능을 물려받은 자식"이라는 뜻이다. A가 **부모(상위) 클래스**, B가 **자식(하위) 클래스**다.

### (2) super
| 표현 | 의미 |
|---|---|
| `super(a)` | **부모 클래스의 생성자**를 호출 (생성자 첫 줄에서만 가능) |
| `super.print()` | **부모 클래스의 `print()` 메서드**를 호출 |

### (3) 오버라이딩
자식이 부모와 **같은 이름·같은 매개변수**의 메서드를 다시 정의하는 것. `B.print()`는 `A.print()`를 덮어쓰기(재정의)한다. 객체가 `B`이면 `B`의 `print()`가 실행된다.

### (4) `a + "a"`
`int + String`이면 **문자열 연결**이다. 즉 `10 + "a"` → `"10a"`.

## 3. 클래스 구조
```text
        A ─ private int a;  A(int a)  print(): a + "a" 출력
        ▲
        │ extends
        B ─ private int b;  B(int a,int b)  print(): super.print() 후 b + "b" 출력
```

## 4. 실행 과정
`B obj = new B(10, 20);`
1. `B(10, 20)` 생성자 진입 → 첫 줄 `super(a)` 로 **부모 생성자 `A(10)`** 호출
2. `A(10)`: `this.a = 10` (부모의 a = 10)
3. 돌아와서 `this.b = 20` (자식의 b = 20)

`obj.print();`

| 순서 | 실행 | 출력 |
|---|---|---|
| ① | `B.print()` 시작 (오버라이딩된 자식 메서드) | |
| ② | `super.print()` → `A.print()` : `a + "a"` = `"10a"` | `10a` |
| ③ | 이어서 `b + "b"` = `"20b"` | `20b` |

`print()`는 줄바꿈이 없는 `System.out.print`이므로 이어서 붙어 나온다.

> **정답: `10a20b`**

## 5. 암기 포인트
- 자식 객체 생성 시 **부모 생성자가 먼저** 실행된다.
- `private` 필드(`a`)는 자식이 직접 접근하지 못하므로 부모 생성자/메서드를 통해 사용한다.
- `print` vs `println` : 줄바꿈 유무를 반드시 확인.
