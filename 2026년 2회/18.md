# 문제 18 — C 재귀 함수 계산

## 문제

다음 C언어 코드의 출력값을 쓰시오.

```c
#include <stdio.h>
int c(int n) {
    if (n <= 1) return n;
    return c(n - 1) + c(n - 3);
}
int main() {
    printf("%d", c(5));
    return 0;
}
```

## 핵심 개념

재귀 함수는 기저 조건에 도달할 때까지 호출을 확장한다. 여기서는 `n <= 1`일 때 해당 정수 n을 그대로 반환한다.

## 문제 풀이

기저값은 c(1)=1, c(0)=0, c(-1)=-1이다. c(2)=c(1)+c(-1)=0, c(3)=c(2)+c(0)=0, c(4)=c(3)+c(1)=1, c(5)=c(4)+c(2)=1+0=1이다.

## 오답 및 혼동 포인트

기저 조건에서 음수 입력을 0으로 바꾸지 않고 n을 그대로 반환한다. 따라서 c(-1)=-1이며, 이 부분을 잘못 처리하면 재귀 결과가 달라진다.

## 암기 포인트

문제에 적힌 기저 조건을 그대로 적용한다. `n <= 1`이면 0이나 1로 뭉뚱그리지 않고 n을 반환한다.
