# 문제 18

## 문제

다음은 C언어 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
#include <stdio.h>

int c(int n) {
    if (n <= 1) return n;
    return c(n - 1) + c(n - 3);
}

int main() {
    printf("%d", c(5));
    return 0;
}
```

## 1. 문제에서 묻는 것
**재귀 함수** `c(n) = c(n-1) + c(n-3)`에 5를 넣었을 때의 반환값을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 재귀 함수
자기 자신을 다시 호출하는 함수. 반드시 **종료 조건(기저 조건)** 이 있어야 하고, 호출이 **끝까지 내려간 뒤 값이 위로 올라오며** 계산된다.

### (2) 이 함수의 규칙
```c
int c(int n) {
    if (n <= 1) return n;        // 종료 조건: n이 1 이하이면 n 그대로 반환
    return c(n - 1) + c(n - 3);
}
```
- 종료 조건이 `n == 1`이 아니라 **`n <= 1`** 이라서 **0도, 음수도 그 값 그대로** 반환한다. (`c(0)=0`, `c(-1)=-1`)

## 3. 작은 값부터 채우기 (표)
| n | 계산 | c(n) |
|---:|---|---:|
| -1 | n ≤ 1 → n | **-1** |
| 0 | n ≤ 1 → n | **0** |
| 1 | n ≤ 1 → n | **1** |
| 2 | c(1) + c(-1) = 1 + (-1) | **0** |
| 3 | c(2) + c(0) = 0 + 0 | **0** |
| 4 | c(3) + c(1) = 0 + 1 | **1** |
| 5 | c(4) + c(2) = 1 + 0 | **1** |

## 4. 호출 트리
```text
c(5)
├─ c(4)
│   ├─ c(3)
│   │   ├─ c(2)
│   │   │   ├─ c(1) = 1
│   │   │   └─ c(-1) = -1      → c(2) = 0
│   │   └─ c(0) = 0            → c(3) = 0
│   └─ c(1) = 1                → c(4) = 1
└─ c(2)
    ├─ c(1) = 1
    └─ c(-1) = -1              → c(2) = 0
                               → c(5) = 1 + 0 = 1
```

> **정답: `1`**

## 5. 실수 포인트
- `n-3`에서 `c(-1)`, `c(0)`이 생기는 것을 놓치기 쉽다. 종료 조건이 `n <= 1`이므로 **음수도 그대로 반환**된다.
- 피보나치처럼 보여도 항이 `n-1`, `n-3`이라 값이 전혀 다르다.
