## 1. 문제에서 묻는 것
IP 주소와 서브넷 정보를 보고 **같은 네트워크(같은 서브넷)에 속하는 IP**를 골라 빈칸을 채우는 문제다.

## 2. 먼저 알아야 할 개념
### (1) IP 주소와 서브넷 마스크
IP 주소는 **네트워크 부분 + 호스트 부분**으로 나뉜다. `/24`, `/22` 같은 **프리픽스 길이**는 "앞에서부터 몇 비트가 네트워크 부분인가"를 뜻한다.

| 표기 | 서브넷 마스크 | 호스트 비트 |
|---|---|---|
| /24 | 255.255.255.0 | 8 |
| /22 | 255.255.252.0 | 10 |

### (2) 같은 네트워크인지 판별하는 법
**IP AND 서브넷마스크 = 네트워크 주소**. 네트워크 주소가 같으면 같은 네트워크다.

### (3) /24 와 /22 계산 요령
- **/24**: 앞 3옥텟이 같으면 같은 네트워크 (예: `192.168.35.*`)
- **/22**: 세 번째 옥텟을 **4 단위 블록**으로 본다 (256 − 252 = 4). 8~11이 한 블록.
  ```text
  블록: 0~3 | 4~7 | 8~11 | 12~15 ...
  ```

## 3. 문제 데이터 (그림)
| 번호 | IP / 서브넷 |
|---|---|
| 1 | 192.168.35.3/24 |
| 2 | ( ) |
| 3 | 129.200.10.72/22 |
| 4 | ( ) |
| 5 | ( ) |
| 6 | 192.168.36.16/24 |

문제의 구조상 같은 네트워크끼리 짝이 지어진다: **(1,2) 네트워크 A**, **(3,4) 네트워크 B**, **(5,6) 네트워크 C**.

## 4. 풀이
| 빈칸 | 짝 | 네트워크 주소 | 가능한 범위 | 예시 답 |
|---|---|---|---|---|
| 2 | 1번 `192.168.35.3/24` | 192.168.35.0 | 192.168.35.1 ~ .254 | **192.168.35.72** |
| 4 | 3번 `129.200.10.72/22` | 10 → 블록 8~11 → **129.200.8.0/22** | 129.200.8.1 ~ 129.200.11.254 | **129.200.8.249** |
| 5 | 6번 `192.168.36.16/24` | 192.168.36.0 | 192.168.36.1 ~ .254 | **192.168.36.249** |

- 4번은 세 번째 옥텟이 8, 9, 10, 11 중 어느 것이어도 되고, 네 번째는 0~255 (단 주소 `129.200.8.0`과 브로드캐스트 `129.200.11.255`는 제외).
- 호스트 주소로는 **네트워크 주소(호스트 비트 전부 0)** 와 **브로드캐스트 주소(전부 1)** 를 쓸 수 없다.

> **정답(예시)**: 2. 192.168.35.72 / 4. 129.200.8.249 / 5. 192.168.36.249
> (범위 안의 값이면 다른 답도 정답이다.)

## 5. 암기 포인트
- **네트워크 주소 = IP AND 마스크**, 사용 가능 호스트 수 = 2^(호스트비트) − 2.
- /22 에서는 세 번째 옥텟을 **4씩 묶어서** 판단한다.
