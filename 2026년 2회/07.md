# 문제 07

## 문제

다음은 C언어 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
#include <stdio.h>

typedef struct N {
    int v;
    struct N* a;
    struct N* b;
} N;

int c = 0;
int ans = 0;

void pst(N *n) {
    if (!n) return;
    pst(n->a);
    pst(n->b);
    if (++c == 3) ans = n->v;
}

int main() {
    N ne = {35, 0, 0};
    N nd = {64, 0, 0};
    N nc = {53, 0, 0};
    N nb = {12, &ne, &nc};
    N na = {21, &nb, &nd};

    pst(&na);
    printf("%d\n", ans);
    return 0;
}
```

12

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
이진 트리를 **후위 순회**하면서, **세 번째로 방문하는 노드의 값**이 `ans`에 저장된다. 그 값을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 구조체와 포인터
```c
typedef struct N { int v; struct N* a; struct N* b; } N;
```
노드 하나는 **값 `v`** 와 **왼쪽 자식 `a`**, **오른쪽 자식 `b`** 를 가리키는 포인터를 가진다. `0`(NULL)은 "자식 없음"이다.

### (2) 이진 트리 순회 3가지
| 순회 | 순서 | 이름의 의미 |
|---|---|---|
| 전위 | **루트** → 왼 → 오 | 루트가 앞 |
| 중위 | 왼 → **루트** → 오 | 루트가 가운데 |
| **후위** | 왼 → 오 → **루트** | 루트가 뒤 |

`pst`의 순서는 `pst(왼쪽); pst(오른쪽); (현재 노드 처리)` → **후위 순회**.

### (3) `++c == 3`
먼저 `c`를 1 올린 뒤 3과 비교한다. 전역 변수 `c`는 **방문한 노드 수**를 센다.

## 3. 트리 그리기
```c
N nb = {12, &ne, &nc};   // 12의 왼쪽=35, 오른쪽=53
N na = {21, &nb, &nd};   // 21의 왼쪽=12, 오른쪽=64
```
```text
            21 (na)
           /      \
       12 (nb)    64 (nd)
       /    \
   35 (ne)  53 (nc)
```

## 4. 실행 과정 (후위 순회)
```text
pst(21) → pst(12) → pst(35)  : 자식 없음 → 35 처리  (c=1)
                  → pst(53)  : 자식 없음 → 53 처리  (c=2)
                  → 12 처리                         (c=3) ← ans = 12
        → pst(64)  : 64 처리                         (c=4)
        → 21 처리                                    (c=5)
```
| 방문 순서 | 노드 | c | c==3? |
|---|---|---|---|
| 1 | 35 | 1 | X |
| 2 | 53 | 2 | X |
| 3 | **12** | 3 | **O → ans = 12** |
| 4 | 64 | 4 | X |
| 5 | 21 | 5 | X |

> **정답: `12`**

## 5. 암기 포인트
- 후위 순회 결과 열 = **35 → 53 → 12 → 64 → 21** (루트가 마지막).
- 포인터가 `0`이면 `if (!n) return;`으로 재귀가 끝난다(종료 조건).
