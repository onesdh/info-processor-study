# 문제 07 — C 후위 순회

## 문제

다음 C언어 코드의 출력값을 쓰시오.

```c
#include <stdio.h>
typedef struct N { int v; struct N *a; struct N *b; } N;
int c = 0, ans = 0;
void pst(N *n) {
    if (!n) return;
    pst(n->a);
    pst(n->b);
    if (++c == 3) ans = n->v;
}
int main() {
    N ne = {35, 0, 0}, nd = {64, 0, 0}, nc = {53, 0, 0};
    N nb = {12, &ne, &nc}, na = {21, &nb, &nd};
    pst(&na);
    printf("%d\n", ans);
    return 0;
}
```

<details>
<summary><strong>정답 보기</strong></summary>

12

</details>



<details>
<summary><strong>상세 해설</strong></summary>

이 문제는 **이진 트리의 후위 순회(Postorder)** 순서를 따라가면서 `c`가 3이 되는 순간의 노드 값을 찾는 문제입니다.

### 1. 트리 구조 확인

코드에서 연결 관계를 정리하면 다음과 같습니다.

```text
          21 (na)
         /      \
     12 (nb)    64 (nd)
     /    \
 35 (ne)  53 (nc)
```

각 노드의 연결은 다음과 같습니다.

* `na = 21` → 왼쪽 `nb(12)`, 오른쪽 `nd(64)`
* `nb = 12` → 왼쪽 `ne(35)`, 오른쪽 `nc(53)`
* `ne = 35` → 자식 없음
* `nc = 53` → 자식 없음
* `nd = 64` → 자식 없음

---

### 2. `pst()`는 후위 순회

함수를 보면:

```c
void pst(N *n) {
    if (!n) return;
    pst(n->a);
    pst(n->b);
    if (++c == 3) ans = n->v;
}
```

순서는

> **왼쪽 → 오른쪽 → 현재 노드**

입니다.

따라서 트리를 후위 순회하면:

```text
35 → 53 → 12 → 64 → 21
```

가 됩니다.

---

### 3. `c` 값 변화

각 노드에 도착할 때마다

```c
++c
```

가 실행됩니다.

| 순서 | 노드 값 | `c` | `c == 3` |
| -: | ---: | --: | :------: |
|  1 |   35 |   1 |     X    |
|  2 |   53 |   2 |     X    |
|  3 |   12 |   3 |     O    |
|  4 |   64 |   4 |     X    |
|  5 |   21 |   5 |     X    |

3번째로 방문하는 노드는 **12**입니다.

따라서

```c
if (++c == 3) ans = n->v;
```

에서 `ans`에 `12`가 저장됩니다.

### 정답

```text
12
```

핵심은 `pst`라는 이름처럼 **Postorder(후위 순회)**&#xB97C; 먼저 판단하고, `c == 3`이 되는 **세 번째 방문 노드의 값**을 찾는 것입니다.
