# 문제 07 — C 후위 순회

## 문제

다음 C언어 코드의 출력값을 쓰시오.

```c
#include <stdio.h>
typedef struct N { int v; struct N *a; struct N *b; } N;
int c = 0, ans = 0;
void pst(N *n) {
    if (!n) return;
    pst(n->a);
    pst(n->b);
    if (++c == 3) ans = n->v;
}
int main() {
    N ne = {35, 0, 0}, nd = {64, 0, 0}, nc = {53, 0, 0};
    N nb = {12, &ne, &nc}, na = {21, &nb, &nd};
    pst(&na);
    printf("%d\n", ans);
    return 0;
}
```

## 정답

12

## 핵심 개념

후위 순회는 왼쪽 하위 트리, 오른쪽 하위 트리, 현재 노드 순서로 방문한다.

## 문제 풀이

트리의 후위 방문 순서는 35, 53, 12, 64, 21이다. 방문 횟수 `c`가 3이 되는 노드는 값 12이므로 `ans`에 12가 저장된다.

## 오답 및 혼동 포인트

현재 노드를 먼저 처리하는 전위 순회나 왼쪽-현재-오른쪽의 중위 순회가 아니다. 함수에서 두 재귀 호출 뒤 `++c`를 수행하므로 후위 순회다.

## 암기 포인트

후위 순회는 왼쪽 → 오른쪽 → 루트다.
