# 문제 13

## 문제

다음 &lt;A&gt;, &lt;B&gt; 테이블과 SQL문을 참고하여, SQL문을 실행했을 때 출력되는 RESULT 값을 구하시오.

앞서 설명한 개념을 바탕으로, 문제의 전체 풀이 과정을 깔끔하게 다시 정리해 드릴게요.

---

### 1. 쿼리의 핵심 의미

이 SQL문은 테이블 A의 각 행(`A`)에 대해 다음을 계산하는 상관 서브쿼리(Correlated Subquery)입니다.

> **"A의 현재 행 `x`값보다 작은 `x`값을 가진 행들의 B 테이블 `y` 평균값(`AVG(y)`)을 구한 뒤, 그 평균보다 현재 `x`값이 더 큰 행의 개수(`COUNT(*)`)를 세어라."**
> 

---

### 2. 테이블 데이터 정리

* **[표 ]**
* `id = 1`: `x = 10`
* `id = 2`: `x = 20`
* `id = 3`: `x = 30`
* `id = 4`: `x = 40`


* **[표 ]**
* `id = 1`: `y = 5, 15`
* `id = 2`: `y = 20`
* `id = 3`: `y = 35`
* `id = 5`: `y = 50`



---

### 3. A의 각 행별 연산 과정

#### ① `id = 1` (`x = 10`)

1. **나보다 `x`가 작은 행(`A2.x < 10`)**: 없음 (Empty)


2. **해당 행들의 B 테이블 `y` 평균**: 구할 수 없음 (`NULL`)
3. **조건 검사 (`10 > NULL`)**: **거짓 (False)**

#### ② `id = 2` (`x = 20`)

1. **나보다 `x`가 작은 행(`A2.x < 20`)**: `id = 1`

2. **`id = 1`의 `y` 평균**: $(5 + 15) / 2 = \mathbf{10}$

3. **조건 검사 (`20 > 10`)**: **참 (True)** $\rightarrow$ **[선택 1]**

#### ③ `id = 3` (`x = 30`)

1. **나보다 `x`가 작은 행(`A2.x < 30`)**: `id = 1, 2`

2. **`id = 1, 2`의 `y` 평균**: $(5 + 15 + 20) / 3 = \mathbf{13.33...}$

3. **조건 검사 (`30 > 13.33...`)**: **참 (True)** $\rightarrow$ **[선택 2]**

#### ④ `id = 4` (`x = 40`)

1. **나보다 `x`가 작은 행(`A2.x < 40`)**: `id = 1, 2, 3`

2. **`id = 1, 2, 3`의 `y` 평균**: $(5 + 15 + 20 + 35) / 4 = \mathbf{18.75}$

3. **조건 검사 (`40 > 18.75`)**: **참 (True)** $\rightarrow$ **[선택 3]**

---

### 4. 최종 결과

조건을 만족하는 행은 `id`가 **2, 3, 4**인 총 **3개**입니다.

따라서 `SELECT COUNT(*) AS RESULT`의 최종 결과는 다음과 같습니다.

| RESULT |
| --- |
| **3** |


---

가장 안쪽 조건인 `WHERE A2.x < A.x`부터 시작해서 `WHERE B.id IN (...)`으로 확산되며 데이터가 어떻게 걸러지는지 **A 테이블의 행별로 변화 과정**을 순서대로 보여드릴게요.

---

### 1. `A.x = 10` (id: 1) 일 때

1. **`WHERE A2.x < 10`**
* A2 테이블에서 `x`가 10보다 작은 행 선택 $\rightarrow$ **없음 (Empty)**

* `SELECT A2.id` 결과 $\rightarrow$ `( )`


2. **`WHERE B.id IN ( )`**
* B 테이블에서 `id`가 빈 값인 행 선택 $\rightarrow$ **없음 (Empty)**
* `SELECT AVG(y)` 결과 $\rightarrow$ **`NULL`**



---

### 2. `A.x = 20` (id: 2) 일 때

1. **`WHERE A2.x < 20`**
* A2 테이블에서 `x`가 20보다 작은 행 선택 $\rightarrow$ `x = 10` (id: 1)


* `SELECT A2.id` 결과 $\rightarrow$ `(1)`



2. **`WHERE B.id IN (1)`**
* B 테이블에서 `id = 1`인 행의 `y` 값 선택 $\rightarrow$ **`y = 5, 15`**

* `SELECT AVG(y)` 결과 $\rightarrow$ **`10`**



---

### 3. `A.x = 30` (id: 3) 일 때

1. **`WHERE A2.x < 30`**
* A2 테이블에서 `x`가 30보다 작은 행 선택 $\rightarrow$ `x = 10, 20` (id: 1, 2)


* `SELECT A2.id` 결과 $\rightarrow$ `(1, 2)`



2. **`WHERE B.id IN (1, 2)`**
* B 테이블에서 `id`가 1 또는 2인 행의 `y` 값 선택 $\rightarrow$ **`y = 5, 15, 20`**

* `SELECT AVG(y)` 결과 $\rightarrow$ **`13.33...`**



---

### 4. `A.x = 40` (id: 4) 일 때

1. **`WHERE A2.x < 40`**
* A2 테이블에서 `x`가 40보다 작은 행 선택 $\rightarrow$ `x = 10, 20, 30` (id: 1, 2, 3)


* `SELECT A2.id` 결과 $\rightarrow$ `(1, 2, 3)`



2. **`WHERE B.id IN (1, 2, 3)`**
* B 테이블에서 `id`가 1, 2, 3 중 하나인 행의 `y` 값 선택 $\rightarrow$ **`y = 5, 15, 20, 35`**

* `SELECT AVG(y)` 결과 $\rightarrow$ **`18.75`**



---

| 현재 검사 중인 행 (`A.x`) | `A2.x < A.x` 조건 필터 | 추출된 `A2.id` (IN 조건) | `B.id IN (...)`로 뽑힌 `y` 값들 | 최종 `AVG(y)` |
| --- | --- | --- | --- | --- |
| **`x = 10`** | `x < 10` | 없음 `( )` | 없음 | **`NULL`** |
| **`x = 20`** | `x < 20` | `(1)` | `5, 15` | **`10`** |
| **`x = 30`** | `x < 30` | `(1, 2)` | `5, 15, 20` | **`13.33...`** |
| **`x = 40`** | `x < 40` | `(1, 2, 3)` | `5, 15, 20, 35` | **`18.75`** |
