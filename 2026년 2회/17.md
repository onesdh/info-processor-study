# 문제 17

## 문제

다음 설명에 해당하는 보안 기술 용어를 쓰시오.

입력값의 길이와 상관없이 항상 정해진 길이의 결과값을 만들어내는 암호 기술이 있다.

이 기술은 단방향성을 가지고 있어 결과값만으로는 원래의 입력값을 알아낼 수 없으며, 서로 다른 두 입력값이 같은 결과값을 만들어내는 경우가 최대한 발생하지 않도록 설계되어야 한다.

이러한 성질을 가진 암호 기술을 무엇이라 하는가?

## 1. 문제에서 묻는 것
"입력 길이와 상관없이 **고정 길이** 결과", "**단방향**", "서로 다른 입력이 **같은 결과를 최대한 만들지 않아야**" → 어떤 암호 기술인지 묻는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 암호 기술의 큰 갈래
| 구분 | 키 사용 | 되돌릴 수 있나 | 예 |
|---|---|---|---|
| 대칭키 암호 | 암·복호화 **같은 키** | 가능 | AES, DES |
| 비대칭키 암호 | **공개키/개인키** 쌍 | 가능 | RSA |
| **해시 함수** | 키 없음 | **불가능(단방향)** | MD5, **SHA-256** |

### (2) 해시 함수(Hash Function)
임의 길이의 데이터를 넣으면 **항상 같은 길이의 값(해시값, 지문)** 을 출력한다.
```text
"abc"                  ─┐
"안녕하세요 아주 긴 글…" ─┼─▶ [ 해시 함수 ] ─▶ 고정 길이 값 (예: SHA-256 → 256비트)
(파일 전체)            ─┘
```
### (3) 해시의 3가지 성질
| 성질 | 의미 |
|---|---|
| **단방향성(일방향)** | 해시값으로 원본을 **알아낼 수 없다** |
| **충돌 저항성** | 서로 다른 입력이 **같은 해시값을 내는 일**이 극히 어렵다 |
| 눈사태 효과 | 입력이 1비트만 달라도 결과가 **완전히 달라진다** |

### (4) 어디에 쓰나?
- **무결성 검증**: 파일이 바뀌었는지 해시로 비교
- **비밀번호 저장**: 원문이 아니라 해시값만 저장
- **전자서명, 블록체인**

## 3. 문제 풀이
| 문제의 단서 | 해시의 성질 |
|---|---|
| 입력 길이와 무관하게 정해진 길이 | 고정 길이 출력 |
| 단방향성, 결과로 입력 추정 불가 | 일방향성 |
| 서로 다른 입력 → 같은 결과 최소화 | 충돌 저항성 |

> **정답: 해시 (Hash 함수)**

## 4. 암기 포인트
- 암호화(Encryption)는 **복호화가 가능**하고, 해시는 **복호화가 불가능**하다.
- 해시 알고리즘: MD5(취약), SHA-1(취약), **SHA-2(SHA-256 등)**, SHA-3.
