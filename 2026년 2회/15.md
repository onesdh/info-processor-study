# 문제 15 — Java 상속과 메서드 오버라이딩

## 문제

다음 Java 코드의 출력값을 쓰시오.

```java
class A {
    int a;
    private int b;
    protected int c;
    void set(int aa, int bb, int cc) { a = aa; b = bb; c = cc; }
    int hap() { return a + b + c; }
}
class B extends A {
    public int hap() { return a * c; }
}
public class Main {
    public static void main(String[] args) {
        A aaa = new A();
        B bbb = new B();
        aaa.set(1, 5, 3);
        bbb.set(10, 30, 50);
        System.out.print(aaa.hap() + bbb.hap());
    }
}
```

## 정답

509

## 핵심 개념

하위 클래스가 상위 메서드와 같은 시그니처로 재정의하면 실행 시 실제 객체의 메서드가 호출된다. `private` 필드는 A 내부에서만 접근하지만 A의 `set`과 `hap`은 그 필드를 사용할 수 있다.

## 문제 풀이

`aaa.hap()`은 A의 메서드로 1+5+3=9다. `bbb.hap()`은 B가 재정의한 메서드로 상속된 `a`와 `c`를 곱해 10×50=500이다. 두 반환값의 합은 509다.

## 오답 및 혼동 포인트

B 객체에서도 `set`은 상속된 A 메서드이므로 private 필드 b까지 설정하지만, B의 `hap()`은 이를 사용하지 않는다. 반환값을 문자열로 붙이는 것이 아니라 정수 덧셈한다.

## 암기 포인트

오버라이딩된 메서드는 객체의 실제 클래스 구현을 실행한다.
