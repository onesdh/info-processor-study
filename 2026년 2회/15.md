# 문제 15

## 문제

다음은 Java 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
class A {
    int a;
    private int b;
    protected int c;

    void set(int aa, int bb, int cc) {
        a = aa;
        b = bb;
        c = cc;
    }

    int hap() { return a + b + c; }
}

class B extends A {
    public int hap() { return a * c; }
}

public class Main {
    public static void main(String[] args) {
        A aaa = new A();
        B bbb = new B();

        aaa.set(1, 5, 3);
        bbb.set(10, 30, 50);

        System.out.print(aaa.hap() + bbb.hap());
    }
}
```

## 1. 문제에서 묻는 것
**상속 + 메서드 오버라이딩 + 접근 제어자**가 섞인 코드에서 최종 출력(두 `hap()` 결과의 합)을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 접근 제어자
| 키워드 | 접근 가능 범위 |
|---|---|
| `private` | **같은 클래스 안**에서만 |
| (없음, default) | 같은 패키지 |
| `protected` | 같은 패키지 + **자식 클래스** |
| `public` | 어디서나 |

### (2) 오버라이딩과 동적 바인딩
자식이 부모와 **같은 시그니처**의 메서드를 정의하면 자식 것으로 **덮어쓴다**. 호출은 변수 타입이 아닌 **실제 객체 타입**을 따른다.

### (3) 객체마다 필드는 따로
`aaa`와 `bbb`는 서로 다른 객체이므로 각자의 `a, b, c`를 가진다.

## 3. 클래스 분석
```text
A : a, b(private), c(protected)        set(a,b,c) 로 세 값 저장
    hap() = a + b + c
B : A를 상속 (필드 a, b, c 그대로)
    hap() 재정의 = a * c               ← b는 private라 접근 불가, 쓰지 않음
```
- B의 `hap()`에서 `a`, `c`는 접근 가능(default/protected), `b`는 접근 불가 → 곱 `a * c`만 사용.
- `set()`은 A 안에서 실행되므로 `b`에 접근해도 문제없다. B 객체도 `set()`을 호출하면 **자기 자신의 b에 값을 저장**한다.

## 4. 실행 과정
| 객체 | 호출 | a | b | c | 실행되는 hap() | 결과 |
|---|---|---:|---:|---:|---|---:|
| `aaa` (A) | `set(1,5,3)` | 1 | 5 | 3 | A.hap: 1+5+3 | **9** |
| `bbb` (B) | `set(10,30,50)` | 10 | 30 | 50 | **B.hap(오버라이딩)**: 10×50 | **500** |

`System.out.print(aaa.hap() + bbb.hap())` → 9 + 500 = **509**
(두 값 모두 `int`이므로 문자열 연결이 아니라 **덧셈**이다.)

> **정답: `509`**

## 5. 암기 포인트
- 자식이 재정의한 메서드가 있으면 **자식 것이 실행**된다(`bbb.hap()` = a×c).
- `int + int`는 덧셈. 문자열 `"…"`이 끼어야 연결이 된다.
