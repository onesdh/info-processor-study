# 문제 15

## 문제

다음은 Java 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
class A {
    int a;
    private int b;
    protected int c;

    void set(int aa, int bb, int cc) {
        a = aa;
        b = bb;
        c = cc;
    }

    int hap() { return a + b + c; }
}

class B extends A {
    public int hap() { return a * c; }
}

public class Main {
    public static void main(String[] args) {
        A aaa = new A();
        B bbb = new B();

        aaa.set(1, 5, 3);
        bbb.set(10, 30, 50);

        System.out.print(aaa.hap() + bbb.hap());
    }
}
```

## 해설

이 문제는 **상속, 메서드 오버라이딩, 접근 제어자(`private`, `protected`)**를 이해하는 문제이다.

### 1. 클래스 A의 구성

```java
class A {
    int a;
    private int b;
    protected int c;

    void set(int aa, int bb, int cc) {
        a = aa;
        b = bb;
        c = cc;
    }

    int hap() {
        return a + b + c;
    }
}
```

`A`에는 다음과 같은 멤버 변수가 있다.

| 변수 | 접근 제어자 | 의미 |
|---|---|---|
| `a` | default | 같은 패키지에서 접근 가능 |
| `b` | `private` | **A 클래스 내부에서만 직접 접근 가능** |
| `c` | `protected` | 같은 패키지 및 자식 클래스에서 접근 가능 |

`set()` 메서드는 `A` 클래스 내부에 있으므로 `a`, `b`, `c` 모두 변경할 수 있다.

---

### 2. `aaa` 객체

```java
A aaa = new A();
aaa.set(1, 5, 3);
```

`set()`을 실행하면:

```text
a = 1
b = 5
c = 3
```

이 된다.

`aaa`는 `A` 객체이므로 `A`의 `hap()`이 실행된다.

```java
int hap() {
    return a + b + c;
}
```

따라서:

```text
aaa.hap()
= 1 + 5 + 3
= 9
```

---

### 3. `bbb` 객체

```java
B bbb = new B();
bbb.set(10, 30, 50);
```

`B`는 `A`를 상속하므로 `A`의 멤버를 물려받는다.

따라서 `set()`을 실행하면:

```text
a = 10
b = 30
c = 50
```

이 된다.

하지만 `B`에는 `hap()`이 다시 정의되어 있다.

```java
class B extends A {
    public int hap() {
        return a * c;
    }
}
```

이는 `A`의 `hap()`을 **오버라이딩(재정의)**한 것이다.

따라서 `bbb.hap()`을 호출하면 `A`의

```java
a + b + c
```

가 아니라 `B`의

```java
a * c
```

가 실행된다.

```text
bbb.hap()
= 10 × 50
= 500
```

여기서 `b = 30`은 계산에 사용되지 않는다.

---

### 4. `private`와 `protected`의 영향

이 문제에서 접근 제어자를 구분해서 봐야 한다.

#### `b` → `private`

```java
private int b;
```

`b`는 `A` 클래스 내부에서만 직접 접근할 수 있다.

따라서 `A`의 `hap()`에서는 사용할 수 있다.

```java
int hap() {
    return a + b + c;  // 가능
}
```

하지만 `B`에서 다음과 같이 작성하면:

```java
public int hap() {
    return a + b + c;  // b 직접 접근 불가능
}
```

`b`가 `private`이므로 컴파일 오류가 발생한다.

다만 현재 `B.hap()`에서는 `b`를 사용하지 않는다.

```java
return a * c;
```

따라서 `private` 때문에 현재 코드에서 문제가 발생하지 않는다.

#### `c` → `protected`

```java
protected int c;
```

`c`는 자식 클래스인 `B`에서 직접 접근할 수 있다.

따라서:

```java
return a * c;
```

에서 `c`를 정상적으로 사용할 수 있다.

---

### 5. 최종 계산

```java
System.out.print(aaa.hap() + bbb.hap());
```

각 객체의 `hap()` 결과는:

```text
aaa.hap() = 1 + 5 + 3 = 9

bbb.hap() = 10 × 50 = 500
```

따라서:

```text
9 + 500 = 509
```

### 핵심 정리

이 문제에서는 다음 세 가지를 기억하면 된다.

1. **`aaa`는 A 객체이므로 `A.hap()` 실행**
   - `1 + 5 + 3 = 9`

2. **`bbb`는 B 객체이고 `hap()`을 오버라이딩했으므로 `B.hap()` 실행**
   - `10 × 50 = 500`

3. **`private`와 `protected`**
   - `b`는 `private` → B에서 직접 접근 불가능
   - `c`는 `protected` → B에서 직접 접근 가능
   - 현재 `B.hap()`은 `b`를 사용하지 않고 `a`, `c`만 사용하므로 정상 실행된다.

따라서 최종 출력값은 **509**이다.
