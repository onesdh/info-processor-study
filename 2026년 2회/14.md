## 문제

## 1. 문제에서 묻는 것
`RIGHT OUTER JOIN` 후 `WHERE A.id IS NULL` 조건을 걸었을 때 `COUNT(*)`가 몇 개인지 묻는 문제다. **"B에는 있고 A에는 없는 행"** 의 개수를 구하는 전형적인 패턴이다.

## 2. 먼저 알아야 할 개념
### (1) JOIN
두 테이블을 **공통 열(여기서는 id)** 기준으로 옆으로 이어 붙이는 연산.

| 종류 | 결과 |
|---|---|
| INNER JOIN | 양쪽에 **모두 일치하는 행**만 |
| LEFT OUTER JOIN | **왼쪽 테이블 전체** + 오른쪽 일치 값 (없으면 NULL) |
| **RIGHT OUTER JOIN** | **오른쪽 테이블 전체** + 왼쪽 일치 값 (없으면 NULL) |

### (2) 벤 다이어그램으로 보기
```text
   A ( ●●●●●(●●●)●●●●● ) B       RIGHT OUTER = B 전체  (가운데 + 오른쪽)
         왼쪽만   교집합   오른쪽만
   WHERE A.id IS NULL  → "오른쪽(B)에만 있는 부분"만 남김
```
### (3) `IS NULL`
NULL 여부는 `= NULL`이 아니라 반드시 `IS NULL`로 비교한다.

## 3. 문제 데이터 (그림)
**A**

| id | v |
|---:|---:|
| 1 | 10 |
| 1 | 20 |
| 2 | 30 |

**B**

| id | w |
|---:|---:|
| 1 | 100 |
| 3 | 300 |
| 4 | 400 |

```sql
SELECT COUNT(*)
FROM A RIGHT OUTER JOIN B ON A.id = B.id
WHERE A.id IS NULL;
```

## 4. 풀이
**① JOIN 결과** (B의 모든 행 유지)

| B.id | B.w | A.id | A.v | 설명 |
|---:|---:|---:|---:|---|
| 1 | 100 | 1 | 10 | A의 id=1이 **2행**이라 2번 매칭 |
| 1 | 100 | 1 | 20 | |
| 3 | 300 | NULL | NULL | A에 id=3 없음 |
| 4 | 400 | NULL | NULL | A에 id=4 없음 |

**② WHERE A.id IS NULL** → `A.id`가 NULL인 행: id=3, id=4 → **2행**

**③ COUNT(\*)** = **2**

> **정답: 2**

## 5. 암기 포인트
- `OUTER JOIN ... WHERE 반대쪽.키 IS NULL` = **한쪽에만 있는 데이터 찾기**(차집합).
- JOIN은 일치하는 행이 여러 개이면 **행이 늘어난다**(id=1이 2번 나온 것). 하지만 이 문제는 NULL 행만 세므로 영향 없음.
