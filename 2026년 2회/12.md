# 문제 12

## 문제

다음 &lt;학생&gt; 테이블에서 성이 '이'씨인 학생의 정보를 조회하되, 학번을 기준으로 내림차순 정렬하여 출력하고자 한다. SQL문의 괄호 안에 들어갈 알맞은 내용을 각각 쓰시오.

## 1. 문제에서 묻는 것
`LIKE`로 "이"씨 성을 조회하고 `ORDER BY`로 학번 내림차순 정렬하는 SQL의 빈칸 2개를 채우는 문제다.

## 2. 먼저 알아야 할 개념
### (1) SELECT 문의 기본 모양
```sql
SELECT 열 이름        -- 무엇을 보여줄까 (*: 모든 열)
FROM   테이블 이름    -- 어느 테이블에서
WHERE  조건           -- 어떤 행만
ORDER BY 열 [ASC|DESC]; -- 어떤 순서로
```
### (2) LIKE와 와일드카드
문자열이 **특정 패턴**과 같은지 비교한다.
| 기호 | 의미 | 예 |
|---|---|---|
| `%` | **0개 이상**의 임의 문자열 | `'이%'` = "이"로 시작하는 모든 값 |
| `_` | **정확히 1개**의 임의 문자 | `'이_'` = "이" + 한 글자 |

### (3) ORDER BY
| 키워드 | 의미 |
|---|---|
| `ASC` | 오름차순 (작은 값 → 큰 값, **기본값**) |
| `DESC` | **내림차순** (큰 값 → 작은 값) |

## 3. 문제 데이터 (그림)
| 학번 | 성명 | 학과 |
|---|---|---|
| 2020001 | 이몽룡 | 컴퓨터공학과 |
| 2020002 | 김철수 | 전자공학과 |
| 2020003 | 이순신 | 정보통신공학과 |
| 2020004 | 박영희 | 컴퓨터공학과 |

## 4. 풀이
```sql
SELECT * FROM 학생
WHERE 성명 LIKE '( 1 )'
ORDER BY 학번 ( 2 );
```
1. 성이 "이"씨 = 이름이 "이"로 시작 → `'이%'`
2. 학번 큰 것부터 → `DESC`

실행 순서: ① FROM 학생 → ② WHERE로 이몽룡(2020001), 이순신(2020003)만 남김 → ③ ORDER BY 학번 DESC로 정렬.

| 학번 | 성명 | 학과 |
|---|---|---|
| 2020003 | 이순신 | 정보통신공학과 |
| 2020001 | 이몽룡 | 컴퓨터공학과 |

> **정답: 1. 이%  2. DESC**

## 5. 암기 포인트
- `%` = 여러 글자, `_` = 한 글자.
- `'%이'`는 "이"로 **끝나는** 값, `'%이%'`는 "이"를 **포함**하는 값.
- `ORDER BY`를 안 쓰면 순서는 보장되지 않고, 쓰면 기본은 `ASC`.
