# 문제 19

## 문제

통합 테스트에서 사용하는 더미 모듈에 대한 설명이다. 빈칸에 들어갈 용어를 쓰시오.

(1)은 하위 모듈을 대신해 단순한 결과값을 반환하도록 임시 작성되며 하향식 통합 테스트에 필요하다.
(2)는 상위 모듈을 대신해 하위 모듈의 데이터 입력과 출력을 확인하도록 임시 작성되며 상향식 통합 테스트에 필요하다.

<details>
<summary><strong>정답 보기</strong></summary>

1. 스텁 (Stub)
2. 드라이버 (Driver)

</details>

## 핵심 개념

아직 준비되지 않은 모듈을 대신하는 테스트용 더미를 테스트 더블이라고 한다. 상위에서 하위로 내려가는 통합 테스트에서는 하위 모듈 대신 스텁을 쓰고, 하위에서 상위로 올라가는 테스트에서는 상위 모듈 대신 드라이버를 쓴다.

## 문제 풀이

하향식 테스트에서 아직 구현되지 않은 하위 모듈의 응답을 흉내 내는 것은 스텁이다. 상향식 테스트에서 하위 모듈을 호출하고 결과를 확인하는 가짜 상위 모듈은 드라이버다.

## 오답 및 혼동 포인트

둘 다 실제 모듈을 대신하지만 대체 위치가 다르다. 스텁은 호출받는 쪽인 하위 모듈을 대신하고, 드라이버는 호출하는 쪽인 상위 모듈을 대신한다.

## 암기 포인트

Top-down은 Stub, Bottom-up은 Driver.
