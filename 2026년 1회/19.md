# 문제 19

## 문제

다음은 통합 테스트에서 사용되는 더미 모듈에 대한 설명이다. 괄호 안에 들어갈 알맞은 용어를 쓰시오.

( 1 ) 은/는 하위 모듈을 대신하여 단순한 결과값만 반환하도록 임시로 작성된 더미 모듈로, 하향식 통합 테스트 수행 시 필요하다.  
( 2 ) 은/는 상위 모듈을 대신하여 하위 모듈의 데이터 입력과 출력을 확인하기 위한 더미 모듈로, 상향식 통합 테스트 수행 시 필요하다.

## 1. 문제에서 묻는 것
**통합 테스트**에서 아직 만들어지지 않은 모듈을 대신하는 **더미 모듈 2가지**(하향식용 / 상향식용)의 이름을 묻는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 통합 테스트
단위(모듈)별로 테스트를 마친 뒤, 모듈들을 **합쳐서 연결 부분(인터페이스)의 오류**를 찾는 테스트다.

### (2) 왜 더미 모듈이 필요한가?
모듈 구조는 위(상위)가 아래(하위)를 호출하는 **계층 구조**다. 테스트 시점에 일부 모듈이 아직 개발 전이면 **임시 모듈**로 대신한다.
```text
          [ 상위 모듈 A ]
           /          \
   [ 하위 B ]      [ 하위 C ]
```
### (3) 하향식 vs 상향식
| 구분 | 하향식(Top-down) | 상향식(Bottom-up) |
|---|---|---|
| 진행 방향 | 상위 → 하위 | 하위 → 상위 |
| 아직 없는 모듈 | **하위** 모듈 | **상위** 모듈 |
| 필요한 더미 | **스텁(Stub)** | **드라이버(Driver)** |

```text
 하향식:  A(실제) ─호출▶ [스텁 B'] : 정해진 결과값만 돌려줌
 상향식:  [드라이버 A'] ─호출▶ B(실제) : B에 입력을 주고 출력을 확인
```
- **스텁(Stub)**: **호출을 받는** 가짜. 하위 모듈 대신 **간단한 결과값만 반환**.
- **드라이버(Driver)**: **호출하는** 가짜. 상위 모듈 대신 하위 모듈에 **데이터를 넣고 결과를 확인**.

## 3. 문제 풀이
| 문장 | 정답 |
|---|---|
| (1) **하위** 모듈 대신, **단순 결과값만 반환**, **하향식** 때 필요 | **스텁(Stub)** |
| (2) **상위** 모듈 대신, 하위 모듈의 **입출력 확인**, **상향식** 때 필요 | **드라이버(Driver)** |

> **정답: 1. 스텁 / 2. 드라이버**

## 4. 암기 포인트
- **하향식 = 스텁**(하위 대체), **상향식 = 드라이버**(상위 대체). ("스하 / 드상")
- 드라이버는 **운전(drive)해서** 하위 모듈을 호출한다고 기억하면 쉽다.
