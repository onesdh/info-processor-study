# 문제 08 — Python 문자열 역순 필터링

## 문제

다음 Python 코드에서 입력값으로 `HumanDev`를 주었을 때 출력 결과를 쓰시오.

```python
i = input()
x = []

for word in i.split():
    x.append(word)

y = ''.join(x)
z = ''.join(c for c in y[::-1] if c not in 'ong')
print(z)
```

## 정답

veDamuH

## 핵심 개념

문자열 슬라이싱 `[::-1]`은 문자를 역순으로 읽는다. `c not in 'ong'`는 각 문자가 `o`, `n`, `g` 중 하나가 아닌지 검사한다.

## 문제 풀이

공백 없는 입력 `HumanDev`를 역순으로 만들면 `veDnamuH`다. 이 중 `n`은 제외 집합 `ong`에 포함되어 제거되고, 나머지 문자를 이어 `veDamuH`가 출력된다.

## 오답 및 혼동 포인트

`'ong'`와 같은 문자열을 하나의 단어로 비교하는 것이 아니라, `in`이 각 반복 문자를 문자열의 문자들과 비교한다. 입력에 공백이 없으므로 `split()`과 `join()`은 원래 문자열을 유지한다.

## 암기 포인트

`[::-1]`은 역순, `c not in 'ong'`는 o·n·g 세 문자를 걸러낸다.
