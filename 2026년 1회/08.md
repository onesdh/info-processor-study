# 문제 08

## 문제

아래 파이썬 코드가 있다. 입력값으로 HumanDev를 주었을 때 출력되는 결과를 쓰시오.

```
i = input()
x = []

for word in i.split():
    x.append(word)

y = ''.join(x)
z = ''.join(c for c in y[::-1] if c not in 'ong')

print(z)
```

veDamuH

</details>

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
입력 `HumanDev`에 대해 **문자열을 합치고, 뒤집고, 특정 문자를 제거**한 결과를 구하는 문제다.

## 2. 먼저 알아야 할 개념
| 문법 | 의미 | 예 |
|---|---|---|
| `input()` | 사용자 입력(문자열) | `"HumanDev"` |
| `s.split()` | 공백으로 나눈 **단어 리스트** | `"a b"` → `['a','b']` |
| `''.join(리스트)` | 리스트 원소를 **구분자 없이 이어 붙여** 문자열로 | `['a','b']` → `"ab"` |
| `s[::-1]` | **뒤집은** 문자열 | `"abc"` → `"cba"` |
| `c for c in s if 조건` | 조건을 만족하는 문자만 뽑음(제너레이터) | |
| `c not in 'ong'` | c가 `o`,`n`,`g` **중 어느 것도 아니면** 참 | |

## 3. 실행 과정
입력: `HumanDev` (공백이 없다)

| 단계 | 코드 | 값 |
|---|---|---|
| ① | `i.split()` | `['HumanDev']` (단어 1개) |
| ② | `x.append(word)` 반복 | `x = ['HumanDev']` |
| ③ | `y = ''.join(x)` | `"HumanDev"` |
| ④ | `y[::-1]` | `"veDnamuH"` |
| ⑤ | `'o','n','g'` 제거 | 아래 표 |

```text
y[::-1] = v e D n a m u H
```
| 문자 | v | e | D | **n** | a | m | u | H |
|---|---|---|---|---|---|---|---|---|
| 'ong'에 포함? | X | X | X | **O(제거)** | X | X | X | X |

남는 글자: `v e D a m u H` → `z = "veDamuH"`

> **정답: `veDamuH`**

## 4. 암기 포인트
- 소문자 `n`만 제거된다(대문자 `H`, `D`는 `'ong'`에 없음). 문자 비교는 **대소문자 구분**.
- `join`은 `x`가 리스트일 때만 의미 있게 이어 붙인다.
