# 문제 17

## 문제

다음은 Java 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
public class Main {
    public static void main(String[] args) {
        int x1 = 9;
        int x2 = 2;
        String x3 = "3";
        System.out.println(x1 + x2 + "2" + x3);
    }
}
```

<summary><strong>정답 보기</strong></summary>

1123

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
`+` 연산자가 **숫자 덧셈**과 **문자열 연결** 중 무엇으로 동작하는지 단계별로 판단하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) `+`의 두 얼굴 (Java)
| 피연산자 | 동작 |
|---|---|
| 숫자 + 숫자 | **덧셈** |
| 문자열이 하나라도 끼면 | **문자열 연결** (숫자는 문자열로 변환) |

### (2) 계산 순서
`+`는 **왼쪽에서 오른쪽으로** 하나씩 계산한다.
`x1 + x2 + "2" + x3` = `((x1 + x2) + "2") + x3`

## 3. 단계별 계산
| 단계 | 식 | 판단 | 결과 |
|---|---|---|---|
| ① | `x1 + x2` = `9 + 2` | 숫자 + 숫자 → **덧셈** | `11` (int) |
| ② | `11 + "2"` | 숫자 + **문자열** → 연결 | `"112"` |
| ③ | `"112" + x3` (`x3 = "3"`) | 문자열 + 문자열 → 연결 | `"1123"` |

> **정답: `1123`**

## 4. 실수 포인트
- ①에서 `9 + 2`를 `"92"`로 이어 붙이면 안 된다. 앞의 두 개는 **둘 다 int**라 먼저 더해져 11이 된다.
- 만약 `"" + x1 + x2` 처럼 문자열이 **맨 앞**에 있었다면 `"92"`가 된다.
