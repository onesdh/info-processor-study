# 문제 17 — Java 문자열 결합의 평가 순서

## 문제

다음 Java 코드의 출력값을 쓰시오.

```java
public class Main {
    public static void main(String[] args) {
        int x1 = 9;
        int x2 = 2;
        String x3 = "3";
        System.out.println(x1 + x2 + "2" + x3);
    }
}
```

<details>
<summary><strong>정답 보기</strong></summary>

1123

</details>

## 핵심 개념

Java에서 `+`는 숫자끼리 만나면 덧셈을 하고, 한쪽이 문자열이면 문자열 결합을 한다. 같은 우선순위 연산자는 왼쪽부터 평가된다.

## 문제 풀이

먼저 `9 + 2`가 숫자 덧셈으로 11이 된다. 이후 문자열 `"2"`가 연결되어 `"112"`, 마지막으로 `x3`의 `"3"`이 연결되어 `"1123"`이 출력된다.

## 오답 및 혼동 포인트

전체 식을 처음부터 문자열 결합으로 처리하지 않는다. 문자열을 만나기 전까지의 `9 + 2`는 정수 덧셈이다.

## 암기 포인트

문자열이 나타나기 전에는 산술 연산, 그 뒤부터는 왼쪽에서 문자열 결합이다.
