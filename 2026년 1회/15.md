# 문제 15

## 문제

다음은 특정 공격 기법에 대한 설명이다. 아래 내용을 읽고 해당하는 공격 기법을 [보기]에서 골라 쓰시오.

원본 데이터 파일은 별도로 존재하며, 공격자는 해당 파일의 경로를 가리키는 특수 파일을 생성한다. 프로그램이 임시 파일을 생성하는 순간을 틈타 해당 임시 파일을 미리 준비한 특수 파일로 교체한다. 이후 프로그램이 임시 파일의 존재를 확인하면 교체된 파일을 정상으로 인식하고 동작하게 된다.

공격 절차

1. 공격자는 실제 파일이 아닌, 특정 파일의 경로를 참조하는 특수 파일을 미리 준비한다.  
2. 프로그램이 임시 파일을 생성하는 시점을 노려 해당 임시 파일을 준비한 특수 파일로 교체한다.  
3. 프로그램이 임시 파일의 존재 여부를 확인할 때, 조건에 부합하면 정상으로 판단하고 동작하며 부합하지 않으면 임시 파일을 삭제한다.

## 1. 문제에서 묻는 것
"프로그램이 **임시 파일을 만드는 순간**을 노려 **특수 파일로 교체**"하는 공격이 무엇인지, 보기(링크 종류)에서 고르는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 파일 링크 2종류 (리눅스)
| 구분 | 설명 | 비유 |
|---|---|---|
| **하드 링크** | 같은 **데이터(inode)** 에 이름을 하나 더 붙임. 원본을 지워도 데이터 유지 | 같은 집에 문패 2개 |
| **심볼릭 링크 (= 소프트 링크)** | **다른 파일의 경로**를 담은 **특수 파일**. 원본이 없어지면 끊어짐(dangling) | 바로가기 아이콘 |

```text
 심볼릭 링크 tmp.txt ─────▶ /etc/passwd   (경로 문자열을 가리킴)
```
### (2) 심볼릭 링크 공격(Symlink Attack / TOCTOU)
- **TOCTOU(Time Of Check, Time Of Use)** 경쟁 조건: 프로그램이 "파일이 있나?" **확인한 시점**과 "그 파일을 **사용하는** 시점" 사이의 **틈**을 노린다.
- 공격 절차(문제의 1~3번)
```text
 ① 공격자: /etc/passwd 같은 중요 파일을 가리키는 심볼릭 링크를 미리 준비
 ② 프로그램이 임시 파일(tmp)을 만드는 순간, tmp를 그 링크로 교체
 ③ 프로그램은 tmp가 있다고 믿고 쓰기 → 실제로는 중요 파일을 덮어씀/변조
```
특히 **setuid(높은 권한) 프로그램**이 임시 파일에 쓸 때 위험하다.

## 3. 문제 풀이
| 문제 단서 | 해당하는 것 |
|---|---|
| 해당 파일의 **경로를 가리키는 특수 파일** | **심볼릭 링크** |
| 임시 파일 생성 순간을 노려 교체 | 심볼릭 링크 공격(TOCTOU) |

보기 분석: 하드링크(같은 inode, 경로 참조 아님) ❌ / **심볼릭링크** ✅ / 소프트링크(심볼릭 링크의 다른 이름이지만 보기의 표준 답은 심볼릭링크) / 정적링크·동적링크(프로그램 **라이브러리 연결** 방식이라 무관) ❌

> **정답: 심볼릭링크**

## 4. 암기 포인트
- 심볼릭 링크 = **경로를 가리키는 바로가기**, 하드 링크 = **같은 데이터에 이름 추가**.
- 대응: 임시 파일을 `O_EXCL`로 생성, 예측 불가능한 이름(`mkstemp`) 사용, 링크 여부 검사.
