# 문제 01

## 문제

다음은 C언어 문제이다. 아래 코드를 확인하여 알맞은 출력값을 작성하시오.

```c
#include <stdio.h>

double arr1(int p[], int len) {
    double av = 0;
    int i;
    for (i = 0; i < len; i++) {
        av += (double) p[i];
    }
    return av / len;
}

double arr2(int *p, int len) {
    double av = 0;
    int i;
    for (i = 0; i < len; i++) {
        av += (double) *(p + i);
    }
    return av / len;
}

int main() {
    int arr[10] = {80, 20, 50, 55, 45, 95, 55, 10, 40, 80};
    int len = 10;

    printf("%.2f", arr1(arr, len) + arr2(arr, len));
    return 0;
}
```

<summary><strong>정답 보기</strong></summary>

106.00

</details>

<summary><strong>상세 해설</strong></summary>

## 핵심 개념

배열 매개변수 `int p[]`는 함수 안에서 첫 원소를 가리키는 포인터처럼 동작한다. `int *p`와 표기만 다를 뿐 두 함수 모두 같은 배열 원소들을 순회한다. 평균은 원소 합계를 원소 수로 나눈 값이다.

## 문제 풀이

배열 원소의 합은 530이고 길이는 10이므로 평균은 53이다. `arr1`은 `p[i]`, `arr2`는 `*(p+i)`로 같은 원소를 읽는다. 따라서 두 함수의 반환값은 각각 53.0이고, 합은 106.0이다. `%.2f`가 소수점 아래 두 자리까지 출력하므로 결과는 `106.00`이다.

## 오답 및 혼동 포인트

`arr1`과 `arr2`가 다른 계산을 한다고 보면 안 된다. C에서 `p[i]`는 `*(p+i)`와 같은 원소 접근이다. 또한 두 평균의 합이므로 평균 하나인 53이 아니라 106을 출력한다.

## 암기 포인트

배열 인덱스 표기와 포인터 산술은 같은 주소 접근을 표현할 수 있다.
