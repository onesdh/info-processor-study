# 문제 06

## 문제

HDLC는 비트 중심의 데이터 링크 제어 프로토콜로, 프레임 단위로 데이터를 전송하며 흐름 제어 및 오류 복구 기능을 제공한다. 다음 설명을 읽고 알맞은 용어를 쓰시오.

HDLC 구성 요소

1. HDLC 프레임의 구성 단위로, 실제 사용자 데이터를 전송하는 프레임

2. 데이터 링크의 흐름을 관리하고 오류 제어 및 통신 상태를 감시하는 프레임

3. 순서 번호 없이 링크 설정, 해제, 모드 설정 등 제어 기능을 수행하는 프레임

4. 두 국(Station)이 동등한 위치에서 서로 명령과 응답을 주고받는 모드

5. 종국(Secondary)이 주국(Primary)의 허가 없이도 자발적으로 응답을 전송할 수 있는 모드

## 1. 문제에서 묻는 것
**HDLC**의 **프레임 종류 3가지**(정보/감독/비번호)와 **동작 모드**(비동기 균형 모드 / 비동기 응답 모드)를 구분하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) HDLC란?
**High-level Data Link Control**. OSI 7계층 중 **2계층(데이터링크 계층)** 에서 쓰는 **비트 중심(bit-oriented)** 프로토콜. 데이터를 **프레임** 단위로 보내며, **흐름 제어와 오류 제어**를 한다.

### (2) 프레임 구조
```text
| 플래그 | 주소부 | 제어부 | 정보부(데이터) | FCS(오류검출) | 플래그 |
  01111110   A       C         (I-프레임만)        CRC        01111110
```
제어부의 앞 비트로 프레임 종류가 결정된다.

### (3) 프레임 3종류
| 프레임 | 약자 | 역할 |
|---|---|---|
| **정보 프레임** | I | **사용자 데이터** 전송 (순서번호, 확인응답 포함) |
| **감독 프레임** | S | **흐름 제어·오류 제어**, 통신 상태 감시 (RR, RNR, REJ, SREJ) |
| **비번호 프레임** | U | **순서 번호 없이** 링크 설정·해제, **모드 설정** |

### (4) 동작 모드
| 모드 | 의미 |
|---|---|
| **표준(정상) 응답 모드 (NRM)** | 종국은 **주국의 허락을 받을 때만** 전송 (주-종 구조) |
| **비동기 응답 모드 (ARM)** | 종국이 주국의 허가 **없이도** 자발적으로 응답 전송 |
| **비동기 균형 모드 (ABM)** | **두 국이 대등(복합국)** 하게 서로 명령·응답 |

```text
 NRM : 주국 ──허락──▶ 종국 → 응답        (주국이 통제)
 ARM : 종국이 허락 없이 전송 가능         (종국에 자유)
 ABM : 국A ◀──▶ 국B  (동등한 복합국)      (점대점, 가장 흔함)
```

## 3. 문제 풀이
| 번호 | 설명 | 정답 |
|---|---|---|
| 1 | **사용자 데이터**를 전송하는 프레임 | **정보(I) 프레임** |
| 2 | **흐름 관리, 오류 제어, 통신 상태 감시** | **감독(S) 프레임** |
| 3 | **순서 번호 없이** 링크 설정·해제·모드 설정 | **비번호(U) 프레임** |
| 4 | 두 국이 **동등한 위치**에서 명령·응답 | **비동기 균형 모드(ABM)** |
| 5 | 종국이 **주국 허가 없이** 자발적으로 응답 | **비동기 응답 모드(ARM)** |

> **정답: 1. 정보 / 2. 감독 / 3. 비번호 / 4. 비동기 균형 모드 / 5. 비동기 응답 모드**

## 4. 암기 포인트
- 프레임: **I(정보)=데이터, S(감독)=제어·감시, U(비번호)=링크 관리**.
- 모드: **NRM**=주국 허락, **ARM**=종국 자유, **ABM**=동등.
