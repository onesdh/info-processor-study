# 문제 06 — HDLC 프레임과 동작 모드

## 문제

HDLC는 비트 중심의 데이터 링크 제어 프로토콜로, 프레임 단위로 데이터를 전송하며 흐름 제어 및 오류 복구 기능을 제공한다. 설명에 맞는 용어를 쓰시오.

1. HDLC 프레임 구성 단위로 실제 사용자 데이터를 전송하는 프레임
2. 데이터 링크의 흐름을 관리하고 오류 제어 및 통신 상태를 감시하는 프레임
3. 순서 번호 없이 링크 설정·해제·모드 설정 등 제어 기능을 수행하는 프레임
4. 두 국(Station)이 동등한 위치에서 서로 명령과 응답을 주고받는 모드
5. 종국(Secondary)이 주국(Primary)의 허가 없이도 자발적으로 응답을 전송할 수 있는 모드

## 정답

1. 정보 프레임 (I-frame)
2. 감독 프레임 (S-frame)
3. 비번호 프레임 (U-frame)
4. 비동기 균형 모드 (ABM)
5. 비동기 응답 모드 (ARM)

## 핵심 개념

HDLC의 I-frame은 사용자 데이터를 실어 나르고, S-frame은 흐름·오류 제어를 담당하며, U-frame은 링크 제어와 모드 설정에 사용된다.

## 문제 풀이

실제 데이터 전달은 정보 프레임, 상태와 흐름 제어는 감독 프레임, 번호 없는 제어 명령은 비번호 프레임이다. 두 국이 동등하게 동작하면 균형 모드(ABM), 종국이 주국의 명령 없이 응답할 수 있으면 ARM이다.

## 오답 및 혼동 포인트

S-frame도 제어에 관여하지만 순서 번호를 갖는 정보 프레임을 보조하는 감독 기능이다. U-frame은 링크 관리용이며, ABM과 ARM은 프레임 종류가 아니라 통신 모드다.

## 암기 포인트

I는 Information, S는 Supervisory, U는 Unnumbered의 머리글자다.
