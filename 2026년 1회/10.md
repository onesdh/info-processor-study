# 문제 10

## 문제

PLAYER 테이블에서 TEAM 테이블의 특정 칼럼을 참조하는 외래키 제약 조건을 추가하려 한다. 조건에 맞게 빈칸에 들어갈 예약어 또는 칼럼명을 쓰시오.

조건: 제약 조건명은 `TEAM_TF`, PLAYER의 `TEAM_ID`가 외래키이고 TEAM의 `TEAM_ID2`를 참조한다.

```sql
CREATE TABLE PLAYER (
  PLAYER_ID CHAR(7) NOT NULL,
  PLAYER_NAME VARCHAR2(20) NOT NULL,
  TEAM_ID CHAR(3) NOT NULL,
  PRIMARY KEY (PLAYER_ID),
  (1) TEAM_TF
  (2) KEY (3)
  (4) TEAM (5)
);
```

## 핵심 개념

외래키는 다른 테이블의 후보키나 기본키를 참조해 테이블 간 참조 무결성을 보장한다. 제약 조건 이름은 `CONSTRAINT`로 지정하고, 외래키 선언은 `FOREIGN KEY`로 시작한다.

## 문제 풀이

문장 골격은 `CONSTRAINT TEAM_TF FOREIGN KEY (TEAM_ID) REFERENCES TEAM (TEAM_ID2)`이다. 따라서 빈칸 순서는 CONSTRAINT, FOREIGN, TEAM_ID, REFERENCES, TEAM_ID2다.

## 오답 및 혼동 포인트

PLAYER의 `TEAM_ID`는 참조하는 쪽의 외래키다. 참조받는 TEAM의 칼럼은 조건에서 `TEAM_ID2`로 지정했으므로 두 칼럼을 바꾸어 쓰면 안 된다.

## 암기 포인트

제약 이름 → FOREIGN KEY(현재 테이블 칼럼) → REFERENCES(참조 테이블 칼럼) 순서다.
