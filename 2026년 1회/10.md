# 문제 10

## 문제

아래는 선수(PLAYER) 정보를 관리하는 테이블을 정의하는 SQL 문이다. 팀(TEAM) 테이블의 특정 칼럼을 참조하는 외래키 제약 조건을 추가하려 할 때, 괄호 ①~⑤에 들어갈 적절한 예약어(keyword) 또는 칼럼명을 아래 조건을 참고하여 쓰시오.

조건

외래키 제약 조건의 이름은 TEAM\_TF 로 지정한다.  
PLAYER 테이블의 TEAM\_ID 칼럼이 외래키 역할을 한다.  
TEAM 테이블의 TEAM\_ID2 칼럼을 참조 대상으로 한다.

SQL 문

CREATE TABLE PLAYER (  
&nbsp;&nbsp;PLAYER\_ID  CHAR(7)     NOT NULL,  
&nbsp;&nbsp;PLAYER\_NAME VARCHAR2(20) NOT NULL,  
&nbsp;&nbsp;TEAM\_ID   CHAR(3)     NOT NULL,  
&nbsp;&nbsp;PRIMARY KEY (PLAYER\_ID),  
&nbsp;&nbsp;( 1 ) TEAM\_TF  
&nbsp;&nbsp;( 2 ) KEY ( 3 )  
&nbsp;&nbsp;( 4 ) TEAM ( 5 )  
);

## 1. 문제에서 묻는 것
`CREATE TABLE` 문 안에서 **외래키(FOREIGN KEY) 제약조건**을 정의하는 문법의 빈칸 5개를 채우는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 키(Key)
| 키 | 의미 |
|---|---|
| **기본키(PK)** | 행을 **유일하게 식별**하는 열 (NULL·중복 불가) |
| **외래키(FK)** | **다른 테이블의 기본키를 참조**하는 열. 두 테이블을 연결 |

```text
 TEAM                         PLAYER
 ┌────────────┐               ┌───────────┬─────────┬──────────┐
 │ TEAM_ID2 PK│◀──── 참조 ────│ PLAYER_ID │ ...     │ TEAM_ID  │ (FK)
 └────────────┘               └───────────┴─────────┴──────────┘
```
### (2) 참조 무결성
외래키 값은 **참조 대상 테이블에 실제로 존재하는 값**(또는 NULL)이어야 한다. 팀이 없는 선수 데이터가 생기지 않게 막는다.

### (3) 테이블 레벨 외래키 문법
```sql
CONSTRAINT 제약조건이름
    FOREIGN KEY (이 테이블의 열)
    REFERENCES 참조테이블 (참조 열)
```
| 구문 요소 | 뜻 |
|---|---|
| `CONSTRAINT 이름` | 제약조건에 **이름 부여** |
| `FOREIGN KEY (열)` | **외래키로 지정할 열** |
| `REFERENCES 테이블(열)` | **참조 대상 테이블과 열** |

## 3. 문제 풀이
```sql
CREATE TABLE PLAYER (
  PLAYER_ID   CHAR(7)      NOT NULL,
  PLAYER_NAME VARCHAR2(20) NOT NULL,
  TEAM_ID     CHAR(3)      NOT NULL,
  PRIMARY KEY (PLAYER_ID),
  ( 1 ) TEAM_TF
  ( 2 ) KEY ( 3 )
  ( 4 ) TEAM ( 5 )
);
```
| 빈칸 | 근거 | 정답 |
|---|---|---|
| ① | 제약조건 이름(`TEAM_TF`) 앞 | **CONSTRAINT** |
| ② | `( ② ) KEY` → 외래키 | **FOREIGN** |
| ③ | 외래키 역할 칼럼 = PLAYER의 `TEAM_ID` | **TEAM_ID** |
| ④ | 참조를 나타내는 예약어 | **REFERENCES** |
| ⑤ | 참조 대상 = TEAM의 `TEAM_ID2` | **TEAM_ID2** |

완성된 문장:
```sql
CONSTRAINT TEAM_TF
FOREIGN KEY (TEAM_ID)
REFERENCES TEAM (TEAM_ID2)
```

> **정답: ① CONSTRAINT ② FOREIGN ③ TEAM_ID ④ REFERENCES ⑤ TEAM_ID2**

## 4. 암기 포인트
- 순서: `CONSTRAINT 이름 → FOREIGN KEY(열) → REFERENCES 대상(열)`.
- ③은 **자식(PLAYER)의 열**, ⑤는 **부모(TEAM)의 열** — 둘을 헷갈리지 말 것.
