# 문제 16

## 문제

다음은 특정 보안 공격 기법에 대한 설명이다. 해당하는 공격 기법의 명칭을 쓰시오.

공격자는 목표 대상이 업무 또는 관심사로 인해 자주 방문하는 합법적인 웹사이트를 사전에 파악한다.

해당 사이트에 악성코드를 삽입하여 감염시켜 놓고, 피해자가 해당 사이트에 접속하는 순간 피해자의 시스템에 악성 프로그램이 자동으로 설치되도록 유도한다. 공격자는 불특정 다수를 노리는 것이 아니라 특정 조직이나 인물을 겨냥하며, 접속자의 IP나 환경 조건을 확인하여 목표 대상에게만 선택적으로 악성코드가 실행되도록 설계하는 경우도 있다.

피해자는 정상적인 사이트를 방문했을 뿐이므로 감염 사실을 인지하기 어렵다는 특징이 있다.

워터링 홀 (Watering Hole)

## 1. 문제에서 묻는 것
"표적이 **자주 방문하는 합법 사이트**를 미리 감염시켜 두고 기다린다" → 어떤 공격인지 명칭을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 표적형 공격(APT)의 접근 방식
특정 조직·인물을 노릴 때 직접 침투하기 어려우면 **우회로**를 쓴다.

| 공격 | 방식 |
|---|---|
| 스피어 피싱 | 표적 **개인에게 맞춤 이메일** 전송 |
| **워터링 홀(Watering Hole)** | 표적이 **자주 가는 사이트를 감염**시켜 놓고 접속을 **기다림** |
| 드라이브 바이 다운로드 | 웹사이트 방문만으로 악성코드 **자동 다운로드** |
| 공급망 공격 | 소프트웨어 **업데이트·납품 경로**를 감염 |

### (2) 이름의 유래
사자가 **물웅덩이(Watering Hole)** 에 매복했다가 물 마시러 온 동물을 사냥하는 모습에서 따왔다.
```text
  공격자 ─(감염)─▶ [ 업계 포럼 / 협회 사이트 ] ◀─ 방문 ─ 표적 직원
                          │ 접속자 IP·환경 확인
                          └─ 표적일 때만 악성코드 실행  ──▶ 표적 PC 감염
```
### (3) 특징
- 피해자는 **정상 사이트**를 방문했을 뿐이라 **감염을 알아채기 어렵다.**
- 불특정 다수가 아닌 **특정 집단**이 대상. IP·환경 조건으로 **선별 감염**하기도 한다.

## 3. 문제 풀이
| 문제 단서 | 대응 |
|---|---|
| 표적이 업무상 **자주 방문하는 합법 사이트** 파악 | 워터링 홀 |
| 그 사이트에 **악성코드 삽입** | 매복(감염) |
| **특정 조직·인물** 겨냥, 조건 확인 후 선택 실행 | 표적형 |

> **정답: 워터링 홀 (Watering Hole)**

## 4. 암기 포인트
- **표적이 모이는 곳을 감염** = 워터링 홀. **메일로 표적 속임** = 스피어 피싱.
