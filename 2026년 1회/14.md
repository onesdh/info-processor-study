# 문제 14

## 문제

다음 Python 코드를 실행했을 때 출력값을 쓰시오.

```python
def f(a):
    m = [[x] for x in a]
    b = m[:]
    for i in range(len(b) - 1):
        b[i + 1] += b[i]
    return sum(len(x) for x in m)

print(f([1, 2, 3, 4]))
```

<summary><strong>정답 보기</strong></summary>

10

</details>

## 핵심 개념

리스트 슬라이스 `m[:]`은 바깥 리스트만 복사하는 얕은 복사다. 안에 들어 있는 하위 리스트 객체는 원본과 복사본이 공유한다.

## 문제 풀이

처음 `m`은 `[[1],[2],[3],[4]]`이고 `b`는 같은 하위 리스트들을 가리킨다. `b[1] += b[0]`부터 각 하위 리스트가 제자리에서 확장되므로 `m`의 하위 리스트 길이는 차례로 1, 2, 3, 4가 된다. 합은 10이다.

## 오답 및 혼동 포인트

`m[:]`이 모든 내부 리스트까지 복제한다고 생각하면 합을 잘못 계산한다. 리스트의 `+=`는 기존 리스트를 확장하므로 별칭으로 연결된 `m`에도 변화가 보인다.

## 암기 포인트

얕은 복사는 바깥 컨테이너만 새로 만들고 내부 객체는 공유한다.
