# 문제 14

## 문제

아래 파이썬 코드를 실행했을 때 출력되는 값을 쓰시오.

```
def f(a):
    m = [[x] for x in a]
    b = m[:]
    for i in range(len(b) - 1):
        b[i+1] += b[i]
    return sum(len(x) for x in m)

print(f([1, 2, 3, 4]))
```

## 1. 문제에서 묻는 것
**얕은 복사(shallow copy)** 의 함정을 묻는 문제다. `b = m[:]`로 복사했는데 `b`를 바꾸면 **`m`도 바뀐다**는 것을 알아야 한다.

## 2. 먼저 알아야 할 개념
### (1) 리스트 안의 리스트 = 참조(주소)
리스트는 안에 **객체 자체가 아니라 객체를 가리키는 참조**를 담는다.
```text
 m  ──▶ [ ●─────▶[1] ,  ●─────▶[2] ,  ●─────▶[3] ,  ●─────▶[4] ]
```
### (2) 얕은 복사
`b = m[:]` 는 **바깥 리스트만 새로 만들고**, 안쪽 리스트 4개는 **같은 객체를 공유**한다.
```text
 m ──▶ [ ●, ●, ●, ● ]──┐
 b ──▶ [ ●, ●, ●, ● ]──┤   (바깥 껍데기만 둘, 안쪽 [1],[2],[3],[4]는 공유)
                       ▼
                 [1] [2] [3] [4]
```
### (3) `+=`는 제자리(in-place) 연산
리스트에서 `b[i+1] += b[i]` 는 새 리스트를 만들지 않고 **`b[i+1]` 객체 자체에 `b[i]`의 원소를 이어 붙인다**(`extend`).
공유된 객체이므로 `m`에서도 같은 변화가 보인다.

## 3. 실행 과정
`f([1, 2, 3, 4])` → `m = [[1],[2],[3],[4]]`, `b = m[:]` (안쪽 공유)

`range(len(b)-1)` = `range(3)` → i = 0, 1, 2

| i | 실행 | 변화 후 b (= m 안쪽) |
|---:|---|---|
| 초기 | | `[1], [2], [3], [4]` |
| 0 | `b[1] += b[0]` → `[2] + [1]` | `[1], [2,1], [3], [4]` |
| 1 | `b[2] += b[1]` → `[3] + [2,1]` | `[1], [2,1], [3,2,1], [4]` |
| 2 | `b[3] += b[2]` → `[4] + [3,2,1]` | `[1], [2,1], [3,2,1], [4,3,2,1]` |

`m`의 안쪽 리스트도 같은 객체이므로 위와 같다.
`sum(len(x) for x in m)` = 1 + 2 + 3 + 4 = **10**

> **정답: `10`**

## 4. 암기 포인트
- 얕은 복사(`[:]`, `copy()`, `list()`)는 **안쪽 객체를 공유**. 완전히 분리하려면 `copy.deepcopy`.
- `b[i+1] += b[i]`는 새 객체 생성이 아니라 **기존 리스트에 추가**(in-place).
- 만약 `b[i+1] = b[i+1] + b[i]`라면 새 리스트가 만들어져 `m`은 변하지 않아 답이 4가 된다.
