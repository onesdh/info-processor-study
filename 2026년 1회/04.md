# 문제 04

## 문제

다음은 비기능적 요구사항에 대한 설명이다. 각 항목이 의미하는 요구사항 유형을 보기에서 골라 쓰시오.

1. 시스템 운영 중 로그 관리 및 모니터링 기능을 제공해야 한다.  
2. 시스템 운영 시 최소 메모리 용량을 확보해야 하며, 자원 사용량은 제한 범위 내에 있어야 한다.  
3. 사용자 요청에 대한 응답 시간은 최대 1분을 초과하지 않아야 한다.

## 1. 문제에서 묻는 것
**비기능 요구사항**을 설명하는 3개 문장이 어떤 유형(운영/자원/성능…)에 해당하는지 보기에서 고르는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 기능 vs 비기능 요구사항
| 구분 | 내용 | 예 |
|---|---|---|
| **기능 요구사항** | 시스템이 **무엇을 해야 하는가** | 회원가입, 결제, 검색 |
| **비기능 요구사항** | 기능을 **어떤 품질/제약**으로 제공할 것인가 | 응답 시간, 보안, 가용성 |

### (2) 비기능 요구사항 유형
| 유형 | 의미 | 예 |
|---|---|---|
| 성능 | **처리 속도·응답 시간·처리량** | 응답 시간 1초 이내 |
| 자원 | **CPU·메모리·디스크** 등 사용량 제한/확보 | 최소 메모리 8GB, 사용량 제한 |
| 운영 | **운영·관리** 편의 (로그, 모니터링, 백업) | 로그 관리, 모니터링 |
| 신뢰성 | 오류 없이 **일정 수준 유지** | 장애 발생률 |
| 가용성 | 필요한 때 **사용 가능**한 비율 | 연중 99.9% 가동 |
| 유지보수성 | 수정·개선의 **용이성** | 모듈화, 문서화 |
| 이식성 | 다른 환경으로 **옮기기** 쉬운 정도 | OS/브라우저 호환 |
| 보안 | 접근 통제, 암호화 | 개인정보 암호화 |
| 품질 | 품질 기준·표준 준수 | 코딩 표준 |

## 3. 문제 풀이
| 번호 | 문장의 핵심 단서 | 유형 |
|---|---|---|
| 1 | 시스템 **운영 중** 로그 관리·**모니터링** | **운영** |
| 2 | **최소 메모리** 확보, **자원 사용량** 제한 | **자원** |
| 3 | 사용자 요청의 **응답 시간** 최대 1분 | **성능** |

## 4. 헷갈리는 포인트
- "모니터링/로그" → 시스템을 **운영·관리**하는 일이라서 *운영*. (유지보수성은 *고치기 쉬운지*)
- "메모리·CPU·디스크" → **자원**. (성능은 *속도* 문제)
- "응답 시간·처리량" → **성능**.

> **정답: 1. 운영 / 2. 자원 / 3. 성능**
