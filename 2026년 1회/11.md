# 문제 11

## 문제

두 호스트 a, b의 IP 주소와 서브넷 마스크가 주어졌을 때, 각 호스트가 속한 네트워크 주소를 CIDR 표기법으로 쓰시오.

조건

· 호스트 a의 IP 주소: 192.168.11.20  
· 호스트 b의 IP 주소: 192.168.12.200  
· 서브넷 마스크: 255.255.254.0

구하는 것

a. 호스트 a (192.168.11.20) 가 속한 네트워크 주소  
b. 호스트 b (192.168.12.200) 가 속한 네트워크 주소

<details>
<summary><strong>정답 보기</strong></summary>

a. 192.168.10.0/23

b. 192.168.12.0/23

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
IP 주소와 서브넷 마스크 `255.255.254.0`이 주어졌을 때, 각 호스트의 **네트워크 주소를 CIDR 표기**로 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 서브넷 마스크와 CIDR
- 서브넷 마스크의 **1이 연속된 비트 수**가 프리픽스 길이다.
```text
 255.255.254.0 = 11111111.11111111.1111111 0.00000000
                 └ 8 ┘     └ 8 ┘     └ 7 ┘  → 8+8+7 = /23
```
- **CIDR 표기**: `네트워크주소/프리픽스` → `192.168.10.0/23`

### (2) 네트워크 주소 구하는 법
**IP 주소 AND 서브넷 마스크** = 네트워크 주소. 마스크가 `254`(= 11111110)인 옥텟은 **2씩 묶은 블록**으로 생각하면 빠르다. (블록 크기 = 256 − 254 = **2**)
```text
 3번째 옥텟 블록 : 0~1 | 2~3 | ... | 10~11 | 12~13 | ...
```

## 3. 풀이
**a. 192.168.11.20**
| 옥텟 | IP | 마스크 | AND |
|---|---:|---:|---:|
| 1 | 192 | 255 | 192 |
| 2 | 168 | 255 | 168 |
| 3 | 11 = `00001011` | 254 = `11111110` | `00001010` = **10** |
| 4 | 20 | 0 | 0 |

→ **192.168.10.0/23** (범위 192.168.10.0 ~ 192.168.11.255)

**b. 192.168.12.200**
| 옥텟 | 3번째: 12 = `00001100` AND `11111110` = `00001100` = **12** |
|---|---|

→ **192.168.12.0/23** (범위 192.168.12.0 ~ 192.168.13.255)

> **정답: a. 192.168.10.0/23 / b. 192.168.12.0/23**

## 4. 암기 포인트
- /23 → 3번째 옥텟 블록 크기 2: 짝수에서 시작 (10, 12, 14 …).
- 11은 홀수이므로 **한 칸 내린 10**이 네트워크 주소. 12는 짝수이므로 그대로 12.
