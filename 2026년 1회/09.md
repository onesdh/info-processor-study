# 문제 09

## 문제

아래 조건을 참고하여 각 SQL 구문을 실행했을 때 반환되는 행(Row)의 수를 쓰시오.  
(단, DEPT 칼럼은 학과명이다.)

테이블 조건

STUDENT 테이블에는 다음 세 학과의 학생 정보가 저장되어 있다.  
컴퓨터과  50명  · 인터넷과  100명  · 사무자동화과  50

SQL 구문

1. SELECT DEPT FROM STUDENT;  
2. SELECT DISTINCT DEPT FROM STUDENT;  
3. SELECT COUNT(DISTINCT DEPT) FROM STUDENT  
&nbsp;&nbsp;&nbsp;&nbsp;WHERE DEPT = '컴퓨터과';

<details>
<summary><strong>정답 보기</strong></summary>

1. 200

2. 3

3. 1

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
세 SQL의 **반환되는 행 수**를 구하는 문제다. `SELECT`, `DISTINCT`, `COUNT(DISTINCT ...)`의 차이를 이해해야 한다.

## 2. 먼저 알아야 할 개념
### (1) 데이터 상황
`STUDENT` 테이블 (한 행 = 학생 한 명)

| DEPT | 인원(행 수) |
|---|---:|
| 컴퓨터과 | 50 |
| 인터넷과 | 100 |
| 사무자동화과 | 50 |
| **합계** | **200행** |

### (2) 핵심 문법
| 문법 | 의미 |
|---|---|
| `SELECT DEPT` | 모든 행의 DEPT 값을 출력 (**중복 허용**, 행 수 그대로) |
| `SELECT DISTINCT DEPT` | **중복을 제거**하고 서로 다른 값만 출력 |
| `COUNT(DISTINCT DEPT)` | 서로 다른 값의 **개수를 세어 1행**으로 반환 |
| `WHERE` | 조건에 맞는 **행만 먼저 걸러냄** |

### (3) 실행 순서
`FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY`. 즉 `WHERE`가 `SELECT`(COUNT 포함)보다 **먼저** 실행된다.

## 3. 풀이
**① `SELECT DEPT FROM STUDENT;`**
- 조건·중복제거 없음 → **200행** (학생 수 그대로)

**② `SELECT DISTINCT DEPT FROM STUDENT;`**
```text
 컴퓨터과(50행)     ─┐
 인터넷과(100행)    ─┼─ 중복 제거 ─▶ 컴퓨터과 / 인터넷과 / 사무자동화과  = 3행
 사무자동화과(50행) ─┘
```
- 서로 다른 학과 3개 → **3행**

**③ `SELECT COUNT(DISTINCT DEPT) FROM STUDENT WHERE DEPT = '컴퓨터과';`**
1. `WHERE`로 컴퓨터과 50행만 남김
2. 그 50행의 DEPT는 모두 '컴퓨터과' → 서로 다른 값 **1개**
3. `COUNT(...)`는 집계 함수라 결과가 **항상 1행** (값은 1)

→ 반환 행 수는 **1행** (그 행의 값은 1).

> **정답: 1. 200 / 2. 3 / 3. 1**

## 4. 암기 포인트
- 집계 함수(`COUNT`, `SUM`…)만 있는 SELECT는 `GROUP BY`가 없으면 **항상 1행**을 반환한다.
- `COUNT(DISTINCT 열)`: **중복 제외 개수**, `COUNT(*)`: 전체 행 수.
