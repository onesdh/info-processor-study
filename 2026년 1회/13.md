# 문제 13 — Python 역방향 슬라이스 간격

## 문제

다음 Python 코드의 출력값을 쓰시오.

```python
lst = list(range(10))
for c in lst[::-2]:
    print(c, end='A')
print()
```

<details>
<summary><strong>정답 보기</strong></summary>

9A7A5A3A1A

</details>

<summary><strong>상세 해설</strong></summary>

## 핵심 개념

슬라이스 `[start:stop:step]`의 세 번째 값은 이동 간격이다. `[::-2]`는 끝에서 시작해 인덱스를 두 칸씩 줄인다.

## 문제 풀이

`range(10)`은 0부터 9까지다. 이를 역방향으로 두 칸씩 읽으면 9, 7, 5, 3, 1이다. 각 숫자 뒤에 `A`를 붙이므로 `9A7A5A3A1A`가 된다.

## 오답 및 혼동 포인트

역방향이라고 모든 원소를 출력하는 것이 아니다. 간격이 -2이므로 짝수 인덱스 쪽 원소는 건너뛴다.

## 암기 포인트

음수 step은 뒤에서 앞으로 이동하고, `-2`는 한 칸씩 건너뛴다.
