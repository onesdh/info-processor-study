# 문제 07 — Java 오버라이딩과 오버로딩

## 문제

다음 Java 코드의 출력값을 작성하시오.

```java
class A {
    String f(Object x) {
        return "1";
    }

    String g() {
        return f("a");
    }
}

class B extends A {
    String f(Object x) {
        return "2";
    }

    String f(String x) {
        return "3";
    }
}

public class Main {
    public static void main(String[] args) {
        A a = new B();
        System.out.println(a.g());
    }
}
```

## 핵심 개념

오버로딩은 매개변수 목록이 다른 같은 이름의 메서드를 여러 개 정의하는 것이고, 오버라이딩은 하위 클래스가 상위 클래스의 같은 시그니처 메서드를 다시 구현하는 것이다.

## 문제 풀이

`a`의 선언 타입은 A이므로 `g()` 안의 `f("a")` 호출은 컴파일 시점에 A의 `f(Object)`로 결정된다. 실행 시점에는 실제 객체가 B이므로 오버라이딩한 `B.f(Object)`가 실행되어 문자열 `2`를 반환한다.

## 오답 및 혼동 포인트

B에는 `f(String)`도 있지만, `g()`의 본문은 A 클래스에서 컴파일되므로 그 오버로드는 후보가 아니다. 동적 바인딩은 이미 선택된 시그니처의 오버라이딩 구현을 고른다.

## 암기 포인트

오버로드 선택은 컴파일 시 타입 기준, 오버라이딩 구현 선택은 실행 시 객체 기준이다.
