# 문제 07

## 문제

다음은 Java 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
class A {
    String f(Object x) {
        return "1";
    }

    String g() {
        return f("a");
    }
}

class B extends A {
    String f(Object x) {
        return "2";
    }

    String f(String x) {
        return "3";
    }
}

public class Main {
    public static void main(String[] args) {
        A a = new B();
        System.out.println(a.g());
    }
}
```

## 1. 문제에서 묻는 것
**오버로딩(Overloading)** 과 **오버라이딩(Overriding)** 이 함께 나오는 코드에서, `a.g()`가 최종적으로 어떤 `f`를 호출하는지 가려내는 문제다. 함정이 있는 유형이다.

## 2. 먼저 알아야 할 개념
### (1) 오버라이딩 vs 오버로딩
| 구분 | 오버라이딩(재정의) | 오버로딩(중복 정의) |
|---|---|---|
| 의미 | 부모 메서드를 **자식이 같은 시그니처로 다시 정의** | **같은 이름, 다른 매개변수**로 여러 개 정의 |
| 위치 | 부모-자식(상속) 관계 | 같은 클래스(또는 상속 포함) |
| 결정 시점 | **실행 시** (실제 객체 타입) | **컴파일 시** (변수의 선언 타입, 인자 타입) |

### (2) 호출이 결정되는 2단계
1. **컴파일 시**: 변수의 **선언 타입(A)** 에 있는 메서드 중 **어떤 시그니처**를 호출할지 정한다.
2. **실행 시**: 그 시그니처를 **실제 객체(B)** 가 오버라이딩했다면 **B의 것**이 실행된다.

## 3. 코드 구조
```text
A : f(Object x) → "1"
    g()         → return f("a");        // A 안에서 호출
B extends A :
    f(Object x) → "2"     ← A.f(Object)를 오버라이딩
    f(String x) → "3"     ← 새 메서드(오버로딩). A에는 없음!
```
`A a = new B();` → 변수 타입은 **A**, 실제 객체는 **B**.

## 4. 실행 과정
`a.g()` 호출 → 실제 객체가 B이지만 `g()`는 B가 재정의하지 않았으므로 **A의 `g()`** 실행.
`g()` 안의 `f("a")`:

| 단계 | 판단 |
|---|---|
| 컴파일 | `g()`는 **클래스 A 안**의 코드다. A가 가진 `f`는 `f(Object)` **하나뿐**. (B의 `f(String)`은 A에서 보이지 않음) → `f(Object)`로 결정 |
| 실행 | 실제 객체가 B이고 B가 `f(Object)`를 오버라이딩 → **B.f(Object) 실행** → `"2"` |

```text
 a.g() ─▶ A.g() ─▶ f("a") ─(컴파일: f(Object))─▶ B.f(Object) ─▶ "2"
                                                 ✗ B.f(String)("3") 은 선택되지 않음
```

> **정답: `2`**

## 5. 흔한 오답
- "인자가 `"a"`(String)니까 `f(String)` → 3": **틀림**. `g()`가 A 안에 있어 A의 시그니처 `f(Object)`로 이미 결정된다.
- "A의 f니까 1": **틀림**. 오버라이딩된 B의 f가 실행된다.

## 6. 암기 포인트
- 오버로딩은 **컴파일 타임(선언 타입)**, 오버라이딩은 **런타임(실제 객체)**.
- 메서드 호출은 "선언 타입에서 시그니처 결정 → 실제 객체의 재정의 실행" 순서로 푼다.
