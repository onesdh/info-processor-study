# 문제 12

## 문제

다음은 C언어에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
struct fns {
    int* (*fn)(int*);
} mine;

int* dummy(int *d) {
    return d + 1;
}

int main() {
    struct fns mine;
    int n[] = {16, 32};
    mine.fn = dummy;
    printf("%x", *mine.fn(n));
    return 0;
}
```

20

## 1. 문제에서 묻는 것
**함수 포인터**를 멤버로 가진 구조체를 사용하는 코드에서 출력값을 구하는 문제다. 낯설어 보이지만 하나씩 풀면 쉽다.

## 2. 먼저 알아야 할 개념
### (1) 함수 포인터
함수도 메모리에 놓여 있으므로 **주소**가 있다. 그 주소를 담는 변수가 함수 포인터다.
```c
int* (*fn)(int*);
```
읽는 법: `fn`은 **(int*를 받아서 int*를 반환하는 함수)를 가리키는 포인터**.
- 변수 이름 `fn`을 먼저 찾고, `(*fn)`이 있으므로 "포인터", 뒤의 `(int*)`가 매개변수, 앞의 `int*`가 반환형.

### (2) 구조체 멤버로서의 함수 포인터
```c
struct fns { int* (*fn)(int*); } mine;
mine.fn = dummy;        // dummy 함수의 주소를 저장
mine.fn(n);             // dummy(n) 호출과 동일
```
### (3) 포인터 연산
`d + 1`은 **다음 `int` 칸의 주소**(4바이트 뒤). 배열 이름 `n`은 첫 원소 주소다.
```text
 n :  [16][32]
       ^   ^
      n   n+1
```
### (4) `printf("%x")`
정수를 **16진수**로 출력한다. (10진수 32 = 16진수 20)

## 3. 실행 과정
1. `int n[] = {16, 32};`
2. `mine.fn = dummy;` → `mine.fn`이 `dummy`를 가리킴
3. `mine.fn(n)` → `dummy(n)` 실행 → `return d + 1;` = `&n[1]` (n의 두 번째 칸 주소)
4. 연산자 우선순위: `*mine.fn(n)` = `*( mine.fn(n) )` → 반환된 주소의 **값** = `n[1]` = **32**
5. `%x`로 32를 출력 → **`20`**

| 단계 | 값 |
|---|---|
| `mine.fn(n)` 반환 | `&n[1]` |
| `*mine.fn(n)` | 32 (10진수) |
| `%x` 출력 | **20** (16진수) |

> **정답: `20`** (32를 10진수로 쓰면 오답!)

## 4. 암기 포인트
- `(*fn)`이 보이면 **함수 포인터**.
- `%x`는 16진수 (`%d`는 10진수). 16진 변환: 32 = 2×16 + 0 → `20`.
