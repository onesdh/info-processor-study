# 문제 12 — C 함수 포인터와 16진수 출력

## 문제

다음 C언어 코드의 출력값을 쓰시오.

```c
#include <stdio.h>

struct fns {
    int *(*fn)(int *);
} mine;

int *dummy(int *d) {
    return d + 1;
}

int main() {
    struct fns mine;
    int n[] = {16, 32};
    mine.fn = dummy;
    printf("%x", *mine.fn(n));
    return 0;
}
```

## 정답

20

## 핵심 개념

함수 포인터는 함수의 주소를 저장해 간접 호출한다. `d + 1`은 정수 포인터를 다음 원소로 이동시키며, `%x`는 정수를 16진수로 출력한다.

## 문제 풀이

`mine.fn`은 `dummy`를 가리킨다. `dummy(n)`은 `n+1`, 즉 `&n[1]`을 반환하고 역참조하면 32다. `%x`는 32를 16진수로 바꿔 `20`을 출력한다.

## 오답 및 혼동 포인트

포인터에 1을 더하면 1바이트가 아니라 가리키는 자료형 크기만큼 이동한다. 반환 포인터를 역참조해 얻는 값은 배열의 두 번째 원소 32다.

## 암기 포인트

십진수 32는 16진수 20이며, `%x` 출력은 접두사 없이 `20`이다.
