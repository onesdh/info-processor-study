# 문제 20

## 문제

다음은 응집도의 유형에 대한 설명이다. 괄호 안에 들어갈 알맞은 용어를 쓰시오.

( 1 ) 은/는 모듈이 다수의 관련 기능을 가질 때, 모듈 안의 구성요소들이 그 기능을 순차적으로 수행하는 경우의 응집도이다.  
( 2 ) 은/는 동일한 입력과 출력을 사용하여 서로 다른 기능을 수행하는 활동들이 모여 있는 경우의 응집도이다.  
( 3 ) 은/는 모듈 내부의 모든 기능이 단일한 목적을 위해 수행되는 경우의 응집도이다.

## 1. 문제에서 묻는 것
**응집도 유형 3가지**를 설명만 보고 이름을 맞히는 문제다. 절차 / 교환(통신) / 기능 응집도를 구분해야 한다.

## 2. 먼저 알아야 할 개념
### (1) 응집도(Cohesion)
**한 모듈 안의 구성요소들이 서로 얼마나 밀접하게 관련되어 있는가**를 나타낸다. 한 가지 일에 집중할수록 **응집도는 높을수록 좋다**. (결합도는 *낮을수록* 좋음)

### (2) 응집도 7단계 (약 → 강)
```text
 우연적 < 논리적 < 시간적 < 절차적 < 교환(통신)적 < 순차적 < 기능적
 (나쁨)                                                    (좋음)
```
| 유형 | 설명 |
|---|---|
| 우연적 | 서로 관련 없는 기능이 우연히 한 모듈에 |
| 논리적 | 논리적으로 비슷한 기능끼리 묶고 매개변수로 선택 |
| 시간적 | 같은 **시간**에 실행되는 기능(초기화 등) |
| **절차적** | 기능들이 **정해진 순서(절차)대로** 수행되어야 할 때 |
| **교환(통신)적** | 서로 다른 기능이 **같은 입력/출력 데이터**를 사용 |
| 순차적 | 앞 기능의 **출력이 다음 기능의 입력** |
| **기능적** | **단일한 목적** 하나만 수행 |

## 3. 문제 풀이
| 문장 | 단서 | 정답 |
|---|---|---|
| (1) 다수의 관련 기능을 **순차적으로 수행** | 순서대로 실행 | **절차적** |
| (2) **동일한 입력과 출력**을 사용하는 서로 다른 기능 | 같은 데이터 공유 | **교환(통신)적** |
| (3) 모든 기능이 **단일한 목적** | 한 가지 일에 집중 | **기능적** |

### 헷갈리기 쉬운 두 쌍
| 비교 | 구분 |
|---|---|
| 절차적 vs 순차적 | 절차적은 **실행 순서**만 중요. 순차적은 앞 **출력이 뒤 입력**으로 이어짐 |
| 교환적 vs 순차적 | 교환적은 **같은 데이터**를 각각 사용. 순차적은 **데이터가 흘러감** |

> **정답: 1. 절차(적) / 2. 교환(통신)(적) / 3. 기능(적)**

## 4. 암기 포인트
- 응집도 순서: **우-논-시-절-교(통)-순-기** ("우논시절교순기").
- 가장 좋은 응집도 = **기능적**, 가장 나쁜 응집도 = **우연적**.
