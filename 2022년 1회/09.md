# 문제 09

## 문제

다음 중, 설명에 대한 답을 영어 약자로 작성하시오.

키보드나 마우스와 같은 장치 없이 말이나 행동 그리고 감정과 같은 인간의 자연스러운 표현으로 컴퓨터나 장치를 제어할 수 있는 환경

## 1. 문제에서 묻는 것
"키보드·마우스 없이 **말, 행동, 감정** 같은 **자연스러운 표현**으로 컴퓨터를 제어하는 환경" → 영어 약자를 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 사용자 인터페이스의 발전
| 인터페이스 | 설명 | 예 |
|---|---|---|
| **CLI** (Command Line Interface) | **명령어 텍스트** 입력 | 터미널, 명령 프롬프트 |
| **GUI** (Graphical User Interface) | **그래픽(아이콘·창)** 과 마우스 | 윈도우, 맥OS |
| **NUI** (Natural User Interface) | **자연스러운 몸짓·음성·표정** 등으로 조작 | 음성 비서(시리), 제스처 인식, 터치, 시선 추적 |

### (2) NUI (Natural User Interface)
기존의 키보드·마우스 같은 **입력 장치 없이**, 사람이 일상에서 쓰는 **말, 행동(제스처), 감정** 같은 **자연스러운 표현**으로 장치를 제어하는 인터페이스다.
```text
 CLI(텍스트) ─▶ GUI(그래픽·마우스) ─▶ NUI(음성·제스처·터치 등 자연스러운 상호작용)
```
## 3. 문제 풀이
| 단서 | NUI |
|---|---|
| **키보드·마우스 같은 장치 없이** | ✅ |
| **말·행동·감정** 등 **인간의 자연스러운 표현**으로 제어 | ✅ |

> **정답: NUI (Natural User Interface)**
