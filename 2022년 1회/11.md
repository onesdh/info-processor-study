# 문제 11

## 문제

다음 Java 코드 중에서 밑줄에 들어갈 알맞는 코드를 작성하시오.

```
class Car implements Runnable{
  int a;

  public void run(){
     system.out.println("message")
  }
}

public class Main{
  public static void main(String args[]){
    Thread t1 = new Thread(new ___());
    t1.start();
  }
}


```

## 1. 문제에서 묻는 것
Java **스레드(Thread)** 생성 방식에서, `Runnable`을 구현한 클래스의 이름을 `Thread` 생성자에 넘기는 코드를 완성하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 스레드(Thread)
프로그램 안에서 **동시에 실행되는 작업 흐름**. 여러 작업을 병렬로 처리할 때 사용한다.

### (2) 스레드를 만드는 두 가지 방법
| 방법 | 설명 |
|---|---|
| **Runnable 인터페이스 구현** | 실행할 작업(`run()`)을 가진 클래스를 만들고 **`Thread`에 전달** |
| Thread 클래스 상속 | `Thread`를 상속해 `run()` 재정의 |

### (3) Runnable 방식의 흐름
```java
class Car implements Runnable {          // ① 작업 클래스: run()을 구현
    public void run() { System.out.println("message"); }
}
Thread t1 = new Thread(new Car());       // ② 작업 객체를 Thread에 전달
t1.start();                              // ③ 새 스레드에서 run()이 실행됨
```
```text
 main 스레드 ──start()──▶ 새 스레드 ─ run() 실행 ─ "message" 출력
```
- 주의: `start()`가 새 스레드를 만들어 `run()`을 호출한다. `run()`을 직접 부르면 일반 메서드 호출일 뿐 **새 스레드가 생기지 않는다.**

## 3. 풀이
`new Thread( ○ )` 의 인자는 **`Runnable`을 구현한 객체**여야 한다. `Car`가 `Runnable`을 구현하므로 `new Car()`.

| 빈칸 | 정답 | 이유 |
|---|---|---|
| `new ___()` | **Car** | `Runnable`을 구현한 클래스의 생성자 |

> **정답: `Car`**
