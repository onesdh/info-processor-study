# 문제 11 — Runnable 구현 객체 생성

## 문제

Car가 Runnable 인터페이스를 구현하고 Thread의 생성자에 전달된다. 빈칸에 들어갈 클래스 이름을 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

Car

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

Runnable 구현 객체는 Thread 생성자에 전달되어 별도 실행 스레드에서 run 메서드를 수행한다.

## 풀이

빈칸에는 new Car()가 들어가며, 전체 구문은 Thread t1 = new Thread(new Car()); 형태다.

## 오답 분석

Thread 클래스 자체를 넘기는 문맥이 아니다. Car는 Runnable을 구현했으므로 생성해 전달한다.

## 암기 포인트

Runnable 구현 객체를 Thread에 넘긴다.
