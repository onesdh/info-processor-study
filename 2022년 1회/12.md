# 문제 12 — JUnit

## 문제

Java에서 xUnit 계열 단위 테스트를 작성하고 실행하는 테스트 프레임워크를 쓰시오.

## 정답

JUnit

## 핵심 개념

JUnit은 Java 코드의 단위 테스트를 자동화하는 테스트 프레임워크다.

## 풀이

테스트 메서드와 단언문을 작성해 코드가 기대한 결과를 내는지 검증한다.

## 오답 분석

Selenium은 웹 UI 자동화 도구이고, xUnit은 언어별 단위 테스트 프레임워크 계열을 가리킨다.

## 암기 포인트
