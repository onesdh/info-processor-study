## 1. 문제에서 묻는 것
"**자바**용 **xUnit** 단위 테스트 프레임워크" → 이름을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 단위 테스트(Unit Test)
프로그램의 **가장 작은 단위(함수·메서드·클래스)** 가 의도대로 동작하는지 **개발자가 직접 검사**하는 테스트다.

### (2) xUnit
언어별로 만들어진 **단위 테스트 프레임워크 계열**을 통칭한다.
| 이름 | 언어 |
|---|---|
| **JUnit** | **Java** |
| NUnit | .NET(C#) |
| PHPUnit | PHP |
| CppUnit | C++ |
| unittest / pytest | Python |

### (3) JUnit
```java
@Test
void 덧셈_테스트() {
    assertEquals(5, calc.add(2, 3));    // 예상 결과와 실제 결과를 비교
}
```
- **테스트를 자동 실행**하고 통과/실패를 보고
- 테스트 코드를 **정형화**해 단위 테스트를 쉽게 작성·반복(회귀 테스트에도 활용)

## 3. 문제 풀이
| 단서 | JUnit |
|---|---|
| **자바** 프로그래밍 언어용 **xUnit** 테스트 기법 | ✅ |
| 숨겨진 단위 테스트를 끌어내어 **정형화**, 단위 테스트를 쉽게 해 주는 **프레임워크** | ✅ |
