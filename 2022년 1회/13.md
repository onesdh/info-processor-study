## 1. 문제에서 묻는 것
보기 중 **블랙박스 테스트 기법 3가지**를 고르는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 블랙박스 vs 화이트박스
| 구분 | 블랙박스 테스트 | 화이트박스 테스트 |
|---|---|---|
| 관점 | **내부 구조를 모르고** 입력→출력(명세)만 검증 | **소스 코드 내부 논리**를 보고 검증 |
| 기법 | **동치 분할, 경계값 분석, 원인-결과 그래프, 오류 예측, 결정 테이블, 상태 전이** | **문장/분기/조건 커버리지, 경로 테스트(기본 경로 테스트)** |

### (2) 블랙박스 기법 설명
| 기법 | 핵심 |
|---|---|
| **동치 분할(Equivalence Partitioning)** | 입력을 같은 결과가 나오는 **구간**으로 나눠 **대표값** 테스트 |
| **경계값 분석(Boundary Value Analysis)** | **구간 경계**의 값 집중 테스트 |
| **원인-결과 그래프(Cause-Effect Graph)** | 입력(원인)과 출력(결과)의 **논리 관계**를 그래프로 표현해 테스트 케이스 도출 |

## 3. 보기 분석
| 보기 | 분류 | 블랙박스? |
|---|---|:---:|
| ㄱ. Cause-Decision Graph | (존재하지 않는 용어, 함정) | ❌ |
| ㄴ. Decision Coverage | 화이트박스(결정 커버리지) | ❌ |
| **ㄷ. Boundary Value Analysis** | 블랙박스 | ✅ |
| **ㄹ. Equivalence Partitioning** | 블랙박스 | ✅ |
| ㅁ. Statement Coverage | 화이트박스(문장 커버리지) | ❌ |
| **ㅂ. Cause-Effect Graph** | 블랙박스 | ✅ |
| ㅅ. Base Path Testing | 화이트박스(기본 경로) | ❌ |
| ㅇ. Base Path Coverage | 화이트박스 | ❌ |
| ㅈ. Boundary Division Analysis | (존재하지 않는 용어) | ❌ |

> **정답: ㄷ, ㄹ, ㅂ**

## 4. 암기 포인트
- 블랙박스: **동치·경계값·원인결과·오류예측·결정테이블**. **"커버리지·경로" = 화이트박스**.
