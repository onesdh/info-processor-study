# 문제 19

## 문제

다음 소스코드가 실행할 때의 출력값을 작성하시오.

```
#include <stdio.h>
int isPrime(int number) {
  int i;
  for (i=2; i<number; i++) {
    if (number % i == 0) return 0;
  }
  return 1;
}

int main(void) {
  int number = 13195, max_div=0, i;
  for (i=2; i<number; i++)
  if (isPrime(i) == 1 && number % i == 0) max_div = i;
  printf("%d", max_div);
  return 0;
}
```

<details>
<summary><strong>정답 보기</strong></summary>

29

</details>

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
13195의 약수 중 **소수이면서 가장 큰 값**(가장 큰 소인수)을 구하는 코드의 출력을 묻는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 소수(Prime)
**1과 자기 자신만을 약수**로 가지는 수. 예) 2, 3, 5, 7, 11, 13 …

### (2) `isPrime(number)`
```c
for (i = 2; i < number; i++)
    if (number % i == 0) return 0;     // 2 ~ number-1 중 나누어떨어지는 수가 있으면 소수 아님
return 1;                               // 없으면 소수
```
### (3) main 로직
```c
for (i = 2; i < 13195; i++)
    if (isPrime(i) == 1 && 13195 % i == 0)   // i가 소수이고 13195의 약수이면
        max_div = i;                           // 가장 최근(=가장 큰) 값으로 갱신
```
## 3. 소인수분해
```text
 13195 = 5 × 2639 = 5 × 7 × 377 = 5 × 7 × 13 × 29
```
| 소인수 | 5 | 7 | 13 | 29 |
|---|---:|---:|---:|---:|

반복 `i`가 커지며 조건을 만족하는 마지막 값 = **가장 큰 소인수 = 29**

| i | 소수? | 13195의 약수? | max_div |
|---:|:---:|:---:|---:|
| 5 | ✅ | ✅ | 5 |
| 7 | ✅ | ✅ | 7 |
| 13 | ✅ | ✅ | 13 |
| **29** | ✅ | ✅ | **29** |
| 35, 65 등 | ❌(합성수) | ✅ | 변화 없음 |

(i는 13194까지만 돌므로 13195 자신은 제외된다.)

> **정답: `29`**

## 4. 암기 포인트
- 소수이면서 약수 = **소인수**. 마지막으로 갱신된 값이 **가장 큰 소인수**.
- 13195 = 5·7·13·29 (기억해 두면 편함).
