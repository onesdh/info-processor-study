# 문제 19

## 문제

다음 소스코드가 실행할 때의 출력값을 작성하시오.

```
#include <stdio.h>
int isPrime(int number) {
  int i;
  for (i=2; i<number; i++) {
    if (number % i == 0) return 0;
  }
  return 1;
}

int main(void) {
  int number = 13195, max_div=0, i;
  for (i=2; i<number; i++)
  if (isPrime(i) == 1 && number % i == 0) max_div = i;
  printf("%d", max_div);
  return 0;
}
```

<details>
<summary><strong>정답 보기</strong></summary>

29

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

소수 i가 13195를 나누어 떨어지게 하면 최대 소인수 후보가 된다.

## 풀이

13195=5×7×13×29이므로 가장 큰 소인수는 29다.

## 오답 분석

루프가 오름차순으로 검사하므로 마지막으로 발견되는 소수가 가장 큰 소인수다.

## 암기 포인트

13195의 소인수 분해에서 가장 큰 소수는 29.
