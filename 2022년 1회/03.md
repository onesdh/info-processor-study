# 문제 03

## 문제

다음 자바 문법에 알맞는 출력 결과를 작성하시오.

```
class A {
  int a;
  int b;
}

  public class Main {

  static void func1(A m){
   m.a *= 10;
  }

  static void func2(A m){
    m.a += m.b;
  }

  public static void main(String args[]){

  A m = new A();

  m.a = 100;
  func1(m);
  m.b = m.a;
  func2(m);

  System.out.printf("%d", m.a);

  }
}

```

<details>
<summary><strong>정답 보기</strong></summary>

2000

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

객체 참조를 매개변수로 넘기면 메서드에서 같은 객체의 필드를 변경할 수 있다.

## 풀이

처음 a=100, func1 뒤 a=1000이다. b에 1000을 대입한 다음 func2에서 a=1000+1000=2000이다.

## 오답 분석

정수 지역 변수만 전달한 경우와 달리 객체 필드 변경은 호출자에게 보인다. b를 먼저 저장한 시점도 확인한다.

## 암기 포인트

객체는 참조를 통해 같은 인스턴스를 공유.
