# 문제 03

## 문제

다음 자바 문법에 알맞는 출력 결과를 작성하시오.

```
class A {
  int a;
  int b;
}

  public class Main {

  static void func1(A m){
   m.a *= 10;
  }

  static void func2(A m){
    m.a += m.b;
  }

  public static void main(String args[]){

  A m = new A();

  m.a = 100;
  func1(m);
  m.b = m.a;
  func2(m);

  System.out.printf("%d", m.a);

  }
}

```

<details>
<summary><strong>정답 보기</strong></summary>

2000

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
Java에서 **객체를 메서드에 전달**했을 때 그 안의 필드가 바뀐다는 것(참조 전달)을 이해하고 최종 값을 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 객체 전달 = 참조(주소) 값 복사
메서드에 객체를 넘기면 **객체의 주소가 복사**되어 전달된다. 같은 객체를 가리키므로 **메서드 안에서 필드를 바꾸면 원래 객체에 반영**된다.
```text
 main의 m ─┐
           ├──▶ [ A 객체: a, b ]   (func1, func2의 m도 같은 객체)
 func의 m ─┘
```
### (2) 복합 대입 연산자
| 식 | 의미 |
|---|---|
| `m.a *= 10` | `m.a = m.a * 10` |
| `m.a += m.b` | `m.a = m.a + m.b` |

## 3. 실행 과정
| 단계 | 코드 | a | b |
|---|---|---:|---:|
| ① | `m.a = 100` | 100 | 0 (기본값) |
| ② | `func1(m)` → `m.a *= 10` | **1000** | 0 |
| ③ | `m.b = m.a` | 1000 | **1000** |
| ④ | `func2(m)` → `m.a += m.b` (1000 + 1000) | **2000** | 1000 |

`printf("%d", m.a)` → **2000**

> **정답: `2000`**

## 4. 암기 포인트
- 객체의 필드 변경은 메서드 밖에서도 **유지**된다(같은 객체).
- 객체의 `int` 필드 기본값은 0.
