# 문제 15

## 문제

다음 중, 괄호 ( ) 안에 들어갈 연산자를 써서 정수를 역순으로 출력하는 알맞는 답을 작성하시오.

```
#include <stdio.h>
int main() {

  int number = 1234;
  int div = 10;
  int result = 0;

  while (number ( 1 ) 0) {

    result = result * div;
    result = result + number ( 2 ) div;
    number = number ( 3 ) div;

  }

  printf("%d", result);return 0;

}
```

결과 : 4321

## 핵심 개념

정수의 마지막 자릿수는 10으로 나눈 나머지로 얻고, 마지막 자릿수를 제거할 때는 정수 나눗셈을 한다.

## 풀이

반복 조건은 number>0, 현재 마지막 자릿수는 number%10, 자릿수 제거는 number/10이다.

## 오답 분석

실수 나눗셈을 사용하면 정수 자릿수가 보존되지 않으므로 정수형 나눗셈이어야 한다.

## 암기 포인트

나머지로 꺼내고 나눗셈으로 줄인다.
