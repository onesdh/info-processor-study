# 문제 15

## 문제

다음 중, 괄호 ( ) 안에 들어갈 연산자를 써서 정수를 역순으로 출력하는 알맞는 답을 작성하시오.

```
#include <stdio.h>
int main() {

  int number = 1234;
  int div = 10;
  int result = 0;

  while (number ( 1 ) 0) {

    result = result * div;
    result = result + number ( 2 ) div;
    number = number ( 3 ) div;

  }

  printf("%d", result);return 0;

}
```

결과 : 4321

## 1. 문제에서 묻는 것
정수를 **역순으로 만드는** 코드의 괄호 3개(`while` 조건, 나머지, 몫)에 들어갈 **연산자**를 채우는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 자릿수 분해의 기본기
| 연산 | 의미 | 예 (`1234`) |
|---|---|---|
| `% 10` | **마지막 자릿수** 추출 | 1234 % 10 = **4** |
| `/ 10` | **마지막 자릿수 제거**(정수 몫) | 1234 / 10 = **123** |

### (2) 역순 만들기 원리
```text
 result를 10배(자릿수 한 칸 왼쪽으로 밀기) 하고, number의 마지막 자릿수를 더한다.
 이것을 number가 0이 될 때까지 반복
```
```c
while (number ( 1 ) 0) {              // number가 0보다 클 동안 반복 → ">"
    result = result * div;             // result × 10
    result = result + number ( 2 ) div;   // + (number % 10)  → 마지막 자릿수
    number = number ( 3 ) div;         // number / 10  → 마지막 자릿수 제거
}
```
## 3. 실행 과정 (`number = 1234`)
| 반복 | `number` | 마지막 자릿수 | `result` (×10 + 자릿수) | 다음 number |
|---:|---:|---:|---:|---:|
| 1 | 1234 | 4 | 0×10 + 4 = **4** | 123 |
| 2 | 123 | 3 | 4×10 + 3 = **43** | 12 |
| 3 | 12 | 2 | 43×10 + 2 = **432** | 1 |
| 4 | 1 | 1 | 432×10 + 1 = **4321** | 0 |
| 종료 | 0 | | `number > 0` 거짓 | |

출력: **4321**

| 빈칸 | 정답 | 역할 |
|---|:---:|---|
| (1) | **`>`** | number가 0보다 클 동안 반복 |
| (2) | **`%`** | 마지막 자릿수 추출 |
| (3) | **`/`** | 마지막 자릿수 제거 |

> **정답: 1. `>` 2. `%` 3. `/`**

## 4. 암기 포인트
- **`% 10`은 끝자리 꺼내기, `/ 10`은 끝자리 버리기** — 자릿수 문제 공식.
- 2022년 2회·2023년 1회의 이진수 변환 문제도 같은 원리다.
