# 문제 18

## 문제

다음 설명과 관련된 답을 보기에 찾아서 작서하시오.  
(실제 기출문제에서는 답의 보기가 주어집니다.(오답 중, Pharming, Ransomware등..))

이 공격은 APT 공격에서 주로 쓰이는 공격으로, 공격 대상이 방문할 가능성이 있는 합법적인 웹 사이트를 미리 감염시킨 뒤, 잠복하고 있다가 공격 대상이 방문하면 대상의 컴퓨터에 악성코드를 설치하는 방식

## 1. 문제에서 묻는 것
"APT 공격에 주로 쓰이는, 공격 대상이 **방문할 가능성이 있는 합법 웹사이트를 미리 감염**시켜 두고 기다림" → 공격 기법 이름을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 워터링 홀(Watering Hole)
이름은 **사자가 물웅덩이에 매복했다가 물 마시러 오는 사냥감을 노리는 것**에서 유래했다. 공격자가 **표적이 자주 방문하는 사이트를 미리 감염**시켜 놓고, 표적이 접속하는 순간 **악성코드를 설치**한다.
```text
  공격자 ─(미리 감염)─▶ [ 협회·포럼·뉴스 등 합법 사이트 ] ◀─ 방문 ─ 표적 직원
                               │ 접속자가 표적일 때
                               └─ 악성코드 설치 ─▶ 표적 PC 감염
```
### (2) 특징
- **APT(지능형 지속 위협)** 에서 침투 단계에 자주 사용
- 피해자는 **정상 사이트**를 방문했을 뿐이라 **감염을 알아채기 어렵다.**

### (3) 보기의 오답과 구분
| 용어 | 설명 |
|---|---|
| **워터링 홀** | **표적이 모이는 사이트를 감염** |
| 파밍(Pharming) | **DNS를 조작**해 가짜 사이트로 유도 |
| 랜섬웨어 | 파일 암호화 후 금전 요구 |
| 스피어 피싱 | 표적에게 **맞춤 이메일** 전송 |

## 3. 문제 풀이
| 단서 | 워터링 홀 |
|---|---|
| **APT 공격**에서 주로 사용 | ✅ |
| **방문 가능성이 있는 합법 웹사이트를 미리 감염**, 잠복 | ✅ |
| 대상이 방문하면 **악성코드 설치** | ✅ |

> **정답: watering hole (워터링 홀)**
