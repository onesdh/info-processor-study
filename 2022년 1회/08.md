## 1. 문제에서 묻는 것
"**임시 키 무결성 프로토콜**"을 **영어 약자**로 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 무선 LAN 보안의 변천
| 방식 | 암호 알고리즘 | 특징 |
|---|---|---|
| **WEP** | RC4 (고정 키) | 키가 쉽게 노출되어 **취약**(폐기) |
| **WPA** | RC4 + **TKIP** | WEP 취약점을 **임시 개선** |
| **WPA2** | **AES-CCMP** | 현재 널리 쓰임 |
| WPA3 | SAE | 최신 |

### (2) TKIP (Temporal Key Integrity Protocol, 임시 키 무결성 프로토콜)
WEP의 약점을 보완하려고 만든 프로토콜로, **패킷마다 암호 키를 바꾸고(임시 키)**, **메시지 무결성 검사(MIC)** 를 더해 보안성을 높였다.
```text
 WEP : 같은 키를 계속 사용  → 도청·해독 쉬움
 TKIP: 패킷마다 새 키 사용(키 혼합) + 무결성 검사 → 보안 강화 (기존 WEP 하드웨어에서도 동작)
```
## 3. 풀이
| 용어 | 의미 |
|---|---|
| **T**emporal | 임시의(수시로 바뀌는) |
| **K**ey | 키 |
| **I**ntegrity | 무결성 |
| **P**rotocol | 프로토콜 |

> **정답: TKIP (Temporal Key Integrity Protocol)**
