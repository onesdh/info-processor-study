# 문제 06

## 문제

다음은 파이썬 코드에서 출력되는 a와 b의 값을 작성하시오.

```
def exam(num1, num2=2):
  print('a=', num1, 'b=', num2)
exam(20)
```

<details>
<summary><strong>정답 보기</strong></summary>

a= 20 b= 2

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
파이썬 함수의 **기본 매개변수(default argument)** 가 어떻게 동작하는지 묻는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 기본 매개변수
```python
def exam(num1, num2=2):       # num2는 "기본값 2"를 가짐
```
- 함수를 부를 때 **num2를 생략하면 기본값 2**가 사용된다.
- num2를 주면(`exam(20, 5)`) 그 값을 사용한다.

### (2) `print`의 여러 인자
`print('a=', num1, 'b=', num2)` : 인자를 **공백으로 구분**해 출력한다.
```text
 print('a=', 20, 'b=', 2)  →  a= 20 b= 2
```
## 3. 실행 과정
`exam(20)` → `num1 = 20`, `num2` 생략 → **기본값 2**

| 인자 | 값 |
|---|---|
| num1 | 20 |
| num2 | 2 (기본값) |

출력: `a= 20 b= 2`

> **정답: `a= 20 b= 2`**

## 4. 암기 포인트
- 기본값이 있는 매개변수는 **뒤쪽**에 놓아야 한다.
- `print`는 쉼표로 구분한 값 사이에 **공백**을 넣어 출력한다.
