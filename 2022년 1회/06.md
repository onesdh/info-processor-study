# 문제 06

## 문제

다음은 파이썬 코드에서 출력되는 a와 b의 값을 작성하시오.

```
def exam(num1, num2=2):
  print('a=', num1, 'b=', num2)
exam(20)
```

<details>
<summary><strong>정답 보기</strong></summary>

a= 20 b= 2

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

기본 매개변수는 호출자가 인수를 생략하면 지정된 기본값을 사용한다.

## 풀이

num1에는 20이 전달되고 num2는 생략되므로 기본값 2를 사용한다.

## 오답 분석

위치 인수와 기본값 인수를 구분한다. 생략된 인수에만 기본값이 적용된다.

## 암기 포인트

생략하면 기본값 2.

</details>
