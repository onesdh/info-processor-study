# 문제 17

## 문제

다음 설명 중, 괄호 ( ) 안에 들어가는 알맞는 답을 보기에서 선택하여 작성하시오.  
(실제 기출문제에서는 답의 보기가 주어집니다.(오답 중, 참조성, 무결성 등..))

1. 슈퍼키는 ( 1 ) 의 속성을 갖는다.

2. 후보키는 ( 1 ) 와/과 ( 2 ) 의 속성을 갖는다.

<details>
<summary><strong>정답 보기</strong></summary>

1. 유일성

2. 최소성

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**슈퍼키**와 **후보키**의 성질(유일성, 최소성)을 묻는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 키(Key)의 성질 2가지
| 성질 | 의미 |
|---|---|
| **유일성(Uniqueness)** | 키 값으로 **튜플을 유일하게 식별**할 수 있음(중복 없음) |
| **최소성(Minimality)** | 키를 구성하는 속성에서 **하나라도 빼면 유일성이 깨짐**(**꼭 필요한 속성만** 사용) |

### (2) 키의 종류와 만족하는 성질
| 키 | 유일성 | 최소성 |
|---|:---:|:---:|
| **슈퍼키** | ✅ | ❌ (불필요한 속성이 있어도 됨) |
| **후보키** | ✅ | ✅ |
| 기본키 | 후보키 중 선택 (✅ ✅ + NULL 불가) | |

```text
 슈퍼키 ⊃ 후보키 ⊃ 기본키
```
### (3) 예: 학생(학번, 주민번호, 이름)
- 슈퍼키: {학번}, {주민번호}, **{학번, 이름}**, {학번, 주민번호, 이름} … → 모두 유일성 ✅
- 후보키: {학번}, {주민번호} → 유일성 ✅ + 최소성 ✅ (`{학번, 이름}`은 이름을 빼도 유일하므로 최소성 ❌)

## 3. 문제 풀이
| 번호 | 문장 | 정답 |
|---|---|---|
| 1 | 슈퍼키는 ( 1 )의 속성을 갖는다 | **유일성** |
| 2 | 후보키는 ( 1 )과 ( 2 )의 속성을 갖는다 | (1) **유일성**, (2) **최소성** |

> **정답: 1. 유일성 2. 최소성**

## 4. 암기 포인트
- **슈퍼키 = 유일성**, **후보키 = 유일성 + 최소성**.
