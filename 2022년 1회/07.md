# 문제 07

## 문제

다음 설명과 관련된 답을 보기에서 골라 작성하시오.  
(실제 기출문제에서는 답의 보기가 주어집니다.(오답 중, remove, sort 등..))

1. 요소를 확장해준다는 의미를 가지고 있으며, 모든 항목을 하나의 요소로 추가  
2. 리스트 내부 요소를 꺼내주는 함수로써, 그 요소는 리스트 안에서 삭제하고 그 값을 반환  
3. 리스트 내부의 요소의 순서는 뒤집는 역할

## 1. 문제에서 묻는 것
파이썬 **리스트 메서드** 3가지(`extend`, `pop`, `reverse`)를 설명과 연결하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 리스트 메서드
| 메서드 | 동작 | 예 (`lst = [1, 2, 3]`) |
|---|---|---|
| **extend(x)** | 리스트 **확장** — x의 **각 요소를 하나씩** 추가 | `lst.extend([4,5])` → `[1,2,3,4,5]` |
| append(x) | x를 **하나의 요소**로 추가 | `lst.append([4,5])` → `[1,2,3,[4,5]]` |
| **pop(i)** | i번째(생략 시 **마지막**) 요소를 **꺼내서 삭제**하고 **그 값을 반환** | `lst.pop()` → 3 반환, `lst = [1,2]` |
| remove(x) | **값이 x인 첫 요소**를 삭제(반환 없음) | |
| **reverse()** | 리스트 **순서를 뒤집음**(제자리) | `[1,2,3]` → `[3,2,1]` |
| sort() | 정렬 | |

### (2) extend vs append 비교
```text
 [1,2,3].append([4,5])  →  [1, 2, 3, [4, 5]]     (리스트가 "하나의 요소"로)
 [1,2,3].extend([4,5])  →  [1, 2, 3, 4, 5]        (요소가 "풀어져서" 추가)
```
## 3. 문제 풀이
| 번호 | 설명 | 정답 |
|---|---|---|
| 1 | 요소를 **확장**, **모든 항목을 요소로 추가** | **extend** |
| 2 | 내부 요소를 **꺼내**, 리스트에서 **삭제**하고 **그 값을 반환** | **pop** |
| 3 | 요소의 **순서를 뒤집음** | **reverse** |

> **정답: 1. extend 2. pop 3. reverse**

## 4. 암기 포인트
- `pop` = 꺼내면서 삭제 + 값 반환, `remove` = 값으로 찾아 삭제(반환 ✕).
- `extend`는 풀어서 추가, `append`는 통째로 추가.
