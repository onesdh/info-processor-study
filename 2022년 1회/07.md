# 문제 07 — Python 리스트 메서드

## 문제

리스트 뒤에 여러 요소를 확장해 붙이는 메서드, 요소를 꺼내 삭제하면서 값을 반환하는 메서드, 순서를 뒤집는 메서드를 순서대로 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

extend; pop; reverse

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

extend는 반복 가능한 항목을 리스트에 펼쳐 추가하고, pop은 요소를 제거하며 반환하고, reverse는 원본 리스트 순서를 뒤집는다.

## 풀이

설명의 확장, 꺼내며 삭제, 역순 변환을 각각 대응시킨다.

## 오답 분석

append는 인수 하나를 단일 요소로 추가하므로 extend와 다르다. sort는 정렬이며 reverse는 단순히 순서를 뒤집는다.

## 암기 포인트

extend는 확장, pop은 꺼냄, reverse는 반전.
