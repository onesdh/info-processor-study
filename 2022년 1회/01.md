# 문제 01

## 문제

아래 설명에 맞는 RAID 단계를 숫자로 작성하시오.

- Striping(스트라이핑) 구현 방식  
- I/O 로드의 분산으로 매우 빠른 속도  
- 데이터를 블럭으로 분할 저장하며, 각 블럭은 다른 디스크로 나뉘어 저장

## 1. 문제에서 묻는 것
"**Striping(스트라이핑)**, I/O 분산으로 **매우 빠른 속도**, 데이터를 블록으로 나눠 **서로 다른 디스크**에 저장" → 어떤 RAID 레벨인지 숫자로 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) RAID (Redundant Array of Independent Disks)
**여러 개의 디스크를 하나처럼 묶어** 속도를 높이거나 **고장에 대비**하는 기술이다.

### (2) 주요 RAID 레벨
| 레벨 | 방식 | 성능 | 안정성(디스크 고장 시) | 최소 디스크 |
|---|---|---|---|:---:|
| **RAID 0** | **스트라이핑(Striping)** | **가장 빠름** | ❌ **하나라도 고장 나면 전체 데이터 손실** | 2 |
| **RAID 1** | **미러링(Mirroring)** — 같은 데이터를 **복제** | 읽기 빠름, 쓰기 보통 | ✅ 한쪽 고장 가능 | 2 |
| RAID 5 | **패리티 분산** 저장 | 좋음 | ✅ 1개 고장 허용 | 3 |
| RAID 6 | 패리티 2개 | | ✅ 2개 고장 허용 | 4 |
| RAID 10 | 1+0 (미러링 + 스트라이핑) | 매우 좋음 | ✅ | 4 |

### (3) 스트라이핑(Striping)
데이터를 **블록 단위로 쪼개 여러 디스크에 번갈아 저장**하고 **동시에 읽고 쓴다.** 그래서 속도가 N배로 빨라진다.
```text
 데이터:  [B1][B2][B3][B4]
 디스크 A : B1, B3  ┐
 디스크 B : B2, B4  ┘ ← 두 디스크가 동시에 일함 → 속도 2배 (대신 복구용 중복 데이터 없음)
```
## 3. 문제 풀이
| 단서 | RAID 0 |
|---|---|
| **Striping** 방식 | ✅ |
| I/O 로드 분산으로 **매우 빠른 속도** | ✅ |
| 블록을 **다른 디스크에 분산** 저장 | ✅ |

> **정답: 0**

## 4. 암기 포인트
- **RAID 0 = 스트라이핑(빠름, 중복 없음)**, **RAID 1 = 미러링(복제)**, **RAID 5 = 패리티**.
