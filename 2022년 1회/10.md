# 문제 10

## 문제

다음은 분석도구에 대한 설명으로 보기에 알맞는 답을 작성하시오.  
(실제 기출문제에서는 답의 보기가 주어집니다.(오답 중, running analysis 등..))

1. 소스 코드의 실행 없이, 코드의 의미를 분석해 결함을 찾아내는 원시적 코드 분석 기법  
2. 소스 코드를 실행하여 프로그램 동작이나 반응을 추적하고 코드에 존재하는 메모리 누수, 스레드 결함 등을 분석

<details>
<summary><strong>정답 보기</strong></summary>

1. static

2. dynamic

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

정적 분석은 실행 없이 코드를 점검하며, 동적 분석은 실행 중 동작을 관찰하고 결함을 찾는다.

## 풀이

실행 전 원시 코드 검사라는 단서는 static, 메모리 누수나 스레드 결함을 실행 중 추적한다는 설명은 dynamic이다.

## 오답 분석

두 기법 모두 결함 분석이지만 프로그램 실행 여부가 핵심 구분 기준이다.

## 암기 포인트

실행 없이 static, 실행하며 dynamic.
