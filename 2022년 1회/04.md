# 문제 04

## 문제

다음 SQL 결과에 알맞는 쿼리을 작성하시오.

![원문 문제 그림 1](source/정보처리기사_2022_1_Q04_01.png)

SELECT name, score FROM 성적 ( 1 ) BY ( 2 ) ( 3 )

<details>
<summary><strong>정답 보기</strong></summary>

1. ORDER

2. score

3. DESC

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

ORDER BY는 결과 행의 정렬 기준을 지정한다. DESC는 내림차순, ASC 또는 생략은 오름차순이다.

## 풀이

FROM 성적 뒤에 ORDER BY score DESC를 둔다.

## 오답 분석

WHERE는 행을 거르고 GROUP BY는 그룹을 만든다. 정렬은 ORDER BY 절이다.

## 암기 포인트

내림차순은 DESC.

</details>
