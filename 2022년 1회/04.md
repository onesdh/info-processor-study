# 문제 04

## 문제

다음 SQL 결과에 알맞는 쿼리을 작성하시오.

![원문 문제 그림 1](source/정보처리기사_2022_1_Q04_01.png)

SELECT name, score FROM 성적 ( 1 ) BY ( 2 ) ( 3 )

<details>
<summary><strong>정답 보기</strong></summary>

1. ORDER

2. score

3. DESC

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
성적을 **점수가 높은 순으로 정렬**해서 출력하는 SQL의 빈칸(`ORDER BY score DESC`)을 채우는 문제다.

## 2. 먼저 알아야 할 개념
### (1) ORDER BY
조회 결과를 **정렬**한다.
```sql
SELECT 열 FROM 테이블 ORDER BY 열 [ASC | DESC];
```
| 키워드 | 의미 |
|---|---|
| `ASC` | **오름차순** (작은 값 → 큰 값), **기본값** |
| `DESC` | **내림차순** (큰 값 → 작은 값) |

### (2) 문제의 형태
`SELECT name, score FROM 성적 ( 1 ) BY ( 2 ) ( 3 )` → `ORDER BY ○○ ○○`

## 3. 문제 데이터 (그림: 성적 테이블)
| Index | name | score |
|---:|---|---:|
| 1 | Kim | 95 |
| 2 | Gun | 90 |
| 3 | Son | 80 |
| 4 | Jung | 60 |

결과가 **점수가 큰 값부터** 나오는 형태(95 → 90 → 80 → 60) = **내림차순**.

## 4. 풀이
| 빈칸 | 정답 | 이유 |
|---|---|---|
| (1) | **ORDER** | `ORDER BY` |
| (2) | **score** | 정렬 기준 열 |
| (3) | **DESC** | 내림차순 |

```sql
SELECT name, score FROM 성적 ORDER BY score DESC;
```
> **정답: 1. ORDER 2. score 3. DESC**

## 5. 암기 포인트
- `ORDER BY 열 DESC` = 내림차순, 생략하면 `ASC`.
- 정렬 기준이 여러 개면 쉼표로 구분: `ORDER BY a DESC, b ASC`.
