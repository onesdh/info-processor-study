### 서브넷 마스크 풀이 연습 (옥텟 중간에서 끊기는 경우)
**핵심: 마스크가 255가 아닌 옥텟 하나만 본다.** 그 옥텟에서 블록 크기 = 256 − 마스크값, 네트워크 주소 = IP 값을 블록 크기의 배수로 내림, 브로드캐스트 = 다음 블록 시작 − 1. 앞 옥텟은 그대로, 뒤 옥텟은 네트워크 0 / 브로드캐스트 255.
| 문제 | 마스크 | 판단 옥텟 | 계산 | 답 |
|---|---|---|---|---|
| 139.127.19.132 | 255.255.255.192 (/26) | 4번째, 블록 64 | 132 → 128 (64·2), 호스트 2⁶−2 | 네트워크 .128, 호스트 **62** |
| 192.168.11.20 | 255.255.254.0 (/23) | 3번째, 블록 2 | 11 → 10 | **192.168.10.0/23** (b: 12.200 → 12.0/23) |
| 192.168.35.10 | 255.255.252.0 (/22) | 3번째, 블록 4 | 35 → 32 (범위 32~35) | 네트워크 192.168.32.0, 브로드캐스트 192.168.35.255. **같은 네트워크 IP는 32.0~35.255 전부 브로드캐스트 수신** |
| 129.200.10.16 | /22 | 3번째, 블록 4 | 10 → 8 (범위 8~11) | 129.200.8.0 ~ 129.200.11.255 → 8.249는 **할당 가능** |
| 10.0.0.0/27 → 2개 | 프리픽스 +1 | | 32주소 → 16주소씩 | **/28** (블록 16: .0~.15, .16~.31) |
| 192.168.1.0/24 → FLSM 3개 | 2ⁿ≥3 → n=2 | 프리픽스 +2 = /26 | 블록 64: .0~.63, .64~.127 | 두 번째 브로드캐스트 **192.168.1.127** |
- **호스트에 줄 수 있는 IP** = 같은 네트워크 범위 안에서 **네트워크 주소(첫 값)·브로드캐스트(끝 값) 제외**. 그림 문제(라우터 각 포트에 네트워크가 붙어 있음)는 각 IP의 /프리픽스로 범위를 구하고 **보기 중 그 범위 안이면서 첫·끝 값이 아닌 것**을 고른다 (예: 192.168.35.3/24 → 35.0 ✕, 35.72 ○ / 192.168.36.24/24 → 36.249 ○).

### 서브넷 마스크 계산
1. 마스크의 `1` 개수 = 프리픽스(/n)
2. **블록 크기 = 256 − 마스크 옥텟 값** (192→64, 224→32, 254→2, 252→4)
3. **네트워크 주소 = IP AND 마스크**(블록 시작), **브로드캐스트 = 블록 끝**
4. **호스트 수 = 2^(호스트 비트) − 2**
5. **FLSM**(고정 길이 분할) 서브넷 N개 → 2ⁿ ≥ N인 n비트를 프리픽스에 더함

| 프리픽스 | 마지막 옥텟 | 블록 | 호스트 |
|---|---:|---:|---:|
| /24 | 0 | 256 | 254 |
| /25 | 128 | 128 | 126 |
| /26 | 192 | 64 | 62 |
| /27 | 224 | 32 | 30 |
| /28 | 240 | 16 | 14 |
| /29 | 248 | 8 | 6 |
| /30 | 252 | 4 | 2 |

기출 [🔥 26년 2회 10번](../2026년%202회/10.md) 외 7회: 223.13.234.132 /26 → **.128 / 62개**, 192.168.11.20 /23 → **192.168.10.0/23**, 129.200.10.16 /22 → **129.200.8.0/22**, 10.0.0.0/27을 2개로 → **/28**, 192.168.1.0/24를 FLSM 3개 → /26, 두 번째 브로드캐스트 **.127**.

## 3. 라우팅 프로토콜
| 구분 | 프로토콜 | 단서 | 기출 |
|---|---|---|---|
| **IGP**(AS 내부) | **RIP** | **거리 벡터, 벨만-포드, 홉 수(최대 15)**, 소규모 | [🔥 23년 3회 18번](../2023년%203회/18.md) |
| IGP | **OSPF** | **링크 상태, 다익스트라**, 대규모, 비용, 홉 제한 없음, Area, 멀티캐스트 | [🔥 26년 2회 4번](../2026년%202회/04.md) 외 3회 |
| **EGP**(AS 간) | **BGP** | **경로 벡터**, 전체 경로, 루프 제거 | [🔥 22년 2회 14번](../2022년%202회/14.md) |
- **최단 경로 문제 풀이**: 출발지에서 시작해 **RIP = 홉 수(거치는 라우터 수)가 가장 적은 경로**, OSPF = **링크 비용 합이 가장 작은 경로**(다익스트라: 확정 안 된 노드 중 거리 최소를 확정 → 이웃 거리 갱신 반복). 그림이 주어지면 모든 경로의 합을 표로 적어 최소를 고른다 (기출 24-2-11 RIP: 홉 수 최소 경로 **A → D → C → F**).
- **AS(자율 시스템)** = 도메인. ⚠ **RIP는 비용이 아닌 홉 수**로 경로 선택.
- 용어: **IGP** [🔥 22년 2회 14번](../2022년%202회/14.md) / **EGP** [🔥 22년 2회 14번](../2022년%202회/14.md)

### 2022년 2회 14번

[해설 보기](../2022년%202회/14.md)

다음 설명에 대해 보기에 주어진 답을 골라 작성하시오.  
(실제 기출문제에서는 답의 보기가 주어집니다.(오답 중, ARP, RARP 등..))

1. 라우터로 상호 접속이 되어있는 여러 개의 네트워크 집합으로 도메인 혹은 자율시스템(Autonomous System, AS)이라고 한다.

같은 도메인 내에 존재하는 라우터는 도메인 내부 라우터가 되고 도메인 외부에 존재하는 라우터는 도메인 외부 라우터가 되는데, 여기서 도메인 내부 경로 설정을 가르킨다.

2. 시스템 사이에 경로 설정 정보 등을 교환하기 위해 사용하는 프로토콜로써,  
다른 도메인 사이에 라우팅 시 정리된 관리가 거의 없고 많은 경우에 신용도가 매우 낮아 빠른 수행보다는 보안과 제어가 본래의 목적이다.

3. IP 라우팅 프로토콜의 한 종류로써 RIP(routing information protocol)보다 규모가 큰 네트워크에서도 사용할 수 있다.  
규모가 크고 복잡한 TCP/IP 네트워크에서 RIP의 단점을 개선한 라우팅 프로토콜로써 RIP에 비해 자세한 제어가 가능하고, 관리 정보의 트래픽도 줄일 수 있다.

4. 서로 다른 자율 시스템(AS)의 라우터 간에 라우팅 정보를 교환하는 데 사용되는 외부 게이트웨이 프로토콜(EGP)이다.  
각 목적지에 대한 전체 경로가 포함되며, 다른 시스템과 교환하는 네트워크 도달 가능성 정보의 데이터베이스를 유지한다.  
네트워크 도달 가능성 정보를 사용하여 AS 연결 그래프를 구성하며, 이를 통해 라우팅 루프를 제거하고 AS 수준에서 정책 결정을 실행할 수 있다.
