# B. 개념 요약
> **풀이 공식**: ① 변수 초기값 표로 정리 → ② 반복·함수 호출 한 줄씩 추적(표) → ③ 출력 서식 확인(`%d` `%c` `%s` `%x` `%.2f`). 코드 문제는 **외우지 말고 추적**한다.

## 1. 출제 패턴과 핵심 개념 (기출 빈도순)
### (1) 문자열·문자 포인터 [🔥 25년 3회 5번](../2025년%203회/05.md) 외 10회
```c
char *p = "KOREA";   // p → K O R E A \0
```
| 표현 | 의미 | 값 |
|---|---|---|
| `printf("%s", p)` / `p+3` | 해당 주소부터 `\0`까지 | `KOREA` / `EA` |
| `*p` , `*(p+3)` | 문자 | `K` , `E` |
| **`*p + 2`** | **`(*p) + 2`** = 'K'(75)+2 → **'M'** (≠ `*(p+2)` = 'R') |
- 문자열 끝 `'\0'`의 인덱스 = **문자열 길이**. `str[len-2]`는 뒤에서 두 번째. 널 문자 **뒤의 글자는 무시**됨(복사 후 `*d='\0'`).
- **길이 구하기**: `while(*p != '\0'){p++; r++;}`. 문자 + 정수는 **ASCII 계산**(대문자 65~90, 소문자 97~122, 숫자 48~57). 시저 암호형(`% 25` 함정, `% 26`).
- 배열 초기화를 일부만 하면 나머지는 **0**(`char Data[5]={'B','A','D','E'}` → Data[4]=0).

### (2) 포인터·배열 [🔥 26년 2회 9번](../2026년%202회/09.md) 외 23회
| 표현 | 의미 |
|---|---|
| `arr[i]` ≡ `*(arr+i)` | i번째 원소 |
| `*arr` ≡ `arr[0]`, `**pp` | 이중 포인터 `*pp`=포인터, `**pp`=값 |
| `p + n` | **자료형 크기 × n** 만큼 이동 (구조체면 구조체 한 칸) |
| `*arr[1] + **arr + 1` | 포인터 배열: `*arr[1]`=두 번째 변수 값, `**arr`=첫 번째 변수 값 |
- **값 전달 vs 주소 전달**: `fn(i)`는 복사본(원본 불변), `fn(&i)`는 `*i=50`으로 **원본 변경**. `swap(int a,int b)`는 교환 **실패**.
- 2차원 배열은 **행 우선**: `int a[3][3]={1..9}` → `a[1]`={4,5,6}. 동적 할당 `arr=malloc(...)`, `arr[i]=malloc(...)`.
- `(*pptr)[1]` = `ptr[1]`, 구조체 대입은 **멤버 전체 복사**.

### (3) 구조체·연결 리스트·자료구조 [🔥 26년 2회 7번](../2026년%202회/07.md) 외 16회
- `.`(변수) / **`->`(포인터)**. `p++` 는 **다음 구조체**로 이동. 초기값 일부만 주면 나머지 멤버=0.
- **head 삽입** `new->next=head; head=new;` → **입력 순서가 뒤집힘** ("BEST" → "TSEB").
- **포인터 재대입은 덮어쓰기** — 마지막 연결만 유효. 연결 순서를 **화살표로 그려** 추적.
- 노드 값 교환/이동(move-to-front: `prev->next=curr->next; curr->next=head; head=curr;`).
- **원형 큐**: `rear=(rear+1)%SIZE`, enq/deq를 표로 추적(FIFO). **스택**: push=`++point`, pop=`point--`(LIFO).
- **트리 후위 순회**: 왼→오→루트, 카운터로 N번째 노드(`++c==3`).

### (4) 연산자·제어문 [🔥 25년 3회 15번](../2025년%203회/15.md) 외 9회
| 주제 | 포인트 |
|---|---|
| **비트 연산** | `&`(둘 다 1) `\|` `^`(**다르면 1**) `<<`(×2ⁿ) `>>`(÷2ⁿ). **0xA5** 마스킹은 이진으로 풀기 |
| **우선순위** | `* / %` > `+ -` > `<< >>` > 비교 > `==` > **`&`** > `^` > `\|` > `&&` > `\|\|` > **`?:`** > `=` — `z & z >> 1` = `z & (z>>1)` |
| **삼항** | `조건 ? 참 : 거짓`, if 조건에 넣으면 **그 값이 0이면 거짓** |
| **switch** | **break 없으면 fall-through**(점프한 case부터 끝까지) |
| **static 지역 변수** | **한 번만 초기화**, 호출 사이 값 유지 |
| **함수 호출** | `r100()=200+r10()` 같이 안쪽부터 값 확정 |
| **함수 포인터** | `int* (*fn)(int*)` → `mine.fn=dummy; *mine.fn(n)`, `%x`=16진수(32→`20`) |

### (5) 알고리즘 패턴 [🔥 26년 2회 18번](../2026년%202회/18.md) 외 11회
| 패턴 | 핵심 |
|---|---|
| **재귀** | 종료 조건부터. `c(n)=c(n-1)+c(n-3)`은 **`n<=1`이면 n 반환(음수 그대로)** → c(5)=1. 팩토리얼 5!=120, 7!=5040 |
| **진법·자릿수** | `% 10` 끝자리, `/ 10` 끝자리 제거. 역순: `result=result*10+number%10`. 2진 변환: `n%2` 저장 후 `n/=2`, 배열을 **거꾸로** 출력 |
| **정렬** | 버블(이웃 비교, 오름차순 `a[j]>a[j+1]`), 선택(`E[i]>E[j]` 교환) |
| **약수·소수** | **완전수(6, 28, 496)**, 소인수: 13195 = 5·7·13·29 → 최대 29 |
| **순위** | `result[i]=1`, `arr[i]<arr[j]`이면 `result[i]++` (큰 값 개수+1) |
| **거듭제곱** | 2¹⁰ = 1024 (`res=1`로 초기화) |
| **2차원 인덱스 규칙** | `arr[((i+1)/rows)%rows][(i+1)%cols]` 같은 식은 **표로 위치 추적** |
| **지뢰찾기** | 1인 칸마다 **3×3 영역에 +1**(범위 밖 제외, 자기 자신 포함) |

### 2026년 2회 07번

[해설 보기](../2026년%202회/07.md)

다음은 C언어 코드에 대한 문제이다. 아래 코드를 확인하여 알맞는 출력값을 작성하시오.

```
#include <stdio.h>

typedef struct N {
    int v;
    struct N* a;
    struct N* b;
} N;

int c = 0;
int ans = 0;

void pst(N *n) {
    if (!n) return;
    pst(n->a);
    pst(n->b);
    if (++c == 3) ans = n->v;
}

int main() {
    N ne = {35, 0, 0};
    N nd = {64, 0, 0};
    N nc = {53, 0, 0};
    N nb = {12, &ne, &nc};
    N na = {21, &nb, &nd};

    pst(&na);
    printf("%d\n", ans);
    return 0;
}
```

**정답:** 12
