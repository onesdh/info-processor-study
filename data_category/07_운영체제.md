# B. 개념 요약
## 1. CPU 스케줄링 (기출 6회)
| 알고리즘 | 선점 | 기준·단서 |
|---|---|---|
| FCFS | 비선점 | 도착 순서 |
| **SJF** | 비선점 | **실행 시간이 짧은** 작업 (Shortest Next CPU Burst) |
| **SRT** | **선점** | **남은 시간이 가장 짧은** 작업, SJF의 선점형, Context Switching 多 |
| **HRN** | 비선점 | **(대기시간 + 서비스시간) / 서비스시간** — SJF의 **기아(Starvation)** 보완, 값 클수록 우선 |
| **RR** | 선점 | **타임 퀀텀**씩 순환, 공평 |
| 우선순위/다단계 큐 | | 에이징으로 기아 방지 |

### 계산법
- **대기시간 = 종료시각 − 도착시각 − 실행시간**, 평균 = 합 ÷ 개수.
- 간트 차트를 그려 **종료 시각**을 구함. SRT: 새 도착마다 **남은 시간 재비교**. RR: 새 도착 프로세스를 **쫓겨난 프로세스보다 먼저** 큐에 삽입.
- 기출 같은 데이터 (P1:0/8, P2:1/4, P3:2/9, P4:3/5): **SRT 평균 대기 6.5ms**, **RR(q=4) 평균 11.75ms**.

## 2. 페이지 교체 (기출 2회)
| 알고리즘 | 교체 대상 |
|---|---|
| FIFO | **가장 먼저 적재**된 페이지 (Belady 이상 현상) |
| **LRU** | **가장 오래 전에 사용**된 페이지 (**hit 시 최신으로 갱신**) |
| **LFU** | **참조 횟수가 가장 적은** 페이지 (동률은 먼저 들어온 것) |
| OPT | 앞으로 **가장 오래 안 쓸** 페이지 (이상적, 실제 불가) |
- 풀이: 프레임 상태표를 만들고 **부재(Page Fault) 횟수**를 센다. 기출: 프레임 3, `7 0 1 2 0 3 0 4 2 3 0 3 2 1 2 0 1 7 0 1` → LRU 부재 **12**; `1 2 3 1 2 4 1 2 5 7` → LRU **6**, LFU **6**.

## 3. 프로세스 상태 (기출 1회)
```text
 생성 → [준비] ─디스패치→ [실행] ─종료→ 완료
          ▲ ◀─타이머 런아웃─┘   │ 입출력 발생
          └──── 웨이크 업 ── [대기]◀┘
```
**준비 → 실행: 디스패치 / 실행 → 준비: 타이머 런아웃(타임아웃) / 실행 → 대기: 입출력 발생 / 대기 → 준비: 웨이크 업**.
- **IPC(Inter-Process Communication)**: **공유 메모리, 메시지 큐, 파이프, 소켓, 세마포어** 등 프로세스 간 통신.
- **교착상태 4조건**: 상호 배제, 점유와 대기, 비선점, 순환 대기.

## 4. 리눅스·유닉스 (기출 3회 + 유닉스 1회)
- **chmod 8진수**: r=4, w=2, x=1, 소유자·그룹·기타 순 → **rwx r-x --x = 751** (`chmod 751 a.txt`).
- 명령어: **pwd**(현재 경로) / **ls**(목록) / **cd**(이동) / **cp**(복사) / mv / rm / mkdir / cat / chown(소유자) / ps / kill.
- **유닉스**: 켄 톰슨·**데니스 리치(벨 연구소)**, **C언어로 90% 이상 구현 → 이식성**, 다중 작업·다중 사용자, **계층적 트리 파일 시스템**. 리눅스는 유닉스 계열 오픈 소스.
- **안드로이드**: **리눅스 기반 모바일 OS**, 미들웨어·UI·표준 앱 포함 스택, **자바·코틀린**, 바이트코드 구동(Dalvik/ART).

## 5. RAID
**RAID 0 = 스트라이핑**(블록을 여러 디스크에 분산, 빠름, 중복 없음·한 개 고장 시 전체 손실) / **RAID 1 = 미러링**(복제) / RAID 5 = 패리티 분산 / RAID 6 / RAID 10.

아래 정보를 바탕으로 라운드로빈(RR) 방식으로 CPU 스케줄링을 수행할 경우 모든 프로세스의 평균 대기시간(Average Waiting Time)은 얼마인가?

|---|---|---|
| P1 | 0 | 8 |
| P2 | 1 | 4 |
