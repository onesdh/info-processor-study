# 문제 17

## 문제

다음은 Java 프로그램이다. 실행 결과를 쓰시오.

```
public class good {
	public static void main(String[] args){
    int i, j;
    for(j=0, i=0; i<=5; i++){
    j+=i;
    System.out.print(i);
    if(i==5){
    System.out.print("=");
    System.out.print(j);
   }else{
   	System.out.print("+");
	}
   }
  }
 }

```

<details>
<summary><strong>정답 보기</strong></summary>

0 + 1 + 2 + 3 + 4 + 5 = 15

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

반복문은 i를 0부터 5까지 출력하고 매회 j에 i를 더한다.

## 풀이

누적합은 0+1+2+3+4+5=15다. 마지막 값에서 등호와 누적합을 출력한다.

## 오답 분석

문자열 사이 공백은 코드에 따라 달라질 수 있지만 핵심 출력 내용은 0부터 5까지와 합 15다.

## 암기 포인트

0부터 5까지의 합은 15.
