# 문제 17

## 문제

다음은 Java 프로그램이다. 실행 결과를 쓰시오.

```
public class good {
	public static void main(String[] args){
    int i, j;
    for(j=0, i=0; i<=5; i++){
    j+=i;
    System.out.print(i);
    if(i==5){
    System.out.print("=");
    System.out.print(j);
   }else{
   	System.out.print("+");
	}
   }
  }
 }

```

<summary><strong>정답 보기</strong></summary>

0 + 1 + 2 + 3 + 4 + 5 = 15

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
`for` 반복문 안에서 **누적 합 `j`** 와 **출력 형식(`+`와 `=`)** 을 정확히 추적해 출력 결과를 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) for문 초기화에 변수 2개
```java
for (j = 0, i = 0; i <= 5; i++)    // 초기화에서 j = 0, i = 0 둘 다 설정
```
### (2) 출력
- `System.out.print` : **줄바꿈 없이** 이어서 출력
- `i`를 먼저 출력한 뒤, `i == 5`이면 `=`와 `j`를, 아니면 `+`를 출력

## 3. 실행 과정
| i | `j += i` (j) | `print(i)` | `i==5`? | 이어서 출력 |
|---:|---:|---|:---:|---|
| 0 | 0 | `0` | X | `+` |
| 1 | 1 | `1` | X | `+` |
| 2 | 3 | `2` | X | `+` |
| 3 | 6 | `3` | X | `+` |
| 4 | 10 | `4` | X | `+` |
| 5 | **15** | `5` | ✅ | `=` `15` |

출력을 이어 붙이면: `0+1+2+3+4+5=15`

> **정답: `0+1+2+3+4+5=15`** (공백 없이 출력됨)

## 4. 암기 포인트
- `j`는 **0부터 5까지의 합** = 15.
- `i == 5`일 때만 `+` 대신 `=`와 합계를 출력한다.
