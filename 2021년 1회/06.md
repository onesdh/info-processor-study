# 문제 06

## 문제

다음 SQL 실행 결과를 숫자만 쓰시오.

| EMPNO | SAL |
|---|---|
| 100 | 1000 |
| 200 | 3000 |
| 300 | 1500 |

SELECT COUNT(\*) FROM 급여

WHERE EMPNO &gt; 100 AND SAL &gt;= 3000 OR EMPNO = 200;

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
`AND`와 `OR`가 섞인 WHERE 조건의 **연산자 우선순위**를 적용해 `COUNT(*)`를 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 논리 연산자 우선순위
**`AND`가 `OR`보다 먼저** 계산된다.
```sql
WHERE EMPNO > 100 AND SAL >= 3000 OR EMPNO = 200
```
는 다음과 같이 해석된다.
```sql
WHERE ( EMPNO > 100 AND SAL >= 3000 )  OR  ( EMPNO = 200 )
```
### (2) COUNT(*)
조건을 만족하는 **행의 수**.

## 3. 문제 데이터
| EMPNO | SAL |
|---:|---:|
| 100 | 1000 |
| 200 | 3000 |
| 300 | 1500 |

## 4. 행별 판정
| EMPNO | SAL | `EMPNO>100` | `SAL>=3000` | (A AND B) | `EMPNO=200` | 최종 |
|---:|---:|:---:|:---:|:---:|:---:|:---:|
| 100 | 1000 | X | X | X | X | **X** |
| 200 | 3000 | ✅ | ✅ | ✅ | ✅ | **✅** |
| 300 | 1500 | ✅ | X | X | X | **X** |

만족하는 행 = EMPNO 200 한 개 → `COUNT(*)` = **1**

> **정답: `1`**

## 5. 암기 포인트
- **AND 먼저, OR 나중**. 의도와 다르면 **괄호**를 쓴다.
- 2024년 1회 18번과 동일한 문제.
