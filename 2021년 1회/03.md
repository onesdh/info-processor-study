# 문제 03

## 문제

다음은 요구사항의 분류에 대한 설명이다. 괄호 (   ) 안에 들어갈 요구사항의 유형에 대해서 쓰시오.

- (   1.   ) 요구사항은 시스템이 제공하는 기능, 서비스에 대한 요구사항이다.

- (   2.   ) 요구사항은 시스템이 수행하는 기능 이외의 사항, 시스템 구축에 대한 제약사항에 관한 요구사항이다.

<details>
<summary><strong>정답 보기</strong></summary>

1. 기능적

2. 비기능적

요구사항이란 시스템 개발 분야에서 어떤 과제를 수행하기 위해, 필요한 조건이나 능력을 말합니다.

- 기능적 요구사항 : 사용자 요구사항, 시스템 요구사항

- 비 기능적 요구사항 : 제품 요구사항, 조직 요구사항, 외부 요구사항

</details>

## 1. 문제에서 묻는 것
**요구사항의 2가지 분류**(기능적 / 비기능적)를 설명과 연결하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 요구사항
시스템 개발에서 **과제를 수행하기 위해 필요한 조건이나 능력**.

### (2) 분류
| 구분 | 의미 | 예 |
|---|---|---|
| **기능적 요구사항** | 시스템이 **제공해야 하는 기능·서비스** ("무엇을 하는가") | 회원가입, 검색, 결제 |
| **비기능적 요구사항** | 기능 외의 **품질·제약사항** ("얼마나·어떻게") | 응답 시간 1초 이내, 보안, 가용성, 이식성 |

### (3) 세부 분류
- 기능적: **사용자 요구사항**, **시스템 요구사항**
- 비기능적: **제품 요구사항**, **조직 요구사항**, **외부 요구사항**

```text
 기능적:    "로그인 기능을 제공한다"              (WHAT)
 비기능적:  "로그인 응답은 2초 이내여야 한다"       (HOW WELL)
```
## 3. 문제 풀이
| 번호 | 단서 | 정답 |
|---|---|---|
| 1 | 시스템이 **제공하는 기능·서비스**에 대한 요구 | **기능적** 요구사항 |
| 2 | 기능 **이외의 사항**, 시스템 구축의 **제약사항** | **비기능적** 요구사항 |

> **정답: 1. 기능적 2. 비기능적**
