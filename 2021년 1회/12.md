## 1. 문제에서 묻는 것
"**공유 메모리, 소켓, 세마포어, 메시지 큐** 등 **프로세스 간 통신**하는 기술" → 약자를 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) IPC (Inter-Process Communication, 프로세스 간 통신)
운영체제에서 **서로 독립된 프로세스들이 데이터를 주고받거나 동기화**하기 위한 메커니즘이다. 프로세스는 기본적으로 **메모리가 분리**되어 있어서 별도 통신 수단이 필요하다.

### (2) IPC 방식
| 방식 | 설명 |
|---|---|
| **공유 메모리(Shared Memory)** | 여러 프로세스가 **같은 메모리 영역**을 공유 — 가장 빠름 |
| **메시지 큐(Message Queue)** | 메시지를 **큐에 넣고 꺼내는** 방식 |
| **파이프(Pipe)** | 한쪽에서 쓰고 다른 쪽에서 읽는 **단방향 통로** |
| **소켓(Socket)** | **네트워크를 통해** (같은 호스트 또는 다른 호스트) 통신 |
| **세마포어(Semaphore)** | 공유 자원 접근을 **동기화(제어)** 하는 신호 장치 |
| 시그널 | 프로세스에 **알림** 전달 |

```text
 프로세스 A ◀──── 공유 메모리 / 메시지 큐 / 파이프 / 소켓 ────▶ 프로세스 B
```
