# 문제 20 — 세션 하이재킹

## 문제

RST 패킷으로 정상 연결을 끊은 뒤 희생자가 아닌 공격자에게 연결을 넘기거나 세션 관리 취약점을 악용하는 공격을 쓰시오.



<details>
<summary><strong>정답 보기</strong></summary>

세션 하이재킹 (Session Hijacking)

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

세션 하이재킹은 유효한 세션을 가로채 인증된 사용자처럼 통신하는 공격이다.

## 풀이

정상 세션을 끊고 공격자가 통신을 이어받는 설명은 세션 탈취다.

## 오답 분석

세션 고정은 공격자가 미리 정한 세션 식별자를 피해자가 사용하게 하는 공격으로, 기존 세션을 가로채는 방식과 구분된다.

## 암기 포인트

세션을 빼앗는 Session Hijacking.

</details>
