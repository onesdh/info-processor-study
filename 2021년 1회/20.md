# 문제 20

## 문제

괄호 안에 공통으로 들어갈 공격 기법을 적으시오.

- (      ) 은/는 '세션을 가로채다' 라는 의미로 정상적 연결을 RST 패킷을 통해 종료시킨 후 재연결 시 희생자가 아닌 공격자에게 연결한다.

- (      ) 은/는 세션 관리 취약점을 이용한 공격 기법이다.

## 1. 문제에서 묻는 것
"'세션을 가로채다'", **RST 패킷으로 정상 연결을 종료시킨 뒤 재연결을 공격자에게**, **세션 관리 취약점 이용**" → 공통으로 들어갈 공격 기법을 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 세션 하이재킹(Session Hijacking)
이미 **인증된 정상 사용자의 세션을 가로채** 인증 없이 사용자 권한으로 접근하는 공격이다.

### (2) 공격 흐름
```text
 ① 공격자가 정상 사용자와 서버의 통신을 감시(스니핑)해 세션 정보(시퀀스 번호, 세션 ID)를 알아냄
 ② 정상 사용자의 연결을 RST 패킷으로 강제 종료시킴
 ③ 서버와의 연결을 공격자가 이어받음(사용자가 아닌 공격자에게 연결)
      정상 사용자 ═╳ (종료)
      공격자 ══════▶ 서버  (사용자 행세)
```
### (3) 원인과 대응
| 원인 | 대응 |
|---|---|
| **세션 관리의 취약점**(예측 가능한 세션 ID, 암호화 미적용) | **HTTPS**, 세션 ID 재발급·만료, 쿠키 `Secure`/`HttpOnly`, 임의적·예측 불가능한 ID |

## 3. 문제 풀이
| 단서 | 세션 하이재킹 |
|---|---|
| '**세션을 가로채다**'라는 의미 | ✅ |
| **RST 패킷**으로 정상 연결 종료 후 **공격자에게 재연결** | ✅ |
| **세션 관리 취약점**을 이용한 공격 | ✅ |

> **정답: 세션 하이재킹 (Session Hijacking)**
