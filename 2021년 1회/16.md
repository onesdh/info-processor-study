# 문제 16

## 문제

데이터를 처리하는 작업 명세, 논리 데이터의 표현 방식, 무결성을 위한 컬럼 제약을 뜻하는 데이터 모델 구성요소를 순서대로 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

연산; 구조; 제약조건

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

데이터 모델은 데이터 구조, 연산, 제약조건으로 구성된다.

## 풀이

처리 작업 명세는 연산, 데이터 표현 방법은 구조, 무결성 유지 규칙은 제약조건이다.

## 오답 분석

구조는 데이터가 어떻게 조직되는지를 말하며 연산과 역할이 다르다.

## 암기 포인트

구조·연산·제약조건의 세 요소.

</details>
