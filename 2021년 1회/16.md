# 문제 16

## 문제

데이터 모델 구성요소 3가지를 쓰시오.

- 데이터베이스에 저장된 실제 데이터를 처리하는 작업에 대한 명세로서 데이터베이스를 조작하는 기본 도구이다.

- 개체 데이터 모델에서는 (  1.  ) 을/를 이용하여 실제 데이터를 처리하는 작업에 대한 명세를 나타내는데 논리 데이터 모델에서는 (  2.  ) 을/를 어떻게 나타낼 것인지 표현한다.

- (  3.  ) 은/는 데이터 무결성 유지를 위한 db의 보편적 방법으로 릴레이션의 특정 칼럼에 설정하는 제약을 의미하며, 개체무결성과 참조 무결성 등이 있다.

## 1. 문제에서 묻는 것
**데이터 모델의 3가지 구성 요소**(연산, 구조, 제약조건)를 설명과 연결하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 데이터 모델의 3요소
데이터베이스에 데이터를 **어떻게 표현하고 다룰지** 정의하는 틀이다.
| 구성 요소 | 의미 |
|---|---|
| **구조(Structure)** | 논리적으로 표현되는 **데이터의 형태·관계**(정적 성질) — "어떻게 나타낼 것인가" |
| **연산(Operation)** | 저장된 **실제 데이터를 처리하는 작업에 대한 명세**, DB를 **조작하는 기본 도구**(조회·삽입·삭제·갱신) |
| **제약조건(Constraint)** | 데이터 **무결성 유지**를 위한 규칙(개체 무결성, 참조 무결성 등) |

```text
 데이터 모델 = 구조(무엇을/어떤 모양으로) + 연산(어떻게 다루나) + 제약조건(어떤 규칙을 지키나)
```
## 3. 문제 풀이
| 번호 | 단서 | 정답 |
|---|---|---|
| 1 | 개체 데이터 모델에서 **실제 데이터를 처리하는 작업에 대한 명세**, 조작 도구 | **연산** |
| 2 | 논리 데이터 모델에서 데이터를 **어떻게 나타낼 것인지** 표현 | **구조** |
| 3 | **데이터 무결성 유지**를 위해 칼럼에 설정하는 제약, 개체·참조 무결성 | **제약조건** |

> **정답: 1. 연산 2. 구조 3. 제약조건**
