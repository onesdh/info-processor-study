# 문제 05 — Python 클래스 리스트 순회

## 문제

good.li의 문자열이 seoul, kyeonggi, inchon, daejeon, daegu, pusan일 때 각 첫 글자를 이어 출력하시오.

## 정답

skiddp

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

문자열 인덱스 0은 첫 문자다. 반복문이 각 문자열의 첫 문자를 누적한다.

## 풀이

s, k, i, d, d, p를 순서대로 붙이면 skiddp다.

## 오답 분석

문자열 전체나 대문자를 출력하는 것이 아니라 각 단어의 첫 글자만 뽑는다.

## 암기 포인트

각 문자열의 0번째 문자를 이어 붙인다.
