# 문제 05

## 문제

다음은 파이썬 코드이다. 출력 결과를 쓰시오.

```
class good :
	li = ["seoul", "kyeonggi","inchon","daejeon","daegu","pusan"]

g = good()
str01 = ''
for i in g.li:
	str01 = str01 + i[0]

print(str01)
```

<summary><strong>정답 보기</strong></summary>

skiddp

각 단어들의 0번째(첫번째 글자) row 출력

</details>

<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
클래스 변수인 **리스트의 각 문자열 첫 글자**를 이어 붙인 결과를 구하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 클래스 변수
```python
class good :
    li = [...]      # 클래스 본문에 선언 → 클래스 변수 (모든 객체가 공유)
g = good()          # 객체 생성
g.li                # 객체를 통해서도 클래스 변수에 접근 가능
```
### (2) 문자열 인덱스
`i[0]` : 문자열의 **첫 글자**. 예) `"seoul"[0]` → `s`

### (3) `for ... in 리스트`
리스트의 원소를 **순서대로 하나씩** 꺼낸다.

## 3. 실행 과정
`str01 = ''` 에서 시작해 각 단어의 첫 글자를 이어 붙인다.
| 반복 | 단어 i | `i[0]` | str01 |
|---:|---|:---:|---|
| 1 | seoul | s | `s` |
| 2 | kyeonggi | k | `sk` |
| 3 | inchon | i | `ski` |
| 4 | daejeon | d | `skid` |
| 5 | daegu | d | `skidd` |
| 6 | pusan | p | `skiddp` |

> **정답: `skiddp`**

## 4. 암기 포인트
- 문자열 인덱스는 0부터 → `[0]` = 첫 글자.
- 문자열 `+`는 **이어 붙이기**.
