# 문제 14

## 문제

주어진 테이블의 Cardinality / Degree를 구하시오.

| 학번 | 이름 | 학년 | 학과 |
|---|---|---|---|
| 20202020 | 김제원 | 3 | 무역과 |
| 20202021 | 김한국 | 1 | 통신과 |
| 20202022 | 허달력 | 4 | 영어과 |
| 20202023 | 이소파 | 2 | 영어과 |
| 20202024 | 장가위 | 3 | 중국어과 |

<details>
<summary><strong>정답 보기</strong></summary>

Cardinality : 5

Degree :  4

Cardinality : 데이터의 행의 수

Degree : 속성의 수

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
주어진 테이블의 **카디널리티(Cardinality)** 와 **차수(Degree)** 를 구하는 문제다.

## 2. 먼저 알아야 할 개념
| 용어 | 의미 | 세는 방법 |
|---|---|---|
| **카디널리티** | **튜플(행)의 개수** | 데이터 행을 센다 (**헤더 제외**) |
| **차수(Degree)** | **속성(열)의 개수** | 열 이름을 센다 |

```text
 학번 │ 이름 │ 학년 │ 학과      ← 속성 4개 → 차수 = 4
 ─────┼──────┼──────┼──────
 ...  │ ...  │ ...  │ ...  ┐
 ...  │ ...  │ ...  │ ...  │ 튜플 5개 → 카디널리티 = 5
 ...                      ┘
```
## 3. 문제 풀이
| 구하는 것 | 센 대상 | 결과 |
|---|---|:---:|
| **카디널리티** | 데이터 행: 김제원, 김한국, 허달력, 이소파, 장가위 | **5** |
| **차수** | 열: 학번, 이름, 학년, 학과 | **4** |

> **정답: Cardinality : 5 / Degree : 4**

## 4. 암기 포인트
- **카디널리티 = 행 수**, **차수 = 열 수**. 헤더 행은 카디널리티에 포함하지 않는다.

</details>
