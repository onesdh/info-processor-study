# 문제 01

## 문제

물리 네트워크(MAC) 주소에 해당하는 IP 주소를 알려주는 프로토콜로 역순 주소 결정 프로토콜을 무엇이라고 하는지 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

RARP (Reverse Address Resolution Protocol)

OSI 7계층은 국제표준화기구(International Standard Organization, ISO)에서 발표한 네트워크 표준 모델로써 네트워크 통신의 각 과정을 계층별로 개념화한 모델이기에 각 계층의 구간별로 데이터의 움직임을 알수 있고, 장치간의 데이터 통신을 설명하는데 유용하게 활용됩니다.

[1계층] 물리 계층 : 전선, 전파, 광섬유, 동축케이블, 도피관, PSTN, DSU, CSU, Modem

[2계층] 데이터 링크 계층 : Ethernet, ToKen Ring, PPP, HDLC, ISDN, ATM

[3계층] 네트워크 계층 : IP, ARP, RARP, ICMP, IGMP, 라우팅 프로토콜

[4계층] 전송 계층 : TCP, UDP, RTP, SCTP, SPX

[5계층] 세션 계층 : TLS, SSH, ISO 8327 / CCITTX225, RPC, NetBIOS

[6계층] 표현 계층 : JPEG, MPEG, XDR, ASN1, SMB, AFP

[7계층] 응용 계층 : HTTP, SMTP, SNMP, FTP, Telnet, SSH&SCP, NFS, RTSP

## 1. 문제에서 묻는 것
"**MAC 주소**에 해당하는 **IP 주소**를 알려주는 **역순 주소 결정 프로토콜**" → 약자를 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) IP 주소와 MAC 주소
| 구분 | IP 주소 | MAC 주소 |
|---|---|---|
| 성격 | **논리적** 주소 (네트워크 위치) | **물리적** 주소 (랜카드 고유번호) |
| 예 | 192.168.0.10 | 00:1A:2B:3C:4D:5E |
| 계층 | 3계층 | 2계층 |

### (2) ARP와 RARP
| 프로토콜 | 변환 방향 | 설명 |
|---|---|---|
| **ARP** (Address Resolution Protocol) | **IP → MAC** | IP 주소를 알 때 그 장치의 MAC 주소를 알아냄 |
| **RARP** (Reverse Address Resolution Protocol) | **MAC → IP** | MAC 주소는 아는데 **IP를 모를 때**(예: 디스크 없는 장비) 서버에 물어 IP를 알아냄 |

```text
 ARP :  "192.168.0.5의 MAC은?"  →  AA:BB:CC:DD:EE:FF     (IP → MAC)
 RARP:  "내 MAC은 AA:BB:...인데 내 IP는?" → 192.168.0.5  (MAC → IP)   ← Reverse(역순)
```
### (3) OSI 계층별 대표 프로토콜
| 계층 | 프로토콜 예 |
|---|---|
| 2 데이터링크 | Ethernet, PPP, HDLC, ATM |
| 3 네트워크 | IP, ARP, RARP, ICMP, IGMP, 라우팅 |
| 4 전송 | TCP, UDP |
| 7 응용 | HTTP, SMTP, FTP, Telnet |

## 3. 문제 풀이
| 단서 | RARP |
|---|---|
| **물리(MAC) 주소**에 해당하는 **IP 주소**를 알려줌 | ✅ |
| **역순** 주소 결정 프로토콜 | ✅ (Reverse) |

> **정답: RARP (Reverse Address Resolution Protocol)**
