# 문제 09

## 문제

다음은 블랙박스 기법에 대한 예제이다. 블랙박스 기법 두 가지를 쓰시오.

예)

1. 0 &lt;= x &lt;= 10이면 -1 0 10 11 검사

2. 입력 데이터의 영역을 유사한 도메인별로 유횻값 / 무횻값을 그룹핑하여 나누어서 검사

블랙박스 테스트 종류

동치 분할 검사(동등분할기법) :

&nbsp;입력 자료에 초점을 맞춰 테스트 케이스를 만들고 검사하는 방법

경계값 분석 :

동치 분할 기법을 보완한 기법으로 입력 조건의 중간값보다 경계값에서 오류가 발생될 확률이 높다는 점을 이용하여 입력 조건의 경계값을 테스트 케이스로 선정하여 검사하는 기법

원인-효과 그래프 검사 :

입력 데이터 간의 관계와 출력에 영향을 미치는 상황을 체계적으로 분석한 다음, 효용성이 높은 테스트 케이스를 선정하여 검사하는 기법

오류 예측 검사 :

과거의 경험이나 확인자의 감각으로 테스트하는 기법

비교 검사 :

여러 버전의 프로그램에 동일한 테스트 자료를 제공하여 동일한 결과가 출력되는지 확인하는 기법

## 1. 문제에서 묻는 것
예제를 보고 해당하는 **블랙박스 기법 두 가지**를 쓰는 문제다. (1) 0 ≤ x ≤ 10일 때 **-1, 0, 10, 11** 검사, (2) 입력 영역을 **유효/무효 그룹**으로 나눠 검사.

## 2. 먼저 알아야 할 개념
### (1) 블랙박스 테스트 기법
| 기법 | 설명 |
|---|---|
| **동치(동등) 분할** | 입력을 **유효/무효 그룹(영역)** 으로 나누고 **그룹별 대표값** 검사 |
| **경계값 분석** | 동치 분할을 보완 — **경계에서 오류가 많다**는 점을 이용해 **경계값**을 테스트 |
| 원인-효과 그래프 | 입력 간 관계와 출력 영향을 분석해 효율적인 케이스 선정 |
| 오류 예측 | 과거 **경험·감각**으로 테스트 |
| 비교 검사 | 여러 버전에 **같은 입력**을 주고 결과가 같은지 비교 |

### (2) 예제 해석
**예 1**: 유효 범위 `0 ≤ x ≤ 10`
```text
 무효 | 유효 0 ........ 10 | 무효
  -1  |  0   (중간)   10   |  11
  ↑ 경계 바로 아래/위, 경계값 자체를 검사
```
**예 2**: 입력 영역을 **유사한 도메인별로 유효값/무효값 그룹핑** → 그룹마다 대표값 → **동치 분할**.

## 3. 문제 풀이
| 번호 | 단서 | 정답 |
|---|---|---|
| 1 | `0 ≤ x ≤ 10`이면 **-1, 0, 10, 11** 검사 (**경계 부근**) | **경계값 분석** |
| 2 | 입력 영역을 유효값/무효값 **그룹으로 나눠** 검사 | **동치(동등) 분할** |

> **정답: 1. 경계값 분석 2. 동등(동치) 분할 테스트**
