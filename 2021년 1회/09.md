# 문제 09 — 경계값과 동등분할 테스트

## 문제

유효 범위가 0부터 10일 때 경계 바깥과 경계를 시험하는 기법, 입력 영역을 유효·무효 동등 클래스로 나누는 기법을 순서대로 쓰시오.

## 정답

경계값 분석; 동등분할 테스트

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

경계값 분석은 오류가 집중되기 쉬운 경계와 인접 값을 선택한다. 동등분할은 같은 방식으로 처리될 입력을 그룹으로 나눈다.

## 풀이

0≤x≤10이라면 -1,0,10,11 같은 경계값 사례를 확인한다. 입력 도메인을 유효·무효 등가 영역으로 나누는 것은 동등분할이다.

## 오답 분석

둘 다 명세 기반 블랙박스 기법이다. 경계값은 경계 주변, 동등분할은 입력 집단 대표값에 초점을 둔다.

## 암기 포인트

경계 주위는 경계값, 입력군은 동등분할.
