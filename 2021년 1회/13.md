# 문제 13

## 문제

시스템 통합에 사용되는 솔루션으로 구축 유형에는 Point to Point, Hub & Spoke, Message Bus가 있다. 기업에서 운영되는 서로 다른 플랫폼 및 애플리케이션 간의 정보를 전달, 연계 , 통합이 가능하도록 해주는 솔루션을 무엇이라고 하는지 쓰시오.

EAI (Enterprise Application integration)

EAI 구축 유형 :

포인트 투 포인트 - 가장 기초적인 애플리케이션 통합 방법 ( 1:1 단순 통합 방법) / 개발자간 대화를 통해 통합 가능

허브 앤 스포크 - 단일한 접점의 허브 시스템을 통하여 데이터를 전송하는 중앙 집중적 방식

메세지 버스 - 애플리케이션 사이 미들웨어를 두어 연계하는 통합 방식 / 뛰어난 확장성과 대용량 데이터 처리 가능

하이브리드 - 그룹 내는 허브 앤 스포크 방식 / 그룹 간에는 메세지 버스 방식 사용하는 통합 방식

## 1. 문제에서 묻는 것
"기업의 **서로 다른 플랫폼·애플리케이션 간** 정보를 **전달·연계·통합**하는 솔루션, 구축 유형: **Point to Point, Hub & Spoke, Message Bus**" → 약자를 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) EAI (Enterprise Application Integration)
기업 내 **여러 응용 시스템(ERP, CRM, 회계 등)** 이 서로 **연동되도록** 데이터와 업무 프로세스를 **통합**하는 솔루션이다.

### (2) EAI 구축 유형
| 유형 | 구조 | 특징 |
|---|---|---|
| **Point-to-Point** | 시스템끼리 **1:1 직접 연결** | **가장 단순**, 시스템이 늘면 연결이 폭증(복잡도 N²) |
| **Hub & Spoke** | **중앙 허브**를 거쳐 전달(스포크=각 시스템) | **중앙 집중**, 관리 쉬움, 허브가 **단일 장애점** |
| **Message Bus** | **미들웨어(버스)** 에 각 시스템이 연결 | **확장성 우수**, **대용량 처리** |
| **Hybrid** | 그룹 내 Hub & Spoke + 그룹 간 Message Bus | 혼합 |

```text
 Point-to-Point:   A─B  A─C  A─D  B─C ...  (선이 매우 많아짐)
 Hub & Spoke:      A ─┐
                   B ─┼─ [ HUB ] ─ D       (모두 허브를 경유)
                   C ─┘
 Message Bus:      A   B   C   D
                   │   │   │   │
               ════╧═══╧═══╧═══╧════  (버스)
```
### (3) 관련 용어
| 약자 | 의미 |
|---|---|
| **EAI** | 기업 **내부** 애플리케이션 통합 |
| ESB | 서비스 지향 **버스**(EAI 발전형, SOA 기반) |
| B2B | 기업 **간** 통합 |

## 3. 문제 풀이
| 단서 | EAI |
|---|---|
| 서로 다른 **플랫폼·애플리케이션 간** 정보 전달·연계·통합 | ✅ |
| 구축 유형 **Point-to-Point, Hub & Spoke, Message Bus** | ✅ |
