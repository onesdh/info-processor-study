# 문제 02

## 문제

다음은 DB 설계 절차에 관한 설명이다. 다음 빈칸에 들어갈 알맞은 용어를 쓰시오.

&nbsp;- (   1.   )은/는 특정 DBMS의 특성 및 성능을 고려하여 데이터베이스 저장 구조로 변환하는 과정으로 결과로 나오는 명세서는 테이블 정의서 등이 있다.

&nbsp;&nbsp;- (   2.   )은/는 현실 세계에 대한 인식을 추상적, 개념적으로 표현하여 개념적 구조를 도출하는 과정으로 주요 산출물에는 E-R 다이어그램이 있다.

&nbsp;- (    3.   )은/는 목표 DBMS에 맞는 스키마 설계, 트랜잭션 인터페이스를 설계하는 정규화 과정을 수행한다.

## 1. 문제에서 묻는 것
**DB 설계 절차**(개념적/논리적/물리적 설계)의 단계별 설명을 단계 이름과 연결하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) DB 설계 절차 5단계
```text
 요구사항 분석 ─▶ 개념적 설계 ─▶ 논리적 설계 ─▶ 물리적 설계 ─▶ 구현
```
| 단계 | 하는 일 | 산출물 |
|---|---|---|
| 요구사항 분석 | 사용자 요구 수집·분석 | 요구사항 명세서 |
| **개념적 설계** | 현실 세계를 **추상적·개념적으로 표현**, 개념적 구조 도출 (**DBMS 독립**) | **E-R 다이어그램** |
| **논리적 설계** | 개념 구조를 **목표 DBMS의 데이터 모델(스키마)** 로 변환, **트랜잭션 인터페이스** 설계, **정규화** | 논리 스키마 |
| **물리적 설계** | **특정 DBMS의 특성·성능**을 고려해 **저장 구조로 변환**(인덱스, 파티션 등) | **테이블 정의서** 등 |
| 구현 | DDL로 DB 생성, 데이터 적재 | 실제 DB |

## 3. 문제 풀이
| 번호 | 단서 | 정답 |
|---|---|---|
| 1 | **특정 DBMS의 특성·성능**을 고려, **저장 구조로 변환**, **테이블 정의서** | **물리적 설계** |
| 2 | 현실 세계를 **추상적·개념적**으로 표현, **E-R 다이어그램** | **개념적 설계** |
| 3 | **목표 DBMS에 맞는 스키마** 설계, 트랜잭션 인터페이스, **정규화** | **논리적 설계** |

> **정답: 1. 물리적 설계 2. 개념적 설계 3. 논리적 설계**

## 4. 암기 포인트
- **E-R = 개념적, 정규화·스키마 = 논리적, 저장 구조·인덱스 = 물리적**.
