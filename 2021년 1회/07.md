# 문제 07

## 문제

다음 Java 프로그램 결과를 쓰시오.

```
public class good{
	public static void main(String[] args){
    	int[][]arr = new int[][]{{45,50,75},{89}};
        System.out.println(arr[0].length);
        System.out.println(arr[1].length);
        System.out.println(arr[0][0]);
        System.out.println(arr[0][1]);
        System.out.println(arr[1][0]);
```

## 1. 문제에서 묻는 것
**2차원 배열(행마다 길이가 다른 가변 배열)** 의 `length`와 원소 값을 출력하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 2차원 배열 = 배열의 배열
Java의 2차원 배열은 **"배열들을 담은 배열"** 이다. 각 행(내부 배열)의 길이가 **서로 달라도** 된다(**가변 배열**).
```java
int[][] arr = new int[][]{ {45, 50, 75}, {89} };
```
```text
 arr ─▶ [ ●─────▶ [45][50][75] ]      arr[0] : 길이 3
        [ ●─────▶ [89]         ]      arr[1] : 길이 1
```
### (2) length
| 표현 | 의미 |
|---|---|
| `arr.length` | **행의 개수**(바깥 배열 길이) |
| `arr[0].length` | **0번 행의 열 개수** |
| `arr[1].length` | 1번 행의 열 개수 |

## 3. 줄별 출력
| 코드 | 의미 | 출력 |
|---|---|:---:|
| `arr[0].length` | 첫째 행 {45,50,75}의 길이 | **3** |
| `arr[1].length` | 둘째 행 {89}의 길이 | **1** |
| `arr[0][0]` | 첫째 행 첫째 값 | **45** |
| `arr[0][1]` | 첫째 행 둘째 값 | **50** |
| `arr[1][0]` | 둘째 행 첫째 값 | **89** |

> **정답**
> ```
> 3
> 1
> 45
> 50
> 89
> ```
> (`println`이므로 각각 줄바꿈되어 출력)

## 4. 암기 포인트
- 행마다 길이가 다를 수 있다 → `arr[행].length`로 각각 확인.
- 인덱스는 0부터.
