# 문제 07 — Java 비정형 배열

## 문제

첫 행이 {45,50,75}, 둘째 행이 {89}인 2차원 배열에서 각 행 길이와 지정 인덱스 값을 출력하시오.

## 정답

3; 1; 45; 50; 89

<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

Java 2차원 배열은 배열의 배열이므로 각 행의 길이가 다를 수 있다.

## 풀이

arr[0].length=3, arr[1].length=1, 나머지 접근은 각각 45,50,89다.

## 오답 분석

전체 행 수 2와 각 행의 열 수를 구분한다. 둘째 행에는 원소가 하나뿐이다.

## 암기 포인트

행마다 길이를 따로 확인.
