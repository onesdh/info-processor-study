# 문제 08

## 문제

정규화된 엔티티, 속성, 관계에 대해 성능 향상과 개발 운영의 단순화를 위해 중복, 통합, 분리 등을 수행하는 데이터 모델링의 기법을 무엇이라고 하는지 쓰시오.

비정규화 or 반정규화 or 역정규화

반정규화 방법 :

테이블 통합, 테이블 분할, 중복 테이블 추가, 중복 속성 추가

## 1. 문제에서 묻는 것
"정규화된 엔티티·속성·관계에 대해 **성능 향상과 개발·운영의 단순화**를 위해 **중복, 통합, 분리** 등을 수행하는 데이터 모델링 기법" → **반정규화**를 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 정규화 vs 반정규화
| 구분 | 정규화 | **반정규화(비정규화, 역정규화)** |
|---|---|---|
| 목적 | **중복 제거**, 이상 현상 방지 | **조회 성능 향상**, 개발·운영 단순화 |
| 방법 | 테이블 **분리** | 테이블 **통합·분할**, **중복 추가** |
| 장점 | 무결성↑ | **JOIN 감소로 조회 빠름** |
| 단점 | JOIN 증가로 조회 느릴 수 있음 | **무결성 저하**(중복 관리 부담) |

```text
 정규화:   주문 + 고객(분리)       → JOIN 필요
 반정규화: 주문(고객명 중복 저장)   → JOIN 없이 빠른 조회, 대신 고객명 변경 시 여러 곳 수정
```
### (2) 반정규화 방법
| 방법 | 설명 |
|---|---|
| **테이블 통합** | 자주 JOIN하는 테이블을 합침 |
| **테이블 분할** | 수직(열)·수평(행) 분할 |
| **중복 테이블 추가** | 집계·조회용 테이블 |
| **중복 속성 추가** | 자주 쓰는 열을 다른 테이블에 복사 |

## 3. 문제 풀이
| 단서 | 반정규화 |
|---|---|
| **정규화된** 모델에 대해 성능 향상을 위해 **중복·통합·분리** | ✅ |
| 개발·운영의 단순화 | ✅ |

> **정답: 반정규화 (비정규화, 역정규화)**
