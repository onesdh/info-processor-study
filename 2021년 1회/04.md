# 문제 04 — WSDL

## 문제

웹 서비스명, 위치, 메시지 형식, 프로토콜 등의 상세 정보를 XML로 기술하는 언어를 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

WSDL (Web Services Description Language)

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 핵심 개념

WSDL은 웹 서비스가 제공하는 작업과 메시지, 바인딩 및 접근 위치를 기술하는 XML 기반 설명 언어다.

## 풀이

서비스 인터페이스와 통신 정보를 기술하므로 WSDL이다.

## 오답 분석

SOAP는 메시지 교환 프로토콜이고 UDDI는 서비스 등록·검색과 관련된다.

## 암기 포인트

서비스 설명은 WSDL.
