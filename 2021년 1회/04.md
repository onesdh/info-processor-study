# 문제 04

## 문제

웹 서비스명, 제공 위치, 메세지 포맷, 프로토콜 정보 등 웹 서비스에 대한 상세 정보가 기술된 XML 형식으로 구성된 언어를 무엇이라고 하는지 쓰시오.

<details>
<summary><strong>정답 보기</strong></summary>

WSDL

WSDL(Web Services Description Language의 약자)은 웹 서비스 기술언어 또는 기술된 정의 파일의 총칭으로 XML로 기술됩니다. 웹 서비스의 구체적 내용이 기술되어 있으며 서비스 제공 장소, 서비스 메시지 포맷, 프로토콜 등이 기술됩니다.

## 1. 문제에서 묻는 것
"웹 서비스명, 제공 위치, **메시지 포맷, 프로토콜** 등 웹 서비스의 **상세 정보를 기술한 XML 언어**" → 약자를 쓰는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 웹 서비스와 3대 요소
웹 서비스는 네트워크를 통해 **서로 다른 시스템이 기능을 주고받는** 기술이다. 3가지 표준이 핵심이다.
| 표준 | 역할 | 비유 |
|---|---|---|
| **SOAP** | 서비스 **요청·응답 메시지 포맷**(XML 기반) | 편지 봉투 규격 |
| **WSDL** | 서비스의 **설명서** — 서비스명, **위치(주소)**, 메시지 포맷, 프로토콜, 제공 함수 | **서비스 안내서** |
| **UDDI** | 서비스를 **등록·검색**하는 저장소 | 전화번호부 |

```text
 서비스 제공자 ─(등록: WSDL)▶ [ UDDI 레지스트리 ] ◀─(검색)─ 서비스 이용자
        ▲────────────── SOAP 메시지로 호출/응답 ──────────────▼
```
### (2) WSDL (Web Services Description Language)
웹 서비스에 **무엇이 있고, 어디 있고, 어떻게 호출하는지**를 **XML로 기술**한 정의 파일(웹 서비스 기술 언어). 서비스 제공 장소, 서비스 메시지 포맷, 프로토콜 등이 기술된다.

## 3. 문제 풀이
| 단서 | WSDL |
|---|---|
| 웹 서비스의 **상세 정보 기술** (서비스명, 제공 위치, 메시지 포맷, 프로토콜) | ✅ |
| **XML 형식**으로 구성된 언어 | ✅ |

> **정답: WSDL (Web Services Description Language)**
