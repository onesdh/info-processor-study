# 문제 15

## 문제

다음은 C언어 프로그램이다. 실행 결과를 쓰시오.

```
#include <stdio.h>

struct good {
	char name[10];
    int age;
 };

 void main(){
 	struct good s[] = {"Kim",28,"Lee",38,"Seo",50,"Park",35};

    struct good *p;
    p = s;
    p++;
    printf("%s\n", p-> name);
    printf("%d\n", p-> age);
```

<summary><strong>정답 보기</strong></summary>

Lee

38

p++로 인해 s[1]가 되면서 두번째 배열인 Lee와 38이 출력이 된다.

</details>



<details>
<summary><strong>상세 해설</strong></summary>

## 1. 문제에서 묻는 것
**구조체 배열과 포인터 증가(`p++`)** 로 두 번째 요소의 멤버를 출력하는 문제다.

## 2. 먼저 알아야 할 개념
### (1) 구조체 배열
```c
struct good { char name[10]; int age; };
struct good s[] = {"Kim",28, "Lee",38, "Seo",50, "Park",35};
```
```text
 s[0] = {"Kim", 28}    s[1] = {"Lee", 38}    s[2] = {"Seo", 50}    s[3] = {"Park", 35}
```
### (2) 구조체 포인터와 `->`
```c
struct good *p;
p = s;          // p는 s[0]을 가리킴
p++;            // 구조체 1개 크기만큼 이동 → s[1]을 가리킴
p->name         // = (*p).name
```
**포인터 증가는 가리키는 자료형의 크기 단위로 이동**한다. `struct good`을 가리키므로 `p++`는 **다음 구조체**로 넘어간다.

## 3. 실행 과정
| 단계 | p가 가리키는 곳 |
|---|---|
| `p = s` | s[0] (Kim, 28) |
| `p++` | **s[1] (Lee, 38)** |

| 출력 | 값 |
|---|---|
| `printf("%s\n", p->name)` | **Lee** |
| `printf("%d\n", p->age)` | **38** |

> **정답**
> ```
> Lee
> 38
> ```

## 4. 암기 포인트
- `p++`는 **구조체 한 칸** 이동 (바이트 1이 아님).
- `p->멤버` = 포인터가 가리키는 구조체의 멤버.
